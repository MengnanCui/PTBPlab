关键信息

M6h 的第一块：分子（非周期）的长程校正 LC-DFTB 与 CAM 杂化泛函（含 β = 0 的全局杂化）的基态——能量、哈密顿量、SCC、力、共线自旋、三种 Screening。交换项依赖整个密度矩阵，不只是 Mulliken 电荷，所以 SCC 要混合整个 ΔP。只做 NumPy 引擎，不开杂化时逐位不变。后续：M6h-2 TD-LC（Casida 与激发态的力），M6h-3 周期体系，M6h-4 杂化泛函下的响应。

  • DFTB+ 的做法（第一节）：Hybrid = LC {…} | CAM {…}；ω、α、β 只来自 SK 文件末尾的 RangeSep 段；默认 Screening = MatrixBased（精确）。交换的哈密顿量 Hx = c[(SΔPS)∘Γ + ((SΔP)∘Γ)S + S(ΔP∘Γ)S + S((ΔPS)∘Γ)]，c = −1/8，自旋时每个自旋 −1/4；能量 ½Σ Hx[ΔPin]∘ΔPin；混合器混 ΔP 的下三角，输入电荷与块布居都由混合后的 ΔPin 导出；力用 ΔPout。
  • 原型已与 DFTB+ 25.1 逐轮一致（第二节，探针 P34–P38）：LC、CAM、全局杂化、自旋，ob2 与我们自己的参数集，三种 Screening；SCC 轮数相同（Thresholded 1e-8 时差 1 轮），每轮 SCC 误差在 DFTB+ 打印的 8 位内相同，总能量差 ≤ 6.3e-13 Ha，电荷 ≤ 7e-13，力 ≤ 9e-12（用 DFTB+ 的 SK 差分步长）。
  • pydftb 的做法（第三、四节）：DFTB(sk, hybrid="lc" | "cam" | {…})；新模块 pydftb/hybrid.py（γHF、γLR 及导数、P0、三种 Screening 的 Fock 矩阵、能量与梯度）；SCC 的混合向量换成打包的 ΔP，其余路径（自旋、+U/onsite 块势、外场、点电荷、溶剂、色散）不动，输入布居由 ΔPin + P0 经现有的布居函数得到。
  • ≤ 6.3e-13原型与 DFTB+ 25.1 的总能量之差（Ha，13 个探针算例）
  • 0SCC 轮数之差（Thresholded 1e-8 除外，差 1 轮）
  • 3Screening：MatrixBased、NeighbourBased、Thresholded，都逐位复现 DFTB+ 的算法

一、DFTB+ 的做法

源码 041e723（25.1 之后 132 个提交；dftb/hybridxc.F90、dftb/rshgamma.F90、type/oldskdata.F90、dftbplus/parser.F90、dftbplus/main.F90），行为以 25.1 的二进制为准。

  • 输入：Hamiltonian = DFTB { Hybrid = LC {…} | CAM {…} }，要求 SCC = Yes。
    • Screening 默认 MatrixBased（稠密、精确；手册写的默认 Thresholded 是旧版本的）；NeighbourBased { CutoffReduction = 0 }；Thresholded { Threshold = 1e-6, CutoffReduction = 0 }（只用于分子）。
    • 没有 ω、α、β 的 HSD 覆盖，只来自 SK 文件。LC 要求 LC 的 SK 文件；CAM 接受 LC、全局、CAM 三种文件。手册里的 Hybrid = Global 解析器不认：全局杂化写成 CAM 加 β = 0 的文件。
    • 解析器版本 ≤ 13 的 RangeSeparated 被改名为 Hybrid，没有 Screening 的旧 LC 输入补上 Thresholded {}。
  • SK 文件的 RangeSep 段：整行为 RangeSep，下一行 LC ω 或 CAM ω α β（ob2 等放在样条之后、<Documentation> 之前）。CAM 按 α、β 重新归类：α ≈ β ≈ 0 报错，α ≈ 0、β ≈ 1 为 LC，β ≈ 0 为全局；ω < 0 报错。DFTB+ 按物种顺序读每个 A ≤ B 的文件（含异核），缺这一段就报错；文件之间不检查一致，最后读到的为准。
  • γ（rshgamma.F90）：τ = 3.2 U（第一个壳层的 U，即非按壳层 SCC 时的 U）；γ = α γHF + β γLR(ω)，系数小于 100 ε 的项不算。
    • 在位（R < 1e-5 Bohr）：γHF = 5τ/16 = U；γLR = 5τ/16 − τ³[(5τ⁶ + 15τ⁴ω² − 5τ²ω⁴ + ω⁶)/16 − ωτ⁵]/(τ² − ω²)⁴。
    • 同 U（|τA − τB| < 3.125e-6）与异 U 的闭式，及其对 R 的解析导数（异 U 用 Y 子式）。
  • 密度与 Fock 矩阵：ΔP = P − P0，P0 是对角的参考布居 q0,μ（分子 Sμμ = 1；自旋时每个自旋一半）。MatrixBased：Hx[ΔP] = c[(SΔPS)∘Γ + ((SΔP)∘Γ)S + S(ΔP∘Γ)S + S((ΔPS)∘Γ)]，Γ 是按轨道展开的原子对 γ，即 Hμν = c Σαβ SμαΔPαβSβν(γμν + γμβ + γαβ + γαν)；它加在 SCC 与自旋的移动之后，每个自旋一份，用的是本轮的输入 ΔPin。
  • 能量：EFock = ½ Σσ Σ Hx[ΔPin]∘ΔPin（detailed.out 的 “Energy Fock”，计入电子能量；results.tag 没有单独一项）。EH0 用输出密度、ESCC 用输出电荷（RecomputeAfterDensity），所以各项只在收敛时自洽。
  • SCC（main.F90 getNextInputDensityReal）：
    • 混合器混稠密的 ΔPin（nOrb² × nSpin，只有下三角，上三角为零）；误差 max|ΔPout − ΔPin|；收敛条件还要求 iSCC ≥ minSccIter（自旋或 +U 时 2），读入电荷或几何步 > 0 时不要求。
    • ΔPin 从 0 开始（第一轮没有交换项），qin = q0；自旋时第一个几何步的第一轮不混合，直接 ΔPin := ΔPout（块布居同样）。
    • 混合之后 qin = Mulliken(ΔPin) + q0（自旋时各加一半），块布居 = 块 Mulliken(ΔPin)，对角换成 qin；SCC、自旋、+U/onsite 的势都由它们给出。
    • 几何步之间沿用 ΔPin（MD 第二步的第一轮误差 4e-3，从零开始时是 0.93）。
  • 三种 Screening（分子）：
    • NeighbourBased：同 MatrixBased，只是距离超过 CAM 截断（最大 SK 截断 − CutoffReduction）的原子对的 S 块当作零；CutoffReduction = 0 时与 MatrixBased 相同。
    • Thresholded：增量构建，Hprev += ΔH[ΔΔP]，ΔΔP = ΔPin − 上一次的 ΔPin；原子块按 max|S| 排序，max|ΔΔP|·max|SCA|（再乘 max|SDB|）小于阈值的跳过；只算下三角再对称化；系数固定 −1/8（不能用于自旋）；几何改变时 Hprev 与上一次的 ΔP 清零。
    • 力不受 Screening 影响：分子的梯度总用完整的 SK 近邻表与 ΔPout，所以 CutoffReduction > 0 或 Thresholded 时力与能量不完全自洽。
  • 力：∂Ex/∂R 在固定 ΔPout 下由两部分组成：S 的导数（四项的“交换”结构）与 γ 的导数（所有原子对）；本征方程的 dS 项已在能量加权密度矩阵里（H 含 Hx）。不算应力（初始化时静默关掉）。
  • 拒绝：非 SCC；SOC；按壳层 SCC；ThirdOrder（只查这一个，ThirdOrderFull 能算）；XL-BOMD；按原子的能量；坐标导数与有限频率的响应；非共线只用 MatrixBased 且只用于分子；Thresholded 加自旋；TD-LC 只能用 Stratmann，不能用窗口、分数占据、onsite 修正、周期体系、一般的 CAM。

探针 P34–P38（草稿目录 m6h/）。原型 lcproto.py 在 pydftb 现有的 SCC 上加 γHF/γLR（照抄 rshgamma.F90）、P0、四项 Hx、ΔP 下三角的混合与力，对照 DFTB+ 25.1。

三、pydftb 的接口

sk = ParamSet("ob2-1-1/shift", max_l={"C": 1, "H": 0}).skset(labels)   # 带 RangeSep 的 SK 文件
r = DFTB(sk, hybrid="lc").calculate(labels, pos)            # MatrixBased（DFTB+ 的默认）
r.e_fock                                                     # DFTB+ "Energy Fock"，已计入 energy
DFTB(sk, hybrid={"type": "cam", "screening": "neighbour", "cutoff_reduction": 4.0})   # Bohr
DFTB(sk, hybrid={"type": "lc", "screening": "threshold", "threshold": 1e-6})
  • 选项：hybrid 为 "lc"、"cam" 或字典（type、screening = "matrix" | "neighbour" | "threshold"、threshold、cutoff_reduction，长度用 Bohr）。ω、α、β 只取自 SK 文件，与 DFTB+ 相同。
  • SK 文件：SKFile.range_sep 读出这一段并按 DFTB+ 的规则归类；SKSet.range_sep 汇总：每个同核文件、每对元素至少一个方向的文件要有这一段，所有出现的值必须相同（比 DFTB+ 严）。LC 要求 LC 的文件，CAM 接受三种；文件带这一段而没有开 hybrid 时报错（与 DFTB+ 相同）。
  • 结果：新字段 DFTBResult.e_fock（不开杂化时为 0）；terms 加 “Fock”；q_in、q_out 为 [布居 | 打包的 ΔP]（布居照不开杂化时的布局，ΔP 取下三角、每个自旋一段），scc_errors 是 max|ΔPout − ΔPin|。q_init 接受整个向量，或只有布居（ΔPin = 0，相当于 DFTB+ 读入不带密度矩阵的电荷文件）；ASE 计算器的 reuse_charges 与 SCC 的重启传整个向量，几何步之间沿用 ΔPin 与布居本身（DFTB+ 也不按新的重叠重算 qin）。
  • 能用：共线自旋（固定或自由总自旋）、Fermi/Gauss/MP 展宽、+U 与 onsite 修正、third_order="full"、外场、点电荷、隐式溶剂、色散、H5 与卤素修正、自定义 Hubbard 与参考占据、全部混合器、结构优化与 MD。
  • 拒绝（按 DFTB+ 的文字或注明里程碑）：周期体系（M6h-3）、torch 与自动求导、非 SCC、SOC、非共线（M6h-1 之后）、按壳层 SCC、third_order="onsite"、XL-BOMD、按原子的能量、Casida（M6h-2）、极化率与响应核（M6h-4）、坐标导数、TruncateSKRange（DFTB+ 静默忽略）、SelectedShells、类型切换、Thresholded 加自旋。
  • 电荷文件：DFTB+ 的 charges.bin/dat（格式 8）在布居与块之后存每个自旋的 ΔPin（整个 N × N，按列，每个值一条记录；DFTB+ 的矩阵只有下三角）。charge_data 写出、populations_from_file 读入；文件没有密度矩阵时只给布居（ΔPin = 0，与 DFTB+ 相同），不开杂化的计算忽略文件里的密度矩阵。DFTB+ 拒绝 Thresholded 的重启，pydftb 允许（第一次构建用整个 ΔP）。
  • 本征态：bands.eigenstates（SCC.states()、PyDFTB.states()）从 q_in 重建 SCC 最后一轮的哈密顿量，含 Hx[ΔPin]；Thresholded 时是一次完整的构建，不是 SCC 累加的那个（差在阈值量级）。
开发细节四、实现

新模块 pydftb/hybrid.py

  • gamma_hf、gamma_lr、gamma_cam 与导数：逐行移植 rshgamma.F90（在位、同 U、异 U 三支，阈值 1e-5 Bohr 与 3.125e-6，100 ε 的系数规则），对原子对向量化。
  • Hybrid（选项归一化，pydftb.Hybrid）与 HybridTerms（只依赖几何，进 _Setup.hybrid）：原子对 γ 与按轨道展开的 Γ，稠密 S，P0（参考占据按 _reference_shell_populations，含 reference_occupations），CAM 近邻掩码，Thresholded 的状态。
  • fock(ΔP, nspin)：MatrixBased 四个矩阵乘；NeighbourBased 用截断的 S；Thresholded 按原子对 (A, B ≤ A) 向量化 C、D 的掩码与权重，ΔHAB = S·AT(ΔΔP∘W)S·B，再对称化、累加。
  • energy 与 gradient(ΔP_out)：∂E/∂S = c[(D∘Γ)SD + ((DS)∘Γ)D + (DS)(D∘Γ) + D((SD)∘Γ)]（对称）在成对元素上加进 dS 的系数；∂E/∂Γ = c[D∘(SDS) + (DS)∘(SD)] 按原子对求和后乘 γ′(R)。自旋时对两个自旋求和，c = −1/4。

计算器

  • _setup：hybrid 选项时建 HybridTerms；_SCCState.hybrid 存 ΔPin、ΔPout、EFock 与打包的向量。golden 用 --allow-new 放过 _Setup.hybrid、_SCCState.hybrid、DFTBResult.e_fock 三个新字段。
  • _scc 的杂化分支：xin = 0（或 q_init）；每轮 H += Hx[ΔPin]（每个自旋）；求解后 xout = pack(ρout − P0)，误差与混合都在 x 上；qin = _populations(ρin = ΔPin + P0)，于是 SCC 位点、自旋壳层、块向量三种布局都由现有代码给出，与 DFTB+ 的“Mulliken(ΔPin) + q0、块 Mulliken 对角换成 qin”完全相同（同一原子内 S 为单位阵，P0 的非对角块为零）。
  • 第一轮规则按 DFTB+ 的杂化分支：只有自旋（及两分量）时第一轮不混合；min_iter 照 getMinSccIters（自旋或 +U 时 2），给出 q_init 时为 1；onsite 修正第一轮不加的规则不变。
  • _energies：EFock 计入 energy 与 free_energy；DFTBResult.q_in/q_out 为 [布居 | 打包的 ΔP]。
  • _gradient：交换项的 dS 系数加在 coef_s 上（与带结构项一起走 _add_pair_terms），γ′ 项按原子加。
  • 写出：detailed.out 风格的能量行加 “Energy Fock”；charges.bin/dat 带密度矩阵（ChargeData.rho）。

六、DFTB+ 的问题与 pydftb 的做法

DFTB+ 的情况pydftb
手册写 Screening 默认 Thresholded、有 Hybrid = Global；代码默认 MatrixBased、没有 Global照代码：默认 matrix，全局杂化用 "cam" 加 β = 0 的文件
SK 文件之间不检查 ω、α、β 是否一致：类型取第一个物种的文件，参数取最后读到的文件；只检查 A ≤ B（物种顺序）的文件所有出现的值必须一致，否则报错；每对元素任一方向的文件有这一段即可
只拒绝 ThirdOrder，ThirdOrderFull 能算支持 "full"（参考算例 ch3oh_lc_dftb3_d3 与 DFTB+ 一致），拒绝 "onsite"
拒绝 Thresholded 的重启（读电荷文件）允许：重启时第一次构建用整个 ΔP
异 U 的 γ 闭式在 U 几乎相同时严重抵消（|ΔU| = 1e-6 时 γLR 错 2.2，1e-4 时 2.4e-7）τ 相差 5 % 以内用 Hermite–Genocchi 积分（与 M2b 的 SCC γ 相同），其余照抄

七、不做的事与风险

  • 周期体系（Γ 点与 k 点、截断的库仑）在 M6h-3；TD-LC 在 M6h-2；响应在 M6h-4；非共线的杂化（DFTB+ 只用 MatrixBased、只用于分子）在 M6h-1 之后补。
  • 规模：MatrixBased 每轮四个 N × N 矩阵乘，Broyden 存 N(N+1)/2 × 轮数的向量；几千个轨道以内可以，更大的体系应换 NeighbourBased 的稀疏实现（不在本块）。
  • Thresholded 的增量算法对舍入敏感：SCC 误差降到阈值附近以后，筛选的取舍随舍入翻转，末尾的轮数在两个程序之间不同（结果相同）。参考算例用 SCC 容差 1e-6（两边都在第 19 轮停，每轮误差相同到 5e-8）。
  • 简并的半满壳层：OH 自由基少数自旋的 π 对只有一个电子，交换（或 +U）让对称性破缺，破缺的方向由舍入决定；两个程序到达等价而取向不同的解，能量相同到 1e-11，轨道布居与轮数不同。这样的体系不能逐轮对照，参考算例用弯曲的 HCO 自由基；CuCO（奇数电子）加 +U 时两边的 SCC 都发散，换成闭壳层的 CuH。
  • 金属团簇（Cu4CO）加 LC 时 DFTB+ 的默认 Broyden 不收敛，pydftb 相同；需要时换混合器或减小混合参数。
