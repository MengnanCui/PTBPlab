关键信息

M6f“常用缺口与分析输出”的第一块：SCC 从哪里开始、每轮怎样混合。补上 DFTB+ 的 Simple、Anderson、DIIS 三种混合器和 Broyden 的全部选项，InitialCharges、共线自旋的 InitialSpins，以及 DFTB+ 的电荷重启文件 charges.bin/charges.dat 的读写（ReadInitialCharges）。目标不只是收敛到同一个解，而是每一轮的 SCC 误差都与 DFTB+ 相同。只做 NumPy 引擎；默认设置下逐位不变。

  • DFTB+ 的做法（第一节，源码 mixer/*.F90、dftb/sccinit.F90）：
    • 三种混合器各有自己的历史存储方式和第一轮的规则，要逐轮一致就必须照抄这些细节（Anderson 的倒序索引环、DIIS 的循环槽位、DynMixingParameters 从最后一项往前查）；
    • InitialCharges 不是“把电荷平均放到轨道上”，而是按 SKF 的壳层顺序逐层填满（aufbau），Cu 多 0.2 个电子时起点是 4s2 4p6 3d3.2；
    • 电荷文件的格式号是 8：头、每个轨道的布居（一类轨道的总量放在第一个轨道上）、多极记录 0 0、+U 时的布居块；文本版是 gfortran 的 list-directed 输出。
  • 探针（第二节）：
    • 9 种“混合器 × 体系”的组合，pydftb 的轮数与 DFTB+ 全部相同，逐轮的 SCC 误差一致到 4e-8 – 2.3e-5（相对，SCC 越长越大）；
    • 7 个初始电荷、初始自旋的组合，轮数相同，第一轮误差一致到 DFTB+ 打印的 8 位；
    • DFTB+ 写的 12 个电荷文件（5 个文本、7 个二进制）pydftb 读入后再写出，逐字节相同；两边互相读对方的文件重启，轮数相同。
  • 探针中发现的坑：
    • SCC 位点很少时（H2O 只有 3 个），DIIS 的矩阵从第 3 个向量起奇异（电荷守恒使各 F 之和为零），两边都在跟随舍入误差；参考算例避开这种情况；
    • 周期体系要用 EwaldTolerance = 1e-12：DFTB+ 默认的 1e-9 使逐轮误差相差 1e-5，CuO 链 Anderson 的轮数差 1；
    • 非共线自旋读电荷重启时，DFTB+ 不读 InitialSpins，并因“未读的输入节点”而停止。
  • pydftb 的接口（第三节）：DFTB(mixer=…, mixing=…, initial_charges=…, initial_spins=…)，calculate(q_init=ChargeData)，dftbplus_io.read_charges/write_charges，PyDFTB(read_charges=…) 与 write_charges()。注意：mixer="anderson" 现在指 DFTB+ 的 Anderson；pydftb 原来叫 "anderson" 的 Pulay 型混合器改名为 "pulay"（仓库里没有代码用过 "anderson"）。
  • 4DFTB+ 的混合器（Broyden、Simple、Anderson、DIIS），逐轮照抄
  • 0探针中 SCC 轮数与 DFTB+ 之差（16 个组合）
  • 12DFTB+ 电荷文件逐字节往返

一、DFTB+ 的做法

记号：q 是一轮 SCC 的输入布居（混合的向量），qout 是它构造的哈密顿量给出的输出布居，F = qout − q。DFTB+ 打印的“SCC error”是 max|F|，小于 SCCTolerance 即收敛，最后一轮之后不再混合。

混合的向量

  • DFTB+ 把轨道布居按“等价类”求和后混合（reduceCharges）：
    • 一类是同一原子上 Hubbard U 相同的轨道（uniqHubbU%getOrbitalEquiv）：原子分辨的 SCC 是整个原子，壳层分辨时一般是一个壳层；
    • 自旋时先把 (q, m) 换成 (上, 下) 再归类，所以混合的是上、下两个通道；非共线时是 q、mx、my、mz 四个；
    • +U 或 onsite 修正时，后面接上布居块中的独立元素（M6b）。
    pydftb 从 M2c、M6a、M6b 起混合的就是同样的向量。唯一的已知差别：壳层分辨时，同一原子上 U 恰好相等的两个壳层在 DFTB+ 中合成一类，pydftb 仍分开混合。这只影响 SCC 的路径，不影响解；参考算例避开这种情况。
  • 每个几何步开始时混合器重置（main.F90 的 chrgMixerReal%reset），历史不跨步保留。
  • 第一轮的特殊规则（M2c、M6b 已实现）：自旋或块混合、且没有读电荷时，第一轮的输出直接作为第二轮的输入，不经过混合器。

四种混合器

混合器关键字与默认值做法
Broyden（默认）MixingParameter 0.2、InverseJacobiWeight 0.01、MinimalWeight 1、MaximalWeight 1e5、WeightFactor 0.01修正的 Broyden（Johnson 1988），pydftb 从 M1 起照抄；本次只是把选项开放出来
SimpleMixingParameter 0.05q′ = q + βF
AndersonMixingParameter 0.05、Generations 4、InitMixingParameter 0.01、DynMixingParameters、DiagonalRescaling 0.01见下
DIISInitMixingParameter 0.2、Generations 6、UseFromStart Yes见下
  • Anderson（andersonmixer.F90）：
    • 保存 m = Generations − 1 组以前的 (qi, Fi)。存储用一个倒序的索引环：indx(1) 指向最新的一组，每次存入时整个环右移一位，最后一个槽位转到最前面被覆盖；
    • 计数 n 从 −1 开始：前 Generations 次调用用 InitMixingParameter，之后用 MixingParameter；
    • DynMixingParameters 是若干行 (阈值, β)：从最后一行往前找第一个阈值大于 |F|（2-范数）的行，用它的 β。第一次调用不受影响，因为第一次总是 q + βinitF；
    • 之后解 A c = b：Aij = ⟨F − Fj | F − Fi⟩，bi = ⟨F | F − Fi⟩；DiagonalRescaling = ω0 > 0 时 Aii 乘以 (1 + ω02)；
    • F̄ = Σ ciFi + (1 − Σc)F，q̄ = Σ ciqi + (1 − Σc)q，新输入 q′ = q̄ + βF̄。
  • DIIS（diismixer.F90）：
    • Generations 个循环槽位，indx = mod(indx, m) + 1，新的一组写到 indx；
    • UseFromStart，或槽位已满时：解加边的方程 [⟨Fi|Fj⟩, −1; −1, 0][c; λ] = [0; −1]，q′ = Σ ci(qi + Fi)；
    • 槽位未满时再加 InitMixingParameter·F；UseFromStart = No 时，未满之前就是简单混合；
    • 源码里还有 AddIntrpGradient，但输入解析从不设置它，恒为关。

InitialCharges 与 InitialSpins

  • 写法：InitialCharges { AllAtomCharges = {…} }，或若干 AtomCharge { Atoms = …; ChargePerAtom = … }（没写的原子为 0）；InitialSpins 在 SpinPolarisation = Colinear {…} 中，用 AllAtomSpins 或 AtomSpin { Atoms; SpinPerAtom }，每个原子一个数 N↑ − N↓。
  • 电荷（initQFromAtomChrg）：
    • 原子 A 的电子数 NA = Σ 参考占据 − qA，按 SKF 中壳层的顺序逐层填，每层最多 2(2l+1)，在 m 上平均分；
    • 填完还剩超过 1e-4 时报错 “Not enough orbitals on species … to hold specified atomic charges”；
    • 所有原子的电荷之和不等于 Charge 时警告（“Your initial charge distribution will be rescaled”）；
    • 最后整体缩放到总电子数（没有 InitialCharges 时也做这一步）。
  • 自旋（initializeCharges）：原子的自旋按壳层布居的比例分到各壳层，m壳层 = q壳层·SA / ΣA 的壳层 q。没有 InitialSpins 时，各壳层 m = q·(N↑ − N↓)/N（M2c 已实现）。
  • 读了电荷文件时，InitialCharges 和 InitialSpins 都不用。

电荷重启文件

  • 写出（writeQToFile）：收敛后，以及每 RestartFrequency（默认 20）轮，写最后一轮的输入布居。二进制是 Fortran 流式文件（没有记录标记，整数与逻辑量 4 字节，实数 8 字节）；WriteChargesAsText = Yes 时写 charges.dat。
  • 格式 8：
    1. 格式号 8；
    2. 五个逻辑量：布居块、虚部布居块、密度矩阵、k 点信息、多极（DFTB 中恒为真）；原子数；自旋通道数；每个通道的 checksum = sum(sum(qq, dim=1), dim=1)；
    3. 每个通道、每个原子一条记录，是各轨道的布居。共线自旋的两个通道是 (q, m)，非共线是 (q, mx, my, mz)。一类轨道的总量放在该类第一个轨道上，其余为 0（OrbitalEquiv_expand 的结果）；
    4. 多极记录：原子偶极数与四极数，文本中是 (2I2) 格式的 “ 0 0”；
    5. +U 或 onsite 修正时，每个通道、每个原子的布居块，一行是块的一列；有虚部块时再写一遍。块的对角只存独立元素，读入时对角用 qq 重建。
  • 读入（initQFromFile）：接受格式 4–8（4 没有原子数，4–5 没有多极记录，6 没有 k 点标志）；文件的原子多于体系时报错，少于时其余为 0；自旋通道数必须相同；checksum 与数组之差超过 1e-7 报错；电子数、共线自旋的磁化与体系相差 ≥ 1e-3 报错（SkipChargeTest 或固定费米能级时跳过）。
  • 文本格式：gfortran 的 list-directed 输出，每项前一个空格：整数占 11 列；逻辑量一个字母；实数为 1PG25.17E3，即 0.1 ≤ |x| < 1017 和 0 用 F20.(16−e) 再接 5 个空格，其余用科学记数法、三位指数，右对齐 25 列。每条 write 语句换一行。

三、pydftb 的接口

DFTB(sk, mixer="anderson")                        # "broyden"（默认）| "simple" | "anderson" | "diis" | "pulay"
DFTB(sk, mixer={"kind": "anderson", "generations": 6, "init_mixing": 0.01,
                "dynamic_mixing": [(1e-2, 0.3), (1e-4, 0.6)], "diagonal_rescaling": 0.01},
     mixing=0.05)                                 # mixing = MixingParameter；None 取 DFTB+ 的默认值
DFTB(sk, initial_charges=[0.2, -0.2, ...])         # 或 {原子: 电荷}，其余为 0
DFTB(sk, spin=True, initial_spins={0: 1.5})        # 共线：每个原子 N↑ − N↓
r = calc.calculate(labels, pos)
r.scc_errors                                       # 每一轮的 max|q_out − q_in|（DFTB+ 的 SCC error）

from pydftb import dftbplus_io
data = dftbplus_io.read_charges("charges.bin", norb_atom)   # 格式 4–8；.dat 按文本读
r = calc.calculate(labels, pos, q_init=data)       # 与 ReadInitialCharges 相同的检查
dftbplus_io.write_charges("charges.dat", calc.charge_data(labels, r))
calc.populations_from_file(labels, "charges.bin", skip_charge_test=False)

atoms.calc = PyDFTB(skdir, read_charges="charges.bin")      # 第一次计算从文件开始
atoms.calc.write_charges("charges.bin")                     # 写最后一次计算的输入布居
  • 混合器：
    • 选项名是 DFTB+ 关键字的 snake_case：Broyden 的 inverse_jacobi_weight、minimal_weight、maximal_weight、weight_factor；Anderson 的 generations、init_mixing、dynamic_mixing、diagonal_rescaling；DIIS 的 init_mixing、generations、use_from_start；
    • 写错的选项、给 DIIS 设 mixing（DIIS 没有这个参数）在构造 DFTB 时就报错；
    • mixing 的默认值从 0.2 改为 None：None 取各混合器在 DFTB+ 中的默认值。Broyden 仍是 0.2，所以默认路径逐位不变；PTBP 不传 mixing；
    • "anderson" 的含义改变：现在是 DFTB+ 的 Anderson；原来的 Pulay 型混合器改名 "pulay"（PulayMixer）。
  • 起点：
    • initial_charges 按 aufbau 填壳层，和不等于 charge 时 RuntimeWarning，然后缩放；
    • initial_spins 现在也用于共线自旋（原来只用于非共线）；
    • 两者可以同用，可以与壳层分辨、+U、onsite、非共线（只用电荷）同用；给了 q_init 时都不用，与 DFTB+ 相同。
  • 电荷文件：
    • calculate(q_init=ChargeData) 在建好体系后把文件换成混合向量，规则与给定 q_init 数组相同（第一轮的输出照常混合，与 DFTB+ 读电荷时相同）；
    • charge_data(labels, result) 用 result.q_in，即构造最后一个哈密顿量的输入布居，也就是 DFTB+ 写的那组；
    • 文本文件写得与 DFTB+（gfortran）逐字节相同。
  • ASE：共线自旋、没有给 initial_spins、atoms 的初始磁矩不全为零时，把磁矩作为 initial_spins（全为零时与以前相同）；torch 后端照旧忽略它们。
  • 限制：新的混合器（Broyden 只改 mixing 除外）、初始电荷、共线初始自旋、电荷文件只在 NumPy 引擎中；torch 后端和 pydftb.autodiff 遇到时报错。
开发细节四、实现
  • mixer.py：
    • BroydenMixer 不动；新的 SimpleMixer、AndersonMixer、DIISMixer 照抄 Fortran（索引环、槽位、gesv 的同样方程）；
    • 原 AndersonMixer 改名 PulayMixer；
    • mixer_spec(kind, mixing, **options) 返回 (名称, 构造参数)，检查选项；make_mixer 用它构造。DFTB.__init__ 先调用一次 mixer_spec，每次 SCC 仍新建混合器（等同于 DFTB+ 每个几何步的重置）。
  • calculator.py：
    • _initial_populations 前面加一个分支 _custom_start，旧代码不动；_custom_shell_populations 给出壳层的 q 与 m，块向量的起点（_initial_block_vector）也从它取壳层布居；
    • 模块级函数 _aufbau_shell_populations（initQFromAtomChrg）、_per_atom（列表或字典）；
    • _scc 记录每轮的 max|F|，DFTBResult.scc_errors；
    • _charge_layout、charge_data、populations_from_file：按类把混合向量展开到第一个轨道（块向量用 BlockTerms.expand/reduce），共线自旋换成 (q, m)，照 DFTB+ 做检查；
    • numpy_only_options：torch 后端在构造时报错，autodiff.evaluate 也检查它。
  • 新文件 dftbplus_io.py：ChargeData、read_charges（流式与 list-directed 两种读法，每条 read 语句从新的一行开始）、write_charges（先写临时文件再改名），gfortran 的 ld_integer/ld_logical/ld_real。checksum 按 DFTB+ 的求和顺序（先原子内、再原子间）。后面各块要写的 DFTB+ 文件也放这里。
  • ase_calc.py：PyDFTB(initial_charges=…, read_charges=…)、write_charges(path, text=None)，共线自旋的初始磁矩。
  • 验证工具：
    • dftbplus.py：mixer_block、initial_charges_block、initial_spins_block，make_hsd(extra_options=…)，解析标准输出中逐轮的 SCC error，run_restart（同一流程跑两次，第二次的输入去掉 InitialSpins）；
    • cases.py：Case.mixer、initial_charges、read_charges（两步：第一次在随机挪动 0.03 Å 的几何上写文件，第二次在算例的几何上读）；
    • refgen.py：参考结果存 scc_errors 与第一次运行的文件（base64）；比较 n_scc（必须相同）、逐轮误差、共线磁矩，以及“文件中的布居 = pydftb 自己第一次运行的输入布居”；
    • dynamics.py：基础算例的混合器也用于 MD，比较每步的 SCC 轮数。

六、不做的事与风险

  • 不做：
    • DFTB+ 写在电荷文件里的密度矩阵（长程校正的重启数据，M6h 再看）与原子多极；
    • 非共线自旋的初始自旋已在 M6a 实现，本次只补共线；
    • 新功能的 torch 与自动求导版本。
  • 风险：
    • 逐轮一致对舍入很敏感：只选离奇异、离收敛阈值都远的算例（DIIS 不用于 SCC 位点少的体系，周期体系用 Ewald 1e-12），并记录每个算例的最大相对差；
    • "anderson" 的含义改变：仓库里没有代码用它，README 与坑表写明；
    • mixing 默认值改为 None：Broyden 仍是 0.2，golden 逐位比较。
