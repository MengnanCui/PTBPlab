关键信息

M4b 让 pydftb 的结果可以对参数和几何求导：SK 表的每个值、onsite 能量、Hubbard U、Hubbard 导数、自旋常数、排斥势系数，以及原子坐标和晶胞。新包 pydftb.autodiff 只在 torch 上工作；SCC 仍由已有的引擎（NumPy 或 M4a 的 torch）收敛，求导部分在 torch 上按同样的公式再算一遍，并接上两种求导方式。

  • hf 模式（默认）：利用 Mermin 自由能对密度是变分的，把收敛的密度 P、能量加权密度 W 和输出电荷当作常数，得到一个“替代能量”。它对任何参数或坐标的梯度就是精确的 dF/dθ、力和应力，不需要对本征分解求导，代价约等于一次 H0/S 的构建。PTBP 的损失只用能量时，用这个就够了（T ≈ 0 时 E 与 F 的导数相同）。
  • implicit 模式：电荷、本征值、以力作损失时，需要“密度如何随参数变”。SCC 的不动点用隐函数定理求导：反向时解一个小线性方程（PTBP 只有 3–6 个电荷），不必展开迭代。密度矩阵对 H 的导数用占据函数的差商（Daleckii–Krein），加上费米能级随参数移动的修正；简并能级不会出现 NaN，T ≈ 0 金属里费米能级上的能级也能精确抵消。
  • 代码怎么共享：SK 表的插值与旋转、γ 的短程函数、三阶的 Γ、排斥势这些核函数改成 NumPy 和 torch 通用；NumPy 路径每改一次都用 golden 工具与 M4 之前逐字节比较。拓扑（邻居表、索引、截断、Ewald 的 α 和 G 的整数格点）仍在主机上，视为常数。
  • 怎么验证：hf 模式的力和应力与解析结果比较；对参数的导数与中心差分比较（SCC 收敛到 1e-12，随机方向）；implicit 模式的电荷、本征值、力的导数与差分比较，并与“把 SCC 循环整个展开求导”的结果比较；密度矩阵的反向用 gradcheck 检查，包括人为构造的简并。
  • 2求导方式：hf（变分）、implicit（不动点）
  • 6可求导的参数类别 + 坐标、晶胞
  • 0NumPy 路径允许改变的位

一、目标

给定参数 θ 和几何，算出能量 E、Mermin 自由能 F、力、应力、电荷、本征值，以及它们对 θ 和几何的导数。θ 包括：

参数进入哪里
SK 表（每个文件存储的列，H 和 S）原子对块 h、s（插值对表值是线性的）
onsite 能量H0 的对角
Hubbard Uγ（以及 DFTB3 的 Γ）
Hubbard 导数 UdDFTB3 的 Γ
自旋常数 W自旋能
排斥势（样条或多项式系数）排斥能

色散（UFF、SK、D3、D4）不依赖这些参数，作为“只依赖几何”的项加入，坐标导数用它自己的解析梯度。

二、hf 模式：替代能量

收敛后，Mermin 自由能对密度是驻定的，所以它对任何参数的全导数等于“密度不动时”的偏导数（Hellmann–Feynman）。pydftb 的解析力（calculator.py:_gradient）正是这样算的。把同样的收缩写成一个能量：

Esur(θ, R) = Σe [ p̂e he + (p̂e v̄̂e − ŵe) se ] + Σμ p̂μμ ε0μ + ½ Δq̂ᵀ γ Δq̂ + E3(Γ, Δq̂) + Espin(W, m̂) + Erep + Edisp

e 遍历所有原子对的矩阵元（含周期镜像），p̂e、ŵe 是收敛的 P、W 折回实空间后在这个元素上的值，v̄̂e = ½(vμ + vν) 是输出电荷的电势；带帽子的量都当作常数。它对 R 的梯度就是 _gradient 的结果，对 θ 的梯度就是 dF/dθ。返回的能量数值取原来的结果，梯度取 Esur 的梯度。

  • 只对 F 精确。E = F + TS；T ≈ 0（PTBP 的默认）时 TS ≤ kT·ln2 量级，两者导数相同；有展宽时要 E 的导数，就用 implicit 模式（hf 模式此时拒绝给 E 的梯度）。
  • SCC 没有完全收敛时，误差与残差同阶；对照时把 SCC 收敛到 1e-12。

三、implicit 模式：密度矩阵与 SCC 不动点

1. 密度矩阵的反向（DensityMatrix）

在正交化后的问题上（H′ = L⁻¹HL⁻ᴴ，L、L⁻¹ 和回变换交给普通的自动求导）：P′ = Y f(ε) Yᴴ，W′ = Y (εf) Yᴴ。H′ 变化 dH′ 时，记 X = Yᴴ dH′ Y：

dP′ = Y [ D ∘ X − dμ · diag(f′) ] Yᴴ，Dij = (fi − fj) / (εi − εj)，Dii = f′i；dμ = Σk,i wk f′ki Xii(k) / Σ w f′

  • 差商 D 对简并的能级给出 f′，而不是 0/0；Fermi 展宽用不会相消的写法 D = −fa(1 − fb) expm1(d)/(d·kT)。
  • dμ 来自电子数守恒，k 点（和自旋）之间就是靠它耦合起来的。每个“μ 组”（一个结构，或固定磁矩时的一个自旋通道）单独守恒。
  • T ≈ 0（kT = 1e-8 Ha）的金属里，费米能级上分数占据的能级 f′ ≈ 2.5e7。把对角项写成 f′i · (Xi − w·S/Z)：先在括号里相减，再乘 f′，这样单个分数占据能级的贡献精确为 0（它的占据数由电子数决定，不随参数变）。
  • μ 的导数跟着引擎实际用的规则走（occupations.fermi_rule）：按电子数二分时用上式；DFTB+ 的带隙中点规则（电子数为整数、中点处电子数误差 ≤ 1e-7 时采用，有展宽时也会用到）给出 dμ = ½(dεH + dεL)；二分落在能隙里、Σ w f′ = 0 时 μ 不确定，不耦合。
  • Gaussian 和 Methfessel–Paxton：能级间隔大时用普通差商，几乎相等（|Δx| < 1e-3）时用中点展开 f′ + f‴ d²/24。
  • 单个简并本征值没有导数（扰动劈裂简并的方式与方向有关）：本征值的梯度在每个简并能级内取平均，这对能级的任何对称函数（和、平均）是精确的。

2. SCC 不动点

Φ(q, θ)：从输入电荷 q 出发、不混合的一次 SCC（电势 → H → 本征分解 → 密度 → Mulliken 电荷）。收敛解 q* = Φ(q*, θ)。前向仍用已有引擎的 Broyden 收敛；求导时：

q̂ = q* + Φ(q*, θ) − stopgrad(Φ(q*, θ))，并在 q̂ 上挂钩子：传进来的梯度 g 换成 y，(I − Jᵀ) y = g，J = ∂Φ/∂q

  • q̂ 的数值精确等于 q*（a − a = 0），梯度则是隐函数定理给出的 dq*/dθ。再从 q̂ 走一次 Φ，得到的 P、W、ε、μ、输出电荷都带着完整的导数。
  • Jᵀ 由 Φ 的向量—雅可比积给出。电荷数 ≤ 64 时直接组出 Jᵀ 求解（PTBP 只有 3–6 个）；更多时用 GMRES 并检查残差。不用不动点迭代：金属的 J 谱半径大于 1，这正是前向需要 Broyden 混合的原因。
  • SCC 没收敛时抛出 GradientUnavailable。
  • 另做一个“展开”模式（线性混合、整条 SCC 都求导），只用于测试 implicit 的结果。

四、力、应力、以力为损失

  • 力：F = −∂Esur/∂R。替代能量里的原子对块用一份单独的坐标（叶张量）计算，SCC 那部分用固定的坐标。
  • 应力：对坐标和晶胞施加应变 ε（叶张量，初值 0），σ = −(∂Esur/∂ε)/V；Ewald 的 α 和 G 的整数格点固定，G 和体积从晶胞重新计算。
  • 以力为损失（M4c 的 dataset 模式）：implicit 模式下，P、W、电势带着对 θ 的导数，再用 create_graph=True 求 F，于是 F 本身可以对 θ 求导。PTBP 用 DFTB+ 的 0.01 Bohr 差分算力（fd_delta），这时原子对块对键矢量的导数用同样的差分核（对表值仍是线性的），使梯度与 PTBP 实际用的力一致。
  • 返回的数值：两种模式返回的能量、力、应力、电荷、本征值、费米能级都是引擎自己算出的数（逐位相同），只是加上了导数（数值 + (t − t.detach())）。

开发细节六、验证计划
  • 每个改动核函数的提交：golden 两个环境逐字节相同，refgen、dynamics 两个后端通过。
  • 通用核函数：torch 与 NumPy 在同样输入上 ≤ 1e-14（相对）。
  • hf：力 vs 解析 ≤ 1e-10 Ha/Bohr，应力 ≤ 1e-11；dF/dθ vs 中心差分（表、onsite、U、Ud、W、排斥势的随机方向，SCC 1e-13，Richardson 外推）相对差 ≤ 1e-7。
  • DensityMatrix：torch.autograd.gradcheck，实和复、精确简并、多个 k 组、自旋组，kT = 1e-3 和 1e-8。
  • implicit：电荷、本征值、力对 θ 的导数 vs 差分 ≤ 1e-6；与展开模式 ≤ 1e-8；伴随方程残差 ≤ 1e-10；hf 与 implicit 的 dF/dθ ≤ 1e-9。
  • 算例：水、甲醇（分子）、Cu fcc 与 Cu₂（金属、k 点、T ≈ 0 和 1000 K）、CuO 链（自旋）、DFTB3 的水二聚体、GdO（f 轨道）。

七、局限与不做的事

  • 拓扑和截断视为常数：原子跨过截断、U 跨过“相等/相近/一般”的分界时导数不连续（与能量本身的不连续一致）。DFTB3 的 Γ 在 |ΔU| = 3.125e-6 处按 DFTB+ 的约定翻倍：相等的 U 只有“一起变”的方向有导数。
  • 异核的 A-B、B-A 两个 SK 文件都存 l₁ = l₂ 的积分（ss、pp、dd、ff），引擎的上、下三角各用一份：只有两份一起变的方向有意义（hotcent 给出的切向就是这样），梯度在两份之间平分。
  • hf 模式求的是“电子数固定的 Mermin 自由能”的导数。引擎的两条 DFTB+ 约定与之不同：MP 展宽配 DFTB+ 的 TS（F 不是变分的，hf 拒绝给 dF）；带隙中点的费米能级（引擎的 F 的导数多出 μ dN/dθ）。Smearing(fermi_level="exact", ts_convention="variational") 去掉两者；implicit 模式直接对引擎的约定求导。
  • 不对 D3/D4 的参数求导；不做 torch 原生色散。
  • 不对 hotcent 求导（M4c 用差分接上）。
  • 二阶导数只到“力对参数”（以力为损失）；不做 Hessian。
  • 不做跨结构的同步批量（见 M4 计划）。
