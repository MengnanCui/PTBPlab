关键信息

M6g（响应性质）的第二块，包括三样东西：

  • DFTB+ 的 Analysis { CoordDerivatives }：原子位置的一阶响应，给出电荷导数、Born 电荷与本征值导数；
  • Driver = SecondDerivatives：对力做中心差分得到 Hessian，同时给出偶极与极化率的导数；
  • DFTB+ 的 modes 程序：简正模的频率与红外、拉曼强度。

坐标响应在 M6g-1 的响应代码上加 H0、S 的导数项。DFTB+ 拒绝或算错的情况，pydftb 都给出正确的导数。只做 NumPy 引擎；不开这些选项时逐位不变。

  • DFTB+ 的做法（第一节）：
    • CoordDerivatives：对每个位移，用差分得到 dS、dH0；加上基态势的项 ½(dS·V + V·dS)、γ 对位置的导数乘电荷、密度不变时的 Mulliken 变化 Σρ·dS，再按 M6g-1 的方式做 SCC 响应；
    • 一阶密度用不含费米面项的公式 Uji = fi(H′ji − εiS′ji)/(εi − εj)，所以拒绝金属和任何简并；
    • SecondDerivatives：每个坐标先 −δ 后 +δ，共 6N 个单点。
  • 探针 P22–P24（第二节，DFTB+ 25.1）：
    • CoordDerivatives 给出的 Born 电荷是 −∂μ/∂x，与 born.out 正好反号；
    • 25.1 带 DFTB3 时照常运行，但漏了三阶项，差 1.4e-2，开发版已修；
    • 外场与点电荷对原子位置的导数两个版本都漏了，Born 电荷差 1.7e-2 和 0.12；
    • 水的有限差分 Hessian 在 H–H 块不对称 1.9e-4：H–H 距离离 SK 表的格点只有 4.6e-6 Bohr，插值的导数在格点处跳变。
  • pydftb 的做法（第三、四节）：
    • 一阶密度用有限温度下的完整公式 X = W∘(M − ε̄N) − f̄N：费米面项、费米能级移动、简并组都包括；
    • γ、三阶、H5、外场与点电荷对位置的导数都算；
    • second_derivatives 与 DFTB+ 的位移顺序相同，normal_modes 给出频率与强度。
  • 原型（草稿目录）：
    • 与 25.1 的 CoordDerivatives 一致到 1e-12（水的原子与壳层分辨 SCC、非 SCC、300 K，甲醇，甲醛），DFTB3 与开发版一致到 1.5e-12；
    • 外场、点电荷、O2 三重态、3000 K 的 Cu4CO、CO2 与有限差分一致到 1e-8（金属 4.8e-7。这里原以为是差分本身的误差；实现时查明是 DFTB+ 的占据窗口截掉了近满、近空的能级，见报告第五节）。
  • 1e-12原型与 DFTB+ 25.1 的 Born 电荷、电荷导数之差
  • 9e-9数值 Hessian 与 DFTB+ 之差（相同的 SK 差分步长）
  • 5DFTB+ 拒绝或算错、pydftb 给出正确导数的情况：自旋、金属、简并、外场与点电荷、DFTB3（25.1）

一、DFTB+ 的做法

源码为 DFTB+ 的 041e723（derivs/perturb.F90: dxAtom、derivs/linearresponse.F90、derivs/numderivs2.F90、dftbplus/main.F90、dftbplus/mainio.F90）与 modes 程序（app/modes）。行为以 25.1 的二进制为准。

CoordDerivatives：原子位置的一阶响应

  • 矩阵的导数：对位移 x = xK,i，dS 与 dH0 是整个稀疏矩阵对原子 K 的中心差分，步长取 Differentiation = FiniteDiff 的 Delta（默认 2−13 ≈ 1.22e-4 Bohr）。Richardson 不支持。
  • 固定项（只在 SCC 时）：
    • Ω = ½(dS·V0A + V0B·dS)，V0 是基态的全部壳层势（SCC、自旋、外场、点电荷）；
    • δVfix = ∂γ/∂x · Δq（短程部分与 1/r）；开发版还加了 DFTB3 的项；
    • 密度不变时的 Mulliken 变化 dqNVμ = ΣνρμνdSμν。
  • SCC 循环：δV = δVfix + γ(dqin + dqNV)（DFTB3 时加它的线性项），dH = dH0 + Ω + ½S(δVμ + δVν)，混合与收敛同 M6g-1；不报告不收敛。
  • 一阶密度：Uji = fi(H′ji − εiS′ji)/(εi − εj)（j ≠ i），Uii = −½fiS′ii，dρ = Σi(dciciT + cidciT)。占据–占据部分合起来是 −½PS′P。没有费米面项和费米能级的移动，所以遇到金属和任何一对简并能级（包括两个空轨道）都报错。
  • 结果：
    • dq = Mulliken(dρ) + dqNV；
    • Born 电荷 Z(j, i, K) = ΣBRB,j∂NB/∂xK,i + δijΔNK，N 是电子布居。它等于 −∂μ/∂x，与 DFTB+ 自己的偶极 μ = Σ(q0 − q)R 的导数反号；
    • 本征值导数 dεi = H′ii − εiS′ii。

Driver = SecondDerivatives：数值 Hessian

  • 对能量梯度做中心差分，Delta 默认 1e-4 Bohr。行是 Atoms 的梯度分量，列是 MovedAtoms（默认等于 Atoms）的位移坐标；部分 Hessian 要求两者都是连续区间。
  • 顺序：原子升序；每个原子 x、y、z；每个坐标先 −δ 后 +δ。共 6N 个单点，未位移的几何不算；SCC 从上一个几何的电荷开始。
  • 同时累积偶极的差分（Born 电荷，常规符号）。有 Polarisability 时，每个几何都做响应计算，并累积第一个频率的极化率的差分（拉曼需要）。

modes 程序

  • Hessian 除以 √(mImJ)，可选投影掉平移与转动（P = I − VVT），然后对角化；频率是带符号的 √|λ|（Hartree）。
  • 没有投影时用上三角，有投影时先把下三角对称过去：两种情况读的是 Hessian 的不同一半。
  • 振型是 M−1/2 乘本征向量再归一化；每个本征向量的第一个非零分量取正。
  • 红外强度 |ΣKZK·dK|²，拉曼（极化率变化）Σ(ΣK∂α/∂xK·dK)²。两者都只对 λ > ε 的模式计算；频率差小于 1e-2 cm−1 的模式合并后写进 vibrations.tag。

三、pydftb 的接口

from pydftb import DFTB
from pydftb.vibrations import second_derivatives, normal_modes

r = DFTB(sk, analysis={"coord_derivatives": True}).calculate(labels, pos)
c = r.analysis.coord_derivatives
c.atoms                    # 位移的原子（0 起）
c.born                     # (n_K, 3, 3)：[K, i, j] = ∂μ_j/∂x_Ki（物理符号，e）
c.atom                     # (n_K, 3, n_qm, n_atom)：dN_B/dx_Ki（电子布居，e/Bohr）
c.orbital                  # (n_K, 3, n_qm, n_orb)：逐轨道
c.eigenvalue_derivatives   # (n_K, 3, n_block, n_level)：dε/dx（Ha/Bohr）
c.fermi_derivatives        # 金属：(n_K, 3, n_channel)

sd = second_derivatives(DFTB(sk, analysis={"polarisability": True}), labels, pos)
sd.hessian                 # (3 n_atoms, 3 n_moved)：∂²E/∂x_row ∂x_col（Ha/Bohr²），列为位移坐标
sd.dipole_derivatives      # (3 n_moved, 3)：dμ/dx（只对分子）
sd.polarisability_derivatives   # (3 n_moved, 3, 3)：dα/dx（计算器带极化率时）
nm = normal_modes(sd.hessian, masses, pos, born=sd.dipole_derivatives,
                  born_derivatives=sd.polarisability_derivatives,
                  remove_translation=True, remove_rotation=True)
nm.frequencies             # Hartree，虚频为负；nm.wavenumbers 为 cm⁻¹
nm.modes, nm.ir, nm.raman
  • coord_derivatives：True，或 {"atoms": [...]}（只位移这些原子，对应开发版的 WrtAtoms）。perturbation 的简并容差同 M6g-1。
  • （实现时新增）perturbation 的 "filling_tol"：默认 None，用 DFTB+ 的窗口：占据数离 0 不到 1e-7、离满不到 1.2e-7 的能级不进入响应，3000 K 时金属的响应因此差约 1e-7（M6g-1 的极化率照此与 DFTB+ 一致）；给一个正数则两边都用它，1e-15 包含所有部分占据的能级，得到精确导数。DFTB+ 没有对应的输入。
  • second_derivatives(calc, labels, positions, cell=None, pbc=None, *, atoms=None, moved_atoms=None, delta=1e-4)：
    • 位移顺序与 DFTB+ 相同，每个位移从参考几何的电荷开始 SCC；
    • 只调用 calculate，所以任何后端、任何能给力的组合都能用（周期体系、激发态的力、XL 之外）；
    • 计算器带 polarisability 分析时再给 dα/dx。
  • normal_modes(hessian, masses, positions=None, *, born=None, born_derivatives=None, remove_translation=False, remove_rotation=False, triangle="average")：
    • 默认对称化 Hessian；triangle="modes" 照 modes 用上三角（有投影时下三角）；
    • 质量单位 amu，可由 DFTB.masses(labels) 取 SKF 中的质量。
  • 写出（dftbplus_io）：
    • coord_derivative_tables(r, dftbplus_sign=True)：detailed.out 的两块；
    • write_band_derivatives(path, r, "coordinate")：dBand_dx.out；
    • write_hessian、write_born、write_born_derivatives：部分 Hessian 用 .a-b 文件名；
    • born_table(sd)：SecondDerivatives 的 detailed.out 块；write_vibrations_tag(path, nm)。
  • 可同用（坐标导数）：
    • 非 SCC、原子或壳层分辨的 SCC、共线自旋（DFTB+ 拒绝）；
    • 完整 DFTB3 与 H–X 阻尼、H5；
    • 外场、点电荷、格点势中的基态（DFTB+ 漏了它们的导数）；
    • Fermi 展宽、金属与简并能级（DFTB+ 拒绝）、固定费米能级；色散（不改变电荷，只进 Hessian）。
  • 报错（坐标导数）：
    • 周期体系（同 DFTB+：Born 电荷要 Berry 相位）；
    • M6g-1 拒绝的一切：非 Fermi 展宽、溶剂、只 onsite 的三阶、+U 与 onsite、非共线与 SOC（M6g-3）、偶极修正、每个 k 点单独填充、选定壳层、类型切换、XL-BOMD、torch 与自动求导。
开发细节四、实现

有限温度下带重叠导数的一阶密度

广义本征问题 Hci = εiSci，ciTScj = δij。微扰 H′、S′ 下，M = CTH′C，N = CTS′C，ρ = ΣficiciT（单位归一的占据，最后乘满占据与 k 权重）。一阶密度是 ρ′ = CXCT，其中

  • Xij = Fij(Mij − ε̄ijNij) − f̄ijNij，ε̄、f̄ 是两个能级的平均，Fij = (fi − fj)/(εi − εj)；
  • 对角与简并时 F 取极限 −δ（δ = βf(1 − f)）；
  • 金属另加 Xii 中的 +δidEF，dEF = Σδi(Mii − εiNii)/Σδi，使电子数守恒（按通道，或 relax_total_spin 时共用）。

这与 DFTB+ 按有序对写的 Uji 逐项相同（T → 0 的绝缘体）；多出的只是费米面项、费米能级移动和简并组的极限。

  • W 矩阵：F 那一项沿用 M6g-1 的成对权重（DFTB+ 的窗口 i ≤ nF、a ≥ nE，θ 权重，带内项）。把每对的 g 的一半散到 W[i, a] 和 W[a, i]：
    • 两个能级都在部分占据窗口里时，两个次序合起来正好是 F；
    • 同一简并组中的两个能级是 −½(δi + δa)，与本征向量的转动无关；
    • 窗口外的对（都满或都空）为 0。
  • f̄N 项用全部能级与实际占据，不截断。
  • 布居：dq = Mulliken(ρ′, S) + Mulliken(ρ, S′)。

坐标微扰的各项

  • H0′、S′：取自 st.pairs 的 dh、ds（对键矢量 RB − RA 的导数）。原子对 (A, B) 的元素对 xK,c 的系数是 δBK − δAK；没有导数时按 calc.fd_delta 重建。用 fd_delta = 2−13 时与 DFTB+ 的差分逐项相同。
  • Ω = ½S′∘(vμ + vν)：v 取 calc._potentials(st, sc.q_in)，即最后一个 H 的电荷势 ± 自旋势。净格点势在 H0 的对角上，与位置无关，没有导数项。
  • δVfix（每个 SCC 位点）：
    • γ 的短程部分用 coulomb._sp_short() 的 dS/dr（已含 H–X 阻尼与 H5），再加原子间 1/r 的导数；
    • 三阶：v3 中把 Γ 换成 ∂Γ/∂R（third.gr_ab）；
    • 外场与点电荷：δAK∇VA，∇VA = ext.gradient(ones)；
    • 电荷取 qin（与最后一个 H 一致）。DFTB+ 的固定项用 qout，收敛时两者只差 SCC 容差。
  • 求解：与 M6g-1 相同的未知量 x（SCC 位点上的 dq 与壳层上的 dm），(I − AB)x = x0 + A·δV。x0 是裸响应在位点上的约化，vtot = δV + Bx，dq = dq0 + χ0vtot。
  • Born 电荷：Z[K, i, j] = δij(q0K − NK) − ΣARA,jdNA/dxK,i。
  • 本征值导数：(Mtot − εN) 的对角元；简并组取组内块的本征值（升序），同 M6g-1。
  • 计算量：每个原子 K 只有它的行非零，CTH′C 按行算，代价 O(nKn²)；ρ′ = CXCT 每个方向 O(n³)。总量 O(3N·n³)，几十个原子的分子在秒级。

数值 Hessian 与简正模

  • second_derivatives：
    • 先算参考几何，取它的输入电荷；然后按 DFTB+ 的顺序做 6·nmoved 个单点，每个从参考电荷开始；
    • H[:, col] = (g(+δ) − g(−δ))/(2δ)，g 是能量梯度；
    • 偶极与极化率同样做差分。周期体系不给偶极导数（DFTB+ 写了，但没有意义）。
  • normal_modes：
    • 质量 amu × AMU_AU；投影与 modes 相同；
    • numpy.linalg.eigh，本征向量的符号照 modes（第一个大于 100ε 的分量取正）；
    • 波数用 DFTB+ 的 Hartree__cm = 2 Rydberg/100（新常数 HARTREE_CM）；
    • 强度与简并合并照 modes。

改动的位置

  • response.py：CoordDerivativesResult、coordinate_derivatives，以及辅助函数：W 矩阵、矩阵导数、γ、三阶与外势的雅可比。
  • analysis.py：coord_derivatives 字段与结果；calculator.py：_check_response 加周期体系的拒绝，新增 DFTB.masses(labels)。
  • 新模块 vibrations.py；constants.py 加 HARTREE_CM；dftbplus_io.py 加写出函数。
  • 验证：
    • validation/dftbplus.py：Driver = SecondDerivatives、CoordDerivatives 的输入，解析 hessian/born/bornderiv 与 modes 的输出；
    • validation/cases.py：新算例与 Case.fd_delta、Case.hessian、Case.modes、Case.born_fd；
    • validation/refgen.py：比较函数。

六、DFTB+ 的问题与 pydftb 的做法

问题pydftb
CoordDerivatives 的 Born 电荷是 −∂μ/∂x，与 born.out（∂μ/∂x）反号；源码注释的符号也错物理符号；写 detailed.out 时 dftbplus_sign=True 复现 DFTB+；比较时反号
25.1 的坐标导数漏了 DFTB3 的项，照常运行不提示（差 1.4e-2）含三阶项；DFTB3 的参考用开发版
外场与点电荷对原子位置的导数被漏掉（两个版本），非 SCC 时连 ½dS·V 项也没有都算；参考用 DFTB+ 自己的差分 Born 电荷
只支持绝缘体、无自旋、无简并（简并的空轨道也拒绝）完整的有限温度公式，金属、简并、共线自旋都可以
标准输出 “dEi/d (eV / AA)” 的数值是 Ha/Å结果用 Ha/Bohr；dBand_dx.out 照 DFTB+ 用 eV/Bohr
只有 CoordDerivatives 的 SecondDerivatives 写出全零的 bornderiv.out；部分 Hessian 留下空的 hessian.out；周期体系也写 born.out不复现：没有极化率就不写 bornderiv，周期体系不给偶极导数
modes 没有投影时读上三角、有投影时读下三角；投影后的零模式可能有强度；25.1 不认 Type2FileNames默认对称化；triangle="modes" 复现
SK 插值的导数在格点处跳变，有限差分 Hessian 看得到（两个程序都如此）写明；参考用相同的差分步长，自查避开格点

七、不做的事与风险

  • 不做：
    • 解析 Hessian（DFTB+ 也没有，以后可以在坐标响应之上做）；
    • 周期体系的 Born 电荷（要 Berry 相位）与电荷导数；
    • 开发版 WrtAtoms 时的文本格式（只给数值）；
    • +U、onsite、非共线与 SOC 下的坐标导数（M6g-3）；
    • 新功能的 torch 与自动求导版本。
  • 风险：
    • 大分子上 3N 次 O(n³) 慢：先写直接版本，以后需要时只在占据子空间里算；
    • 有限差分 Hessian 的格点跳变：参考用 fd_delta，自查避开格点；
    • 近简并（不在容差内）的能级对使 F 很大，是物理的（真正的软响应），与 DFTB+ 相同。
