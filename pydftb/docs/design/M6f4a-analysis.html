关键信息

M6f 的第四块分成两半，这是前一半：DFTB+ Analysis 一节中不需要局域化或激发态的输出。按原子分解的能量（AtomResolvedEnergies）、净布居与杂化比（WriteNetCharges）、CM5 电荷、静电势（ElectrostaticPotential），以及 eigenvec.out/.bin 与 band.out 两种文件。只做 NumPy 引擎；不开分析时逐位不变。Pipek–Mezey 局域化、键分析与 Casida 跃迁电荷是后一半（M6f-4b）。

  • DFTB+ 的做法（第一节）：
    • 按原子的能量只写进 detailed.out，四个块（电子、排斥、总能量，有色散时还有色散），每个原子 8 位小数；总能量块的和是 “Total energy”，不是 Mermin 自由能；
    • 各项的拆法：H0 按 Mulliken 方式把 ρμνH0νμ 记给 μ 所在的原子（异核块各一半），SCC 是 ½ΔqA(γΔq)A（周期体系含 Ewald 的常数项），排斥势、卤素每对各一半，色散按原子对，在位的项（+U、onsite、LS）记给本原子；
    • 静电势用输出电荷的点电荷近似，分子用软化的 1/r，周期体系用 Ewald；文件中两栏都是物理电势（V）。
  • 探针中的发现（第二节）：
    • DFTB+ 默认的 EwaldTolerance = 1e-9 让水盒子的 EH0 差 7.9e-8、按原子的能量差 5.2e-8；收紧到 1e-12 后与 pydftb 一致到 8 位小数的舍入（4.9e-9）。周期算例的参考都收紧 Ewald；
    • s-dftd3 库的 D3（含 D3H5 的 H–H 排斥）DFTB+ 平均分给每个原子（E/N），没有物理意义；D4 按原子对（两体每对一半、三体每个原子三分之一），与 dftd4 库 get_pairwise_dispersion 的行和一致到 4.9e-9。pydftb 默认对 D3 也按原子对分配，测试用的开关复现 E/N；
    • 静电势、本征向量与 band.out 都按源码的格式复现：分子散点差 7e-16 a.u.，周期网格差 4e-10 V，本征向量的 Mulliken 权重（简并组求和）差 ≤ 7e-7（文件只有 6 位小数）；
    • DFTB+ 的问题：ESP 网格的 Directions 不是单位阵时，文件头的原点和步长矢量写错；点恰好落在原子的周期像上时自身项处理不一致；D3H5 的 H–H 排斥把同一原子 ±L 两个像各算一次（晶胞短于 10 Bohr 时能量偏大）。
  • pydftb 的接口（第三节）：DFTB(analysis=True | dict | Analysis(...))，结果在 r.analysis；文件由 dftbplus_io 的写出函数生成（write_band_out、write_eigenvectors、write_esp、detailed_tables）；ASE 计算器提供 get_potential_energies()。
  • 19DFTB+ 参考算例（其中 1 个用开发版）
  • 5.2e-8DFTB+ 默认 Ewald 精度下水盒子按原子能量的误差（Ha）；收紧后 4.9e-9
  • E/NDFTB+ 对 s-dftd3 的 D3 色散的按原子分配：总量平均分

一、DFTB+ 的做法

源码为 DFTB+ 的 041e723（dftbplus/main.F90、dftb/getenergies.F90、dftb/scc.F90、dftb/coulomb.F90、dftb/dispcommon.F90、extlibs/sdftd3.F90、solvation/born.F90、solvation/cm5.F90、dftb/elstatpot.F90、dftbplus/mainio.F90、dftbplus/parser.F90）。这些部分与 25.1 相同；所有规则都用 25.1 的二进制确认过（第二节）。

按原子分解的能量

输入 Analysis { AtomResolvedEnergies = Yes }。各项都用最后一轮的输出电荷（DFTB+ 默认 RecomputeAfterDensity），与总能量相同。

项按原子的拆法记在
H0Σμ∈A Σν Σk wk Re[ρμν(k) H0νμ(k)]，即 Mulliken 式的拆法：在位块全归 A，A–B 两块各一半；自旋相加电子
SCC½ΔqA(γΔq)A（壳层分辨时对壳层求和）；周期体系 γ 含 Ewald 的 −π/(Vα²) 与 −2α/√π；点电荷 ΔqAVpcA（不减半）；只 onsite 的三阶 (UdA/6)ΔqA3；偶极修正 ½ΔqAVdcA电子
完整三阶⅓ΔqA·∂E3/∂qA（E3 是 Δq 的三次齐次式，求和等于 E3）电子
自旋½ml(Wm)l 对 A 的壳层求和（非共线时 m 是三个方向）电子
LSonsite 模型：A 的在位块 Tr(ρAAHSO)；dual 模型：A 的对偶块布居与 Λ 的收缩电子
DFTB+U、onsite 修正A 的块布居的二次式电子
外加势ΔqA(RA·E + VgrossA) + (qnetA − q0A)VnetA电子
GB 溶剂½q′A(Bq′)A（含氢键项）+ SASAA + ΔGshift/N；q′ 是 GB 用的电荷（Mulliken 或 CM5）电子
排斥势每对各一半排斥
色散UFF、Slater–Kirkwood、SimpleDftD3、D4 两体：每对各一半；周期 r−6 的倒空间与自能项按原子（行和）；D4 三体：每个原子 ⅓；s-dftd3 库的 D3（含 D3H5）与 MBD/TS：E/N 平均分色散
卤素修正每对各一半只在总能量
  • 电子 = H0 + SCC + 自旋 + DFTB+U + LS + 外加 + 完整三阶 + onsite + 溶剂；总能量 = 电子 + 排斥 + 色散 + 卤素；Σ 总能量 = “Total energy”。
  • 输出只在 detailed.out：Atom resolved electronic energies、Atom resolved repulsive energies、Atom resolved total energies，有色散时 Atom resolved dispersion energies （标题末尾有空格）；每行 (I5, F16.8, A, F16.6, A)，Hartree 与 eV；单项不按原子打印，没有 tag。
  • 注意 DFTB+ 的 ESCC 含只 onsite 的三阶，detailed.out 里不另印 “Energy 3rd”；pydftb 一直把它放在 e_3rd。按原子的电子与总能量不受影响；pydftb 的分项与自己的总量对应。

净布居与杂化比

MullikenAnalysis { WriteNetCharges = Yes }（只在 MullikenAnalysis = Yes 时读）。qnetA = Σμ∈A ρμμ(R = 0) = Σμ∈A Σk wk Re ρμμ(k)（自旋求和），杂化比 = 1 − qnetA/q0A。块标题 Atomic net (on-site) populations and hybridisation ratios，列头 Atom Population Hybrid.，行 (I5, 1X, F16.8, F16.8)，没有 tag。DFTB+ 只要分配了 qnet（例如 AtomSitePotential { Net }）就打印这一块。

CM5 电荷

MullikenAnalysis { CM5 { Alpha = 2.474 Å⁻¹; Radii = AtomicRadii {...}; Cutoff = 30 Bohr } }。qCM5A = (q0A − qA) + ΣB DZAZB exp[−α(RAB − rA − rB)]，跳过同一物种（类型标签）的原子对，这也去掉了原子自己的周期像；元素由物种名解析。周期体系的近邻表含 30 Bohr 内的像。detailed.out CM5 corrected atomic gross charges (e)，列头 Atom Charge，行 (I5, 1X, F16.8)；results.tag cm5_atomic_charges（全精度）。注：GB 溶剂的 CM5 在 25.1 中把每对算了两次（M6c 已写明），分析输出用的是半表，不加倍。

静电势

ElectrostaticPotential { OutputFile = "ESP.dat"; AppendFile; Points = {...} | Grid {Spacing; Origin; GridPoints; Directions}; Softening = 1e-6 }。

  • 电荷：输出电荷的原子单极子 q0 − q（不含 γ 的展宽，不分壳层）。分子 φ(r) = ΣA(q0A − qA)/√(|r − RA|² + ε²)；周期体系 Ewald：实空间 erfc(α|x|)/√(|x|² + ε²)（软化只在分母），|x| < 1e-5 Bohr 的项跳过；倒空间同 γ；减 π/(Vα²)·Σq；点与中心晶胞的原子重合时再减 2α/√π。α 与 G 矢量来自 SCC 的 Ewald。
  • 偶极修正的势加在内部一栏；外部一栏 = 点电荷 + 外场（物理电势 −E·r，r 不折叠），只在有外场或点电荷时出现。
  • 文件中两栏都写 −(DFTB+ 内部的势) × 27.2113845 = 物理电势（V）；autotest.tag 的 internal_efield、external_efield 是同样符号的原子单位。
  • 网格的点 pijk = A·(i s1 + o1, j s2 + o2, k s3 + o3)，A 的列是归一化的 Directions；第三个下标变化最快。周期体系可以用分数坐标（修饰符 F，此时不读 Directions）。
  • 拒绝：非 SCC；改变静电场的溶剂模型（GB、COSMO；只有 SASA 可以）；xTB；同时给或都不给 Points 与 Grid；非周期体系用分数坐标。AppendFile 只在几何优化或 MD 时读。
  • ESP.dat：首行 ('# ', L2, 3I6, 1x, I0)（有无外部一栏、网格的点数（散点时为 0）、总点数）；网格再写四行 (A,3E20.12)：原点与三个步长矢量（Å）；列标题；数据行网格 (2E20.12) 或 (E20.12)，散点 (3E12.4,2E20.12) 或 (3E12.4,E20.12)（坐标为 Å）。

本征向量文件与 band.out

  • 两者都来自最后一次对角化，即由最后一轮输入电荷构成的 H（pydftb 的 sc.h，探针确认其本征值与 sc.evals 逐位相同）。
  • eigenvec.out（WriteEigenvectors = Yes; EigenvectorsAsText = Yes）：首行 Coefficients and Mulliken populations of the atomic orbitals 后空一行。
    • 实数（分子与 Γ 点）：每个本征向量一行 ('Eigenvector:',I4,4X,'(',A,')'/)（up/down）；
    • 复数（k 点）：(A,I4,4X,A,I4,4X,'(',A,')'/)，即 K-point: 1 Eigenvector: 1 (up)；
    • Pauli：首行后加列头 Atom Orb up spin coefficients down spin coefficients charge x y z 与空行，每个本征向量 K-point: … Eigenvector: …（没有自旋名，后面不空行）；
    • 每个轨道一行：原子的第一个轨道 (I5,1X,A2,2X,A)（序号、物种、壳层名），其余 (10X,A)；壳层名 s、p_、d_、f_ 接轨道名（p：y z x；d：xy yz z2 xz x2-y2；f：y(3x2-y2) xyz yz2 z3 xz2 z(x2-y2) x(x2-3y2)），同一 l 的第二个壳层加序号（s2）；数值从第 23 列起：实数 F10.6,1X,F10.6（系数、Mulliken 权重 cμ(Sc)μ），复数 '(',F10.6,',',F10.6,1X,')',1X,F10.6（权重 Re[cμ*(Sc)μ]），Pauli 两个分量与四个权重（电荷、x、y、z）；每个原子后空一行。
  • eigenvec.bin：流式二进制，一个 int32 的 runId（DFTB+ 随机生成，供 waveplot 与 detailed.xml 核对），然后按 k 最快、自旋其次逐列写本征向量（实数或复数的 real(8)）。
  • band.out（WriteBandOut = Yes，默认开）：先自旋后 k；块头是 gfortran 表控输出的 KPT … SPIN … KWEIGHT …，每行 (I6, F12.4, F9.5)（eV、占据数：无自旋时含因子 2，不乘 k 权重），块后空一行；Pauli 一个块 2N 个态。

源码中的问题（不影响参考算例）

  • ESP 网格的文件头：点是 A·(…+ o)，但写出的原点是未旋转的 o；步长矢量写成 axes_ * spread(spacing, 2, 3)，按行而不是按列乘步长。Directions 是单位阵（且三个步长任意）时正确；分数坐标的网格同样按行乘。pydftb 写正确的值；参考算例用单位方向。
  • 点落在原子的周期像上：实空间跳过该项，但只在点与中心晶胞的原子重合时才减 2α/√π，两种情况结果不同。pydftb 两种情况都去掉自身项（写明）。
  • D3H5 的 H–H 排斥（extlibs/sdftd3.F90 的 addHHRepulsion）：半近邻表中同一原子的 ±L 两个像都在，能量各加一次（应力乘了 ½，能量没有）。晶胞短于截断 10 Bohr 时能量偏大。pydftb 的 hh_repulsion 用全表，每对一半，正确。按原子的 E/N 分配也包含这一偏差。

三、pydftb 的接口

from pydftb import DFTB, Analysis
calc = DFTB(sk, analysis=True)          # 按原子的能量、净布居、CM5（都很便宜）
calc = DFTB(sk, analysis=Analysis(atom_energies=True, net_populations=True, cm5=True,
                                  esp={"points": pts},          # Bohr，(M, 3)
                                  eigenvectors=True))
calc = DFTB(sk, kpts=(k, w), analysis={"esp": {"grid": {"spacing": (2.8, 2.8, 2.8),
                                                         "origin": (0, 0, 0), "points": (3, 2, 2)}}})
r = calc.calculate(labels, pos, cell, pbc)
a = r.analysis
a.atom_energies["total"]            # (n_atom,)，Σ = r.energy；还有 electronic、repulsive、
                                    # dispersion、halogen 与各分项 h0、scc、third_order、spin、
                                    # spin_orbit、plus_u、onsite、external、solvation
a.net_populations, a.hybridisation  # (n_atom,)
a.cm5_charges                       # (n_atom,)，e
a.esp.internal, a.esp.external      # (M,)，Hartree/e（物理电势）；a.esp.points (M, 3) Bohr
a.eigenvectors, a.mulliken_weights  # 每个 (自旋, k) 块

from pydftb import dftbplus_io as io
io.write_band_out("band.out", r)
io.write_eigenvectors("eigenvec", r, text=True)    # eigenvec.out；text=False 写 eigenvec.bin
io.write_esp("ESP.dat", a.esp)
print(io.detailed_tables(r))                       # detailed.out 格式的分析块

atoms.calc = PyDFTB(skdir, analysis=True)
atoms.get_potential_energies()                     # eV，Σ = get_potential_energy()
  • 选项：analysis=True 等于 Analysis(atom_energies=True, net_populations=True, cm5=True)；字典的键同 Analysis 的参数。
    • cm5：True 或 {"alpha": 1/Bohr, "radii": {标签: Bohr}, "cutoff": Bohr}（与 GB 溶剂的 solvation.CM5 同一个类）；
    • esp：{"points": (M, 3)} 或 {"grid": {"spacing", "origin", "points", "directions"}}，可加 "fractional": True（周期体系，分数坐标）与 "softening"（默认 1e-6 Bohr）；
    • eigenvectors：保存本征向量与 Mulliken 权重（N² × 块数的内存，只在要写文件时开）。
  • 拆法：照 DFTB+（第一节的表）。唯一的例外是 s-dftd3 库的 D3：pydftb 用库的 get_pairwise_dispersion 按原子对分配（两体每对一半，三体每个原子 ⅓，同 D4），D3H5 的 H–H 排斥每对一半；DFTB+ 的 E/N 由测试专用的类属性 DFTB._atom_energy_compat 复现。
  • 限制：
    • 只在 NumPy 引擎中，analysis 加入 numpy_only_options；torch 后端与 pydftb.autodiff 报错；
    • XL-BOMD（影子能量）不能按原子分解，报错；Casida 时分析的是基态（同 DFTB+）；
    • 静电势需要 SCC，拒绝 GB 溶剂（同 DFTB+；只有 SASA 可以）。
开发细节四、实现
  • 新文件 analysis.py：
    • Analysis（冻结的数据类，make(spec) 解析 True、字典、对象）与结果类 AnalysisResult、ESPResult；
    • evaluate(calc, st, sc, res)：按选项算各项，只读 _Setup、_SCCState 与结果，不改它们；
    • atom_energies(calc, st, sc, res)：H0 与 LS 的轨道拆法（共线照 _trace 的密度，Pauli 用 so.components 的电荷分量）；SCC 用 coulomb.energy_shift 的势逐点相乘；三阶 ⅓Δq·v3；自旋；块势调用新函数 BlockTerms.atom_energies（逐原子，与 energies 同公式，后者不动）；外加势、点电荷、偶极修正、溶剂各加一个按原子的方法；排斥势照 _repulsive_energy 的原子对按 i 累加一半；色散调用 Dispersion.atom_energies；卤素已有 HalogenTerms.atom_energies；
    • 净布居复用 DFTB._net_populations；CM5 复用 solvation.cm5_correction，周期体系换成 30 Bohr 的 neighbor_list（新参数 cell、pbc，不给时走原来的代码）；
    • electrostatic_potential(points, dq_atom, pos, coulomb, softening, dipole=None)：分子直接求和；周期体系实空间用 neighbors.cross_pairs，倒空间与常数项用 Coulomb 的 α、G、gfac，与 external._pc_potential 角色对调；外部一栏用 ExternalTerms 的点电荷（模糊宽度同 DFTB+）与 −E·r；
    • 本征向量：照 _casida_ground_state 用 ops.eigh 重新对角化 sc.h（k 点逐个，Pauli 用 pauli.s2），给出 Mulliken 权重。
  • dispersion.py：Dispersion.atom_energies(labels, pos, cell, pbc, charge)；对势类用 _pair_terms 的原子对按 i 累加 ½e，ewald_r6_atoms 照 ewald_r6 拆成按原子的三部分；D3/D4/SimpleD3 用库的 get_pairwise_dispersion 行和，compat=True 时 D3 返回 E/N。evaluate 与 ewald_r6 原样不动。
  • calculator.py：DFTB(analysis=None)，检查组合，加入 numpy_only_options；_run 在 _energies 之后（M6f-2 设 n_ef、q0_atom 的地方）只在 self.analysis 不为 None 时调用 analysis.evaluate；DFTBResult.analysis（默认 None）。测试专用的类属性 _atom_energy_compat。
  • dftbplus_io.py：write_band_out、write_eigenvectors（文本与二进制）、write_esp、detailed_tables，沿用 ld_* 表控格式函数，先写 .tmp 再 os.replace；读回用的 read_band_out、read_esp（测试与验证工具用）。
  • ase_calc.py：PyDFTB(analysis=...)（ESP 的点与网格 Å → Bohr）；有按原子的能量时 results["energies"]（eV），implemented_properties 加 energies。
  • 验证工具：
    • cases.py：Case.analysis（字典，同 Analysis，另有 "compat"）；
    • dftbplus.py：make_hsd 写 Analysis 的新键（WriteBandOut、WriteEigenvectors、EigenvectorsAsText、AtomResolvedEnergies、MullikenAnalysis { WriteNetCharges; CM5 {} }、ElectrostaticPotential {…}），run() 解析四个能量块、净布居、CM5、ESP.dat、band.out、eigenvec.out 的权重、autotest.tag 的 internal_efield/external_efield；
    • refgen.py：_compare_analysis，新键加进 refgen.compare 的显式列表。

自洽测试（tests/test_analysis.py）

  • 每个分项按原子求和等于对应的结果字段（e_band、e_scc、e_3rd、e_spin、e_ls、e_plus_u、e_onsite、e_ext、e_solv、e_rep、e_disp、e_halogen），total 之和等于 energy；
  • ESP：分子对直接求和；中性周期晶胞与 Ewald 的 α 无关（换 α 重算）；网格与等价散点相同；分数坐标网格与笛卡尔网格相同；
  • 写出的 band.out、eigenvec.out/.bin、ESP.dat 能读回；格式与 DFTB+ 的文件逐行比较（参考目录里冻结的文本）；
  • 平移、整体旋转（按原子能量不变）；不开分析时结果中没有 analysis，与以前逐位相同；
  • 拒绝项：torch、自动求导、XL-BOMD、ESP 非 SCC、ESP 加 GB。

门槛

与以往相同：golden 两个环境对上一个提交逐位相同（--allow-new analysis）；refgen --check、dynamics --check；三个环境的 pydftb 测试；PTBP 测试；engine_parity。

六、不做的事与风险

  • 不做：
    • MBD/TS 色散、COSMO、xTB 的分析输出（pydftb 没有这些模型）；
    • DFTB+ 的 E/N 作为默认（只在测试中复现）；
    • detailed.xml 与 waveplot 的输入；
    • 新功能的 torch 与自动求导版本。
  • 风险：
    • 8 位小数的舍入使按原子的能量只能比到 1e-8；更严格的检验靠各分项求和等于总量（pydftb 内部 1e-12）；
    • 周期算例必须收紧 Ewald，否则 DFTB+ 自己的误差（5e-8）超过容差；
    • 本征向量的相位与简并组内的旋转任意：只比较简并组内求和的权重；
    • 默认路径：新代码只在 analysis 不为 None 时走，golden 逐位比较。
