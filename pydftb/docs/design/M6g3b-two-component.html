关键信息

M6g 的最后一块：两分量计算（非共线自旋；SOC 的 onsite 与 dual 两种模型；可带 +U 与 onsite 修正）下的极化率、响应核、坐标导数与点电荷导数。代码在新模块 pydftb/response_pauli.py，response.py 的四个入口遇到两分量计算时转过去；只做 NumPy 引擎，不开这些选项时逐位不变。

  • DFTB+ 的情况（第一、二节）：
    • 25.1 的极化率与响应核支持全部两分量计算，输出四个分量（电荷与磁化的 x、y、z）；坐标导数拒绝，但 SecondDerivatives 能跑两分量，差分 Born 电荷可作参考；开发版的点电荷导数能算，只输出电荷分量。
    • dual SOC 与 +U 或 onsite 修正同时用时，25.1 的响应是错的：分子的极化率差 2.2e-5–1.3e-4（相对），DFTB+ 自己的有限外场也确认；周期的 CuO 链（金属，k 点）的响应核差 75 %。原因是响应丢掉了 dual SOC 下块布居的虚部及其势。
    • 没有 SOC 时整体转动全部磁矩不改变能量：响应方程有严格的零模式。DFTB+ 的迭代给出不含转动的解（共线磁矩时磁化响应纯纵向）。
  • pydftb 的做法（第三、四节）：
    • 每个 k 点一个 2N × 2N 的旋量块，每个能级最多 1 个电子，一个费米能级。χ0 的行是四个分量的逐轨道布居，列是四个分量的壳层势，四个分量互相耦合。
    • 核：电荷用 γ（与完整三阶），三个磁化分量各用 W；块势的通道有四个分量，dual SOC 时另有虚部通道。测试专用开关 DFTB._response_skew_compat 去掉虚部通道，复现 DFTB+ 的错误。
    • 求解：没有 SOC 时用以整体转动为边的加边方程，SCC 容差松时也不混进转动；有 SOC 时用奇异值分解，截掉偶然的零模式并警告；有限频率直接求解。
    • 坐标导数（DFTB+ 没有）：旋量的 H′ 加上块势的 S′ 项（含虚部）与 dual SOC 的 ½i(S′Λ + ΛS′)，复数的 X。
  • 结果（第五节，详见完成报告）：21 个新参考算例全过；极化率对 25.1 ≤ 1e-11 a.u.（GdO 的软模式 1.1e-9），磁化导数相对 ≤ 4.2e-9；dual SOC + 块势用开关后与 DFTB+ 一致到 1.4e-13（周期体系 5e-10），物理值对 DFTB+ 自己的有限外场 ≤ 3.8e-12（Cu4CO 6.6e-9，差分的截断），周期体系的响应核对位点势的差分 2.3e-9（|dN| ≈ 10）；坐标导数对 DFTB+ 的差分 Born 电荷 4.4e-9（金属 4.9e-8）；点电荷导数对开发版 4.1e-14。
  • ≤ 1e-11两分量极化率与 DFTB+ 25.1 之差（a.u.，GdO 的软模式除外）
  • 1.3e-4DFTB+ 25.1 在 dual SOC + onsite 时极化率的相对误差
  • 21新的 DFTB+ 参考算例（极化率、响应核、坐标导数、点电荷导数）

一、DFTB+ 的做法

源码 041e723（derivs/linearresponse.F90: dRhoPauli、dRhoFermiChangePauli，derivs/perturb.F90），行为以 25.1 与开发版的二进制为准。

  • 两分量的一阶密度：dRhoPauli 与复数 k 点的 dRhoCmplx 结构相同，只是哈密顿量是 2N × 2N 的旋量矩阵（unpackHPauli），权重函数相同，maxFill = 1；dρ 按四分量（电荷与 σx、σy、σz）打包，各自做 Mulliken 分析；金属的费米能级只有一个。
  • 微扰与核：外场、原子上的势只加在电荷分量上；响应的势由电荷的 γ（与三阶）和三个磁化分量的 W 给出，块势（+U、onsite）按四个分量处理。块势的响应只用实数的块布居：getDftbUShift(…, dqBlockIn)，addOnsShift 的虚部布居传入占位的零，addShift 只由实数部分建 dH，虚部块势从不进入 idH。
  • 坐标导数：两分量时拒绝（“Spin polarised calculations are not yet supported for coordinate derivative perturbations”）；dxAtom 中 dRhoPauli 的调用被注释掉。Driver = SecondDerivatives 不受影响，两分量也写出数值 Hessian 与差分 Born 电荷。
  • 点电荷导数（开发版）：两分量照常运行，tag 与 detailed.out 只有电荷分量。

二、DFTB+ 的实测行为

探针 P29–P32（草稿目录 m6g3b/），测试参数 ptbp_hcocu（GdO 用 hotcent_gdo），算例取自 M6a、M6b、M6c 的参考算例。

探针内容结果
P29 输出极化率与响应核：OH 的非共线、dual 与 onsite SOC，O2 的 SOC（T = 0），Cu4CO 的 SOC（金属），GdO 的 SOC，CuO 链的 SOC（k 点），OH 的非共线 + U、dual SOC + U、dual SOC + onsite
  • 全部能算；staticChargeReponse（nAtom × 4 × 3）与 dqdV（mOrb × nAtom × 4 × nAtom × nω）给出四个分量；
  • dEidEfield 的自旋维为 1；dEidV 的自旋维为 4，第 2–4 个全是零，dV_band.out 也写出 SPIN 2–4 的零块；
  • detailed.out：电荷导数每个原子写 q、x、y、z 四行，dEF/dE 除以 maxFill = 1（即不除），响应核的块只有电荷。
P30 正确性DFTB+ 的解析极化率对 pydftb 在外场中偶极的四阶差分（全精度），可疑的再对 DFTB+ 自己的差分（results.tag 的 dipole_moments）
  • OH 的非共线 1.5e-11，dual SOC 5e-13，onsite SOC 1.4e-12，O2 的 SOC 3e-12，OH 的非共线 + U 1.2e-11，Cu4CO 的 SOC 1.9e-9（h = 2.5e-4；5e-4 时 3e-8 是截断误差），都是相对值；
  • dual SOC + U 8.3e-5，dual SOC + onsite 1.3e-4；DFTB+ 自己的差分给出相同的偏差，而 dual SOC 单独时它的差分与解析值一致到 1.4e-10。
P31 点电荷开发版的 ExternalChargeDerivatives，OH 的 dual SOC 加外场与 3 个点电荷能算，dqdxext（3 × 3 × 2）只有电荷分量。
P32 二阶导数25.1 的 Driver = SecondDerivatives：OH 的 dual SOC、非共线、dual SOC + U都能算，results.tag 有 hessian_numerical 与 born_mudrv_numerical；后者与 pydftb 的解析 Born 电荷差 1.1e-8（差分步长 1e-4 的 O(δ²)）。

转动零模式：没有 SOC 的 OH（磁矩倾斜），(I − AB) 有两个 3.9e-11 的奇异值（垂直于磁矩的两个整体转动）。DFTB+ 的磁化响应与基态磁矩平行；直接求解混进 1.1e-4 的转动。GdO（7 μB，SOC 弱）有一个严格的零模式（电子绕键轴的整体转动，8e-11）和一个软模式（3.4e-4），磁化响应约 240。

三、pydftb 的接口

r = DFTB(sk, spin="noncolinear", spin_constants=w, spin_orbit={"O": [0.0, 0.01]},
         plus_u={"O": [("p", 0.1)]}, smearing=("fermi", 300.0),
         analysis={"polarisability": True, "response_kernel": True,
                   "coord_derivatives": True}).calculate(labels, pos)
p = r.analysis.polarisability
p.charge_derivatives[-1]     # (3, 4, n_atom)：dN_A/dE_i 与 dmx,y,z_A/dE_i
p.eigenvalue_derivatives[0]  # (3, n_k, 2N)：每个 k 点的 2N 个旋量能级
k = r.analysis.response_kernel
k.atom[0]                    # (n_atom, 4, n_atom)：[A, b, B] = d(分量 b)_B / dV_A
r.analysis.coord_derivatives.born                 # (n_atom, 3, 3)：分子
  • 没有新选项：两分量计算加上 M6g 的分析即可；结果类不加字段，“自旋”维长度为 4 时就是 q、mx、my、mz，与 DFTB+ 的输出一致；金属只有一个费米能级（fermi_derivatives[..., 1]，dos_fermi 一个值）。
  • 坐标导数只用于分子；点电荷导数给四个分量（开发版只给电荷）。
  • 拒绝：M6g-1 拒绝的组合照旧（非 Fermi 展宽、溶剂、只 onsite 的三阶、偶极修正、每个 k 点单独填充、选定壳层、XL-BOMD；torch 本来就不支持两分量）；不再拒绝两分量。
开发细节四、实现

基态与矩阵元

  • PauliGroundState（GroundState 的子类，复用 pairs、weights、shells）：每个 k 点 ops.eigh(sc.h[k], st.pauli.s2[k])，max_fill = 1，一个费米能级；窗口与简并组同 M6g-1。费米向量 d_comp（4 × N），净布居用电荷分量 Σs|csμ|²。
  • 布居元：mμ,bai = ½Σss′[c*sμ,aσbss′(Sci)s′μ + (Sca)*sμσbss′cs′μ,i]，即 Trspin(σbρ) 的 Mulliken 布居；壳层 X 上分量 b 的单位势的矩阵元是 Σμ∈Xmμ,bai。

块通道

  • 实部通道：BlockChannels.build（rep "pauli"，四个分量），算符 ½(SEc + EcS)⊗σb。
  • 虚部通道 SkewChannels（dual SOC 加块势时，BlockTerms.imaginary）：元素 (μ, ν)，μ < ν，Ec = Eμν − Eνμ，算符 i½(SEc + EcS)⊗σb（与 _block_hamiltonian 的约定相同），共轭的布居是 2Qiμν（to_q = ½）；核由 BlockTerms.potentials(zero, 单位反对称块) 求出。虚部势只依赖虚部布居，实部势只依赖实部布居，两种核互不耦合。

χ0、核与求解

  • χ0：每个分量的行 [N 个轨道 | 实部通道 | 虚部通道]，列 [壳层 | 实部 | 虚部]，大小 (4 nr) × (4 nc)；静态权重同 M6g-1，有限频率的复数权重取实部（eta_compat 取共轭；两分量的分子在有限频率与 DFTB+ 默认一致，不用开关）；费米能级的移动是跨四个分量的一个秩 1 修正。
  • 未知量 [SCC 位点 dq | 三个磁化分量的壳层 dm | 四分量实部块 Q | 四分量虚部块 Qi]；B = γ（加三阶 Hessian）、三个 W（st.pauli.w，没有自旋常数时为零）、两种块核。
  • 没有 SOC：整体转动的生成元 na = ea × m（每个壳层的磁化与每个实部通道的磁化向量，电荷部分为零，取自基态的输入布居），正交化后为 N；解加边方程 [[I − AB, N], [NT, 0]]，即不含整体转动的解。相容方程中边的乘子为零；SCC 容差 1e-8 时仍与 DFTB+ 差 7.7e-10，只用最小范数解（lstsq）则差 1.2e-5。非磁性基态没有生成元，直接求解。
  • 有 SOC：奇异值分解，截掉小于 max(1e-10 smax, 10 × SCC 误差) 的奇异值并警告（GdO 绕轴的转动）；没有截掉时与直接求解相同。
  • 有限频率：直接求解（转动不是零模式）。

本征值与费米能级导数

  • M = C†dH C 的对角元，由列元素与总势相乘；简并组（含 Kramers 对）取组内块的本征值；费米能级导数 = (d列 · v总) / NF。

坐标导数（分子）

  • 对 x = xK,c，H′ 的 K 行按分量：H′q = H0′ + ½S′(vμ + vν) + ½(S′Vq + VqS′) + ½i(S′Viq + ViqS′)，H′a = ½S′(vaμ + vaν) + ½(S′Va + VaS′) + ½i(S′Ya + YaS′)，Ya = Via + Λa（dual SOC 的 HSO = ½i(SΛa + ΛaS)⊗σa 随 S 变化；onsite 模型没有 S，没有这一项）；拼成旋量行，S′2 = S′⊗1。
  • M = CK†(dC) + h.c.，N 同理，复数的 X = W∘(M − ēN) − f̄N（与实数时同一个推导：Uij = (Nijej − Mij)/(ei − ej)，Uii = −½Nii），dρ = CXC†。
  • 四个分量的 Mulliken 布居加上 ρS′ 项；块布居 Qb = ½(tb + tb†)，tb = (compb(dρ)S + compb(ρ)S′)AA，实部进实部通道、虚部进虚部通道；金属的费米能级移动保持电子数；之后与外场相同的 SCC 响应（同样的加边或 SVD 解）。Born 电荷用电荷分量。
  • dual SOC 的 S′ 项使 OH 的 Born 电荷变化 1.2e-4，差分能检验它。

点电荷导数与写出

  • 点电荷导数：外势 dVA/dRj 只加在电荷分量，与外场相同的求解，结果四个分量。
  • dftbplus_io.response_tables：两分量写 q/x/y/z 四行；dftbplus_fermi 的除数按分量数（原来按 dEF 的个数，两分量会被错误地减半）；write_band_derivatives 的势部分为 SPIN 2–4 写零块。坐标导数与点电荷导数的写出只用电荷分量，不用改。

改动的位置

  • response_pauli.py（新）；response.py：四个入口的分支（坐标导数先拒绝周期体系）与结果类的说明；calculator.py：_check_response 放开两分量；analysis.py：说明；dftbplus_io.py：上述写出。
  • 验证工具：refgen 两分量时电荷（绝对）与磁化（相对于 max(1, |DFTB+|)）分开比较，dEidV 补零，dEF 的除数；skew_compat 流程；field_fd 参考（DFTB+ 的 12 次外场计算）；dftbplus.run 存 dipole_moments。

六、DFTB+ 的问题与 pydftb 的做法

DFTB+pydftb
dual SOC 与 +U 或 onsite 同用时，响应丢掉块布居的虚部及其势：分子的极化率相对差 2.2e-5–1.3e-4，周期的 CuO 链的响应核差 75 %块通道含虚部；测试专用开关 DFTB._response_skew_compat 去掉虚部通道即复现 DFTB+（1e-13）；物理值对照 DFTB+ 自己的有限外场
两分量的坐标导数拒绝加上旋量的 H′、S′ 与 dual SOC 的 S′ 项；参考是 DFTB+ SecondDerivatives 的差分 Born 电荷
没有 SOC 时响应方程有转动零模式，迭代解的磁化部分取决于迭代加边方程给不含整体转动的解，与 DFTB+ 的纵向结果一致
dEidV 与 dV_band.out 的自旋维为 4，第 2–4 个是零结果只存一个；比较与写出时照 DFTB+ 补零

七、不做的事与风险

  • 不做：两分量的周期体系坐标导数（同 M6g-2，要 Berry 相位）；长程校正下的响应（M6h 之后）。
  • 风险：
    • χ0 的大小是共线时的 4 倍（行、列各 4 个分量），虚部通道约再加一倍块通道：只在两分量时走新代码，按 PAIR_CHUNK 分块；
    • 弱 SOC 的磁性体系磁化响应很大且条件数差，结果的磁化部分只能相对地比较；SCC 容差松时 SVD 可能把软模式（如 GdO 的 3.4e-4）也截掉，警告里写出被截掉的奇异值；
    • dual SOC + 块势没有 DFTB+ 的正确解析参考，分子靠有限外场（Cu4CO 的截断误差约 7e-9），周期体系靠位点势的差分（自洽测试）与开关后对 DFTB+ 的比较。
