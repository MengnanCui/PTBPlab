关键信息

M6h-1 的 LC/CAM 杂化泛函推广到周期体系的 Γ 点：DFTB+ 25.1 只用 Γ 点时，交换就是分子的四项公式，只是 S 换成镜像折叠的 S(Γ)，γ 换成对晶格平移求和的截断 γ，P0 换成 q0/Sμμ(Γ)。SCC、混合、能量的写法都与分子相同。k 点（BvK 超胞上的 ΔP(k) 或 ΔP(R)）另作 M6h-3b。

  • 原型与 DFTB+ 的对照（第二节，探针 P62–P69）：
    • 能量：CO2 晶体、金刚石、铜（Fermi 展宽）、O2（自旋）各 1–5 种设置差 ≤ 7.8e-11 Ha，SCC 轮数全部相同；截断与阻尼截断，MatrixBased 与 NeighbourBased（含 CutoffReduction）。
    • 力：用 DFTB+ 的 SK 差分步长时差 ≤ 1.2e-11 Ha/Bohr；与原型自身能量的差分一致到 ≤ 2e-9。
    • 与 +U、onsite、完整 DFTB3 加 D3、外场加点电荷、MP 展宽、Anderson 混合器、自定义 Hubbard U 同用都一致；从 DFTB+ 的电荷文件重启，轮数相同。
  • DFTB+ 25.1 的四处问题（第六节；B1、B6 在原型里照 DFTB+ 改一行就复现到 DFTB+ 的数，B18 照 DFTB+ 的读法错一位就复现它的 SCC 误差）：
    • B1：TruncatedAndDamped 时，HF 部分的导数在阻尼区里用了 LR 的多项式系数。CAM 与全局杂化的力偏 7.0e-7 与 5.6e-6 Ha/Bohr。
    • B6：输入布居由只存下三角的 ΔPin 算 Mulliken，同一原子的非对角块只按列求和。低对称晶胞里 S(Γ) 有原子内的非对角元，三斜的 CO 晶胞电荷偏 1.3e-5，力偏 7.1e-6（能量是二阶，差 3e-11）。
    • B13：k 点写成显式的 Γ 点时，读电荷文件重启会停下（只许单轮的能带计算）；写成 SupercellFolding 就可以。
    • B18（实现时 P70 发现）：分子读 Γ 点的电荷文件时不跳过折叠矩阵记录，ΔPin 整体错一位（第一个元素取成折叠矩阵的 1.0）。反过来，Γ 点读分子的文件会停下。
  • 与分子不同的一处：NeighbourBased 加 CutoffReduction 时，DFTB+ 周期 Γ 点的力用缩减的近邻表，是能量的导数（分子时用完整的表，不是导数）。
  • ≤ 7.8e-11原型与 DFTB+ 25.1 的能量之差（Ha）
  • ≤ 1.2e-11原型与 DFTB+ 的力之差（Ha/Bohr）
  • 4DFTB+ 的问题，每一处都复现到它的数字

一、DFTB+ 的做法

源码 25.1（dftb/hybridxc.F90、rshgamma.F90、dftbplus/parser.F90: parseHybridBlock、initprogram.F90、main.F90: getNextInputDensityReal、dftb/populations.F90、dftb/sccinit.F90）；调研记录在草稿目录 m6h3/research_hybrid_periodic.md，行为以 25.1 的二进制为准。

  • 输入：Hybrid = LC {…} 或 CAM {…} 里多一个只对周期体系读的 CoulombMatrix：
    • Truncated（默认）与 TruncatedAndDamped，子项 CoulombCutoff（Rc）与 GSummationCutoff（Rg）；
    • Full 与 MinimumImage 在 Γ 点拒绝：“Hybrid functionals don't yet support Gamma point calculations for CoulombMatrix types other than 'Truncated' or 'Truncated+Damping'.”；
    • 默认 Rc 是晶胞最小晶面间距的一半，Rg = 2Rc；阻尼区是 (Rc − 1 Bohr, Rc)，Rc ≤ 1 Bohr 时报 “The beginning of the damping region of the truncated Coulomb kernel must be at a positive radius.”。
  • γ：gt(A, B) = Σg γc(|RA − RB − g|)，g 取晶格平移的平行六面体 |ni| ≤ ⌊Rg/hi⌋ + 1（hi 为晶面间距），A = B 时含在位值与自身镜像。
    • Truncated：γc = γ（d < Rc），否则为 0。
    • TruncatedAndDamped：阻尼区内换成 poly5zero，即在 Rd 处与 γ 的值、一阶、二阶导数相等，在 Rc 处三者都为 0 的五次多项式。LR 的二阶导数是一阶解析导数的中心差分（δ = 1e-8），HF 的三者都是解析的。
    • γ = α γHF + β γLR，函数与 M6h-1 相同。
  • 交换：Hx = c[(SΔPS)∘G + ((SΔP)∘G)S + S(ΔP∘G)S + S((ΔPS)∘G)]，S = S(Γ)（MatrixBased）或只含 CAM 截断以内原子对的 S(Γ)（NeighbourBased），G 是 gt 铺到轨道上。c、EFock = ½ Σ Hx[ΔPin]∘ΔPin 都与分子相同。
    • 只用 Γ 点时这是精确的：对实空间的 BvK 表达式求和，镜像和正好分解成 S(Γ) 与 gt。
    • NeighbourBased 的 Threshold 在 Γ 点读入但不使用。
  • 参考密度：ΔP = P − diag(s q0μ / Sμμ(Γ))，s = 1 或每个自旋 ½；Sμμ(Γ) 含轨道与自身镜像的重叠，不是 1。
  • SCC：与分子相同。
    • 混合整个 ΔP 数组（上三角为 0），误差 max|ΔPout − ΔPin|；
    • 第一轮 ΔPin = 0；有自旋时第一轮不混合，至少两轮。
    • qin = denseMullikenReal(ΔPin, S(Γ)) + q0：只存下三角，同一原子的块只按列求和（第六节 B6）。
  • 力（Γ 点两种筛选、两种截断，含自旋）：用 ΔPout。
    • dS 部分加到成对元素的系数上，系数对所有镜像对相同；dγ 部分对镜像求和。
    • NeighbourBased 的 dS 与 dγ 两部分都用缩减的近邻表，是能量的导数（P68）。
    • TruncatedAndDamped 时 HF 部分在阻尼区的导数用了 LR 的系数（B1）。
  • 应力：所有杂化计算静默关掉（tStress … .and. .not. isHybridXc）；晶格优化与恒压 MD 拒绝。
  • 电荷文件：周期杂化在头部置第 4 个逻辑量（k 点信息），在多极子记录之后写一条 12 个数的记录（3 × 3 折叠矩阵按列，再加 3 个平移；Γ 点为单位矩阵与零），然后是 ΔPin（与分子相同，每个数一条记录）。
    • 读入时，k 点写成显式的 Γ 点会被当成能带计算，多于一轮就停下（B13）；用 SupercellFolding 写 Γ 点就能正常重启。
  • 拒绝（P69 实测）：
    • Thresholded：“Hybrid functionality for periodic systems currently not implemented for the threshold algorithm.”
    • 非共线自旋：“Non-collinear spin only available for hybrids with molecular systems at present.”
    • 激发态：“hybrid functional excited states for periodic geometries are currently unavailable”（要激发态力时先报 “Forces in the excited state for periodic geometries are currently unavailable”）。
    • k 点只许不平移的 SupercellFolding（M6h-3b）。

二、DFTB+ 的实测行为与原型

探针 P62–P71（草稿目录 m6h3/；P70、P71 是实现时补做的）。原型 gproto.py 用 pydftb 的分子杂化代码，只替换 S(Γ)、gt、P0（以及 NeighbourBased 的缩减 S）。参数集 ptbp_hcocu_lc、_cam、_global，两边 SCC 容差 1e-10，DFTB+ 的 EwaldTolerance 1e-12（默认的 1e-9 让 CO2 晶体的能量差 8.6e-8，与杂化无关，同 M6f-1）。

探针内容结果
P62 能量与 SCCCO2 晶体（Pa3̄，12 个原子，扰动）：默认截断（Rc = 5.31 Bohr）、Rc = 8 的截断与阻尼截断、NeighbourBased（缩减 0 与 4 Bohr）；金刚石（8 个原子，默认与 Rc = 6）；Cu4（1000 K）；5 Å 盒子里的 O2（自旋）能量差 ≤ 7.8e-11 Ha，EFock ≤ 3.5e-11，电荷 ≤ 1.7e-10，SCC 轮数全部相同（最长 109 轮）。每轮误差前十几轮一致到 1e-8（相对），之后是舍入级的差别（绝对值约 4e-13）。
P63 力同上，加 CAM 截断、CAM 与全局杂化的阻尼截断与 DFTB+ 的力差 ≤ 1.2e-11（DFTB+ 的 SK 步长），与原型自身能量的差分 ≤ 2e-9（解析 SK 导数）。阻尼截断的 CAM 与全局杂化：差 7.0e-7 与 5.6e-6；HF 部分改用 LR 的系数后 6.1e-12（B1）。
P64 低对称晶胞三斜的 CO 晶胞（原子内 S(Γ) 非对角元 5.2e-3）、单斜的 H2O 晶胞（3.2e-4）正确的 Mulliken：能量差 3e-11，电荷 1.3e-5 与 4.6e-6，力 7.1e-6 与 3.0e-7，轮数相同但每轮误差从第 2 轮起不同。照 DFTB+ 的 denseMullikenReal 算 qin：电荷 1.4e-11，力 1.1e-12，每轮误差 9e-9（B6）。
P65 电荷文件DFTB+ 写的 charges.dat 与 charges.bin头部 F F T T T；“0 0” 之后一条 12 个数的折叠矩阵记录；然后 n × n 个 ΔPin。二进制长度相符。
P66 组合CO2 晶体加 +U、onsite、完整 DFTB3 加 D3、外场加点电荷、MP 展宽、Anderson 混合器、自定义 Hubbard U能量差 ≤ 9.3e-11，力 ≤ 8.8e-12，轮数全部相同（Anderson 187/187）。
P67 重启run 1 写 charges.dat，run 2 移动一个原子后读入显式 Γ 点：DFTB+ 停下（B13）。SupercellFolding：DFTB+ 25 轮，原型读同一个文件 25 轮，能量差 1.1e-11。
P68 邻居筛选的力CO2，CutoffReduction 10 Bohr（CAM 截断 5.36 Bohr，去掉所有分子间原子对），Rc = 8DFTB+ 的力对能量差分 2.7e-9：是导数。原型用完整的 S：差 3.1e-5；只在 dS 部分用缩减的 S：9.8e-7；dS 与 dγ 两部分都用：6.1e-12。
P69 拒绝Thresholded、非共线、MinimumImage、Full、Rc = 0.8 的阻尼截断、激发态原话见第一节。
P71 分子的 CoulombMatrix水分子的 Hybrid = LC 加 CoulombMatrix = TruncatedAndDamped 或 FullDFTB+ 停下：“The following 1 node(s) have been ignored by the parser … CoulombMatrix”（没读的输入）。不加时照常运行。
P70 跨类型重启CO2 晶体的原子：分子写的 charges.dat 给 Γ 点读，Γ 点写的给分子读（文本文件）Γ 点读分子的文件：DFTB+ 停下（“only identical k-point samplings”，折叠矩阵印成 0）。分子读 Γ 点的文件：DFTB+ 照常运行，75 轮。它不跳过折叠矩阵记录，ΔPin(1,1) 取成该记录的第一个数 1.0，其后每个数错后一位、最后一个丢掉（B18）：pydftb 从错位的矩阵出发，前两轮的 SCC 误差与 DFTB+ 印出的每一位相同（1.892735、1.801576）；从正确的矩阵出发是 0.0256，24 轮，最后的能量相同。

三、pydftb 的接口

calc = DFTB(sk_lc, hybrid={"type": "lc", "screening": "matrix",
                           "coulomb": "truncated", "coulomb_cutoff": 8.0, "gsum_cutoff": 16.0})
r = calc.calculate(labels, pos, cell, forces=True)      # 只用 Γ 点（kpts=None）
r.e_fock, r.q_in                                         # q_in = [布居 | ΔP 的下三角]
  • 新选项（Hybrid）：
    • coulomb："truncated"（默认）或 "damped"（DFTB+ 的 TruncatedAndDamped）；
    • coulomb_cutoff、gsum_cutoff（Bohr）：默认同 DFTB+（最小晶面间距的一半，及其两倍）；
    • 分子给了这三项就报错：DFTB+ 只在周期体系里读 CoulombMatrix，分子的会作为没读的输入停下（P71，实现时补做；设计原写“分子不读”）。
  • 条件：
    • 周期体系只用 Γ 点；其他 k 点是 M6h-3b，在那之前拒绝；
    • 拒绝（DFTB+ 的原话）：Thresholded、非共线自旋、激发态（TD-LC）、Rc ≤ 1 Bohr 的阻尼截断；
    • 应力：DFTB+ 静默关掉，pydftb 在要求应力时报错，默认不算。
  • 输入布居：pydftb 用 ΔPin 真正的 Mulliken 布居。低对称晶胞里与 DFTB+ 不同（B6），验证用的兼容开关能复现 DFTB+。
  • 力：精确的导数（NeighbourBased 用缩减的近邻表，同 DFTB+）。阻尼截断的 HF 部分用正确的系数；验证用的开关能复现 DFTB+（B1）。
  • 电荷文件：charge_data 写 DFTB+ 的格式（含单位折叠矩阵）；populations_from_file 读 Γ 点的文件，k 点的文件留给 M6h-3b。
  • 组合：自旋、展宽、+U、onsite、完整 DFTB3、D3、外场、点电荷、各混合器、自定义 Hubbard U、重启、优化与 MD（几何步之间沿用 ΔP）。
开发细节四、实现
  • hybrid.py：
    • Hybrid 加 coulomb、coulomb_cutoff、gsum_cutoff（make 认这三个键）。
    • 新函数：
      • ddgamma_hf：解析二阶导数，即 DFTB+ 的 getddHfAnalyticalGammaValue_workhorse 与 getddYGammaSubPart；U 几乎相等时用一阶导数的中心差分，因为 pydftb 在那里本来就用 Hermite–Genocchi 形式。
      • poly5zero；coulomb_gamma(…, kind, derivative=…)：两种截断的值与导数（dftbp_hf 是 B1 的开关）。
      • plane_spacings、default_coulomb_cutoff、lattice_translations。
    • HybridTerms(…, cell=…, pairs=…)：
      • 接收晶胞、成对的块（含镜像）与 S(Γ)；按 Hubbard U 分组对原子对与平移求 gt，用与 S(Γ) 相同的 fold 建 NeighbourBased 的缩减 S(Γ)（缩减为 0 时与 S(Γ) 逐位相同），P0 除以 Sμμ(Γ)。
      • pair_coefficient、gamma_gradient：NeighbourBased 用缩减的 S，且只给 CAM 截断以内的原子对系数；_gamma_force 对镜像求和。
      • 分子的路径不变（逐位）。
      • 验证用的类属性 _dftbp_hf_damped_derivative（B1）。
    • dftbp_dense_mulliken：DFTB+ 的 denseMullikenReal 在只存下三角的 ΔP 上的结果（B6 的兼容开关用）。
  • calculator.py：
    • _setup：周期体系且只有 Γ 点时建周期的 HybridTerms；其余 k 点拒绝（M6h-3b）；Thresholded、非共线、激发态按 DFTB+ 的原话拒绝。
    • _run：杂化时默认不算应力，明确要求时报错。
    • _scc_hybrid：验证用的类属性 _dftbp_gamma_q_in 打开时，qin 用 dftbp_dense_mulliken（B6）。
    • charge_data、populations_from_file：周期杂化的折叠矩阵记录。
  • dftbplus_io.py：读写 k 点信息记录（12 个数），Γ 点以外的折叠矩阵在读入密度矩阵时拒绝（M6h-3b）。
  • bands.py：eigenstates 在 Γ 点加周期的 Hx[ΔPin]，其他 k 点拒绝（M6h-3b）。
  • ase_calc.py：杂化的周期体系要应力时报 ASE 的 PropertyNotImplementedError；coulomb_cutoff、gsum_cutoff 以 Å 为单位；write_charges 写折叠矩阵记录。

六、DFTB+ 的问题与 pydftb 的做法

DFTB+ 25.1证据pydftb
B1：TruncatedAndDamped 时，HF 部分的导数在阻尼区里用了 LR 的多项式系数（hybridxc.F90 第 4370–4373 行；值在第 3801–3804 行用 HF 的系数）CO2 晶体 Rc = 8：CAM 的力偏 7.0e-7，全局杂化 5.6e-6 Ha/Bohr；照 DFTB+ 改后 6.1e-12精确的导数；验证用的兼容开关复现 DFTB+
B6：Γ 点的 qin 由只存下三角的 ΔPin 经 denseMullikenReal 算出，同一原子的块只按列求和，丢了一半原子内非对角的贡献（populations.F90 第 540–552 行）三斜 CO 晶胞：电荷偏 1.3e-5，力偏 7.1e-6，SCC 的不动点不是自洽解（能量是二阶的，3e-11）；照 DFTB+ 改后电荷 1.4e-11、力 1.1e-12。立方、正交、六方晶胞因对称不受影响真正的 Mulliken 布居；验证用的兼容开关复现 DFTB+
B13：显式的 Γ 点加 ReadInitialCharges 被当成能带计算，多于一轮就停下（parser.F90 第 3102–3103 行不查是否只有 Γ 点）P67验证工具对周期杂化写 SupercellFolding
B18：分子读 Γ 点的电荷文件不跳过折叠矩阵记录，ΔPin 整体错一位（sccinit.F90 第 552–573 行：只有本次是周期杂化（tKpointInfo）才读这条记录，第 594–603 行随后逐个读 ΔP）P70两种文件都按格式读（折叠矩阵记录解析后检查）；分子与 Γ 点的 ΔP 是同样的稠密矩阵，互相可读
默认的 EwaldTolerance 1e-9CO2 晶体的能量差 8.6e-8（与杂化无关，M6f-1 记录过）周期算例用 1e-12

七、不做的事与风险

  • M6h-3b（k 点）：
    • MatrixBased 混合每个 k 的复数 ΔP(k)，NeighbourBased 混合 BvK 实空间的 ΔP(R)；
    • k 点的 EFock 用 ΔPout；
    • 力只有 Truncated、不加自旋；MinimumImage。
    • 调研记下的默认截断问题（BvK 向量按分量缩放、对角线交点的求法不稳）也在那时处理。
  • 不做：
    • 应力（DFTB+ 没有）；
    • Full（DFTB+ 只在 k 点、仅供测试）；
    • 周期体系的 TD-LC 与非共线（DFTB+ 拒绝）；
    • Thresholded（DFTB+ 拒绝）。
  • 规模：gt 对原子对与平移逐一求 γ，平移数由 Rg 决定（默认 5 × 5 × 5 以内）；按平移分块，每块至多 220 个原子对 × 平移，大晶胞的内存因此有界（实现时补上：一次建整个数组时，500 个原子的晶胞要几 GB）；交换仍是 Norb 的稠密矩阵积。
  • 风险：U 几乎相等时的 HF 二阶导数用差分，与 DFTB+ 的闭式不同；DFTB+ 的闭式在那里本来就失去精度（M6h-1 坑 117）。测试参数集里没有这样的元素对。
