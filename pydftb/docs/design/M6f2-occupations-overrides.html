关键信息

M6f 的第二块：电子怎样占据能级，以及在输入中临时改动参数。补上 DFTB+ 的五个选项：固定费米能级（FixedFermiLevel）、每个 k 点单独填充（IndependentKFilling）、自定义 Hubbard U（CustomisedHubbards）、自定义参考占据（CustomisedOccupations）、截断 SK 表（TruncateSKRange）。只做 NumPy 引擎；不用这些选项时逐位不变。

  • DFTB+ 的做法（第一节）：
    • 固定费米能级时电子数不守恒，体系与“电子库”交换电子；力是 EFR = EMermin − Σs NsEf,s 的负梯度，results.tag 里的 mermin_energy 写的就是 EFR；
    • 每个 k 点单独填充时，每个 k 点各放 N 个电子、各有自己的费米能级，能带能、熵和费米能级再按 k 权重平均；
    • 自定义的 U 只在大于 0 时生效，并且处处都用它（γ、三阶、激发态）；自定义的参考占据改变 q0 和电子数（“虚拟掺杂”）；SK 表按行截断，排斥势不动。
  • 探针中的发现（第二节）：
    • 固定费米能级的 SCC 很脆弱：OH 自由基、Cu4CO 三重态、带 SOC 的 Cu4CO 都不收敛或要几百轮；致密的周期体系（CuO 链）会“跑掉”，收敛到所有能带全满（N = 52）的解。原因是周期体系中均匀电荷被中和背景抵消，没有恢复力。参考算例只选收敛快、路径平滑的体系；
    • 带电的周期晶胞，DFTB+ 的应力不是它自己能量的应变导数：Cu fcc 差 3.0e-7，盒子中的 Cu4CO 差 1.0e-8（只在对角元上，各向同性），普通的 Charge ≠ 0 也一样。pydftb 的应力与它自己能量的差分一致到 2e-11；参考算例改存 DFTB+ 能量的应变差分 stress_fd；
    • IndependentKFilling 遇到共线自旋时 DFTB+ 25.1 直接崩溃（数组越界）；
    • CustomisedOccupations 必须写在 Hamiltonian 里，写在顶层时 DFTB+ 报“未处理的节点”。
  • pydftb 的接口（第三节）：DFTB(fixed_fermi_level=…, independent_k_filling=…, hubbard=…, reference_occupations=…, truncate_sk_range=…)；结果加 e_force_related、n_electrons、q0_atom。PyDFTB 用 ASE 的单位（eV、Å），固定费米能级时 free_energy 是 EFR（与力一致）。
  • 5DFTB+ 选项：固定费米能级、按 k 点填充、自定义 U、自定义占据、SK 截断
  • 3.0e-7带电晶胞上 DFTB+ 的应力与其能量的应变差分之差（Ha/Bohr3）
  • 20DFTB+ 参考算例

一、DFTB+ 的做法

源码为 DFTB+ 的 041e723（dftbplus/main.F90 的 getFillingsAndBandEnergies、dftb/getenergies.F90、dftbplus/parser.F90、dftbplus/initprogram.F90），所有规则都用本机 25.1 二进制的探针确认过。

固定费米能级

  • 写法：Filling = Fermi { Temperature [K] = …; FixedFermiLevel [eV] = { … } }（Gaussian、Methfessel–Paxton 也可以）。共线自旋要给两个值（上、下），无自旋和两分量（非共线、SOC）给一个。
  • 占据：每个自旋通道在给定的 Ef 上直接用 electronFill，不再按电子数找费米能级；无自旋时与平常一样，每个能级先放一个电子再乘 2。电子数随 SCC 变化，detailed.out 的 “Total charge” = Σq0 − N。
  • 能量（calcEnergies、sumEnergies）：
    • NEf = N↑Ef,↑ + N↓Ef,↓（共线；Ns 由输出布居的 (q, m) 换成上、下），否则 N·Ef；
    • EFR = EMermin + pV − NEf（pydftb 没有外压，pV = 0）；不固定费米能级时 NEf = 0，EFR 就是 Mermin 自由能；
    • detailed.out 的 “Total energy”、“Total Mermin free energy” 照常；“Force related energy” 是 EFR；results.tag 的 mermin_energy 写的是 EFR（另有 forcerelated_energy、number_of_electrons，共线时后者每个通道一个数）。
  • 力和应力：用与平常相同的公式。固定 Ef 时 EFR 是巨势，对占据变分，所以这组公式给出的正是 −dEFR/dR（探针确认，见第二节）。
  • 其他：读电荷文件时不检查电子数和磁化；RelaxTotalSpin 被默默忽略（固定费米能级的分支在前）；IndependentKFilling 不读（于是报“未处理的节点”）。

每个 k 点单独填充

  • 写法：Filling = Fermi { …; IndependentKFilling = Yes }，只对周期体系、且没有固定费米能级时读。
  • 做法：对每个 k 点调用 detFilling，k 权重设为 1：这个 k 点上放 N 个电子（无自旋时每个能级一个电子、N/2 个，再乘 2），各自走“中隙规则”和二分法；能带能、Ef、TS、E0 再按 k 权重相加。得到的占据乘以 k 权重后，总电子数仍是 N。
  • DFTB+ 的错误：共线自旋时 kWeightTmp(:nSpinHams) 给只有一个 k 点的数组传了两个权重，越界；25.1 在第一轮之后崩溃（“munmap_chunk(): invalid pointer”）。两分量计算没有这个问题。

自定义 Hubbard U

  • 写法：Hamiltonian = DFTB { CustomisedHubbards { O = 0.5 } }。壳层分辨的 SCC 每个壳层一个值；原子分辨时一个值，用于该原子的所有壳层。
  • 规则（initHubbardUs_）：where (custom > 0) hubbU = custom，≤ 0 的值保留 SKF 的。原子分辨时 SKF 的值本来就是 s 壳层的 U 用于所有壳层。
  • 影响：所有用到 U 的地方都换成新值：SCC 的 γ（含 Ewald 的短程部分、H–X 阻尼）、三阶（thirdInp%hubbUs）、线性响应（取 HOAO 壳层的 U）、混合的等价类。

自定义参考占据

  • 写法：在 Hamiltonian 中写 CustomisedOccupations { ReferenceOccupation { Atoms = 3; p = 4.2 } … }。一个块里的原子必须是同一类型；一个原子只能出现在一个块里；没给的壳层用 SKF 的参考占据。
  • 影响：
    • q0 换成自定义值，每个壳层的占据平均分到它的轨道上（initQFromUsrChrg）；
    • 电子数 N = Σq0 − Charge：CH3OH 的 O 的 p 设为 4.2 时 N = 14.2，“Total charge”仍为 0；
    • Mulliken 电荷、偶极、SCC 能量都相对于新的 q0；onsite 修正的 q − q0 也一样；
    • SCC 的起点是新的 q0；但 InitialCharges 的 aufbau 仍用 SKF 的参考占据（referenceN0），最后缩放到新的电子数；
    • 与线性响应同用时报错 “Custom occupation not compatible with linear response”。

截断 SK 表

  • 写法：Hamiltonian = DFTB { TruncateSKRange { SKMaxDistance [Bohr] = 6.0; HardCutOff = Yes } }。
  • 规则（SKTruncations、readSKFiles）：
    • HardCutOff = Yes（默认）时 R 先减去尾巴的长度 1 Bohr（distFudge），使截断后的表连同尾巴正好在 R 处变为零；R ≤ 0 时报错；
    • H、S 表保留前 n = min(⌊R/Δr⌋, 实际使用的行数) 行，插值与尾巴从新的末尾重新构造；
    • 排斥势不截断；DFTB+ 警告 “Artificially truncating the SK table, this is normally a bad idea!”；
    • 有长程校正（混合泛函）时不读这个块，于是报“未处理的节点”。

三、pydftb 的接口

calc = DFTB(sk, smearing=("fermi", 300), fixed_fermi_level=-0.140)   # Hartree
calc = DFTB(sk, spin=True, ..., fixed_fermi_level=(-0.13, -0.24))     # 共线：(上, 下)
r = calc.calculate(labels, pos)
r.energy, r.free_energy        # DFTB+ 的 Total energy、Total Mermin free energy（不变）
r.e_force_related              # F − Σ N_s E_f,s：力的负梯度对应的能量（平时就是 F）
r.n_electrons                  # 输出布居的电子数
r.fermi, r.fermi_spin          # 给定的费米能级

DFTB(sk, kpts=..., independent_k_filling=True)            # 每个 k 点单独填充
DFTB(sk, hubbard={"O": 0.5, "H": -1.0})                    # 原子分辨：每类一个值
DFTB(sk_shell, hubbard={"Cu": [0.3, 0.0, 0.4]})           # 壳层分辨：每壳层一个；≤ 0 保留 SKF 的
DFTB(sk, reference_occupations={1: {"p": 4.2}})           # 原子序号（0 起，CH3OH 的 O）→ 壳层占据
r.q0_atom                                                  # 自定义时每个原子的参考布居
DFTB(sk, truncate_sk_range=6.0)                            # Bohr，HardCutOff = Yes
DFTB(sk, truncate_sk_range={"max_distance": 6.0, "hard_cutoff": False})

atoms.calc = PyDFTB(skdir, smearing=("fermi", 300), fixed_fermi_level=-3.81)   # eV
atoms.calc = PyDFTB(skdir, truncate_sk_range=3.175)                            # Å
  • 固定费米能级：
    • 共线自旋也可以只给一个数，用于两个通道；
    • energy、free_energy 的含义不变（与 DFTB+ 的 detailed.out 相同）；e_force_related 与力一致，等于 DFTB+ results.tag 的 mermin_energy；
    • PyDFTB 的 free_energy（ASE 的 force-consistent 能量）取 e_force_related，energy 仍是 Total energy（ASE + DFTB+ 读的是 detailed.out 的 “Total energy”）；
    • 读 DFTB+ 电荷文件时不检查电子数和磁化，与 DFTB+ 相同；
    • 不能与 relax_total_spin（DFTB+ 默默忽略，pydftb 报错）、independent_k_filling、Casida 激发态、XL-BOMD、SP2 求解器同用。
  • 按 k 点填充：周期体系，无自旋或两分量；共线自旋报错（DFTB+ 25.1 在此崩溃），分子报错（DFTB+ 不读这个关键字）。fermi 是各 k 点费米能级的 k 加权平均，与 DFTB+ 相同。
  • 自定义 U：作用在 SK 集合的一个副本上（calc.sk），传入的 SKSet 不变；γ、三阶、Casida 都用新值。不在这组 SK 中的类型标签被忽略（PyDFTB 对每个结构建自己的 SK 集合）。
  • 自定义占据：每个原子一个字典（壳层字母 → 电子数）或每个壳层一个数；没给的壳层用 SKF 的参考占据。结果的 charges 仍是布居，q0_atom − charges 是相对于自定义参考的净电荷；PyDFTB 的 charges 与 DFTB+ 的 Mulliken 电荷一样，相对于自定义参考。与 Casida 同用报错（同 DFTB+）。
  • SK 截断：calc.sk 是截断后的副本，原 SKSet 及其 SK 文件对象、插值系数缓存都不变；同一 SKSet、同一截断只建一次。发出与 DFTB+ 相同的警告。
  • 限制：五个选项都只在 NumPy 引擎中；torch 后端和 pydftb.autodiff 遇到时报错。
开发细节四、实现
  • occupations.py：
    • fill_at(evals, weights, mu, smearing, spin_factor)：用现有的 _electron_fill（DFTB+ 的 electronFill）在给定的 μ 上填，返回与 fill 相同的 (占据, μ, TS)；
    • fill_independent_k(evals, weights, nelec, smearing, spin_factor)：每个 k 点调用 fill(evals[k][None], [1.0], nelec, …)，μ 与 TS 按 k 顺序乘权重相加（与 DFTB+ 的求和顺序相同）。
  • solvers._density(..., occupations=None)：可选的占据函数 (evals, kw, nelec, smearing, spin_factor) → (occ, μ, TS)；None 时照旧调用 fill（旧表达式不动）。
  • calculator.py：
    • _solve 最前面加一个分支：开了固定费米能级或按 k 点填充时，所有路径都走 solver.eig + _density(occupations=…)；默认的无自旋路径仍是 solver.solve；
    • _channel_filling(s) 给出第 s 个通道的占据函数，bands._fill 也用它（能带计算与 SCC 用同样的填充）；
    • _SCCState、DFTBResult 加 n_ef（固定费米能级时的 Σ NsEf,s，否则 None）；e_force_related、n_electrons 是属性，不增加 golden 的字段；
    • _reference_shell_populations(basis)：没有自定义占据时返回与现在完全相同的表达式；用于 _sites（q0 与电子数）、_initial_populations、_custom_shell_populations（不给初始电荷时）、_initial_block_vector、BlockTerms.build（新参数 shell_occupation）；每处都是“有自定义时走新分支，否则旧代码”；
    • DFTBResult.q0_atom 只在自定义占据时给出；ase_calc._store 与 api.SCC.mulliken 在它不为 None 时用它；
    • populations_from_file 在固定费米能级时跳过电子数与磁化的检查；
    • numpy_only_options 列入五个新选项（torch 后端与自动求导因此报错）；构造时检查各种组合。
  • skf.py：
    • SKSet.with_hubbard(custom)：浅副本，files 共享，只换 hubbard 字典；
    • SKSet.truncated(r_max, hard_cutoff=True)：浅副本，files 中每个文件换成 dataclasses.replace(f, table=f.table[:n], _coef=None)，n = min(⌊R′/Δr⌋, 行数)，R′ = R − 1 Bohr（hard）；少于 8 行（插值需要 8 个点）时报错；结果缓存在原 SKSet 的字典里（键为 (R, hard)），绝不修改 _READ_CACHE 中共享的 SKFile。
  • DFTB.__init__：self.sk = sk.with_hubbard(…).truncated(…)（需要时），其余代码不用改。
  • 其他：ase_calc.py（新选项与单位换算、free_energy、q0_atom）、api.py（mulliken）。
  • 验证工具：
    • cases.py：Case.fermi（{"fixed": …} 或 {"independent_k": True}）、hubbard、occupations、truncate_sk、stress_fd；
    • dftbplus.py：filling_block(filling, fixed_ef=…, independent_k=…)，Hamiltonian 中的 CustomisedHubbards、CustomisedOccupations、TruncateSKRange 块，解析 “Force related energy”、标签 forcerelated_energy 与 number_of_electrons；

  • fill_at 在 fill 找到的 μ 上给出相同的占据与 TS；fill_independent_k 只有一个 k 点时与 fill 逐位相同；
  • Ef 取中性自洽解的费米能级时，固定费米能级的结果与普通计算相同（能量、电荷到 SCC 精度）；
  • EFR 对原子位置与应变的有限差分等于力与应力（分子、共线、两分量、带电晶胞）；
  • with_hubbard 与手工改写 SKF 的 U 后建的 SKSet 结果相同；全部 ≤ 0 时与不改逐位相同；
  • 自定义占据等于 SKF 的值时与不设逐位相同；截断到比表还长时与不截断逐位相同；原 SKSet、文件对象和插值缓存都不变；

六、不做的事与风险

  • 不做：
    • DFTB+ 的外压 pV 项（pydftb 没有恒压优化）；
    • 共线自旋的按 k 点填充（DFTB+ 25.1 自己就崩溃，无从对照）；
    • 新功能的 torch 与自动求导版本。
  • 风险：
    • 固定费米能级的 SCC 路径长、对舍入敏感：只选第二节中收敛快的体系，记录每个算例最后几轮离阈值的距离；
    • 带电晶胞的应力以 DFTB+ 能量的差分为准：差分的精度（3e-11）远小于容差，DFTB+ 解析应力的偏差另外记录；
    • SKSet 的副本误改共享的缓存：只做浅副本，新的 SKFile 对象 _coef=None，测试检查原对象不变；
    • 默认路径：每个新分支都放在旧代码之前，golden 逐位比较。
