背景：起点、现状与已定的决定

用户 2026-11-09 定的目标：一套 DFTB 参数集，至少在能量上（成键、断键）达到 DFT 精度，最后用能量和力的误差来判。路线按顺序走：

  1. 单一参数集，比较几种拟合策略；
  2. 多参数（随环境变化），描述符从配位数开始，依次是 2/3 体、SOAP、ACE（MACE）；
  3. 最后才是 Δ-ML。

试用体系有三个：Li、Li/Li 氧化物与界面、../Perovskite。

    • SK 表有噪声，力上能看到台阶；借用 3ob 的 D3 参数会过度结合。

配平的能量差清单

形成能和反应能按产物的原子数归一为 eV/原子；分子反应另报每个反应的误差（eV）。

  • Li
    • bcc、fcc、hcp 的 EOS（相对能、V₀、B）；
    • 空位形成能，(100)/(110)/(111) 表面能；
    • Li₂ 二聚体曲线 E(r) − E(6 Å)；
    • 0.70–0.85 V₀ 的压缩 bcc，随机位移帧与 MD 帧。
    三相之差在 PBE 中 ≲ 2 meV/原子，不作为决定性符号。
  • Li–O
    • Li₂O、Li₂O₂ 的 EOS；
    • 2Li + Li₂O₂ → 2Li₂O；
    • Li₁₆O → 14Li + Li₂O（O 间隙），Li₈O₃ 的 O 空位（以 Li、Li₂O 为参考）；
    • LiO、O₂ 二聚体曲线（与现有数据一样是 ISPIN 1）；
    • Li₂O(111) 表面能，界面能 E(slab) − n·E(Li) − m·E(Li₂O)；
    • 决定性：塌缩快照比初始界面高（DFT +1.29/+1.44 eV/原子），界面 MD 不塌缩。
  • 前驱体溶液
    • MI₂ + nL → MI₂(L)ₙ 的结合能（M = Pb、Sn；L = DMSO、DMF；n = 1–3）。每个配体误差 ≤ 0.1 eV，这个阈值是提议。
    • 决定性：选择性 PbI₂(DMF)₂ + SnI₂(DMSO)₂ ⇄ PbI₂(DMSO)₂ + SnI₂(DMF)₂ 的符号。
    • 溶剂交换；PbI₂ + I⁻ → PbI₃⁻ → PbI₄²⁻ 与 Sn 的对应反应，用 FA⁺、Cs⁺ 离子对中和电荷。
    • 决定性：质子转移 FA⁺ + L → FA + LH⁺、FA⁺·I⁻ → FA + HI 必须吸热。
    • 决定性：FA⁺ π*–I⁻ 5p 的间隙与 DFT 一致。
    • 团簇快照的相对能与力；M409 帧只作测试。

测试集、基线、评测工具与约定

  • 测试集：冻结，按结构家族划分。
    • 家族内测试：例如 seed 101 的随机位移。
    • 家族外测试：例如 hcp、表面、空位、界面帧、MD 帧；溶液体系是 n = 3 的络合物、另一条轨迹的团簇、M409 帧。
    • 选模型只用训练集内的留一家族交叉验证，测试集只在关口打开。
  • 基线：
    • 发表的 PTBP；
    • GFN1-xTB（tblite，本机）；
    • 同一数据上训练的 MACE（K7），表示数据本身能支持的上限；
    • MACE-MP-0 零样本，溶液用 MACE-OMOL。
  • 评测工具 pydftb/assess.py：
    • 输入：计算器工厂（SK 目录、选项、可选的 types/adaptive/Δ 模型）、带 family/role 标签的 extxyz、reactions.yaml 和 MD 方案。
    • 输出：JSON 与表格，包括能量差、力、EOS、二聚体、能带指标、决定性符号，以及 NVE 漂移与最短键的监控（照 bench/adaptive_md 的做法）。
    • examples/07…/evaluate.py 保持不变。
  • 能量参考与数值约定：
    • 孤立原子用 DFT 不含自旋极化的 E₀（E0s_dft.json），与 DFTB 的中性无自旋原子一致；不用最小二乘拟合出的 E₀。
    • DFTB 的 k 网格与展宽对齐 DFT：KSPACING 0.15 的 Γ 心网格，Gaussian 0.05 eV。
    • 力用精确导数；新生成的 SK 表用加密的 hotcent 网格。
    • 溶液体系拟合 E_PBE − E_D3(BJ)，运行时加同一套 D3(BJ)，不借 3ob 的 D3 参数。
    • 两边都不加 SOC。
    • 一次拟合里不混用不同 DFT 程序（VASP、GPAW、CP2K）的能量。

三、第一阶段（A1）：单一参数集能走多远

共同条件

  • 参数：每个元素一对 (r0_w, r0_d)，hotcent PowerConfinement 取 p = 2、自洽约束；σ_rep 每个元素一个（physrep）。这与用户要求的“2 体、单一参数”一致。
  • 拟合的元素：Li、O 都拟合。M5c 只拟合了 Li，O 用的是发表值。
  • 基组作为因素：Li 取 s 或 sp；溶液体系取 S、I、Sn、Cs = d，Pb = p。
  • 用同一个网格消除优化器的差别：
    • Li 只有一个元素，取 2 维 12×12 网格；Li–O 取 4 维 Sobol，256–512 组 SK。
    • 每个网格点的 SK 表都缓存；所有策略的损失在同一批点上计算，直接得到损失地形和帕累托前沿。
    • 再从每个策略最好的网格点出发，用 BO（3 个种子）、bo_grad 或 Nelder–Mead 局部精修，检查网格分辨率不是限制。

策略

编号做法
S1能量 + 力，电子与排斥势同时拟合。新的平衡损失 L_EF 见下式，每一项在验收线上等于 1，两项都在线上时 L_EF = 2。能量用绝对原子化能（用户的默认），另做一组按元素偏移的对照（S1o）
S2EOS 损失，同时拟合：PTBP 的 energygeometry，即 μ_V 与组内 μ_E。另加对照 “S1 只用 EOS 数据”（S1eos），区分是损失的作用还是数据的作用
S3先拟合能带：只用能带损失定 r0，再冻结电子部分，用 L_EF 拟合 σ_rep
S4能量 + 力加能带正则：L_EF + λ·L_band，或在 L_band ≤ 1.1·min 的约束下最小化 L_EF
S5（可选诊断）两中心形式不变，把 SK 的 H、S 表直接作为样条参数拟合（autodiff 已支持对 SK 表求导）。用来判断限制在约束半径这种参数化，还是在两中心形式本身

L_EF = mean组 [ mean |ΔE原子化| / 10 meV/原子 + λF · mean RMS(ΔF) / 0.1 eV/Å ]，λF = 1

对照行（诊断用，不是策略）

  • R₂b：对每个电子部分，在同一个训练集上重拟合柔性的对样条排斥势（pydftb/repfit.py：单调、光滑，在二聚体处锚定）。
  • 样条 oracle：在训练集加测试集上拟合，给出“这个电子部分 + 任意 2 体排斥势”能达到的下限。
  • 为什么要这两行：physrep 每个元素只有一个 σ，而且非负单调，补不了少结合。不加对照，S3 的失败会被误判为“能带没用”。
  • 另一个方向：DFTB3 与 U 的一组（K4）。Li–O 的离子性可能由 U 与三阶项控制，不只是 r0。

能带损失（pydftb/bandloss.py）

  • 窗口：VBM−3 eV 到 CBM+1 eV；金属取 E_F−3 到 E_F+1，另有一个变体包括占据带的底。窗口边缘用 logistic 台阶（τ = 0.1 eV）。
  • 对齐：每个结构一个自由平移 Δ_s（闭式解），不硬对 VBM 或 E_F。
  • 配对：
    • 半芯态按电子数去掉（POTCAR 的 ZVAL 对 DFTB 的价电子，如 Li_sv 的 1s），不按能量截。
    • 价带按序号配对。
    • 窗口内每个 DFTB 导带态配同一 k 上最近的 DFT 态（单向），另加带隙误差项 β·|ΔE_gap|，空态权重 0.3–0.5。
    • 本征值排序后再比，不追踪能带的特征。
  • 第一级：特殊点，加上沿每条相邻线段 5% 与 10% 处的点。第二级：连接特殊点的整条线段（每段 20–40 点），逐段的平均距离。
  • 分子与团簇：用 HOMO−3/LUMO+1 的轨道能级，每个结构一个平移，这样碎片之间的相对位置（FA⁺ π* 对 I⁻ 5p）会被计入。第二级的对应物是轨道能级沿键拉伸或反应扫描的曲线，即构型空间里的“连线”。
  • 无序晶胞：用 SCF 的 IBZ k 点及其权重。
  • 只报告、不优化：DOVE 的 𝒜、占据带宽、带隙、Δ_s。
  • DFTB 一侧：本征值取自收敛的 SCC 电荷，网格与展宽与能量计算相同（bands.eigenstates）。
  • DSKO 的原式没有读到（第十三节）。两级定义按用户的描述：先是特殊点附近的点，再是特殊点之间的连线。

L_band = mean组 mean结构 [ √( Σ w (εDFTB − εDFT − Δs)² / Σ w ) + β · |ΔEgap| ]

顺序

  1. A1.1 Li：数据是现有 VASP 的 EOS、随机位移、Li₂、压缩 bcc，加上 D1 的能带；D2 回来之前用留一家族做测试。产出是 S1/S2/S3 在 (r0_w, r0_d) 平面上的损失地形图，以及能带误差与 R₂b 的 Spearman 相关。
  2. A1.2 Li–O：训练集是 train 68 + 短程 43，测试是 test 8 + 界面 3；D2/D3 批准后再加。另做 MD 检验：
    • 界面 300/600 K NVT 2–10 ps，监控最短的 Li–Li 与 Li_ox–Li_ox 距离和切换权重；
    • 体相 600 K。
  3. A1.3 溶液：先拟合 I、Pb、Sn（加 Cs），H、C、N、O、S 用发表的 PTBP，需要时再放开全部 9 种。数据是 D4，再加 D5。重点看 K5、选择性与质子转移的符号，以及 20 ps MD 中的拓扑（不能有假断键）。

关口 G1

都在家族外测试集上判，阈值事先定好：

  • 某个策略到 A 级且 MD 稳定：第一阶段对这个体系够用，转到下一个体系。
  • 样条 oracle 在 B 级以内，而 physrep 各行差得多：瓶颈在排斥势的形式，建议先做 A3 再做 A2（由用户决定）。
  • oracle 差于 C 级，或界面符号在整个网格上都错：单一参数集加 2 体排斥势做不了断键。若 K6 显示有空间就进入 A2，否则直接做环境相关的排斥势。
  • Spearman(能带误差, R₂b) < 0.3：能带只能当正则项，A2 按 R₂b 判断，而不按能带。

四、第二阶段（A2）：随环境变化的电子部分（排斥势冻结）

什么可以随原子变（通道）

通道做法现有代码与要补的
E1 离散类型M5a/M5b 的 CN 平滑切换，改为对能带拟合引擎要放开“各类型 on-site、U 必须相同”的限制（typeswitch.unequal_type_quantities）：on-site 与 U 按权重混合，补上它们对权重的导数项
E2 连续 r0DOVE 的思路，但带力：每个原子 r0i = f(Di)。SK 对块在 r0 网格的各“类型”之间按 C² B 样条权重插值，直接复用 M5a 的 wi,t·wj,u 混合与 A1 的 SK 网格缓存（同一元素各 r0 的 on-site、U 相同，满足现有约束）力的链式法则 ∂E/∂w · dw/dr0 · dr0/dD · dD/dR；新模块 pydftb/r0mix.py
E3 哈密顿量修正M8a 的做法：on-site 平移、按壳层的跃迁标度、U 平移，作为 Di 的函数现有的 adaptive.py；加能带目标（Sample.bands）和按元素的偏移。adaptive 现在拒绝与类型切换同用，E2 + E3 要另做引擎工作

描述符的阶梯

每一级用同一批能带数据检验，只有满足关口时才往上走。

级描述符
L1配位数，包括总的和按元素的（Li 的 O 配位、I 的 Pb/Sn 配位）
L22 体径向函数（每种邻居几个宽度）与 3 体角度函数（G4/G5、M8b 的 q），解析并带导数（pydftb/descriptors.py）
L3SOAP，作为可选依赖（dscribe 或 featomic），先做 PCA 降维
L4MACE 的不变节点特征（固体用 MP-0，分子用 OFF/OMOL；导数由 torch 的 autograd 给出），或线性 ACE

回归器与训练

  • 回归器依次试：RBF 特征上的线性模型（现有）、GPR（DOVE 的做法）、小型神经网络。
  • 正则：岭回归正则化到 A1 的参数，并保持光滑。
  • 导数：用冻结电荷下的 Hellmann–Feynman 本征值导数 c†(∂H/∂θ − ε∂S/∂θ)c，需要给 bands.eigenstates 加一个保留本征向量的选项。损失值本身用完整的 SCC 计算。
  • 描述符导数：只拟合能带时不需要描述符对位置的导数，所以 SOAP 和 MACE 特征可以先用。
  • 传递检验：每一级之后便宜地重拟合排斥势（physrep σ 与 R₂b），看能带变好是否带来能量和力变好。这正是“能带拟合能不能说明成键断键”的实验。
  • 上限：K6 的逐结构最优 r0 给出能带误差最多能降到多少，任何描述符模型都超不过它。

关口 G2

  • 留一环境的能带误差降 ≥ 30%，且 R₂b 降 ≥ 20%：保留这个电子模型。
  • 能带变好，但 R₂b 降 < 10%：环境相关性应放在排斥势里（A3）。
  • 升到下一级描述符需同时满足两条：训练集的能带误差比逐结构最优高 ≥ 20%，且训练与测试之差 < 30%。

五、排斥势这一维（A3）

编号做法
R1physrep，每个元素一个 σ（A1 的形式）
R2每个原子对一条样条，仍是 2 体（repfit.py，单调，在二聚体处锚定）
R3环境相关的排斥势：M8a 的排斥势标度通道，或按 M5a 的类型混合
R4电子与排斥势一起在能量 + 力上精调，保留能带正则（S4 的形式）

关口 G3：达到 A 级就结束；否则进入 A4。

六、第三阶段（A4）：Δ-ML（最后才做）

编号做法
Δ1在最好的 DFTB 之上，用小型 MACE 或 ACE 学总能量与力的残差（多体的“ML 排斥势”）
Δ2在哈密顿量上加修正，即 E3 用神经网络，保留电子结构的物理意义
Δ3A2 的环境相关电子部分，加 Δ1

对比对象是同一数据上同样大小的纯 MACE，画学习曲线（N = 25、50、100、全部），并看家族外测试。

关口 G4：在 N ≤ 100 或家族外测试上，Δ-ML 要比纯 MLIP 好 ≥ 30%。否则结论是：DFTB 基底对能量精度没有贡献，只在电子结构上有用。

七、先做的便宜检验（A1.0，全部在本机或远程、不花钱）

编号检验不通过时的含义
K1数值下限，三项：
  • k 网格与展宽对齐 DFT 前后的差：Li₁₆ 金属上，PTBP 默认的 kdensity 5 与 T = 0 对比 KSPACING 0.15 与 σ 0.05，要求 ≤ 2 meV/原子、≤ 0.01 eV/Å；
  • SK 网格噪声 ≤ 0.02 eV/Å；
  • 精确力对比差分力。
先修数值设置（G0）
K2Li 二维网格（s 与 sp）上 S1/S2/S3 的地形，以及能带误差与 R₂b 的 Spearman 相关（ptbp scan）能带与能量是否相关
K3在全部 Li–O 数据（含界面）上，对整个 Sobol 网格做样条 oracle（ptbp scan 的 oracle 行）差于 C 级：任何单一参数集加 2 体排斥势都不行，提前进入 A2/A3
K4界面塌缩的符号在 DFTB3 下、以及 U_O 乘 0.8/1.2 时的变化r0 以外的调节量有没有作用
K5溶液体系中，C、N、I 的任何 r0 能否把 FA⁺/I⁻ 的间隙打开到 DFT 的值不能：需要改 on-site/U（E1/E3）
K6逐结构最优 r0 对比全局一套的能带误差收益 < 15%：E2 帮不了能带，改用 E3
K7在同一 Li–O 数据上训练的 MACE达不到 A 级：限制在数据，先补数据，再改方法

执行顺序

  1. 准备数据：li_o/prepare_data.py 写出带标签的训练、测试与家族外集合。
  2. D1 GPAW 能带参考（本机或远程）：li_o/bands_gpaw.py，然后 collect_bands.py。溶液部分用 pvk_ink/orbitals_gpaw.py。
  3. K1：li_o/k1_numerics.py（数值下限）。不通过就先修设置。
  4. Li 的扫描（K2）：ptbp scan points、run --jobs N（或用 Slurm 阵列 --index/--stride）、losses、report，配置是 li_o/scan_li.yaml 与 scan_li_sp.yaml。
  5. Li–O 的扫描（K3）：scan_li_o.yaml、scan_li_o_sp.yaml，同样的四步，看 oracle 行。
  6. K4、K6、K7：k4_dftb3_u.py、k6_per_structure_r0.py、k7_mace.py；再对最好的模型做 ptbp scan export 与 md_check.py。
  7. 基线与关口：common/baselines.py（slurm/baselines.sh），然后 common/gates.py 判 G0、G1。
  8. G1 报告：A1 的完成报告，按关口决定下一步。
  9. A2 或 A3（按 G1）：a2/a2.py plan → prepare → fit --holdout all → transfer → summary，或 a3/a3_repulsive.py r3/r4；用 G2、G3 判定。
  10. A4 与 S5（需要时）：a4/delta_ml.py（G4）、li_o/s5_sk_tables.py。
  11. D2–D5：只在用户批准费用后提交；各脚本只写输入、作业脚本与费用估计。

命令可以写成 ptbp scan …，也可以写成 python parameterize.py scan …。完整的命令、环境与预期输出见 执行手册。

开发细节十二、日志

十二、日志

每个命令（ptbp scan 的每个阶段、examples/08_accuracy 的每个脚本）都用 utils/runlog.session 写一个目录：logs/<name>/<time>-<host>-<pid>/。ptbp scan 写在扫描的输出目录下，根目录也可以用 $PTBP_LOG_ROOT 改。目录里有：

  • run.log：标准输出与标准错误的全部内容（终端仍然显示），加上 Python 警告和未捕获错误的 traceback；
  • meta.json：
    • 命令行、工作目录、参数；
    • git 提交、分支、是否有未提交的改动；
    • 主机、CPU 数、Slurm 作业号与分区、线程变量；
    • Python 与各包的版本：numpy、scipy、ase、pydftb、hotcent、skopt、torch、mace、gpaw、tblite、dftd3、dscribe；
  • events.jsonl：每行一个 JSON 事件（带时间与耗时），可以用 tail -f 跟进度；
  • status.json：最后写入 ok 或 failed、总秒数、错误文本。

扫描的每个点还在 points/pNNNNN/ 里写下：

  • result.json：半径、SK 缓存的键、孤立原子能量、每个结构的重试次数与错误、能带比较、耗时；
  • electronic.npz：电子部分的能量与力；
  • losses.json：每个策略的 σ、损失与评测；
  • 出错时还有 error.txt。

SK 缓存的每一项有 meta.json（半径、设置、hotcent 版本、主机、秒数）。所以远程服务器上的每个结果都能对到代码版本和输入。
