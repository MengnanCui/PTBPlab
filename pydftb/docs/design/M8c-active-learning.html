关键信息

M8a 的自适应模型在 Cu13 的 MD 里走到了训练集之外。主动学习要回答两个问题：模型什么时候在外推？下一批 DFT 该算哪些结构？做法是一个委员会：同一个模型拟合几次，每次用不同的重抽样数据和不同的锚点，成员之间的分歧就是不确定度。从 MD 轨迹里挑分歧最大、彼此不相似、也不像训练集的结构，写成 VASP 输入，接到 M8b 的训练集生成器上。

  • 委员会：fit_committee。先做一次基础拟合，再把 n 个成员各自拟合到一份 bootstrap 重抽样上。重抽样可以按单个结构，也可以按整组（groups=）。成员从基础拟合热启动。
  • 锚点（perturb=）：岭回归把每个成员拉向它自己的锚点 base + perturb · N(0, 1)，即 anchored ensemble（Pearce 等 2020）。没有锚点时，所有成员在数据约束不到的方向上都保持基础拟合的值，恰好在最该有分歧的地方完全一致。
  • 不确定度：committee_predict 给出每个成员的相对能量（减去该成员自己的偏移）和力。σE 是能量的标准差，σF 是力的分歧最大的那个原子的值；SCC 不收敛的帧标为失败，分数记为无穷大。
  • 挑结构：select 按分数从高到低取，有阈值；指纹（CN 与角度 q 的展宽直方图，按原子数归一）离已选的帧和训练集都至少 min_distance。write_candidates 写 VASP 输入，只写，不提交。

一、为什么这样设计

  • 委员会而不是解析的不确定度：模型对系数是非线性的（SCC），用线性化的协方差只在拟合点附近成立；而主动学习要找的恰好是远离数据的结构。委员会只需要多拟合几次，复用 M8a 的拟合和并行。
  • 热启动：成员从基础拟合出发，30–40 次评估就收敛，四个成员的代价约等于一次从零开始的拟合。
  • 相对能量：每个成员的偏移不同（能量零点是自由的），分歧要在各自减去偏移之后算，否则零点的差别会被当成不确定度。
  • 指纹：用模型自己的描述符（CN 与 q），所以“像不像训练集”与模型看到的环境一致；按原子数归一，不同大小的结构可以比较。
  • 接到生成器上：挑出的帧走 cu_dft_dataset.write_set，INCAR、k 点、核数、Slurm 数组与 M8b 训练集完全相同，collect.py 照用。

二、接口

from pydftb.active import fit_committee, committee_predict, fingerprints, select, write_candidates

com = fit_committee(models, samples, sk, options, n=4, perturb=0.02, base=fit)   # groups=… 可选
u = committee_predict(com, frames, sk, options)          # u.sigma_e, u.sigma_f, u.failed, u.score()
pick = select(u.score(), fingerprints(com.base, frames), n=10,
              reference=fingerprints(com.base, [s.atoms for s in samples]))
write_candidates("cu_dft_m8b_active", [frames[k] for k in pick], names, group="round1")

实验脚本：python -m pydftb.bench.active_cu adaptive_cu.json cu13_adaptive.extxyz --perturb 0.02 --write DIR。

三、实验设计

  • 校准：委员会在不含 diamond 的 5 个相上拟合，在全部 6 个相上预测。合格的标准是 diamond 的 σ 明显大于见过的相，并且 σ 与基础模型的真实误差相关（对数相关系数）。
  • 筛选：围绕 M8a 的自适应拟合建委员会，跑 M8a 那段 Cu13 轨迹（41 帧，每 10 fs 一帧）。期望团簇重构时 σ 上升，挑出的帧落在重构段。
  • 两种委员会对照：按相重抽样且锚定在基础拟合上；按结构重抽样且锚点扰动 0.02。
  • 单元测试：bootstrap 的计数（整组同进同出）；预测等于成员自己的能量减偏移；并行与串行逐位相同；离数据远的结构 σ 更大；成员相同时 σ = 0；SCC 失败的处理；指纹的平移与超胞不变性；select 的顺序、阈值与去重；VASP 输入；锚点让数据约束不到的系数分开。

四、风险与之后

  • σ 偏小：小委员会通常低估误差，需要用留出数据标定一个比例因子。
  • 扰动的大小：on-site 系数的单位是 Hartree，扰动 0.1 已经是 2.7 eV，SCC 会不收敛。所以成员失败时把扰动减半重试，最多三次。按通道设不同的尺度留到之后。
  • 之后：DFT 数据回来后的完整循环：拟合 → MD → 挑结构 → DFT → 再拟合；用 σ 做 MD 中的停止条件（不确定度超过阈值就停下并挑帧）。
