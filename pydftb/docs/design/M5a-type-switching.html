关键信息

M5 的第一块，只做引擎机制。pydftb 早已支持离散的类型标签（一个元素有 Cu、Cu2 两套参数，文件 Cu-Cu2.skf 等，即 DFTB+ 的 Type2FileNames），但每个原子的类型是固定的。M5a 让被切换元素的每个原子 A 带一组权重 wA,t ≥ 0（Σt wA,t = 1），它是原子配位数的光滑函数；H0、S 与排斥能按权重混合。能量、力、应力彼此一致，周期体系与 MD 都能用。动机见 WHY.md 第 4 节：固态电池中的 Li 在电解质、正极、界面需要不同的参数，DFTB+ 每个原子只能固定一种类型。PTBP 的拟合一侧（M5b）与电池算例留到以后。

  • 模型（第一节）：
    • 配位数 CNA = ΣB f(rAB)，计数函数 f 在 ron 内为 1、roff 外为 0，中间是 C² 的五次光滑台阶；默认 ron/roff = 1.1/1.3 倍共价半径之和；
    • 类型按 CN 从小到大排列，相邻两种之间有一个切换窗口（中心、宽度），窗口外权重恰为 0 或 1；
    • H0AB = Σt,u wA,twB,uHtuAB(R)，S 同理；排斥能混合能量（各原子对的样条节点不同），不混合系数；
    • 同一元素的各类型必须有相同的 on-site 能、U、占据数、基组和质量（逐位相等），否则拒绝；PTBP 做的类型本来就满足（hot_hamiltonian 用 PTBP 表中的值覆盖这些量）。
  • 力与应力：固定权重的通常各项（用混合后的 H0、S），加上权重随几何变化的一项 ΣA,t(∂E/∂wA,t)(∂wA,t/∂CNA)(∂CNA/∂R)。密度固定时（变分）∂E/∂w 只要把各类型对的 H、S 块与力的代码本来就有的系数（dH0 的密度、dS 的系数）缩并，再加排斥能。
  • 探针中的发现（第二节）：
    • hotcent 2.1 对同一元素的两个原子只算一个方向、只取第一个原子的波函数范围、写出带 on-site 行的文件；生成脚本绕过这三点；
    • 异标签文件（Cu-Cu2.skf）若带 on-site 行，DFTB+ 不报错，能量错 3.1e-2 Ha；pydftb 遇到时拒绝；
    • 固定类型标签时 pydftb 与 DFTB+ 25.1 一致（平板 5.6e-11 Ha，团簇 4.7e-11 Ha，SCC 轮数相同）；
    • SK 块的计算与同批算哪些原子对无关（逐位），所以混合路径在权重为 0/1 时可以与显式标签逐位相同。
  • 接口（第三节）：DFTB(sk, type_switching=[TypeSwitch("Cu", ("Cu2", "Cu"), centre=10.5, width=1.0)])，calculate 对被切换元素的原子只收元素名 "Cu"；结果加 type_weights；PyDFTB(type_switching=…)。模块名为 typeswitch.py（types.py 会遮住标准库，见第二节 P8）。
  • 2离散极限的 DFTB+ 参考算例（Cu 平板、Cu13 团簇）
  • 3.1e-2异标签文件多一行 on-site 时 DFTB+ 的能量误差（Ha），不报错
  • 0权重为 0/1 时混合路径与显式标签之差（逐位）

一、模型

配位数

  • CNA = ΣB≠A f(rAB)，对所有近邻（含周期像，包括 A 自己的像）求和；可以只数某些元素。
  • 计数函数：x = (r − ron)/(roff − ron)，f = 1 − S(x)，S(x) = 6x5 − 15x4 + 10x3（x 截到 [0, 1]）。于是 r ≤ ron 时 f = 1，r ≥ roff 时 f = 0，处处 C²；导数 f′(r) = −S′(x)/(roff − ron)，S′(x) = 30x²(1 − x)²。
  • 默认窗口：ron/roff = 1.1/1.3 × (RA + RB)，R 为 ASE 的共价半径（Cordero 等）。Cu–Cu 为 2.904/3.432 Å：fcc 的第一壳层 2.55 Å 计 1，第二壳层 3.61 Å 计 0，所以平板与团簇的 CN 是整数（P6）。也可以给 (ron, roff)（Bohr），或按近邻元素分别给（字典的键就是要数的元素）。
  • 为什么不用 D3 的计数函数 1/(1 + e−k₁(R₀/r − 1))：它在 r → ∞ 时趋于 1/(1 + e16) ≈ 1.1e-7 而不是 0，CN 依赖于截断和原子数，还要另乘一个截断函数。紧支撑的台阶没有这些问题；热振动下第一壳层不进入窗口时 CN 不变，切换只发生在真正改变配位的地方。

权重

  • 类型 t0, …, tm−1 按 CN 从小到大排列；窗口 k（中心 ck、宽度 dk）把 tk−1 换成 tk：sk = S((CN − ck + dk/2)/dk)。
  • w0 = 1 − s1，wk = sk − sk+1，wm−1 = sm−1。窗口不得重叠，于是 s1 ≥ s2 ≥ …，权重非负、和为 1；窗口外恰为 0 或 1（浮点数也恰好），导数为 0。
  • ∂w/∂CN 非零的 (A, t) 必有 0 < wA,t < 1：窗口内两种相邻类型的权重都在 (0, 1) 中，在窗口边上导数为 0。这一点使梯度只需要已经算出的类型对。
  • 窗口与计数窗口都是用户的超参数，不拟合。

混合

  • H0AB = Σt,u wA,twB,uHtuAB(R)，S 同理；Htu 用 t-u 与 u-t 两个文件，与固定标签时完全一样。原子与自己的周期像之间也是这样。没被切换的原子只有一种类型，权重为 1。
  • Erep = ½Σ有序对Σt,uwA,twB,uVtu(rAB)：各原子对样条的节点不同，所以混合能量。
  • 要求相等（逐位）：基组（lmax）、on-site 能、Hubbard U（含 hubbard 选项之后）、参考占据数、质量；按标签给的选项 Ud、W、ξ、DFTB+U、onsite 修正。否则 on-site 能和 U 也得混合：DFTB+ 的“等 U”规则使三阶的 Γ 在 |ΔU| 跨过 3.125e-6 时跳一倍（thirdorder.py），γ 的截断表按不同的 U 各建一份（coulomb.py、thirdorder.py），U 连续变化就是 O(n²) 的工作量。PTBP 做的类型满足这些要求：utils/hotpy.py 的 hot_hamiltonian 在 hotcent 原子计算之后用 PTBP 表中的值覆盖本征值、Hubbard 值与占据数，所以 PTBP 的类型之间只有 H/S 表与排斥能不同。
  • 色散、H5、卤素修正、溶剂按元素（由标签推出），与类型无关，不变。

力与应力

  • 固定权重：力的代码不变，只是 dH0、dS 换成混合后的导数 Σ w w dHtu。
  • 权重的导数：力的代码给出每个原子对元素 e 的 ∂E/∂H0e = ρe 与 ∂E/∂Se = ce（SCC 移位乘密度减能量加权密度，含自旋、自旋轨道与块势的项）。这对任何改变 H0、S 的参数都成立（变分），所以
    ∂E/∂wA,t = Σ以 A 为一端的元素 e Σu wB,u(ρeHtue + ceStue) + ½Σ以 A 为一端的有序对ΣuwB,uVtu(r)
    （A 在第一或第二个位置的有序对都算；Htu 用的是值，不是距离导数）。
  • dE/dR 再加 ΣA(Σt∂E/∂wA,t·∂wA,t/∂CNA)·∂CNA/∂R，∂CNA/∂rp = f′(rp)rp/|rp|。
  • 应力：均匀应变下 drp/dε = rp ⊗ rp/|rp|，所以维里加 ΣCN 对 p(dE/dCNA)·f′(rp)/rp·rp ⊗ rp，与其他对项的约定相同。
  • 只有窗口内的原子（∂w/∂CN ≠ 0）需要这一项；它们的类型对都已为 H0 算过（上节最后一条），只要在算力时留下这些原子对的未加权块。权重全为 0/1 时这一项恰为零，不加。

三、pydftb 的接口

from pydftb.typeswitch import TypeSwitch

sw = TypeSwitch("Cu", types=("Cu2", "Cu"),   # 按 CN 从小到大：低配位用 Cu2，块体用 Cu
                centre=10.5, width=1.0,      # 每个窗口的中心与宽度（CN）；三种类型时各给两个
                cutoff=None)                 # 计数窗口 (r_on, r_off) Bohr，或 {元素: (r_on, r_off)}
sk = ParamSet(skdir).skset(["Cu", "Cu2"])    # 所有类型都要在 SK 集中
calc = DFTB(sk, kpts=k, type_switching=[sw])          # 也收字典或单个 TypeSwitch
r = calc.calculate(["Cu"] * n, pos, cell, pbc)        # 被切换元素的原子只给元素名
r.type_weights        # {"Cu": (n,), "Cu2": (n,)}：每个原子在每种类型上的权重
sw.coordination_numbers(elements, pos, cell, pbc)     # 不跑 DFTB 也能看 CN，便于选窗口

atoms.calc = PyDFTB(skdir, kpts=(4, 4, 1), type_switching=[sw])   # 窗口与截断都用 Bohr
  • 标签：被切换元素的原子在 calculate 中必须给元素名；给类型标签（"Cu2"）时报错，因为类型由权重决定。引擎内部用切换的“参考类型”（元素名在类型中时就是它，否则是第一种类型）作为这些原子的标签，基组、on-site、U、按标签的选项都按它查；同一元素各类型的值必须相同（给多种类型时逐一比较）。
  • 可以组合：SCC 与非 SCC，k 点，应力，DFTB3、H–X 阻尼、H5，共线自旋、非共线自旋与自旋轨道（两分量），DFTB+U 与 onsite 修正，外场、点电荷、位点势，溶剂，色散，卤素修正，偶极修正，固定费米能级与独立 k 点填充，fd_delta，各求解器与 k 点线程，能带与电荷文件。它们对 H0、S 的依赖都已经在 dS 的系数里，权重的导数直接用这个系数。
  • 拒绝（ValueError）：torch 后端与 pydftb.autodiff（加入 numpy_only_options）；Casida 激发与激发态的力；XL-BOMD；类型之间 on-site、U、Ud、W、ξ、DFTB+U、占据数、基组或质量不同；类型不在 SK 集中；异标签文件带 on-site 行；窗口重叠或宽度 ≤ 0。
  • 结果：DFTBResult.type_weights，每种类型一个 (natom,) 数组（别的元素为 0）；不用切换时为 None。
开发细节四、实现
  • 新文件 typeswitch.py：
    • smoothstep；TypeSwitch（检查标签、窗口、截断；weights(cn) 给出 w 与 dw/dCN；coordination_numbers 给出 CN 与梯度所需的原子对 (i, j, r, f′/r)，近邻表用 neighbors.neighbor_list）；
    • setup(switches, species, pos, cell, pbc, derivatives) → 内部标签与 TypeMixing（权重矩阵 (natom, nlabel)、dw/dCN、CN、每个内部标签的候选类型）；没有被切换的原子时返回 None，走原来的路径；
    • mixed_repulsive：按有非零权重的标签排序遍历类型对，与 DFTB._repulsive_pairs 同序，权重为 0/1 时求和逐位相同；同时给出 dE/dw；
    • weight_gradient：把保留的未加权块与 ρe、ce 缩并得 dE/dw，乘 dw/dCN，经 CN 原子对得到梯度与维里；
    • 检查函数：类型之间不同的量、按标签的选项、带 on-site 行的异标签文件。
  • hamiltonian.py：新函数 build_mixed_pairs，build_pairs 不动。按内部标签分组（与 build_pairs 按标签分组同法），组内对每个类型对 (t, u) 只算 wA,twB,u ≠ 0 的原子对，块的计算是 build_pairs 中 blocks() 的原样复制（同样的运算顺序），乘权重后累加；导数同样。需要时返回窗口内原子所在原子对的未加权块及其元素下标。
    元素的排列与固定标签时不同（按内部标签而非类型标签分组），但每个原子对的块在原子对内部的顺序相同，原子对一级的数组按近邻表顺序：Γ 点折叠中同一 (行, 列) 的周期像次序不变，k 点折叠每个 (T, 行, 列) 唯一，力中 segment_sum 按原子对求和，所以结果逐位相同（P5 与第五节的检查）。
  • calculator.py（新分支都在旧代码之前，旧表达式不改）：
    • DFTB(type_switching=…)：解析、加入 numpy_only_options，_check_type_switching 检查 SK 集、相等性、选项、文件与拒绝的组合；torch 后端单独给出 M5a 的报错；
    • _setup：先由 typeswitch.setup 得到内部标签与权重，再用 build_mixed_pairs；混合排斥能像色散一样在 setup 中算一次；_Setup.switching（新字段，默认 None）；
    • _repulsive_energy、_repulsive_gradient：有切换时取 setup 中的结果；
    • _gradient：在 _add_pair_terms 之后加权重的梯度，维里同样；
    • _run：DFTBResult.type_weights（新字段，默认 None）；_charge_layout 映射标签；_check_xl 拒绝。
  • ase_calc.py：PyDFTB(type_switching=…)，SK 集加入所有类型，电荷的参考布居按内部标签取。
  • 验证工具：
    • validation/make_cu_types_set.py：生成 tests/data/skf/cu_types/（4 个文件，约 0.5 MB），在 cases.SKF_SETS 登记，PROVENANCE.md 加一节；
    • cases.py：Case.type_switching（TypeSwitch 的字段）放在数据类最后；标签由切换在构建时算出（并检查权重全为 0/1）；两个算例接在 CASES 末尾，torch=False；
    • refgen.py：run_pydftb(..., switching=True)（元素名、全部类型的 SK 集）；compare 对这类算例再用切换跑一次，与显式标签的结果逐位比较，偏差记为 switch（容差 0）。

  • 能量连续：一个原子的 CN 穿过窗口时能量的差分与解析力一致，窗口两端与显式标签逐位相同；
  • NVE MD（ASE VelocityVerlet）：原子穿过切换区时的能量漂移与不切换时相当；
  • 权重：和为 1、窗口外恰为 0/1、dw/dCN 与差分一致；CN 的导数与差分一致（含周期像与按元素计数）；
  • 拒绝项；PyDFTB；能带与电荷文件。

门槛

golden 两个环境对 5b90f55 逐位相同（--allow-new type_weights switching）；refgen --check、dynamics --check；三个环境的 pydftb 测试；PTBP 测试；engine_parity。

六、不做的事与风险

  • 不做：
    • PTBP 的拟合（M5b：类型的约束参数、窗口的选择）与电池算例（等数据）；
    • 类型之间 on-site 能、U 等不同（拒绝；要做就得混合它们并处理三阶的等 U 规则与 γ 表）；
    • torch 后端、自动求导、Casida、XL-BOMD 的切换版本；
    • CN 以外的描述符（接口留了位置：权重只依赖每个原子的一个标量）。
  • 风险：
    • 类型差别大时切换区的力很大（测试参数每原子差约 0.03–0.05 Ha）：只影响 MD 的步长，不影响一致性；
    • DFTB+ 用差分求 H0、S 的导数，个别几何上力差到 1e-7（P7 的平板）：按需要放宽容差并写明原因；
    • 默认路径：所有新代码都在 type_switching 不为 None 的分支里，golden 逐位比较。
