关键信息

DFTB+ 拒绝杂化泛函下的有限频率响应（“Finite frequency hybrid xc-functional calculation not currently supported”）。M6h-4c 给出全部三条路径的有限频率极化率与响应核：分子与 Γ 点、k 点（共线）、两分量（分子）。静态时一阶密度矩阵是对称的，有限频率时它还有反对称部分：库仑、自旋与块势只看对称部分，交换两部分都看。所以轨道对空间的未知量加倍，方程仍对称，仍用批量的 MINRES；接近激发时小体系改用稠密解。

  • 方程：P1 = Ps + Pa，[[I + DKsD, −ΩG], [−GΩ, G(I + DKxD)G]] [zs; y] = [D ∘ Mext; 0]。
    • Ωij = ω/(εi − εj)；G = 1/√(1 + Ω2) 让每个对的 2×2 块有界；za = G y。
    • Ks 是静态的全部响应势；Kx 只有 Pa 的交换。布居取自 Ps。
    • ω = 0 时两块解耦，回到 M6h-4。
  • 原型（P96、P97）：
    • 与 TD-LC Casida 对全部激发的求和一致到 ≤ 1.8e-13（相对），含第一激发以上的频率，含开壳层的 CH3。
    • 去掉交换后等于 M6g、M6g-3b 的有限频率响应，≤ 1e-12；含金属、+U、onsite、DFTB3、Γ 点与 k 点。
    • k 点的核等于超胞 Γ 点的核，≤ 1.1e-12；两分量的磁矩都沿 z 时等于共线的结果，≤ 6.9e-11。
  • 接近激发：方程在激发能处奇异。
    • C6H6 在 0.148–0.160 Ha 有 8 个激发。离一个激发 1e-5 Ha 时，MINRES 跑 1000 轮也只到相对误差 1e-4：Lanczos 向量失去正交性，450 个未知量却跑了 1000 轮。
    • 稠密直接解 0.1 s，误差就是条件数乘机器精度：1e-5 处 1e-11，1e-7 处 1e-9。
    • 所以 MINRES 在未知量个数的轮数内不收敛、而体系不大时，改用稠密解；其余情况在 1000 轮后警告，并给出达到的残差。
    • 实现后的计时：第一激发以下 MINRES 与静态一样快（约 25 轮）；在稠密的激发谱里（水团簇、干冰在 0.4 Ha）大体系 1000 轮只到相对残差 2e-3–5e-2，只能警告（第七节）。
  • 两分量的反厄米交换：基态的 Pauli 交换用 “右上块 = 左下块的伴随”，只对厄米矩阵成立。对 Pa 这样会使布居差 25–50 %，所以 Pa 用反号。
  • ω → 0 的两分量：
    • 没有 SOC 时，整体自旋转动在有限频率下变成本征值 ∝ ω2 的近零模（H3 120°：ω = 1e-5 时条件数 2.8e8）。
    • 不投影的 MINRES 仍给出 dq(0) + O(ω2)，但残差可能停在 1e-13–1e-12 的平台上，达不到容差；稠密解在这里反而差 1e-4。
    • 右端与转动正交到舍入（≤ 4e-15，与 SCC 的容差无关），精确解不含它们；是舍入把它们带进 Lanczos 过程。H3 在 ω = 1e-5 有 3 个本征值 2.1e-9 的近零模（约 21ω2），下一个是 2.3e-3。平台时有时无：SCC 容差 1e-6 到 1e-14 的基态里只有 1e-12 的那个出现平台（2–3e-13），其余 6–8 轮收敛。稠密解则把舍入放大 1/ω2 倍。
    • 所以有转动的两分量先跑 MINRES，接受不超过 1e-11、100 轮内没有减半的平台残差；MINRES 失败（残差更大，频率在激发附近）时再用稠密解，这时频率不小，稠密解准确（HCO 磁矩沿 z 时强制稠密解，ω 从 0.5 到 1e-3 与共线的结果相对差 ≤ 5.0e-12，与 MINRES 的相同）。
  • η：DFTB+ 与 M6g 的权重带 +iη（1e-8）。有交换时 η 让方程不再对称，pydftb 解 η → 0 的极限（离裸跃迁能 1e-8 以外，两者差 O(η2)）。显式给出别的 η 时拒绝。
  • ≤ 1.8e-13与 TD-LC 对全部激发的求和（相对）
  • ≤ 1.1e-12k 点与超胞 Γ 点（有限频率）
  • 1e-11离激发 1e-5 Ha 时稠密解的误差
  • 2×未知量（对称与反对称两部分）

一、范围与 DFTB+

  • DFTB+ 25.1：Polarisability、ResponseKernel 的 Frequencies 配 Hybrid 时停下（initprogram，开发版相同）。它的对称化写法 ½(dc c† + c dc†) 只给出 Ps，而交换使 A − B 不是对角的，需要 Pa（M6h-4 的坑 156）。
  • 不加杂化时（M6g、M6g-3b）：DFTB+ 的有限频率权重是 θ(fi − fa)[1/(Δ + ω + iη) + 1/(Δ − ω + iη)] 取实部，没有带内项，不移动费米能级。pydftb 照做，并且有交换时去掉交换要回到它。
  • M6h-4c 做：三条路径的有限频率极化率与响应核（含 RPA），频率的给法同 M6g（frequencies、frequency_range、static）。点电荷导数只有静态的（DFTB+ 也是）。

二、探针与原型

原型在草稿目录 m6h4c/：p96.py（实数路径）、p97.py（k 点与两分量）、dense.py（稠密解）。它们用 M6h-4、M6h-4b 实现里的类，只换掉方程。

三、pydftb 的算法

对称与反对称部分

  • 对 e−iωt 的扰动，一对 (i, j) 的一阶密度 δPij = Fij(Ms + Ma)ij/(Δij + ω)，F = fi − fj，Δ = εi − εj。拆成对称与反对称部分：[[1, Ω], [Ω, 1]] [Ps; Pa] = W [Ms; Ma]，W = F/Δ 是静态权重。
  • 含时密度 δρ(t) = Ps cos ωt − iPa sin ωt。Mulliken 布居对反对称（反厄米）矩阵为零，所以库仑、三阶、自旋常数与块势只作用在 Ps 上，交换两部分都作用。
  • P = −C(D ∘ z)C†，D = √(−W)（M6h-4 的 D），za = G y，就得到关键信息里的对称方程。它在 Re Tr(a†b) 的内积下对称（P96c）。ω = 0 时 Ω = 0，回到 M6h-4。
  • 对：同一简并组的对（含带内的对角元）在 ω ≠ 0 时 F = 0，去掉；窗口里的对保留 W 的 θ 分配。不移动费米能级（DFTB+）。
  • 输出：布居、在位布居取自 Ps；本征值导数取 C†(Hext + Ks[Ps])C 的对角元（Kx[Pa] 的对角元是零或纯虚数），简并组取子块的本征值；费米能级导数为零（同 M6g）。

三条路径

  • 实数路径：zs 实对称，y 实反对称；Pa 的交换就是基态的四项公式（对任意矩阵成立）。
  • k 点：zs 厄米，y 反厄米；Pa(k)/wk 照 Ps 叠起来交给 BvK 卷积。约化 k 点集成立，因为超胞里的 Pa 是实矩阵（P97b）。
  • 两分量：Pa 的 Pauli 交换右上块取左下块伴随的相反数（response_fock(..., antihermitian=True)）。有限频率不投影整体转动：转动在 ω ≠ 0 时不是零模，方程有唯一解；投影只在 ω → 0 时改善收敛，并且不精确（P97e）。

求解

  • MINRES，判据同静态（每个右端的残差 ≤ 1e-13 |b|），有限频率不报鞍点。
  • 小体系（未知量 ≤ 3000）、没有静态零模：在 min(未知量个数, 1000) 轮内不收敛时，建物理子空间上的稠密矩阵（基 (eij ± eji)/√2，复数时加 i 倍），右端分批算出矩阵，LU 求解。
  • 有两分量的转动，或者体系大：MINRES 最多 1000 轮；相对残差不超过 1e-11、并且 100 轮内没有减半时当作收敛（达到的精度，OMEGA_PLATEAU、PLATEAU_STEPS）。仍不收敛时，小体系用稠密解，大体系警告并给出达到的相对残差与稠密解需要的 DENSE_LIMIT，结果用最后一步。
  • 多个频率逐个求解；RPA 时没有核，每个对直接是 zs = b/(1 − Ω2)。

四、pydftb 的接口

DFTB(sk_lc, hybrid="lc", analysis={"polarisability": {"frequencies": [0.1, 0.2]}})
DFTB(sk_lc, hybrid="lc", kpts=supercell_folding((2, 2, 2)),
     analysis={"response_kernel": {"static": False, "frequency_range": (0.05, 0.3, 0.05)}})
  • 结果类同 M6g：每个频率一组极化率、布居、本征值导数；写出 DFTB+ 格式的 detailed.out 块与 dE_band.out、dV_band.out。
  • 拒绝：显式给出的 perturbation={"eta": …} 不等于 DFTB+ 的默认值 1e-8 时（pydftb 解 η → 0 的极限）；坐标导数仍拒绝（M6h-4d）。

五、实现 开发细节

位置内容
response_hybrid.py
  • 静态路径的算术不变（golden 含 M6h-4 的 37 个算例）。
  • _minres 加可选的算符、轮数上限与平台判据，不收敛时可返回而不报错；静态的调用不变。
  • 有限频率：每个块的 D（去掉同组的对）、Ω、G；堆叠未知量上的算符；三条路径共用，路径相关的只有 T、T†（实数或复数）与 Pa 的交换（k 点叠 k 点，两分量反号）。
  • 稠密回退：物理子空间的基与坐标、按批量右端建矩阵、LU。
  • polarisability、response_kernel 逐个频率求解，结果与 M6g 同形。
hybrid.pyresponse_fock(dps, antihermitian=False)：Pauli 分支的右上块带符号；其余的类接受这个参数（公式本来就对任意矩阵成立）。
calculator.py去掉 “Finite frequency hybrid” 的拒绝；有限频率配显式的非默认 η 时拒绝。
测试新文件 tests/test_hybrid_response_frequency.py（第六节）；test_hybrid.py、test_hybrid_response.py 的有限频率拒绝改成 η 的拒绝。

没有 DFTB+ 参考算例（DFTB+ 拒绝），不加 refgen 的算例。

六、验证 开发细节

  • 实数路径：
    • TD-LC 对全部激发的求和：H2O（含第一激发以上）、CH3 自旋（每个元素一个 W），界 1e-10（相对）。
    • 接近激发：C6H6 离激发 1e-5 Ha，稠密回退，界 1e-8。
    • 去掉交换等于 M6g：CuCO 金属、H2CO +U、干冰 Γ 点；RPA 等于 M6g 的裸 χ0(ω)。
    • ω → 0 连续：H2O 在 ω = 1e-4 与静态差 O(ω2)。
  • k 点：超胞 Γ 点（CO 盒子与三重态 O2），界 1e-11；去掉交换等于 M6g（金属），界 1e-11。
  • 两分量：去掉交换等于 M6g-3b；磁矩沿 z 等于共线的结果；Pa 的 Pauli 交换反厄米；H3 在 ω = 1e-5 接受平台、不警告，并且 α(ω) − α(0) 按 ω2 变化；强制的稠密解等于共线的结果。
  • 求解器：轮数上限调小时小体系转稠密解、结果不变；稠密上限为 0 时警告；平台判据用合成的算符检验（零空间上 1e-12 的不相容右端：接受平台，不让残差递推继续漂移）。
  • 拒绝：非默认 η；坐标导数。
  • 门槛：golden 两个环境逐位相同、refgen（NumPy、torch）、dynamics、pytest 三个环境、PTBP 测试与 G1。

七、不做的事、风险与之后

  • 不做：η 的展宽（吸收谱）；两分量磁体的异相（旋光）响应，同 M6g-3b 与 DFTB+ 只给同相部分。
  • 风险：
    • 大体系在激发附近或稠密的激发谱里只能警告（稠密回退限于 3000 个未知量，可以调大 DENSE_LIMIT）。
    • 两分量在 ω → 0 时受整体转动的近零模影响：接受平台残差；残差更大时才用稠密解。
    • 每个频率单独求解，每轮两次批量的交换构建（Ps 与 Pa）。
  • M6h-4d：坐标导数（分子）。
