关键信息

DFTB+ 25.1 在杂化泛函下只做静态的 Polarisability 与 ResponseKernel，而且只在实数路径上（分子与 Γ 点）；开发版还有 ExternalChargeDerivatives。一阶密度矩阵 P1 的交换 Hx[P1] 进入一阶哈密顿量，DFTB+ 混合稠密的 dRho 迭代响应的 SCC。pydftb 把静态响应写成对称的线性方程，在占据–空轨道对的空间里用批量的 MINRES（最小残差法）同时解所有方向或所有原子，每轮只做一次批量的交换构建。

  • 与 DFTB+ 对照：原型在 42 个运行（40 个杂化）上与 DFTB+ 的全部输出相比，分子差 ≤ 1.4e-10，Γ 点 ≤ 2e-9。比较的量有极化率、dq/dE、dε/dE、核 dq/dV、在位布居、dε/dV、NF、dEF/dE，以及 detailed.out 的表。最大的是 Γ 点金属 Cu4 的核（1.8e-9，在位布居 5.8e-9），DFTB+ 自己迭代了 55 轮。MINRES 用 2–53 轮（最多的是不定的 Γ 点 Cu4，其余 ≤ 27）。
  • 独立检查：
    • 与 pydftb 自己的有限场、有限差分相比：极化率 ≤ 8.5e-7，即中心差分的截断误差；Γ 点 onsite 的核 2.4e-8。
    • 与 TD-LC Casida 对全部单重激发求和得到的静态极化率相比：H2O 9e-15，C6H6（225 个态）5.4e-13。两者的交换核相同，这一项检查不依赖 DFTB+。
  • DFTB+ 的新问题：
    • B24：k 点杂化的 ResponseKernel 段错误。
    • B25：非共线杂化的 Polarisability 段错误。
    • B26：杂化时响应的 SCC 从不更新块布居，+U 与 onsite 的块势不响应，开发版也是这样。H2CO +U 的 α 因此差 1.1 a.u.。
    • B27：25.1 的响应 SCC 把点电荷的静电势加进每一个一阶势，有没有杂化都一样，开发版已修。CH3OH 的 α 因此差 0.7–0.8 a.u.，响应核差 0.23。
    pydftb 默认给正确的物理，另有两个只供验证的开关复现 DFTB+ 的做法，与 DFTB+ 一致到 2e-9 以内。
  • 不稳定的基态：交换是负的，可能让响应方程不定。Γ 点的 Cu4（LC，1000 K）有五个约 −1.7 的本征值，CuCO 自旋（300 K）有三个，最低的 −0.49。这时 SCC 的解是鞍点，不是极小，但响应仍有定义，DFTB+ 的混合也照样收敛到它。所以 pydftb 不用共轭梯度（它要求正定），改用 MINRES，并在遇到负曲率时警告。
  • Thresholded 筛选：DFTB+ 的响应接着基态的增量历史累加，结果是精确响应加上筛选误差，H2O 的 α 偏 3.9e-6。pydftb 给精确的响应。
  • 范围：M6h-4 做 DFTB+ 能做的这些，加上开发版的点电荷导数。k 点、非共线、有限频率、坐标导数是 DFTB+ 拒绝或崩溃的，放到 M6h-4b，用差分与 Casida 验证（SOC 配杂化的基态 DFTB+ 就拒绝）。
  • ≤ 1.4e-10分子的响应与 DFTB+ 之差（不含 DFTB+ 的错误；Γ 点 ≤ 5.8e-9）
  • 9e-15CPKS 与 TD-LC Casida 求和的静态极化率（H2O）
  • 2–53批量 MINRES 的轮数（每轮一次交换构建）
  • B24–B27DFTB+ 的新问题

一、DFTB+ 的做法

源码 25.1：derivs/perturb.F90（response、wrtEField、wrtVAtom），derivs/linearresponse.F90（dRhoReal、dRhoFermiChangeReal），dftbplus/initprogram.F90，dftb/scc.F90（getShiftPerAtom），dftb/hybridxc.F90（addCamHamiltonian_real、addCamHamiltonianThreshold_cluster）。开发版 041e723 的 dxExtCharges 走同一个 response。记录在草稿目录 m6h4/notes.md。

一阶哈密顿量

  • 每轮的一阶哈密顿量 dH 由两部分组成，都以 ½Sμν(VA + VB) 的形式进入：
    • 外部扰动：电场方向的坐标、单位原子势，或点电荷的位置导数。
    • SCC 的一阶势：γ 加上三阶的 Hessian、自旋常数 W，以及 +U、onsite 的块势。
  • 实数路径（dRhoReal，分子与 Γ 点）在 dH 上加 hybridXc%addCamHamiltonian_real(dRhoSqr)，即输入的一阶密度矩阵的交换。屏蔽方式与基态相同：MatrixBased、NeighbourBased 或 Thresholded。之后照常做 M = CT dH C、简并组的旋转；本征值导数取 diag(M)，所以含交换。
  • 复数路径（dRhoCmplx，k 点）与两分量（dRhoPauli）都没有交换项，而且一运行就崩溃（B24、B25）。

响应的 SCC

  • 混合：杂化时混合稠密的 dRho（n2·nspin），用基态的 chrgMixerReal。误差是 max|dRhoout − dRhoin|。第一轮直接取 dRhoin = dRhoout，dqin 由 denseMullikenReal 求。
  • 金属：每个自旋通道 dEF = −Σdq / NF，dq 是裸响应的 Mulliken 布居。dRhoFermiChangeReal 把费米能级的移动加到稠密的 dRho 上。
  • 块布居（B26）：dqBlockIn 只在非杂化的分支里更新，杂化时一直是零，所以 +U 与 onsite 的块势不响应。开发版同样。
  • 点电荷（B27）：从第二轮起，sccCalc%getShiftPerAtom 的结果含有点电荷的静电势（extCharges%addShiftPerAtom）。收敛后，等于把这个静电势加到外部扰动上。25.1 中所有有 SCC 的响应都这样，与杂化无关；开发版改成 getShiftPerAtom(…, isOnlyInternalShifts=.true.)。
  • RPA 的核：没有 SCC（0 轮），即裸的 χ0，与交换无关。
  • Thresholded：addCamHamiltonianThreshold_cluster 接着基态最后的 ΔPprev、Hprev 累加。第一轮 ΔΔP = dRho − ΔP基态，Hprev 之后跟着 dRho 的增量变化。结果是精确的响应加上筛选误差，轮数也多：H2O 三个方向 22、17、25 轮，MatrixBased 是 12 轮。

拒绝与限制

  • 有限频率：初始化时停下，“Finite frequency hybrid xc-functional calculation not currently supported.”
  • 坐标导数：“Coordinate derivative perturbations do not yet work with hybrid functionals”。
  • 周期体系的极化率：只给电荷响应，并警告 “Electric field polarisability not currently available for this boundary condition”（同 M6g）。
  • 其余条件同 M6g：只用 Fermi 填充、只有完整的三阶、不加溶剂与色散。

二、探针与原型

三、pydftb 的算法

M6g 把响应写成壳层与块布居的小方程，直接求解。这在杂化下不行：交换依赖整个 P1，无法缩到布居的空间。DFTB+ 的混合迭代要 12–56 轮，而且带着 PerturbSccTol 的误差。pydftb 改在轨道对的空间里写出一个对称正定的方程。

χ0 与对称化

  • 记号：块 b 是 Γ 点的一个自旋通道，Cb 是实本征向量，Wb 是 M6g 的静态对权重矩阵（static_weights：带内 −δi，窗口内的简并对 −(δi + δj)/2，DFTB+ 的窗口与 θ 权重）。Wb 处处 ≤ 0，f 是满填充数，wb 是权重。
  • χ0：Xb = f wb Wb ∘ (CbT H Cb)，P1 = Σb Cb Xb CbT（同一自旋的块相加）。
  • 金属：窗口的对角元另加 f wb δi dEF，dEF = Σ w δ Mii / Σ w δ。每个自旋通道各自保持电子数；RelaxTotalSpin 时两通道共用一个费米能级（同 M6g）。
  • 令 Db = √(−f wb Wb)，T z = Σb Cb (Db ∘ zb) CbT，TT H = Db ∘ (CbT H Cb)。在每个费米组（一个通道，或共用费米能级的两个通道）里，TT 把窗口的对角元投影到与 u ∝ √(w δ) 正交的方向。这个投影就是费米能级的移动：(I − uuT) 夹在 √(wδ) 之间，正好是 diag(wδ) − (wδ)(wδ)T/Σwδ。于是 χ0 = −T TT。

方程与求解

  • P1 = −T z，H1 = Hext + K[P1]，z = TT H1，所以 (I + TT K T) z = TT Hext。
  • K 由四部分组成：
    • γ（加三阶的 Hessian）作用在壳层布居上，以 ½S(VA + VB) 进入；
    • 自旋 W；
    • 块势：对偶块布居 ½(P1S + SP1)AA 经 M6g-3a 的块核，以 ½(SV + VS) 进入；
    • 交换 Hx[P1]：四项公式，MatrixBased 用 S，NeighbourBased 与 Thresholded 用 CAM 截断以内的 S。
  • K 的每一项都是能量的二阶导数，所以对称。基态是 SCC 的极小时，I + TTKT 正定。但交换是负的，热的金属或开壳层的 d 体系可能不定：SCC 的解是鞍点，响应照样有定义（DFTB+ 的混合也收敛到它）。所以用 MINRES：它适用于对称的方程，不要求正定。写法是 Paige 与 Saunders 的：Lanczos 过程每轮乘一次 A，三对角矩阵用 Givens 旋转做 QR 分解，只记前两个方向（与 SciPy 的 minres 相同，不加预条件）；每个右端有自己的一组标量。遇到负曲率（单位 Lanczos 向量的 Rayleigh 商 vTAv < −1e-8）时警告“基态是鞍点”。
  • 批量：所有右端一起解，即极化率的 3 个方向、核的 natom 个原子、点电荷导数的 3nj 个坐标。每轮只做一次批量的交换构建（矩阵乘法按批广播）。右端按内存分块，每块 r·n2 ≤ 2·106。
  • 收敛判据：每个右端的相对残差 ≤ 1e-13，最多 1000 轮，否则报错。全部探针用 2–53 轮，不定的 Γ 点 Cu4 最多，其余 ≤ 27；RPA 的核不迭代。
  • RPA 的核：P1 = −T TT Hext，与 M6g 的裸 χ0 相同到 2e-14。

输出（与 M6g 的结果类相同）

  • 布居：P1 的 Mulliken 布居（电荷 = 上 + 下，磁化 = 上 − 下），在位布居 diag(P1)。
  • 本征值导数：diag(CT H1 C)，含交换；简并组取该块的本征值。
  • 费米能级导数：Σ w δ Mii / Σ w δ。
  • 分子的极化率：−ΣA RA,j dNA/dEi。
  • 交换算符：用无状态的精确构建。Thresholded 不碰基态的筛选历史，结果与计算的顺序无关。

四、pydftb 的接口

  • 支持：
    • 体系：分子与 Γ 点；LC、CAM、全局杂化。
    • 屏蔽：三种都支持，Thresholded 给精确的响应。
    • 组合：共线自旋（含 RelaxTotalSpin）、金属、DFTB3，外场、点电荷与格点势。
    • +U 与 onsite：块势参与响应，这是正确的物理，与 DFTB+ 不同（B26）。
    • RPA 的核；点电荷导数。
  • 拒绝：
    • 有限频率：用 DFTB+ 的原话。
    • 坐标导数：用 DFTB+ 的原话，注明 M6h-4b。
    • k 点（M6h-4b）：DFTB+ 25.1 在这里段错误（B24）。
    • 非共线（M6h-4b）：DFTB+ 25.1 段错误（B25）。
  • 选项：perturbation 不变，degeneracy_tol 与 filling_tol 照旧。
  • 只供验证的类属性：DFTB._response_blocks_compat 复现 B26（块势不响应），DFTB._response_pc_compat 复现 B27（点电荷的静电势加进每个扰动；非杂化的路径也有，默认关闭，旧路径逐位不变）。

五、实现 开发细节

改动的文件
  • response_hybrid.py（新）：
    • HybridResponse：基态（M6g 的 GroundState）、Db、费米组、T 与 TT、批量的核（SCC、自旋、块、交换）、批量 MINRES、输出。
    • polarisability、response_kernel、external_charge_derivatives，返回 M6g 的结果类。
  • hybrid.py：HybridTerms.response_fock(dps)，无状态的精确交换，可批量；Thresholded 用 CAM 截断以内的 S，不动筛选的状态。
  • response.py：
    • 三个分析入口在 st.hybrid 不为空时转到 response_hybrid，像两分量时转到 response_pauli 一样。
    • 非杂化路径加 B27 的开关：只在打开时把点电荷的势加到 vext 上，RPA 不加。
  • calculator.py：
    • _check_hybrid：去掉 M6h-4 的拒绝；加有限频率（原话）与非共线（M6h-4b）的拒绝。
    • _check_periodic_hybrid：k 点加响应时拒绝（M6h-4b）。
    • 两个只供验证的类属性。
  • validation：
    • cases.py：新算例；分析里的 blocks_compat 与 pc_compat。
    • refgen：把 M6g-3b 处理 skew_compat 的方式推广到这两个开关。先比 pydftb 自己的结果与 DFTB+ 自己的有限场（pol_fd）以及 DFTB+ 的解析值（pol_dftbp，即 DFTB+ 的误差），再打开开关比全部输出。

六、验证 开发细节

  • DFTB+ 参考（约 25 个，25.1 与开发版）：

    • 不加杂化：CH3OH 外场加点电荷的极化率与核（B27）。
    • 开发版：两个点电荷导数、一个点电荷下的极化率（不开开关）。
  • 自洽检查（test_hybrid_response.py）：
    • 求解：I + TTKT 对称；MINRES 等于小体系的稠密直接解，不定的也一样；分块的右端等于一起解的；不定时警告。

    • 差分：有限场与格点势的差分，覆盖 LC、CAM、自旋、金属、+U、onsite、点电荷、Γ 点。
    • 独立对照：TD-LC Casida 的求和。
    • Thresholded：不改变筛选的状态，重复计算结果相同。
    • 开关、拒绝的原话、detailed.out 的表与 dE_band.out。
  • 门槛：
    • golden 两个环境，基于 M6h-3c 的文档提交 ba68f99；
    • refgen（NumPy、torch）、dynamics；
    • pytest 三个环境、PTBP 测试、G1。

七、DFTB+ 的问题与 pydftb 的做法

DFTB+证据pydftb 的做法
B24（新）：k 点杂化的 ResponseKernel 段错误；复数路径本来就没有交换项P90：金刚石 2×2×2 LC，返回码 −11，停在 “Derivative with respect to potential at atom 1”拒绝到 M6h-4b
B25（新）：非共线杂化的 Polarisability 段错误；dRhoPauli 也没有交换项P90：HCO LC，返回码 −11，停在 “Polarisabilty for field along x”拒绝到 M6h-4b
B26（新）：杂化时响应的 SCC 不更新 dqBlockIn，+U 与 onsite 的块势不响应（25.1 与开发版）P90–P93：关掉块的响应后，与 DFTB+ 一致（分子 ≤ 6.1e-12，Γ 点 ≤ 6.2e-10）；不关时，H2CO +U 的 α 差 1.1 a.u.。pydftb 带块响应的结果与它自己的有限场差 8.5e-7给正确的物理；_response_blocks_compat 复现 DFTB+
B27（新，25.1）：响应 SCC 的一阶势含点电荷的静电势，有没有杂化都一样，开发版已修P91、P93：CH3OH 外场加点电荷 α 差 0.72–0.83，核差 0.23；把 vpc 加进扰动后差 ≤ 2e-13；开发版不加就对上给正确的物理；_response_pc_compat 复现 25.1
Thresholded 的响应接着基态的筛选历史（不是错误）P90：α 偏 3.9e-6，轮数 22/17/25 对 12给精确响应；参考的容差放宽，文档写明
TD-LC 的核用未屏蔽的长程 γ，NeighbourBased 缩减时与基态的算符不同（不是错误）Casida 求和：C6H6 缩减 10 时与 CPKS 差 4.3e-3，MatrixBased 5.4e-13照 DFTB+（M6h-2）；CPKS 用基态的算符
（排除）CuCO 的 α 的 x、y 行为零P91：直线分子的 Mulliken 偶极没有横向分量，pydftb 的有限场同样为零不是错误

八、不做的事与风险

  • M6h-4b，都由差分或 Casida 验证：
    • k 点：复数的 P1(k)，交换要全网格的 P1(q)；
    • 非共线：两分量的 P1（SOC 配杂化的基态 DFTB+ 就拒绝）；
    • 有限频率：交换使 A − B 不是对角的，P1 的反对称部分（X − Y）也要跟踪，DFTB+ 的对称化写法在杂化下不对；
    • 坐标导数：交换在固定密度下对坐标的导数。
  • 基态是鞍点时只警告：响应是这个驻点的响应（与 DFTB+ 相同），对称性破缺后更低的解另有自己的响应。
  • 核要解 natom 个右端，每个右端每轮一次交换构建：240 个轨道、120 个原子，原型约 40 s（实现 23 s），大体系很慢。
  • 两个开关只为与 DFTB+ 对照，不是推荐的设置。
