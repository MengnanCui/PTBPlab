关键信息

M6 补齐 DFTB+ 的第二批功能，顺序按用户的要求：自旋轨道耦合（SOC）、DFTB+U、外电场等、激发态。M6a 是第一步：让 pydftb 能做“两分量”计算，也就是每个轨道带上自旋向上、向下两个分量，自旋方向不再限定在一个轴上（非共线自旋），并可以加上自旋轨道耦合。只做 NumPy 引擎；torch 后端、自动求导和 SP2 求解器遇到这些选项时明确报错。

  • 做什么：
    • 非共线自旋：每个原子的磁矩是一个三维向量（DFTB+ SpinPolarisation = NonColinear）。
    • 自旋轨道耦合：HSO = ξ L·S，ξ 每个壳层一个（DFTB+ SpinOrbit）。两种模型都做：
      • onsite 模型：只加在同一原子的轨道块上；
      • dual 模型：DFTB+ 的默认，通过重叠矩阵也作用到相邻原子之间，因此有力的贡献。
    • SOC 可以不加自旋极化，也可以与非共线自旋一起用；可以与 DFTB3、壳层分辨 SCC、色散、k 点、力和应力、能带与 DOS 一起用。这些组合 DFTB+ 25.1 都支持（已试）。
  • DFTB+ 的实测行为（第二节）：
    • 没有 SOC 时，磁矩方向任意转动，能量和力都不变（O₂、OH、GdO 已试）。
    • SOC 让磁矩倾向某个方向，dual 与 onsite 的 ELS 不同（OH：−5.12 与 −5.24 mHa）。
    • SOC 不加自旋时磁矩为零，但 k 点必须是完整网格：用时间反演约化的网格，能量、力、应力碰巧不变，磁矩却算错。
  • DFTB+ 也有算不了的情况：周期体系里磁矩不沿坐标轴时（CuO 链，各种温度和混合参数），DFTB+ 的 SCC 发散。原因是磁矩整体转动不改变能量，Broyden 混合在这个方向上不稳定。pydftb 用同样的混合器，预计同样发散。这些组合不做 DFTB+ 对照，改用 pydftb 自身的一致性检查（旋转不变性、力与能量差分一致）。
  • 用法：DFTB(sk, spin="noncolinear", initial_spins=[[0, 0, 1], ...], spin_constants=W, spin_orbit={"Cu": [0, 0, 0.0037]})。ξ 的单位是 Hartree；spin_orbit_dual=False 切换到 onsite 模型。
  • 验证：16 个新的 DFTB+ 参考算例（分子、周期体系、f 轨道、能带），比较能量各项、力、应力、电荷、磁矩向量、轨道角动量和 SCC 轮数。旧算例逐位不变。
  • 2N旋量哈密顿量的维数（N 为轨道数）
  • 2SOC 模型：onsite、dual（默认）
  • 16新的 DFTB+ 参考算例

一、DFTB+ 的做法

旋量表示

两分量计算中，每个轨道 μ 有自旋向上、向下两个分量。DFTB+ 把所有轨道的“向上”排在前，“向下”排在后，哈密顿量和重叠矩阵都是 2N × 2N 的复矩阵，重叠矩阵为 S ⊗ 1。所有量都用四个“Pauli 分量”存储：电荷 q 和磁化 (mx, my, mz)。

  • 哈密顿量：H = Hq ⊗ 1 + Hx σx + Hy σy + Hz σz + HSO（sparse2dense.F90:unpackHPauli）。
    • Hq = H0 + ½ S (Vμ + Vν)，与共线计算相同；
    • Ha = ½ S (vaμ + vaν)，va = W ma（每个壳层），三个方向用同一个自旋常数矩阵 W。
  • 密度的四个分量：由旋量密度矩阵 ρ 的四个 N × N 块得到（packHSPauli）：
    • n = ρ↑↑ + ρ↓↓，mz = ρ↑↑ − ρ↓↓；
    • mx = ρ↑↓ + ρ↓↑，my = i(ρ↑↓ − ρ↓↑)。
    Mulliken 布居对每个分量分别计算。共线计算只是 mx = my = 0 的特例。
  • 占据：只有一个费米能级，2N 个能级每个最多 1 个电子（getFillingsAndBandEnergies，nSpin = 4）。
  • 能量：E = EH0 + ESCC + E3rd + Espin + ELS + Erep + Edisp：
    • EH0 = Tr(n H0)；ESCC、E3rd 只看总电荷；
    • Espin = ½ Σa ma · W · ma；
    • ELS = Tr(ρ HSO)，对密度是线性的。
    DFTB+ 的 detailed.out 分别列出 “Energy SPIN” 和 “Energy L.S”。

自旋轨道耦合

  • 每个壳层 l > 0 有一个常数 ξ；s 壳层的 ξ 必须为零，否则 DFTB+ 报错（initprogram.F90:3866）。DFTB+ 不提供 ξ 的默认值。
  • 角动量算符 Lx、Ly、Lz 先在复球谐函数基里写出，再变换到 DFTB+ 的实轨道顺序，例如 p 轨道为 y、z、x（angmomentum.F90:getLOperators）。在实轨道基里 La = i Λ'a，Λ'a 是实反对称矩阵。下文记 Λa = ½ ξ Λ'a，即 ½ ξ La 的虚部，每个原子一个块。
  • onsite 模型（Dual = No）：HSO = i Σa Λa ⊗ σa，只加在同一原子的块上（spinorbit.F90:addOnsiteSpinOrbitHam）。与几何无关，没有力的贡献。
  • dual 模型（Dual = Yes，默认）：把 Λa 当作“虚部块势”，按 DFTB+U 的规则乘上重叠矩阵，HSO = i Σa ½ (S Λa + Λa S) ⊗ σa（getDualSpinOrbitShift、shift.F90:addShift_block）。
    • S 的对角块是单位阵，所以 onsite 部分与 onsite 模型相同；
    • 多出的是相邻原子之间的项，它依赖 S，因此有力和应力的贡献；
    • DFTB+ 的 ELS 由块布居 Q = ½(ρS + Sρ) 的虚部（反对称）算出，等于 Tr(ρ HSO)。
  • 轨道角动量：DFTB+ 在 detailed.out 中按壳层列出自旋、轨道和总角动量（以 μB/ħ 计，即磁矩，所以有负号）。onsite 模型用同一原子的密度块，dual 模型用块布居的虚部。

SCC 的规则

  • 混合向量：每个壳层的 (q, mx, my, mz)，按分量排成 4 段（Spin_getOrbitalEquiv 与 OrbitalEquiv_merge）。原子分辨 SCC 时电荷部分也是按壳层的，这与 pydftb 现有的共线自旋（每个壳层的 ↑、↓）一致。
  • 初始值：电荷为参考布居（按电子数缩放）；每个原子的初始磁矩向量 s 按壳层电荷分配，m壳层 = q壳层 · s / q原子（initializeCharges）。没有给初始磁矩时为零。
  • 第一轮不混合：第一轮的输出直接作为第二轮的输入，与共线自旋相同（getNextInputCharges）。
  • 至少两轮：两分量计算的 SCC 至少迭代两轮才判断收敛（getMinSccIters）。读入初始电荷时除外。
  • 收敛判据：混合向量（四个分量）的最大变化小于 SCCTolerance。

k 点

  • 有 SOC 时 H(−k) ≠ H(k)*，不能用时间反演把 k 和 −k 合并。DFTB+ 的 SupercellFolding 在 SOC 时自动用完整网格；直接给的 KPointsAndWeights 原样使用。
  • 没有 SOC 的非共线自旋，DFTB+ 仍然约化。这只在所有磁矩共面时严格成立；不共面时约化是近似。

二、DFTB+ 25.1 的实测行为

用 pydftb 的参考数据集（PTBP 的 H/C/O/Cu、hotcent 的 Gd/O）、ParserVersion = 14、单线程，试了下面这些组合。ξ 取较大的值（Cu d 0.01 Ha，C p 0.004，O p 0.006–0.01，Gd p/d 0.005、f 0.01），以便各项都明显不为零。

体系设置结果
O₂ 三重态非共线，初始磁矩沿 z，或沿 (1, 2, 2)/3能量与共线计算相同（−6.4203608577 Ha），力相同，2 轮；Espin = −0.028
O₂非共线 + SOC，T = 0dual：ELS = −0.920 mHa，14 轮；onsite：−1.021 mHa，15 轮；磁矩转向分子轴
O₂磁矩倾斜 + SOC，T = 0不收敛（500 轮，在两个态之间来回）；300 K 时 94 轮收敛
OH 自由基，300 K非共线，沿 z 或倾斜能量相同，11 和 10 轮
OH非共线 + SOC，沿 z 或倾斜开始收敛到同一个态（17 和 20 轮）；dual 与 onsite 的 ELS 为 −5.12 与 −5.24 mHa
OH，DFTB3非共线 + SOC20 轮；三阶项照常
Cu₄CO，300 K只有 SOC（无自旋极化）：dual、onsite；壳层分辨 SCC；壳层分辨 + DFTB3；非 SCC都收敛；磁矩 < 2e-13
GdO（f 轨道），壳层分辨非共线，沿 z 或倾斜能量相同，30 轮
GdO非共线 + f 壳层 SOC倾斜开始 166 轮收敛；沿 z 开始发散（费米能级搜索失败）
GdO只有 SOC32 轮
CuO 链，k 点 4×2×2只有 SOC，完整网格与约化网格能量、力、应力完全相同（17、18 轮）；约化网格的磁矩不为零（错误），完整网格为零
CuO 链非共线沿 z（无 SOC）与共线相同，26 轮；完整网格与约化网格相同
CuO 链非共线，磁矩倾斜或不共面；或非共线 + SOC全部发散或停滞（500 K、1000 K、混合参数 0.05 都试过）；2000 K 倾斜 + SOC 83 轮收敛到无磁矩的态
Cu fcc，k 点 6³只有 SOC，Klines 能带、投影、DOSΓ 点 d 带分裂为 4 + 2 重；2 轮；输出 2N = 18 个能级，一个“自旋通道”

CuO 链发散的原因：没有 SOC 时，所有磁矩一起转动不改变能量，SCC 的残差在这个方向上的导数为零。Broyden 混合器在这个方向上的逆雅可比估计趋于无穷，数值噪声就被放大。磁矩恰好沿 z 时，x、y 分量严格为零，这个方向不会被激发，所以能收敛。SOC 带来的各向异性很弱，不足以压住它。

三、pydftb 的接口

选项（DFTB）含义DFTB+
spin="noncolinear"非共线自旋（需要 spin_constants）。spin=True 和 "colinear" 仍是共线SpinPolarisation = NonColinear
initial_spins每个原子的初始磁矩向量，(n_atom, 3)；默认全零InitialSpins { AllAtomSpins }
spin_orbit{类型标签: 每个壳层的 ξ}，Hartree。只有 s 壳层的元素可以省略SpinOrbit { <Sp> = {…} }
spin_orbit_dualTrue（默认）：dual 模型；False：onsite 模型Dual = Yes|No
  • 与 DFTB+ 相同的限制：
    • SOC 配共线自旋报错；
    • s 壳层的 ξ 不为零报错；
    • 非共线自旋不能给 unpaired_electrons、relax_total_spin，因为两分量计算只有一个费米能级，总磁矩是自由的。
  • pydftb 自己的限制：
    • 有 SOC 时，k 点集合必须对 k → −k 封闭，否则报错，避免算错磁矩。
    • api.SCC、PyDFTB 给 Monkhorst-Pack 网格时，两分量计算默认用完整网格（time_reversal=None 表示自动）。非共线无 SOC 时也用完整网格，所以磁矩不共面时同样正确；直接给约化网格也接受（与 DFTB+ 相同）。
    • backend="torch"、pydftb.autodiff、solver="sp2" 遇到这些选项报错（只做 NumPy）。
  • 结果（DFTBResult，新字段都有默认值，追加在末尾）：
    • magmoms 为 (n_atom, 3) 的磁矩向量（共线时仍是 (n_atom,)）；
    • q_spin 为 (4, n_shell)：每个壳层的 q、mx、my、mz，也就是混合向量，可直接用作重启；
    • e_ls：自旋轨道能；
    • orbital_moments：每个壳层的 ⟨L⟩，(n_shell, 3)，只在有 SOC 时给出；
    • 本征值和占据：每个 k 点 2N 个，每个能级最多 1 个电子；fermi_spin 为 None。
  • ASE：PyDFTB(spin="noncolinear") 在没有给 initial_spins 时，读取 atoms 的 (N, 3) 初始磁矩；结果的 magmoms 为 (N, 3)，magmom 为总磁矩向量的长度。
  • 能带与 DOS：eigenstates、SCC.states 支持两分量：每个 k 点 2N 个态、一个通道；投影为两个自旋分量之和，与 DFTB+ 的 ProjectStates 相同。

数据结构

  • _Pauli（setup 中）：W（全部壳层，块对角；无自旋极化时为 None），初始磁矩，Λa（3 × N × N 实数，块对角，无 SOC 时为 None），dual 标志，以及每个 k 点的 HSO(k)（2N × 2N 复数，SCC 中不变，只算一次）。
  • 旋量矩阵按 DFTB+ 的顺序：[全部轨道 ↑，全部轨道 ↓]；重叠矩阵为 blockdiag(S, S)，交给现有求解器（eigh、batched 及 k 线程）。
  • _SCCState 不加字段：两分量时 h、rho、wdm 为 (nk, 2N, 2N)，vs_orb 为 (3, N) 的自旋势，mu 为一个数。

SCC 一轮

  1. 由混合向量得到 dq（总电荷）与壳层磁化 ma；电荷势 v（SCC、三阶）同前；自旋势 va = (W ma)[轨道的壳层]。
  2. Hq = H0 + ½S(vμ + vν)；Ha = ½S(vaμ + vaν)； 旋量 H = [[Hq + Hz, Hx − iHy], [Hx + iHy, Hq − Hz]] + HSO。
  3. HSO：令 Xa = Λa（onsite）或 ½(SkΛa + ΛaSk)（dual），则 ↑↑ 块 iXz，↓↓ 块 −iXz，↓↑ 块 iXx − Xy，↑↓ 块 iXx + Xy。与 DFTB+ 的 ½ξLz、½ξL+ 写法逐项相同。
  4. 对角化后用一个费米能级填充（fill，spin_factor = 1）。
  5. 四个分量 msk 的 Mulliken 布居 Σk wk Re(mskSk)μμ，按壳层求和，得到新的混合向量。
  6. 第一轮不混合；至少两轮（没有给 q_init 时）。

能量

  • EH0 = Σk wk Re Tr(nk H0k)；Espin = ½Σa ma·W·ma；ELS = Σk wk Re Tr(ρk HSO,k)，都用最后一轮的输出量，与 DFTB+ 相同。
  • dual 模型下 ELS 也可以写成 −ΣAΣaΣμν Qiaνμ Λaμν（Qi 为块布居的虚部），这是 DFTB+ 的写法，测试中两者互相核对。
  • terms 增加 “LS”。

力与应力

  • 沿用现有的对元素求和（每个 H0、S 元素的导数乘以系数）：
    • pe 来自 n 的实空间元素；
    • we 来自能量加权密度的 ↑↑ + ↓↓；
    • 自旋项 Σa pa · ½(vaμ + vaν)，其中 pa 是 ma 的实空间元素（共线时只有 a = z）。
  • dual SOC 的新项：HSO 依赖 S。设 Ia(T) = Im Σk wk e2πik·T mak（实空间磁化的虚部，按平移 T 分组，与现有的 _pair_densities 相同）。对元素 (μ 行，ν 列，平移 T)，S 导数的系数加上 −½ Σa (Λa Ia(T) + Ia(T) Λa)νμ。对应 DFTB+ 的 derivative_iBlock。应力由同样的元素梯度得到。
  • onsite SOC 没有显式的力项：它不依赖几何，SOC 对本征值的影响已经包含在能量加权密度里。
  • 用能量对坐标、应变的中心差分检查（每种 SOC 模型、分子和周期体系）。

轨道角动量

  • ⟨La⟩壳层 = −Σμν∈壳层 Λ'a,μν Xνμ，其中 Λ'a = Im La：
    • onsite 模型的 X 为同一原子 n 块的虚部（getLOnsite）；
    • dual 模型的 X 为电荷分量块布居的虚部 Qiq（getLDual）。
  • DFTB+ 打印的是 −⟨L⟩（磁矩）和 −(g/4) m（g = 2.00231930436），保留 8 位小数，对照时换算。

不改的部分

共线与无自旋的路径一行不改，两分量只走新分支（if st.pauli is not None）。golden 只会多出新字段（pauli、e_ls、orbital_moments），用 --allow-new。

  • L 算符：[Lx, Ly] = iLz，L² = l(l+1)，在实轨道基里为纯虚（l = 1、2、3）。
  • 没有 SOC 时整体转动磁矩，能量、力不变（分子；周期体系用完整网格）。
  • 非共线沿 z 与共线计算（共用一个费米能级）的能量、力、电荷相同。
  • 力、应力与能量的中心差分一致：dual、onsite，分子与 CuO 链（包括 DFTB+ 不收敛的倾斜磁矩，用较宽的展宽）。
  • ELS 的两种算法（Tr(ρHSO) 与块布居）一致。
  • 报错：SOC + 共线自旋、s 壳层 ξ ≠ 0、SOC 下的约化 k 网格、torch、autodiff、SP2、非共线 + unpaired_electrons。
  • api.SCC、PyDFTB 的完整网格默认值和 (N, 3) 磁矩；q_spin 作为重启。

门槛

  • golden：两个环境（conda、最小环境）对 M6a 之前的提交 d0ca575 逐位相同，--allow-new pauli e_ls orbital_moments；新算例只在工作树中，不参与比较。
  • refgen --check（全部，NumPy）、dynamics --check。
  • pydftb 测试三个环境；PTBP 测试；G1 不受影响（PTBP 不用这些选项），跑 engine_parity 确认。

六、不做的事与风险

  • 不做：torch 后端与自动求导的两分量版本；DFTB+U 与 SOC 的组合（M6b，DFTB+ 要求 dual 模型）；Casida 等不支持两分量的功能本来也不支持；混合泛函。
  • 风险：长 SCC 的轮数。GdO + SOC 要 166 轮，微小的舍入差别经过多轮放大后，轮数和收敛点可能与 DFTB+ 略有不同。对策：结果按容差比较，轮数只列出对照。
  • 风险：简并能级的相位。Kramers 简并对的本征向量可以任意混合。只要简并能级的占据相同，密度矩阵不受影响；T = 0 时简并能级正好在费米能级上的情形要避开（参考算例用 300 K，或检查过占据）。
  • 风险：周期体系的非共线 SCC 不稳定（第二节）。这是 DFTB+ 的混合器本身的问题，pydftb 照样复现，不另改混合器；在文档中说明，并给出可收敛的做法（沿坐标轴的初始磁矩、加 SOC 与展宽）。
