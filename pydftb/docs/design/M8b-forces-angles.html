关键信息

M8a 的自适应模型只拟合了 6 个理想相的能量，在 Cu13 的 MD 里不稳定，留一相交叉验证里 diamond 也没有改进。M8b 补三样东西：力进入损失函数；一个区分 diamond 与密堆、平面配位的角度描述符；一份带力与应力的 Cu DFT 训练集（VASP 输入，只生成，不提交）。这次只做不依赖新数据的部分：框架与描述符用单元测试和现有的 66 个结构验证，训练集等用户决定是否在电光云上算。

  • 力进入拟合：Sample(atoms, energy, forces=…)，fit_adaptive(..., force_weight=w)。残差加上 √w (F − Fref)，它对 θ 的 Jacobian 用 θ 的中心差分（每个系数两次计算）。
  • 角度描述符：qA = ΣB,C fB fC P3(cos θBAC) / (CNA2 + 0.01)。有反演对称的环境（fcc、bcc、sc）q = 0，diamond 5/9，石墨 0.624，二聚体 0.99。用法是 AdaptiveParams(..., angular=RBF(...))，Φ = [Φ(CN), Φq(q)]，仍然对 θ 线性。
  • 训练集：176 个结构，分为二聚体、团簇（含 MD 里重构掉的 Cu13）、MD 快照、表面、空位、扰动与拉伸的晶胞、PTBP 原有的相。估计 1403 核时、约 140 元（dg83）。
  • 176训练集结构数（只生成）
  • ~1403估计核时，dg83，约 140 元
  • 0 / 5/9q：fcc、bcc / diamond
  • 1e-8dq/dR 对差分

一、为什么这样设计

  • 力：一个 N 原子结构有 3N 个力分量，只有 1 个能量，所以力是信息最多、最便宜的数据。M8a 的 MD 失败正是因为没有约束“短键、低配位”这类畸变环境的力。
  • 力的 Jacobian 用差分：解析的 ∂F力/∂θ 要对 ∂F/∂θ 再对坐标求一次导数，即 SCC 的响应（M8a 设计里提到的 implicit 求导）。差分代价是每次评估 2·nθ 次计算，对 48 个系数可以接受，而且与能量的解析 Jacobian 共用同一套并行。解析版本留到系数多到差分太贵的时候（神经网络 Φ）。
  • 角度：CN 无法区分 diamond（CN 4，四面体）与平面四配位，也无法区分 CN 相近的 β-Sn 与密堆环境的畸变。l = 3 的勒让德多项式对有反演中心的环境严格为 0，对四面体最大，所以一个数就能把“共价、方向性强”与“金属、各向同性”分开，导数简单（只要单位矢量）。
  • q 用 CN2 归一：S = Σ fB fC P3 随邻居数平方增长，除以 CN2 后 q 只看形状；加 0.01 让孤立原子 q = 0 且光滑。

二、力进入拟合

  • Sample.forces（eV/Å，形状 (N, 3)，可以是 None）。有力的样本贡献 3N 个残差 √wF · wk · (F − Fref)，wF 的单位是 (eV/atom)2 每 (eV/Å)2。
  • evaluate_all(models, samples, sk, opts, x, with_forces, step)：能量与解析的 ∂E/∂θ 照旧；有力时在 θ ± step 处各算一次力，得到 ∂F力/∂θ。
  • FitResult.force_rmse（eV/Å）；拟合历史是 (时间, 能量 RMSE, 力 RMSE)。
  • 检验：∂F力/∂θ 应等于 −∇R(∂F/∂θ)（混合二阶导数对称），即“差分的力 Jacobian”与“解析 ∂F/∂θ 的坐标差分”一致。

三、角度描述符

  • 对原子 A 的邻居条目 B（含周期像），uB = rAB/|rAB|，cBC = uB·uC，S = fT P3(c) f（含 B = C 的对角项，P3(1) = 1），q = S / (CN2 + ε)。截断函数 f 与 CN 相同（M5a 的光滑计数函数），所以 q 在截断处光滑。
  • dq/drB = [2 ΣC fC P3'(cBC) fB (uC − cBC uB)/|rB| + 2 (P3 f)B f'B uB] / (CN2 + ε) − 2 CN S/(CN2 + ε)2 · f'B uB。每个邻居条目给一个 3 矢量，与 CN 的对导数走同一条散射到力与应力的路（coordinate_gradient 加上 q 的条目）。
  • AdaptiveParams.angular 是一个不含常数的 RBF（常数已在 CN 的基里，必须 constant=False）；features(cn, q) 返回 Φ、∂Φ/∂CN、∂Φ/∂q。每个通道的系数个数变成 size = CN 基 + q 基。
  • 结果里多了 AdaptiveResult.q。不用 angular 时什么都不变（Φ 与以前逐位相同）。

  • collect.py 把结果写成 cu_m8b.extxyz（自由能、力、应力），直接给 Sample。

五、实验设计

  • 单元测试：q 的取值（二聚体、石墨、diamond、bcc、fcc）与 dq/dR 对差分；带角度的模型的力、应力、∂F/∂θ 对差分（与 CN 模型同一组测试，参数化为 cn 与 cn+angular）；力 Jacobian 的对称性检验；用力拟合恢复一个已知模型（远离平衡的水分子，|F| > 0.5 eV/Å）。
  • 现有数据上的角度模型：在 M8a 的自适应模型上加 q 的 RBF（中心 0.3、0.6，宽 0.15），共 48 个系数；拟合全部 66 个结构，再做留出 diamond 与留出 β-Sn 两折交叉验证，与 M8a 的固定、自适应模型比较。
  • 不做：带力的真实拟合（现有的 66 个结构都是理想晶格，力按对称为 0，没有信息）与新数据上的 MD，等训练集算完。

六、风险与之后

  • 6 个相不够约束角度项：训练集里 q 只取 0、0.62、0.99 三个值，q 的基函数可以只“记住”石墨与二聚体。留出 diamond 正是在测这件事（结果见报告）。
  • 差分的力 Jacobian：每次评估多 2 nθ 次带力的计算。176 个结构、48 个系数时约 1.7 万次计算一轮，本机要按小时算；系数再多就要解析的 implicit 导数。
  • VASP 与 FHI-aims：ptbp 组用 VASP 重算，就不需要跨代码的能量对齐。
  • 之后：数据回来之后的带力拟合与 MD；按元素的 CN；神经网络的 Φ；M8c 主动学习。
