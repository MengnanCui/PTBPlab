关键信息

DFTB+ 拒绝杂化泛函下的坐标导数（“Coordinate derivative perturbations do not yet work with hybrid functionals”）。M6h-4d 给出分子的 CoordDerivatives：布居对原子位置的导数、Born 电荷、本征值导数，金属另有费米能级的导数。算法是 M6g-2 的坐标响应搬到 M6h-4 的轨道对空间。交换出现两次：一次是它在固定密度下对坐标的显式导数（S′ 与 γ′），一次是响应核。两分量（非共线，分子）也做，旧计算路径逐位不变。

  • 原型（M6h-4b 时写好，P98a 用现在的代码重跑）：
    • Born 电荷与解析杂化力对外场的差分（Maxwell 关系，原子不动）：H2O LC 3.4e-12，CH3OH LC 3.5e-11，H2CO CAM 3.9e-11（|Z*| 0.4–0.7）。
    • 去掉交换后等于 M6g-2：1.7e-16；CH3 自旋对 SCC 电荷的几何差分 1.9e-10。
  • 屏蔽（P98b）：NeighbourBased 与 Thresholded 的交换用截断以内的 S，它的导数是 S′ 乘以原子对的近邻掩码。CutoffReduction 10 的苯：带掩码与几何差分一致到 2.5e-10，不带掩码差 1.0e-2。
  • SK 表的折点（P98c）：H2O 的一个 H 沿 y 移动时，S 本身的差分与解析的 S′ 差 3e-5，h 从 1e-4 缩到 1e-5 也只到 1.4e-5，所以那里的几何差分不可靠。干净的检验是 Born 电荷对 dF/dE。
  • 范围：分子；实数路径（闭壳层、共线自旋、金属、+U、onsite、DFTB3、外场与点电荷，三种屏蔽，LC、CAM、全局杂化）与两分量（MatrixBased，同基态）。周期体系拒绝，同 M6g-2。
  • ≤ 3.9e-11Born 电荷对 dF/dE（原型）
  • 1.7e-16去掉交换后与 M6g-2 之差
  • 2.5e-10带掩码的屏蔽交换导数对差分
  • 0旧计算路径改变的位

一、范围与 DFTB+

  • DFTB+ 25.1（与开发版相同，initprogram.F90）：CoordDerivatives 配 Hybrid 时停下。它的坐标导数另外还拒绝自旋、+U、onsite、SOC 与非团簇的边界条件；pydftb 的 M6g-2、M6g-3a、M6g-3b 已经越过这些限制。
  • M6h-4d 做：分子的坐标导数，结果类与 M6g-2 相同（CoordDerivativesResult）：dNB/dxK,c（含自旋的磁化，两分量的四个分量）、Born 电荷、本征值导数、金属的 dEF/dx；可以只移动部分原子（{"atoms": [...]}）。
  • 不做：周期体系（同 M6g-2：周期体系的 Born 电荷要 Berry 相；DFTB+ 也只给团簇）。

二、探针与原型

原型在草稿目录 m6h4b/proto_x.py（M6h-4b 时写好）与 m6h4d/。

探针内容结果
P98a原型用现在的代码重跑：Born 电荷对解析杂化力的外场差分（h = 1e-4，四点公式）；SCC 电荷的几何差分；去掉交换对 M6g-2Born：H2O 3.4e-12，CH3OH 3.5e-11，H2CO CAM 3.9e-11；几何差分：CH3 自旋 1.9e-10，H2O 2.9e-6（P98c 的折点）；去掉交换 ≤ 2.2e-16。
P98b屏蔽交换 four_terms(Sx, G, ΔP) 在固定 ΔP 下的导数对几何差分：原子对近邻掩码、原型的 “Scam ≠ 0” 掩码、不加掩码苯 NeighbourBased（CutoffReduction 10）：2.5e-10、2.5e-10、1.0e-2；苯 Thresholded（CutoffReduction 4）：都是 2.5e-10。“Scam ≠ 0” 在这些几何里碰巧对，但对称性为零的 S 元素导数不一定为零，所以用原子对的掩码。
P98cH2O：S 本身的几何差分对解析的 S′H 原子沿 y：h = 1e-3、1e-4、1e-5 时差 3.2e-5、3.0e-5、1.4e-5（不随 h 收敛）；其余方向 h = 1e-5 时 ≤ 4e-12。SK 表的插值在这个距离上有折点，P98a 的 2.9e-6 与 P98b 中 H2O 的 9.6e-5 都来自它。

三、pydftb 的算法

对坐标 x = xK,c，S′、H0′ 来自原子 K 的原子对（同 M6g-2）。基态密度 ρs = Cs f CsT（每个自旋通道），ΔPs = ρs − P0。

固定密度下的显式导数

  • He = H0′ + ½ S′∘(vμ + vν) + ½ S∘(v′μ + v′ν) + ½(S′Vb + VbS′) + c·L(Sx′, G′; ΔP)。
    • v 是基态的 SCC 势（自旋时每个通道 v ± vs），v′ 是固定电荷时势的导数（γ′、三阶、外场、点电荷，M6g-2 的 Jacobian）；Vb 是基态的块势（+U、onsite）。
    • L 是四项算子 four_terms(S, G, ΔP) 对 (S, G) 的线性变化；c = −1/8（闭壳层）或 −1/4（每个自旋通道）。
    • Sx′ = S′（MatrixBased），或 S′ 乘以原子对近邻掩码（NeighbourBased、Thresholded 的极限，同 M6h-4 的响应）；G′ 是 γ′(RAB) 在 K 所在原子对上的投影。
  • 正交归一的约束：N = CTS′C，PN = −Σs w C(f̄∘N)CT，f̄ij = ½(fi + fj)。
  • 固定 P 时 Mulliken 与块布居随 S 变：qS′ = diag(ρS′)，QS′ = ½(ρS′ + S′ρ)；它们的库仑、自旋常数与块势记作 Kc[ρS′]（没有交换：交换只看 ΔP）。

响应

  • (I − TTKT) z = TT(He + K[PN] + Kc[ρS′] − SC(ε̄∘N)CTS)，投影同 M6h-4（金属的费米能级移动；两分量另投影掉整体自旋转动）。
  • 最后一项是 M6g-2 的 −W∘(ε̄∘N)：CTSC = 1，所以它在对空间里正好是 −D∘(ε̄∘N)，并且一起被投影。
  • P1 = PN + Tz；dN = diag(P1S) + diag(ρS′)。
  • 本征值导数：H1 = He + K[P1] + Kc[ρS′]，dεi = [CTH1C − ε̄∘N]ii；简并组取子块的本征值（同 M6g-2）。
  • 金属：dEF/dx = Σ窗口 w δ dε / Σ w δ（每个费米组）。
  • Born 电荷：∂μj/∂xK,i = δij(q0 − N)K − ΣA RA,j dNA/dxK,i（物理符号，同 M6g-2）。

两分量

  • 旋量的 He：H0′ ⊗ 1 + Σb ½ S′∘(vbμ + vbν) ⊗ σb + ½ S∘(v′μ + v′ν) ⊗ 1 + 块势的四个分量 + 交换的线性变化（对 ΔP 的四个 N×N 块各用一次 L，系数 −1/4）；N = C†(S′ ⊗ 1)C。
  • 其余照实数路径，内积取实部；右端投影掉整体自旋转动（与位置无关的扰动不激发它们，投影只去掉噪声）。

四、pydftb 的接口

r = DFTB(sk_lc, hybrid="lc", analysis={"coord_derivatives": True}).calculate(labels, pos)
cd = r.analysis.coord_derivatives
cd.atom[K, i, 0, B]      # dN_B / dx_K,i；cd.born[K, i, j] = dμ_j / dx_K,i
  • 输出同 M6g-2：detailed.out 的坐标导数块（coord_derivative_tables）与 dBand_dx.out。
  • 拒绝：周期体系（同 M6g-2）。

五、实现 开发细节

位置内容
response_hybrid.py
  • 实数路径与两分量的 kernel 各拆成两段：_scc_populations(ps, ds=None)（壳层与块布居；给出 ds 时是固定密度 ps 在 S′ 下的布居）与 _scc_h(pops, nr)（SCC 势的 H1），交换另加。运算与顺序不变，静态结果逐位相同。
  • coordinate_derivatives：两条路径共用一个函数，路径相关的只有旋量的组装（_spinor、S′ ⊗ 1）、布居的布局与投影（_orbital_populations、_project）。按原子分批：每批 RHS_ELEMENTS / (6 n块 n2) 个原子（同时存在的数组约为静态求解的两倍）。
hybrid.py模块函数 four_terms_lin（四项算子在固定 D 下沿 (S′, G′) 的变化）；HybridTerms.gamma_derivative(atoms)（轨道层面的 γ′）与 exchange_derivative(dps, ds, dg)（S′ 乘原子对近邻掩码、系数、两分量的四个块）。
response.pycoordinate_derivatives 有杂化时转到 response_hybrid（周期体系的检查在前）。
calculator.py去掉 “Coordinate derivative perturbations” 的拒绝。

没有 DFTB+ 参考算例（DFTB+ 拒绝），不加 refgen 的算例。

六、验证 开发细节

  • Born 电荷对 dF/dE（解析杂化力的外场差分，力已与 DFTB+ 对上）：H2O、H2CO CAM、C2H4 全局杂化、CH3 自旋、CuCO 300 K、+U、onsite、DFTB3、外场加点电荷、NeighbourBased、Thresholded（阈值 1e-14）、两分量（含 300 K、外场加点电荷）。界 1e-9。
  • 去掉交换等于 M6g-2、M6g-3a、M6g-3b 的坐标导数（同一基态），界 1e-12。
  • 几何差分（避开 SK 表的折点）：SCC 电荷、本征值、金属的费米能级；NeighbourBased 带 CutoffReduction 时只用它（那里的力不是能量的导数，Born 对 dF/dE 不成立）。
  • 两分量：磁矩沿 z 时等于共线的杂化坐标导数。
  • 屏蔽交换的显式导数：苯 CutoffReduction 10，对位移后的算子做差分。
  • 部分原子与分批：部分原子的结果等于全部计算的对应行；每批一个原子不改变结果。
  • 门槛：golden 两个环境逐位相同、refgen（NumPy、torch）、dynamics、pytest 三个环境、PTBP 测试与 G1。

七、风险与之后

  • 内存：每列一个 n×n 的 S′、He 与 PN，按 RHS_ELEMENTS 分批。
  • Thresholded：用筛选的极限（同 M6h-4 的响应），不碰基态的筛选历史。
  • CutoffReduction：力（DFTB+ 与 pydftb）用不截断的 S′，不是能量的导数；坐标导数是截断模型自身的导数。两者在截断边界附近的原子对上不一致，属预期。
  • 之后：M6h 全部完成，转到路线图的 M7、M8。
