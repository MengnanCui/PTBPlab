关键信息

验证 pydftb 通过 ASE 做结构优化和分子动力学（MD）时，与 DFTB+ 自带的驱动给出相同的结果；顺带让 SCC 没有完全收敛时的力也与 DFTB+ 相同。

  • 力和应力改用最后一轮的输出电荷（DFTB+ 的默认做法 RecomputeAfterDensity）。在 PTBP 用的 SCC 容差 1e-5 下实测 10 个体系：原来用输入电荷时与 DFTB+ 的力差最多 8.1e-7 Ha/Bohr，改后 ≤ 3.2e-11。
  • PyDFTB 新增 reuse_charges：每一步从上一步的输入电荷开始 SCC，与 DFTB+ 驱动在几何步之间的做法相同，优化和 MD 的 SCC 轮数会大幅减少。默认关闭，保持与“ASE + DFTB+、每步一个新进程”逐步一致。
  • 对照方法：DFTB+ 用自己的 GeometryOptimisation、VelocityVerlet；pydftb 用 ASE（BFGS、FrechetCellFilter、VelocityVerlet），设 fd_delta = 1.22e-4 让力与 DFTB+ 的数值导数相同，并打开 reuse_charges。
  • 探测实验：从扰动过的结构直接优化时，DFTB+ 的 LBFGS 在软的水二聚体上步长越来越大，最后 SCC 发散、程序退出；Rational 稳定但很慢（甲醇 1918 步）。所以优化算例先用 pydftb 预优化到 0.02 eV/Å，两边再从同一个起点精细收敛，这时 DFTB+ 的 LBFGS 最快。
  • MD：DFTB+ 默认每步去掉质心运动（KeepStationary），ASE 不会，对照时关掉。ASE 的单位常数与 DFTB+ 相差约 1e-7，所以另写一个用 DFTB+ 常数的速度 Verlet，把积分器、力和单位常数分开检验。
  • 验收：优化终点能量差 ≤ 1e-9 Ha、结构差 ≤ 1e-4 Å、晶格常数差 ≤ 1e-5 Å；MD 40 步内经 ASE 每帧位置差 ≤ 1e-7 Å、能量差 ≤ 2e-8 Ha，用 DFTB+ 常数时 ≤ 2e-8 Å、≤ 2e-9 Ha。
  • 11对照算例（7 个优化、4 段 MD）
  • ≤ 3.2e-11SCC 容差 1e-5 时与 DFTB+ 的力差（Ha/Bohr）
  • 0.5 fsMD 时间步长
实施中的变化（详见完成报告第六节）：优化算例从预优化的起点开始；Cu₄CO 的优化换成 Cu fcc 的晶格优化，Li bcc 改用立方惯用胞做均匀缩放；DFTB3 + D3 水二聚体的优化没有做；另加了容差 1e-5 的单点算例和 DFTB+ 常数下的速度 Verlet。

一、目标与用途

单点计算（一个结构的能量、力、应力）已经与 DFTB+ 逐项一致。实际工作中更常用的是在此基础上“走起来”：

  • 结构优化：沿着力的方向移动原子（周期体系还可以改变晶胞），直到力和应力都接近零，得到稳定结构和晶格常数。
  • 分子动力学（MD）：按牛顿方程一步步推进原子的位置和速度，研究振动、扩散、反应。常用的速度 Verlet 算法在没有热浴时保持总能量守恒（NVE）。

pydftb 不自己实现优化器和积分器，而是作为 ASE 的计算器，用 ASE 现成的 BFGS、FIRE、VelocityVerlet 等。本阶段要回答：这样得到的结果与 DFTB+ 自带驱动的结果是否一致；差在哪里、为什么。

二、DFTB+ 的驱动怎么工作

结构优化（Driver = GeometryOptimisation）

  • 优化器：Rational（默认）、LBFGS、FIRE、SteepestDescent。
  • 收敛判据（Convergence 块）：默认只看梯度的最大分量 GradElem（1e-4 Ha/Bohr），并要求这一步能量没有升高；梯度范数、位移的判据默认关闭。
  • LatticeOpt = Yes 时，原子的笛卡尔坐标和三个晶格矢量作为独立变量一起优化；晶格的“梯度”由应力换算而来。收敛时力和应力同时为零，与 ASE 的 FrechetCellFilter 求的是同一个极小点。

分子动力学（Driver = VelocityVerlet）

  • 算法：v(t+½Δt) = v(t) + ½a(t)Δt，x(t+Δt) = x(t) + v(t+½Δt)Δt，算新的力，v(t+Δt) = v(t+½Δt) + ½a(t+Δt)Δt。更新顺序与 ASE 的 VelocityVerlet 相同。
  • 初速度可以由输入给出（Velocities [AA/ps]），DFTB+ 原样使用；质量取自 SKF 文件（测试用的参数中与 ASE 的值相同）。
  • KeepStationary 默认开启：每一步去掉质心速度。ASE 的积分器不这样做，对照时关掉。
  • 输出：md.out 每步的 Mermin 自由能（“Potential Energy”）、动能、总能（Hartree，10 位小数）；geo_end.xyz 每步的坐标（Å）、电荷和速度（Å/ps），8 位小数。

几何步之间的 SCC

  • 下一步的初始电荷是上一步最后的输入电荷，混合器（Broyden）每步重置。
  • 开自旋时，只有第一个几何步要求至少 2 轮 SCC；之后的步可以在第 1 轮就收敛。

力用哪一组电荷

RecomputeAfterDensity 默认开启：每次对角化之后，DFTB+ 用这一轮的输出电荷重新算 SCC 势（main.F90:processPotentials）。所以 SCC 结束时，力中的电荷项（库仑力 addForceDc）和势项（derivative_shift 用的 potential%intBlock）都来自输出电荷。pydftb 原来用输入电荷；SCC 收敛到 1e-10 时两者差 < 1e-10，看不出来，收敛到 1e-5 时就看得出来了。

三、pydftb 的做法

力改用输出电荷

calculator.DFTB._gradient 用最后一轮的输出布居重新算电荷势和自旋势，库仑力和三阶项的力也用输出布居。能量本来就用输出电荷（与 DFTB+ 相同），不变。

电荷复用

PyDFTB(reuse_charges=True)：若上一次计算的类型标签与这次相同，就把上一次的 q_in 作为这次 SCC 的初值；混合器每次计算新建，与 DFTB+ 每步重置混合器相同。默认关闭：PTBP 用 ASE + DFTB+ 时每个结构都是一个新的 DFTB+ 进程，从中性原子开始。

对照方式

  • 新模块 validation/dynamics.py：算例登记（引用已有单点算例的结构和哈密顿量设置）、DFTB+ 驱动的输入与输出解析、pydftb 经 ASE 的同一任务、冻结的 JSON（tests/data/ref_dynamics/）和比较。
  • 优化：起点是基础算例的结构经 pydftb + BFGS 预优化到 0.02 eV/Å 的结果（冻结在 JSON 中），这样两边精细收敛的是同一个极小点。DFTB+ 用 LBFGS 收敛到 GradElem；pydftb 用 ASE 的 BFGS 收敛到同样大小的 fmax（换算成 eV/Å；ASE 判据是每个原子力的模长，比最大分量更严）。比较终点的 Mermin 能、结构（分子先做 Kabsch 叠合，周期体系比较分数坐标）和晶格参数。
  • MD：初速度由 ASE 按 Maxwell-Boltzmann 分布生成（固定随机种子，去掉质心平动和整体转动），写进 DFTB+ 的输入；两边都走 40 步、0.5 fs。逐帧比较位置、Mermin 能和动能。
  • 两边的单位常数不同（ASE 用 CODATA 2014，DFTB+ 用自己的一组），相对差约 1e-7。除了 ASE 的 VelocityVerlet，再用 DFTB+ 的常数在原子单位下跑同一个速度 Verlet（verlet_dftbplus_units），两条路径分别比较。

开发细节五、探测实验记录

脚本在 scratchpad（m2f/，未进仓库），本机 DFTB+ 25.1。

  • force_charges.py：10 个单点算例，DFTB+ 与 pydftb 都用 SCCTolerance = 1e-5，pydftb 用 fd_delta = 1.22e-4。SCC 轮数全部相同；力差用输入电荷时为 1.6e-11 到 8.1e-7 Ha/Bohr（随 |qout − qin| 增大），用输出电荷时全部 ≤ 3.2e-11；应力差同样从 1.1e-9 降到 ≤ 1.8e-11。
  • probe_md.py：给定速度的 VelocityVerlet 正常运行；Steps = 6 时 md.out 和 xyz 各有 7 帧（第 0 帧是初始结构），与 ASE 的记录方式相同。
  • probe_opt.py：水二聚体（从扰动过的结构开始）用 Optimiser = LBFGS {}，第 12 步后步长从 0.2 增大到 0.8 Bohr，第 23 步的结构上 SCC 500 轮不收敛，程序报错退出。
  • optimisers.py：从预优化的起点，DFTB+ 的 LBFGS、Rational、FIRE 到 GradElem = 1e-7 的步数：H₂O 9/63/65，甲醇 45/1918/125，能量全部相同。
  • Cu₄CO（测试用的 PTBP Cu 参数）：从算例结构出发，团簇在优化中塌缩，能量一路下降、力达到 10–80 eV/Å，三种优化器都收敛不了。这不是有意义的极小点，改用 Cu fcc 的晶格优化。
  • Li bcc 原胞的晶格优化：DFTB+ 的 LBFGS 沿一个非常软的剪切方向漂移，停在比对称极小点高 6.6e-9 Ha 的位置（两边在同一结构上的应力相差约 1e-14 Ha/Bohr³，力与应力本身一致）。Isotropic = Yes 也不行：它只收敛压强，而晶格步长沿 L−T，对非正交的原胞会剪切晶胞（停在高 2.7e-7 Ha 处）。改用立方惯用胞（2 个原子）做均匀缩放。
  • vv_au.py：用 DFTB+ 的常数在原子单位下积分，四段 MD 与 DFTB+ 的轨迹相差 ≤ 1.5e-8 Å（xyz 只有 8 位小数）、能量 ≤ 5e-10 Ha；经 ASE 则为 ≤ 4.4e-8 Å、≤ 1.1e-8 Ha，差别来自单位常数。

测试（tests/test_md_opt.py，不需要 DFTB+）

  • 冻结的优化与 MD 参考逐个复现；
  • reuse_charges：第二次计算的 SCC 轮数明显减少，结果不变；类型标签变了就不复用；
  • SCC 容差放宽时，力仍是能量的导数（与能量的有限差分比较），并且与“完全收敛”的力相差在容差量级。

七、局限与不做的事

  • 热浴（Andersen、Berendsen、NHC）、压浴、约束和 XL-BOMD 不在本阶段对照（XL-BOMD 在 M6）。
  • DFTB+ 旧式的优化驱动（已弃用）不对照。
  • pydftb 自己不实现优化器和积分器，全部交给 ASE。
