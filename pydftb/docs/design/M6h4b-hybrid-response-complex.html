M6h-4 设计

关键信息

M6h-4 只做了实数路径（分子与 Γ 点的共线计算）上的杂化响应。k 点与非共线的杂化响应 DFTB+ 25.1 会段错误（B24、B25），有限频率与坐标导数 DFTB+ 直接拒绝。M6h-4b 做复数路径：k 点（共线）与两分量（非共线，分子）的静态极化率、响应核与点电荷导数。算法仍是 M6h-4 的轨道对空间与批量 MINRES，只是 z 成为每个块的厄米矩阵，内积取实部。

  • 拆分：原定的 M6h-4b 有四项，四项的原型都已跑通（第二节），实现按工作量分三块：
    • M6h-4b：k 点与两分量的静态响应（本文）。
    • M6h-4c：有限频率。P1 的对称与反对称部分都进交换。
    • M6h-4d：坐标导数（分子）。交换在固定密度下对坐标的导数。
  • 没有 DFTB+ 参考：DFTB+ 在这两条路径上崩溃。验证全靠 pydftb 自己：
    • 格点势与外场的有限差分；
    • 不重叠自身镜像的晶胞，k 点等于超胞的 Γ 点（Γ 点已在 M6h-4 与 DFTB+ 对上）；
    • 去掉交换后等于 M6g 的 k 点响应与 M6g-3b 的两分量响应（都与 DFTB+ 对过）；
    • 约化的与完整的 k 点网格结果相同。
  • 原型结果（P94、P95）：
    • k 点的核与格点势的差分差 ≤ 5.2e-10，覆盖 MatrixBased、NeighbourBased、CAM、全局、Damped、MatrixBased 的 MinimumImage、自旋、金属、+U、onsite、DFTB3、外场加点电荷与三斜晶胞；
    • 与超胞 Γ 点一致到 2.8e-12；去掉交换后与 M6g 一致到 1.6e-14；
    • 两分量的极化率与有限场差 ≤ 5e-10（相对），核与差分差 ≤ 4.9e-10；去掉交换后与 M6g-3b 一致到 1.2e-15。
  • 两分量的零模：没有 SOC 时，所有磁矩一起转动不改变能量，方程有零本征值。三个磁矩互成 120° 的 H3 不去掉这些转动就收敛不了（停在相对残差 1.8e-13）。所以 pydftb 在 MINRES 里投影掉它们，得到不含整体转动的响应，与 M6g-3b 的加边方程相同。
  • 拒绝与说明：
    • MinimumImage 配 NeighbourBased 在 k 点的交换算符不自伴（B22），双线性形式的对称性差 4.8e-2。响应方程因此不对称，拒绝，与力相同。
    • NeighbourBased 的 Threshold 给筛选的极限：带筛选的 SCC 的增量依赖历史，不是线性算符（与 M6h-4 的分子 Thresholded 相同）。
    • Full 核配粗网格时，金刚石的对称 SCC 解是鞍点，与 M6h-4 的 Cu4 一样：照样求解并警告。MatrixBased 的 MinimumImage（金刚石 3×1×2）也是鞍点，实现时才发现：稠密算符有 4 个负本征值，最低 −0.56。
    • SOC 配杂化的基态 DFTB+ 拒绝，pydftb 照做；非共线的杂化只有分子（DFTB+ 的规定）。
  • ≤ 5.2e-10k 点的核与格点势差分之差
  • 2.8e-12k 点与超胞 Γ 点之差
  • ≤ 5e-10两分量的极化率与有限场（相对）
  • 3两分量要投影掉的整体转动

一、范围与 DFTB+

  • DFTB+ 25.1（M6h-4 的探针 P90）：
    • k 点杂化的 ResponseKernel 段错误（B24）：dRhoCmplx 没有交换项。
    • 非共线杂化的 Polarisability 段错误（B25）：dRhoPauli 也没有。
    • 有限频率与坐标导数配杂化，DFTB+ 拒绝（"Finite frequency hybrid xc-functional calculation not currently supported"、"Coordinate derivative perturbations do not yet work with hybrid functionals"）；开发版 041e723 相同。
  • 基态的前提：
    • k 点：M6h-3b、M6h-3c 支持的全部组合（屏蔽、库仑核、自旋、金属、+U、onsite、DFTB3、色散、外场与点电荷），MP 展宽除外（响应只接受 Fermi 填充，M6g 的规定）。
    • 两分量：DFTB+ 只允许分子的非共线杂化、只允许 MatrixBased，SOC 配杂化拒绝（pydftb 照做）。+U 与 onsite 可以（P95）。
  • M6h-4b 做：k 点（共线）与两分量（分子）的静态极化率（周期体系只有电荷响应，同 M6g）、响应核（含 RPA）、点电荷导数。结果类与 M6g 相同，两分量的布居有四个分量（M6g-3b 的约定）。
  • 之后：M6h-4c 有限频率，M6h-4d 坐标导数（第七节）。

二、探针与原型

原型都在草稿目录 m6h4b/，直接用 M6h-4 的 HybridResponse 的求解器，换掉块的部分。对照的都是 pydftb 自己：格点势的四点差分（h = 1e-4 Ha，scc_tol 1e-13）、有限场、超胞、M6g 与 M6g-3b。

P94ak 点的核，M6h-3 的参考基态：CO2 2×1×1 的 MatrixBased 与 NeighbourBased；金刚石 2×2×2 的 LC、CAM、全局、Damped；MatrixBased 的 MinimumImage（3×1×2）；O2 盒子自旋 2×2×2；DFTB3 加 D3；外场加点电荷；三斜 CO 2×2×2与格点势的差分差 4.3e-12 到 5.2e-10；去掉交换后与 M6g 的 k 点核一致到 ≤ 1.6e-14；双线性形式对称到 ≤ 1e-13。

P94c金属：金刚石 2×2×2 在 30000 K（8 个块一个费米组），O2 盒子自旋在 20000 K差分 2.5e-11 与 4.2e-12；M6g 4.4e-15 与 2.7e-15。

P94e约化的 k 点集（DFTB+ 的 4 个）对完整的 Γ 心网格（6 个），金刚石 3×1×21.2e-14。

P94gNeighbourBased 的 Threshold 1e-6（金刚石 3×1×2）筛选极限的响应与带筛选的 SCC 的差分差 1.3e-2（|核| 11.8）：1e-6 的筛选噪声被 h = 1e-4 放大。Threshold 取 1e-100 时差分对上，2.2e-11。

P94iFull 核（金刚石 2×2×2）；MatrixBased 的 MinimumImage（3×1×2，实现后补查）Full：MINRES 判为不定；dN0/dV0 = +0.78 > 0。±1e-4 Ha 的格点势让 0.0023 e 在两个 C 之间转移，两个方向的能量都下降 1.9e-6 Ha：对称解是鞍点，差分跳到破缺对称的解上。MinimumImage：稠密算符有 4 个负本征值（最低 −0.56），也是鞍点；但 ±1e-4 Ha 的 SCC 停在同一个驻点，差分与核一致（1.8e-11）。
P95a两分量的极化率对有限场（h = 1e-4）：HCO、HCO 300 K、CH3、O2 CAM 90°、H3 120°、HCO +U 与 onsite相对差 3.2e-12 到 5.0e-10。H3 的响应强烈非线性，h = 1e-3 时差分误差 3e-6（h4 的截断）。
P95b两分量的核对格点势的差分：上面的分子，外场加点电荷，DFTB3 加 D3≤ 4.9e-10。
P95c去掉交换后对 M6g-3b（同一基态），H3 120°α 1.7e-16，全部四个分量的布居 1.2e-15。
P95d整体转动的投影共线样的磁矩有 2 个转动，H3 120° 有 3 个。两种都收敛时结果相同（≤ 7e-13）；H3 不投影就不收敛。
M6h-4c有限频率的原型（分子）与 TD-LC Casida 对全部单重态的求和一致到 2e-13（相对，H2O、CH3OH、C6H6，含第一激发以上的频率）；去掉交换后与 M6g 的有限频率一致到 2.7e-13（含 CuCO 金属）。C6H6 在离激发 4e-4 Ha 处 MINRES 不收敛。
M6h-4d坐标导数的原型（分子）显式的 ∂Hx/∂R 与差分一致到 4e-12；Born 电荷与解析力对外场的差分（Maxwell 关系）一致到 3.4e-12–3.9e-11；去掉交换后与 M6g 一致到 1.7e-16。原子位移的差分受 SK 表插值的影响（不加杂化的 M6g 也差 2.4e-6）。

三、pydftb 的算法

复数的块

  • M6h-4 的方程不变：P1 = T z，(I − TTKT) z = TTHext，T z = −C (D ∘ z) C†，TTH = D ∘ (C†HC)，费米能级的移动是窗口对角元的投影。
  • 块 b 是一个 (自旋, k) 或一个两分量的 k 点。P1,b 带着 k 点的权重 wb（D2 = −fmax wb W），zb 是厄米矩阵。
  • 内积 ⟨z, y⟩ = Σb Re Tr(zb†yb)，⟨P, H⟩ = Σb Re Tr(PbHb)。对厄米的 z 与 H，TT 是 T 的伴随（D 实对称）；K 是能量的二阶导数，所以 I − TTKT 在这个实内积下对称，MINRES 照用。
  • 布居：Σb Re diag(P1,bSb)，在位布居 Σb Re diag(P1,b)。
  • 块势（+U、onsite）：对偶块布居 Σb Re[½(P1,bSb + SbP1,b)]μν，算符 ½(SbV + VSb)。

k 点的交换

  • ΔP1(k) = P1,b/wb，交换用基态的 k 点算符（KPointHybridTerms，M6h-3b）：BvK 超胞里的卷积 Hx(k) = c[𝒞(SΔPS) + 𝒞(SΔP)S + S𝒞(ΔPS) + S𝒞(ΔP)S]，𝒞(X)(k) = 1/N Σq X(q) ∘ G(k − q)。
  • 对实的扰动，P1(−k) = conj P1(k)，所以约化的 k 点集够用（P94e）。
  • 批量：to_bvk 是 (N, nk) 的矩阵乘以 (nk, r n2)，r 个右端一起做，G(n) 按批广播。
  • NeighbourBased：截断以内的 S（M6h-3b 的 Sx）。Threshold：给它的极限，即同一个 Sx 不筛选增量，不碰基态的筛选状态。
  • MatrixBased 的 MinimumImage：Wigner–Seitz 格矢上的 γ，算符自伴（P94a，对称到 4e-16）。
  • MinimumImage 配 NeighbourBased：算符不自伴（B22），拒绝。

两分量

  • 一个 k 点一个块（分子只有一个），C 是 2N×2N 的复数旋量，每个能级至多一个电子，一个费米能级（M6g-3b 的 PauliGroundState）。
  • Pauli 分量 Pb = Trspin(σbP1)，b = 0, x, y, z（spinorbit.components）。布居 Re diag(PbS)：电荷进 γ（和三阶），三个磁化分量各进自旋常数 W。
  • 一阶哈密顿量 H1 = Σb [½ S ∘ (Vbμ + Vbν)] ⊗ σb，块势用 Pauli 的四个分量（M6g-3b 的 BlockChannels，n_comp = 4）。
  • 交换：基态的 Pauli 算符，c = −1/4 作用在 ΔP 的每个 N×N 块上，右上块是左下块的伴随（M6h-1b）。
  • 零模：没有 SOC 时能量在整体自旋转动下不变，δPb = −i/2 [σb ⊗ 1, P0] 是零模。它在轨道对空间的像 zb = −(C−1δPbC−†)/D（C−1 = C†S），正交化后（共线样的磁矩 2 个，一般 3 个）从右端与每个 Lanczos 向量里投影掉，即解 P(I − TTKT)P z = P b。自旋无关的扰动的右端与零模正交，所以这只去掉 SCC 噪声，结果是不含整体转动的响应，与 M6g-3b 的加边方程相同。

不稳定的基态

交换是负的。M6h-4 已经看到热的金属与开壳层 d 体系可能是鞍点；k 点配 Full 核或 MinimumImage 与粗网格时，绝缘体也可能（P94i）。MINRES 照样求解，遇到负曲率时警告（与 M6h-4 相同的原话）。

四、pydftb 的接口

DFTB(sk_lc, hybrid="lc", kpts=supercell_folding((2, 2, 2)),
     analysis={"response_kernel": True, "polarisability": True})   # k 点：核与电荷响应
DFTB(sk_lc, hybrid="lc", spin="noncolinear", spin_constants=w, initial_spins=m,
     analysis={"polarisability": True, "external_charge_derivatives": True})   # 两分量
  • 结果类与 M6g 相同；两分量的 atom[w, A, c, B] 有 c = 0（电荷）与 1–3（磁化）。
  • 拒绝：
    • MinimumImage 配 NeighbourBased 的 k 点（不自伴，B22）；
    • 有限频率（M6h-4c）、坐标导数（M6h-4d），都按 DFTB+ 的原话；
    • MP 展宽（M6g 的规定）。

五、实现 开发细节

位置内容
response_hybrid.py
  • HybridResponse（实数路径）的算术不变：M6h-4 的 37 个算例已经进了 golden，要逐位相同。_minres 改调 self._dot，实数路径仍是原来的函数。
  • KPointHybridResponse（新，k 点）：每个块的 C、S(k)、D；t_apply、t_adjoint、布居、块势、交换按块；复数内积；输出每个块的本征值导数（简并组取厄米子块的本征值）与费米能级导数。
  • PauliHybridResponse（新，两分量）：Pauli 分量的布居与 H1、四分量的块势、Pauli 交换、整体转动的投影；输出 (r, 4, N) 的布居。
  • 三个入口按 st.pauli 与 k 点选类。
hybrid.py
  • HybridTerms.response_fock 的 Pauli 分支：无状态，可带批量维。
  • KPointHybridTerms.response_fock（新）：无状态的精确算符（Threshold 取极限），批量的 BvK 卷积。
  • NeighbourMinimumImageTerms.response_fock：报错（B22）。
response.py三个入口里杂化的分支放到两分量的分支之前（不加杂化的两分量不受影响）。
calculator.py去掉 k 点与两分量的 M6h-4b 拒绝；MinimumImage 配 NeighbourBased 的 k 点响应按力的原因拒绝。
测试新文件 tests/test_hybrid_response_complex.py，27 项（第六节）；test_hybrid_response.py 与 test_hybrid.py 的拒绝改成新的。

没有 DFTB+ 参考算例（DFTB+ 崩溃），所以不加 refgen 的算例；验证都在测试里，用 pydftb 自己的差分与等价关系。

六、验证 开发细节

  • k 点：
    • 超胞：CO 盒子 2×1×1 的核（LC MatrixBased、NeighbourBased）等于超胞 Γ 点的核（镜像求和），界 1e-11；自旋用同一盒子里的三重态 O2（三重态 CO 的超胞 SCC 可能不收敛，见报告第七节）。
    • 格点势的差分：金刚石 2×2×2 LC、CO2 2×1×1 +U、金刚石 30000 K（金属）、O2 盒子自旋、MinimumImage（MatrixBased），界 2e-9。
    • 去掉交换后等于 M6g 的 k 点核与极化率（含 +U、金属、自旋），界 1e-12。
    • 约化的与完整的网格相同；dq/dE 等于核乘坐标；Threshold 等于极限；Full 核的鞍点给出警告；MinimumImage 配 NeighbourBased 拒绝。
    • 点电荷导数对移动点电荷的差分。
  • 两分量：
    • 极化率对有限场（HCO、O2 CAM 90°、H3 120°、+U、onsite），界 2e-8（相对）。
    • 核对格点势的差分，界 2e-9。
    • 去掉交换后等于 M6g-3b，界 1e-12。
    • 磁矩都沿 z 时等于共线的杂化响应（M6h-4，已与 DFTB+ 对上）。
    • 整体转动的投影：H3 120° 不投影不收敛，投影后与差分一致。
    • 点电荷导数对移动点电荷的差分。
  • 以上共 27 项测试，实测值见报告的第三、四节。
  • 门槛：golden 两个环境逐位相同（含 M6h-4 的 37 个算例）、refgen（NumPy、torch）、dynamics、pytest 三个环境、PTBP 测试与 G1。

七、不做的事、风险与之后

  • 不做：k 点的两分量（基态就不支持）、SOC 配杂化（DFTB+ 拒绝基态）、MinimumImage 配 NeighbourBased（不自伴）、MP 展宽。只有 NumPy 引擎。
  • 风险：
    • k 点的交换每个右端一次 BvK 卷积，核要解 natom 个右端；大网格的内存是 N n2 r，右端按 M6h-4 的方式分块（块数把 nk 也算进去）。
    • 两分量的零模投影依赖基态的 P0；SOC 打开时没有零模（不在范围内）。
  • M6h-4c 有限频率：
    • P1 分成对称与反对称部分，[[I + DKsD, −Ω], [−Ω, I + DKxD]] [zs; za] = [D ∘ Mext; 0]，Ω = ω/Δ。反对称部分按 1/√(1 + Ω2) 缩放；同一简并组的对不进。
    • 方程对称不定，MINRES 可解；离激发很近时的求解器要再定（停滞判据、MINRES-QLP 或小体系的稠密解）。
  • M6h-4d 坐标导数（分子）：
    • P1 = PN + T z，PN = −C(f̄ ∘ N)CT。
    • 右端含显式的 ∂Hx/∂R（S′ 与 γ′，固定 ΔP）、ρS′ 的布居的库仑势，以及 −D ∘ (ē ∘ N)。
    • 用 Born 电荷对 dF/dE 验证。
