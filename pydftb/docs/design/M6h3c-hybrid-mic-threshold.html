关键信息

M6h-3b 之后 k 点杂化还缺两项：库仑矩阵 MinimumImage（DFTB+ 只在 k 点允许），以及 NeighbourBased 的 Threshold 筛选（DFTB+ 默认 1e-6，只在 k 点起作用）。两者在 DFTB+ 里各有 MatrixBased 与 NeighbourBased 两种做法，结果不同。原型在 pydftb 的 KPointHybridTerms 上实现，全部与 DFTB+ 25.1 对上。

  • MinimumImage：不截断的 γ，格点和只取 BvK 超胞的 Wigner–Seitz 胞（WignerSeitzReduction 缩小超胞）。
    • MatrixBased：就是 M6h-3b 的交换，平行六面体的平移换成 WS 向量、核换成完整的 γ。9 个探针能量差 ≤ 4.6e-11 Ha，SCC 轮数相同（80 轮的一个差 1 轮）。
    • NeighbourBased：WS 只限制每条路径 M → A → B → N 中 A–B 的密度矩阵，γ 在路径的实际距离上取值。重写成显式格胞的核的卷积（FFT），与 DFTB+ 差 5.7e-12 Ha（WS 缩小 1 时 3.1e-12，轮数相同）。
    • 新发现（B23）：WS 向量是折回晶胞后的格矢，不按原子对取最近像，所以能量随原子怎样折回晶胞而变：金刚石 2×1×1 的一个原子越过晶胞面 2e-6 Bohr，MatrixBased 的能量跳 1.82 Ha、NeighbourBased（缩小 1）跳 0.073 Ha，DFTB+ 与 pydftb 的跳变一致到 5e-11。
    • 新发现（B22）：NeighbourBased 的 MinimumImage 交换算符不是自伴的（⟨H[P], Q⟩ 与 ⟨H[Q], P⟩ 差 23 %），交换矩阵不是能量的导数。所以它的力要响应计算，SCC 收敛也慢；DFTB+ 本来就不给力。pydftb 不给它的力，MatrixBased 的给（是导数）。
  • Threshold 筛选：交换按 ΔPin 的增量累加，增量的四项只保留 pmax·estMA·estNB ≥ Threshold 的近邻对组合，结果依赖 SCC 的历史。移植后 7 个算例与 DFTB+ 差 ≤ 7.9e-11 Ha（不筛选的构建与之差到 1.7e-5），轮数多数相同。默认 1e-6 时 MinimumImage 的 SCC 停在 1e-5 的误差上不收敛（DFTB+ 也一样，固定 20 轮时每轮误差都对上）。
  • 接口：Hybrid 新增 wigner_seitz_reduction（默认 0）与 neighbour_threshold（默认 None，即不筛选、精确；给 1e-6 即 DFTB+ 的默认）。已有的字段与默认值都不变。
  • ≤ 4.6e-11MatrixBased MinimumImage 与 DFTB+ 的能量之差（Ha）
  • 5.7e-12NeighbourBased MinimumImage（金刚石 2×2×2）
  • ≤ 7.9e-11移植的 Threshold 筛选与 DFTB+（7 个算例）
  • 23 %NeighbourBased MinimumImage 算符的非自伴程度

一、DFTB+ 的做法

源码 25.1：dftb/hybridxc.F90（updateCoords_kpts、addCamHamiltonianNeighbour_kpts_mic、addCamHamiltonianNeighbour_kpts_ct、getFourLoopCompositeIndex、calculateOverlapEstimates、getCamGammaFourier、getCamGammaGResolved），math/wignerseitz.F90，dftbplus/parser.F90: parseHybridBlock，dftbplus/initprogram.F90。记录在草稿目录 m6h3c/notes.md。

MinimumImage

  • 输入：CoulombMatrix = MinimumImage { WignerSeitzReduction = 0 }，不读 CoulombCutoff 与 GSummationCutoff。Γ 点拒绝（“Hybrid functionals don't yet support Gamma point calculations for CoulombMatrix types other than 'Truncated' or 'Truncated+Damping'.”）。默认截断仍要算，a2 沿 z 的晶胞照样停在 B3 的话上。
  • WS 向量（generateWignerSeitzGrid）：超胞 N′ = max(N − r, 1)（r 是 WignerSeitzReduction）；n ∈ [−2N′, 2N′]³ 中，度量长度 |n·A|² 在 n − i∘N′（i ∈ [−2, 2]³）里最小（容差 1e-8 Bohr²）的都保留，再按长度排序。边界上的并列向量都以权重 1 计入（B9）：FCC 原胞 2×2×2 有 19 个向量、8 个类；3×1×2 有 11 个、6 个类。
  • γ：不截断的 β γLR + α γHF，在折回晶胞的坐标上取值。
  • MatrixBased（getCamGammaFourier 的格点和换成 WS 向量）：G(k, k′)12 = Σg∈WS γ(|R′2 − R′1 − g|) ei2π(k−k′)·g，其余同 M6h-3b。在超胞实空间里就是 g(n) = Σg∈WS, g≡n γ(g) 的四项公式。力的代码对它也成立（但 DFTB+ 拒绝非 Truncated 核的力）。
  • NeighbourBased（addCamHamiltonianNeighbour_kpts_mic）：对近邻表的四重循环 M、A ∈ nbr(M) 在胞 h、N、B ∈ nbr(N) 在胞 l，以及 g ∈ WS：A–B 的密度块取 BvK 胞 −g（即 B 在 A 的 g 胞），M–N 的偏移 T = g + h − l，相位 e−i2πk·T，四项 SMAΔPABSBN 乘 γMN(T) + γMB(g + h) + γAN(g − l) + γAB(g)，γ 在这条路径的实际距离上取。只有 A–B 的偏移限在 WS 里，M–N 的 T 不限。增量构建与 Threshold 筛选同下。力拒绝（“… for CoulombMatrix setting 'MinimumImage'.”）。
  • 拒绝：非 Truncated 核的力、自旋配非 Truncated 核（都包括 MinimumImage）。

NeighbourBased 的 Threshold

  • 周期体系才读（默认 1e-6）；Γ 点的 addCamHamiltonianNeighbour_real 不用它（B16）。分子的 NeighbourBased 没有这个关键词。
  • 增量构建（k 点的两种 NeighbourBased 都是）：ΔΔP = ΔPin − ΔPprev（第一次是 ΔPin 本身），pmax = max|ΔΔP|（所有自旋）；H = Hprev + c·H4[ΔΔP]，只对保留的近邻对组合求。pmax < 1e-16 时返回 H = 0 而不是 Hprev（B7，SCC 中没有触发）。
  • 保留的组合（getFourLoopCompositeIndex）：近邻对 p = (M, A@h)、q = (N, B@l)，est = max|S 块|（在位为 1），按 est 降序遍历、低于阈值即退出：保留 pmax·estq·estp ≥ Threshold。
  • 新几何（updateCoords）：Hprev、ΔPprev 清零，第一次构建是完整的。能带运行（读电荷、一轮）同样是从文件的 ΔP 一次构建。
  • 力（addCamGradientsNeighbour_kpts_ct）不筛选：未筛选的公式在筛选后的 SCC 密度上。
  • 非零 γ 表只留 γ ≥ 机器精度的项（B11）：γ 为负的 CAM 参数会被丢掉。测试参数 α = 0.19、β = 0.46，碰不到。

二、探针与原型

原型 m6h3c/micproto.py 在 M6h-3b 的提交 68d342c 上把三个类挂进计算器：MatrixMIC（WS 平移的 KPointHybridTerms）、NeighbourMIC（显式格胞核的卷积）、ScreenedNeighbour 与 ScreenedNeighbourMIC（增量筛选）。参数、容差与 M6h-3b 相同；DFTB+ 的 NeighbourBased 写 Threshold = 1e-100，筛选探针写各自的值。

探针内容结果

三、pydftb 的接口

calc = DFTB(sk_lc, kpts=supercell_folding((2, 2, 2)),
            hybrid={"type": "lc", "coulomb": "minimum_image",          # MatrixBased（默认屏蔽）
                    "wigner_seitz_reduction": 0})
calc = DFTB(sk_lc, kpts=..., hybrid={"type": "lc", "screening": "neighbour",
                                     "coulomb": "minimum_image"})      # DFTB+ 的 NeighbourBased 版本
calc = DFTB(sk_lc, kpts=..., hybrid={"type": "lc", "screening": "neighbour",
                                     "neighbour_threshold": 1e-6})    # DFTB+ 的默认筛选
  • wigner_seitz_reduction：非负整数，只配 coulomb="minimum_image"（其他核报错，DFTB+ 只在 MinimumImage 块里读它）。
  • neighbour_threshold：None（默认）不筛选，与 M6h-3b 相同；给一个非负数即 DFTB+ 的增量筛选，结果依赖 SCC 的历史。只配 screening="neighbour"；分子报错（DFTB+ 不读它）；Γ 点接受但不起作用（同 DFTB+，B16）。
  • 力：MatrixBased MinimumImage 给精确的导数（DFTB+ 拒绝，按你在 M6h-3b 的决定支持，用差分验证）。NeighbourBased MinimumImage 拒绝（B22：它的交换矩阵不是能量的导数，精确的力要解响应方程；DFTB+ 也拒绝）。有筛选时给未筛选公式在 SCC 密度上的值（同 DFTB+）；筛选后的能量依赖历史，没有严格的导数。
  • 自旋：两种 MinimumImage 都支持（DFTB+ 拒绝），力同上。
  • 能带：eigenstates 在任意 k 上建 Hx：MatrixBased 用 WS 平移的 G(k − q)；NeighbourBased 用显式格胞的核按实际 T 求相位；有筛选时是从 ΔP 一次的筛选构建（同 DFTB+ 的能带运行）。
  • 电荷文件与重启：与 M6h-3b 相同（记录与核无关）。

四、实现 开发细节

改动的文件
  • hybrid.py：
    • wigner_seitz_vectors(nfold, cell, reduction)：generateWignerSeitzGrid 的移植（稳定排序）。
    • Hybrid：两个新字段与检查；COULOMBS 不变。
    • KPointHybridTerms：MinimumImage 时平移取 WS 向量、核取完整的 γ（不按距离截断）；其余路径逐位不变。
    • NeighbourMinimumImageTerms(KPointHybridTerms)：在折回原子的坐标系里把 S（CAM 截断以内，加在位单位阵）、PWS 与 γ 放到显式格胞的 L 网格上（Ld = 2(2hmax + gmax) + 1，卷积不混叠），四项 (S⋆P⋆S)∘γ、((S⋆P)∘γ)⋆S、S⋆((P⋆S)∘γ)、S⋆(P∘γ)⋆S 用 FFT；折回 BvK、换回 pydftb 的规范（_bvk_shifted）；fock_at 用显式格胞的相位；力拒绝。
    • 筛选（两个类共用）：状态 ΔPprev、Hprev；按 est 把 p 分组，每组的 q 集合是 est ≥ 某一级的近邻对，四项对每组用 SP、SQ 求；pmax < 1e-16 返回 0（同 DFTB+，B7）；reset 清空状态。
  • calculator.py：去掉 M6h-3c 的拒绝；NeighbourBased MinimumImage 的力拒绝（DFTB+ 的原话加原因）；分子配 neighbour_threshold 报错；_kpoint_hybrid_terms 选类。
  • bands.py：能带用新建的 terms（筛选时一次构建）。
  • validation：hybrid_block 写 WignerSeitzReduction 与 neighbour_threshold（没有时仍是 1e-100）；新算例；refgen 不变。

五、验证 开发细节

  • DFTB+ 参考（约 16 个，小晶胞，DFTB+ 的 NeighbourBased MinimumImage 很慢）：
    • MatrixBased MinimumImage：金刚石 2×2×2、3×1×2、2×2×2 缩小 1、CAM、全局；CO2 2×1×1；三斜 CO 2×2×2；一个能带重启、一个电荷文件重启。
    • NeighbourBased MinimumImage：金刚石 2×2×2 缩小 1；金刚石 2×2×2（SCC 容差放到尾巴分开之前）；一个能带重启。
    • Threshold：金刚石 3×1×2 的 1e-6 与 1e-4、阻尼截断 1e-6；CO2 2×1×1 1e-6；筛选的 MinimumImage 固定 20 轮；一个能带重启。容差按 P86 选，避开爬行的尾巴。
  • 自洽检查（test_hybrid_mic.py）：WS 向量的性质（类覆盖、对称、缩小）；MatrixBased MinimumImage 的力对能量差分，含自旋；闭壳层自旋等于不加自旋；两种 MinimumImage 的第四项相同；自伴性（NeighbourBased 不是）；Threshold 1e-100 等于不筛选；筛选与历史（重置后重复同一序列结果相同）；能带在网格上等于 SCC 的能级；所有拒绝的原话。
  • 门槛：golden 两个环境（基于 M6h-3b 的文档提交 68d342c，新字段 wigner_seitz_reduction、neighbour_threshold 用 --allow-new），refgen（NumPy、torch），dynamics，pytest 三个环境，PTBP 测试，G1。

六、DFTB+ 的问题与 pydftb 的做法

DFTB+ 25.1证据pydftb 的做法
B23（新）：MinimumImage 的 WS 向量是折回原子的坐标系里的格矢，能量随原子怎样折回晶胞而变P89：原子越过晶胞面时金刚石 2×1×1 跳 1.82 Ha（MatrixBased）与 0.073 Ha（NeighbourBased）照 DFTB+（与折回的约定一起），文档写明；差分测试让原子离开晶胞面
B22（新）：NeighbourBased MinimumImage 的交换算符不自伴，WS 只限制每项中 A–B 的密度，与它配对的 M–N 元素不限P84d：23 %；SCC 慢（55–59 轮），力无法从能量得到照 DFTB+ 算能量；力拒绝并说明原因
B9（证实）：WS 边界上的并列向量都以权重 1 计入P83：FCC 2×2×2 19 个向量、8 个类照 DFTB+（这是它的 MinimumImage 的定义）
B10（证实）：MatrixBased 与 NeighbourBased 的 MinimumImage 是不同的近似P84c：金刚石 2×2×2 差 1.1e-3 Ha两种都照 DFTB+；文档写明
筛选（不是错误）：默认 1e-6 时 MinimumImage 的 SCC 不收敛；截断核的 SCC 在容差附近爬行P86、P86b默认不筛选；给阈值时照 DFTB+
B7：ΔPin 不变时返回 H = 0源码；SCC 中未触发照 DFTB+（只在筛选的增量构建里）
B16：Γ 点不用 Threshold源码同 DFTB+

七、不做的事与风险

  • NeighbourBased MinimumImage 的力（需要响应方程，DFTB+ 也没有）。
  • 筛选的构建按 est 分组，组数最多是近邻对数；大体系很慢，只为复现 DFTB+。
  • DFTB+ 的 NeighbourBased MinimumImage 每轮要几十秒，参考只用最小的晶胞；它的 SCC 尾巴对舍入敏感，参考的容差要选在分开之前。
  • B11（负的 γ 被丢）不复现：测试参数碰不到，pydftb 保留所有 γ。
  • MinimumImage 的结果依赖折回（B23），原子越过晶胞面时能量跳变，结构优化与 MD 中不可用；照 DFTB+ 实现只为对照。
