关键信息

M6 的最后一步，包含两件互相独立的事。一是激发态的力：用 Z 向量方法求 E0 + ω 对原子位置的导数，由此可以做激发态的结构优化和分子动力学，并得到激发态的 Mulliken 电荷与偶极。二是 XL-BOMD（扩展拉格朗日的 Born–Oppenheimer 分子动力学）：辅助电荷随原子一起积分，每步只做很少几轮 SCC。只做 NumPy 引擎。

  • DFTB+ 的实测（第二节）：
    • 单重态、三重态、自旋极化、色散：DFTB+ 的激发态力与它自己的 E0 + ω 的差分一致到 2.5e-7 – 5e-7 Ha/Bohr。这是 DFTB+ 用数值差分求 SK 导数带来的误差。
    • DFTB+ 的激发态力在五种组合下不正确，与差分相差：
      • 外电场：1.1e-3 Ha/Bohr；
      • 点电荷：5.4e-3；
      • 能量窗口：3.9e-3；
      • H–X 阻尼：1.3e-4；
      • 按壳层取值的自旋常数：8.8e-6。
      源码中的原因见第一节。
    • DFTB+ 自己的驱动（MD、结构优化）在激发态中使用 E0 + ω：md.out 的势能就是 E0 + ω。
    • XL-BOMD（水二聚体）：
      • Xlbomd 的轨迹与 BO 相同，SCC 总轮数从 582 降到 457；
      • XlbomdFast 每步只做 1 轮 SCC，Scale = 0.5 时稳定，Scale = 1 时发散；
      • MinSccIterations 只对第一步起作用（之后的步收敛判据不看它），而第一步本来就是普通的 BO 步，所以它实际上不起作用。
    • DFTB+ 默认的差分步长是 ε1/4 = 2−13 = 1.2207e-4 Bohr（dftb_pin.hsd 中的 Delta），不是此前验证工具里写的 1.22e-4。两点跨过 SK 网格点时，这点差别使力相差可达 2.4e-8 Ha/Bohr（第二节）。
  • pydftb 的做法：
    • 激发态的力按 E0 + ω 的完整导数实现，上面五种组合里 DFTB+ 漏掉的项都计入：
      • 外加势；
      • 阻尼后的 γ′；
      • 窗口以外的轨道弛豫；
      • 按壳层取值的自旋常数：响应核只用 HOAO 的 W，导数无法精确，这种情况报错。
    • XL-BOMD 照搬 DFTB+ 的积分器、影子能量、力和 SCC 规则。
  • 验证：
    • 主要检查：pydftb 的激发态力与它自己的 E0 + ω 的差分，目标 1e-8 Ha/Bohr。pydftb 的 SK 导数是精确的，所以能做到这个精度。
    • 在 DFTB+ 正确的组合上，与 DFTB+ 的力直接对照，用 DFTB+ 的差分步长复现它的数值导数。
    • 其余组合：参考结果存 DFTB+ 的 E0 + ω 的差分。
    • XL-BOMD：与 DFTB+ 逐步对照轨迹、影子能量和每步的 SCC 轮数。
  • 5DFTB+ 激发态力不正确的组合
  • 1e-8目标：pydftb 的力与自身能量差分之差（Ha/Bohr）
  • 1 轮XlbomdFast 每步的 SCC 轮数

一、DFTB+ 的做法

记号与 M6d 相同：i、j 是占据轨道，a、b 是空轨道，p、q 是任意轨道，ωia = εa − εi，qpqA 是 Mulliken 跃迁电荷，Ω 是激发能。实现在 DFTB+ 的 timedep/linrespgrad.F90（Heringer、Niehaus、Frauenheim，J. Comput. Chem. 28, 2589 (2007)），XL-BOMD 在 md/extlagrangian.F90、md/xlbomd.F90（Niklasson 等；Aradi 等，JCTC 11, 3357 (2015)）。

激发态的力：Z 向量方法

  • 出发点：激发能可以写成 X+Y、X−Y 的二次型：
    • Ω = Σpq Tpq Fpq + 2 (X+Y)T K (X+Y)，F 是基态 Kohn–Sham 矩阵（MO 表象）；
    • T 是未弛豫的差密度：Tab = ½ Σi [(X+Y)ia(X+Y)ib + (X−Y)ia(X−Y)ib]；Tij 为对应的负值形式。
    这个式子对 X±Y 是驻定的，但基态轨道随几何改变（轨道弛豫）。Z 向量方法用一个线性方程代替对每个原子坐标求轨道响应：
    • (A+B)singlet Z = R，R 是 Ω 对轨道转动的导数；
    • (A+B) 是基态的轨道 Hessian，所以三重态也用单重态的 A+B；
    • DFTB+ 用对角预条件的共轭梯度求解，收敛到 |r|² ≤ εdouble²。
  • R 的组成（闭壳层单重态；三重态把 γ 换成 W，自旋极化时前因子减半并加上 W 项）：
    • K 项：−4 Σb (X+Y)ib V[γ ξ]ab + 4 Σj V[γ ξ]ij (X+Y)ja，其中 ξA = Σia (X+Y)ia qiaA；
    • 弛豫项：−4 V[γ q(T)]ia，基态哈密顿量对差密度 T 的响应，三重态也用 γ。
    这里 V[g]pq = ΣA qpqA gA 是原子势 g 在 MO 表象中的矩阵元，q(T) 是 T 的 Mulliken 电荷。
  • 能量加权矩阵 W（占据—占据、空—空、占据—空三块）：
    • 由 X±Y、ε 和 Ω 组成；
    • 加上 4 V[γ q(T)]、4 V[γ q(Z)] 的占据—占据块，以及 Zia εi。
  • 弛豫密度 P = T + ½(Z + ZT)，变换到 AO 表象 C P CT。它的 Mulliken 布居就是激发态电荷的改变 Δqex（DFTB+ getExcMulliken）。
    • XCH.DAT：每个原子的净电荷 −Δq − Δqex；
    • XREST.DAT：偶极 −ΣA RA(ΔqA + ΔqexA)，单位 Debye；
    • 两者都由 WriteMulliken = Yes 打开。
  • 梯度（addGradients，每个原子对一次）：
    • 2 dH0·P；
    • dS·P (VA + VB)；
    • −dS·W；
    • (VexA + VexB) dS·D0，其中 Vex = γ Δqex，D0 是基态密度；
    • 2(γξA + γξB) dS·(X+Y)AO；
    • γ′ 项：(ΔqAΔqexB + ΔqexAΔqB + 4 ξAξB) dγAB/dR；
    • 自旋极化时另有两项：基态自旋势作用在 P 的磁化部分上，以及 W Δmex 作用在基态自旋密度上。
    总的力是 −∇(E0 + Ω)，基态部分照旧。
  • DFTB+ 的五处问题（源码）：
    • 外电场：dS·P 项的位移 V 来自 sccCalc%getShiftPerAtom，其中只有 SCC 势和外部点电荷的势，没有外电场；Δqex·∇Vext 一项也没有。
    • 点电荷：位移里有点电荷的势，但同样没有 Δqex·∇Vpc 一项。
    • H–X 阻尼：γ′ 项用 expGammaPrime，没有阻尼；而响应用的 γ 是有阻尼的。
    • 能量窗口：Z 向量只在窗口内的跃迁上求解（rhs(nxov_rd)）；窗口外的占据—空轨道弛豫被丢掉。
    • 按壳层的自旋常数（ShellResolvedSpin = Yes）：Z 向量的 A+B 用 HOAO 的 W，基态的轨道 Hessian 用整个 W 矩阵。
  • DFTB+ 的限制：
    • 周期体系（“Forces in the excited state for periodic geometries are currently unavailable”）；
    • 分数占据；
    • 没有指定单个态（StateOfInterest = 0）；
    • 振子窗口；
    • onsite 修正（“Excited state property evaluation currently incompatible with onsite corrections”）。
  • 驱动：DFTB+ 在激发态中做 MD 或结构优化时，用的能量是 EMermin + Ω（md.out 的 Potential Energy、优化器打印的 Total Energy）。detailed.out 的 “Total energy” 仍是基态的（M6d 已记录）。

XL-BOMD

  • 思路：辅助电荷 n 像坐标一样随时间积分，用作每一步 SCC 的初值（XlbomdFast 时就是唯一一轮的输入）。积分公式：
    • n(t+δt) = 2n(t) − n(t−δt) + κ s [qout(t) − n(t)] + α Σk=0..K ck n(t−kδt)；
    • 最后一项是使数值噪声衰减的耗散项；
    • K = 5、6、7 各有一组 c、α、κ（K = 7 的 α = 1.6e-3 在源码中是单精度常数）。
  • 阶段：
    1. off：前 PreSteps 步，完整 SCC，下一步从 qout 出发；
    2. fillingUp：K+1 步，完整 SCC，把 qout 存入环形缓冲；
    3. interpolating：TransientSteps 步，完整 SCC，缓冲中的最新值与 qout 线性混合；
    4. on：用 XL 的 SCC 设置。
    前三个阶段的 SCC 用哈密顿量部分的容差和最大轮数。
  • SCC 设置：
    • Xlbomd：MinSccIterations = 1、MaxSccIterations = 200、SccTolerance = 1e-5；
    • XlbomdFast：每步 1 轮 SCC、TransientSteps = 10，Scale ∈ (0, 1]。
    两条通用规则：
    • DFTB+ 在最后一轮 SCC 之后不混合（达到最大轮数时也不混合），所以输出的 n 就是构造 H 的电荷；
    • 第一步之后的收敛判据不看 MinSccIterations：getNextInputCharges 中写的是 iSccIter ≥ minSccIter .or. iGeoStep > 0。
  • 影子能量：
    • E = Eband[D(n)] + ½(2qout − n)·γ·n + E3(n) + v3(n)·(qout − n) + Erep + Edisp，电荷取相对中性原子的偏差；
    • D(n) 来自用 n 构造的 H，md.out 的势能就是它（EMermin）；
    • 旧的 ThirdOrder（只有同一原子项）与 XL 同用时报错（“XLBOMD not working with third order yet”），ThirdOrderFull 可以。
  • 力：在 n 固定时对影子能量求导。
    • 能带部分：用 H[n] 的密度和 V[n]，DFTB+ 跳过了对角化之后用 qout 更新势的那一步。
    • SCC 部分：γ′ 的前因子为 qout,AnB + nAqout,B − nAnB。
    • 三阶部分：同理，是线性化后的形式。
  • ForceEvaluation：三种取值。XL 只接受后两种，DynamicsT0 还要求电子温度为零。
    • Traditional：能量加权密度 Σ f ε c cT；
    • DynamicsT0：½ D H D；
    • Dynamics：½(D H S−1 + S−1 H D)。
    H 就是被对角化的矩阵时，三者在数学上相同，只差舍入。
  • 限制：
    • 不能用热浴、压浴、自旋、+U、onsite、外场、点电荷、溶剂；
    • 只能用 Fermi 展宽；
    • 只能用 DFTB 哈密顿量。

实现过程中的其他发现：

  • 差分步长：DFTB+ 的默认 Delta 是 ε1/4 = 2−13。M2f 以来 validation/dynamics.py 用的是 1.22e-4，相对差 5.8e-4。两点都落在同一段插值多项式上时，力只差约 3e-12 Ha/Bohr；两点跨过 SK 网格点（0.02 Bohr 一个）时，两段多项式的差被 1/(2h) 放大，力相差可达 2.4e-8 Ha/Bohr。水二聚体 XL 轨迹的第 30 步正好如此（O–H 距离离网格点 2e-5 Bohr），使速度相差 1.6e-6 Å/ps。改用 2−13 后，各 XL 轨迹与 DFTB+ 一致到它打印的位数。
  • 能量的位数：detailed.out 只打印 10 位小数，对 DFTB+ 的能量做差分（步长 1e-4 Bohr）会带来约 1e-6 Ha/Bohr 的噪声；autotest.tag 的 mermin_energy 是全精度的 E0 + ω，用它做差分，误差降到 5e-11。
  • 能量窗口下的 XCH.DAT：DFTB+ 的激发态电荷来自只在窗口内求解的 Z，与完整弛豫的电荷相差 4.7e-2 e；对照时用复现 DFTB+ 写法的 _compat 运行。
  • 点电荷受的力：DFTB+ 在激发态中打印的仍是基态的点电荷受力；pydftb 给出 −∇Rpc(E0 + ω)。
  • 自旋极化时的 DynamicsT0：DFTB+ 在每个自旋通道上也取 ½DHD，而通道的占据数是 0 或 1，能量加权密度只有一半，三重态 O2 的力差 0.19 Ha/Bohr；Dynamics 是对的。pydftb 用 DHD / fmax。

三、pydftb 的接口

calc = DFTB(sk, casida=Casida(6, state_of_interest=2))   # excited_forces 默认为 True
r = calc.calculate(labels, positions)        # r.forces = −∇(E0 + ω2)
r.excited_energy, r.excited_free_energy      # E0 + ω（r.energy 仍是基态，同 DFTB+ 与 M6d）
r.excited_charges                            # 激发态的 Mulliken 布居（电子数，同 r.charges）
r.excited_dipole                             # 激发态偶极（e·Bohr）
Casida(6, state_of_interest=2, excited_charges=True)   # 不算力时也求激发态电荷（WriteMulliken）

# ASE：能量取 E0 + ω，与力一致，可直接做激发态的结构优化和 MD
atoms.calc = PyDFTB(skdir, casida={"n_excitations": 6, "state_of_interest": 1})

# XL-BOMD：每次计算是一个 MD 步，积分器的状态保存在计算器里
from pydftb.xlbomd import XLBOMD
atoms.calc = PyDFTB(skdir, xlbomd=XLBOMD(integration_steps=5, scc_tol=1e-6))
VelocityVerlet(atoms, 0.5 * units.fs).run(100)
PyDFTB(skdir, xlbomd=XLBOMD(fast=True, scale=0.5))       # 每步 1 轮 SCC
  • 激发态的力：
    • 适用范围：分子，整数占据，一个态（state_of_interest > 0 或最亮态）；
    • 单重态、三重态、共线自旋极化；
    • 可以与外电场、点电荷、格点势、色散、H–X 阻尼、能量窗口同用（pydftb 的导数是完整的）。
    • 报错的情况：
      • 与 DFTB+ 相同：周期体系、分数占据、振子窗口、onsite 修正；
      • pydftb 自己加的：自旋常数按壳层取不同值（自旋极化时）；
      • 与 XL-BOMD 同用。
    • excited_forces=False 返回基态的力，与 M6d 相同。
  • 能量的约定：
    • DFTBResult.energy 与 free_energy 仍是基态的，与 DFTB+ 的 detailed.out 一致；
    • 新字段 excited_energy、excited_free_energy 给出加上 ω 的值；
    • ASE 计算器在算激发态的力时，把 E0 + ω 作为 energy 和 free_energy，与 DFTB+ 的驱动相同，优化器和 MD 看到的能量与力一致。
  • XL-BOMD：
    • XLBOMD 的参数与 DFTB+ 的 Xlbomd/XlbomdFast 一一对应：integration_steps、pre_steps、min_scc、max_scc、scc_tol；fast=True 时另有 transient_steps、scale；
    • 阶段 off、fillingUp、interpolating 的 SCC 用计算器自己的 scc_tol、max_scc；
    • 能量是影子能量（与 DFTB+ 的 md.out 相同）；
    • force_evaluation 默认在 T = 0 时取 "dynamics_t0"，否则取 "dynamics"；明确写 "traditional" 时报错，与 DFTB+ 相同；
    • 限制与 DFTB+ 相同；
    • 积分器假定每次计算就是下一个 MD 步（ASE 的 VelocityVerlet），calc.reset() 重新开始。
  • 引擎层：DFTB.calculate(…, scc_control=SCCControl(min_iter, max_iter, tol), xl=True) 是 XL-BOMD 的底层入口，给出一步的 SCC（最后一轮之后不混合）和影子能量与力；force_evaluation 也可以单独用于普通计算（DFTB+ 的 ForceEvaluation）。
开发细节四、实现

激发态的力

  • casida.py（数值不变）：
    • Excitations 增加 xmy（X−Y = F√(Ω/ωia)）；
    • excitations() 内部拆出求解部分，供梯度复用同一组本征向量。
  • 新模块 casida_grad.py：全部在稠密的 MO/AO 矩阵上做，不需要大的跃迁电荷数组。
    • mo_potential(g) = ½ CT(G S + S G) C，即 V[g]；mulliken(D) 按原子求和 (D∘S)·1。
    • X±Y 放到 N×N 的占据—空块，T、W 的各块是矩阵乘积。
    • Z 向量：(A+B) 的乘积为 ω∘Z + 4 V[γ q(Z)]ov（自旋极化时为 2 倍，再加 W 项）。
      • 在全部占据—空轨道对上求解，不受窗口限制；
      • 轨道对不超过 EXACT_LIMIT 时组装矩阵直接解，否则用对角预条件的 CG，收敛到机器精度。
    • 输出 Relaxed(P_ao, W_ao, dqex, xi, xpy_ao, …)，以及原子对元素上的 dS 系数。
  • calculator.py：
    • 把 _gradient 中按原子对求和的三行抽成 _add_pair_terms(st, grad, p_e, coef_s)，运算顺序不变，旧路径逐位相同。
    • 激发态部分：P 代替 ρ，W 代替能量加权密度，dS 系数中加入第一节的各项；位移用基态的完整势（_potentials 已包含外场、点电荷、格点势）。
    • γ′ 项用 Coulomb.gradient(dq, other=dqex)（新参数，求 ½ dq·γ·dqex 的导数，与 gradient 用同一个有阻尼的 γ）和 gradient(ξ)。
    • 外加势加上 ext.gradient(dqex)。
  • 测试专用：_compat 集合（"external"、"damping"、"window"）按 DFTB+ 的写法去掉相应的项，用来证明与 DFTB+ 的差别正好来自这几处。
  • torch 后端和自动求导遇到激发态的力或 XL-BOMD 时报错。

XL-BOMD

  • SCCControl：最少轮数、最多轮数、容差；收敛或达到最多轮数时停在构造 H 的那组输入电荷上，不再混合；不收敛时不警告（XL 的正常情况）。
  • XL 模式（xl=True）：
    • 能量：SCC 项 qout·γ·n − ½ n·γ·n；三阶项 E3(n) + v3(n)·(qout − n)；其余项照旧。
    • 力：位移用 V[n]；SCC 项为 2·gradient(q_out, other=n) − gradient(n)；三阶项用新的 ThirdOrder.gradient_xl(n, q_out)。
  • force_evaluation：_dynamics_wdm 按 DFTB+ 的公式求 ½DHD 或 ½(DHS−1 + S−1HD)（实现时发现自旋通道上应为 DHD，见第二节）。
  • 新模块 xlbomd.py：
    • ExtLagrangian：照搬 DFTB+ 的环形缓冲、系数表、四个阶段、插值，运算顺序与 Fortran 相同；
    • XLBOMD：选项和每个阶段的 SCC 设置；
    • DFTB+ 的规则：第一步之后最少轮数取 1。
  • ase_calc.py：PyDFTB(xlbomd=…, force_evaluation=…) 每次计算传入积分器给出的 n，再把 qout 交给积分器。

验证工具

  • dftbplus.py：写 WriteMulliken、ExcitedStateForces；解析 XCH.DAT、XREST.DAT；md_driver 加 XL 块，HSD 加 ForceEvaluation。
  • refgen.py：
    • casida_options 不再写死 excited_forces=False；
    • 参考结果可存 forces_fd：对 DFTB+ 的 E0 + ω 做四点中心差分，全部 3N 个分量，步长 1e-4 Bohr。
  • dynamics.py：新的 DynCase（激发态 MD 与优化、各种 XL）；XL 的比较同时用 ASE 的 VelocityVerlet 和 verlet_dftbplus_units，并比较每步的 SCC 轮数。
开发细节五、验证计划

自洽测试（不需要 DFTB+）

  • 激发态力与 pydftb 自己的 E0 + ω 的中心差分，目标 ≤ 1e-8 Ha/Bohr。覆盖：
    • 单重态、三重态、自旋极化、最亮态；
    • 外场、点电荷、格点势、色散；
    • H–X 阻尼、能量窗口。
  • Z 向量：稠密解与 CG 一致；P 的迹为零（激发不改变电子数）。
  • 平移、转动不变：力之和为零，力矩为零。
  • XL-BOMD：
    • 系数表、阶段转换与 DFTB+ 一致；
    • 环形缓冲与写开的递推公式一致；
    • 影子能量的力和应力与它自己的差分一致（n 固定）；自洽时影子能量等于能量，三种力的算法给出相同的力。

  • refgen --check（Casida 算例分别用三种求解器）、dynamics --check；

六、不做的事与风险

  • 不做（按需再说）：
    • 非绝热耦合向量（StateCouplings）和锥形交叉优化；
    • 多个态同时求力（本机 DFTB+ 不支持，CHANGELOG 的未发布部分才有）；
    • 周期体系、分数占据、onsite 修正的激发态力；
    • 自旋、+U、外场下的 XL-BOMD；XL-BOMD 的热浴。
  • 风险：
    • Z 向量的符号和因子 2：以 pydftb 自己的精确差分为主要检查，DFTB+ 只在它正确的组合上直接对照。
    • 激发态 MD 中的态交叉：参考算例选短轨迹、离交叉远的态。
    • XL 轨迹长时间后混沌地分开：只比较 ≤ 60 步，并逐步比较 SCC 轮数。
    • 旧路径被改动：scc_control=None、xl=False、force_evaluation="traditional" 走原来的代码；golden 逐位比较。
