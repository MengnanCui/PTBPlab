关键信息

M6 的第四步：激发态。DFTB 的线性响应（TD-DFTB，Casida 方程）在基态 SCC 收敛之后进行：用基态的轨道、轨道能和原子间的 γ 矩阵，求分子的垂直激发能、振子强度和跃迁偶极，也就是吸收光谱。只做 NumPy 引擎；torch 后端和自动求导遇到时明确报错。

  • 拆分：原计划的 M6d 还包括激发态的力和 XL-BOMD。读完 DFTB+ 的源码后，按原计划“量大时单列”的约定拆开：
    • M6d（本阶段）：激发态本身，即能量、振子强度、跃迁偶极及相关输出。
    • M6e（下一阶段）：激发态的力（Z 向量方法）、激发态的电荷与偶极、激发态的结构优化与分子动力学，以及 XL-BOMD。
    理由：Z 向量的力占 DFTB+ 线性响应代码的一半以上（linrespgrad.F90 5800 行中的大部分）；XL-BOMD 是一套独立的机制（影子能量、动力学型的力），与激发态无关。
  • 做什么（全部对照 DFTB+ 25.1 的 ExcitedState { Casida }）：
    • 单重态、三重态、两者（Symmetry）；共线自旋极化体系的激发（带自旋污染 Δ⟨S²⟩）；
    • 分数占据（有电子温度时，部分占据能级之间的跃迁）；onsite 修正；Γ 点周期体系；
    • 能量窗口和振子窗口（缩小参与耦合的单粒子跃迁）；“最亮态”（StateOfInterest < 0）；
    • 与 DFTB+ 输出文件对应的内容：EXC.DAT（激发能、振子强度、主要跃迁、权重、对应的单粒子能量、对称性或 Δ⟨S²⟩）、SPX.DAT（单粒子跃迁）、TRA.DAT、TDP.DAT（跃迁偶极），以及 X+Y 向量。
  • DFTB+ 的实测（第二节）：
    • DFTB+ 的两种迭代求解器（ARPACK、Stratmann）在小分子上给出相同的 ω²（差 ≤ 1e-15）。pydftb 在跃迁不多时对整个 Casida 矩阵做精确的稠密对角化，另备迭代解法给大体系（实现时定为分块 Davidson，见完成报告）。
    • DFTB+ 不允许：非 SCC、DFTB3、k 点（只能 Γ 点）、壳层分辨 SCC、非共线自旋、SOC、DFTB+U、隐式溶剂；onsite 修正只能配 ARPACK。外电场、点电荷、色散可以同用（只影响基态）。pydftb 照此限制。
    • 在 StateOfInterest 非零时，DFTB+ 写在 results.tag 和 detailed.out 里的 “Total energy”、“Mermin free energy” 仍是基态能量，激发能另行打印为 “Excitation Energy”（与手册的说法不同）。
    • 为 M6e 先做的检查：DFTB+ 的激发态力（单重态、三重态、自旋极化）与 E0 + ω 的有限差分一致到 3e-7 Ha/Bohr。
    • 含部分占据 d 能级的金属团簇（Cu4CO，300 K）上，DFTB+ 的两个求解器都失败（ARPACK 迭代次数用尽、Stratmann 子空间对角化失败）。pydftb 的精确对角化不受影响。
  • 用法：DFTB(sk, casida=Casida(n_excitations=6, symmetry="singlet"))，结果在 result.excitations（能量用 Ha，偶极用 e·Bohr）；ASE 中 PyDFTB(…, casida=…)。
  • 验证：约 15 个 DFTB+ 参考算例。从 autotest.tag 取全精度的 ω²、振子强度和跃迁偶极大小，从 EXC.DAT、SPX.DAT 取主要跃迁、权重和 Δ⟨S²⟩。旧算例逐位不变。
  • 1e-15DFTB+ 的 ARPACK 与 Stratmann 求解器之间的差（ω²，Ha²）
  • 3自旋情形：单重态、三重态、自旋极化
  • ≈ 15计划的 DFTB+ 参考算例

一、DFTB+ 的做法

下文 i、j 是占据轨道，a、b 是空轨道，ωia = εa − εi 是单粒子跃迁能，c 是基态轨道系数，S 是交叠矩阵，A、B 是原子。实现在 DFTB+ 的 timedep/linresp.F90、linrespgrad.F90、linrespcommon.F90、transcharges.F90，方法来自 Niehaus 等（Phys. Rev. B 63, 085108 (2001)）。

单粒子跃迁

  • 所有 fi > fa 的能级对都算一个跃迁（按自旋通道分开）。有电子温度时，部分占据的能级既是“占据”也是“空”，它们之间的跃迁也计入。按 ωia 从小到大排序。
  • 占据数因子 nia = fi − fa，闭壳层再除以 2（占据数 0…2），程序中用的是 √nia。
  • 跃迁电荷（Mulliken 近似）：qiaA = ½ Σμ∈A [cμi(Sca)μ + cμa(Sci)μ]。同一原子上 s、p 轨道之间的跃迁电荷为零，所以这类跃迁（例如水分子 HOMO 的 p 孤对到 LUMO）不与其他跃迁耦合，激发能就等于单粒子能量差，振子强度为零。
  • 单粒子跃迁偶极 dia = ΣA RA qiaA，单粒子振子强度 (2/3) ωia |dia|²（SPX.DAT）。

Casida 矩阵

  • 厄米形式：Ω F = ΩI² F，Ωia,jb = δia,jb ωia² + 4 √(niaωia) Kia,jb √(njbωjb)。ΩI 是第 I 个激发能。
  • 单重态：K = ΣAB qiaA γAB qjbB。三重态：K = ΣA qiaA WA qjbA（W 是原子的自旋常数，所以三重态需要 SpinConstants）。
  • 自旋极化（共线）：两个自旋通道的跃迁放在一起，前因子从 4 变为 2，K = ΣAB q γ q + σsσt ΣA q WA q（σ = ±1 表示自旋向上、向下）。
  • γ：原子分辨的 γ 矩阵（库仑 1/r 部分加短程部分；周期体系为 Ewald 和），即基态 SCC 用的 γ。DFTB+ 要求原子分辨 SCC，这时所有壳层用 s 壳层的 U。
  • W：每种元素取“最高占据原子轨道”所在壳层的对角元 W(lHOAO, lHOAO)（initprogram.F90：参考占据数不为零的壳层中，原子本征值最高的那个）。
  • onsite 修正（onsiteEner）：把跃迁密度在每个原子上的轨道块 ½[cμi(Sca)ν + …] 与 onsite 常数矩阵收缩，再对每个壳层的对角元减去平均值（转动不变性修正）。闭壳层单重态用 f↑↑ + f↑↓，三重态用 f↑↑ − f↑↓；自旋极化时同自旋用 f↑↑、异自旋用 f↑↓。

求解与输出

  • 求解器：ARPACK（对 Ω 求最小的几个本征值，相对容差为单精度的 ε ≈ 1.2e-7）和 Stratmann（在 A+B、A−B 的子空间中迭代，残差阈值 1.2e-8）。两者都只求 NrOfExcitations 个最低的态。
  • X+Y = F √(ωia/ΩI)，F 是归一化的本征向量；X−Y = (X+Y) ΩI/ωia。
  • 跃迁偶极 μI = Σia dia √nia (X+Y)ia,I，闭壳层乘 √2；振子强度 fI = (2/3) ΩI |Σ d √n (X+Y)|²，闭壳层乘 2。闭壳层的三重态振子强度为零。
  • 主要跃迁与权重：wia = (X+Y)ia² / ‖(X+Y)²‖2，取最大的一个（EXC.DAT 的 Transition、Weight、KS [eV] 三列）；TRA.DAT 列出全部跃迁的权重。
  • 自旋污染（自旋极化时 EXC.DAT 的最后一列 Δ⟨S²⟩）：由归一化的 X+Y 和不同自旋轨道之间的交叠 ⟨φp↑|φq↓⟩ 组成三项之和（García 的博士论文），DFTB+ 认为绝对值小于 0.5 的态可信。
  • 窗口：EnergyWindow 只保留 ωia ≤ ωN + 窗口的跃迁（N = NrOfExcitations）；OscillatorWindow 再把更高的、按能级简并分组后振子强度之和超过阈值的跃迁加进来。窗口会改变激发能（参与耦合的跃迁变少）。
  • 最亮态：StateOfInterest < 0 时取振子强度最大的单重态。
  • 简并：简并能级中各个态的振子强度取决于本征向量的任意组合，只有和有意义。autotest.tag 中简并的态合并为一个（能量取一个，振子强度相加）。

二、DFTB+ 25.1 的实测行为

参数为测试用的 ptbp_hcocu（H、C、O、Cu），探针脚本在会话的临时目录（m6d/probe*.py）。

试验结果
H2O、H2CO、C2H4、CH3OH，单重态与三重态，两种求解器ω² 相差 ≤ 1e-15，振子强度 ≤ 7e-9（CH3OH，ARPACK 的容差）。对称禁戒的态振子强度为 1e-30 量级的数值噪声。H2CO 最低的 n→π* 态（2.708 eV）单重态与三重态相同，等于单粒子能量差（跃迁电荷为零）。
autotest.tag需要 Options { WriteAutotestTag = Yes }。内容：exc_energies_sqr（Ω²）、exc_oscillator，以及（开启 WriteTransitionDipole 时）exc_transdip（|μ|）。简并的态合并（苯：8 个态只剩 4 个值）。Symmetry = both 时只保留后算的单重态，三重态只在 EXC.DAT 中。
自旋极化（H2CO+ 二重态、O2 三重态）可以计算；EXC.DAT 最后一列为 Δ⟨S²⟩，不再标 S/T。
电子温度 3000 K（H2CO）出现部分占据能级之间的低能跃迁（0.57 eV 等），振子强度大多为零。
onsite 修正ARPACK 可用；Stratmann 报错 “Onsite corrections not implemented for Stratmann diagonaliser”。
Γ 点周期（H2CO 在 8 Å 的立方盒子中）可以计算激发能（与孤立分子差 0.01 eV 左右）；打开力时报错 “Excited state stresses not implemented”。
能量窗口 2 eV、振子窗口 0.01参与耦合的跃迁变少，高处的激发能改变（H2CO 第 4 个态 6.570 → 7.908 eV）。
外电场、点电荷、Lennard-Jones 色散都可以与 Casida 同用，激发能随基态改变；激发态的力也能运行（正确性在 M6e 中检查）。
Cu2、CuH、CuCO+（T = 0）正常，覆盖 d 轨道之间的跃迁；CuH 的简并态合并后只剩 3 个值。
Cu4CO（300 K，部分占据的 d 能级）ARPACK：“Maximum number of iterations reached”；Stratmann：“TDDFT diagonalisation failure. Increase SubSpaceFactor”（加大到 60 仍失败）；T = 0 时基态 SCC 不收敛。
StateOfInterest = 4（H2CO，单重态）detailed.out 的 “Total energy” 与 results.tag 的 mermin_energy 都是基态能量（Eelec + Erep），激发能单独打印为 “Excitation Energy: 0.2365 H”。DFTB+ 的激发态力与 E0 + ω 的中心差分一致到 1.3e-7 – 3.2e-7；三重态（第 2 个态）3.7e-7，Stratmann 1.4e-7，自旋极化的 H2CO+ 3.0e-7。
不计算力时写 ExcitedStateForces输入错误（该节点不被读取）；计算力而 StateOfInterest = 0 时，必须写 ExcitedStateForces = No，否则报错 “Excited forces only available for StateOfInterest non zero”。

三、pydftb 的接口

from pydftb.casida import Casida

calc = DFTB(sk, temperature=0.0,
            spin_constants={"H": -0.072, "C": -0.023, "O": -0.028},   # 三重态或自旋极化时需要
            casida=Casida(n_excitations=6, symmetry="singlet"))        # "triplet"、"both"
r = calc.calculate(labels, positions)
x = r.excitations
x.energies                  # (n,) Ha
x.oscillator_strengths      # (n,)
x.transition_dipoles        # (n, 3) e·Bohr
x.symmetries                # "S" / "T"；自旋极化时为 None
x.transitions, x.weights    # 主要的单粒子跃迁 (i, a, 自旋)，从 0 起；权重
x.spin_contamination        # 自旋极化时的 Δ⟨S²⟩
x.single_particle           # SPX：单粒子跃迁能、振子强度、(i, a, 自旋)
x.xpy                       # (跃迁数, n) X+Y
print(x.table())            # EXC.DAT 格式的文本

Casida(n_excitations=10, energy_window=0.05, oscillator_window=0.01,   # Ha；无量纲
       state_of_interest=-1,                                           # 最亮的单重态
       solver="auto")                                                  # "exact"、"davidson"、"arpack"
  • 单位：能量 Ha，偶极 e·Bohr；table() 与 DFTB+ 一样用 eV。
  • 求解器："exact" 对整个 Ω 做稠密对角化，只取最低的 n 个本征对；"davidson"（分块 Davidson）与 "arpack"（SciPy 的 ARPACK）用不存储 Ω 的矩阵—向量乘积，供跃迁数很多的体系使用；"auto"（默认）按跃迁数选择，500 个以内用稠密对角化。（设计时只有 "exact" 与基于 ARPACK 的 "iterative"，实现时按实测改为现在的样子，见完成报告第八节。）
  • state_of_interest：大于 0 时，r.excitation_energy 给出该态的激发能（DFTB+ 的 “Excitation Energy”）；能量的其他字段仍是基态，与 DFTB+ 相同。M6d 中这时要求力就报错，提示 M6e；Casida(excited_forces=False) 返回基态的力（DFTB+ 的 ExcitedStateForces = No）。
  • 限制（与 DFTB+ 相同）：需要 SCC；不能与 DFTB3、壳层分辨 SCC、非共线自旋、SOC、DFTB+U、隐式溶剂同用；周期体系只能用 Γ 点。onsite 修正可以用（DFTB+ 只在 ARPACK 中支持）。外电场、点电荷、色散可以用。
  • 其他入口：api.SCC(…, casida=…)；ASE 的 PyDFTB(…, casida=…)，结果在 calc.excitations。
开发细节四、实现

新模块 pydftb/casida.py

  • Casida：选项与检查。Excitations：结果（上表的字段，加 EXC.DAT 格式的 table()；SPX.DAT 格式由 single_particle.table() 给出）。
  • single_particle_transitions(eps, f, spin)：按 DFTB+ 的规则列出跃迁（fi > fa + 容差），排序（有振子窗口时用稳定排序，同 DFTB+ 的 merge_sort）。
  • transition_charges(c, sc, orb_atom, pairs)：按原子分段求和，向量化，得到 (跃迁数, 原子数) 的矩阵。onsite 修正另需每个原子的跃迁密度块。
  • omega_matrix(...)：组装 Ω（单重态、三重态、自旋极化、onsite）；omega_product(v)：不组装矩阵的乘积，复杂度为（跃迁数 × 原子数）。
  • 求解：scipy.linalg.eigh(Ω, subset_by_index=[0, n−1])；迭代时用分块 Davidson（以 ωia² 为预条件）或 scipy.sparse.linalg.eigsh（LinearOperator，which="SA"），Ω 是对称正定的。
  • 性质：X+Y、振子强度、跃迁偶极、权重与主要跃迁、单粒子振子强度、Δ⟨S²⟩、窗口、最亮态，公式与第一节相同。

引擎（calculator.py）

  • DFTB(…, casida=None)：检查限制；新字段 DFTBResult.excitations、excitation_energy，默认 None，旧算例没有新属性。
  • _run 在能量之后调用 Casida：用最后一轮 SCC 的哈密顿量 sc.h（DFTB+ 也用最后一轮对角化的本征向量）和交叠矩阵重新求本征向量（广义本征问题），占据数取自 sc.occ，γ 取自 st.coul.gamma（原子分辨时站点就是原子），W 由自旋常数和 HOAO 规则得到，onsite 常数取自块势的设置。
  • Γ 点周期体系：用 Γ 点的 H、S（实数）；有 k 点时报错。
  • torch 后端、自动求导：报错（“NumPy backend only (milestone M6d)”）。

数值上的注意

  • 简并轨道的本征向量与 DFTB+ 不同（任意组合），激发能不受影响；单个态的振子强度、跃迁偶极的分量可能不同，只比较简并组的和与 |μ| 的和。
  • X+Y 的整体符号任意：比较 |μ| 和振子强度，跃迁偶极的分量比较绝对值。
  • 负的 Ω²（基态不稳定）：DFTB+ 在 EXC.DAT 中写 “< 0”；pydftb 保留负值并给出警告。

比较的量与容差

  • 基态部分照旧（能量、电荷、SCC 轮数）。
  • autotest.tag：Ω²（按简并组）、振子强度（组内求和）、|μ|：1e-8（量纲为 Ha²、无量纲、e·Bohr）。基态本征值与 DFTB+ 差 1e-11 左右，传到激发能也在这个量级。
  • EXC.DAT：每个态的激发能（3 位小数，eV）、主要跃迁、权重（3 位小数）、单粒子能量、对称性或 Δ⟨S²⟩（3 位小数）；SPX.DAT：单粒子跃迁能、振子强度。Symmetry = both 的三重态只能这样比较。
  • “最亮态”：选中的态号与 detailed.out 的 “Excitation Energy”。

自洽测试（不需要 DFTB+）

  • 精确解与迭代解一致；Ω 对称；(X+Y)T(X−Y) = 1。
  • 极限：γ 和 W 都为零时激发能等于单粒子能量差；闭壳层的三重态在 W = 0 时等于单粒子能量差。
  • 分子整体平移、转动：激发能、振子强度不变，跃迁偶极随之转动。
  • 自旋极化路径用于闭壳层分子（未成对电子为 0）时，激发能是单重态与三重态的并集，Δ⟨S²⟩ 区分两者。
  • torch 后端、自动求导报错；不允许的组合报错。

门槛

golden（两个环境逐位相同，新属性 excitations、excitation_energy 用 --allow-new）；refgen --check（NumPy；新算例跳过 torch）；三个环境的 pydftb 测试；PTBP 测试；engine_parity。

六、不做的事与风险

  • 放到 M6e：激发态的力（Z 向量）、激发态的 Mulliken 电荷与偶极（XCH.DAT、XREST.DAT，也来自 Z 向量）、激发态的结构优化与 MD、非绝热耦合向量（StateCouplings）、XL-BOMD。
  • 不做：长程校正（LC-DFTB）的激发态（需要专门的 SKF）；pp-RPA（ExcitedState { PP-RPA }）；锥形交叉优化；激发态的自然轨道与系数文件（COEF.DAT、excitedOrbs）——按需再做。
  • 风险：
    • 简并与相位：只比较简并组的和与大小，单个态的分量不比较。
    • 窗口与排序：振子窗口时 DFTB+ 用稳定排序，简并的单粒子跃迁的顺序会影响选中的跃迁；pydftb 照搬排序规则，按简并组选取。
    • 大体系：Ω 的大小是跃迁数的平方（1 万个跃迁约 0.8 GB），需要用迭代解法；默认的 "auto" 在超过阈值（500 个跃迁）时切换到 Davidson。
    • DFTB+ 在 Cu4CO 一类体系上失败，这类体系不放进参考算例，只做 pydftb 的自洽测试。
