关键信息

M6f 的第三块：DFTB+ 的三项修正。H5 修正氢键（HCorrection = H5），卤素修正修正 DFTB3 中 O/N 与 Cl/Br/I 之间的相互作用（HalogenXCorr），偶极修正抵消平板计算中沿法向的人为偶极场（DipoleCorrection）。只做 NumPy 引擎；不用这些选项时逐位不变。

  • DFTB+ 的做法（第一节）：
    • H5 只改 γ 的短程部分：含一个 H 的原子对乘以 1 + g(r)，g 是以 0.714 倍范德华半径和为中心的高斯；
    • 卤素修正是只依赖几何的对势，在 0.7–0.8 倍范德华半径和之间用 7 次多项式开关；
    • 偶极修正在真空中放一层偶极，能量 E = 2πD²/V 记在 ESCC 里，D 是平板沿 z 的偶极。
  • 探针中的发现（第二节）：
    • DFTB+ 的激发态梯度漏了 H5（激发能里却有），激发态的力与 E0 + ω 的差分差 4.1e-3；XL-BOMD 的梯度也漏了 H5；
    • 卤素修正在开关区间内，梯度中 dσ 那两项的符号反了，力差 4.5e-3；按反号的公式能把 DFTB+ 的力重现到 8e-17；
    • 25.1 拒绝周期体系的卤素修正，25.1 也没有偶极修正：这两项用自编的开发版 DFTB+（041e723）对照。开发版在 13 个已有算例上与 25.1 的参考结果一致（能量逐位相同，力差 ≤ 3.4e-14）；
    • 偶极修正没有应力项：DFTB+ 的应力恰好差 (E/V)·diag(1, 1, −1)；晶格检查只看第三个晶格矢量，a1 带 z 分量的晶胞也照算。
  • pydftb 的接口（第三节）：DFTB(h5=True | {…})、DFTB(halogen_correction=True)、DFTB(dipole_correction=True | {"layer_position": z0})；结果加 e_halogen、e_dipole_corr。默认给出正确的力和应力；需要时用测试专用的开关复现 DFTB+ 的错误，证明差别只在这些项上。
  • 3DFTB+ 的修正项：H5、卤素修正、偶极修正
  • 4.5e-3卤素修正开关区间内 DFTB+ 的力与其能量差分之差（Ha/Bohr）
  • 14DFTB+ 参考算例（其中 3 个用开发版，1 条 MD）

一、DFTB+ 的做法

源码为 DFTB+ 的 041e723（dftb/h5correction.F90、dftb/shortgamma.F90、dftb/halogenx.F90、dftb/vdwdata.F90、dftb/dipolecorr.F90、dftbplus/parser.F90、dftbplus/initprogram.F90）。前四个文件与 GitHub 上 25.1 的同名文件逐行相同（只差一行注释）；dipolecorr.F90 在 25.1 之后才有。规则都用二进制的探针确认过。

H5 氢键修正

  • 写法：Hamiltonian = DFTB { HCorrection = H5 { RScaling = 0.714; WScaling = 0.25; H5Scaling { O = 0.06; N = 0.18; S = 0.21 } } }。在 SCC 块中读，不要求三阶。HCorrection 只有一个值，所以 H5 与 H–X 阻尼（HCorrection = Damping）不能同时写。
  • 公式：γ = 1/r − S(r)，H5 只改短程部分 S：
    • S′ = S(1 + g) − g/r，也就是 γ′ = γ(1 + g)；
    • g = k·exp(−(r − r0)²/(2c²))，r0 = RScaling·(RH + RX)，c = WScaling·(RH + RX)/(2√(2 ln 2))（WScaling 乘半径和是半高全宽）；k 是受体元素的缩放；
    • 导数 dS′/dr = (dS/dr)(1 + g) + S·dg/dr − (dg/dr)/r + g/r²；
    • 短程截断不变：截断处 g 约为 e−60。
  • 哪些原子对：
    • 正好一个原子的物种名是 “H”，另一个的缩放 > 0，并且查得到它的范德华半径；
    • 缩放的默认值按物种名精确匹配 O、N、S，其余为 −1（不修正）；
    • 半径用 Mantina 等人的表（pm × 0.01 × AA__Bohr），按物种名的前两个字符、不分大小写查。所以物种名 O2 得不到 H5：没有默认值，在 H5Scaling 里给了也查不到半径，只给警告；
    • 没有 H 原子时报 “H5 correction used without H atoms present”（这项检查按质量 < 3.5 amu）。
  • 用到 H5 的地方：SCC 的 γ 与势、力、应力（addGradientsDc、addStressDc），周期体系 Ewald 的短程部分，Casida 的 γ 矩阵（addAtomicMatrix），M6g 要用的耦合微扰导数。三阶不用 H5（thirdorder.F90 只有阻尼）。
  • DFTB+ 的错误：
    • 激发态梯度（linrespgrad）直接调用 expGammaPrime，既漏了阻尼也漏了 H5，而激发能用的 γ 矩阵含 H5；
    • XL-BOMD 的梯度（addGradientsDcXlbomd）漏了 H5。

卤素修正

  • 写法：HalogenXCorr = Yes，写在 DFTB 块中。只在有 ThirdOrder 或 ThirdOrderFull、并且同时有 O/N 与 Cl/Br/I 物种时才读；否则这个节点“未处理”，DFTB+ 报错退出。
  • 原子对：O–Cl、O–Br、O–I、N–Cl、N–Br、N–I，按物种名精确匹配。
  • 能量（kcal/mol 与 Å）：
    • Epair = c1[σ·e−c2(r−d)c3 + (1 − σ)·e−c2(0.7R−d)c3]，R 是两个范德华半径之和；
    • σ = −20x7 + 70x6 − 84x5 + 35x4，x = (r − 0.7R)/(0.1R)；r < 0.7R 时为 0（能量取常数），r > 0.8R 时为 1；
    • d：O–Cl 1.237、O–Br 1.099、O–I 1.313、N–Cl 1.526、N–Br 1.349、N–I 1.521 Å；c = (7.761, 0.050, 4.518)；
    • 每个原子分一半；总能量包含它，detailed.out 另有一行 “Halogen correction energy”；
    • 截断 = 体系中出现的原子对的最大 d + 4.2245 Å，截断处的对能不超过 2e-14 kcal/mol。
  • DFTB+ 的错误：
    • 开关区间内，梯度中 dσ 的两项符号反了：源码是 +σ′[f(r) − f(0.7R)]，正确的是 −σ′[f(r) − f(0.7R)]。应力用同一个导数，同样错（dx/dR 的因子 halogendSigma 已经除了，不缺）；
    • r < d 时 (r − d)4.518 是 NaN，σ = 0 也乘不掉；成键的 O–Cl、N–I 等都比 d 长，实际很少遇到；
    • 25.1 的解析器只在非周期体系中读 HalogenXCorr；开发版改成在周期体系中只给警告 “Halogen correction was not fitted for periodic systems in original paper”。

偶极修正

  • 写法（只有开发版）：Hamiltonian = DFTB { DipoleCorrection { DipoleLayerPos [AA] = 5.0 } }，层的位置默认 −h/2。
  • 公式：
    • h = a3,z，V = det(a)；折叠后的 z：zf = mod(z − z0, h) + z0，层的中心 zc = z0 + h/2；
    • D = ΣA ΔqA(zf,A − zc)，势 VA = (4π/V)·D·(zf,A − zc) 与其他 SCC 势一样进入 H 和力的 dS 项；
    • E = ½ΣA ΔqAVA = 2πD²/V，计入 “Energy SCC”，不单独打印；
    • 显式梯度 ∂E/∂zA = (4π/V)·D·ΔqA；
    • 中性体系中 zc 消掉，所以只要没有原子跨过层，层放在哪里、输入坐标落在哪个周期像上，结果都相同（z0 与 z0 + h 等价，手册写的 c/2 与代码的 −c/2 也等价）。
  • 检查：只用于周期体系；每次更新电荷都要求 |ΣΔq| ≤ 1e-7；晶格检查用的是 matmul(latVecs, e_z)，即第三个晶格矢量的三个分量，实际只要求 a3 ∥ z。
  • DFTB+ 的错误：
    • 没有应力项（addStressDc 不含它）；
    • 不检查 a1、a2 有没有 z 分量，与报错文字和手册（“正交晶胞”）都不符；
    • 外部点电荷不算进 D，点电荷上的力也没有偶极势的贡献。

二、DFTB+ 的实测行为

DFTB+ 为本机的 25.1（commit a23bfb2）和自编的开发版（041e723：conda-forge 的 gfortran 16.2 与 OpenBLAS，串行，不带可选依赖）。参数为测试用的 ptbp_hcocu；卤素与 H5 受体用现有的类型副本机制把 O 的参数复制成 “Cl”“Br”“N”“S”，DFTB+ 只按物种名识别它们，走的是与真实元素完全相同的代码（“只用于测试”）。SCC 容差 1e-10。

开发版的检验

用 13 个已有算例与冻结的 25.1 参考结果比较：分子与周期 SCC、DFTB3、H–X 阻尼、Ewald 与应力、k 点、共线与非共线自旋、SOC、DFTB+U、Casida（Stratmann）、GB 溶剂。能量逐位相同，力差 ≤ 3.4e-14，应力差 ≤ 1.8e-16，SCC 轮数相同。开发版没有 s-dftd3，DFT-D3 的算例跑不了，开发版的算例都不用它。

三、pydftb 的接口

calc = DFTB(sk, h5=True)                                    # 论文的参数
calc = DFTB(sk, h5={"r_scaling": 0.8, "w_scaling": 0.3,
                    "scaling": {"O": 0.1, "S": 0.3}})       # 按元素；≤ 0 表示不修正
calc = DFTB(sk, third_order="full", hubbard_derivs=ud, halogen_correction=True)
r.e_halogen                                                  # 计入 energy、free_energy
calc = DFTB(sk, kpts=k, dipole_correction=True)             # 层在 −h/2（等价于 h/2）
calc = DFTB(sk, kpts=k, dipole_correction={"layer_position": 9.45})   # Bohr
r.e_dipole_corr                                              # 2πD²/V，已含在 e_scc 中

atoms.calc = PyDFTB(skdir, h5=True, halogen_correction=False,
                    dipole_correction={"layer_position": 5.0})        # Å
  • H5：
    • 需要 SCC；不能与 h_damping 同用（DFTB+ 的 HCorrection 只有一个值）；没有 H 原子时报错；
    • 按元素识别 H 和受体（DFTB+ 按物种名）：只有带后缀的类型标签（如 O2）结果不同，pydftb 认为它仍是 O；
    • γ、势、力、应力、Casida 的 γ 与激发态的力、XL-BOMD 的力都含 H5，三阶不含（同 DFTB+）。
  • 卤素修正：需要 third_order（完整的或只 onsite 的）；没有 O/N 或没有 Cl/Br/I 时报错；周期体系给警告（同开发版；25.1 拒绝）。力和应力是能量的导数；r < 0.7R 时不计算 f(r)，不会出 NaN。
  • 偶极修正：
    • 周期体系，a3 ∥ z，并且 a1、a2 没有 z 分量（比 DFTB+ 严格）；总电荷为 0，每轮 |ΣΔq| ≤ 1e-7；
    • 给出完整的应力，含 DFTB+ 缺的项；
    • 不能与固定费米能级、点电荷、外场、XL-BOMD 同用。
  • 限制：三项都只在 NumPy 引擎中；torch 后端和 pydftb.autodiff 遇到时报错。
开发细节四、实现
  • 新文件 corrections.py（对应 DFTB+ 的 vdwdata.F90、h5correction.F90、halogenx.F90、dipolecorr.F90）：
    • 范德华半径表照抄 vdwdata.F90（pm，−1 表示没有），换算照 DFTB+ 的写法 0.01 × pm × (1/Bohr)；
    • H5：解析选项，给出每个原子的 (是否 H, k, R)，没有半径而缩放 > 0 时警告并跳过；
    • halogen_terms(labels, pos, cell, pbc, grad, compat) → HalogenTerms(energy, gradient, virial, atom_energies)：原子对取自 neighbors.neighbor_list（含周期像），截断同 DFTB+；compat=True 时 dσ 项反号，复现 DFTB+；
    • DipoleCorrection：检查晶格，以平板法向 n = a1 × a2/|a1 × a2| 定义高度 u = r·n 与周期 h = V/|a1 × a2|（a3 ∥ z 时就是 z 与 a3,z），给出折叠后的 uf − uc、h、V；potential(dq_atom)、energy、gradient、virial。
  • coulomb.py：Coulomb(..., h5=None)；_sp_short 在阻尼分支旁加一个新分支，按原子对的 H5 掩码修改 s 与 ds。γ 矩阵、势、梯度、维里都经过 _sp_short，自动跟着变；thirdorder.py 用自己的 dgamma_du，不受影响。
  • calculator.py：
    • DFTB.__init__ 新参数 h5、halogen_correction、dipole_correction，检查各种组合，三项都加入 numpy_only_options（torch 后端与自动求导因此报错）；
    • _setup：给 Coulomb 传 H5 参数；卤素项像色散一样算一次，存为 _Setup.halogenx；偶极修正存为 _Setup.dipole_corr；
    • _potentials：在溶剂项之后加偶极势（新分支）；每轮检查 |ΣΔq|；
    • _energies、_energies_pauli：ehalogen 计入总能量；2πD²/V 计入 eSCC 与总能量；新字段 e_halogen（默认 0.0，同 e_disp）、e_dipole_corr（默认 None）；terms 加 “halogen”；
    • _gradient：卤素的梯度与维里；偶极修正的显式梯度与维里 W = E(2nnT − I)：均匀应变 ε 下 u 与 h 都乘 (1 + nTεn)，D 也乘这个因子，V 乘 (1 + tr ε)。（初稿写的是 (4πD/V)·sym(ez ⊗ ΣAΔqArf,A) − E·I，其中的 xz、yz 两项随原子取哪个面内周期像而变，不是能量的导数，实现时改正，见报告第八节。）
    • _excited_gradient：compat "damping" 扩充为“DFTB+ 的 γ′ 不含阻尼与 H5”；
    • 测试专用的类属性 _halogen_compat（默认 False）。
  • 其他：ase_calc.py（三个选项，层的位置 Å → Bohr）。
  • 验证工具：
    • cases.py：Case.h5、halogen（含 compat 与 forces_fd）、dipole_correction、dftbplus（"dev" 时重新生成用 $DFTBPLUS_DEV）、stress_fd 可以只取部分分量；
    • dftbplus.py：HCorrection = H5 {…}、HalogenXCorr = Yes、DipoleCorrection {…}；解析 “Halogen correction energy”；run(..., binary=)；
    • refgen.py：基态的 forces_fd（对 DFTB+ 的 EMermin 做 4 点差分，h = 1e-4 Bohr）、新的比较函数 _compare_corrections；参考 JSON 记下开发版的版本串。

SCC 容差按通用做法挑：最后两轮的误差离阈值至少约 2 倍（探针：水盒子 H5 的 1.6e-10 离 1e-10 太近，N–Br 的 7.0e-11 也是；水层用 1e-9）。新的比较键 e_halogen 对 detailed.out 的 “Halogen correction energy”，容差 1e-12（实现时改为 1e-10：这一行只有 10 位小数）。

自洽测试（tests/test_corrections.py）

  • H5：分子与周期体系的力、应力对有限差分；缩放全部 ≤ 0 时与不开 H5 逐位相同；O2 标签得到 H5；拒绝项；
  • 卤素：能量与梯度在 0.7R、0.8R 处连续；跨开关区间的有限差分；截断；r < d 不出 NaN；compat 的力与 DFTB+ 的公式一致；
  • 偶极修正：E = 2πD²/V；力、应力（含 xz、yz）对有限差分；z0 与 z0 + h 等价；整个平板平移（不跨层）能量不变；拒绝项；
  • XL-BOMD + H5：XL 的力等于影子能量的差分（DFTB+ 漏了 H5，不做 DFTB+ 参考）；
  • PyDFTB 的单位；torch 与自动求导的拒绝。

门槛

与以往相同：golden 两个环境对 89b24d4 逐位相同（--allow-new 只放实际新增的字段，预计 e_halogen e_dipole_corr h5 halogenx dipole_corr）；refgen --check、dynamics --check；三个环境的 pydftb 测试；PTBP 测试；engine_parity。

六、不做的事与风险

  • 不做：
    • XL-BOMD 加偶极修正（DFTB+ 的 XL 梯度也没有这一项，pydftb 报错）；
    • 按物种名识别 H5 与卤素（pydftb 按元素，写明差别）；
    • 新功能的 torch 与自动求导版本。
  • 风险：
    • 开发版 DFTB+ 与 25.1 有别的差异：13 个已有算例上能量逐位相同、力差 ≤ 3.4e-14，只用于 25.1 没有的两项；
    • DFTB+ 用差分求 H0、S 的导数，个别几何上与解析导数差到 1e-6（水层上 6e-7）：按需要放宽这些算例的力容差，并写明原因；
    • 默认路径：每个新分支都放在旧代码之前，golden 逐位比较。
