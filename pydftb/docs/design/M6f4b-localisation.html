关键信息

M6f-4 的后一半：DFTB+ Analysis 中需要本征向量或激发态的三项输出。Pipek–Mezey 局域轨道（Localise { PipekMezey }）、键布居、键能与 Mayer 键级（WriteBondPopulation、WriteBondEnergy、WriteBondOrder，开发版的新功能），以及 Casida 跃迁电荷（WriteTransitionCharges）。只做 NumPy 引擎；不开这些选项时逐位不变。

  • DFTB+ 的做法（第一节）：
    • 局域化每个自旋通道最低的 nint(Nσ/(3 − nspin)) 个轨道，泛函是各轨道 Mulliken 布居的平方和；稠密算法按轨道对依次做 Jacobi 旋转，旋转角由 acos 求得；
    • 键布居 BAB = ΣT Σμ∈A, ν∈B Pμν(T)Sμν(T)，键能把 S 换成 H0，Mayer 键级用 (PS)μν(PS)νμ，都用自旋求和的密度；
    • 跃迁电荷 qA = κ Σia qiaA(X+Y)ia，κ = √2（无自旋）或 1（自旋极化），只对指定的态。
  • 探针中的发现（第二节）：
    • 按 DFTB+ 的顺序做的原型，从 DFTB+ 自己的本征向量出发，复现了它的局域轨道（系数差 ≤ 5e-9，泛函差 1e-13）；从 pydftb 的本征向量出发，泛函差 ≤ 1.4e-10，每个局域轨道的 Mulliken 布居差 ≤ 2.3e-10；
    • acos 在 1 附近的精度使旋转角只能分辨到约 4e-9 rad，局域轨道只能确定到这个量级；有简并时（O2）扫描次数取决于舍入，局域轨道的选取也不同，但泛函与布居的集合相同；
    • k 点的 Pipek–Mezey 有问题：DFTB+ 用不取共轭的乘积，结果随本征向量的任意相位改变（同一组 k 点的泛函和为 78.5、70.0 或 68.0），在 CuO 链上 8 个 k 点全部超过最大扫描次数，结果随 MaxIterations 变化（78.33、80.33）。pydftb 只局域化实数轨道（分子与 Γ 点），k 点报错并说明原因；
    • 键分析包含全部周期像（一个原子的 fcc Cu：B = 11 = 电子数），ΣB = N、行和 = Mulliken 布居、ΣE = EH0；周期体系拒绝 Mayer 键级；
    • 跃迁电荷：三重态拒绝；StateOfInterest = Brightest 时 DFTB+ 写出 NaN（拿 −1 当下标），pydftb 用找到的最亮态。
  • pydftb 的接口（第三节）：Analysis(localise=…, bond_populations=…, bond_energies=…, bond_orders=…)，结果在 r.analysis.localisation、r.analysis.bond_populations 等；Casida(transition_charges=True) 给 r.excitations.transition_charges；文件由 dftbplus_io 写出（localOrbs.out/.bin、bond_*.dat、ATQ.DAT）。

  • 2.3e-10从 pydftb 的本征向量局域化，各局域轨道 Mulliken 布居与 DFTB+ 的最大差

一、DFTB+ 的做法

源码为 DFTB+ 的 041e723（dftb/pmlocalisation.F90、dftbplus/main.F90 的 calcPipekMezeyLocalisation 与 getBondInfo、dftb/bondpopulations.F90、dftbplus/mainio.F90 的 writeBondInfo、timedep/linrespgrad.F90 的 getAndWriteTransitionCharges、dftbplus/initprogram.F90、dftbplus/parser.F90）。局域化与跃迁电荷与 25.1 相同（用 25.1 的二进制确认）；键分析的三个关键字在 25.1 中只属于 ElectronDynamics，基态的版本是 25.1 之后的新功能，对照开发版。

Pipek–Mezey 局域化

输入 Analysis { Localise { PipekMezey { MaxIterations = 100; Dense = No; SparseTolerances = {…}; Tolerance = 1e-4 } } }。

  • 局域化哪些轨道：在全部几何步之后，对最后的本征向量（最后一轮输入电荷的 H）做一次。每个自旋通道（及 k 点）取最低的 n = nint(Nσ/(3 − nspin)) 个轨道，Nσ 是该通道的电子数（无自旋时为总电子数），Fortran 的 nint 远离零取整；不看占据数，分数占据时只警告。两个自旋通道各自局域化。不支持非共线与 SOC（报错）。
  • 泛函：P = Σi ΣA (QiA)²，QiA = Σμ∈A cμi(Sci)μ（k 点为 Re[c*μi(Sci)μ]）。
  • 稠密实数算法（PipekMezeyOld_real）：每次扫描先令 αmax = 0，再对 s = 1…n、t = s+1…n 依次处理轨道对，每对算完立即旋转：
    • QstA = ½Σμ∈A[cμs(Sct)μ + cμt(Scs)μ]，Ast = ΣA[(QstA)² − ¼(QssA − QttA)²]，Bst = ΣAQstA(QssA − QttA)；
    • α = ¼·acos(−A/√(A² + B²))，B ≤ 0 时取负，A² + B² = 0 时 α = 0；cs ← cos α cs + sin α ct，ct ← cos α ct − sin α cs；
    • if (alphamax < abs(alpha)) alphamax = alpha：存的是带符号的 α，所以 αmax 不是最大的 |α|，而取决于各对的顺序与符号；
    • 扫描结束后从第 3 次起检查 ||αmax| − |αlast|| < Tolerance 或 αmax = 0，满足就停；超过 MaxIterations 只警告。αlast 的初值有隐式 SAVE，但前两次扫描不检查，不影响结果。
  • 稀疏算法（分子默认，PipekMezeySuprtRegion_real）：收敛阈值 TPipekMezeyInp%tolerance 在这条路径上从未赋值；本轮不做，也不拿来对照（甲醇上它碰巧收敛到与稠密算法相同的泛函）。
  • 输入规则：分子不写 Dense = Yes 时 Tolerance 不读，只写 Tolerance 会因“未处理的节点”退出；周期体系强制稠密，写 Dense 或 SparseTolerances 会退出。
  • k 点（PipekMezeyOld_kpoint）：每个 k 点独立，用同样的实数旋转，但 Qst、Qss 由不取共轭的乘积 cμs(Sct)μ 构成，A 用 |Q|²，B 取实部；结束后把每个轨道绝对值最大的系数转成正实数。这样的 Q 不是 Mulliken 布居，会随每个本征向量的任意相位 eiφ 改变（第二节）。
  • 输出：标准输出每个通道一行 Original localisation（E15.8）与 Final localisation （E20.12；k 点对 k 与自旋直接相加，不乘权重）；autotest.tag 的 pm_localisation 是最后一个通道的终值（只写 autotest.tag）；localOrbs.bin 总是写（格式同 eigenvec.bin：被局域化的 n 个轨道换成局域轨道，其余不变）；localOrbs.out 只在 WriteEigenvectors = Yes 且 EigenvectorsAsText = Yes 时写（格式同 eigenvec.out）。

键布居、键能与 Mayer 键级

  • 输入 Analysis { WriteBondPopulation = Yes; WriteBondEnergy = Yes; WriteBondOrder = Yes }（开发版；MPI 版不读 WriteBondOrder）。每个几何步在输出电荷之后算一次，用最后的输出密度 rhoPrim(:,1)（自旋求和）。
  • 键布居：BAB = ΣT Σμ∈A, ν∈B Pμν(T)Sμν(T)，T 取遍所有周期像（半近邻表中每个像对一次，再对称填充；对角含自身的周期像）。ΣB = N，行和 = Mulliken 布居。
  • 键能：同式，S 换成 H0（含在位能），ΣE = EH0。
  • Mayer 键级：MAB = Σμ∈A, ν∈B (PS)μν(PS)νμ，P、S 为 Γ 点展开的方阵；只用总密度（开壳层的 Mayer 键级本应加上自旋密度项）；周期体系报错（“currently only supported for non-periodic, cluster geometries”）。闭壳层整数占据时行和 = 2 × 布居。
  • 输出：只在写 tag 时（WriteAutotestTag 或 WriteResultsTag）写 bond_pop.dat、bond_energy.dat、bond_order.dat：两行注释（# Mulliken bond populations: B_AB = sum_{mu in A, nu in B} P_{mu nu} S_{mu nu} 等，# nAtom = N），每个原子一行 (*(ES16.8,1x))；tag bond_populations、bond_energies、bond_orders（全精度，每个几何步追加）。

Casida 跃迁电荷

  • 输入 ExcitedState { Casida { WriteTransitionCharges = Yes } }。要求 StateOfInterest ≠ 0，单重态或自旋极化；三重态与 Symmetry = Both 报错。
  • qA = κ Σia qAia(X+Y)ia,n，n 是指定的态，κ = √2（无自旋单重态）或 1（自旋极化，两个通道的跃迁直接相加）；qia 是 Mulliken 跃迁电荷（与 Casida 矩阵所用的相同）。不乘 √(ni − na)：Casida 矩阵与跃迁偶极都带这个因子，跃迁电荷没有（分数占据时两者不同）。
  • 输出 ATQ.DAT：三行头（#、# atom transition charge、#），每个原子一行 (2x,i5,5x,f12.9)；autotest.tag 的 transq_sqr = qA²。
  • StateOfInterest = Brightest（内部为 −1）能通过检查，但写跃迁电荷时直接拿 −1 当下标，结果是 NaN。

二、DFTB+ 的实测行为

DFTB+ 25.1（局域化、跃迁电荷）与开发版 041e723（键分析），参数 ptbp_hcocu，用现有算例的几何与设置。探针与原型在 scratchpad 的 m6f4b/。

P15：Pipek–Mezey（稠密，Tolerance 1e-10，MaxIterations 10000）

测试结果
甲醇（7 个轨道）、O2 三重态（7 + 5）、水盒子 Γ 点（32）pm_localisation 4.60995609907495、3.53848197636037（自旋向下一个通道的值；向上为 6.55560832048）、25.2361201136659；扫描次数 8、4 + 114、9；写了 localOrbs.out 与 localOrbs.bin
原型（逐行照 PipekMezeyOld_real），输入 DFTB+ 的 eigenvec.bin甲醇：扫描 8 次，与 localOrbs.bin 的系数差 3.6e-9，泛函差 2e-14；水盒子：系数差 5.3e-9，泛函差 6e-14；O2：泛函相同（差 3e-14），但局域轨道不同（π 轨道简并，扫描次数 984/2956 与 DFTB+ 的 4/114 不同），各轨道布居的集合相同（差 3.6e-15）
原型，输入 pydftb 的本征向量泛函差：甲醇 1e-14、O2 2e-14、水盒子 1.4e-10；各局域轨道的 Mulliken 布居按最佳配对后最大差 7.6e-11、1.3e-14、2.3e-10
O2 的收敛π 轨道简并，泛函沿简并方向是平的，旋转角由舍入决定；DFTB+ 的判据要求相邻两次的 |αmax| 相差 < Tolerance，只能碰巧满足：DFTB+ 用了 4 + 114 次，pydftb 的定稿代码自旋向下的通道 10000 次仍未满足（泛函早已与 DFTB+ 相同到 6e-14）。参考算例改用没有简并的甲醛阳离子：DFTB+ 9 + 8 次、pydftb 5 + 7 次，两个通道的泛函差 5e-15
输入规则甲醇只写 Tolerance：退出（“Code halting due to the presence of errors in dftb_in file”）；水盒子写 Dense = Yes：退出；甲醇什么都不写（稀疏算法）：泛函 4.60995609907495，与稠密相同

系数差 4e-9 的来源：接近收敛时 −A/√(A² + B²) = 1 − B²/(2A²) + …，当 |B/A| ≲ 1e-8 时舍入成 1，acos 得 0；acos 在 1 附近的分辨率约 1.5e-8，旋转角只能分辨到约 4e-9 rad。这是 DFTB+ 算法本身的精度下限，比较局域轨道只能到 1e-8 量级。

k 点的 Pipek–Mezey

测试结果
DFTB+ 25.1，CuO 链 4 × 2 × 2（8 个 k 点，17 个轨道）初值 73.3600482306（与 pydftb 的本征向量算出的初值相同）；Tolerance 1e-4、MaxIterations 100：7 个 k 点 “Exceeded iterations”，终值 78.33；Tolerance 1e-10、MaxIterations 2000：8 个 k 点全部超出，终值 80.33
原型（照 PipekMezeyOld_kpoint），pydftb 的本征向量，原样或乘随机相位 eiφn2000 次扫描都不收敛；k 点之和 78.48、70.01、67.99；有的 k 点终值低于初值（8.95 → 8.80，换相位后 7.56）

结论：DFTB+ 的 k 点算法依赖本征求解器给出的任意相位，既不收敛也不能复现；pydftb 不实现它，k 点（复数本征向量）时报错并说明原因。真正的复数 Pipek–Mezey 需要复数的两参数旋转，不在本轮范围内。

P16：键分析（开发版）

测试结果
甲醇、O2 三重态（三项）；CuO 链 k 点、fcc Cu（1 个原子）、GdO 岩盐（布居与键能）三个文件与三个 tag（N × N，对称）；ΣB = N（14、12、34、11、16）；行和 = Mulliken 布居（≤ 1e-8，8 位小数）；ΣE − EH0 ≤ 4.4e-11；fcc Cu 的 B = 11：周期像全部计入

三、pydftb 的接口

from pydftb import DFTB, Analysis, Casida
calc = DFTB(sk, analysis=Analysis(localise=True))           # MaxIterations 100, Tolerance 1e-4
calc = DFTB(sk, analysis={"localise": {"max_iterations": 10000, "tolerance": 1e-10},
                          "bond_populations": True, "bond_energies": True,
                          "bond_orders": True})
r = calc.calculate(labels, pos)
loc = r.analysis.localisation
loc.orbitals              # 每个自旋通道 (N, N)：最低的 n 个换成局域轨道（同 localOrbs）
loc.n_localised           # 每个通道的 n = nint(N_σ / (3 − n_spin))
loc.initial, loc.final    # 每个通道的泛函；loc.value = final[-1]（DFTB+ 的 pm_localisation）
loc.sweeps, loc.converged
loc.populations           # 每个通道 (n, n_atom)：局域轨道的 Mulliken 布居 Q_i^A
r.analysis.bond_populations, r.analysis.bond_energies, r.analysis.bond_orders   # (n_atom, n_atom)

calc = DFTB(sk, casida=Casida(6, state_of_interest=2, transition_charges=True))
r.excitations.transition_charges        # (n_atom,)，指定态的跃迁电荷

from pydftb import dftbplus_io as io
io.write_eigenvectors("localOrbs.out", r, localised=True)   # 或 localOrbs.bin（text=False）
io.write_bond_files(r, ".")              # bond_pop.dat、bond_energy.dat、bond_order.dat
io.write_transition_charges("ATQ.DAT", r)
  • 局域化：localise=True 或 {"max_iterations", "tolerance"}（默认同 DFTB+：100、1e-4）。只有 DFTB+ 的稠密算法（分子默认也用它；DFTB+ 分子默认的稀疏算法不做）。逐步照 DFTB+：轨道对的顺序、立即旋转、acos 求角、带符号的 αmax、第 3 次扫描起检查。有分数占据时警告（同 DFTB+）。拒绝：k 点（复数本征向量，见第二节）、非共线与 SOC（同 DFTB+）。
  • 键分析：三个开关各自独立；用最后的输出密度（自旋求和）。BAB 与 EAB 在 k 空间算：Σk wk Re[ρμν(k) Sνμ(k)]（或 H0）按原子求和，与实空间对所有周期像求和恒等。Mayer 键级只用于分子（周期体系报错，同 DFTB+）。非共线时用电荷分量（同 DFTB+ 的 rhoPrim(:,1)）。
  • 跃迁电荷：Casida(transition_charges=True)，要求指定态（state_of_interest ≠ 0）与单重态或自旋极化（同 DFTB+）；state_of_interest < 0（最亮态）时用找到的态号（DFTB+ 写 NaN）。
  • 限制：只在 NumPy 引擎中（analysis、casida 已在 numpy_only_options）。
开发细节四、实现
  • analysis.py：
    • Analysis 加 localise（False、True 或字典）、bond_populations、bond_energies、bond_orders；make 认新键；新数据类 Localisation；AnalysisResult 加 localisation、bond_populations、bond_energies、bond_orders；
    • pipek_mezey(c, s, starts, tolerance, max_iterations)：逐行照 PipekMezeyOld_real（Sct 在每个 s 开头对 t > s 一次算好，Scs 每对重算，原子的和用 np.add.reduceat）；返回轨道、扫描次数、是否收敛；pm_functional(c, s, starts)；
    • _localise(st, sc, res, spec)：本征向量由 _eigenvectors 的同一个函数给出（重新对角化 sc.h）；每个通道 n = floor(Nσ/(3 − nspin) + 0.5)，Nσ 取自结果的电子数（自旋极化时由占据数求和）；
    • bond_analysis(st, sc, which)：ρ 用 sc.rho 对自旋求和（Pauli 用 so.components 的电荷分量），S 用 st.smat_precise、H0 用 st.h0，np.einsum("k,kij,kji->ij") 后对行列按原子求和；Mayer：PS = P @ S（Γ 点实数方阵），M = Σ (PS)∘(PS)T 按原子求和。
  • casida.py：Casida.transition_charges（默认 False，检查同 DFTB+）；Excitations.transition_charges：在 excitations() 中、态号确定之后，用已有的 qia（transition_charges(gs, pairs)）与该态的 X+Y 相乘，κ 按自旋。
  • dftbplus_io.py：write_eigenvectors(…, localised=False)（localised 时写局域轨道及其权重）；write_bond_files(res, directory) 与 write_bond_matrix(path, matrix, kind)（两行注释 + ES16.8,1x）；write_transition_charges(path, res)（ATQ.DAT）；读回用的 read_bond_matrix、read_transition_charges。
  • calculator.py：不改 _run（分析的钩子 M6f-4a 已有）；Casida 的新选项经 Casida 数据类传入。ase_calc.py 无需改动（analysis= 已有）。

自洽测试（tests/test_analysis.py）

  • 局域化：局域轨道 S-正交（CTSC = I）、张成的空间不变（ΣiciciT 不变）、泛函不减；翻转输入轨道的符号，输出只差符号；拒绝 k 点、Pauli；分数占据的警告；
  • 键分析：ΣB = N、行和 = Mulliken 布居、ΣE = 结果的 H0 能量；闭壳层 Mayer 行和 = 2 × 布居；Γ 点超胞与 k 点的一致；拒绝周期 Mayer；
  • 跃迁电荷：Σq = 0；整数占据时 ΣqARA = 该态的跃迁偶极；最亮态取找到的态；拒绝三重态、无指定态；
  • 写出与读回：localOrbs.out/.bin、bond_*.dat、ATQ.DAT；不开这些选项时结果逐位不变。

六、不做的事与风险

  • 不做：
    • DFTB+ 的稀疏 Pipek–Mezey（收敛阈值未赋值）与 k 点算法（依赖相位、不收敛）；复数轨道的局域化；
    • 开壳层的 Mayer 键级的自旋项（DFTB+ 也没有）；周期体系的 Mayer 键级；
    • 电子动力学中的键布居与键能（实时 TD 不在这一波）；
    • 新功能的 torch 与自动求导版本。
  • 风险：
    • 局域轨道只能确定到 acos 的分辨率（约 4e-9），简并时局域轨道的选取与扫描次数由舍入决定：参考比较泛函与布居的集合，不比较系数与扫描次数；参考算例避开简并的体系；
    • 键分析只在开发版中，参考算例的生成依赖 $S/dftbdev（与 M6f-3 的偶极修正相同，参考 JSON 里记录版本）；
    • 默认路径：新代码只在对应选项打开时走，golden 逐位比较。
