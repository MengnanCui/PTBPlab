关键信息

M0–M3 与 DFTB+ 逐项对照时，踩到了三十多个“输入写了却不是那个意思”的坑（dftbplus_map.md 第三节）。M3d 把其中能从输入和输出文件里查出来的做成规则：python -m pydftb.advisor 目录 读 dftb_in.hsd、dftb_pin.hsd、DFTB+ 的屏幕输出和 SKF，列出发现的问题、证据所在的行和建议；PTBP 每次运行自动检查一次 DFTB+ 的运行目录。顾问只报告，不改任何设置。

  • PTBP 的实际情况：PTBP 经 ASE 写出的历史输入是 ParserVersion = 1、IgnoreUnprocessedNodes = Yes。DFTB+ 因此自动加了壳层分辨 SCC 和 0.01 Bohr 的有限差分步长，放在 Filling 外面的 Fermi、MethfesselPaxton 被悄悄忽略，实际是 T = 0；栈只有 8 MB。这些都会被列出来；其中已发表的参数正是在这些设置下拟合的，标为“预期”。
  • 规则 v1（17 条）：旧解析器的自动改写（P01）、MP 阶数减 1（P02）、被忽略的节点（P03）、温度没写单位（F01）、U 几乎相等时 γ 公式失准（H01）、SKF 缺 Spline 段（K01）、能带运行的 SCC 判据（B01）、线程超订（T01）、MPI 分组（T02）、小矩阵上的 OpenMP 线程（T03）、栈大小（T04）、SCC 未收敛却继续（S01）、Ewald 容差（E01）、非正交晶胞的 Isotropic（G01）、LBFGS 没有步长上限（G02）、周期 D4 的 EEQ 电荷和三体项（D02、D03）。
  • 只读、最小环境可用：自带只读的 HSD 解析器（记录行号），不依赖 DFTB+、不运行 DFTB+。
  • 17v1 规则，各有出处（坑号或实测）
  • 0顾问改动的设置

一、读什么

来源得到什么
dftb_in.hsd（必需）用户写的设置和行号；ParserVersion、IgnoreUnprocessedNodes；<<< 引用的几何文件（GenFormat：原子、元素、晶胞），<<+ 引用的 HSD 文件
dftb_pin.hsd（有就读）DFTB+ 实际用的设置（含默认值和旧版本转换后的结果），例如 Filling = Fermi { Temperature = 0 }、Differentiation = FiniteDiff { Delta = 0.01 }
屏幕输出（*.out 中含 DFTB+ 标题的那个，或 --stdout）旧版本转换的警告、被忽略的节点（路径和行号）、OpenMP 线程数、MPI 进程数和分组、栈大小、“SCC is NOT converged”、错误信息
SKF（按 SlaterKosterFiles 的规则找）每个壳层的 Hubbard U（简单格式和扩展格式）、有没有 Spline 段
环境OMP_NUM_THREADS、BLAS 线程变量、可用核心数、栈限制（ulimit -s）

二、规则目录

严重程度：error（DFTB+ 会报错退出，或结果明显不对）、warning（结果多半不是想要的，或精度、速度损失明显）、info（提示）。每条规则给出证据（文件和行号）、后果和建议。

编号查什么程度出处
P01ParserVersion < 14 时 DFTB+ 自动做的改写，按输入内容列出实际生效的：版本 < 3 且 SCC = Yes → 加 ShellResolvedSCC = Yes；版本 < 5 → Differentiation = FiniteDiff { Delta = 0.01 }（默认 1.22e-4），SpinConstants 加 ShellResolvedSpin；版本 < 7 且有 DftD3 → DFTB3 的默认参数；版本 < 9 且用 LBFGS → LineSearch、oldLineSearchwarningoldcompat.F90；M1
P02版本 < 14 且 Filling = MethfesselPaxton { Order = n }：实际用 n − 1（n = 1 变成高斯展宽，n ≤ 0 报错）warning坑 1
P03IgnoreUnprocessedNodes = Yes 时被悄悄忽略的节点（屏幕输出的列表，或对比输入和 pin）；Fermi、MethfesselPaxton、Gaussian 放在 Filling 外面时专门说明：实际的展宽取自 pin（PTBP 的历史输入为 T = 0）warningM1
F01Filling 的 Temperature 没写单位：DFTB+ 按 Hartree 读。数值 > 0.5 时几乎一定是想写开尔文（2000 Ha 相当于 6×10⁸ K）error（> 0.5）/ infoparser.F90:readFilling
H01任意两个参与 SCC 的 U 值（壳层分辨时每个壳层，否则每种元素取 s 壳层的）相差 3.1e-6 到 3e-4 Ha：DFTB+ 的 γ 闭式公式相减抵消。实测每个原子对的 γ 误差：ΔU = 1e-5 时约 1e-4 Ha，3e-5 时约 4e-6 Ha，1e-4 时约 5e-8 Ha，1e-3 时 < 3e-10 Ha。开 DFTB3 时 ∂γ/∂U 的误差还要大得多error（< 3e-5，或 DFTB3 且 < 1e-3）/ warning坑 6；M2b
K01用到的 SKF 没有 Spline 段，而这对元素没有 PolynomialRepulsive：DFTB+ 报错退出（hotcent 直接写出的文件就是这样）error坑 30
B01有 KPointsAndWeights = Klines（MaxSCCIterations 默认变成 1）、多原子晶胞、没有 ConvergentSCCOnly = No：DFTB+ 判定 SCC 未收敛并退出error坑 16；M2e
T01OpenMP 线程 × BLAS 线程 × MPI 进程超过可用核心warningRESEARCH §4.4
T02不带 MPI 的版本里的 Parallel 块被忽略（Groups > 1 时 warning）；MPI 版本中 Groups 不能整除进程数时 DFTB+ 报错info / warning / errorRESEARCH §4.2–4.3；mpienv.F90
T03OpenMP 线程 > 1 而矩阵小于 500 阶：更慢（36 个轨道 4 线程慢 3.3 倍，288 个轨道慢 1.2–1.3 倍）warningM3a、M3c 实测
T04栈限制不是 unlimited（屏幕输出 “Current stacksize: 8 [Mb]”，或本机的 ulimit -s）：大体系可能随机崩溃infoenvcheck.F90
S01屏幕输出有 “SCC is NOT converged”，而 ConvergentSCCOnly = No 让 DFTB+ 照常给出结果（PTBP 的历史输入就是这样）warningmain.F90
E01周期 SCC 计算用默认的 EwaldTolerance = 1e-9：24 个原子的水盒子里与 1e-12 相差 1.3e-7 Ha；要比较 1e-7 以下的差别时调小infoM2e
G01LatticeOpt = Yes 加 Isotropic = Yes，晶胞不正交：晶格梯度不平行于晶格，LBFGS 会剪切晶胞，收敛判据只看压强warning坑 25；M2f
G02GeometryOptimisation 用 LBFGS：没有步长上限，软势能面上步长越来越大直到 SCC 发散（水二聚体第 12 步后 0.2 → 0.8 Bohr）info坑 24；M2f
D02周期体系用 DFTB+ 自己的 D4 且 EEQ 电荷开着（ChargeScale ≠ 0）：结果随 Ewald 参数变化（1.3e-4 Ha），大盒子也不收敛到分子值warning坑 11；M2d
D03周期体系用 DFTB+ 的 D4 且三体项开着（s9 ≠ 0）：原胞与超胞算出的每胞三体能相差 10%warning坑 12；M2d

v2 候选（时间够再加）：D4 参考体系的差别（坑 10）、dftd4 的截断（坑 13）、SlaterKirkwood 的 0/0（坑 14）、UFF 按类型名前两个字母查参数（坑 15）、HubbardDerivs 写在一行（坑 31）、TimingVerbosity 的提示。

三、命令行与输出

python -m pydftb.advisor PATH [--stdout FILE] [--json] [--fail-on error|warning|info|never]
                         [--cores N] [--mpi-procs N] [--list-rules] [--explain P03]
  • PATH：运行目录或 dftb_in.hsd。屏幕输出默认找目录里第一行带 DFTB+ 标题的 *.out（ASE 写的是 标签.out）。
  • 文字输出每条一段：[P03] warning Hamiltonian/DFTB/Fermi (dftb_in.hsd:10-12) ignored by the parser ...，接着后果和建议；--json 输出同样内容的列表。
  • 退出码：0 没有达到 --fail-on（默认 error）的发现；1 有；2 用法错误或找不到输入；3 输入读不了。
  • --list-rules 列出全部规则；--explain ID 给出一条规则的说明、出处和例子。

四、PTBP 的自动检查

  • 只在 DFTB+ 引擎、ptbp optimize（cli/run.py）运行时启用，每次运行只检查第一个 BO 步里第一个完成的 DFTB+ 运行目录（并行时保留这一个任务目录，检查后删除）。
  • 某个 DFTB+ 运行失败时（不是缺 SKF 的那种），检查它保留的目录，把结论附在异常上（add_note）。
  • 输出加 [advisor] 前缀，并写运行目录里的 advisor.json。
  • P01、P03 和 0.01 Bohr 的差分步长在 PTBP 的历史输入下标为“预期”：已发表的参数就是在这些设置下拟合的，不要改；想要真正的展宽用 --smearing。
  • 钩子本身绝不抛异常，也不改任何设置；check_dftbplus_filling（M1）照旧。

七、局限与不做的事

  • 只读、只报告：不改输入，不重跑 DFTB+。
  • 几何只读 GenFormat 和显式的 TypesAndCoordinates；其他格式时与几何有关的规则跳过并说明。
  • MPI 进程数只能从屏幕输出或 --mpi-procs 得到。
  • 规则针对 DFTB+ 25.1（解析器版本 14）；26.1 的版本 15 另有改写（RecomputeAfterDensity 等），用到时再加。
