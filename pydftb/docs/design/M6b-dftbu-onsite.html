关键信息

M6 的第二步。DFTB+U 和 onsite 修正都是“块势”：它们不是每个轨道一个数，而是作用在同一原子的整个轨道块上（包括 p、d 轨道之间的非对角元），依赖的是“块布居”，也就是同一原子上两个轨道之间的电子数。两者共用一套机制：块布居、块势进入哈密顿量、混合向量里的块元素、力和应力中的块项。只做 NumPy 引擎；torch 后端和自动求导遇到这些选项时明确报错。

  • 做什么：
    • DFTB+U（DFTB+ OrbitalPotential）：对指定原子的指定壳层（例如 Cu 的 d、Gd 的 f）加 U−J 修正，常用于局域的 d、f 电子。两种泛函：FLL（完全局域极限，DFTB+ 默认）和 pSIC（赝自相互作用修正）。
    • onsite 修正（DFTB+ OnSiteCorrection）：补上同一原子不同轨道之间的交换类积分，改善氢键等。每个元素两个 n壳层 × n壳层 的常数矩阵（同自旋、异自旋）。DFTB+ 手册给出 H、C、N、O、S、Ti、Au 的 PBE 值，pydftb 一并收录。
    • 两者可以单独用，也可以一起用；可以配无自旋、共线自旋、非共线自旋、SOC（DFTB+U 配 SOC 时只能用 dual 模型，与 DFTB+ 相同）、DFTB3、色散、k 点、力和应力、能带与 DOS。
  • 和 DFTB+ 逐轮一致的关键：混合向量要与 DFTB+ 相同。有块势时，DFTB+ 把被修正的轨道各自单独混合，并把块的非对角元也放进混合向量。第一轮的输出不混合，直接作为第二轮的输入；有 +U 时至少迭代两轮。onsite 修正在每个几何步的第一轮不加进哈密顿量。这些规则都照搬（第一节）。
  • DFTB+ 的实测（第二节）：所有组合都能跑，包括 SOC dual + U、SOC + onsite、两者同时用。只有 s 壳层的 +U 组会让 DFTB+ 25.1 崩溃（段错误），pydftb 支持这种情况，用自身的一致性检查验证。
  • 用法：DFTB(sk, plus_u={"Cu": [("d", 0.15)]})（U−J 以 Hartree 计，plus_u_functional="psic" 切换泛函）；DFTB(sk, onsite_corrections=ONSITE_PBE)。
  • 验证：16 个新的 DFTB+ 参考算例，比较能量各项（含 EU、Eons）、力、应力、逐轨道布居、本征值、磁矩和 SCC 轮数；另有一个分子动力学对照。旧算例逐位不变。
  • 2块势：DFTB+U（FLL、pSIC）、onsite 修正
  • ½(SV + VS)块势进入哈密顿量的方式
  • 16新的 DFTB+ 参考算例

一、DFTB+ 的做法

块布居与块势

  • 块布居（dual Mulliken，populations.F90:mulliken 的块版本）：QAμν = ½ Σκ (ρμκSκν + Sμκρκν)，μ、ν 都在原子 A 上，κ 遍历所有轨道（含周期像）。对角元就是普通的逐轨道 Mulliken 布居。每个自旋分量各算一份：无自旋时只有电荷 q；共线自旋为 (q, m)；两分量为 (q, mx, my, mz)。有 dual SOC 时还有虚部（反对称）Qi，M6a 已经实现了它的计算。
  • 块势进入 H（shift.F90:addShift）：每个原子一个块势 VA，Hνμ += ½[Σκ∈A SνκVAκμ + Σκ∈B VBνκSκμ]，即 H += ½(S V + V S)，V 为各原子块组成的块对角矩阵。普通的电荷势、自旋势只是 V 为对角阵的特例，这时公式退化为现有的 ½Sμν(vμ + vν)。k 点下 S 换成 S(k)，V 不变（它只在原子上）。
  • 各自旋分量的 H 按现有规则组装：共线时 H↑/↓ = Hq ± Hm；两分量时 H = Hq ⊗ 1 + Σa Ha σa。虚部块势 Vi 以 i·½(S Vi + Vi S) 加到对应分量上，与 M6a 的 dual SOC 完全相同。
  • 势的计算顺序（main.F90:processPotentials）：电荷、自旋、三阶项 → DFTB+U → onsite 修正。

DFTB+U（dftbplusu.F90）

  • 输入：每个元素若干个“组”，每组是一个或几个壳层加一个 U−J 值（Hartree，可带单位）。同一组的几个壳层之间的块（例如 p–d）也受修正。U−J ≤ 1e-10 报错，同一壳层出现在两组里报错。
  • 势（对每个自旋分量 s，组内所有轨道对 μ、ν）：Vsμν = −(U−J)/2 · Qsμν。FLL 另在电荷分量的对角元加 +(U−J)/2。有 dual SOC 时，虚部 Vis = −(U−J)/2 · Qis。
  • 能量：EU = Σ原子 Σ组 [ −(U−J)/4 Σs Σμν ((Qsμν)² + (Qisμν)²) + FLL 时 (U−J)/2 Σμ Qqμμ ]。换成每个自旋的占据矩阵 nσ 就是熟悉的形式：EFLL = (U−J)/2 Σσ Tr(nσ − nσnσ)，EpSIC = −(U−J)/2 Σσ Tr(nσnσ)。上面的势正是能量对 Q 的导数。
  • FLL 把被修正壳层中的已占态压低、空态抬高；pSIC 只压低已占态，所以 EpSIC 是一个大的负数（Cu₄CO：−2.96 Ha），总能量不能直接与 FLL 比较。

onsite 修正（onscorrection.F90）

  • 输入：每个元素两个矩阵 fuu、fud（同自旋、异自旋），维数为该元素的壳层数，单位 Hartree。DFTB+ 要求结构中每个元素都给出（全零也要写）。矩阵先对称化；同一个 s 壳层自身的元素（ss′）不用。
  • 系数：f± = fuu ± fud，按 (壳层(μ), 壳层(ν)) 铺到轨道对上；同一 l > 0 壳层内部（含对角元）都用该壳层的对角值。电荷分量用 f+，各磁化分量用 f−。
  • 势：Wsμν = f(s)μν (Qsμν − δs,qδμν q0μ)，再对每个壳层的对角元减去该壳层对角元的平均值（转动不变性修正），这样只有壳层内各轨道布居的差别起作用。Vs = Ws。虚部 Wis = f(s) ∘ Qis，对角元置零，没有平均修正。
  • 能量：Eons = ½ ΣA Σs Σμν (Wsμν Qsμν + Wisμν Qisμν)。它是 Q 的二次型，势就是它的导数。
  • 参考：Domínguez, Niehaus, Frauenheim, J. Phys. Chem. A 119, 3535 (2015)；常数取自 García 的学位论文（DFTB+ 手册附录）。

SCC 的规则

  • 混合向量（reduceCharges、setEquivalencyRelations）：
    1. 轨道布居按“等价类”求和。没有块势时，等价类就是 pydftb 现在混合的位点（原子，或壳层，有自旋时每个壳层每个自旋）。加 +U 后，被修正壳层的每个轨道单独成一类；加 onsite 后，所有轨道都单独成类。
    2. 接着是块的非对角元：+U 时为各组内的轨道对，onsite 时为每个原子的全部轨道对，每对 (i > j) 一个数 ½(Qij + Qji)。
    3. 有 dual SOC 时再接虚部块 ½(Qiij − Qiji)，轨道对与上一条相同。
    共线自旋时布居和块都按 ↑、↓ 存放（与现有的共线路径相同）；两分量时按 (q, mx, my, mz)。
  • 收敛判据：整个混合向量（包括块元素）的最大变化小于 SCCTolerance。
  • 第一轮不混合：有块势时，第一轮的输出直接作为第二轮的输入（与自旋计算相同，getNextInputCharges）。
  • 至少两轮：有 +U（或自旋）时至少两轮（getMinSccIters）；只有 onsite 且无自旋时为一轮。给了初始电荷时为一轮。
  • 初始块：对角块，每个轨道取所在壳层的平均布居，非对角元为零（initializeCharges）。所以第一轮的 +U 势只有对角元。
  • onsite 在第一轮缺席：每个几何步的第一轮 SCC，onsite 势不加进 H（processPotentials 的条件 iSCCIter > 1 .or. tReadChrg）。能量和力用的输出势里总是有它。这只改变 SCC 的路径，不改变收敛结果。DFTB+ 读入电荷文件时（ReadInitialCharges）第一轮就有它，DFTB+ 的能带计算就属于这种情况。pydftb 不给初始电荷时与 DFTB+ 相同；给了 q_init（重启、ASE 的 reuse_charges）时当作读入的电荷，第一轮就加。所以分子动力学里每步的 SCC 轮数比 DFTB+ 的少，轨迹不变。
  • 能量用输出量：对角化之后，DFTB+ 用这一轮的输出布居和输出块重建所有势，EU、Eons 都由输出块算出，与 ESCC 等相同（calcEnergies）。detailed.out 中为 “Energy DFTB+U” 和 “Energy onsite”。

力与应力

  • 块势只通过 S 依赖几何（V 本身是密度的函数，这部分在自洽解中抵消）。对每个 S 元素 (ν, μ)，导数的系数为 Σs ½(Vsρs + ρsVs)μν（forces.F90:derivative_blockEuclidean），ρs 为各自旋分量的实空间密度。V 为对角阵时，就是现有的 ρμν · ½(vμ + vν)。
  • 虚部块势的系数为 −½ Σs (Vis Is + Is Vis)μν，Is 为实空间密度的虚部（derivative_iBlock），与 M6a 的 dual SOC 项同形。
  • 应力由同样的元素梯度得到（getBlockStress）。所以力和应力对分子、Γ 点、k 点都自动成立。

限制

  • 两者都只在 SCC 计算中可用。
  • DFTB+U 配 SOC 只能用 dual 模型（initprogram.F90:4171）。onsite 修正配两种 SOC 模型都可以；只有 dual 模型下才有虚部块。
  • 不支持：XL-BOMD、Casida 激发态（DFTB+U 不支持；onsite 只支持激发能，不支持力），M6d 时照此限制。

三、pydftb 的接口

选项（DFTB）含义DFTB+
plus_u{类型标签: [(壳层, U−J), …]}。壳层可写成角动量字母（"d"、"pd"）或从 0 开始的壳层序号（[1, 2]）；U−J 以 Hartree 计OrbitalPotential { <Sp> { Shells = {…} UJ = … } }（壳层序号从 1 开始）
plus_u_functional"fll"（默认）或 "psic"Functional = FLL | pSIC
onsite_corrections{类型标签: {"uu": 矩阵, "ud": 矩阵}}（或 (uu, ud) 二元组），矩阵为 n壳层 × n壳层，Hartree；结构中每个类型都要给出OnSiteCorrection { <Sp>uu = {…} <Sp>ud = {…} }
  • 常数表：pydftb.blockpot.ONSITE_PBE 收录 DFTB+ 手册的 PBE 值（H：s；C、N、O：sp；S、Ti、Au：spd），可以直接传给 onsite_corrections。用于壳层结构不同的参数集时会报错，而不是悄悄截取。
  • 与 DFTB+ 相同的限制：需要 SCC；U−J ≤ 1e-10 报错；同一壳层在一个元素的两组里出现报错；DFTB+U 配 SOC 时要求 dual 模型。
  • 比 DFTB+ 多的：只含 s 壳层的 +U 组可以用（DFTB+ 崩溃）。
  • pydftb 自己的限制：backend="torch"、pydftb.autodiff 报错；SP2 求解器若不能给出所需的密度矩阵也报错（实现时确认）。
  • 结果（DFTBResult，新字段有默认值，追加在末尾）：e_plus_u（“Energy DFTB+U”）、e_onsite（“Energy onsite”）；terms 增加 “+U”、“onsite”。q_in 为块路径的完整混合向量，可直接用于重启和能带计算。q_spin、magmoms 的含义不变。
  • ASE 与 api.SCC：新选项原样传给 DFTB；reuse_charges 与重启使用块路径的混合向量。
  • 能带与 DOS：eigenstates 把块势加进每个 k 点的 H，与 DFTB+ 的能带计算（读入电荷，第一轮就有 onsite 势）相同。

块路径的混合向量

  • 通道：无自旋 1 个（q）；共线 2 个（↑、↓）；两分量 4 个（q、mx、my、mz）。
  • 等价类：对每个通道 c、原子、轨道 μ，键为：μ 是 +U 轨道或开了 onsite 时 (c, μ)；否则为 (c, 位点(μ))，位点即现有路径的原子或壳层（有自旋或两分量时为壳层）。按 (通道, 原子, 轨道) 的顺序第一次出现时编号，与 DFTB+ 的 OrbitalEquiv_merge 相同。
  • 块元素：+U 时按 DFTB+ blockIndx 的循环顺序（通道 → 原子 → 组 → 组内壳层对 → 轨道对，取行 > 列）；onsite 时按 ons_blockIndx（通道 → 原子 → i < j）。虚部块用同样的轨道对，接在后面。
  • 向量 → 布居（expandCharges）：每类的总数放在该类的第一个轨道上，其余为零（只影响按位点求和以外的用途，块路径里没有）；块的对角元取单独成类的轨道布居，非对角元对称填入，虚部反对称填入；共线时再由 ↑、↓ 换成 (q, m)。
  • 布居 → 向量（reduceCharges）：逐轨道 Mulliken 布居按类求和；块元素取 ½(Qij + Qji)；共线时块和布居都用 ↑、↓。
  • 旧路径（无块势）的混合向量与代码一行不改。块路径只在 st.block is not None 时进入。

SCC 一轮

  1. 由向量展开得到逐轨道布居（每个通道）与块 Q、Qi。位点电荷、壳层磁化由逐轨道布居求和，电荷势、自旋势照旧。
  2. 块势：+U（第一轮也有）与 onsite（第一轮没有），每个原子、每个分量（q、m 或 q、mx、my、mz）一个小矩阵；有 dual SOC 时还有虚部。
  3. Hs = （现有的对角部分）+ ½(S Bs + Bs S)，Bs 为块对角矩阵。按原子分块计算：(S B)[:, A] = S[:, A] BA，B S = (S B)†，代价 O(nk N² nA)，不做 N³ 的整体乘法。虚部：X = ½(S Bi − (S Bi)†)，加 iX。
  4. 对角化、填充照旧。输出：逐轨道 Mulliken 布居与块布居 ½Σk wk(ρkSk + Skρk)AA（只算需要的原子），拼成输出向量。
  5. 第一轮不混合；有 +U、自旋或两分量时至少两轮（没有 q_init 时）。

能量、力

  • EU、Eons 由最后一轮的输出向量展开得到的块算出，加入总能量。
  • 力：输出块的块势（含 onsite），对每个自旋分量 s 的实空间密度 Rs(T)（Γ 点为 Σkwkρk），系数 ½(BsRs + RsBs)[元素] 加到现有的 S 导数系数上；虚部项照 dual SOC 的写法推广到四个分量。应力随之得到。

不改的部分

无块势的所有路径（无自旋、共线、两分量）一行不改。golden 只会多出新字段（结果的 e_plus_u、e_onsite，以及 _Setup.block，旧算例中为 None），用 --allow-new block e_plus_u e_onsite。

动力学：h2o_ons_md，DFTB+ 的 VelocityVerlet 与 pydftb（ASE，reuse_charges=True）逐帧对照，检验每个几何步第一轮缺少 onsite 势、块向量在几何步之间的传递。

不依赖 DFTB+ 的测试（tests/test_blockpot.py）

  • 力、应力与能量的中心差分一致：FLL、pSIC、onsite；无自旋、共线、两分量 + dual SOC（虚部块）；分子与 k 点。
  • EU 的两种写法（Q 的二次式与 ΣσTr(n − n²)）一致；onsite 常数全为零时与无修正的结果相同。
  • 只有 s 壳层的 +U 组（DFTB+ 崩溃）：差分检查。
  • 混合向量布局：类的个数、块元素个数与 DFTB+ 的规则一致；向量 → 布居 → 向量还原。
  • 用 q_in 重启：1–2 轮收敛到同一结果；eigenstates 在 SCC 的 k 点上重现 SCC 的本征值。
  • 报错：非 SCC、U−J ≤ 0、壳层重复、未知壳层字母、SOC onsite 模型 + U、torch、autodiff、onsite 缺少某个类型、矩阵形状不对、ONSITE_PBE 用于壳层不同的参数集。
  • PyDFTB、api.SCC 传递新选项。

门槛

  • golden：两个环境（conda、最小环境）对 M6b 之前的提交逐位相同，--allow-new block e_plus_u e_onsite；新算例只记数，不比较。
  • refgen --check（全部，NumPy；torch 只跑旧算例）、dynamics --check。
  • pydftb 测试三个环境；PTBP 测试；engine_parity 确认 PTBP 不受影响。

六、不做的事与风险

  • 不做：torch 后端与自动求导的块势版本；DFTB+ 等价类中“U 相同的壳层合并”这一条（第二节）；U−J、onsite 常数的计算（hotcent 没有现成的 fuu/fud 算法；DFTB+ 也不提供 U−J 的默认值，需要用户给出）。
  • 风险：长 SCC。CuO 链 + U 要 73 轮，舍入差别可能让轮数与 DFTB+ 相差一两轮。对策：结果按容差比较，轮数只列出对照。
  • 风险：块乘法的代价。onsite 修正每轮要对所有原子做 S 的分块乘法和块布居，大体系里与对角化相比不可忽略。先保证正确，报告中给出耗时。
  • 风险：输入写法。DFTB+ 的壳层序号从 1 开始，pydftb 用从 0 开始的序号或字母；文档和报错信息都写明，参考算例由同一份设置生成两边的输入。
