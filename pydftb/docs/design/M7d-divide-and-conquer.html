关键信息

M7d 把体系按空间分成子体系：每个子体系是一块核心区加上它周围的缓冲区，在全局 H(k)、S(k) 的主子矩阵上单独做本征分解，再按分区矩阵把各子体系的密度矩阵拼回全局（Yang 与 Lee 的分治密度矩阵，Nakai 组的 DC-DFTB）。子体系互相独立，分给本机的多个进程或多台机器上的 MPI 进程。整条路径建在 M7c 的图样上，没有 N × N 的矩阵。DFTB+ 没有这种求解器：它的 Solver = DivideAndConquer 是 LAPACK 的 hegvd（pydftb 已有同名驱动），所以新求解器叫 Subsystems，对照用 pydftb 的本征分解。

  • 精确极限（P112、P114）：缓冲区覆盖全部原子时，任意分法都到舍入等于本征分解：216 个水分子每个原子的能量差 7e-16，电荷 4e-14 e，力 4e-14 Ha/Bohr；k 点（2×2×2）、两种共线自旋与 300 K 的共用费米能级也一样，SCC 轮数相同。
  • 缓冲区收敛（Γ 点，SCC 加力，对本征分解）：
    • 真实的水（P115d：DFTB+ 测试用的 mio-1-1，216 个水分子，先弛豫）：缓冲 4、5、6、8 Å 时电荷差 5.2e-3、1.0e-4、1.9e-5、1.3e-7 e，力差 8.4e-3、2.0e-4、3.2e-5、5.5e-8 Ha/Bohr。同一盒子上 M7c 截断 1e-6 的稀疏路径是 1.1e-7 e 与 8.2e-8 Ha/Bohr，所以要它的精度，分治需要 8 Å。
    • M7c 的计时盒子（P112，ptbp_hcocu 的参数，分子取向随机、没有弛豫）氢键耦合弱，误差小得多：6 Å 时电荷差约 1e-6 e，从 512 到 1728 个水分子不变。这组数只用来比较做法与计时，精度以上一条为准。
    • 按原子取缓冲区会切断 O–H 键，同样 6 Å 时电荷差大两个数量级，所以分区的单位是成键的片段；核心区大一些也更准（216 个水分子、6 Å：核心 6 Å 时每个原子的能量差 4e-12，核心 4 Å 时 7e-10）。
    • 金属不行（P113）：Cu 在 1000 K 与 3000 K 时缓冲到 5 Å（子体系 753 个轨道），每个原子的能量差仍有 4e-4–7e-4 Ha、电荷 0.04–0.08 e，与 M7c 里金属不稀疏是一回事。
  • 费米能级（P113）：子体系的态带着核心权重（核心轨道上的 Mulliken 布居）一起求公共的 μ。有限缓冲下这些权重之和与电子数差约 1e-6 e，所以 T = 0 时按能量顺序填充，跨过电子数的那一级取余数，μ 落在价带顶或导带底；精确极限下电子数恰好守恒，用 DFTB+ 的带隙中点规则，费米能级与本征分解相同。
  • SCC 的收敛：缓冲区 ≤ 4 Å 时，被切开的氢键网络在带隙里留下边界态，T = 0 时 μ 钉在这样的态上，它的占据随每轮电势跳变，SCC 可能不收敛（O2 盒子 200 轮不收敛）。300 K 的 Fermi 展宽或 6 Å 的缓冲区都能收敛。
  • 力与 MD（P115、P115c）：用分区的 P 与 W 照常算力，不是分治能量的严格导数。扣掉有限差分自身的截断误差后，6 Å 时两者差约 3e-8 Ha/Bohr，与分治本身的误差同量级；4 Å 时差 5e-6，分治误差 3.6e-5。mio 的 64 个水分子 NVE（0.5 fs，50 fs）：6 Å 时总能量漂移 2.7e-4 Ha/ps（分区固定）与 2.8e-4（每步重分），本征分解 2.8e-4；4 Å 时 1.0e-2 与 2.3e-2，每步重分时还有一步 SCC 200 轮不收敛。
  • 速度（P116，本机 4 核，核心 6 Å、缓冲 6 Å）：
    • 1000 个水分子 SCC 加力：4 个进程共 119 s，本征分解 404 s，M7c 的稀疏路径 219 s；
    • 1728 个水分子：232 s，本征分解估计约 1800 s，稀疏路径 411 s；
    • 分治的部分每轮 SCC 每个水分子 4.2–4.5 ms，随 N 线性（稀疏路径 9.8 ms）；
    • 4 个进程的本征分解比单进程快 3.0 倍；线程几乎不加速，4 个线程只快 1.1 倍（SciPy 的这个调用看来没有释放 GIL）。
    • 这是 6 Å 的计时。真实的水要与稀疏路径同等精度需要 8 Å，子体系大约 5 倍的本征分解时间。实现后实测（报告第五节）：1000 个水分子 8 Å、4 个进程共 287 s，比稀疏路径（219 s）慢 1.3 倍。分治的长处在别处：内存分在各进程上、每轮只交换图样上的数值，适合多机；有限温度可用；6 Å 已是 MD 够用的精度。
  • 多机（P117）：mpi4py 的原型，0 号进程跑 SCC，其余进程常驻子体系。1、2、3 个进程的能量、电荷与力逐位相同；本机 0–4 个工作进程也逐位相同（P116b，BLAS 线程数相同时）。
  • 建立阶段（P118）：分治之后，瓶颈是 Ewald 的实空间对表。1728 个水分子时对表 2.7 GiB、建立时峰值 9.3 GiB，随 N1.5 增长；5000 个水分子约要 46 GiB。这与求解器无关，作为紧接的一块另做（第九节）。
  • 7e-16精确极限：每个原子的能量差（Ha）
  • 1.3e-7真实的水（mio，216 个分子）8 Å 缓冲的电荷误差（e）；6 Å 为 1.9e-5
  • 4.2 ms1728 个水分子每轮 SCC 每个分子的分治耗时（4 个进程）
  • 逐位1–4 个进程与 1–3 个 MPI 进程的结果相同

一、范围

  • 做：
    • Subsystems(buffer=…, core=…, units=…, processes=…)：空间分治的密度矩阵，建在 M7c 的图样上；
    • 分子、周期体系的 Γ 点与 k 点；无自旋与共线自旋（各通道的 μ，或 relax_total_spin 的共用 μ）；
    • T = 0 与 T > 0 的 Fermi 填充，熵按核心权重算；固定费米能级与每个 k 单独填充；
    • 力与应力（第三节，近似）；M7c 稀疏路径能用的电势项与能量项照样能用；
    • 本机多进程（标准库的 multiprocessing）与多机（可选的 mpi4py），结果与进程数无关，逐位相同；
    • ASE 的计算器与 MD：每一步重新分区。
  • 不做（报错并说明原因）：
    • 与 M7c 相同的那些：两分量、块势、杂化、Casida、要本征矢的分析、XL-BOMD 的力、torch；
    • MP 与 Gaussian 展宽：分治的熵与 μ 只按 Fermi 函数做（同 M7b 的 FOE）；
    • 全局的本征值与占据数：没有，结果里是 None（同 M7a）。
  • 照旧：Coulomb 的 γ 与 Ewald 的建立（第九节）。
  • DFTB+：没有空间分治。它的 MPI Parallel { Groups } 把 k 点与自旋分到进程上，pydftb 的 k 点线程（M3）在一台机器内做了这件事，多机的 k 点分组不做（小晶胞的 k 点多机意义不大，PTBP 的多结构已经分进程）。

二、探针

草稿目录 m7d/：原型 dcproto.py（串行）、dcpar.py（本机进程与线程）、dcmpi.py（MPI），探针 p112_buffers.py、p113_general.py、p115_forces.py、p115c_md.py、p116_parallel.py、p116b_threads.py、p117_mpi.py、p118_setup.py。原型是一个鸭子类型的求解器，走 M7c 的稀疏路径（sparse = True，没有本征对，有限温度），不改 pydftb。水盒子与 M7c 相同（M7a 的 water_box，约 1 g/cm³，ptbp_hcocu 的 H、O），参考是 M7c 计时时存下的本征分解结果。本机 4 核，15 GB。

文献：Yang 与 Lee（J. Chem. Phys. 103, 5674, 1995）的分治密度矩阵；Nishizawa、Nishimura、Kobayashi、Irle、Nakai（J. Comput. Chem. 37, 1983, 2016）的 DC-DFTB-K（这里的 K 是 K 计算机，不是 k 点），以及 Nishimura 与 Nakai 的周期 DC-DFTB（J. Comput. Chem. 2018，复制晶胞）与 DCDFTBMD（J. Comput. Chem. 40, 1538, 2019）。把子体系取成全局 H(k) 的主子矩阵是 pydftb 的做法：它在缓冲覆盖全部原子时精确，k 点也一样。

三、方法

  • 分区：
    • 单位：成键的片段（共价半径判定，含周期像），每个片段整个属于一个核心、整个进出缓冲区。片段大于 max_unit（默认 64 个原子，例如共价晶体、金属）时退回按原子。
    • 核心：沿三个晶格矢量把晶胞（分子是包围盒）分成边长约 core 的格子，片段按第一个原子归入格子。
    • 缓冲区：到核心里任一原子的距离（含周期像）小于 buffer 的原子所在的片段。子体系 α 的原子集合 Aα = 核心 ∪ 缓冲区。一个原子的几个像都在范围内时只算一次。
  • 子体系的矩阵：Hα(k) = H(k)[Aα, Aα]，Sα(k) 同样，取自 M7c 图样上的全局折叠矩阵。周期像之间的耦合已在折叠里，所以 Aα 等于全部原子时 Hα 就是 H(k)：精确极限。
  • 分区矩阵：pαij = (ci + cj)/2，ci = 1 表示轨道 i 在 α 的核心里：核心对核心 1，核心对缓冲 ½，缓冲对缓冲 0。
    • Pij = Σα pαij g Σn fn Cαin Cα*jn，W 同样乘 εn；只取图样上的元。
    • 每个图样元 (i, j) 只来自 i 与 j 所在的两个核心，也就是最多两个子体系。
    • 核心权重 wn = Σi∈核心 Re(Cin*(S C)in)。全局的 Mulliken 布居之和 = g Σα,k,n wk wn fn，所以电子数按核心权重来数。
  • 费米能级：
    • 所有子体系、k 点（与共用 μ 时的两个自旋通道）的 (εn, wk wn) 一起排序。
    • T = 0（kT ≤ 1e-8，pydftb 的约定）：从低往高累加权重。累加恰好到电子数（误差 ≤ 1e-7，DFTB+ 的 elecTolMax）时用 DFTB+ 的带隙中点规则；否则跨过电子数的那一级取余数（简并的几态按权重分），μ 就是这一级。精确极限走前者，有限缓冲一般走后者，μ 在带边，电子数精确守恒。
    • T > 0：二分到电子数，熵 TS = g kT Σ wk wn s(fn)。
    • 固定费米能级：直接用给定的 μ；每个 k 单独填充：每个 k 各自求 μ。
  • 能量、力、应力：都用图样上的 P 与 W，与 M7c 的稀疏路径相同的代码（能带能量、Mulliken、SCC 与 DFTB3 的项、邻居对上的 dH、dS 系数与位力）。P 不是全局问题的变分解，所以力不是分治能量的严格导数，偏差与分治误差同量级（P115），缓冲越大越小。
  • SCC：照常混合全局的电荷；分区在 SCC 中不变，每个几何重分一次。

四、并行

  • 工作进程常驻子体系：每个几何按 m3（m 为子体系的轨道数）把子体系分给工作进程，大的先分给负担最轻的。工作进程拿到图样的结构与自己的子体系（原子集合、核心标记），自己建立子矩阵的下标。
  • 每个几何：S 的图样数值传一次。
  • 每轮 SCC 两次交换：
    1. H 的图样数值传给工作进程；工作进程对自己的子体系做本征分解，留下 C，传回 (ε, w)。
    2. 主进程按子体系的固定次序拼起所有 (ε, w)，求 μ，传给工作进程；工作进程算出 P、W 的贡献，各自累加成 (通道数, nnz) 的数组传回，主进程按进程的固定次序相加。
  • 逐位相同：每个图样元最多两个非零的贡献，加零与两数相加的次序无关，所以结果与进程数、子体系的分配都无关；μ 与熵按子体系的固定次序求。前提是所有子体系的本征分解用同样的 BLAS 线程数：工作进程与主进程内的串行模式都用单线程。主进程自己的计算（Ewald 等）照用原来的线程数。
  • 本机：processes=n 用 multiprocessing 的 fork 启动 n 个工作进程，经管道通信；每个几何重新启动。不用线程：SciPy 的广义本征求解不释放 GIL（P116b）。不支持 fork 的平台退回主进程串行。
  • 多机：processes="mpi"，用 mpi4py：0 号进程跑 pydftb，其余进程在 pydftb.subsystems.serve() 里等命令；数值数组用 Bcast 与 Reduce（缓冲区接口，不经 pickle），(ε, w) 用 gather。启动方式见第六节。
  • 内存：主进程是 O(nnz) 的图样数组与 γ；工作进程是自己子体系的 C（Σ m2）。1728 个水分子、核心与缓冲 6 Å 时所有子体系的 C 共约 0.7 GB。

五、计算器的接入

  • _setup：求解器有 subsystems = True 时与 M7c 一样建图样（sparse = True），再调用 solver.set_geometry(species, pos, cell, pbc, basis, pattern)：分区、子体系的下标，多进程时启动或通知工作进程。
  • _check_subsystems：M7c 的拒绝，加上非 Fermi 的展宽。
  • _solve_density 分派到 _solve_subsystems：无自旋、两个自旋通道各自的 μ、relax_total_spin 的共用 μ、固定费米能级、每个 k 单独填充，返回图样上的 P、W，μ 与 TS（同 M7b 的 _solve_fermi_operator 的结构）。
  • 其余（布居、能量、力、应力）是 M7c 的稀疏分支，不改。
  • solvers.SOLVERS["subsystems"] = Subsystems；solver="subsystems" 用默认参数。
  • ASE：PyDFTB(solver=Subsystems(...)) 的求解器对象在各步之间共用，每一步重分区。

六、pydftb 的接口

from pydftb.subsystems import Subsystems
DFTB(sk, solver=Subsystems())                              # 核心 6 Å，缓冲 6 Å，按成键片段
DFTB(sk, solver=Subsystems(buffer=8.0, processes=4))       # 4 个本机工作进程
DFTB(sk, solver=Subsystems(processes="mpi"))               # 多机：mpiexec -n 64 python -m pydftb.subsystems run.py
DFTB(sk, solver=Subsystems(buffer=float("inf")))           # 精确极限：等于本征分解（检查用）
  • buffer、core：Å，默认都是 6.0。真实的水 6 Å 时电荷误差约 2e-5 e、力约 3e-5 Ha/Bohr，MD 的能量守恒与本征分解相同；8 Å 时与 M7c 截断 1e-6 的稀疏路径相当（第二节 P115d）。
  • units："auto"（默认：成键片段，片段大于 max_unit 时按原子）、"fragments" 或 "atoms"。
  • processes：None（默认，主进程串行，BLAS 单线程）、整数（本机工作进程数）或 "mpi"。
  • MPI 的两种启动：
    • mpiexec -n N python -m pydftb.subsystems script.py：0 号进程运行 script.py，其余进程服务；脚本不用改。
    • 脚本开头 if pydftb.subsystems.serve(): sys.exit()：非 0 号进程在这里服务，结束后返回 True。
  • 结果：没有本征值与占据数，fermi 是 μ（有限缓冲时在带边）；solver.last_count_error、子体系的个数与大小、各段耗时。
  • 可选依赖：pydftb[mpi] 装 mpi4py；没有它时 processes="mpi" 报错并说明。必需的依赖不变（NumPy、SciPy、ASE、threadpoolctl）。
  • 建议：缓冲区小于 6 Å 时给一个电子温度（如 300 K），否则 SCC 可能不收敛（第二节 P114）。

八、验证 开发细节

  • 精确极限：分子、Γ 点、k 点、两种共线自旋、T > 0、DFTB3、色散、外场、点电荷、固定费米能级：能量、电荷、力、应力到舍入（≤ 1e-11）等于本征分解，费米能级与 SCC 轮数相同。refgen 的全部适用算例。
  • 有限缓冲：水盒子的误差界（与 P112 一致）；按片段的分区保持分子完整；周期像与斜晶胞的缓冲区。
  • 逐位相同：主进程串行与 1、2 个本机工作进程；MPI（装了 mpi4py 与 mpiexec 时，用子进程跑 mpiexec -n 2，否则跳过）。
  • 拒绝的原文；ASE 的 MD 冒烟测试。
  • 大体系（报告）：水 1000–1728 个分子的耗时与 1、2、4 个进程的加速，对本征分解与 M7c 的稀疏路径。
  • 门槛：golden 两个环境逐位相同（新的 _Setup 字段要加 --allow-new），refgen（NumPy、torch、sparse、foe、subsystems），dynamics，pytest 三个环境（可选库缺失时跳过），PTBP 测试与 G1。

九、风险与之后

  • 金属：几个 Å 的缓冲远远不够（P113：Cu 到 5 Å 时每个原子的能量差仍有 4e-4–7e-4 Ha），分治只用于有带隙的体系；文档写明。
  • 同等精度下的速度：真实的水要 8 Å 才到稀疏路径 1e-6 的精度，单机 4 核上分治估计更慢（第二节），报告里实测。分治的定位是多机与 MD 级的精度，不是取代稀疏路径。
  • 小缓冲区与 T = 0：带隙里的边界态会让 SCC 不收敛；默认 6 Å，文档建议小缓冲区配电子温度。
  • 力的一致性：力不是分治能量的严格导数，MD 的能量守恒取决于缓冲区（P115c）。分区在步与步之间变化时能量有小的跳跃。
  • 传输量：本机每轮把 H 传给每个工作进程。几千个水分子以内不是瓶颈；需要时改共享内存。
  • 建立阶段：Ewald 的实空间对表在 N1.5 增长，几千个水分子以上放不下（P118）。紧接 M7d 的一块：实空间部分分块计算、不存对表（力也分块），γ 之外的内存降到 O(N)；小体系保留原来的代码，golden 逐位不变。再往上要不建 γ 的电势（每轮用结构因子），之后再做。
  • 之后：大体系的 Coulomb（上一条）；M7e GPU 自检与跨结构批量。
