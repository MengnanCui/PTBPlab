关键信息

M7 做大体系。第一块 M7a 是不用本征分解、只用矩阵乘法求密度矩阵的求解器。DFTB+ 通过 ELSI 提供这类求解器：Solver = NTPoly（四种纯化）、OMM、PEXSI；另有三种 LAPACK 驱动与 ELPA。pydftb 照 NTPoly 的代码移植四种纯化，逐轮复现 DFTB+；三种 LAPACK 驱动也照做。在 DFTB+ 不支持的地方，pydftb 继续做：自旋通道、两分量、k 点、杂化泛函、torch 设备与混合精度。

  • 参考程序：
    • 本机 conda 的 DFTB+ 25.1 没有 ELSI。conda-forge 的 25.1 MPICH 版把 ELSI 列为依赖，但没有链接它，选这些求解器时报 “Not compiled with ELSI supported solvers”。
    • 24.1 的 MPICH 版链接了 ELSI 2.9.1（ELPA 2021.11、NTPoly 2.7.1、libOMM 1.0；没有 PEXSI），用作参考。它用 LAPACK 时与 25.1 冻结的参考差 ≤ 1e-13，SCC 轮数相同。
  • P100：pydftb 移植的 NTPoly 在 9 个算例 × 6 种设置上复现 DFTB+：
    • SCC 轮数全部相同，包括 TRS2 在默认容差下多出的轮数；
    • 能量差 ≤ 1.1e-10 Ha（DFTB+ 打印 10 位小数）；
    • 化学势在默认设置下差 ≤ 1e-11 Ha。
  • 精度（P99，DFTB+ 的 NTPoly 对它自己的对角化）：
    • 默认的 TRS4 ≤ 2.4e-8 e，把容差收紧也不变，原因是迭代在 tr G < 1e-14 时提前退出；
    • TRS2 在默认容差 1e-5 下差到 2.7e-4 e，收紧容差后精确到 1e-14；
    • PM、HPCP 约 1e-10–1e-9。
  • 发现的 DFTB+ 问题：
    • B28：NTPoly 用稠密输入（Sparse = No）且有块势（+U、onsite）时结果错，H2O 4.3e-3 Ha，水盒子 3.6e-2 Ha。
    • B29：没有自旋而电子数为奇数时，NTPoly 把电子数悄悄进到偶数，H2O+ 按中性水算。
    • OMM：16 次默认设置的运行里 9 次 SCC 不收敛，其余要多 3–30 倍的轮数。pydftb 不实现 OMM。
  • 速度（P102，本机 4 核）：稠密纯化比本征分解慢 4–6 倍（1296–3072 个轨道）。它的用处在 GPU 上；GPU 的实测等用户运行自检脚本。
  • 54 / 54SCC 轮数与 DFTB+ NTPoly 相同
  • ≤ 1.1e-10能量对 DFTB+ NTPoly（Ha）
  • 2新发现的 DFTB+ 问题（B28、B29）
  • 4–6×CPU 上纯化比本征分解慢

一、M7 的分块

路线图里的 M7 是 “大体系：GPU 混合精度 SP2、Chebyshev、分治多机”，CPU 原型见 RESEARCH.md 第三节。按功能分五块，每块照常有探针、设计、实现、门槛与报告：

块内容对照
M7a稠密的免对角化求解器：DFTB+ 的 NTPoly 纯化（PM、TRS2、TRS4、HPCP）、LAPACK 驱动、ELPA；自旋通道、两分量、k 点、杂化；torch 设备与混合精度DFTB+ 24.1 + ELSI；pydftb 的本征分解
M7b有限温度的免对角化：Chebyshev 费米算符展开（金属、自旋共用费米能级、熵）pydftb 的本征分解（DFTB+ 的 PEXSI 不在这些构建里）
M7c稀疏的线性标度：块稀疏的 H、S，稀疏的 S−1/2 与带截断的纯化（NTPoly Sparse = Yes 的对应），O(N) 的布居与力DFTB+ 的 NTPoly；本征分解
M7d分治（divide-and-conquer）：按空间分块加缓冲区，多进程与多机本征分解（缓冲区收敛）
M7eGPU 自检脚本的新项目与跨结构批量用户的 GPU

二、DFTB+ 的求解器与范围

  • M7a 越过 DFTB+ 的部分（只要密度矩阵与能量加权密度矩阵的功能都可以用纯化）：
    • 共线自旋（固定总自旋，每个通道各自纯化）；
    • 两分量（非共线、SOC，2N × 2N 的复矩阵，每个能级一个电子）；
    • k 点（每个 k 各自纯化，占据数相同，只适用于有带隙的体系）；
    • 杂化泛函（分子、Γ 点、k 点）、+U、onsite、DFTB3、外场、点电荷、溶剂、色散；
    • 力、应力、结构优化与 MD（含 XL-BOMD）；
    • torch 设备与混合精度。
  • 拒绝：
    • 要本征值或本征矢的功能：Casida、响应与坐标导数、eigenvec.out、SCC 自己的 band.out、Pipek–Mezey、固定费米能级、每个 k 单独填充（能带与 DOS 的后处理在 SCC 电荷上自己对角化，照样可用，见报告）；
    • 自旋共用费米能级（relax_total_spin）；MP 与 Gaussian 展宽（DFTB+ 的原话）；
    • 每个通道的电子数不是整数（DFTB+ 悄悄进位，B29）。

三、探针与原型

草稿目录 m7a/：p99_elsi.py、p99b_odd.py（DFTB+ 24.1），ntproto.py、ommproto.py（原型），p100_compare.py，p102_timing.py。NTPoly 2.7.2 与 ELSI 2.9.1 的源码只在草稿目录里参考。

探针内容结果
P99DFTB+ 24.1 + ELSI 在 9 个有带隙的冻结算例（分子、Γ 点水盒子、onsite、自定义 U、H5、DIIS）上：三种 LAPACK 驱动、ELPA 两种模式、NTPoly 四种方法（默认与收紧）、稠密输入、OMM 四种设置；另跑拒绝与边界情况，共 188 次
  • LAPACK 与 ELPA：对 25.1 的参考 ≤ 1e-13，轮数相同。
  • NTPoly：TRS4 ≤ 2.4e-8 e（收紧也不变），TRS2 默认 ≤ 2.7e-4 e（水二聚体多 2 轮），PM、HPCP ≤ 1.7e-9；费米能级与 LAPACK 的差 1e-5–3e-2 Ha（它是纯化多项式的 0.5 等值点，不是 HOMO–LUMO 的中点）。不写本征值，不打印 Mermin 自由能。
  • OMM：9 次 SCC 不收敛，其余轮数是 LAPACK 的 3–30 倍，nIterationsELPA = 0 时一次收敛到差 75 Ha 的态。
  • 拒绝原文：“Solver does not currently support spin polarisation”“This electronic solver can only be used for Fermi function distributed electrons”“This solver requires as many parallel processor groups as there are independent spin and k-point combinations”“This solver currently requires spin values to be relaxed”。
  • Cu4CO 300 K：NTPoly 给 T = 0 的密度（电荷差 2.1e-3 e），不报错。
P99 稠密输入Sparse = No 对 Sparse = Yes：没有块势、+U、+U 加 onsite、onsite相同、5.3e-6、2.2e-2、4.3e-3–3.6e-2 Ha（B28）。DFTB+ 的 unpackHSRealBlacs 把原子自身的块照原样写进稠密矩阵，只对不同原子的块写转置；LAPACK 与 ELPA 只读一个三角，NTPoly 的稠密输入读整个矩阵。最可能的原因是带块势的对角块不对称。
P99b奇数电子、没有自旋：OH、H2O+LAPACK 正确；NTPoly 按 2·nint(N/2) 个电子算：OH 的净电荷 −1，H2O+ 的能量与中性水逐位相同（B29）。
P100pydftb 的 NTPoly 原型（ISR、四种方法、化学势、能量加权密度矩阵、截断）接在 pydftb 的 SCC 上，对 P99 的 DFTB+ NTPoly54 次运行：SCC 轮数全部相同；能量差 ≤ 1.1e-10 Ha；化学势在默认设置下 ≤ 1e-11 Ha。收紧容差时化学势的二分法达不到 |p − 0.5| < 1e-10，走满 100 步，结果随舍入变，差到 4e-4 Ha。水盒子对冻结参考的 1.3e-7 Ha 是参考用了 DFTB+ 默认的 Ewald 容差（pydftb 的本征分解同样差 1.32e-7）。
P101libOMM 的原型（Polak–Ribière CG、精确的四次线搜索、能量的相对变化作收敛判据）60 维随机矩阵：容差 1e-10 时密度差 7e-5，1e-14 时 2e-6。判据只看能量，密度收敛得慢，这正是 P99 里 SCC 不收敛的原因。
P102本机 4 核：水盒子（64、216、512 个水，384–3072 个轨道）的非 SCC H0，本征分解对 TRS4、TRS2（DFTB+ 默认与收紧）与 float32 迭代
  • 3072 个轨道：本征分解 3.2 s，TRS4 19 s，TRS2 收紧 16 s，float32 14 s。
  • float64 的电荷误差 ≤ 1.5e-12（3072）；64 个水时 TRS4 收紧后反而是 6e-8：收敛后 σ 的步骤不保持迹。
  • float32 迭代后接 float64 的步骤：能量差 5e-11 Ha（二阶），电荷差 2–3e-6 e。float32 舍入造成的子空间误差，之后只用 X 的多项式步骤修不掉。

四、算法

照 NTPoly 2.7（DensityMatrixSolversModule.F90、SquareRootSolversModule.F90）与 ELSI 2.9（elsi_ntpoly.f90）。下面的 X 是正交基里的投影（每个轨道占据 1），n 是矩阵维数，ne 是一个通道的 “电子数” 参数（见下）。

S−1/2

  • 耦合的 Newton–Schulz（Taylor 五阶）：λ = 1/max(|emin|, |emax|)（Gershgorin），Z0 = I，Y0 = λS；每步 X = Z Y − I，范数取列绝对值和的最大值；X 的五阶多项式（系数由 −40/35、48/35、−64/35、128/35 给出）乘到 Z 左边与 Y 右边；范数 ≤ Tolerance 后再走一步才退出。Z·√λ = S−1/2。
  • 截断 max(0.01·Truncation, 1e-15)。每个几何算一次。

四种纯化

H̃ = Z H ZT（每次乘法后截断）。四种方法共用两件事。收敛判据：每步之后 E = 2 tr(X H̃)，|E − E前| ≤ Tolerance 时退出。化学势：在 [0, 1] 上二分，把每步的多项式依次作用在中点上，找出映到 0.5 的点；|p − 0.5| < Tolerance 或走满 100 步就停。二分只用 “退出步数 − 1” 步，最后一步不计入，这是 NTPoly 的 outer_counter − 1。

方法起点每步化学势
PM（0）λ = tr H̃/n，α = min(ne/2/(emax − λ), (n − ne/2)/(λ − emin))，X0 = α/n (λ − H̃) + ne/(2n)c = tr(X² − X³)/tr(X − X²)；c > ½：X ← ((1+c)X² − X³)/c，否则 ((1−2c)X + (1+c)X² − X³)/(1−c)λ − (n·mid − ne/2)/α
TRS2（1）X0 = (emax − H̃)/(emax − emin)tr X > ne/2：X²；否则 2X − X²emax + (emin − emax)·mid
TRS4（2，默认）同 TRS2F = X²(4X − 3X²)，G = X²(I − X)²，σ = (ne/2 − tr F)/tr G；σ > 6：2X − X²，σ < 0：X²，否则 F + σG；|tr G| < 1e-14 时直接退出同 TRS2
HPCP（3）μ = tr H̃/n，β1 = ne/(2n)，β2 = min(β1/(emax − μ), (1 − β1)/(μ − emin))，D0 = β1 + β2(μ − H̃)σ = tr(D²(I − D))/tr(D(I − D))，D ← D + 2D²(I − D) − 2σD(I − D)μ + (β1 − mid)/β2
  • 密度：P = g·ZT X Z（g = 2 闭壳层，1 自旋通道与两分量）；能量加权密度矩阵 W = P H P / g（ELSI 的 EnergyDensityMatrix）。每次乘法后截断。
  • 复矩阵（k 点、两分量）：迹与 tr(AB) 取实部，转置换成共轭转置。

电子数、自旋与 k 点

  • DFTB+/ELSI 把 ne = 2·nint(N/(nspin·g)) 交给 NTPoly，奇数时进位（B29）。pydftb 要求每个通道的占据数 N/g 是整数，否则报错。
  • 共线自旋（固定总自旋）：上、下自旋各纯化一次，占据数 n↑、n↓，各有一个化学势（fermi_spin）。
  • 两分量：一个 2N × 2N 的厄米矩阵，占据数 N。
  • k 点：每个 k 纯化一次，占据数相同。这只对每个 k 的占据带数相同的体系（有带隙）成立；报告的费米能级是各 k 化学势按权重的平均。
  • 温度：纯化给出 T = 0 的投影（DFTB+ 相同）。Fermi 填充的 T > 0 时警告；MP 与 Gaussian 报错（DFTB+ 的原话）。

混合精度

  • precision="mixed"：S−1/2 与 H̃ 用 float64，纯化先用 float32 迭代。tr(X − X²) 到达 float32 的噪声（10·n·ε32），或者已小于 1e-2·√n 而两步内不再下降时，转到 float64，最多再走 4 步或到 NTPoly 的判据满足。P、W 用 float64。原先设想的能量判据（|ΔE| 不再减小就转）让 TRS2 过早停下、HPCP 走满 100 步，所以实现改用这个幂等性判据（见报告第八节）。
  • 精度（P102）：能量 ≈ 5e-11 Ha，电荷 ≈ 3e-6 e。float32 引入的子空间误差（占据与空轨道之间的混合）只靠 X 的多项式修不掉，文档写明；要 1e-10 的结果用 float64。在 SCC 里，scc_tol < 1e-5 时警告（1e-10 时 Broyden 不收敛）。

LAPACK 驱动

  • "qr" = hegv，"divideandconquer" = hegvd（等于 pydftb 一直用的 "eigh"），"relativelyrobust" = DFTB+ 的 hegvr：Cholesky，hegst 化成标准形式，heevr（abstol = 安全最小值），trsm 回代。结果只在舍入上不同（P99 ≤ 1e-13）。
  • "elpa"：ELPA 是并行的本征分解，结果与本征分解相同，取 "eigh"。

五、pydftb 的接口

DFTB(sk, solver="ntpoly")                    # DFTB+ Solver = NTPoly {}：TRS4，1e-5，1e-10
from pydftb.purification import NTPoly
DFTB(sk, solver=NTPoly(method="trs2", tolerance=1e-10, truncation=0.0))
DFTB(sk, solver=NTPoly(precision="mixed"), backend="torch", device="cuda")
DFTB(sk, solver="relativelyrobust")          # 或 "qr"、"divideandconquer"、"elpa"
  • method："pm"、"trs2"、"trs4"、"hpcp"，或 DFTB+ 的 0–3。
  • 结果：eigenvalues 与 occupations 为 None，fermi 是化学势（自旋时 fermi_spin），TS = 0；solver.last_iterations 记录当前几何每次纯化的步数，solver.isr_iterations 记录 S−1/2 的步数。
  • PyDFTB(solver=...) 同样可用；solver="omm"、"pexsi" 报错并说明原因。
  • 原来的 "sp2" 原型（M0，Kruchinin 判据）保持不变。

八、风险与之后

  • 速度：本机上稠密纯化比本征分解慢 4–6 倍，价值在 GPU 与之后的稀疏版（M7c）。GPU 的耗时写进自检脚本，由用户实测。
  • 精度：DFTB+ 的默认 TRS4 有 1e-8 量级的误差，TRS2 默认容差下有 1e-4 量级的误差；pydftb 照搬（为了逐轮对照），文档写明怎样设置得到精确结果。
  • k 点：每个 k 的占据数相同，只适用于有带隙的体系；金属会悄悄给出错误的占据（与 DFTB+ 的组并行相同），文档写明。
  • OMM：不实现。DFTB+ 的 OMM 在 P99 里大多不收敛；M7c 的稀疏版若需要局域轨道的极小化，另作设计。
  • 之后：M7b 有限温度（Chebyshev），M7c 稀疏线性标度，M7d 分治，M7e GPU 与批量。
