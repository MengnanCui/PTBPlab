关键信息

M6g-3 原计划一块做完：+U、onsite 修正、非共线自旋与 SOC 下的响应，以及开发版 DFTB+ 的 ExternalChargeDerivatives。量较大，按“量大时单列”拆成两块：

  • M6g-3a（本块）：DFTB+U（FLL、pSIC）与 onsite 修正进入 M6g-1、M6g-2 的三种响应（极化率、响应核、坐标导数），以及原子电荷对外部点电荷位置的导数；
  • M6g-3b：两分量（非共线自旋、SOC 的 onsite 与 dual 两种模型）下的三种响应。
  • DFTB+ 的情况（第一、二节）：
    • 25.1 的极化率与响应核支持 +U 与 onsite，但两者同用时拒绝；坐标导数遇到任何一种都拒绝；
    • ExternalChargeDerivatives 只有开发版有：分子的 tag dqdxext 是原子电子布居 N 对点电荷坐标的导数 dN（e/Bohr；detailed.out 的标题写“charges”，数值同样是 dN，单位 e/Å）；周期体系（Ewald）也能算，但符号反了（倒空间与实空间的导数对原子而不是对点电荷求，见第六节）；WrtCharges 只对部分点电荷；
    • DFTB+ 的 +U、onsite、两分量极化率与它自己的差分一致到差分的精度（约 1e-6，受 detailed.out 偶极的 8 位小数限制），没有看到错误。
  • pydftb 的做法（第三、四节）：
    • 块势是块布居的仿射函数 V = L(Q) + 常数。把原子块的矩阵元作为 χ0 的新通道（算符 ½(S Ec + EcS)），未知量加上块布居，核取 L：与 M6g-1 的直接解法一致，不迭代；
    • 坐标导数再加两项：基态块势的 ½(S′V + VS′)，以及密度不变时块布居的变化 ½(ρS′ + S′ρ)；
    • 对点电荷位置的导数只是一个外势 dVA/dRj（分子与 Ewald），没有 H0、S 的变化。
  • 原型（草稿目录 m6g3/proto_block.py）：静态极化率与 DFTB+ 25.1 一致，Cu4CO 的 FLL +U（300 K 的金属，α ≈ 162）3.7e-11，pSIC 1.2e-11，GdO 的共线自旋 + f 壳层 +U 1.0e-12，水与甲醇的 onsite 修正 7e-14 与 8e-13。
  • ≤ 3.7e-11原型的极化率与 DFTB+ 25.1 之差（a.u.，5 个体系）
  • 3接受块势的响应：极化率、响应核、坐标导数
  • 1新分析：对外部点电荷位置的导数（DFTB+ 只有开发版）

一、DFTB+ 的做法

源码为 041e723（derivs/perturb.F90、derivs/linearresponse.F90、dftbplus/initprogram.F90、dftbplus/main.F90、dftbplus/parser.F90），行为以 25.1 与开发版的二进制为准。

  • 块势的响应：有 OrbitalPotential（+U）或 OnsiteCorrection 时，响应循环像基态一样混合块布居 dqBlockIn/dqBlockOut：
    • 响应的输出块布居是 dρ 的对偶 Mulliken 块 ½(dρS + Sdρ)AA；
    • 它的势是 +U 与 onsite 的块势对布居的线性部分（FLL 的常数项、onsite 的参考布居都不进入），经 ½(SV + VS) 进入 dH；
    • 混合向量与基态相同（轨道类的和、块的非对角元），用基态的混合器迭代。
  • 限制：+U 与 onsite 同用时报 “Onsite corrected and DFTB+U terms currently not compatible for perturbation”；坐标导数遇到 +U 或 onsite 都拒绝（dxAtom 中块的部分被注释掉）。
  • ExternalChargeDerivatives（开发版，dxExtCharges）：对每个点电荷 j 与方向 c，外势在各原子上的导数 dVA/dRj,c（周期体系含 Ewald）作为微扰，H0、S 不变，响应循环与电场相同；输出 dqdxExt(A, c, j)。输入 ExternalChargeDerivatives = Yes，或 { WrtCharges = … } 只对列出的点电荷（1 起）。

二、DFTB+ 的实测行为

探针 P25–P28（草稿目录 m6g3/），测试参数 ptbp_hcocu，算例取自 M6b、M6c 的参考算例加上分析选项。

探针内容结果
P25 支持Cu4CO 的 +U（FLL、pSIC）、水与甲醇的 onsite、OH 与 O2 的非共线与 SOC、Cu4CO 的 SOC、OH 的非共线 + U、Cu4CO 的 +U + onsite；极化率、响应核、坐标导数
  • 极化率与响应核：除 +U + onsite 外都能算；
  • 坐标导数：+U、onsite、非共线、SOC 全部拒绝（后两者报 “Spin polarised calculations are not yet supported …”）。
P26 正确性DFTB+ 的解析极化率对它在外场中偶极的差分（二阶 h = 1e-4，四阶 h = 1e-3）
  • 二阶：相对差 1.4e-6–8.7e-6（差分的 O(h²)）；
  • 四阶：+U、onsite、两分量 4e-7–1.9e-6，没有块势与两分量的水、甲醇、Cu4CO 也是 3e-7–6e-7：下限是 detailed.out 中偶极的 8 位小数，看不到 DFTB+ 的错误。
P27 输出+U 与 onsite 的极化率与响应核与 M6g-1 相同的 tag（staticPolResponse、staticChargeReponse、dEidEfield、dqdV、dqnetdV、dEidV，金属另有 neFermi、dEfdE）与 detailed.out 块，现有的解析与比较可以直接用。
P28 点电荷水与 3 个点电荷（开发版）；周期的水盒子（Ewald）；带展宽的点电荷与 WrtCharges = 2
  • tag dqdxext（维度 nAtom × 3 × n电荷）：分子是电子布居的导数 dN（e/Bohr），与 pydftb 自己移动点电荷的差分一致；周期体系是 −dN（DFTB+ 自己的差分也确认，|差分 + tag| = 4.9e-6）；
  • detailed.out：“Derivatives of atomic charges w.r.t. coordinates of external charges”，每个点电荷一块（“Chg#j x y z”，行 “AtA”），数值与 tag 相同，单位 e/Å；
  • 标准输出逐个位移打印 Mulliken 与净布居的导数，符号与 tag 相反；
  • 周期体系、展宽、WrtCharges 都能算；也写出点电荷受的力。

三、pydftb 的接口

r = DFTB(sk, plus_u={"Cu": [("d", 0.2)]},
         analysis={"polarisability": True, "response_kernel": True,
                   "coord_derivatives": True}).calculate(labels, pos)

calc = DFTB(sk, point_charges={"positions": R, "charges": Q},
            analysis={"external_charge_derivatives": True})        # 或 {"charges": [0, 2]}
e = calc.calculate(labels, pos).analysis.external_charge_derivatives
e.charges            # 求导的点电荷（0 起）
e.atom               # (n_j, 3, n_qm, n_atom)：dN_B/dR_j,c（电子布居，e/Bohr）
e.orbital            # (n_j, 3, n_qm, n_orb)
print(dftbplus_io.external_charge_tables(r))   # DFTB+ detailed.out 的块（dN，e/Å）
  • 块势：没有新选项。极化率、响应核、坐标导数接受 plus_u（FLL、pSIC）与 onsite_corrections，两者同用也可以（DFTB+ 拒绝），可与共线自旋、k 点（电荷响应）、DFTB3、外场同用。
  • 点电荷导数：需要 point_charges；分子与周期体系；与 M6g-1 一样可与共线自旋、金属、DFTB3、+U、onsite 同用；结果与 coord_derivatives 一样用电子布居 dN，与开发版分子的 tag 与 detailed.out 相同；周期体系开发版的符号是反的，pydftb 不照抄。
  • 拒绝：两分量（M6g-3b）以及 M6g-1 拒绝的其他组合（非 Fermi 展宽、溶剂、只 onsite 的三阶、偶极修正、每个 k 点单独填充、选定壳层、XL-BOMD、torch 与自动求导）；坐标导数仍只用于分子。
开发细节四、实现

块通道

  • 对 BlockTerms 中的每个原子 k，取块势会碰到的矩阵元：+U 是各组的 idx × idx，onsite 是整个原子块；对称元素 i ≤ j 各算一个通道 c。
  • 通道的势 V = v·Ec，Ec = (Eij + Eji)/(1 + δij)；算符 Oc = ½(S Ec + EcS)；共轭的布居 Pc = Tr(ρOc) = (2 − δij)Qij，Q 是对偶块布居 ½(ρS + Sρ)AA。
  • 分子轨道基中的矩阵元 mcai = ½[(Sca)*μcνi + (Sca)*νcμi + c*μa(Sci)ν + c*νa(Sci)μ]/(1 + δμν)；μ = ν 时就是 M6g-1 的逐轨道矩阵元。

χ0 与求解

  • χ0 的行是逐轨道的 Mulliken 布居与块通道的 Pc，列是壳层势与块通道的势：χ0[r, c] = Σp gp Re(conj(mrp)mcp)，对 M6g-1 的成对权重 g 一次累加（各频率同时）。
  • 金属的费米能级移动仍是秩 1 修正，行、列的向量 d 加上块通道的分量 dc = ΣkwkΣi∈Wδimcii。
  • 共线自旋先按 up/down 分块，再像壳层一样换成 (q, m)：块布居 Qq,m = Q↑ ± Q↓，势 V↑,↓ = Vq ± Vm。
  • 未知量 x = (SCC 位点上的 dq，壳层上的 dm，每个自旋分量的块布居 dQc)；B 把 x 映到势：γ（加完整三阶的 Hessian）、W，以及块核 L(dQ) = potentials(dQ) − potentials(0)（逐个单位块求出，L 只依赖参数，与基态无关）。
  • (I − AB)x = A Vext（M6g-2 的坐标微扰再加 x0），vtot = Vext + Bx，布居 = χ0vtot。
  • 本征值导数与费米能级导数：M 加上块势 ½(S dV + dV S) 的对角元（简并组取组内块的本征值）。
  • 响应核的净布居：χ0 的净布居行同样加上块通道的列。

坐标导数

  • H′ 再加基态块势的项 ½(S′Vs + VsS′)（每个自旋分量 s，V 取最后一个 H 的块势），进入 M = CTH′C；
  • 块布居的变化 dQ = ½(dρS + Sdρ)AA + ½(ρS′ + S′ρ)AA，前一项由裸的一阶密度 CXCT 的原子块求出，后一项是密度不变时的变化；它们作为 x0 的块分量；
  • Born 电荷的公式不变。

对点电荷位置的导数

  • ExternalTerms.pc_jacobian()：dVA/dRj = Qjφ′(d)(rA − Rj)/d（展宽时 φ 用 erf 的形式），周期体系另加倒空间项 −QjΣGg(G) sin(G·(rA − Rj))G；
  • 每个 (j, c) 一列外势（原子 A 的各壳层同值），x0 = 0，与电场相同的求解；结果 dN、逐轨道 dN。

改动的位置

  • response.py：块通道（BlockChannels）、χ0 与 Response 的扩展、本征值与费米能级导数、坐标导数的块项、external_charge_derivatives 与结果类；
  • external.py：pc_jacobian；analysis.py：external_charge_derivatives 选项与结果；calculator.py：_check_response 放开块势（两分量仍拒绝），点电荷导数需要点电荷；
  • dftbplus_io.py：external_charge_tables；验证工具：ExternalChargeDerivatives 的输入（开发版）与 tag、detailed.out 的解析与比较。

六、DFTB+ 的问题与 pydftb 的做法

DFTB+pydftb
+U 与 onsite 同用时拒绝响应可以同用（块核是两者之和）
坐标导数拒绝 +U 与 onsite加上块势的 S′ 项与块布居的非变分项
点电荷导数只在开发版；tag 与 detailed.out 是 dN（标题却写“charges”），单位分别是 e/Bohr 与 e/Å结果用 dN（与坐标导数一致），写出的块与开发版相同
周期体系的点电荷导数符号反了：calcInvRPrimeAsymmPeriodic 的实空间与倒空间导数对 rA − Rj 求（即对原子），分子版 calcInvRPrimeAsymmCluster 才是对点电荷求周期与分子用同一个符号（dN）；验证时把开发版周期体系的值换号再比较，并用 pydftb 自己的差分确认

七、不做的事与风险

  • 不做：两分量（M6g-3b）；多极 DFTB；块势对点电荷导数以外的新导数。
  • 风险：
    • onsite 修正让每个原子的整个块都成为通道（Cu 的 sd 基 81 个元素中 45 个对称元），大体系时 χ0 的块部分变大：只在有块势的原子上建通道，按需再改成无矩阵的解法；
    • k 点时块矩阵元是复数，只取对称（实）部分；虚部只在 dual SOC 时出现（M6g-3b）。
