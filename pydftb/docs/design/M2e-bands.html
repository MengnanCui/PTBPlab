关键信息

在已经收敛的电荷上，求任意 k 点的本征态，给出能带（沿 k 路径）、态密度（DOS）和投影态密度（PDOS），与 DFTB+ 的两步算法和 dp_dos 脚本逐项一致。

  • DFTB+ 分两次运行：先在 k 网格上做 SCC 并写出 charges.bin；再读回电荷，在 Klines 路径上只算一轮。pydftb 在同一个进程里做第二步：用 SCC 最后一轮的输入布居（正是 charges.bin 的内容）建一次势，然后分批对角化。
  • 探测实验：多原子晶胞的第二次运行必须写 ConvergentSCCOnly = No，否则 DFTB+ 报“SCC 未收敛”退出；单原子晶胞不需要（原子布居恒等于电子数，SCC 误差恒为 0）。
  • 投影权重沿用 DFTB+ ProjectStates 的定义：本征态 c 在轨道 μ 上的份额 Re[cμ*(S c)μ]，对全部轨道求和为 1。
  • DFTB+ 本身不做展宽，DOS 曲线由 dptools 的 dp_dos 生成。pydftb 的 dos() 用与它相同的展宽函数、截断和能量网格。
  • 验收：本征值差 ≤ 1e-8 Ha；投影权重差 ≤ 1e-6（DFTB+ 区域文件只有 6 位小数）；同一输入下 DOS 曲线与 dp_dos 相差 ≤ 1e-10。
  • 6计划的 DFTB+ 对照算例
  • 1e-8 Ha本征值验收标准
  • 0新增依赖（ASE 已是依赖）
实施中的变化（详见完成报告第四节）：玻尔兹曼常数的统一从 M2f 提前到本阶段；排查本征值残差时把短程 γ 的截断也改成了 DFTB+ 的规则；绝缘体的路径费米能级改为与能隙中点比较（DFTB+ 的 middleGap 有舍入问题）。

一、目标与用途

SCC 计算给出的是基态：总能量、力、电荷，以及计算所用 k 网格上的本征值。分析电子结构还需要另外两样东西：

  • 能带：沿布里渊区中一条折线（k 路径，例如 fcc 的 Γ–X–W–L–Γ–K）画出本征值，看带隙、色散和简并。路径上的点不适合做 SCC（它们不是对布里渊区的均匀取样），所以电荷要沿用 SCC 的结果，只做一次对角化。
  • 态密度（DOS）和投影态密度（PDOS）：把本征值展宽成连续曲线，看各能量处有多少电子态；PDOS 再把每个态按原子、壳层或轨道拆开，例如 Cu 的 d 带在哪里、O 的 p 态在哪里。

用途：分析计算结果；PTBP 的能带拟合模式（--optimization_option bandstructure）需要在固定电荷下求路径上的本征值。PTBP 这一模式本身的错误另有任务处理，本阶段只提供 pydftb 一侧的能力。

二、DFTB+ 怎么算能带和 DOS

两次运行

  1. SCC 运行：在 k 网格上（如 SupercellFolding）做 SCC。结束时 DFTB+ 写出 charges.bin，内容是最后一轮的输入布居（收敛后不再混合，见 main.F90 的 getNextInputCharges）。
  2. 能带运行：同一目录，ReadInitialCharges = Yes 读回电荷，k 点换成 Klines。DFTB+ 发现是 Klines 时把 MaxSCCIterations 的默认值设为 1，于是只建一次哈密顿量、对角化一次。本征值写进 band.out（4 位小数的 eV）和 results.tag（全精度 Hartree）。
容易踩的坑：只算一轮时，路径上的输出电荷与读入电荷不同，DFTB+ 判定“SCC 未收敛”并报错退出，所以多原子晶胞要加 ConvergentSCCOnly = No。单原子晶胞（如 Cu fcc）是例外：唯一原子的布居恒等于电子数，SCC 误差恒为 0，不加也能跑。

Klines 的规则

每行“N k”表示从上一个点走到 k，取 N 个等距点：不含起点、含终点。第一行之前隐含一个 Γ 点 (0, 0, 0)。N = 0 表示跳到 k 而不取点，下一段从 k 出发（同样不含 k）。所以常见写法是第一行 1 0.0 0.0 0.0（只取 Γ 本身），之后每段写段内点数。k 点权重全部为 1（再归一化）。

投影态（PDOS 的原始数据）

Analysis { ProjectStates { Region { ... } } } 为每个区域写一个文件。区域由一组原子定义，可以按壳层拆（ShellResolved，每个壳层一个文件 标签.壳层号.out）或按轨道拆（OrbitalResolved，标签.壳层号.m.out）。文件中每个 k 点、每个自旋一块，每个本征态一行：本征值（eV，6 位小数）和该态在区域轨道上的权重（6 位小数）。权重不乘占据数，也不乘 k 点权重。

展宽成曲线

DFTB+ 不输出 DOS 曲线。官方工具 dp_dos（dptools）读 band.out 或区域文件，用 Gaussian（默认，σ = 0.1 eV，截断 3.5σ）、Fermi 函数导数或 Methfessel-Paxton 函数展宽，能量网格间隔 0.01 eV。不加 -w 时每个态权重为 1（总 DOS）；加 -w 时用第二列（band.out 中是占据数，区域文件中是投影权重）。

三、pydftb 的做法

冻结电荷求本征态

新模块 pydftb/bands.py 的核心函数 eigenstates 做 DFTB+ 第二次运行的事：

  1. 用计算器的第一段（_setup）建实空间的 H0、S 对块和库仑核，但不在 SCC 网格上折叠矩阵；
  2. 用给定的布居一次性算出电荷势（含 DFTB3 三阶项）和自旋势（_potentials，与 SCC 循环用的是同一个函数）；
  3. 把 k 点分批：每批折叠出 H0(k)、S(k)，加上势，求广义本征值问题。分批是为了控制内存（每批的复数矩阵约占 200 MB 以内）。

布居用 SCC 最后一轮的输入布居 q_in，这正是 DFTB+ 写进 charges.bin 的量，因此 SCC 网格上的本征值与 SCC 本身的结果完全相同。DFTBResult 新增字段 q_in 保存它。

占据数

与 DFTB+ 第二次运行一样，按同样的展宽方式和电子数，在新的 k 点集合上重新求费米能级和占据数（States.occupations、States.fermi）。画能带时的参考能量则用 SCC 运行的费米能级（States.scc_fermi），路径上的费米能级没有物理意义。

投影权重与 PDOS

需要时（projections=True）对每个态保存 wμn = Re[cμn*(S c)μn]。区域权重是对区域内轨道求和。选择方式与 DFTB+ 的 Region 一一对应：一组原子；可再限定一个壳层（ShellResolved 的一个文件）；可再限定磁量子数 m（OrbitalResolved 的一个文件）。

DOS 曲线

broaden() 照搬 dp_dos：同样的三种展宽函数和归一化、同样的截断宽度、同样的网格起点（向下取整到网格间隔的整数倍）。唯一的差别是累加的顺序（pydftb 向量化），只影响最后一两位。能量用 DFTB+ 的 Hartree→eV 常数，与 DFTB+ 写出的文件一致。

k 点从哪里来

  • klines(spec)：按 DFTB+ Klines 的规则生成路径点，便于和 DFTB+ 输入一一对应；
  • ASE 的 BandPath（atoms.cell.bandpath("GXWLGK", npoints=100)）：自动给出各晶格的高对称点；
  • Monkhorst-Pack 网格或显式列表：用于更密网格上的 DOS（网格做时间反演约化，与 SCC 相同）。

路径点不做时间反演约化（约化会把路径上的点合并、打乱顺序），权重相等。

四、接口

# 底层：任意 DFTB 计算器 + 收敛的布居
from pydftb.bands import eigenstates, klines
res = calc.calculate(labels, pos, cell, pbc)
path, w = klines([(1, (0, 0, 0)), (20, (0.5, 0, 0.5)), (10, (0.5, 0.25, 0.75))])
st = eigenstates(calc, labels, pos, cell, pbc, res.q_in, kpts=path, scc_fermi=res.fermi)
st.eigenvalues           # (n_spin, n_k, n_state)，Hartree

# PySCF 风格
mf = pydftb.SCC(system, params, kpts=(6, 6, 6)); mf.kernel()
st = mf.states(kpts=(12, 12, 12), projections=True)
e, dos = st.dos(sigma=0.1)                 # eV，与 dp_dos 相同
e, pd = st.pdos(atoms=[0], shell=2)        # 第 0 个原子的 d 壳层

# ASE
atoms.calc = PyDFTB(skdir, kpts=(6, 6, 6)); atoms.get_potential_energy()
bs = atoms.calc.band_structure(path="GXWLGK", npoints=100)   # ase BandStructure
bs.plot()
  • PyDFTB.band_structure() 不带参数时保持 ASE 原有行为（用计算器自己的 k 点）；带 path 时在 SCC 电荷上沿路径计算。
  • PyDFTB(kpts=BandPath 或 {"path": ..., "npoints": ...}) 直接用路径点（不约化、等权重），与 ASE + DFTB+ 的用法相同，适合非 SCC 或固定电荷的计算。
  • States 的能量单位：eigenvalues 为 Hartree；dos()、pdos() 和 band_structure() 返回 eV。

dp_dos 的规则（逐条复现）

  • Gaussian：前因子 1/(σ√π)，函数 exp(−x²/σ²)，默认 σ = 0.1 eV，截断 3.5σ。
  • Fermi：前因子 0.5/σ，函数 1/(1 + cosh(x/σ))（即费米函数的导数，kT = σ），截断 7σ。
  • Methfessel-Paxton（阶数 N）：前因子 1/σ，函数 Σi=0..N Ai H2i(x/σ) exp(−x²/σ²)，Ai = (−1)i/(i! 4i √π)，截断 3.5σ。
  • 网格：min = 最低本征值 − 截断宽度，max = 最高本征值 + 截断宽度；起点 floor(min/Δ)·Δ，终点 ceil(max/Δ)·Δ，np.arange(起点, 终点 + Δ, Δ)（浮点步长可能多出一个点，照搬）。
  • 每个态只加到 [floor((ε − 截断 − 起点)/Δ), ceil((ε + 截断 − 起点)/Δ)] 这些网格点上，系数为 前因子 × k 点权重 × 权重。
  • 自旋极化时 dp_dos 输出“总和、↑、↓”三列；pydftb 返回每个自旋一行，由调用者求和。
  • dp_dos 的一个边界问题：若浮点舍入使最低态的起始下标为 −1，Python 的切片规则会让这个态整个被丢掉。pydftb 把下标截到 0，不复现这个问题（实际几乎碰不到）。

投影权重在简并时是否唯一

简并能级的本征向量可以在简并子空间内任意旋转，单个态的投影权重因此可能不唯一。若区域在对称操作下不变（例如单原子晶胞中一个原子的某个壳层），交叉项为零，每个态的权重与旋转无关；一般情况下只有简并组的权重之和不变。对照时把本征值相差小于 1e-7 Ha 的态归为一组，比较每组的权重之和。

验收标准

  • 本征值 ≤ 1e-8 Ha（预计 1e-11 量级：两边的 SCC 路径相同，电荷几乎逐位一致）；
  • 占据数 ≤ 1e-8；路径上的费米能级 ≤ 1e-8 Ha；
  • 区域权重 ≤ 1e-6（区域文件 6 位小数，舍入误差 5e-7）；
  • 同一份输入（解析出的 band.out 和区域文件）下，broaden() 与 dp_dos 的输出 ≤ 1e-10；pydftb 用自己全精度本征值算出的曲线与 dp_dos 的差只来自 DFTB+ 文件的舍入。

单元测试（tests/test_bands.py，不需要 DFTB+）

  • Klines 规则：隐含 Γ 起点、不含起点含终点、N = 0 跳转，以及非法输入报错；
  • 在 SCC 网格上冻结电荷求得的本征值与 SCC 结果相同（无自旋、自旋、DFTB3、分子）；
  • 投影权重对全部轨道求和为 1；乘占据数和 k 点权重后还原 Mulliken 轨道布居；
  • DOS 对能量积分等于态数（Gaussian 与 Fermi 展宽），PDOS 对各区域求和等于总 DOS；
  • 路径点不做时间反演约化、顺序不变；
  • ASE：band_structure() 返回的 BandStructure 能取出能量并画图；kpts 为 BandPath 时 ASE 默认的 band_structure() 也能用；
  • 分批大小不影响结果。

八、局限与不做的事

  • 不做能带反折叠（超胞到原胞）、四面体积分 DOS、非共线自旋和自旋轨道耦合（后两者属于 M6）。
  • PTBP 能带拟合模式的修复不在本阶段（另有任务卡）。
  • 大体系的 PDOS 需要保存 (轨道数)² 个投影值，projections 默认关闭，需要时再打开。
