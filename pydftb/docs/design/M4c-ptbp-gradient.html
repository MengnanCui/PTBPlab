关键信息

M4c 算出 PTBP 损失 μ 对两个约束半径 r0_w、r0_d 的梯度，并加两个可选的梯度优化器。梯度由三段相乘：hotcent 的切向（差分）、pydftb 的自动求导（M4b）、损失本身的偏导（解析）。默认仍是 BO，损失值和所有文件逐字节不变；梯度功能要求 --engine pydftb 并安装 torch。

  • 调研发现：在现在的 hotcent 里，r0_d 不改变 SKF。hotcent 2.1 默认 perturbative_confinement=True，而 hotpy 给每个价层都设了波函数约束；密度约束解出的轨道随后被丢弃，电子密度由波函数约束的轨道重建。r0_d 取 5、12.036、30 Bohr 时，SKF 文件逐字节相同。所以损失只经罚函数依赖 r0_d。对 Cu，罚函数在 r0_d = 4 r_cov = 9.98 Bohr 处最小；发表值 12.036 让损失高 4.3%（其它不变）。梯度会把 r0_d 推向 9.98。要不要让 r0_d 真正起作用会改变结果，由用户决定，M4c 不改 hotpy。
  • hotcent 有数值噪声。r0_w 的切向在相邻步长之间相差 0.3%–1%（rms）；单个结构的 dE/dr0_w 随步长变化 1–2%。默认步长 0.04 Bohr，梯度本身带约 1–2% 的误差，报告给出误差棒。
  • σ_rep 的内层搜索用包络定理处理。在最优的 σ 处，σ 的变化不进入一阶导数。σ 落在搜索边界上、或落在某一项 |·| 的折点上时，各用相应的公式。PTBP 的 L-BFGS-B 只收敛到 ftol 1e-3，所以先在它给的 σ̂ 附近精确找到局部极小 σ*，并报告两者的差。
  • 预计代价。每次“值 + 梯度”多跑 2–3 次 hotcent（每次约 4 秒）。DFTB 阶段第一遍顺带算出能量梯度，实测与只算能量同一量级。dataset/reaction 模式还要第二遍“力的反向”，实测约为引擎的 1.4–1.6 倍。合起来，energygeometry 约 1.6 个 BO 步，dataset 约 2.5–3 个 BO 步。只有两个参数时，梯度法很可能赢不了 BO，报告会如实写出对比结果。
  • 验证分四层。L1 是 pydftb 内部对照（与 NumPy 的切向收缩、与参数空间的差分）；L2 是 hotcent 的步长研究；L3 在固定 σ 时与整条流程的差分比较；L4 连同 σ 搜索一起做差分，只报告。另外，纯函数 μ 与 Loss 的值逐位相同。
  • 2参数：r0_w、r0_d（r0_d 当前只经罚函数起作用）
  • 3损失模式：energygeometry、dataset、reaction
  • 0默认 BO 允许改变的字节

一、目标与范围

PTBP 用 BO 在 (r0_w, r0_d) 平面上找损失 μ 的最小值。每一步要：用 hotcent 生成 SKF，对数据集里每个结构算 DFTB（只有能带部分），再在 [0.1, 0.8] 上搜索排斥势参数 σ_rep，最后得到 μ。M4c 要给出：

  • ∂μ/∂r0_w、∂μ/∂r0_d：可用于敏感度分析，也可用于梯度优化。
  • 两个可选的优化器：--optimizer gradient（投影 BFGS）和 --optimizer bo_grad（先 BO，再做几步梯度精修）。
  • 分层的验证工具，以及在相同墙钟时间下与 BO 的对比。

覆盖 energygeometry、dataset、reaction 三种模式，单元素和多元素（--multi_element）都支持。bandstructure 模式不做。

二、损失函数回顾

以下都是 utils/loss.py 现有的定义，M4c 不改它们。E、F 的单位是 eV、eV/Å；E_band、F_band 来自 DFTB 阶段，E_rep、F_rep 来自 physrep，只依赖 σ。

energygeometry：结构按 EOS 分组，每组 n = eos_points 个结构，组的 Boltzmann 权重为 bg，L = Σbg≥0.1 bg。

μ = P(r0) · [ ½ μV + ½ μE ]

μE = (1/L) Σg bg · (1/Bg) Σm∈g |xm|，xm = (em − eg,min) − (eDFTm − eDFTg,min)，e = E/N

μV = (1/L) Σg bg |v0g / v0DFTg − 1|，v0g 来自对 (V/N, E/N) 的 Birch–Murnaghan 拟合

dataset、reaction：E0Z 是孤立原子（20 Å 的盒子）的 DFTB 能量，NF 是力分量的总数。

μ = P(r0) · [ 0.9 Σi |ei − eDFTi| + 0.1 (1/NF) Σi,c |Fic − FDFTic| ]，ei = (Ei − ΣZ niZ E0Z) / Ni

两种模式都有 E = Eband(θ(r0)) + Erep(σ)、F = Fband + Frep(σ)。罚函数 P = ((r0_w/2r − 1)² + 1)² · ((r0_d/4r − 1)² + 2)²，r 是被优化元素的共价半径。BO 看到的值是 μ*(r0) = minσ μ(r0, σ)，最小值由 11 点网格加 L-BFGS-B（ftol 1e-3，最多 20 次）近似求出。失败时 μ 取 97–99 的随机整数；EOS 拟合失败时四个参数取 1000；NaN 记为 100。

三、梯度的链式结构

θ 表示 SKF 里的全部参数：SK 表、onsite 能量、Hubbard U。hotcent 把 r0 映射到 θ，DFTB 把 θ 映射到 Eband、Fband，损失再把它们映射到 μ。在 σ = σ*（下一节）处：

dμ/dr0 = Σi (∂μ/∂Ei) Ėi + Σi,c (∂μ/∂Fic) Ḟic + ΣZ (∂μ/∂E0Z) Ė0Z + (μ/P) ∂P/∂r0

Ėi = ⟨∂Eband,i/∂θ, t⟩，Ḟic = ⟨∂Fband,ic/∂θ, t⟩，t = ∂θ/∂r0（hotcent 切向）

  • ∂μ/∂E、∂μ/∂F 是解析的：绝对值取符号；energygeometry 中每组能量最低的结构通过其它结构的相对能量进入；恰好为零的残差单独标出（见下一节）。
  • EOS 拟合用隐函数定理。拟合参数 p = (E0, B0, B′, V0) 使 S = Σj (f(Vj; p) − êj)² 最小，于是 dp/dêj = H⁻¹ ∇pfj，H = Σj (∇fj ∇fjᵀ + rj ∇²fj)，rj 是拟合残差。μ 只用到 V0（B、B′ 只写进日志）。
  • 孤立原子 E0：没有原子对落在截断内，onsite 能量和 U 取自 PTBP 的参数表，所以对 hotpy 来说 Ė0 = 0。仍然用自动求导算一次（一个原子，Γ 点，代价可以忽略），这样换了 SKF 来源也成立。
  • 罚函数：∂ln P/∂r0_w = 2a / (r(a² + 1))，a = r0_w/2r − 1；∂ln P/∂r0_d = b / (r(b² + 2))，b = r0_d/4r − 1。Cu 在发表点上 ∂ln P/∂r0_d = 4.05%/Bohr。
  • 失败点不求导：μ 为失败值（97–99、EOS 的 1000、NaN 的 100）、SCC 没有收敛、或某一步拿不到导数时，梯度记为“不可用”，并写明原因，由优化器当作失败点处理。
为什么用自动求导而不是直接差分 r0？只有 r0_w 一个方向真正起作用时，“DFTB 阶段跑两遍差分”与“自动求导 + 切向”的代价相近。但自动求导一次就给出对所有 SKF 参数的梯度，再与任意多个切向做内积几乎不花时间；参数变多时（分壳层半径、幂次 p、多元素同时优化），DFTB 的代价不随参数个数增长，只多跑 hotcent。

四、σ_rep：包络定理、边界与折点

μ*(r0) = minσ μ(r0, σ)。设 σ*(r0) 是局部极小。

  • 光滑的内部极小：∂μ/∂σ = 0，所以 dμ*/dr0 = ∂μ/∂r0（包络定理），σ 怎么移动不影响一阶导数。
  • 在边界上（σ* = 0.1 或 0.8，且导数指向外侧）：σ 留在边界上，同样 dμ*/dr0 = ∂μ/∂r0。
  • 在折点上：μ 是绝对值之和，极小常常正好落在某一项 rk(r0, σ) = 0 的折点上。这时 σ* 随 r0 沿 rk = 0 移动：

dσ*/dr0 = −(∂rk/∂r0) / (∂rk/∂σ)，dμ*/dr0 = ∂μ̃/∂r0 + (∂μ̃/∂σ) · dσ*/dr0，μ̃ = 去掉第 k 项的 μ

修正量最多是“第 k 项的权重 × 它对 r0 的敏感度”。dataset 模式里单个力分量的权重很小，修正可以忽略；energygeometry 的 μV 只有几组，体积恰好与 DFT 相等的那一组可能贡献可观的修正，所以必须处理。若几项的折点重合（例如对称的原子给出相同的力残差），按一组处理；它们给出的 dσ*/dr0 不一致时，退回 ∂μ/∂r0 并给出警告。

先找 σ*：PTBP 的 L-BFGS-B 用差分梯度、ftol 1e-3，给出的 σ̂ 只是近似极小。M4c 用同一个纯函数 μ(σ)（不写文件，几十毫秒一次），在 σ̂ 附近沿下降方向找到包住极小的区间，再用 Brent 法收敛到 1e-9；然后按 σ* 处到最近折点的距离和是否在边界上分类。报告 σ̂、σ*、两者的 μ 之差（内层搜索的差距）和所属情形。损失值本身仍是 PTBP 的 μ(σ̂)，不改。

需要的 σ 导数：∂Erep/∂σ、∂Frep/∂σ。physrep 的势是 V(r) = Z₁Z₂ erfc(γr)/r（k_xc = 0），γ = 1/√(a₁² + a₂²)，a = Rcov·σ。在 physrep 的节点上解析算出 ∂V/∂σ，用同样的节点和自然边界条件建一条样条，代入 physrep 自己的 evaluate_pbc，就得到节点固定时样条对 σ 的精确导数。节点集合（截断 rcut）随 σ 离散跳动，带来约 1e-8 Ha 的跳变，忽略不计。μV 项再经 EOS 的隐函数导数：∂v0/∂σ = Σj (∂v0/∂êj) ∂êj/∂σ。

五、hotcent 切向

hotcent 不能求导，用中心差分：在 r0_w ± h 各跑一次 hotcent（与主流程同样的并行设置，写到临时目录），对每个 SKF 文件的表、onsite、U 取差分，得到 t = ∂θ/∂r0_w。表的形状、键与 pydftb.autodiff.Params 一致，可以直接与梯度做内积。

r0_d 的探测：每次运行第一次求梯度时，在 r0_d + hd（默认 0.2 Bohr）跑一次 hotcent。所有 SKF 文件与基准逐字节相同，就记下“r0_d 不影响 SKF”，切向为零，本次运行不再探测；否则在 r0_d − hd 再跑一次，用中心差分。原因见关键信息：AtomicDFT 在 perturbative_confinement=True 时，对设了波函数约束的价层，密度约束那一步解出的轨道不会被采用（atomic_dft.py 的 if nl not in self.wf_confinement），密度由约束后的轨道重新计算。

SKF 里随 r0 变化的只有表（onsite 和 U 取自参数表；PTBP 的多项式排斥势系数全为零）。如果某个文件的排斥势部分发生变化，给出错误，因为 physrep 之外的排斥势不在这次的范围里。

六、DFTB 阶段：两遍计算

第一遍（所有模式）就是原来的 DFTB 阶段。工作进程改用 PyDFTB.evaluate：它运行同一个引擎，结果（能量、力、应力、电荷）逐位就是引擎的，所以 dftb_band.xyz 等文件逐字节不变。顺带用自动求导算出每个非零切向上的 Ėi，并返回收敛的输入电荷 qin。没有展宽（PTBP 默认，T = 0）时用 hf 模式（E 的导数就是 F 的导数）；有展宽时 hf 不能给 E 的导数，改用 implicit 模式。

第二遍（只有 dataset、reaction）：σ* 定下来之后，力的权重 wi = ∂μ/∂Fi 才知道。每个结构从 qin 起步（SCC 一两步就收敛），用 implicit 模式求 ⟨∂(wi·Fi)/∂θ, t⟩。力按 PTBP 的设置用 DFTB+ 式的 0.01 Bohr 差分核，M4b 已经能对它求导。

  • 实测（Cu 结构，单线程）：第一遍的 hf 求值约为引擎的 0.9–1.2 倍（它本身包含 SCC，所以与原来的阶段相比几乎不加时间）；第二遍约为引擎的 1.4–1.6 倍（1372–1688 个 k 点的结构），小结构 5–7 倍但绝对时间不到 0.5 秒。
  • 线程与 fork：torch 在每个工作进程里固定 1 个线程，在任何 torch 运算之前设好（M4a 的 fork 规则）；父进程进入梯度模式时也设为 1 个线程。NumPy 引擎部分照旧用计划里的线程数。
  • 逐位可复现：引擎结果对任何线程数逐位相同；torch 部分固定单线程；梯度在父进程里按结构顺序求和。所以 1、2、4 核的梯度逐位相同（有测试）。
  • 某组结构因缺少 SKF 被跳过时，梯度只对保留下来的结构求和，与 μ 的定义一致。

七、梯度优化器与命令行

  • --optimizer gradient：在 BO 的边界内做投影 BFGS，加 Armijo 回溯。起点与 BO 相同（元素在 PTBP 表里时用表值，否则用 r_cov 的 3 倍和 5 倍）。某次求值失败（失败值或梯度不可用）时，这一步算作被拒绝，步长减半。停止条件：投影梯度足够小、步长小于 1e-3 Bohr，或达到 --grad_maxiter（默认 20）。
  • --optimizer bo_grad：先按 --n_calls 跑 BO，再从 BO 的最好点出发做至多 --grad_maxiter 步（此时默认 5）梯度精修。
  • --hotcent_fd_step W [D]：r0_w 和 r0_d 的差分步长，默认 0.04、0.2 Bohr。
  • 没有 --engine pydftb、没有 torch、或是 bandstructure 模式时，拒绝运行并说明原因。
  • 梯度模式的每次求值目录名用 6 位小数（opt_2.749000_12.036000），避免步长很小时与已有目录重名；BO 仍是 3 位。切向的 hotcent 跑在求值目录下的 tangent/ 里，用完删除。
  • 每次求值在 grad.out 记一行：r0_w、r0_d、μ、两个偏导、σ̂、σ*、情形（光滑/折点/边界）、内层差距、各段耗时。返回结果与 BO 相同的形式（x、fun、x_iters、func_vals），后处理与绘图不用改。
  • YAML 配置与 TUI 的优化器列表加上两个新选项。

线搜索用的是 PTBP 自己的 μ（与 BO 看到的一样，写进 par.out）。梯度对应精确内层极小的 μ*；两者的差通常远小于 ftol，会随每次求值报告。
