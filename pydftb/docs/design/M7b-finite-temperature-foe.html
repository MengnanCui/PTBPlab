关键信息

M7a 的纯化只给 T = 0 的密度，体系要有带隙。M7b 给出有限温度的 Fermi 密度 f((H − μ)/kT)，同样不做本征分解。这样金属、k 点共用的费米能级、自旋共用的费米能级与熵 TS 都能算。方法是 Niklasson 的递归 Fermi 算符展开（Phys. Rev. B 68, 233104 (2003)）：映射 x → x²/(x² + (1 − x)²) 把 y = β(ε − μ) 精确加倍，从高温的近似出发，加倍 n 次到目标温度，每步一次 Cholesky 分解。DFTB+ 在这些构建里没有有限温度、不做对角化的求解器（ELSI 的 PEXSI 没有编译），所以验证用的是 DFTB+ 本征分解的冻结参考：134 个 Fermi 填充的参考算例换成新求解器后，SCC 轮数全部不变。

  • 方法的选择（P104）：
    • Chebyshev 展开在这些体系上要 293–5593 阶（1e-12），就是同样多次矩阵乘法；
    • 极点展开要几十次稠密复数 LU，也不比本征分解快；
    • 递归只要 22 步。
  • 数值上的两点：
    • 递归写成 D = X − ½ 的形式（D ← 2D(1 + 4D²)−1），舍入误差约为 βρε，不随步数变。直接写 X 的形式舍入误差约为 2nε（1e-12），使 48 个算例的 SCC 多走轮数，5 个不收敛。
    • 化学势用精确的平移关系 P(μ + d) = P[P + e−βd(1 − P)]−1 求：在 ±5 kT 之内用这个关系，更远就重新递归。
  • 精度（P105）：
    • 134 个算例：114 个与本征分解差 ≤ 3e-13 Ha（电荷 5e-12 e，力 6e-13 Ha/Bohr，TS 2e-14 Ha）；
    • 另外 20 个的差别来自 DFTB+ 的费米能级规则：有带隙时，若带隙中点的电子数与整数差 ≤ 1e-7，就取中点。新求解器用精确的电子数，与 fermi_level="exact" 的本征分解差 ≤ 1e-13 e。
  • 速度（P106，本机 4 核）：每次 SCC 迭代一次递归，是本征分解的 10–16 倍（288–3072 个轨道）。好处在 GPU（矩阵乘法与 Cholesky 比本征分解好并行）与之后的稀疏版本。
  • 134 / 134Fermi 参考算例的 SCC 轮数与本征分解相同
  • ≤ 3e-13其中 114 个与本征分解的能量差（Ha）
  • 22递归步数（Chebyshev 要 293–5593 阶）
  • 10–16×CPU 上一次递归相对本征分解的耗时

一、范围

  • 做：
    • Fermi 填充、T > 0 的密度矩阵 ρ、能量加权密度矩阵 W、熵 TS 与费米能级，不要本征值；
    • 无自旋、共线自旋（固定总自旋时每个通道一个费米能级，relax_total_spin 时共用）、两分量（非共线、SOC）；
    • k 点共用一个费米能级，所以金属也可以；
    • 固定费米能级（fixed_fermi_level，不用求 μ）与每个 k 点单独填充（每个 k 一个 μ）；
    • 所有只要 ρ、W 的功能：力、应力、MD、XL-BOMD、杂化泛函、块势、外场、溶剂等；torch 设备。
  • 不做：
    • MP 与 Gaussian 展宽（DFTB+ 的 PEXSI 与 NTPoly 同样只用 Fermi）；
    • T = 0（用 M7a 的 "ntpoly"）；
    • 要本征矢的分析与 Casida（同 M7a）。
  • 参考：DFTB+ 的有限温度、不做对角化的求解器是 ELSI 的 PEXSI，conda-forge 的构建里没有，没有直接的对照。新求解器给的是同一个 Fermi 密度，所以 DFTB+ 本征分解的冻结参考就是它的参考：每个 Fermi 填充的参考算例换成新求解器，结果与 SCC 轮数都应该不变。差别只在 DFTB+ 的费米能级规则（见第三节）。

二、方法的选择

方法代价P104 的结果
Chebyshev 展开（Goedecker）阶数约 βρ ln(1/ε)/π（ρ 是谱的半宽），每阶一次矩阵乘法；求 μ 要第二遍或存下所有 Tk1e-12 需要的阶数：Li bcc 1000 K 293，Cu4 LC 1000 K 478，CuO 链 500 K 2048，Cu4CO 300 K 5593；3000 K 时 103–1954
极点展开（PEXSI 的做法）log(βρ) 量级的极点（几十个），每个一次复数线性方程稠密时每个极点约 4 次实数 LU 的工作量，几十个极点比本征分解慢；它的价值在稀疏的选择性求逆（M7c）
递归 Fermi 算符展开（Niklasson 2003）n ≈ 22 步，每步一次乘法、一次 Cholesky 分解与求解密度 ≤ 1e-14，熵 ≤ 3e-12（以 k 为单位）

三、算法

与 M7a 相同，先用 Z = S−1/2（Newton–Schulz，每个几何一次）化成正交基 H̃ = Z H Z†；结果是 P̃ = f(H̃)，ρ = g Z† P̃ Z。

递归

  • f(y) = 1/(1 + ey)。映射 x ↦ x²/(x² + (1 − x)²) 把 f(y) 变成 f(2y)，是精确的。从 T = β(H̃ − μ0)/2n 出发，X0 = ½ − T/4（f(t) 的一阶近似，也就是 R = (1 + T/2)(1 − T/2)−1 时的 (1 + R)−1），走 n 步得到 f(Y′)，Y′ = 2n+1 artanh(T/2) = Y + Y³/(12·4n) + …。
  • 截断误差：Y′ 与 Y 只在远离 μ 的能级上差得多，那里 f 已经是 0 或 1；对占据数的影响最大约为 0.1/4n。n = 22 时约 6e-15。
  • 步数：至少 22 步；若 ‖Y‖1 > 2n−8，就自动加步，使 ‖T‖1 ≤ 2−8。这样 X0 的本征值在 (0, 1) 之内，tr ln(1 + T/2) 的级数也短。1000 K 时 22 步对 ‖H̃ − μ‖1 ≤ 52 Ha 都够；在 Cu4 与 Cu4CO 上，10 K 用 22–24 步，1 K 用 25–27 步，0.1 K 用 29–31 步，密度与精确值差都 ≤ 3.5e-13。
  • D 形式：设 D = X − ½，映射变成 D ↦ 2D(1 + 4D²)−1（tanh 的倍角公式）。矩阵 1 + 4D² 的本征值在 [1, 2] 之内，用 Cholesky 分解求解。舍入误差与 D 的大小成比例；早期 D 很小，所以误差总共约为 βρε，不随 n 增长。直接写 X 时 X ≈ ½ 的舍入（ε）每步翻倍，误差约为 2nε（P104：n = 18 时 1e-12，n = 24 时 5e-10）。

化学势

  • μ 是 1 的倍数，所以 P(μ0 + d) = P[P + e−βd(1 − P)]−1 是精确的关系（D 形式：D′ = [(1 − c)/4 + (1 + c)D/2][(1 + c)/2 + (1 − c)D]−1，c = e−βd）。每次只要一次 Cholesky，不必重新递归。
  • 舍入使这个关系只在 |d| ≲ 5 kT 之内精确：离 μ0 远的能级的占据数只有绝对精度 ε，平移后误差放大约 eβ|d| 倍。
  • 做法：
    • 在 μ0 递归一次，然后算 d = ±5 kT 时的电子数。
    • 目标电子数在这两个值之间时，在窗口里用 Newton 法加二分求 d。导数是 dN/dμ = β Σk wk tr P(1 − P)，同样精确。
    • 目标在窗口之外时，从窗口边上按 Newton 法走一步；在带隙里导数太小，就在 Gershgorin 界之内二分，再递归一次。
  • SCC 中 μ0 取上一次的 μ，通常一次递归就够。P105 的 OH 非共线算例在第 1、2 轮之间 μ 移动了 110 kT；只靠平移每次移动有限，原型的第一版因此给出错误的 μ。
  • 费米能级规则：新求解器求的是精确的电子数（pydftb 的 fermi_level="exact"）。DFTB+（与 pydftb 的默认）在电子数为整数时先看带隙中点：那里的电子数与整数差 ≤ 1e-7，就用中点。没有本征值时找不到 HOMO 与 LUMO，所以不仿照这条规则。差别只在有带隙的体系里，电荷差 < 1e-7 e（P105 最大 2e-8 e，能量 1.6e-8 Ha）。

熵

  • 对任意起点 X0，递归给出 ln P 与 ln(1 − P) 的乘积分解，所以计算出的 P 的熵是 S = Σk 2n−1−k tr ln Mk − 2n tr[P ln X0 + (1 − P) ln(1 − X0)]，Mk = ½ + 2Dk²。
  • 线性起点下化简为 S = N ln 2 + Σk 2n−1−k tr ln(1 + 4Dk²) − 2n tr ln(1 + T/2) + tr(P Y′)。其中 2nN ln 2 的大项已经在解析上相消。
  • 各项的求法：
    • 早期 1 + 4D² 接近 1，tr ln 用迹的级数。4D² 半正定，各项交替且递减，某一项的迹小于 1e-19 就停。
    • 后期用 Cholesky 对角元的对数；
    • tr ln(1 + T/2) 用 T 的幂的迹。T 不定，奇次幂的迹可以为零，比如 μ0 正好在能级对称的中点。所以停的条件用上界 N‖T/2‖1j/j < 1e-19，而不用迹。第一版按迹停，在每个 k 单独填充的 Li 算例上（μ 在两个能级正中）漏掉二次项，熵差 4.8e-6。
  • 必须用 P 自己对应的 Y′，而不是 Y：深能级上 ln(1 + e−y) ≈ −y 与 y·f(y) 相消，Y′ − Y 在那里大到 1e-3（P104 的第一版熵差 4e-5–2）。
  • 化学势平移后：tr ln(1 + e−(Y′−βd)) 增加 Nβd + ln det[P + c(1 − P)]，tr(Y′P) 换成 tr((Y′ − βd)P′)。
  • TS = kT g Σk wk Sk，与 DFTB+ 的 Fermi 填充相同。

W 与其他

  • W̃ = f(H̃)H̃，两者可交换，取 (P̃H̃ + H̃P̃)/2。
  • 自旋共用费米能级：上、下自旋的矩阵一起，作为同一个 μ 的 2Nk 个块。
  • 两分量：一个 2N × 2N 的复数矩阵，g = 1。
  • 固定费米能级：不求 μ。每个 k 单独填充：每个 k 的 μ 分开求，费米能级与 TS 按 k 点权重求和（同 M6f）。

四、探针与原型

草稿目录 m7b/：foe_proto*.py（递归）、cheb_degree.py、p105_scc.py（SCC）、p106_timing.py。

探针内容结果
P104在 4 个有限温度算例的收敛 H 上（Cu4CO +U 300 K，CuO 链 4×2×2 500 K，Li bcc 1000 K，Cu4 LC 1000 K），递归对本征分解；Chebyshev 的阶数
  • X 形式：n = 14–18 时密度 3e-13–6e-12，n 增大误差反而增大（2nε）；
  • D 形式：n = 22–24 时 ≤ 7e-15，熵 ≤ 3e-12；
  • 精确平移从 μ + 0.01 Ha 出发 7–10 步收敛到 1e-13；
  • Chebyshev 见第二节。
P105原型接在 pydftb 的 SCC 上，跑所有 Fermi 填充、T > 0 的冻结参考（143 个，其中 9 个用固定费米能级或每个 k 单独填充，原型不做）
  • 最终版：134 个算例的 SCC 轮数全部与本征分解相同，能量都在 DFTB+ 参考的容差之内；
  • 114 个差 ≤ 3e-13 Ha、电荷 ≤ 5e-12 e、力 ≤ 6e-13 Ha/Bohr、TS ≤ 2e-14 Ha；
  • 其余 20 个（Cu4CO 壳层分辨、CuO 链自旋、Cu4CO +U 等）是费米能级规则，与 fermi_level="exact" 的本征分解差 ≤ 1e-13 e。
过程中的两个问题：
  • X 形式的 1e-12 噪声使 48 个算例多走 SCC 轮数（非共线 OH 26 对 63 轮），scc_tol 1e-12 的 4 个算例与 GdO 非共线不收敛；
  • 第一版的 μ 搜索在 μ 大幅移动时出错。
P106本机 4 核：水盒子（绝缘体）与 Cu fcc 超胞（金属）的非 SCC H0，1000 K，Γ 点；一次密度的耗时，μ 已知（SCC 中的情形）与从头求 μ
  • 水 64（384 个轨道）：eigh 0.022 s，FOE 0.21 s（9.6 倍），从头 0.47 s（2 次递归）；
  • Cu 2×2×2（288）：0.011 s 对 0.10 s（9.9 倍），从头 0.24 s（2 次）；
  • 水 216（1296）：0.26 s 对 3.24 s（12.6 倍），从头 3.08 s（1 次）；
  • Cu 3×3×3（972）：0.11 s 对 1.34 s（12.7 倍），从头 3.06 s（2 次）；
  • Cu 4×4×4（2304）：1.11 s 对 17.4 s（15.7 倍），从头 37.4 s（2 次）；
  • 水 512（3072）：3.23 s 对 40.0 s（12.4 倍），从头 43.4 s（1 次）；
  • S−1/2（每个几何一次）：0.011–7.6 s；密度与 W 的误差 ≤ 1.3e-13。

五、pydftb 的接口

DFTB(sk, solver="foe", smearing=("fermi", 1000.0))      # 金属、k 点、自旋都可以
from pydftb.fermi_operator import FermiOperator
DFTB(sk, solver=FermiOperator(steps=22), backend="torch", device="cuda")
  • 结果：eigenvalues 与 occupations 为 None；fermi（自旋时 fermi_spin）是求出的化学势；TS 与本征分解相同。
  • 拒绝：MP 与 Gaussian 展宽、T = 0（提示用 "ntpoly"）、要本征矢的分析与 Casida。

六、实现 开发细节

位置内容
fermi_operator.py（新）
  • recursion（D 形式与熵的各项）、shift（精确平移）与化学势的窗口搜索；NumPy 或 torch（Cholesky 在设备上）。
  • 求解器类 FermiOperator（eigenpairs = False，finite_temperature = True）：prepare(S) 用 M7a 的 inverse_sqrt；density(...) 返回 (ρ, W, μ, TS)；μ 留给下一次调用作起点。

solvers.pySOLVERS["foe"]；PEXSI 的拒绝改为指向 "foe"。
validationrefgen 的 --solver foe：用新求解器检查所有适用的 Fermi 参考算例（容差与 SCC 轮数同原来），不适用的算例打印原因跳过。

七、验证 开发细节

  • DFTB+ 参考：所有适用的 Fermi 填充、T > 0 的冻结参考算例用新求解器，过原来的容差，SCC 轮数相同。费米能级规则造成的差别都在容差之内。门槛里跑全部，单元测试里跑一组代表。
  • 对本征分解（fermi_level="exact"）：无自旋、两种共线自旋、两分量、k 点、杂化、块势、固定费米能级、每个 k 单独填充：ρ、能量、电荷、力、TS ≤ 1e-12。
  • 单元测试：随机矩阵上的密度、熵、μ 的大幅移动与带隙里的 μ；D 形式对 X 形式的舍入；拒绝的原文；torch。
  • 门槛：golden 两个环境逐位相同、refgen（NumPy、torch）、dynamics、pytest 三个环境、PTBP 测试与 G1。

八、风险与之后

  • 速度：本机 CPU 上是本征分解的 10–16 倍。GPU 上 Cholesky 与矩阵乘法的并行度比本征分解好，实测要等你运行自检脚本（M7e）。还可以用更高阶的起点减少步数，或用 Newton–Schulz 求逆（只用矩阵乘法）。
  • 费米能级规则：有带隙的体系与 DFTB+ 差 < 1e-7 e，文档写明。报出的费米能级是隙中的某一点（与 fermi_level="exact" 相同）。
  • 极低温：步数自动增加（见第三节），0.1 K 时密度仍到 1e-13。T = 0 用 M7a 的纯化。
  • 之后：M7c 稀疏线性标度，M7d 分治，M7e GPU 与批量。
