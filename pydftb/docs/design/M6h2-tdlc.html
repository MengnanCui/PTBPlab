关键信息

M6d/M6e 的 Casida 激发与激发态力，加上 M6h-1 的长程校正（LC）交换：DFTB+ 25.1 的 TD-LC-DFTB。A+B 与 A−B 各加一项长程交换，A−B 不再是对角阵，所以 Casida 方程改成对称化的 (A−B)½(A+B)(A−B)½ 求解；激发态力的 Z 向量、W 矩阵与显式导数都多出交换项。只做 NumPy，不开杂化时逐位不变。

  • 范围（与 DFTB+ 相同）：LC 型的 SK 文件，分子，整数占据；单重态、三重态、两者、自旋极化；激发能、振子强度、跃迁偶极、Δ⟨S²⟩、跃迁电荷、激发态的电荷与偶极、激发态力；基态可以用三种屏蔽中的任何一种。
  • 原型与 DFTB+ 的对照（第二节，探针 P53–P58）：
    • 激发能：11 种分子与设置的 Ω² 与 DFTB+ 相差 ≤ 6e-14，覆盖单重态、三重态、两者、自旋极化、O2 简并态、CuH 的 d 轨道、最亮态。苯的差为 2e-9，来自 DFTB+ Stratmann 求解器的收敛阈值。
    • 激发态力：用 DFTB+ 的 SK 差分步长时，原型与 DFTB+ 的力一致到 ≤ 1.1e-12，覆盖单重态、三重态、自旋极化、C2H4 S1、CH3OH S3；用解析 SK 导数时，原型的力与自身 E0 + Ω 的差分一致到 ≤ 1e-9。
  • DFTB+ 的情况（第六节）：
    • 外场加点电荷时，TD-LC 激发态力偏差 3.0e-3 Ha/Bohr，与 M6e 非杂化时漏的项相同。
    • 自旋极化且自旋常数是壳层矩阵时，偏差 2.6e-4，与 M6e 的机理相同，pydftb 拒绝这种设置。
    • NeighbourBased、Thresholded 屏蔽下，力不是 E0 + Ω 的导数。原因在基态的屏蔽：Thresholded 的基态力本身就偏差 1.4e-3。pydftb 照 DFTB+ 的写法给出相同的力。
  • 拒绝（DFTB+ 的原话）：CAM 与全局杂化、能量或振子窗口、分数占据、onsite 修正。DFTB+ 的 TD-LC 只用 Stratmann 求解器；pydftb 自己的 ARPACK 求解的是 Hermite 形式，用于 TD-LC 时拒绝。
  • ≤ 6e-14与 DFTB+ 25.1 的 Ω² 之差（原型，11 个设置）
  • ≤ 1.1e-12与 DFTB+ 的激发态力之差（Ha/Bohr，原型）
  • 3.0e-3DFTB+ 加外场与点电荷时的激发态力误差（Ha/Bohr）

一、DFTB+ 的做法

源码 25.1（timedep/linrespgrad.F90 的 LinRespGrad_old、buildAndDiagExcMatrixStratmann、getZVectorEqRHS、solveZVectorPrecond、calcWVectorZ、addGradients，timedep/linrespcommon.F90 的 actionAplusB、actionAminusB、initialSubSpaceMatrixApmB，dftbplus/initprogram.F90 的 ensureLinRespConditions、ensureHybridXcReqs）；行为以 25.1 的二进制为准。

  • 输入：Hybrid = LC {…} 加 ExcitedState { Casida { Diagonaliser = Stratmann {} … } }，不需要另外的开关。
    • 函数类型取自 SK 文件的 RangeSep，而不是 Hybrid 关键字：LC 文件配 Hybrid = CAM 照常运行。
    • CAM 文件报 “General CAM functionals not currently implemented for linear response.”。
    • β = 0 的 CAM 文件（全局杂化）报 “Global hybrid functionals not currently implemented for linear response.”。
  • 交换核：(pq|rs) = ΣAB qpqA γlrAB qrsB。
    • qpqA = ½ Σμ∈A (cμp(Scq)μ + cμq(Scp)μ)，与 ia 对的跃迁电荷是同一个公式（transq）。
    • γlr 来自 getCamGammaCluster：原子级的 LC γ，与基态用哪种屏蔽无关。
    • 在 AO 基中，它就是 M6h-1 的四项算子：Kx[M] = ¼[(SMS)∘Γ + ((SM)∘Γ)S + S((MS)∘Γ) + S(M∘Γ)S]，并且对不对称的 M 也成立。
  • A ± B（cExchange = 1）：
    • A+B = Δε + KC − [(ij|ab) + (ib|ja)]，A−B = Δε − [(ij|ab) − (ib|ja)]。
    • KC 与 M6d 相同：闭壳层单重态 4qγq，三重态 4qWq，自旋极化 2q(γ + σσ′W)q。
    • 交换项只在同一自旋内，系数在三种情形下都是 1。
    • 写成 AO 形式：(A±B)xy = −2 CoT Kx[Ys 或 Ya] Cv，Y = Co y CvT，s、a 分别是对称与反对称部分。
  • Stratmann 求解器：
    • 子空间 B 上取 M± = BT(A±B)B，对角化 H = M−½ M+ M−½，得到 Ω²。
    • X+Y = B M−½T / √Ω，X−Y = B M−−½T √Ω。
    • 两个残差 (A−B)(X−Y) − Ω(X+Y) 与 (A+B)(X+Y) − Ω(X−Y)，各除以 (Ω − wia) 后扩充子空间。
    • 收敛条件是残差平方 < 0.1 ε单精度 ≈ 1.2e-8；初始子空间是能量最低的 SubSpaceFactor × n 个单位向量。
  • 激发态力：与 M6e 的步骤相同（T，R，(A+B)Z = R，W，P = T + Zs），交换带来四处新项：
    • R 与 W 中的 H±[X±Y] 交换部分（getHvvXY、getHooXY）；
    • 基态对 T 的交换响应（getHovT、getHooT）；
    • Z 向量方程的 A+B 中的交换项，以及 Woo 中 Z 的交换响应；
    • addGradients 中交换积分对 S 与 γlr 的显式导数（lrGammaOrb、getDirectionalCamGammaPrimeValue）。
  • 拒绝（ensureLinRespConditions、ensureHybridXcReqs、LinRespGrad_old）：
    • 非 Stratmann 求解器：“TD-LC-DFTB implemented only for Stratmann diagonaliser.”
    • 周期体系。
    • 能量或振子窗口：“hybrid functional excited states not available for window options.”
    • 分数占据：在激发计算中检查，任何一个占据与 0 或满占据相差超过 elecTolMax 都会触发，报 “Fractional occupations not implemented for TD-LC-DFTB.”
    • onsite 修正：“Onsite corrections not implemented for Stratmann diagonaliser.”
    • 三重态与自旋极化只给警告（“not well tested”）。
    • 线性响应的一般限制照旧：非 SCC、DFTB3、按壳层 SCC、+U、溶剂、非共线与 SOC。

二、DFTB+ 的实测行为与原型

探针 P53–P58（草稿目录 m6h2/），参数集 ptbp_hcocu_lc，DFTB+ 用 Stratmann 求解器。原型（tdlc_proto.py、tdlc_grad.py）用 pydftb 的 LC 基态，加上第一节的 A±B（稠密，精确求解）和第四节的梯度。

三、pydftb 的接口

calc = DFTB(sk_lc, hybrid="lc",
            casida=Casida(n_excitations=6, symmetry="singlet", state_of_interest=2))
r = calc.calculate(labels, pos)
r.excitations.energies, r.excitation_energy, r.forces   # forces = -d(E0 + Omega)/dR
  • 选项：M6d/M6e 的 Casida 全部可用：对称性、态、最亮态、激发态力与电荷、跃迁电荷、求解器。条件与 DFTB+ 相同：
    • SK 文件必须是 LC 型；hybrid="cam" 配 LC 文件也可以。
    • 没有窗口，没有 onsite 修正。
    • 占据必须是整数，否则在计算激发时按 DFTB+ 的原话报错。
  • 求解器：
    • "exact"：稠密的 A±B，用 (A−B)½ 对称化后对角化。
    • "davidson"：TD-LC 时是 Stratmann 型子空间迭代，A±B 不建成矩阵，残差收敛到 1e-10，比 DFTB+ 的阈值严得多。
    • "auto"：跃迁数 ≤ 500 时用前者，更多时用后者。
    • "arpack"：只适用于 Hermite 的 Ω，TD-LC 时拒绝。
  • 屏蔽：基态可以用三种屏蔽中的任何一种。TD 部分与 DFTB+ 一样用不屏蔽的 γlr 与 S。屏蔽下的激发态力照 DFTB+ 给出，与基态的力一样不是能量的导数。
  • 外场与点电荷：pydftb 给出 E0 + Ω 的精确导数。DFTB+ 漏掉的项可以用验证专用的兼容模式去掉（M6e 的 _excited_compat = {"external"}）。
  • 自旋常数：激发态力与电荷仍要求每种元素一个 W（M6e 的规则）。
开发细节四、实现

激发能

  • hybrid.py：四项算子写成模块函数 four_terms(s, g, d)，HybridTerms._four_terms 调用它，运算相同，基态结果逐位不变。
  • casida.py：
    • GroundState.lr_gamma：原子级的 γlr，不开杂化时为 None。
    • _Exchange：
      • 每个自旋通道的 qoo、qvv、qov；
      • 稠密的 (ij|ab) 与 (ib|ja) 各用一次 GEMM（跃迁数² × 原子数）；
      • 乘积用 AO 的 four_terms，每个向量 O(N³)，内存 O(N²)。
    • HybridResponse：
      • A±B 的稠密矩阵与乘积；
      • 精确解：(A−B) 的 eigh → (A−B)½ → M = (A−B)½(A+B)(A−B)½ 的 eigh；A−B 不正定时报基态不稳定。
      • Stratmann 迭代：多跟踪几个态以免边缘处的简并组断开；子空间满了就从 X+Y、X−Y 重新开始。
    • excitations：gs.lr_gamma 不为 None 时走这条路；_properties 接收现成的 X±Y。原来的路径不变：算 X±Y 的表达式只是挪到调用处。

激发态力（AO 与 MO 的矩阵形式）

  • 记号：
    • R = Co(X+Y)CvT，L = Co(X−Y)CvT；
    • Ω 的交换部分为 −⟨Rs, KxRs⟩ − ⟨La, KxLa⟩，对称与反对称部分自动分开；
    • q± = CTKx[Rs]C 与 CTKx[La]C。
  • 轨道梯度（C → C(1 + κ)，G = ∂Ω/∂κ）：
    • Goo = −2(q+ovXT + q−ovYT)
    • Gvo = −2(q+vvXT + q−vvYT)
    • Gov = −2(q+ooX − q−ooY)
    • Gvv = −2(q+ovTX + q−ovTY)
    • 这里 X = X+Y，Y = X−Y。基态对对称矩阵 M（T 与 Zs）的交换响应是 −2Kx[M]，进入 ov 与 oo 两块。
  • 与 M6e 代码的对应：rhs = Gov − GvoT，wov = Gov + Zεo，woo 与 wvv 是 G 的对称部分。M6e 的库仑项就是 q± 换成 V[γξ]、系数换成 c 的同一组公式。
  • Z 向量：A+B 加 −2CoTKx[Zs]Cv（_APlusB 的稠密矩阵、乘积与对角都加，对角是 −[(ii|aa) + (ia|ia)]）；Woo 加 −2Kx[Zs]oo。
  • 显式导数：对 B(M1, M2) = ⟨M1, KxM2⟩ 求 ∂/∂S 与 ∂/∂Γ。
    • 三项：−½ B(P, ΔP)（闭壳层；自旋极化时每个通道 −B(Pσ, ΔPσ)）、−B(Rs, Rs)、−B(La, La)；ΔP 是基态的 ΔPout。
    • dS 部分加到 M6e 的成对元素系数上，dγ 部分按原子对求和后乘 γ′(R)。
    • 函数放在 hybrid.py：bilinear_ds、bilinear_dg、HybridTerms.exchange_force。
  • Relaxed：加 xmy_ao = C(Ỹ − ỸT)CT = 2La；原有的 xpy_ao = 2Rs。

计算器与工具

  • _check_hybrid：删去“TD-LC 是 M6h-2”的拒绝，加上 TD-LC 的条件（第三节，DFTB+ 的原话）。_casida_ground_state 传 lr_gamma；_excited_gradient 加显式的交换项。
  • validation/dftbplus.spin_constants_block：W 不是标量时报错（P53t 的教训）。

六、DFTB+ 的问题与 pydftb 的做法

DFTB+ 的情况证据pydftb
外场加点电荷时，激发态力漏了 dqex·∇Vext，shift 中也没有外场（M6e 已记录，TD-LC 相同）H2CO S2：DFTB+ 的力对其 E0 + Ω 的差分错 3.0e-3 Ha/Bohr；原型 1.5e-9精确的导数；兼容模式 external 复现 DFTB+ 的力（验证用）
自旋常数是壳层矩阵时，响应只用 HOAO 的 W，基态用整个矩阵，两者不一致（M6e 的机理）自旋极化的 H2CO+：DFTB+ 的力错 2.6e-4（M6e 非杂化时为 8.8e-6）照 M6e 拒绝，要求每种元素一个 W
屏蔽：TD 部分用不屏蔽的交换，基态用屏蔽的交换苯 NeighbourBased：DFTB+ 与原型对差分都差 4.76e-5；Thresholded 的基态力本身就差 1.4e-3照 DFTB+ 给出（与基态的屏蔽力一样不是能量的导数），在文档中说明
Stratmann 的收敛阈值是残差平方 1.2e-8苯：Ω² 差 1.8e-9，力差 8e-8（原型对差分 7e-10）pydftb 收敛到 1e-10；苯的参考容差放宽，小分子仍按 1e-10 比较
Stratmann 扩充子空间时，L 残差的预条件分母用的是上一个循环剩下的 dummyReal代码（linrespgrad.F90，第 1437 行）只影响收敛快慢，不影响结果；pydftb 按每个态的 Ω 做预条件

七、不做的事与风险

  • CAM 与全局杂化的 TD、窗口、onsite、分数占据：DFTB+ 拒绝，pydftb 也拒绝。实现上并不难：CAM 只是换 γ，onsite 是在 A+B 里加一项。但没有参考，等以后有需要再做。
  • 非绝热耦合与锥形交叉优化：pydftb 的 Casida 本来就没有，不在范围内。周期体系的 TD-LC 留给 M6h-3 之后，DFTB+ 也不支持。
  • 规模：
    • 稠密路径存 A+B、A−B 和 M 三个跃迁数² 的矩阵，"auto" 只在 ≤ 500 个跃迁时使用。
    • 迭代路径每个向量做一次 AO 的四项乘积，O(N³)。
    • 力的显式导数用几个 N × N 的稠密积。
  • 稳定性：A−B 必须正定；基态不稳定时报错，并给出最小的本征值。
