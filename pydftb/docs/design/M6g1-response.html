关键信息

M6g（响应性质）的第一块：DFTB+ Analysis 中的耦合微扰 SCC。电场极化率（Polarisability，静态与频率相关）与响应核（ResponseKernel，各原子的布居对原子势的导数）。pydftb 用与 DFTB+ 相同的态求和公式，但直接解线性方程，不迭代，得到精确的自洽解。只做 NumPy 引擎；不开这些选项时逐位不变。

  • DFTB+ 的做法（第一节）：
    • 微扰 H′μν = ½Sμν(VA + VB)：电场时 VA 是原子坐标，响应核时是一个原子上的单位势；
    • 一阶密度矩阵对未微扰的本征态求和，权重为 (fi − fa)/(εi − εa)；频率相关时为 (fi − fa)/(εi − εa ± ω + iη)；
    • 简并的能级先按微扰旋转；金属另加费米能级的移动，使电子数守恒；
    • SCC 响应用基态的混合器迭代，到 PerturbSccTol（默认 1e-5）为止；极化率 αji = −ΣARA,j∂qA/∂Ei（q 为电子布居）。
  • 探针 P19–P21（第二节，DFTB+ 25.1）：
    • 默认容差下，水的极化率张量不对称 1.6e-7，与收敛解差 2.5e-7。把容差设为 1e-11，水 7 轮收敛到 1e-13，张量的 12 位有效数字逐位对称；参考都用 1e-11；
    • 只 onsite 的三阶、色散、溶剂、Methfessel–Paxton 展宽被拒绝；周期体系不给极化率张量，只给电荷响应；Static = No 又没有频率时什么也不算，也不提示。
  • pydftb 的做法（第三、四节）：
    • 在壳层空间里显式构造非相互作用响应矩阵 χ0（含费米能级修正），再解 (I − χ0K)x = χ0Vext；K 是 SCC 势对布居的导数（γ、自旋常数 W、DFTB3 在基态处的线性化）；
    • 接口为 Analysis(polarisability=…, response_kernel=…)，结果在 r.analysis.polarisability、r.analysis.response_kernel，全部频率都保留。
  • M6g 拆成三块（第七节）：
    • M6g-1：本块；
    • M6g-2：坐标导数与 Born 电荷，SecondDerivatives 的 Hessian；
    • M6g-3：+U/onsite 与非共线/SOC 下的响应，外部点电荷的导数。
  • 19DFTB+ 参考算例（响应自洽容差 1e-11）
  • 2.5e-7DFTB+ 默认容差（1e-5）时水的极化率与收敛解之差（a.u.）
  • 425.1 拒绝的组合：只 onsite 的三阶、色散、溶剂、MP 展宽

一、DFTB+ 的做法

源码为 DFTB+ 的 041e723（derivs/perturb.F90、derivs/linearresponse.F90、derivs/rotatedegen.F90、derivs/fermihelper.F90、dftbplus/parser.F90、initprogram.F90、main.F90、mainio.F90）。电场与响应核两部分 25.1 已有，行为以 25.1 的二进制为准。

输入

  • Polarisability { Static = Yes; Frequencies [单位] = {…}; FrequencyRange [单位] = 起 止 步长 }，ResponseKernel { RPA = No; Static/Frequencies/FrequencyRange }。频率表：Static 时先放 0，再接 Frequencies，再接 FrequencyRange 的点（n = int((止 − 起)/步长) + 1）；ω 是 ħω，单位 Hartree。
  • 同一层的选项：
    • PerturbDegenTol：1e-9 Ha，绝对值；
    • PerturbEta：1e-8 Ha，只在有 ω ≠ 0 时读；
    • MaxPerturbIter：SCC 时 100，非 SCC 时 1；
    • PerturbSccTol：1e-5，与基态的 SccTolerance 无关；
    • ConvergedPerturb：Yes。
  • 求解器只有一种：对未微扰态的谱求和（spectralSum）。
  • 要求与拒绝：
    • 只接受 Fermi 展宽；
    • 只接受完整的三阶（ThirdOrderFull）；
    • 拒绝溶剂、色散、REKS、ΔDFTB、mDFTB、NEGF；
    • 周期体系不分配极化率张量，但电荷响应照算；
    • +U、onsite、共线与非共线自旋、SOC、k 点都支持。

一阶密度矩阵

对每个 (k, 自旋) 块，εi、ci 是最后一次对角化的本征对（最后一轮输入电荷的 H），fi = 1/(1 + eβ(εi − EF))，β = 1/kBT（T 不低于 1e-8 Ha）。

  • 窗口：
    • nF 是最后一个占据数大于 1e-7 的能级；nE 是第一个占据数与满占据之差大于 1.19e-7（单精度的 ε）的能级，满占据无自旋时为 2，有自旋时为 1；
    • nF ≠ nE − 1 时该块是“金属”，窗口 W = [nE, nF] 内是部分占据的能级。
  • 矩阵元：M = C†H′C。简并组（相邻能级差 ≤ 容差，可链式相连）内对角化 MGG（本征值升序），并把本征向量旋转过去；Mii 就是本征值的导数 ∂εi。
  • 静态权重：对 i ≤ nF、a ≥ nE（同一简并组内 i ≠ a 的对除外），Uai = MaiθiaFia。
    • θia = 1/(1 + eβ(εi − εa))：W 内的对 (i, a)、(a, i) 都出现，θia + θai = 1，不重复计数；
    • Fia = (fi − fa)/(εi − εa)；|εi − εa| ≤ 10εdp 时取 −δi，δi = βfi(1 − fi)（带内项，i = a 时 θ = ½）；
    • dci = Σa c̃aUai，dρu = Σi≤nF(dcic̃i† + c̃idci†)。
  • 频率相关（ω ≠ 0）：对 s = ±1，Uai = Maiθia(fi − fa)/(εi − εa + sω + iη)，dρu += ½(dc c̃† + c̃ dc†)，实数本征向量取实部。
    • 没有带内项（i = a 时为 0）；
    • 两个符号都用 +iη；对实数本征向量这只影响虚部，对 k 点的复数本征向量会在布居中留下一个 ∝ η 的反对称项。
  • 费米能级的移动（静态、金属、没有 FixedFermiLevel）：
    • dEF = −Σdqu/NF，其中 NF = 满占据 × ΣkwkΣi∈Wδi（DFTB+ 称为 neFermi）；
    • 再加上满占据 × Σi∈WδidEFcici†（用未旋转的本征向量），每个自旋通道各自守恒电子数；
    • 最后乘满占据：dρ = 满占据 × dρu，有自旋时换成 (q, m) = (↑ + ↓, ↑ − ↓)。

SCC 响应

  • 每轮由输入的 dq 得到响应势：
    • γ 的 1/r（或 Ewald）与短程部分，按基态的原子或壳层分辨；
    • 自旋 Vm = W dm；
    • DFTB3 用基态 Δq（最后一轮的输入电荷）处的精确线性化；
    • 点电荷与外场的势不变，不进入响应。
  • dH = ½(SVB + VAS) 加外加的微扰，经上面的公式得到 dqout。第 1 轮只有外加微扰，第 2 轮起用基态的混合器（同类型、同参数）混合，直到 max|dqout − dqin| < PerturbSccTol。返回最后一轮的输出 dq。
  • RPA = Yes 的响应核只做一轮，即裸的 χ0，没有 SCC 的屏蔽；非 SCC 计算也只做一轮。

输出

  • 电场：
    • 每个方向 i 和频率 ω：dqμ/dEi（电子布居，正值表示电子增加）；
    • αji(ω) = −ΣARA,jΣμ∈Adqμ/dEi，单位 a.u.（Bohr³），不对称化；
    • ∂ε/∂Ei（WriteBandOut 时）、dEF/dEi、NF；
    • tag：staticPolResponse(3, 3, nω)、dEidEfield、staticChargeReponse（拼写如此）、neFermi、dEfdE。除极化率外都只保留最后一个 ω。
  • 响应核：对每个原子 A 的单位势：
    • dqdV(mOrb, nAtom, nSpin, nAtom, nω)：逐轨道的布居导数，有自旋时为 (q, m)；
    • dqnetdV：净（on-site）布居的导数；
    • dEidV：本征值的导数；
    • detailed.out 另有最高占据、最低空轨道的导数，以及 “Atom Mulliken On-site” 表。
  • 文件：detailed.out 的 “Electric field polarisability (a.u.)” 块（每个 ω 三行 3E20.12，每行一个场方向），dE_band.out、dV_band.out（(I6, E16.6)）。

三、pydftb 的接口

from pydftb import DFTB
r = DFTB(sk, analysis={"polarisability": {"frequencies": [0.05, 0.1]},     # Hartree，静态默认也算
                       "response_kernel": True}).calculate(labels, pos)
p = r.analysis.polarisability
p.frequencies            # (nω,)，0 在前
p.tensor                 # (nω, 3, 3)，a.u.；周期体系为 None
p.charge_derivatives     # (nω, 3, n_atom)：dq_A/dE_i，电子布居
p.fermi_derivatives      # (nω, 3, n_channel)：dE_F/dE_i（金属，物理值）
k = r.analysis.response_kernel
k.atom                   # (nω, n_atom, n_atom)：[ω, A, B] = dq_B/dV_A
k.orbital                # (nω, n_atom, n_qm, n_orb)：逐轨道
k.net                    # (nω, n_atom, n_atom)：净布居
  • polarisability：True，或 {"static": True, "frequencies": […], "frequency_range": (起, 止, 步长)}，单位 Hartree。频率表的顺序照 DFTB+。
  • response_kernel：True，或 {"rpa": False, "static": True, "frequencies": …}。
  • perturbation：{"degeneracy_tol": 1e-9, "eta": 1e-8}，即 DFTB+ 的 PerturbDegenTol、PerturbEta。没有 PerturbSccTol 与 MaxPerturbIter：pydftb 直接解线性方程，不迭代。
  • 其余结果：
    • 本征值的导数（每个 ω、方向或原子的 (k, 自旋) 块）、NF、是否金属；
    • 写出函数 dftbplus_io.response_tables(...)，给出 detailed.out 的响应块；
    • write_band_derivatives(path, ...)，写 dE_band.out、dV_band.out。
  • 与 DFTB+ 的差别：
    • 所有 ω 的电荷响应和本征值导数都保留；
    • dEF/dE 给物理值（DFTB+ 除了满占据，见第六节）；
    • 共线自旋 + relax_total_spin 的金属两个通道共用一个费米能级；
    • 色散不影响响应，所以允许（DFTB+ 拒绝）。
  • 可同用：
    • 非 SCC、原子或壳层分辨的 SCC、共线自旋、完整 DFTB3 与 H–X 阻尼；
    • H5（在 γ 里）、外场与点电荷中的基态、自定义 U 与参考占据、截断 SK 表；
    • 固定费米能级、Fermi 展宽、k 点与 Γ 点周期体系（只有电荷响应）、色散。
  • 报错：
    • 与 DFTB+ 相同：非 Fermi 展宽、溶剂；
    • DFTB+ 支持、pydftb 留到 M6g-3：+U、onsite 修正、非共线自旋与 SOC；
    • 只 onsite 的三阶（DFTB+ 拒绝，pydftb 也先拒绝）；
    • 偶极修正（DFTB+ 的响应不含它的势）、每个 k 点单独填充、类型切换、选定壳层、XL-BOMD；
    • torch 后端与自动求导（analysis 已在 numpy_only_options）。
开发细节四、实现

思路：显式的 χ0 与线性方程

对一个 (k, 自旋) 块，定义壳层（或轨道）X 上的矩阵元 mXai = ½Σμ∈X[c*μa(Sci)μ + (Sca)*μcμi]。

  • H′ 是每个壳层上的势 VX 时，Mai = ΣXVXmXai；一对 (i, a) 的密度项 U caci† + h.c. 在 Y 上的 Mulliken 布居是 2Re[U·conj(mYai)]。
  • 所以
    • 静态：χ0,u(Y, X) = 2ΣpgpRe[mXpconj(mYp)]；
    • 频率相关：Σs=±ΣpRe[gspmXpconj(mYp)]；
    • p 遍历 DFTB+ 的对集合，g 是 DFTB+ 的权重（θF 或 θ(fi − fa)/(Δ + sω + iη)）；
    • 对 k 点加权求和，再乘满占据。
  • 费米能级的移动给出一个对称的秩 1 修正：+(满占据/NF)ddT，dY = ΣkwkΣi∈WδimYii。加上它后每一列的和为 0，即电子数守恒。
  • 简并组：
    • 静态、组在窗口内：DFTB+ 旋转后只保留对角项 −δiM̃ii；δ 在组内相等时，这与未旋转的整块 −δ Σi,j∈GMijcicj† 相同，与旋转无关、对 V 线性。所以组内的对 (i ≠ j) 取 g = −δ̄/2（两个方向合起来为 −δ̄）；
    • 频率相关：组内的对贡献为 0（占据相同），照 DFTB+ 取 0；
    • 本征值的导数：组内 MGG 的本征值，升序。
  • 自旋：每个通道一个 χs。V↑ = Vq + Vm，V↓ = Vq − Vm，(dq, dm) = (χ↑ + χ↓, χ↑ − χ↓) 的分块。
  • SCC 核 K：
    • q 部分用 Coulomb.gamma，位点与基态相同（原子或壳层），H5 已在 γ 中；
    • DFTB3 用 E3 的 Hessian：J = ⅓[diag(Gdq)A + diag(Adq)G + GTdiag(dq)A + GTdiag(Adq) + A diag(Gdq) + A diag(dq)G]，G = γ3，A 是同一原子的指示矩阵，dq 取基态最后一轮的输入电荷（DFTB+ 的做法）；
    • m 部分用 _spin_matrix 的 W。
  • 解：未知量 x = (q 位点上的 dq, 壳层上的 dm)，(I − χ0K)x = χ0Vext。
    • 电场：Vext 是三个方向的坐标列，周期体系照 DFTB+ 用中心晶胞的坐标；
    • 响应核：每个原子一列，一次解出全部列；
    • 逐轨道的结果用 χ0orb(Vext + Kx)；
    • 非 SCC 与 RPA：x = χ0Vext。
  • 代价：
    • m 对每个块是 n壳层 × n对，按对分批累加 χ0，内存与 n壳层 × 批大小成正比；
    • 本征值的导数需要完整的 M = C†dH C，每个微扰一次 O(N3)；
    • 验证用的体系都很小。大体系的无矩阵版本（每列一次 χ0 作用 + Krylov）以后需要时再做。

目标：α 与布居导数的相对差 ≤ 1e-9（DFTB+ 的残差约 1e-11）；基态的能量、电荷与 SCC 轮数照旧比较。

自洽测试（tests/test_response.py）

  • 与差分比较：静态 α 对 pydftb 外场下偶极的中心差分，覆盖水、DFTB3、自旋、金属；
  • 对称性与守恒：
    • 静态 α 与响应核对称；
    • 响应核每一列的和为 0（绝缘体与金属）；
    • 频率很小时 α(ω) → 静态（绝缘体）；
    • 非 SCC 等于 RPA；
  • 不改变结果的选项：开关色散，响应逐位相同；
  • 与旋转无关：简并组的处理不依赖本征向量在组内的旋转（对 cG 乘随机正交矩阵）；
  • 拒绝的组合与默认路径：拒绝的组合会报错；不开选项时逐位不变。

门槛

照旧：golden 两个环境逐位相同（--allow-new 只放新增的字段名）；refgen --check（与 torch）、dynamics --check；三个环境的 pydftb 测试；PTBP 测试；ptbp parity。

六、DFTB+ 的问题与 pydftb 的做法

问题pydftb
报告的 dEF/dE 是物理值除以满占据（无自旋时差一半）：dEF 用未乘满占据的 dρ 的电荷除以已含满占据的 NF。电荷与 α 不受影响给物理值 Σδi∂εi/Σδi；比较时乘回
RelaxTotalSpin（两个通道共用费米能级）时仍按每个通道各自守恒电子数共用一个移动；测试专用开关复现 DFTB+
默认 PerturbSccTol 1e-5：极化率只准到约 2.5e-7，张量不对称直接解，没有迭代误差
多个频率时，dq/dE、∂ε/∂E、dEF/dE 只保留最后一个 ω全部保留
多个频率时，dV_band.out 中原子 1 的部分每个 ω 都以覆盖方式重写，最后只剩最后一个 ω全部 ω 都写（本征值用 eV、微扰用原子单位，与 DFTB+ 相同）
k 点（复数本征向量）的有限频率响应：按时间反演约化的 k 点集里留下一个 ∝ η 的项，它在完整的 k 网格中与 −k 抵消。CuO 链（1 eV，η = 1e-8）的 dq/dE 因此偏离完整网格的结果约 2e-6（实现时发现）去掉这一项，约化与完整的 k 点集给出相同的结果；测试专用的 DFTB._response_eta_compat 复现 DFTB+
符号与单位不一致：电场的电荷响应是电子布居（+），gross_atomic_charges 是 −(q − q0)结果字段写明是布居（与 DFTB+ 的 tag 相同）
频率单位 Hz、THz、cm−1 少了 2π（与能量单位 cm−1 不一致）只用 Hartree（原子单位）；验证算例用 eV
WriteBandOut = No（socket 驱动的默认值）时写未分配的数组 dEiTmp不适用
Static = No 又没有频率时什么也不算，也不提示报错
±ω 两项都用 +iη（非因果配对）照 DFTB+（实数本征向量只影响虚部；复数本征向量见上一行）

七、拆分、不做的事与风险

  • M6g 的拆分（同一套响应代码）：
    • M6g-1：本块；
    • M6g-2：坐标导数与 Born 电荷（CoordDerivatives：dS、dH0 的差分，含 −εiS′ 的一阶密度，DFTB+ 的 Born 电荷符号与 −∂μ/∂x 相反），Driver = SecondDerivatives 的 Hessian（hessian.out、born.out，带极化率时的 bornderiv.out）；DFTB3 的坐标导数只在开发版中；
    • M6g-3：+U、onsite 修正、非共线自旋与 SOC 下的响应，外部点电荷的导数（ExternalChargeDerivatives，开发版）。
  • 不做：MPI 版本的差异（简并判据、缺少的混合泛函项）；混合泛函的响应（M6h 之后）；溶剂的响应（DFTB+ 不支持，以后可以加 GB 的核并用差分验证）；新功能的 torch 与自动求导版本。
  • 风险：
    • 简并组内 δi 略有不同（近简并）时，DFTB+ 的结果依赖旋转，pydftb 用组平均。差别约 β·容差·δ，验证用的体系是严格简并（对称性），可忽略；
    • k 点的频率相关项含 η 的反对称部分：实现时发现它是约化 k 点集的人为项（见第六节），pydftb 去掉它；
    • 金属的 χ0 有秩 1 修正，(I − χ0K) 的条件数可能较大，用直接解（LU）并检查残差；
    • 默认路径：新代码只在 analysis 请求时走，golden 逐位比较。
