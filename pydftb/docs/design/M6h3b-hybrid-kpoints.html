关键信息

M6h-3a 的周期杂化从 Γ 点推广到 k 点，对应 DFTB+ 25.1 用不平移的 SupercellFolding 的杂化计算。交换在对偶空间里算：每个 k 的 Hx(k) 是 SCC 网格上所有 q 的 ΔP(q)、S(q) 与 γ 的格点和 G(k − q) 的卷积，等于 BvK 超胞 Γ 点的交换算符。MatrixBased 混合每个约化 k 的复数 ΔP(k)，NeighbourBased 混合 BvK 实空间的 ΔP(R)。截断、阻尼截断与 Full 三种库仑核，共线自旋，力，电荷文件与重启，任意 k 上的能带。MinimumImage 放在 M6h-3c。

  • 原型与 DFTB+ 的对照（第二节，探针 P72–P82）：
    • 能量：金刚石原胞（2×2×2、3×3×3、1×2×3、3×1×2）、CO2 晶体 2×1×1、Cu 3×3×3（1000 K）、O2 盒子 2×2×2（自旋）；LC、CAM、全局杂化；两种屏蔽；默认与显式截断、阻尼截断。差 ≤ 4.8e-11 Ha，SCC 轮数全部相同。
    • 力：用 DFTB+ 的 SK 差分步长时差 ≤ 6.0e-12 Ha/Bohr；原型对自身能量的差分 ≤ 3.9e-9。DFTB+ 不给力的组合（阻尼截断、自旋），原型对差分到 ≤ 2.3e-10。
    • 重启：读 DFTB+ 写的电荷文件，Matrix 与 Neighbour 都与 DFTB+ 第二次运行的轮数相同，前几轮的误差每一位相同。能带重启的本征值差 ≤ 2.5e-14 Ha。
    • 组合：DFTB3 + D3、外场加点电荷、MP 展宽、Anderson、DIIS、Simple 混合器、自定义 Hubbard U 都一致。+U 与 onsite 只有照 DFTB+ 的做法冻住块布居才一致（B20）。
  • DFTB+ 25.1 的新问题（第六节）：
    • B20：k 点时混合后的块布居从不更新，DFTB+U 与 onsite 修正一直用起始的块布居。正确地每轮从 ΔPin 求块布居时，CO2 晶体 +U 的能量差 2.2e-3 Ha，onsite 差 3.6e-2 Ha。
    • B19：Full 的格点和是围绕折回晶胞的原子坐标的有限平行六面体，结果随原子怎样折回晶胞而变。
    • B12 证实：负的非对角折叠能通过检查，算出别的能量。B3：a2 沿 z 的晶胞，DFTB+ 算不出默认截断而停下（Γ 点也一样）。
    • NeighbourBased 的默认 Threshold 1e-6：能量偏到 1.6e-6 Ha，轮数变多；1e-8 时 SCC 卡在 5e-9 不收敛。
    • B21：几何步之间沿用的 ΔPin(k) 是上一步折回坐标的规范；原子沿折叠方向穿过晶胞面的那一步，DFTB+ 从错的规范起步，多 4–5 轮 SCC（结果不变）。
  • 超出 DFTB+ 的部分（你的决定）：DFTB+ 在 k 点拒绝的三种组合，即非 Truncated 核的力、自旋配非 Truncated 核、自旋的力，pydftb 都给出精确的结果，用差分与自洽检查验证。
  • ≤ 4.8e-11原型与 DFTB+ 25.1 的能量之差（Ha）
  • ≤ 6.0e-12原型与 DFTB+ 的力之差（Ha/Bohr）
  • 2.5e-14能带重启的本征值之差（Ha）
  • 0.1 s原型的金刚石 3×3×3（DFTB+ 0.9 s）

一、DFTB+ 的做法

源码 25.1（dftb/hybridxc.F90、rshgamma.F90、dftb/densitymatrix.F90、dftb/periodic.F90、dftb/boundarycond.F90、dftbplus/main.F90: getNextInputDensityCplx、dftb/sccinit.F90、mixer/*.F90）；调研记录在草稿目录 m6h3/research_hybrid_periodic.md 第四节起。

  • k 点集：只许 SupercellFolding，折叠矩阵是对角的 diag(N1, N2, N3)，平移为零；k = (i1/N1, i2/N2, i3/N3)，i1 最慢、i3 最快，k 与 −k 合并、保留先出现的一个，权重相加（getSuperSampling，按反演约化）。显式的 k 点只许在单轮的能带重启里用。
  • γ 的格点和：G(k, k′)AB = Σg γc(|RB − RA − g|) ei2π(k−k′)·g，g 取与 Γ 点相同的平行六面体，原子坐标是折回晶胞的坐标（foldCoordsToCell：frac − ⌊frac⌋）。截断核在格点和覆盖 Rc 以内时与坐标怎样折回无关；Full（不截断）的有限和就与之有关（B19）。
  • 交换（MatrixBased，addCamHamiltonianMatrix_kpts）：对每个约化 k，Hx(k) = c Σk′ (wk′/2)[T(k, k′) + T(k, −k′)]，T 是 Γ 点四项公式的对偶形式，各项是 SΔPS、SΔP、ΔPS、ΔP 在 k′ 上与 G(k, k′) 的哈达玛积，再在 k 一侧乘 S(k)。它等于对完整网格求 (1/N)Σq。
    • pydftb 的约定 M(k) = ΣT M(0, T) ei2πk·T 下写成 Hx(k) = (c/N) Σq[(SΔPS)(q)∘G(k−q) + ((SΔP)(q)∘G(k−q))S(k) + S(k)((ΔPS)(q)∘G(k−q)) + S(k)(ΔP(q)∘G(k−q))S(k)]，G(p)AB = Σg γc(|RB + g − RA|) ei2πp·ng。
    • 这正是 N1×N2×N3 超胞在 Γ 点的交换算符（固定的 ΔP 下与 M6h-3a 的超胞计算差 1.1e-16）。
    • ΔPin 全为零时（第一轮）Hx = 0。
  • NeighbourBased（addCamHamiltonianNeighbour_kpts_ct）：实空间的四重循环，S 是 CAM 截断以内的对称近邻表，ΔP 取 BvK 数组。Threshold 很小时它与 MatrixBased 是同一个算符（S 换成缩减的 S）。默认的 Threshold 1e-6 下按增量筛选，结果依赖历史（P80）。
  • 参考密度：ΔP(k) = P(k) − diag(s q0μ/Sμμ(k))，Sμμ(k) 只取决于晶格。实空间的 P0 因此不是纯在位的，k 点计算只有在原子不与自身镜像重叠时才等于超胞的 Γ 点计算。
  • 能量：EFock = Σk wk ½ Re Σ Hx[ΔPin](k)∘conj ΔPout(k)，用的是 ΔPout（Γ 点用 ΔPin，B4）。
  • SCC（getNextInputDensityCplx）：
    • MatrixBased：混合所有约化 k 与自旋的完整复矩阵 ΔP(k)（复数混合器只取内积的实部，等于实数混合器作用在 [Re | Im] 上），误差为复数模的最大值。
    • NeighbourBased：混合实的 BvK 数组 ΔP(n) = Σk wk Re[ΔP(k) e−i2πk·n]，误差为最大绝对值。
    • qin = Mulliken(ΔPin) + q0（k 点没有 Γ 点的 B6：packHS 把原子块补成厄米的）。
    • 块布居（+U、onsite）混合后不更新（B20）。
    • 第一轮、自旋第一轮不混合、最少轮数、重启时可在第一轮收敛：与 Γ 点相同。
    • 几何步之间沿用 ΔPin(k)，是折回坐标的规范：原子穿过晶胞面时规范跳变（B21，P82）。
  • 力：只有 Truncated、不加自旋。MatrixBased 是能量的导数（P74，调研里的 B17 疑问不成立）；NeighbourBased 混用 ΔPin(R) 与 ΔPout(k)（B5），差别是 SCC 误差的量级，紧容差下看不出。
  • 默认截断：Rc 由 getCoulombTruncationCutoff(latVecs, nK) 照代码算：BvK 向量按笛卡尔分量乘折叠数（B2），两条体对角线的交点只用 x、y 投影求（B3）；Rg = 2Rc。
  • 电荷文件：折叠记录（对角 N，零平移）之后只有一条记录。MatrixBased 是复数 ΔPin(k)（nOrb, nOrb, nK·nSpin），k 最快、自旋在外；NeighbourBased 是 BvK 数组（nOrb, nOrb, N1, N2, N3, nSpin）。两者都是折回坐标的 Bloch 规范。重启要相同的折叠；能带重启（KLines、MaxSCCIterations = 1）从文件的 ΔP(k′) 在任意 k 上建 Hx。
  • 拒绝（P78，原话见第二节）：带平移或非对角的折叠、显式 k 点、Thresholded、非 Truncated 核的力、自旋配非 Truncated 核、自旋的力、折叠不同的重启、非共线、激发态。

二、DFTB+ 的实测行为与原型

探针 P72–P82（草稿目录 m6h3b/，记录在 notes_k.md）。原型 kproto.py 在 M6h-3a 的工作树上换掉 k 点的 SCC 与交换。参数集 ptbp_hcocu_lc、_cam、_global，SCC 容差 1e-10，EwaldTolerance 1e-12；DFTB+ 的输入写 SupercellFolding，NeighbourBased 写 Threshold = 1e-100（同 DFTB+ 自己的测试）。

三、pydftb 的接口

from pydftb.bands import eigenstates
from pydftb.kpoints import supercell_folding
calc = DFTB(sk_lc, hybrid="lc", kpts=supercell_folding((2, 2, 2)))   # DFTB+ 的约化与顺序
r = calc.calculate(labels, pos, cell, forces=True)
r.e_fock, r.q_in                     # q_in = [布居 | 打包的 ΔP(k) 或 BvK ΔP(R)]
eigenstates(calc, labels, pos, cell, populations=r.q_in, kpts=path)  # 任意 k（Hx 取自 SCC 网格的 ΔP）
atoms.calc = PyDFTB(skdir, hybrid="lc", kpts={"size": (2, 2, 2), "gamma": True})
  • k 点集：
    • 周期杂化的 k 点必须是不平移的超胞折叠网格（完整的，或按 DFTB+ 约化的）；pydftb 由 k 点认出 N1×N2×N3，其余用 DFTB+ 的原话拒绝。
    • 新函数 kpoints.supercell_folding(n) 给出 DFTB+ 的约化集与顺序（电荷文件按这个顺序）。
    • ASE：kpts={"size": (n1, n2, n3), "gamma": True}（ASE 的写法）；杂化配带平移的网格时报错并提示这个写法。
  • Hybrid 的选项：
    • coulomb 多一个 "full"，只在 k 点用；
    • "minimum_image" 到 M6h-3c 之前拒绝；
    • 默认 Rc 照 DFTB+ 的代码（B2）；B3 的晶胞报 DFTB+ 停下时的原话并说明原因，Γ 点也一样。
  • NeighbourBased 的 Threshold：pydftb 不筛选（等于 DFTB+ 的 Threshold → 0）。DFTB+ 默认的 1e-6 与之差到 1e-6 Ha（P80），文档写明，对照时设 1e-100。
  • 超出 DFTB+ 的组合（你的决定）：阻尼截断与 Full 的力、自旋配阻尼截断与 Full、自旋的力，都给出能量的精确导数；文档写明 DFTB+ 拒绝、没有 DFTB+ 参考。
  • 块布居：+U、onsite 每轮从 ΔPin 求块布居（同 Γ 点）。验证用的类属性 _dftbp_stale_blocks 照 DFTB+ 冻住它（B20）。
  • 电荷文件：
    • charge_data 与 populations_from_file 读写两种 k 点记录，按 DFTB+ 折回坐标的规范换算（由本次的坐标求 T）。
    • 布局由记录长度认出；pydftb 能把 MatrixBased 的文件读给 NeighbourBased 的计算，反之亦然（DFTB+ 不能，文档写明）。
    • 折叠不同时报 DFTB+ 的原话。
  • 其余同 Γ 点：应力（报错）、Thresholded、非共线、TD-LC、torch 拒绝。几何步之间沿用打包的 ΔP，用于结构优化与 MD（只有 Truncated 能对照 DFTB+）。
开发细节四、实现
  • hybrid.py（分子与 Γ 点的路径逐位不变）：
    • dftbp_coulomb_cutoff(cell, nk)：照 getCoulombTruncationCutoff 移植（B2），B3 的退化情形报错。Γ 点仍用 default_coulomb_cutoff（非退化晶胞的值逐位不变），只加退化检查。
    • dftbp_fold_shifts(pos, cell)：DFTB+ 折回时减去的晶格矢量。
    • KPointHybridTerms：与 HybridTerms 相同的接口（reference、pack、unpack、error、reset、fock、energy、pair_coefficient、gamma_gradient），另加 fock_at（能带）与 DFTB+ 文件布局的换算。
      • KPointLayout：本次计算的 k 点集（完整网格或任一约化集）与 BvK 超胞的 N 个胞（DFTB+ 的顺序，n1 最快）之间的变换 X(n) = Σk wk Re[X(k) e−i2πk·n] 与 X(k) = Σn X(n) ei2πk·n，都是 (N × Nk) 的实矩阵积；打包、解包、误差；DFTB+ 记录的规范换算（D†ΔP(k)D 与胞号移 TB − TA）与 k 点集的对应（±k 取共轭）。
      • 卷积 (1/N)Σq X(q)∘G(k − q) 写成 BvK 实空间的乘积：C(X)(k) = Σn [X(n)∘g(n)] ei2πk·n，g(n)AB 是格点和中胞号 ng + TA − TB ≡ n 的各项。格点和用 DFTB+ 折回的坐标与 Γ 点相同的平行六面体（等于每个原子对的平行六面体移 TA − TB，B19）；截断核只留 Rc 以内的项。
      • Hx(k) = c[C(SΔPS) + C(SΔP)S(k) + S(k)C(ΔPS) + S(k)C(ΔP)S(k)]：每个 k 三次矩阵积，四个卷积各两次实矩阵积。fock_at 在任意 k 上用带相位 ei2πk·ng 的格点和。
      • 力：S 的系数 X(k) = c[C(ΔP) S ΔP + C(ΔPS) ΔP + ΔP S C(ΔP) + ΔP C(SΔP)]，其 BvK 矩阵在胞 −T 的元素就是成对元素的系数；γ 的系数是 BvK 实空间的 W(n) = c[ΔP(n)∘(SΔPS)(n) + (ΔPS)(n)∘(SΔP)(n)]，乘以格点和各项的 γ′（每项同时出现在 (A, B, n) 与 (B, A, −n)）。NeighbourBased 用缩减的 S 与截断掩码，同 Γ 点。
  • kpoints.py：supercell_folding(n)；folding_of(kpts, weights) 认出 N 并检查（完整网格等权重，或每对 ±k 中任一个、权重 2/N 与自反的 1/N）。
  • calculator.py：
    • _setup 与 _check_periodic_hybrid：放开 k 点，建 KPointHybridTerms；MinimumImage 拒绝到 M6h-3c，Γ 点的 Full 照 DFTB+ 拒绝。
    • _scc_hybrid_kpoints：每个自旋的复数 ΔP(k)，Fock 按自旋拼接，EFock 在对角化之后用 ΔPout，混合后的 qin 与块布居来自 ΔPin(k) + P0(k)（_dftbp_stale_blocks 照 DFTB+ 冻住块布居）。Γ 点与分子的 _scc_hybrid 不变。
    • charge_data、populations_from_file 多 positions、cell 两个参数（k 点的规范要用）；calculate 读文件时自己传入。
  • dftbplus_io.py：ChargeData 多两个字段（复数的 ΔP(k) 与实的 BvK 数组，都保持 DFTB+ 文件里的样子）；文本里复数是 “(a,b)” 记号，二进制是一条记录。
  • bands.py：k 点杂化在任意 k 上的本征态（fock_at，缩减 S 用于 NeighbourBased）。
  • ase_calc.py：kpts 的 {"size" 或 "density", "gamma"}；带平移的网格由 DFTB 的检查报错，提示这个写法。

六、DFTB+ 的问题与 pydftb 的做法

DFTB+ 25.1证据pydftb
B20：k 点混合后不更新块布居（main.F90 的 getNextInputDensityCplx 只更新 qin；Γ 点的 getNextInputDensityReal 用 denseBlockMulliken 更新 qBlockIn），DFTB+U 与 onsite 的势一直用起始的块布居（自旋时是第一轮的输出）P79：照此冻住块布居时与 DFTB+ 一致到 7.5e-11；正确的做法差 2.2e-3（+U）与 3.6e-2 Ha（onsite）每轮从 ΔPin 求块布居；验证用的 _dftbp_stale_blocks 复现 DFTB+
B19：Full 的格点和是折回坐标的有限平行六面体（rCoords 是近邻表的折回坐标），结果随原子怎样折回晶胞而变P72f：用原坐标差 0.1–0.3 Ha，用折回坐标差 4e-11与 DFTB+ 相同（每个原子对的像移 TA − TB）；文档写明 Full 只供测试、不收敛
B2：默认 Rc 的 BvK 向量按笛卡尔分量缩放P75：FCC 1×2×3 为 2.88885（本意 1.94586）与 DFTB+ 相同（照代码），文档写明
B3：a2 沿 z 等晶胞的对角线交点求不出，DFTB+ 停下P75，Γ 点与 k 点报 DFTB+ 的原话并说明，可给 coulomb_cutoff
B12：负的非对角折叠能通过检查P78：能量 −3.15436（对角 −3.13078）只认对角折叠的网格
B4：k 点的 EFock 用 ΔPout调研；P72 的 EFock 一致到 6e-11与 DFTB+ 相同
B5：NeighbourBased 的 k 点力混用 ΔPin(R)P74：紧容差下 9.7e-13精确的导数（ΔPout）
NeighbourBased 的默认 Threshold 1e-6P80：能量偏到 1.6e-6 Ha，轮数多；1e-8 时不收敛不筛选；文档写明；移植筛选放在 M6h-3c
B21：几何步之间沿用的 ΔPin(k) 是上一步折回坐标的规范，原子穿过晶胞面后规范跳变P82：穿过的那一步多 4–5 轮，其余相同ΔP(k) 是未折回坐标的规范，连续；动力学的参考把晶胞居中

七、不做的事与风险

  • M6h-3c：MinimumImage（NeighbourBased 的 Wigner–Seitz 网格，表面向量不加权 B9；MatrixBased 加 MIC 的另一种近似 B10），以及 NeighbourBased 的 Threshold 增量筛选（P80 的差别到 1e-6 Ha）。
  • 不做：应力（DFTB+ 没有）；Thresholded、非共线、周期的 TD-LC（DFTB+ 拒绝）；带平移或非对角的折叠（DFTB+ 拒绝）。
  • 规模：
    • 混合向量长 2·Nk·n²·Nspin（MatrixBased）或 N·n²·Nspin（NeighbourBased），Broyden 的历史与之成正比，与 DFTB+ 相同。
    • 交换每轮 O(Nk·N·n²) 的实矩阵积（BvK 变换）加 O(Nk·n³) 的矩阵积；轨道级的 g(n) 占 N·n² 个实数。
  • 风险：
    • DFTB+ 不给力的组合只有差分与自洽检查，没有外部参考；
    • Full 不收敛，只能固定轮数对照；
    • B20 的对照依赖兼容开关，pydftb 自己的 +U/onsite k 点结果只与差分和 Γ 点的超胞比较。
