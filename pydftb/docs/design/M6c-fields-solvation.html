关键信息

M6 的第三步：分子所处的“环境”。外电场、外部点电荷和原子格点势是固定的外加电势，隐式溶剂是随电荷变化的介电响应。它们都只作用在原子电荷上，进入哈密顿量的方式与 SCC 的库仑势相同，所以不改动混合向量，也不改动现有路径。只做 NumPy 引擎；torch 后端和自动求导遇到这些选项时明确报错。

  • 做什么（全部对照 DFTB+ 25.1）：
    • 外电场（ElectricField { External }）：均匀静电场。分子直接用 r·E；周期体系与 DFTB+ 一样用锯齿势（原子坐标先折回晶胞）。给出能量、力和应力。
    • 外部点电荷（ElectricField { PointCharges }）：静电嵌入，例如 QM/MM 中的 MM 原子。可以加高斯展宽；周期体系用 Ewald 求和。另给出点电荷受的力，并实现 ASE 的 QM/MM 嵌入接口（embed）。
    • 原子格点势（AtomSitePotential）：给指定原子加一个常数电势，作用在 Mulliken 电荷上（Gross）或只作用在原子自身的“净”布居上（Net）。
    • 隐式溶剂（Solvation）：广义 Born 模型（GB，Still 或 P16 核）及其 ALPB 变体，溶剂可及表面积项（SASA），氢键修正，CM5 电荷修正；溶剂常数表、参考态换算、xtb 格式的 GBSA 参数文件。只用于分子，与 DFTB+ 相同。
  • DFTB+ 的实测（第二节）：
    • 外场和点电荷可以与自旋、非共线自旋、SOC、DFTB+U、onsite 修正、DFTB3、k 点同用。溶剂可以与外场、点电荷、两分量计算同用。
    • 与原计划不同：原计划说 DFTB+ 不允许外场与溶剂同用，25.1 其实允许，并且默认把外场放大 3ε/(2ε+1) 倍（RescaleSolvatedFields）。pydftb 照此实现。
    • 有点电荷时 DFTB+ 不输出应力，也不报错。
    • 周期体系加外场时，DFTB+ 的应力张量不对称，对称化以后才与应变差分一致（1e-6）。另外，它用的是未折回晶胞的坐标，有原子在晶胞外时对角元也不对。pydftb 给出与能量一致的对称应力。
  • 用法：DFTB(sk, electric_field=(0.01, 0, 0))（原子单位）；DFTB(sk, point_charges=(R, Q))；DFTB(sk, solvation=GeneralizedBorn(solvent="water", …))；ASE 中 PyDFTB(…, electric_field=(0.5, 0, 0))（V/Å）。
  • 验证：22 个新的 DFTB+ 参考算例和 1 个溶剂中的分子动力学对照，比较能量各项（含 Eext、Esolv）、力、应力、电荷、点电荷受的力、偶极矩和 SCC 轮数。旧算例逐位不变。
  • 4外加项：外电场、点电荷、格点势、隐式溶剂
  • 3ε/(2ε+1)溶剂中外场的放大倍数（DFTB+ 默认）
  • 22 + 1新的 DFTB+ 参考算例 + 分子动力学对照

一、DFTB+ 的做法

下文 ΔqA = qA − q0A 是原子 A 多出的电子数（与 DFTB+、pydftb 现有约定相同），原子的净正电荷是 −ΔqA。所有外加项都先给出每个原子的电势 VA，再像 SCC 的库仑势一样以 ½Sμν(VA + VB) 进入 H（只作用在电荷分量上，自旋和两分量路径不变）。这样“交叠矩阵导数”那部分力自动正确，另外只需加上 VA 对坐标的显式导数。

外电场（extfields.F90）

  • 势：VA = rA·E，E = 场强 × 单位方向。分子用原子坐标。周期体系用折回晶胞后的坐标（分数坐标取 [0, 1)），也就是锯齿势；DFTB+ 会提醒“周期方向上要有真空层”，若有原子对跨过锯齿的间断还会再警告。
  • 能量：Eext = ΣA ΔqA (rA·E)，记在 “Energy ext. field”。物理上就是电子（负电荷）在场中的势能。
  • 力：除 S 导数项外，每个原子多一项 dE/drA = ΔqA E。应力：ΣA ΔqA Ei rA,j / V（见第二节关于 DFTB+ 应力的两点问题）。
  • 含时外场（Frequency、Phase）只能用于 DFTB+ 自己的 MD 驱动，pydftb 不做。

外部点电荷（extcharges.F90、coulomb.F90）

  • 势：VA = −Σj Qj φ(rA − Rj)。分子中 φ(r) = 1/r，加高斯展宽 σ 时 φ(r) = erf(r/σ)/r（r ≥ 10σ 时直接用 1/r）。周期体系的 φ 是 Ewald 和：实空间 erfc(αr)/r（有展宽时改为 [erf(r/σ) − erf(αr)]/r），倒空间项，加上中和背景 −π/(Vα²)。负号来自电子数的约定：DFTB+ 内部把点电荷存为 −Q。
  • 能量：ΣA ΔqA VA，与原子电荷之间的库仑能一起记在 “Energy SCC”。只有电荷转移部分与点电荷相互作用，中性原子的芯不参与。
  • 力：原子上多一项 ΔqA ∂VA/∂rA；点电荷受的力是它的反作用，写在 results.tag 的 forces_ext_charges 和 detailed.out 的 “Forces on external charges”。
  • 应力：有点电荷时 DFTB+ 关掉应力（initprogram.F90：tStress = tStress .and. .not. tExtChrg），不报错。

原子格点势（AtomSitePotential）

  • Gross：VA 为常数，按上面的方式进入 H；能量 ΔqAVA。
  • Net：只作用在原子自身的“净”布居 NA = Σμ∈A ρμμ 上（同一原子的轨道交叠为单位阵），即只把 VA 加到 A 的对角元上（addOnsiteShift）；能量 (NA − q0A)VA。它与坐标无关，也不含 S，所以没有额外的力。
  • 两者的能量都记在 “Energy ext. field”。

广义 Born 与 ALPB（born.F90）

  • 能量：EGB = ½ ΣAB qA BAB qB，BAB = kε f(RAB, aA, aB)，对角元 kε/aA；kε = (1/ε − 1)/(1 + αβ)，ALPB 时 β = αALPB/ε（αALPB = 0.571412），否则 β = 0。电荷取 Δq（符号对二次项无关）。
  • 核：Still，f = [R² + aAaB exp(−R²/(4aAaB))]−1/2；P16，f = 1/[R + √(aAaB)(1 + ζR/(16√(aAaB)))−16]，ζ = 1.028。
  • Born 半径（GBOBC）：先按成对近似求体积积分 ΨA（xtb 的公式，按两个原子的范德华半径与“去屏蔽”半径 sBRB 是否重叠分四种情形），再 1/aA = [1/(RA − Roff) − tanh(bΨ − cΨ² + dΨ³)/RA]，最后乘 BornScale。默认 OBC 系数 (1.00, 0.80, 4.85)。只考虑截断半径内（默认 35 Å）的原子对。
  • ALPB 的形状项：B 的每个元素再加 kεαβ/Adet，Adet 由以 R3 加权的转动惯量张量的行列式得到。只影响带电体系（能量 ∝ (ΣΔq)²）。
  • 氢键修正：每个原子的能量加 SASAA hA ΔqA²，hA = HBondStrength/(探针半径 + RA)²。
  • CM5：GB 用的电荷改为 ΔqA − cA，cA = ΣB DAB exp[−α(RAB − RA − RB)]（D 来自 CM5 原文的元素参数）。只依赖几何，所以 SCC 势仍是 B 乘以电荷，力里多一项 c 的导数。
  • 势：VA = ΣB BABqB（+ 2 SASAAhAΔqA）。与三阶项一样，SCC 每一轮用输入电荷更新，能量和力用最后的输出电荷。
  • 能量：Esolv = EGB + EHB + ESASA + ΔGshift，记在 “Solvation energy”。ΔGshift 是常数（FreeEnergyShift 加参考态换算：gsolv 不加；mol1bar 加 kT ln(24.79 T/298.15)；reference 再加 kT ln(ρ溶剂/ρ参考 · M参考/M溶剂)）。
  • 只用于分子：周期体系报错（“currently not available with the selected boundary conditions”）。

溶剂可及表面积（sasa.F90）

  • 每个原子取半径 RA + 探针半径的球面，用 Lebedev 角向网格（默认 230 点）积分。每个网格点的“暴露度”是所有邻居的平滑阶跃函数之积（平滑宽度默认 0.3 Å，三次多项式），暴露度 ≤ 1e-6 的点直接舍去。
  • ESASA = ΣA γA SASAA，其中 γ 按 DFTB+ 的约定乘 4π·10−5。与电荷无关，只有能量和力。
  • 可以单独使用（Solvation = SASA），也是 GBSA 的一部分。

溶剂中的外场（fieldscaling.F90）

  • 有溶剂且 RescaleSolvatedFields = Yes（默认）时，外场强度乘 3ε/(2ε+1)（ε 无穷大时为 3/2），即球形空腔内的场。只有 SASA 时没有静电效应，DFTB+ 警告后关掉缩放。
  • detailed.out 打印的偶极矩同样乘这个倍数。点电荷不缩放。

偶极矩

D = ΣA (q0A − qA) rA（原子单位 e·Bohr），DFTB+ 写在 detailed.out。带电体系的偶极矩依赖原点，周期体系没有明确意义，DFTB+ 都会警告。

  • DFTB+ 的外场应力项是 Σ Δq Ei fj 乘晶格矢量（getExtFieldStress），没有对称化；对称应变只能“看到”它的对称部分。反对称部分对应外场对体系的力矩，不是应力。

  • 能带：eigenstates 把外加势和溶剂势一并加进 H，与 DFTB+ 能带计算（读入电荷）相同。

进入 SCC 的方式

  • 固定势（外场、点电荷、Gross 格点势）：几何确定后算一次，存为每个原子的 vext。_potentials 把 vext[orb_atom] 加到电荷势上，所以 H、能带、力里的 S 导数项都自动包含它；共线自旋时它只进入电荷分量，两分量时只进入 Hq。
  • 净势：加在 H 的对角元上（每个 k 点、每个自旋分量都一样），不经过 S。能量用对角布居 Σk wk Re ρμμ(k) 计算。
  • 溶剂势：与三阶项相同，由当前输入电荷 Δq（按原子求和）算出 B·q 加到电荷势上；SASA 与几何有关的量在 setup 中算好。
  • 能量的归属：点电荷能量并入 e_scc（DFTB+ 的口径）；外场与格点势为 e_ext；溶剂为 e_solv；总能量相应增加。所有新项都用 if st.ext is not None 一类的条件门控，不加零数组，旧路径逐位不变。
  • 混合向量不变：外加项都只依赖原子电荷，不新增需要混合的量。

力、应力与点电荷受的力

  • 原子力的显式部分：外场 ΔqAE；点电荷 ΔqA∂VA/∂rA（分子用解析式，周期用 Ewald 实空间与倒空间的导数）；溶剂为 Born 矩阵对坐标和 Born 半径的导数（链式经过 Ψ）、ALPB 形状项、SASA、氢键、CM5。
  • 点电荷受的力：−∂E/∂Rj，与原子上的显式项方向相反、数值对应。
  • virial：外场 Σ ΔqA Ei rA,j（折回坐标），由最后的对称化处理。点电荷的周期体系不给应力；溶剂只有分子，没有应力。

需要逐项照搬的细节

  • 折回：分数坐标减去 floor，与 DFTB+ foldCoordsToCell 相同。锯齿警告的判据：存在 SK 邻居对，其晶格平移与场方向不正交。
  • 点电荷展宽：r < 10σ 才乘 erf(r/σ)（DFTB+ erfArgLimit_）。
  • Born 半径的四种重叠情形、Ψ 的截断（35 Å）、SASA 舍去暴露度 ≤ 1e-6 的点、平滑函数的三个系数，全部照 born.F90、sasa.F90。
  • CM5：DFTB+ 在 GB 中用对称邻居表调用 getCorrection，循环里没有防止重复计数的判断（Born 半径的循环有）。实现时数值核实：DFTB+ 确实把每对原子算了两次；pydftb 默认按 CM5 原文，CM5(double_count=True) 复现 DFTB+（报告第五节）。
  • 参数文件：前 8 行为 ε、摩尔质量（amu）、密度（kg/L）、BornScale、探针半径（Å）、自由能平移（kcal/mol）、BornOffset（0.1 Å）、未用；随后 94 行为每个元素的表面张力、去屏蔽、氢键参数（氢键强度 = −h² kcal/mol）。

六、不做的事与风险

  • 不做：含时外场（只用于 DFTB+ 自己的 MD 驱动）；COSMO（区域分解求解，另作专题）；周期体系的溶剂（DFTB+ 也不支持）；静态极化率与响应核（Perturbation）；静电势网格输出；有点电荷时的应力（DFTB+ 不给）；torch 后端与自动求导。
  • 风险：
    • SASA 的阈值舍去和平滑函数使能量在个别构型上有微小的不连续；与 DFTB+ 逐点照搬，差分测试避开阈值附近。
    • 周期点电荷的 Ewald 和依赖截断；pydftb 用自己的 α 与 1e-12 的容差，DFTB+ 默认容差 1e-9，参考算例两边都设 1e-12。
    • CM5 在 DFTB+ 中重复计数（第四节；已核实，见报告第五节）。
    • SciPy 早于 1.15 时没有 Lebedev 网格：只有用到 SASA 时才报错，并说明所需版本。
