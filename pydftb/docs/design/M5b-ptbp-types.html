关键信息

M5 的第二块，PTBP 一侧。PTBP 给每个元素三个参数：r0w、r0d（hotcent 的波函数与密度约束半径）和 σrep（physrep 排斥势的大小）。调研确认现在的 PTBP 对多元素数据集让所有元素共用一组 (r0w, r0d, σrep)。按用户的决定，M5b 起参数按“类型”记账：类型默认就是元素，所以多元素数据集默认每个元素各三个参数；--shared-parameters 复现共用一组；单元素数据集不变。可选地把一个元素分成几个类型，用 M5a 的平滑切换（按配位数），每个类型三个参数，切换窗口是固定的超参数。

  • 记账（第三节）：类型 = 标签 + 元素。优化器看到每个参数集的 (r0w, r0d)，共 2N 维（N 个参数集）；σrep 每个参数集一个，在内层搜索。罚项是各参数集罚项的几何平均（最小值仍是 4，两个类型取相同半径时等于单类型的罚项）。--multi_element 改为“只拟合这些元素，其余元素用 PTBP 发表的参数”，同时修好它原来的几处错误。
  • 逐位不变：一个参数集、没有固定类型、没有切换（单元素，或 --shared-parameters）时走 M5b 之前的代码，所有文件逐字节相同（唯一的例外是有意的修正：非 Hill 顺序的多元素结构在 dftb_full.xyz 中的元素顺序，P5），检查点仍是版本 2。按类型的布局是损失版本 3，检查点记下类型。
  • σrep 的 N 维搜索（第三节）：先按原来的一维搜索找一个共用的 σ，再让每个参数集在 11 点格子上单独走一步（其他保持当前值），然后对全部 σ 联合 L-BFGS-B；格子在联合极小处还能改进时再来一轮（至多 3 轮）。11N 的格点不可行。
  • hotcent、physrep、引擎（第四节）：同一元素的两个类型的表两个方向都算、去掉 on-site 行、按标签命名（P2：与 M5a 的 cu_types 逐字节相同）；physrep 按标签记账，有切换时排斥能由 pydftb.typeswitch 自己的函数按权重混合（含权重对力的贡献）；pydftb 引擎收到 type_switching，DFTB+ 遇到切换时报错。
  • 梯度（第五节）：按元素的参数有 2N 个方向，每个方向只重算该类型的表；σ 为向量时包络定理在联合最优处仍成立，M4c 的一维折点修正推广为乘子形式 dμ*/dx = ∂μ̃/∂x + λ·∂rK/∂x（JKTλ = −∇σμ̃），一维时就是 M4c 的公式。有切换时梯度优化器报错（pydftb.autodiff 没有混合块）。
  • 探针中的发现（第二节）：energygeometry 的 Boltzmann 权重让 Cu 数据集的二聚体、AA 石墨、金刚石（CN 1、3、4）全部不进入损失，所以“CN ≤ 4 / CN ≥ 10”的分法使低配位类型没有数据；示范改用 β-Sn（CN ≈ 10）与密堆积（CN 12、14）之分。data.get_full_dftb 按 Hill 顺序重建结构，N3Na 写出的元素与坐标错位（修正）。
  • 2N优化器的维数（N 个参数集，默认每个元素一个）
  • 0单元素与 --shared-parameters 允许改变的字节
  • 0.797Cu 两类型在发表的 r0 上只分开 σrep 的损失（单类型 0.920）

一、目标与用户的决定

  • 用户的决定：参数化是每个元素三个参数（r0w、r0d、σrep）。多元素数据集从 M5b 起默认每个元素各三个参数；--shared-parameters 复现现在的共用方式，逐字节相同；单元素（Cu）不变。
  • 类型：参数按类型记账。类型默认就是元素；可选地声明一个元素的几个类型（M5a 的平滑切换），每个类型三个参数，切换窗口的 centre、width 固定（不拟合）。PTBP 默认不用多类型。
  • 范围：energygeometry、dataset、reaction 三种模式；BO、并行 BO、PSO、梯度与 BO+梯度五种优化器（有切换时只有前三种）；pydftb 与 DFTB+ 两个引擎（有切换时只有 pydftb）。bandstructure 模式不变。

三、类型、参数集、罚项与 σrep 的搜索

类型与参数集

  • 类型（utils/typemodel.py 的 PType）：标签（SKF 文件名用它，Cu2-Cu.skf）、元素、以及不拟合时的固定值。顺序：元素按原子序数；被切换元素的类型按切换的顺序（CN 从小到大）。
  • 参数集（ParameterSet）：一组 (r0w, r0d, σrep) 和用它的类型。默认每个类型一个参数集；--shared-parameters 时所有拟合的类型共用一个；--multi_element E… 时只有这些元素的类型拟合，其余类型固定在 PTBP 表的值（r0w、r0d、σrep）。
  • 旧布局（TypeModel.legacy）：只有一个参数集、没有固定类型、没有切换，就是 M5b 之前的布局（单元素或 --shared-parameters）；Loss 走原来的代码，cli/run.py 写原来的表头。
  • 优化器的向量：x = (r0w, r0d) 按参数集排列，维名 r0_w_B, r0_d_B, r0_w_N, …（一个参数集时仍是 r0_w, r0_d）。边界按参数集的共价半径（ASE 的值）：r0w ∈ [2.1, 7 rcov]，r0d ∈ [3.4, 9 rcov]，与原来的公式相同。起点：声明的起始值，否则 PTBP 表，否则 rcov × (3, 5)，再截到边界内（P6）。
  • 结果文件夹：opt_<r0_w>_<r0_d>[_<r0_w>_<r0_d> …]，按参数集顺序；一个参数集时与原来相同。

罚项

  • 每个参数集 Pk = ((r0w/2r − 1)² + 1)² · ((r0d/4r − 1)² + 2)²（原来的公式，r 为该参数集的共价半径），总罚项取几何平均 P = (Πk Pk)1/N。
  • 理由：最小值仍是 4，损失与单元素同一量级；乘积形式与原来一致，ln P 可加，∂ln P/∂r0k 就是原来的导数除以 N；两个类型取相同的 r0 时 P 等于单类型的罚项，所以多类型模型在“类型参数相同”时的损失（σ 也相同时）就是单类型的损失。算术平均在偏离小时与几何平均一阶相同，乘积会让 N 个类型的最小值变成 4N。
  • 共用参数集（旧布局，或 --shared-parameters 加 --multi_element）：原来的规则，一个半径（--multi_element 的第一个元素，否则最重的元素）。

σrep 的搜索

  • 外层只优化 r0；σ 每个参数集一个，在固定 r0 下搜索。损失在 σ 处的值由 utils/loss_grad.mu(step, σ) 计算（M4c 的纯函数，现在也收 σ 向量；不写文件），每次求值写一行日志（reaction 模式另写各化学式的明细）。
  • 一个 σ（例如 --multi_element 只给一个元素）：原来的做法，11 点格子 + fmin 抛光，再 L-BFGS-B（ftol 1e-3，最多 20 次）。
  • N 个 σ：① 原来的一维搜索找一个所有参数集共用的 σ（截到 [0.1, 0.8]）；② 依次让每个参数集在 11 点格子上单独搜索（其他参数集保持当前值；比当前值好才接受）；③ 从这里对全部 σ 联合 L-BFGS-B（ftol 1e-3，最多 20N 次）；④ 从联合极小处再做一遍 ②，若有改进再做 ③，至多 3 轮。共约 11 + 抛光 + 1 + 22N + 20N 次求值（第二轮的格子没有改进时），而 11N 的格子不可行。第 ① 步保证结果不比共用 σ 差（在同样的 r0 下）。第 ④ 步是实现中加的：L-BFGS-B 停在折点上，而几乎不影响损失的 σ（平台，如 reaction 示例中 Na 的 σ）要等其他 σ 移动之后才在格子上显出更好的点（报告第八节）。
  • 搜索结束后在 σ* 处写一次文件（SKF 的样条、dftb_full.xyz，energygeometry 的 EOS 文件），不再每次求值都写（P7 的写法只是重复覆盖）。例外：dataset/reaction 模式在搜索前先写一次样条，因为孤立原子的参考能量由 DFTB 引擎在这一步的 SKF 上计算，DFTB+ 拒绝没有样条排斥的文件（孤立原子没有排斥，写哪个 σ 都一样）。排斥能与旧路径一样只写给有结果的结构的元素。
  • 日志：par.out 每个类型 r0w、r0d、σrep 三列，再加罚项与 μ；log.out 同样的类型列，再加 μE、μV（dataset/reaction 为 μF）、μB、罚项、μ。

检查点

  • LOSS_VERSION = 3：按类型的布局，checkpoint.pkl.meta.json 记下布局、参数集（名字、类型、半径）、固定类型与切换；续跑时必须相同，否则拒绝（维数或含义不同的点会破坏 BO 的模型）。
  • 旧布局仍写、仍检查版本 2（SHARED_LOSS_VERSION），已有的单元素检查点照常续跑；tools/rescale_checkpoint.py 转换出的也是版本 2。

四、hotcent、physrep 与 DFTB 引擎

hotcent（utils/hotpy.py、utils/hotcent_parallel.py）

  • hotpy.set_variables(..., elements={标签: 元素})：每个标签的原子按它的元素（组态、价层、PTBP 表的 on-site 能、U、占据数）和它自己的约束计算；表按标签对计算，文件按标签命名。没有标签时调用与文件都不变。
  • 同一元素的两个标签（Cu-Cu2）：hotcent 2.1 当作一个原子（只算一个方向、只取第一个原子的波函数范围、按元素名写带 on-site 行的文件）。新的 ShardedCross 两个方向都算、取两个原子的范围（与 make_cu_types_set.CrossTable 相同，行照样分片并逐位重放），两个文件用 hotcent 的 write_skf 按异核格式写出（没有 on-site 行）。
  • 不同元素的标签对（N2-B）：hotcent 按元素名写到临时目录，再按标签改名。
  • 参考实现（PTBP_HOTCENT_REFERENCE 或别的 hotcent 版本）按元素命名文件，遇到标签时报错。
  • generate_all(..., only=标签集)：只算涉及这些标签的表（梯度的切向用，第五节）。

physrep（tools/physrep.py）

  • physrep(labels, ..., numbers={标签: 原子序数})：键可以是标签，核电荷与共价半径按原子序数，文件 Cu2-Cu.skf；键是原子序数时运算逐位不变。按元素的参数（没有切换）就是原来的 physrep，每个元素自己的 σ（它本来就收每个元素一个 scale_cov）。
  • 切换：switched_physrep 包住按标签的 physrep。evaluate_pbc 用 pydftb.typeswitch 自己的 setup（CN 与权重）、mixed_repulsive（Erep = ½Σ有序对ΣtuwA,twB,uVtu(r)，固定权重的梯度与 ∂E/∂w）和 weight_gradient（权重随几何变化的那部分力），只把 physrep 的样条包成 pydftb 的排斥能接口（截断与 0.01 Bohr 的下限同 evaluate_pbc）。权重只依赖几何，按结构缓存。dftb_full.xyz 另存每个原子的类型权重 type_weight_<标签>。

DFTB 引擎（utils/engines.py）

  • set_type_switching(switches)：进程级设置（分叉的工作进程继承），不放进 settings()，所以不用切换时 settings()、plan.json 都不变。pydftb 的计算器收到 type_switching，原子仍用元素名（M5a 的约定）。
  • DFTB+ 经 ASE 只能写元素名、每个原子一种类型：有切换时 make_calculator 报错，cli/run.py 在开始前就以同样的说明退出。按元素的参数（没有切换）两个引擎照常可用。torch 后端也拒绝（M5a 的切换只在 NumPy 引擎中）。

五、梯度优化器

  • 方向：每个参数集两个方向（维名同上）。hotcent_tangent.compute_types 对一个方向只移动该参数集的半径、只重算涉及它的类型的表，其余文件复制自这一步本身，所以它们的差分恰为零（“每个类型只动自己的表”）。r0d 的探测按参数集与运行设置各做一次。
  • 包络定理：μ*(x) = minσ μ(x, σ)。在联合最优 σ* 处，光滑时 ∇σμ = 0，在边界上的分量保持在边界，都有 dμ*/dx = ∂μ/∂x。
  • 折点的推广：μ 是 P Σ wj|rj| 的形式，σ* 常落在若干残差 K 的折点上（rK(x, σ*) = 0）。这时 σ* 是 μ̃ = P Σj∉K wj|rj| 在 rK = 0 上的极小，在自由分量上 ∇σμ̃ + JKTλ = 0（JK = ∂rK/∂σ），由约束优化的包络定理 dμ*/dx = ∂μ̃/∂x + λ·∂rK/∂x。λ 用最小二乘求出，残差大时在 grad.out 中注明。一个 σ、一个折点时 λ = −(∂μ̃/∂σ)/(∂rk/∂σ)，正是 M4c 的修正（测试逐位比较）。力残差的折点：ΣkλkḞk 用一遍第二遍计算（权重为 λ）得到。
  • σ* 的精确化：在 PTBP 的 σ̂（ftol 1e-3）附近，以 1e-3 的小单纯形做有界 Nelder–Mead（xatol 1e-11），再对检测到的折点残差做几步 Newton（自由分量上的最小二乘），使它们恰为零；然后按 σ* 分类（光滑、折点、边界）。
  • 切换：pydftb.autodiff 没有混合块与权重项，声明了多类型时 --optimizer gradient/bo_grad 报错，只能用 BO、并行 BO 或 PSO。

六、命令行、YAML 与界面

ptbp optimize data.xyz                         # 多元素：默认每个元素一套参数
ptbp optimize data.xyz --shared-parameters     # 所有元素一套参数（M5b 之前的做法，逐字节相同）
ptbp optimize cu.xyz --engine pydftb --switch Cu Cu2,Cu 11.0 1.0 \
     --type-start Cu2 2.749 12.036             # Cu 分成 Cu2（低配位）与 Cu（高配位）两个类型
ptbp optimize cuo.xyz --multi-element Cu       # 只拟合 Cu，O 用 PTBP 发表的参数
  • --switch ELEMENT LABELS CENTRE WIDTH（可重复）：标签按 CN 从小到大，CENTRE、WIDTH 每个窗口一个（逗号分隔）；计数窗口默认（1.1/1.3 倍共价半径之和），YAML 中可给 cutoff（Bohr）。
  • YAML：shared_parameters: true；types: [{element: Cu, labels: [Cu2, Cu], centre: 11.0, width: 1.0, cutoff: ..., start: {Cu2: [2.749, 12.036]}}]；type_start: [[Cu2, 2.749, 12.036]]。ptbp_run.yaml 写回合并后的声明；不用这些选项时它不多出任何键。
  • 旧的平铺命令行：--shared_parameters、--types JSON、--type_start LABEL R0_W R0_D。
  • 界面（TUI）第 6 步：参数“每个元素 / 共用”的单选，以及切换类型的输入框（Cu:Cu2,Cu:11.0:1.0）。
  • ptbp plan --switch …：计划按类型标签数 hotcent 的表（Cu 两类型 3 张，单类型 1 张）；--multi-element 不再减少表数（固定类型的表每步也要算）。

九、不做的事与风险

  • 不做：切换窗口的拟合（固定超参数）；数据集中逐原子的固定类型标签（类型只由切换决定）；DFTB+ 的多类型（ASE 不能写标签）；切换的梯度（需要先给 pydftb.autodiff 加混合块与权重项）；bandstructure 模式。
  • 损失的含义：energygeometry 的 μE 只比较每个 EOS 组内的相对能量，Boltzmann 权重 < 0.1 的组不进入损失（P4）。多类型的价值在于跨配位的可转移性，而这个损失只部分地检验它；是否为多类型改变权重或改用 dataset 模式，需要用户决定（报告列出）。
  • 代价：维数从 2 变成 2N，BO 需要更多次调用（skopt 默认先取 10 个随机点）；σ 的搜索每步约 12 + 42N 次求值（第二轮格子没有改进时；每次在内存中，约 0.1 s）；两类型的 hotcent 约为单类型的 3.5 倍。
  • 默认行为的改变：多元素数据集的默认结果改变（用户的决定）；--multi_element 的含义改为“只拟合这些元素，其余用 PTBP 表”（原来的路径跑不通）；dftb_full.xyz 的元素顺序修正。
