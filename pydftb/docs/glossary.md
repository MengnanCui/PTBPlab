# 名词小词典

报告和文档中的专业词，在这里集中用通俗的话解释一遍。

## DFTB 物理

| 名词 | 通俗解释 |
|---|---|
| DFTB | 密度泛函紧束缚，是 DFT（第一性原理计算）的快速近似版。速度快 100–1000 倍，精度稍低。 |
| SKF（Slater-Koster 文件） | DFTB 的参数表，记录两个原子在不同距离下的相互作用数值，`A-B.skf` 存放元素（或类型）A 与 B 之间的数据。PTBP 生成的就是这种文件。 |
| 同核 / 异核 SKF | `A-A.skf` 比 `A-B.skf` 多一行，存放原子本身的能级、U 和电子数。DFTB+ 判断是否同核看的是**物种名**，不是元素。 |
| 轨道 s / p / d / f | 原子里电子的不同“形状”。d 轨道主要出现在过渡金属（如铜），f 轨道出现在镧系、锕系元素。 |
| 最高角动量（max_l） | 计算中每种原子用到哪些轨道：0 表示只有 s，1 表示 s+p，2 表示 s+p+d。ASE/PTBP 取“占据数不为 0 的最高轨道”。 |
| 矩阵 H、S | 把整个体系的电子相互作用写成的两张大表。边长约等于所有原子的轨道数之和。 |
| Slater-Koster 变换（旋转） | SKF 里存的是“两个原子沿 z 轴排列”时的数值，计算时要按实际成键方向转过去。 |
| 对角化 / 本征分解 | 从 H、S 中解出电子能级的标准数学操作，计算量随矩阵边长的三次方增长。 |
| SCC（电荷自洽） | 电子分布和电荷互相影响，需要反复迭代直到不再变化，一般 10–20 轮。 |
| 混合器（Pulay / Anderson / Broyden） | 让电荷自洽更快收敛的技巧：把前几轮的结果加权组合，猜出下一轮的输入。DFTB+ 默认用改进 Broyden。 |
| Hubbard U | 原子多容纳一个电子要付出的能量代价，从 SKF 中读取。 |
| γ（gamma）函数 | 描述两个原子上的多余电荷之间相互作用强度的函数。距离远时趋于 1/R，距离近时由 U 决定。 |
| Ewald 求和 | 计算晶体中无穷远静电相互作用的标准方法。 |
| Mulliken 电荷 / 布居 | 每个原子（或每个轨道）分到多少电子的一种算法。 |
| 排斥势 | 两个原子靠得太近时互相推开的那部分能量。存放在 SKF 末尾，有样条和多项式两种形式。 |
| k 点 / Γ 点 | 晶体计算中对周期性的采样点。只取一个点（Γ 点）最快，大体系通常这样做。 |
| 时间反演约化 | k 和 −k 两个点算出的能级相同，所以只需算一半的 k 点。 |
| 电子温度 / 展宽 | 给电子一个“温度”，让金属计算更容易收敛。有 Fermi、Methfessel-Paxton（MP）、Gaussian 等几种方式。 |
| Total / Mermin / Extrapolated 能量 | DFTB+ 报告的三种总能：Total 是总能量；Mermin 自由能是 Total − TS（TS 为电子熵贡献）；“外推到 0 K”是 Total − TS/2。 |
| 费米能级 | 电子填到的“水位线”。DFTB+ 在有带隙时把它放在带隙中间。 |
| 应变 | 把整个晶体均匀拉伸、压缩或剪切的比例，例如拉长 1% 就是应变 0.01。 |
| 应力 / 压强 | 晶体“想变大还是变小”的程度，等于能量对应变的导数除以体积。ASE 的约定是负值表示被压缩、想膨胀，单位 eV/Å³（1 eV/Å³ ≈ 160 GPa）。DFTB+ 的单位是 Hartree/Bohr³（1 Ha/Bohr³ ≈ 29,400 GPa），符号与 ASE 相反。 |
| 维里（virial） | 能量对应变的导数（3×3 矩阵），应力 = −维里 / 体积（DFTB+ 的符号）。算法上就是把每一对原子之间的“力 × 键矢量”加起来。 |
| 晶格优化 | 同时调整原子位置和晶胞的形状、大小，直到力和应力都接近零，得到平衡晶格常数。 |
| 网格节点 / 插值窗口 | SKF 表格每隔 0.02 Bohr 存一个数，这些点叫节点。节点之间的值用相邻 8 个节点拟合出的多项式来估计，这个范围叫插值窗口。每越过一个节点就换一个多项式，所以数值连续，但斜率有极小的跳变。 |

## 软件与数值

| 名词 | 通俗解释 |
|---|---|
| 类型标签（label） | 告诉程序每个原子用哪套参数。通常就是元素名；同一元素要用多套参数时，起不同的名字，如 `Li1`、`Li2`（DFTB+ 和 ASE 的约定），也支持 `Li_el`、`Li@el` 这类写法。 |
| ParamSet | pydftb 中“参数从哪里来”的对象：一个 SKF 目录加上读取选项。 |
| System | pydftb 中“算什么”的对象：原子的类型标签、元素、坐标、晶胞、总电荷。 |
| 复步长求导 | 一种数学技巧：给输入加一个极小的虚数扰动，从结果的虚部直接得到导数，精度可以达到计算机能表示的极限。 |
| 有限差分 | 用两个相距很近的点上函数值之差除以它们的距离来估计导数。DFTB+ 用这种方法求 H、S 的导数，步长 1.22e-4 Bohr；两个点若落在不同的插值窗口里，误差会变大。 |
| 冻结的参考数据 | 先用 DFTB+ 算好标准答案存成 JSON 文件。之后测试只需要 pydftb，不必安装 DFTB+。 |
| ops 分发层 | 物理代码通过它调用少数几个与硬件相关的操作（累加、本征分解等），换成 GPU 时只需替换这一层。 |
| SP2 纯化 | 只用矩阵自乘（约 20 次）代替对角化的方法，适合 GPU。 |
| 稀疏矩阵 / 线性标度 | 只存储、只计算非零元素，计算量随原子数一次方增长，而不是三次方。 |
| FP64 / FP32、混合精度 | 双精度（约 16 位有效数字）和单精度（约 7 位，快约 2 倍）。先用单精度算，再用双精度修正。 |
| MPI / OpenMP / OpenBLAS | 三种并行：多台机器之间（MPI）、一台机器的多核之间（OpenMP）、数学库内部的多线程（OpenBLAS）。 |
| 线程超订 | 开的线程比 CPU 核心多，线程互相抢资源，结果反而更慢。 |
| ParserVersion | DFTB+ 输入格式的版本号。版本过低时，DFTB+ 会按旧规则悄悄改写某些设置。 |
| PyTorch | 一个支持 GPU 和自动求导的 Python 数值库，计划作为 pydftb 的加速后端。 |
| 自动求导 | 程序在计算结果的同时，自动算出结果对每个输入参数的导数。 |
| 贝叶斯优化（BO） | PTBP 目前用的参数搜索方法。不需要导数，但每试一组参数都要重算全部结构。 |
