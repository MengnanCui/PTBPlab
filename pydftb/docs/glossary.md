# 名词小词典

报告和文档中的专业词，在这里集中用通俗的话解释一遍。

## DFTB 物理

| 名词 | 通俗解释 |
|---|---|
| DFTB | 密度泛函紧束缚，是 DFT（第一性原理计算）的快速近似版。速度快 100–1000 倍，精度稍低。 |
| SKF（Slater-Koster 文件） | DFTB 的参数表，记录两个原子在不同距离下的相互作用数值，`A-B.skf` 存放元素（或类型）A 与 B 之间的数据。PTBP 生成的就是这种文件。 |
| 同核 / 异核 SKF | `A-A.skf` 比 `A-B.skf` 多一行，存放原子本身的能级、U 和电子数。DFTB+ 判断是否同核看的是**物种名**，不是元素。 |
| 轨道 s / p / d / f | 原子里电子的不同“形状”。d 轨道主要出现在过渡金属（如铜），f 轨道出现在镧系、锕系元素。 |
| 最高角动量（max_l） | 计算中每种原子用到哪些轨道：0 表示只有 s，1 表示 s+p，2 表示 s+p+d。ASE/PTBP 取“占据数不为 0 的最高轨道”。 |
| 矩阵 H、S | 把整个体系的电子相互作用写成的两张大表。边长约等于所有原子的轨道数之和。 |
| Slater-Koster 变换（旋转） | SKF 里存的是“两个原子沿 z 轴排列”时的数值，计算时要按实际成键方向转过去。 |
| 对角化 / 本征分解 | 从 H、S 中解出电子能级的标准数学操作，计算量随矩阵边长的三次方增长。 |
| SCC（电荷自洽） | 电子分布和电荷互相影响，需要反复迭代直到不再变化，一般 10–20 轮。 |
| 混合器（Simple / Anderson / DIIS / Broyden / Pulay） | 让电荷自洽更快收敛的技巧：把前几轮的结果加权组合，猜出下一轮的输入。Simple 只按固定比例走一步；Anderson、DIIS、Broyden 用前几轮的“输入—输出差”外推。DFTB+ 默认用改进 Broyden，四种都已逐轮照抄（M1、M6f-1）；Pulay 是 pydftb 原有的一种，M6f 前叫 "anderson"。 |
| SCC 误差（SCC error） | 每轮 SCC 输出与输入布居之差的最大绝对值，DFTB+ 在每轮打印它，小于容差就算收敛。pydftb 的 `DFTBResult.scc_errors` 是同一个量，M6f-1 起逐轮与 DFTB+ 对照。 |
| 初始电荷 / 初始自旋 | SCC 的起点。DFTB+ 的 `InitialCharges` 给每个原子一个净电荷，电子按壳层顺序逐层填满（aufbau），不是平均分；`InitialSpins` 给每个原子一个自旋，按壳层的布居比例分下去。只影响收敛的快慢，不影响解（除非体系有几个解，例如铁磁和反铁磁）。 |
| 电荷重启文件（charges.bin / charges.dat） | DFTB+ 把最后一轮的输入布居写到这个文件，下一次计算用 `ReadInitialCharges` 从它开始。`.bin` 是 Fortran 的二进制流，`.dat` 是同样内容的文本。pydftb 读写两种格式，文本与 DFTB+ 写的逐字节相同（M6f-1）。 |
| list-directed 输出 | Fortran 用 `write(unit, *)` 写数时的默认格式，每个编译器自己决定宽度和位数。DFTB+ 的 charges.dat 就是这样写的；gfortran 给实数 17 位有效数字，所以文本文件能无损地还原二进制的值。 |
| Hubbard U | 原子多容纳一个电子要付出的能量代价，从 SKF 中读取。DFTB+ 的 `CustomisedHubbards`（pydftb 的 `hubbard`，M6f-2）可以在输入里换掉它。 |
| γ（gamma）函数 | 描述两个原子上的多余电荷之间相互作用强度的函数。距离远时趋于 1/R，距离近时由 U 决定。 |
| Ewald 求和 | 计算晶体中无穷远静电相互作用的标准方法。 |
| Mulliken 电荷 / 布居 | 每个原子（或每个轨道）分到多少电子的一种算法。 |
| 排斥势 | 两个原子靠得太近时互相推开的那部分能量。存放在 SKF 末尾，有样条和多项式两种形式。 |
| k 点 / Γ 点 | 晶体计算中对周期性的采样点。只取一个点（Γ 点）最快，大体系通常这样做。 |
| 时间反演约化 | k 和 −k 两个点算出的能级相同，所以只需算一半的 k 点。 |
| 电子温度 / 展宽 | 给电子一个“温度”，让金属计算更容易收敛。有 Fermi、Methfessel-Paxton（MP）、Gaussian 等几种方式。 |
| Total / Mermin / Extrapolated 能量 | DFTB+ 报告的三种总能：Total 是总能量；Mermin 自由能是 Total − TS（TS 为电子熵贡献）；“外推到 0 K”是 Total − TS/2。 |
| 费米能级 | 电子填到的“水位线”。DFTB+ 在有带隙时把它放在带隙中间（k 点权重有舍入时 DFTB+ 偶尔放偏，pydftb 仍取中点，见 M2e 报告）。 |
| 固定费米能级 / 电子库 | 不规定电子数，而是规定费米能级（DFTB+ `FixedFermiLevel`）：体系好像连着一个电极，电子可以进出，电子数由自洽决定。这时力对应的能量是“力相关能量” E<sub>FR</sub> = F − N·E<sub>f</sub>（共线自旋时上、下各算一项），不是 Mermin 自由能（M6f-2）。 |
| 力相关能量（Force related energy） | 力是它的负梯度的那个能量。平常就是 Mermin 自由能 F；固定费米能级时是 F − Σ N<sub>s</sub>E<sub>f,s</sub>（巨势）。DFTB+ 写在 detailed.out 的 “Force related energy”，results.tag 的 `mermin_energy` 在固定费米能级时写的也是它；pydftb 为 `DFTBResult.e_force_related`（M6f-2）。 |
| 按 k 点独立填充 | 周期体系中每个 k 点各自放入全部电子、各有自己的费米能级（DFTB+ `IndependentKFilling`），而不是所有 k 点共用一个费米能级；报告的费米能级是各 k 点的加权平均（M6f-2）。 |
| 虚拟掺杂（自定义参考占据） | 改变某些原子的“中性参考”电子数 q<sub>0</sub>（DFTB+ `CustomisedOccupations`），例如让 O 的 p 壳层参考 4.2 个电子：体系多出 0.2 个电子，但仍算“电中性”，Mulliken 电荷相对于新的 q<sub>0</sub>（M6f-2）。 |
| SK 表截断 | 把 Slater-Koster 表中某个距离以外的 H、S 积分去掉（DFTB+ `TruncateSKRange`），排斥势不动。用于测试截断的影响，DFTB+ 自己警告“通常是个坏主意”（M6f-2）。 |
| 中和背景（带电晶胞） | 周期体系带净电荷时，Ewald 求和的总静电能无穷大，通常的做法是加一个均匀的反号电荷“背景”。背景的能量与晶胞体积有关，所以也贡献应力；DFTB+ 的应力在这里与它的能量不一致（M6f-2 发现）。 |
| 能带 / 能带图 | 晶体中电子能级随 k 点连续变化形成的“带”。沿布里渊区中一条折线（k 路径）把能级画出来，就是能带图，可以看出带隙、金属性和简并。 |
| k 路径 / 高对称点 | 能带图横轴上的折线，连接布里渊区里的特殊点（Γ、X、L 等）。DFTB+ 用 `Klines` 指定：每段给出终点和段内点数。ASE 的 `BandPath` 能自动给出各种晶格的标准路径。 |
| 冻结电荷 | 先在均匀的 k 网格上做完 SCC，再把电荷固定，只在别的 k 点上建一次 H、对角化一次。画能带都这样做，因为路径上的点不适合求电荷。 |
| 态密度（DOS） | 每个能量附近有多少个电子态。把每个能级换成一个窄峰（展宽），再加起来得到连续曲线，单位是“态 / eV”。 |
| 投影态密度（PDOS） | 把 DOS 按原子、壳层或轨道拆开：每个态按它在这些轨道上的份额加权。例如 Cu 的 d-PDOS 显示 d 带的位置。DFTB+ 的份额定义为 Re[c*·(S c)]。 |
| 区域（Region） | DFTB+ `ProjectStates` 中“一组原子（可再按壳层或轨道拆分）”，每个区域写一个文件，记录每个态在区域上的份额。 |
| 玻尔兹曼常数 | 把温度（K）换算成能量（Hartree）的系数。pydftb 自 M2e 起与 DFTB+ 25.1 用同一个值（3.16681534524639e-6 Ha/K）。 |
| DFTB3（三阶项） | 让原子的硬度 U 随它带的电荷变化，从而修正 DFTB2 对带电体系、质子转移、氢键的描述。3ob 参数集是为它拟合的。 |
| Hubbard 导数 Uᵈ | U 随电荷变化的斜率：U(q) = U + Uᵈ·Δq。DFTB3 的输入参数，3ob 中 H、C、O 分别为 −0.1857、−0.1492、−0.1575。 |
| H–X 阻尼 | 对含氢原子对的短程相互作用乘一个随距离衰减的因子，改善氢键。DFTB+ 写作 `HCorrection = Damping { Exponent = 4.0 }`。 |
| H5 修正 | 另一种改善氢键的办法（DFTB+ `HCorrection = H5`）：H 与 O、N、S 之间的 γ 乘以 1 + g(r)，g 是一个钟形（高斯）函数，峰在约 0.7 倍范德华半径和处，只在氢键的距离上起作用。与 DFTB3、D3 色散一起用就是已发表的 DFTB3-D3H5 模型（M6f-3）。 |
| 范德华半径 | 原子“表面”的半径，两个原子的范德华半径之和大致是它们不成键时能靠多近。H5 与卤素修正都用 Mantina 等人的表（DFTB+ 的 `vdwdata.F90`），例如 H 1.20 Å、O 1.52 Å、Cl 1.75 Å（M6f-3）。 |
| 卤素修正 | DFTB3 低估 O、N 与 Cl、Br、I 之间的排斥（卤键距离偏短），DFTB+ 的 `HalogenXCorr` 加一个只依赖距离的对势补上；在 0.7–0.8 倍范德华半径和之间用多项式平滑地打开（“开关函数”）。DFTB+ 在开关区间内的力有符号错误，pydftb 给出正确的力（M6f-3）。 |
| 开关函数 | 让一项修正在一段距离内从“关”平滑过渡到“开”的函数，例如 σ(x) = −20x⁷ + 70x⁶ − 84x⁵ + 35x⁴：x = 0 时为 0，x = 1 时为 1，两端的前三阶导数都为 0，所以能量和力都连续。 |
| 偶极修正（平板） | 用周期晶胞计算表面（平板 + 真空层）时，如果平板两侧不对称、沿法向有偶极，周期像之间会产生人为的电场。DFTB+ 的 `DipoleCorrection` 在真空中放一层反向的偶极把它抵消，能量 2πD²/V 记在 SCC 能量里（D 是晶胞沿法向的偶极，V 是体积）。25.1 之后的版本才有；DFTB+ 没有给它的应力项，pydftb 补上了（M6f-3）。 |
| 自旋极化 / 磁矩 | 自旋向上和向下的电子数不相等。每个原子的磁矩 = N↑ − N↓。O₂ 基态是三重态，有 2 个未配对电子。 |
| 自旋常数 W | 描述同一原子上自旋不平衡时能量降低多少的参数，为负值；可以每种原子一个数，也可以按壳层组成矩阵。 |
| 应变 | 把整个晶体均匀拉伸、压缩或剪切的比例，例如拉长 1% 就是应变 0.01。 |
| 应力 / 压强 | 晶体“想变大还是变小”的程度，等于能量对应变的导数除以体积。ASE 的约定是负值表示被压缩、想膨胀，单位 eV/Å³（1 eV/Å³ ≈ 160 GPa）。DFTB+ 的单位是 Hartree/Bohr³（1 Ha/Bohr³ ≈ 29,400 GPa），符号与 ASE 相反。 |
| 维里（virial） | 能量对应变的导数（3×3 矩阵），应力 = −维里 / 体积（DFTB+ 的符号）。算法上就是把每一对原子之间的“力 × 键矢量”加起来。 |
| 晶格优化 | 同时调整原子位置和晶胞的形状、大小，直到力和应力都接近零，得到平衡晶格常数。 |
| 结构优化 | 沿着力的方向一步步移动原子，直到每个原子受的力都接近零，得到稳定结构。常用的算法有 BFGS、LBFGS（用前几步的信息估计曲率）和 FIRE（模拟带阻尼的运动）。 |
| 分子动力学（MD） | 按牛顿方程一步步推进原子的位置和速度，模拟原子随时间的运动。每一步都要算一次力。 |
| 速度 Verlet | 最常用的 MD 积分算法：先用当前的力把速度推进半步、移动原子，再用新位置的力把速度推进另外半步。 |
| NVE | 原子数、体积、总能量都不变的 MD（不加热浴）。总能量是否守恒是检验力是否准确的好办法。 |
| 能量漂移 | 长时间 NVE 模拟中总能量的缓慢变化。力与能量的导数不一致（例如数值求导的误差）或时间步太大都会造成漂移。 |
| 输入电荷 / 输出电荷 | SCC 每一轮用一组电荷（输入）建哈密顿量，解出的电子分布给出另一组电荷（输出）。收敛时两者几乎相同；没完全收敛时，DFTB+ 用输出电荷算力。 |
| 电荷复用 | 结构优化或 MD 中，下一步的 SCC 从上一步收敛的电荷开始，而不是从中性原子开始，可以省掉大部分 SCC 迭代。 |
| 质心运动 | 整个体系一起平移。MD 中通常去掉，否则体系会整体“飘走”。 |
| 色散（范德华吸引） | 原子之间电子云瞬时涨落引起的弱吸引，距离远时按 1/R⁶ 衰减。DFTB 本身缺这一项，所以在总能量上加一个只依赖原子位置的经验修正。 |
| C6 系数 | 色散吸引 −C6/R⁶ 中的系数，原子越大、越容易被极化，C6 越大。D3/D4 让 C6 随原子的配位环境（和 D4 中的电荷）变化。 |
| 阻尼函数（BJ / 零阻尼） | 原子靠得很近时 1/R⁶ 会发散，阻尼函数让修正在短程平滑地减弱。Becke-Johnson（BJ）把它压到一个有限值，零阻尼把它压到 0。 |
| 三体项（ATM） | Axilrod-Teller-Muto 项：三个原子同时极化产生的修正，一般是小的排斥。计算量大，DFTB+ 默认关闭。 |
| 配位数（CN） | 一个原子周围“算作成键”的邻居数，用平滑的计数函数求得，可以是小数。D3/D4 据此在几个参考体系之间插值 C6。 |
| EEQ 电荷 | 电负性均衡模型：按电负性和硬度快速估计每个原子的电荷，D4 用它让 C6 随电荷变化。 |
| UFF / Lennard-Jones | UFF 是通用力场，给每种元素一个范德华半径和阱深；Lennard-Jones 势是 r⁻¹² 排斥加 r⁻⁶ 吸引的经典形式。 |
| Slater-Kirkwood 公式 | 由两个原子的极化率和有效电子数估计 C6 的经典公式，DFTB 早期的色散修正（Elstner 2001）用它。 |
| 网格节点 / 插值窗口 | SKF 表格每隔 0.02 Bohr 存一个数，这些点叫节点。节点之间的值用相邻 8 个节点拟合出的多项式来估计，这个范围叫插值窗口。每越过一个节点就换一个多项式，所以数值连续，但斜率有极小的跳变。 |
| f 轨道 | 角动量 l = 3 的原子轨道，每个壳层 7 个。镧系、锕系元素有部分填充的 4f 或 5f 壳层，磁性和化学性质主要由它决定。pydftb 自 M2g 起支持。 |
| 扩展 SKF 格式 | 带 f 轨道的 SKF：第 1 行是 `@`，在位行多出 f 的在位能、U 和占据数，积分表每行 40 个数（H、S 各 20 个，含 sf…ff）。不带 f 的元素仍可用原来的简单格式，两种可以混用。 |
| 实球谐函数 | 原子轨道角度部分的实数形式，例如 p 轨道的 x、y、z，d 轨道的 xy、z² 等。DFTB+ 规定了每个壳层内的排列顺序，pydftb 与它相同。 |
| 无迹对称张量 | 把一个 l 次的实球谐函数写成 l 阶张量（例如 xyz 对应一个三阶张量），对称、且任意两个指标求迹为 0。轨道旋转时张量的每个指标都乘同一个旋转矩阵，pydftb 用它统一算 p、d、f 轨道的旋转。 |
| 非共线自旋 | 每个原子的磁矩是一个三维向量，方向可以各不相同（共线自旋只有“向上、向下”两个方向）。没有自旋轨道耦合时，所有磁矩一起转动能量不变（M6a）。 |
| 自旋轨道耦合（SOC） | 电子的自旋与它绕原子核的轨道运动之间的相互作用，H<sub>SO</sub> = ξ L·S，ξ 每个壳层一个。重元素中更强，会让能级分裂（例如 d 带在 Γ 点分成 4 + 2 重），并让磁矩倾向特定方向（M6a）。 |
| 两分量（旋量）计算 | 每个轨道带上“向上”“向下”两个自旋分量，矩阵边长加倍为 2N。非共线自旋和自旋轨道耦合都要这样算（M6a）。 |
| Pauli 分量 | 两分量计算中的量都写成四部分：电荷 q 和磁化的三个方向 m<sub>x</sub>、m<sub>y</sub>、m<sub>z</sub>（对应单位矩阵和三个 Pauli 矩阵）。DFTB+ 的混合向量、布居、势都按这四个分量存储（M6a）。 |
| onsite / dual 模型 | DFTB+ 加自旋轨道耦合的两种方式。onsite 只加在同一原子的轨道块上；dual（默认）把它当作作用在原子上的“块势”，再乘重叠矩阵，因此也作用到相邻原子之间，并带来一个力的贡献（M6a）。 |
| Kramers 简并 | 没有磁场或磁化时，每个能级都至少两重简并（一个态和它的时间反演态）。简并对里的态可以任意混合，单个态的自旋方向因此没有确定的意义，只有整对的总和有意义（M6a）。 |
| 轨道角动量 ⟨L⟩ | 电子绕原子核运动的角动量，自旋轨道耦合下不再为零。DFTB+ 在 detailed.out 中按壳层列出它对应的磁矩 −⟨L⟩（M6a）。 |
| 块布居（dual Mulliken 布居） | 同一原子上任意两个轨道之间“共享”的电子数，排成一个小矩阵；对角元就是普通的逐轨道 Mulliken 布居。算法是 ½(ρS + Sρ) 取该原子的块。DFTB+U、onsite 修正和 dual 模型的 SOC 都依赖它。 |
| 块势 | 作用在同一原子整个轨道块上的势，不只是每个轨道一个数。它以 ½(SV + VS) 的形式进入哈密顿量，所以也影响相邻原子之间的矩阵元，力中多出一项。普通的电荷势、自旋势是块势为对角阵的特例。 |
| DFTB+U | 对局域的 d、f 电子加一个 U − J 修正（取自 LDA+U），让这些壳层的电子更倾向于整数占据：FLL（完全局域极限，DFTB+ 默认）压低已占态、抬高空态；pSIC（赝自相互作用修正）只压低已占态。DFTB+ 中写作 `OrbitalPotential`，U − J 要用户给出。 |
| U − J | DFTB+U 的唯一参数：库仑排斥 U 减去交换 J 的有效值，每组壳层一个。Cu、Ni 的 3d 常取 4–8 eV（0.15–0.3 Ha）。注意它与 SCC 中的 Hubbard U 是两回事。 |
| onsite 修正 | 补上 DFTB 忽略的“同一原子上不同轨道之间”的交换积分，改善氢键等（Domínguez 等，2015）。每种元素两个常数矩阵：同自旋 f<sub>uu</sub> 和异自旋 f<sub>ud</sub>；DFTB+ 手册给出 H、C、N、O、S、Ti、Au 的 PBE 值，pydftb 收录为 `ONSITE_PBE`。 |
| 等价类（混合） | SCC 混合时把哪些轨道的布居合在一起算一个数。没有块势时按原子或壳层；有 +U 时被修正的轨道各自单独混合，有 onsite 时所有轨道都单独混合，块的非对角元也加入混合向量。要与 DFTB+ 逐轮一致，混合的量必须完全相同。 |
| 外电场 | 均匀电场 E 作用在原子的 Mulliken 电荷上：原子 A 处的势是 r<sub>A</sub>·E，能量为 Σ Δq<sub>A</sub> r<sub>A</sub>·E。分子的偶极矩等于能量对电场的导数取负（M6c）。 |
| 锯齿势 | 均匀电场的势 r·E 不是周期函数。DFTB+ 在周期体系中先把原子坐标折回晶胞再算 r·E，势在晶胞边界上跳变一次，形状像锯齿。原子跨过边界时能量会跳变，所以 DFTB+ 和 pydftb 都给出警告；只有电场方向上留有足够厚的真空层时结果才有意义（M6c）。 |
| 点电荷嵌入（静电嵌入） | 把周围环境（溶剂分子、蛋白质等）表示成固定的点电荷，它们的静电势进入 DFTB 的哈密顿量，使电子云被极化。这是 QM/MM 最常用的耦合方式。pydftb 同时给出点电荷受的力，供 MM 部分使用（M6c）。 |
| 高斯展宽（点电荷） | 把点电荷换成宽度为 σ 的高斯分布，势从 1/r 变为 erf(r/σ)/r，近距离处不再发散，避免电子被紧挨着的点电荷过度吸引（M6c）。 |
| Gross / Net 格点势 | DFTB+ 中直接加在指定原子上的常数势（`AtomSitePotential`）。Gross 作用在原子的 Mulliken 总布居上（含与邻居共享的一半），效果类似一个局部电场；Net 只作用在原子自身的“净”布居（密度矩阵在该原子上的对角块），只改哈密顿量的对角元，没有力的贡献（M6c）。 |
| 隐式溶剂 | 不显式放入溶剂分子，而把溶剂看作连续的介电介质，用溶剂化自由能描述它对溶质的作用。DFTB+ 和 pydftb 的模型由三部分组成：静电部分（广义 Born）、空腔与色散部分（SASA）和氢键修正（M6c）。 |
| 广义 Born（GB） | 隐式溶剂静电部分的近似：把每个原子看作带电的球，放在介电常数为 ε 的溶剂中，原子 A、B 之间的作用为 −½(1 − 1/ε) q<sub>A</sub>q<sub>B</sub>/f<sub>GB</sub>。f<sub>GB</sub> 在远处趋于原子间距离，在近处趋于 Born 半径。Still 和 P16 是 f<sub>GB</sub> 的两种写法（M6c）。 |
| Born 半径 | 原子在分子中被“埋”得多深的有效半径：被其他原子包围得越多，半径越大，溶剂对它的屏蔽越弱。由原子的范德华半径和邻居的遮挡（descreening）按 GBOBC-II 公式算出（M6c）。 |
| ALPB | 解析线性 Poisson–Boltzmann 模型（Sigalov 等，2006）：在广义 Born 上加一项与分子形状有关的修正，对介电常数小的溶剂和带电分子比 GB 更准。GFN-xTB 的溶剂模型也用它（M6c）。 |
| SASA（溶剂可及表面积） | 溶剂分子（看作一个探针球）能接触到的分子表面积。每个原子的 SASA 乘以一个表面张力系数，近似空腔形成与色散的自由能。pydftb 与 DFTB+ 一样在每个原子的球面上用 Lebedev 网格数值积分，并把表面平滑化，使能量可导（M6c）。 |
| Lebedev 网格 | 球面上的一组点和权重，能精确积分到一定阶数的球谐函数。SASA 在每个原子的球面上取这些点，判断它们是否被其他原子遮住（M6c）。 |
| 氢键修正（隐式溶剂） | 按原子的 SASA 和电荷平方给出的额外溶剂化能，模拟溶质与溶剂之间的氢键。每种元素的强度取自 DFTB+ 的溶剂参数文件（M6c）。 |
| CM5 电荷 | Charge Model 5（Marenich 等，2012）：在 Hirshfeld 或 Mulliken 电荷上加一项只与几何有关的修正，使电荷给出的偶极更接近实验。溶剂模型可以选择用 CM5 修正后的电荷计算 Born 能（M6c）。 |
| 参考态（溶剂化自由能） | 溶剂化自由能的标准态约定，DFTB+ 有三种：`gsolv`（气相和溶液各 1 L，默认）、`mol1bar`（1 bar 理想气体和 1 mol/L 溶液）、`reference`（再折算到无限稀释，多一项纯溶剂的摩尔浓度，水约 55 mol/L）。不同约定只差一个常数（M6c）。 |
| 溶剂中的外场放大 | 溶剂中的分子感受到的局域电场比外加电场强，近似为 3ε/(2ε+1) 倍（ε 很大时约 1.5 倍）。DFTB+ 在溶剂与外电场同时使用时默认这样放大（`RescaleSolvatedFields`），pydftb 相同，也可以关闭（M6c）。 |
| 激发态、垂直激发能 | 分子吸收光子后电子跃迁到的较高能态。垂直激发能是原子不动（基态结构）时激发态与基态的能量差，对应吸收光谱的峰位（M6d）。 |
| 线性响应（TD-DFTB） | 不直接求激发态的波函数，而是看基态的电荷密度对一个小的含时扰动怎样响应：响应在某些频率上发散，这些频率就是激发能。DFTB 中的做法由 Niehaus 等（2001）给出（M6d）。 |
| Casida 方程 | 线性响应写成的本征值问题 Ω F = ω² F：Ω 的对角元是单粒子跃迁能 ω<sub>ia</sub> 的平方，非对角元是跃迁之间经 γ（三重态为自旋常数 W）的耦合，本征值是激发能的平方。矩阵的边长等于单粒子跃迁数（M6d）。 |
| 单粒子跃迁 | 一个电子从占据轨道 i 移到空轨道 a，能量 ω<sub>ia</sub> = ε<sub>a</sub> − ε<sub>i</sub>。激发态是这些跃迁的组合；占比最大的那个称为“主要跃迁”，它的占比就是 EXC.DAT 的权重（M6d）。 |
| 跃迁电荷 | 轨道 i 与 a 的乘积在每个原子上的 Mulliken 分配 q<sup>ia</sup><sub>A</sub>。跃迁之间的耦合用它近似。同一原子上 s、p 轨道之间的跃迁电荷为零，这类跃迁（例如水的孤对电子激发）就不与其他跃迁耦合（M6d）。 |
| 振子强度 | 一个激发吸收光的强弱，无量纲，(2/3) ω |μ|²。为零的是“暗态”，例如闭壳层分子的三重态和对称性禁戒的跃迁（M6d）。 |
| 跃迁偶极 μ | 基态与激发态之间的偶极矩阵元，方向决定吸收的偏振；DFTB 中由跃迁电荷与原子位置算出（M6d）。 |
| 单重态、三重态 | 闭壳层分子的激发按自旋组合分成两类：单重态（总自旋 0，与基态自旋相同，可以吸收光）与三重态（总自旋 1，不能直接由光激发）。三重态的耦合只含自旋常数 W，所以通常能量较低（M6d）。 |
| 自旋污染 Δ⟨S²⟩ | 自旋极化（开壳层）体系的激发态不是总自旋的本征态，⟨S²⟩ 相对基态的变化衡量它混入了多少别的自旋态。闭壳层分子按自旋极化计算时，单重态为 0、三重态为 2；DFTB+ 认为绝对值小于 0.5 的态可信（M6d）。 |
| 能量窗口、振子窗口 | 缩小 Casida 矩阵的办法：能量窗口只保留低于第 N 个跃迁能加某个值的跃迁；振子窗口再把更高、但单粒子振子强度大的跃迁加回来。窗口会改变高处的激发能（M6d）。 |
| 最亮态 | 振子强度最大的单重态，`StateOfInterest = -1`（M6d）。 |
| 按原子分解的能量 | 把总能量拆成每个原子的份额，求和等于总能量。DFTB+ 的 `AtomResolvedEnergies` 给出电子、排斥、色散与总能量四列：在位的项全归本原子，两个原子之间的项各分一半。可以用来看反应中哪些原子的能量变了，也可以给机器学习势当标签（M6f-4a）。 |
| 净布居（在位布居）与杂化比 | Mulliken 布居中只算原子自身轨道之间的那部分（不含与邻居的重叠份额）就是净布居；杂化比 = 1 − 净布居/中性原子的电子数，数值越大，原子的电子越多地参与成键（M6f-4a）。 |
| 静电势（ESP） | 空间某点上原子电荷产生的电势，把每个原子看作点电荷 q0 − q：分子直接求和（距离加一个很小的“软化”量 ε 避免除以零），周期体系用 Ewald 求和。DFTB+ 写成 ESP.dat，单位伏特；有外场或外部点电荷时另有一栏（M6f-4a）。 |
| Mulliken 权重（本征向量） | 一个本征态在每个原子轨道上的份额 c<sub>μ</sub>(Sc)<sub>μ</sub>，对所有轨道求和为 1。eigenvec.out 在每个系数旁边写出这个值；简并态的系数可以任意旋转，比较时把简并的几个态加起来（M6f-4a）。 |
| eigenvec.out、band.out | DFTB+ 的两个输出文件：前者列出每个本征态的系数与 Mulliken 权重（`WriteEigenvectors`），后者列出每个 k 点、每个自旋的本征值（eV）与占据数，dptools 的 `dp_dos` 由它画 DOS（M6f-4a）。 |
| Pipek–Mezey 局域化 | 把占据轨道重新组合（不改变它们张成的空间与总密度），使每个轨道尽量集中在少数原子上：最大化各轨道 Mulliken 布居的平方和 Σ<sub>i</sub>Σ<sub>A</sub>(Q<sub>i</sub><sup>A</sup>)²。得到的轨道接近化学直觉中的键、孤对与内层（M6f-4b）。 |
| Jacobi 旋转 | 每次只把两个轨道按一个角度 α 互相旋转（c<sub>s</sub> ← cos α c<sub>s</sub> + sin α c<sub>t</sub>），取使目标函数最大的 α；对所有轨道对依次做一遍叫一次“扫描”，反复扫描直到角度很小。DFTB+ 的 Pipek–Mezey 用 acos 求这个角，所以角度只能分辨到约 4e-9。 |
| 键布居（Mulliken 键布居） | 原子 A、B 之间共享的电子数 Σ<sub>μ∈A,ν∈B</sub> P<sub>μν</sub>S<sub>μν</sub>（周期体系对所有周期像求和）；对角元是原子自身的部分，每一行的和就是该原子的 Mulliken 布居，全部之和是电子总数。把 S 换成 H0 就是“键能”，总和是 E<sub>H0</sub>（M6f-4b）。 |
| Mayer 键级 | 衡量两个原子之间成键数目的指标 Σ<sub>μ∈A,ν∈B</sub>(PS)<sub>μν</sub>(PS)<sub>νμ</sub>：单键约 1、双键约 2（甲醇的 C–O 为 0.95）。DFTB+ 只用总密度、只用于分子（M6f-4b）。 |
| 跃迁电荷（激发态） | 一个激发态的“跃迁密度”在每个原子上的份额 q<sub>A</sub>：基态与激发态之间的电荷重新分布的原子图像，Σq<sub>A</sub> = 0，整数占据时 Σq<sub>A</sub>R<sub>A</sub> 就是跃迁偶极。常用于计算分子之间激发能转移的耦合（DFTB+ 的 ATQ.DAT，M6f-4b）。 |
| 简并态 | 能量相同的几个态，例如苯、C<sub>60</sub> 等高对称分子中的激发。它们可以任意线性组合，单个态的振子强度、跃迁偶极、主要跃迁都不唯一，只有整组的和有意义（M6d）。 |

## 软件与数值

| 名词 | 通俗解释 |
|---|---|
| 类型标签（label） | 告诉程序每个原子用哪套参数。通常就是元素名；同一元素要用多套参数时，起不同的名字，如 `Li1`、`Li2`（DFTB+ 和 ASE 的约定），也支持 `Li_el`、`Li@el` 这类写法。 |
| ParamSet | pydftb 中“参数从哪里来”的对象：一个 SKF 目录加上读取选项。 |
| wheel | Python 包的标准发行文件（`.whl`）：已经排好目录的 zip 包，`pip install` 直接解压到 site-packages，不需要在安装时构建。pydftb 的 wheel 不含 `docs/` 与 `bench/`，含测试与冻结的参考数据（P1）。 |
| sdist | 源码发行包（`.tar.gz`）：项目的源文件加构建配置，安装时先构建成 wheel。P1 检查过 sdist 构建出的 wheel 与直接构建的逐字节相同。 |
| 可编辑安装（editable install） | `pip install -e`：不复制文件，只登记“这个包的源码在某个目录”，改源码立即生效，适合开发。本机的共享环境在 P1 合并后改为 `pip install -e ./pydftb -e .`。 |
| 命令行入口（console script） | 包在安装时生成的可执行命令，如 `pydftb`、`ptbp`；它调用包里的某个函数（`pydftb.cli:main`）。与 `python -m pydftb` 等价（P1）。 |
| System | pydftb 中“算什么”的对象：原子的类型标签、元素、坐标、晶胞、总电荷。 |
| 复步长求导 | 一种数学技巧：给输入加一个极小的虚数扰动，从结果的虚部直接得到导数，精度可以达到计算机能表示的极限。 |
| 灾难性抵消 | 两个几乎相等的大数相减，有效数字大量丢失。DFTB+ 的 γ 公式在两个 U 几乎相等时就是这样失效的。 |
| 均差 / Hermite–Genocchi 公式 | 均差是导数的“差商版本”；Hermite–Genocchi 公式把它写成一个积分，可以避开相减抵消。pydftb 用它稳定地计算 U 几乎相等时的 γ。 |
| 有限差分 | 用两个相距很近的点上函数值之差除以它们的距离来估计导数。DFTB+ 用这种方法求 H、S 的导数，步长 1.22e-4 Bohr；两个点若落在不同的插值窗口里，误差会变大。 |
| 冻结的参考数据 | 先用 DFTB+ 算好标准答案存成 JSON 文件。之后测试只需要 pydftb，不必安装 DFTB+。 |
| 开发版 DFTB+ | 从 DFTB+ 的 GitHub 主分支自己编译的程序。本机的 25.1 没有偶极修正，也拒绝周期体系的卤素修正，这两项的参考结果用开发版（commit 041e723）生成；它先在 13 个已有算例上与 25.1 对照（能量逐位相同，力差 ≤ 3.4e-14），才拿来用。只用于对照，不进仓库（M6f-3）。 |
| 测试专用开关（compat） | pydftb 默认给出正确的结果；DFTB+ 有错误时，另有一个只给测试用的开关故意按 DFTB+ 的错法计算。两者分别与“DFTB+ 能量的差分”和“DFTB+ 的输出”一致，就证明差别只在那一项上（M6e 起）。 |
| 超胞 | 把晶胞沿某个方向重复几次得到的大晶胞。描述的是同一个晶体，所以每个原胞的能量必须与原胞计算的结果相同，这是检验周期求和的好办法。 |
| 硬截断 | 只计入一定距离以内的相互作用。截断处函数值不为 0 时，原子跨过截断，能量会有微小跳变。 |
| 短程 γ 截断 | γ 的短程部分随距离指数衰减，小于 1e-10 Ha 的原子对就不再计算。pydftb 自 M2e 起与 DFTB+ 在同一距离截断。 |
| dp_dos | DFTB+ 附带的 Python 小工具（dptools），把 `band.out` 或区域文件展宽成 DOS/PDOS 曲线；pydftb 的 `dos()` 用相同的规则。 |
| 可选依赖 | 只有用到某个功能时才需要安装的软件包。pydftb 的 D3/D4 色散需要 `dftd3`、`dftd4`，不用这两种色散时不必安装。 |
| ops 分发层 | 物理代码通过它调用少数几个与硬件相关的操作（累加、本征分解等），换成 GPU 时只需替换这一层。`ops.namespace()` 按输入的类型返回 NumPy 或“NumPy 名字的 torch”，同一段代码可以在两个后端上运行（M4a）。 |
| SP2 纯化 | 只用矩阵自乘（约 20 次）代替对角化的方法，适合 GPU。 |
| 稀疏矩阵 / 线性标度 | 只存储、只计算非零元素，计算量随原子数一次方增长，而不是三次方。 |
| FP64 / FP32、混合精度 | 双精度（约 16 位有效数字）和单精度（约 7 位，快约 2 倍）。先用单精度算，再用双精度修正。 |
| MPI / OpenMP / OpenBLAS | 三种并行：多台机器之间（MPI）、一台机器的多核之间（OpenMP）、数学库内部的多线程（OpenBLAS）。 |
| 线程超订 | 开的线程比 CPU 核心多，线程互相抢资源，结果反而更慢。 |
| 进程 / 线程 | 进程各有自己的内存，互不干扰；线程在同一个进程里，共享内存。PTBP 把不同的结构分给进程，把一个结构的 k 点分给线程（M3a）。 |
| fork（派生子进程） | Linux 上复制当前进程得到子进程的方法。子进程直接继承父进程里的全部数据，不必重新读入，也不必打包传送。 |
| CPU 预算 | 一次运行可以用的核心数：取 CPU 亲和性（taskset、SLURM 绑核）、容器的 CPU 配额、`SLURM_CPUS_PER_TASK`、`PTBP_NCORES`、`--ncores` 中最小的一个。进程数 × 每个进程的线程数不超过它。 |
| 方案（plan） | PTBP 启动时定下的并行安排：每个阶段用几个进程、每个进程几个线程、任务按什么顺序发放，附带理由。启动时打印出来，并存为运行目录里的 `plan.json`。 |
| 最大优先调度（LPT） | 把任务按估计耗时从大到小排好，哪个进程先空下来就先领下一个。大任务先开工，最后不会只剩一个大任务让其他进程干等。M3a 用 k 点数 × 轨道数³ 估计耗时；M3c 起第一个 BO 步用成本模型，之后用上一步实测的每个结构耗时。 |
| k 点线程 | 把一个周期结构的 k 点切成几块，交给几个线程同时做对角化和密度矩阵。每个 k 点的计算与不切块时完全相同，所以结果逐位相同。 |
| GIL（全局解释器锁） | Python 同一时刻只让一个线程执行 Python 代码。NumPy 调用 LAPACK、BLAS 时会先释放这把锁，所以线程能同时做矩阵运算；SciPy 的 `eigh` 接口不释放，用它就快不起来。 |
| 逐位相同 / 逐字节相同 | 两次计算得到的浮点数每一位都相同；写出的文件每个字节都相同。比“误差很小”更严格，并行改动以此为验收标准。 |
| 分片与回放 | hotcent 的一张积分表有 700 个距离点，各点互不相关。分片：几个进程各算一部分距离点，把结果记录下来；回放：父进程再走一遍 hotcent 自己的流程，用记录代替计算，由 hotcent 生成最终的表格和文件。这样不必复制 hotcent 的数值代码，结果逐字节相同（M3b）。 |
| 成本模型 | 在计算之前估计一个结构要算多久、要多少内存的公式（`pydftb/perfmodel.py`，M3c）。输入是轨道数、k 点数和截断内的原子对数，常数用实测数据拟合。估计的耗时与实测通常相差一到两成，但哪个结构大、哪个小排得很准。 |
| 计算策略推荐器 | PTBP 根据成本模型决定每个阶段用几个进程、几个线程（`utils/recommender.py`，M3c）：模拟几种分法的调度，去掉内存放不下的，取最快的。只调整不影响结果的设置，其余的作为建议打印。`ptbp plan` 不运行优化就能看到它的结论。 |
| 库仑原子对 | SCC 计算中，电荷之间的 γ 相互作用要对截断以内的所有原子对求和。截断由最小的 Hubbard U 决定（γ 的短程部分随 exp(−3.2 U r) 衰减，算到 1e-10 为止）：Cu 的 4p 壳层 U = 0.08 Ha，截断 96 Bohr，64 个原子的晶胞就有 300 万个原子对，大晶胞的耗时和内存主要花在这里。 |
| 安全系数 | 内存估计乘上的放大倍数（1.5）。标定数据中内存模型最多低估 29%，规划时宁可少开一个进程，也不让机器内存耗尽。 |
| Amdahl 定律 | 只有一部分工作能并行时，加速比 = 1 / (串行部分 + 并行部分 / 并行加速)。pydftb 的 k 点线程只加速每个 k 点的矩阵运算，库仑部分和力不分线程，所以 4 个线程整体只快 1.3–1.4 倍。 |
| 吞吐 | 单位时间能评估多少个参数点。parallel_bo 同时算几个点，每个点只分到一个核心，单个点慢一些，但总的吞吐更高；它提出参数点的方式不同，优化路径会变，所以只作为建议。 |
| 探测（probe） | `ptbp plan --probe` 用约 0.7 秒跑三个小的矩阵运算，得出本机比标定机器快多少，按机器（CPU 型号、核心数、NumPy 和 BLAS 版本）缓存，之后的估计都按这个比例换算。 |
| HSD | DFTB+ 输入文件的格式：`标签 = 值`、`标签 = 方法 { ... }`、`标签 [单位] = 值`，块里也可以直接写数据行。`dftb_in.hsd` 是用户写的输入，`dftb_pin.hsd` 是 DFTB+ 处理后实际用的输入（含默认值和旧版本转换的结果）。 |
| IgnoreUnprocessedNodes | DFTB+ 的解析选项：打开后，DFTB+ 不认识或没读到的节点只在屏幕上警告一下就被跳过；不开时 DFTB+ 报错退出。ASE 写的输入默认打开，PTBP 的展宽块因此被悄悄忽略（M3d 的 P03）。 |
| 配置顾问 | `pydftb advisor 运行目录`（M3d）：读 DFTB+ 的输入、实际生效的输入、屏幕输出和 SKF，按规则报告“写了却不是那个意思”的设置，附上行号和建议；只读，不改任何东西。PTBP 用 DFTB+ 时自动检查一次。 |
| 规则（顾问） | 顾问的一条检查，编号如 P01（解析器）、H01（参数）、T01（线程）、D02（色散）。每条都来自一个对照中踩过的坑或实测，`--explain 编号` 给出说明。 |
| 预期（顾问） | 在 PTBP 的历史输入下本来就该出现、不要改的发现：已发表的参数就是在这些设置下拟合的，改了结果就不可比。 |
| σ_rep 搜索 | PTBP 每个 BO 步对排斥势参数 σ_rep 做的一维搜索：网格 11 点、Nelder–Mead 细化、再 L-BFGS-B，共约 74 次评估；每次都重算全部结构的排斥能和力，并拟合状态方程。 |
| 状态方程（EOS）拟合 | 用一组不同体积下的能量拟合 Birch–Murnaghan 曲线，得到平衡体积和体弹模量。PTBP 的 energygeometry 损失比较 DFT 与 DFTB 的这两个量。 |
| 进程组 | 可以一起收到信号的一组进程。PTBP 的每个工作进程自成一组，结束时连同它启动的 DFTB+ 一起结束，不会留下孤儿进程。 |
| ParserVersion | DFTB+ 输入格式的版本号。版本过低时，DFTB+ 会按旧规则悄悄改写某些设置。 |
| PyTorch | 一个支持 GPU 和自动求导的 Python 数值库，pydftb 的第二个后端（M4a 起，可选安装）。 |
| 后端（backend） | pydftb 做数组运算用的库：NumPy（默认）或 PyTorch。`DFTB(backend="torch", device=..., dtype=...)` 把每轮 SCC 中最重的部分（k 点折叠、本征分解、密度矩阵、布居）放到 torch 上，其余仍用 NumPy（M4a）。 |
| 设备（device） | torch 做运算的硬件：`cpu`、`cuda`（NVIDIA，AMD 的 ROCm 版也用这个名字）、`mps`（Apple）、`xpu`（Intel）。 |
| golden 检查 | 改动 NumPy 路径时的验收工具（`pydftb golden --base 提交`）：在工作区和旧提交里各跑一遍同样的计算，逐字节比较所有结果和中间量，必须完全相同。 |
| torch 的线程数与 MKL | torch 自带一份静态链接的 MKL，threadpoolctl 看不到它。只改 OpenMP 的线程数会让 MKL 仍按原来的线程数开并行区；在多线程跑过 torch 的父进程 fork 出的子进程里，这会卡死。所以 pydftb 总是用 `torch.set_num_threads` 设线程数（M4a）。 |
| 自动求导 | 程序在计算结果的同时，自动算出结果对每个输入参数的导数。pydftb 的 `pydftb.autodiff`（M4b）给出能量、力、电荷等对 SK 表、U、排斥势系数和坐标的导数。 |
| 变分（驻定） | 自洽收敛后，Mermin 自由能 F 对密度的一阶变化为零：密度稍微不准，F 只差二阶小量。所以求 F 对参数的导数时，可以把密度当作常数。 |
| 替代能量（hf 模式） | 把收敛的密度矩阵、能量加权密度矩阵和电荷当作常数代入能量公式得到的函数。它与 F 数值不同，但对参数、坐标的一阶导数与 F 完全相同，所以求导时不必对本征分解求导（M4b）。 |
| 不动点、隐式微分 | SCC 的解满足 q* = Φ(q*)：输入电荷算出的输出电荷等于输入。参数变化时 q* 怎么变，可以不重做迭代，由隐函数定理直接解一个小的线性方程得到（M4b 的 implicit 模式）。 |
| 伴随方程 | 反向求导时代替“q* 对每个参数的导数”的那个线性方程 (I − Jᵀ)y = g：只解一次，代价与参数个数无关。PTBP 的结构只有几个电荷，直接解；电荷多时用 GMRES 迭代。 |
| 展开求导 | 把 SCC 的每一轮迭代都记下来，整条链一起求导。慢、占内存，但完全独立于隐式微分，M4b 只用它检验隐式微分。 |
| Daleckii–Krein 差商 | 密度矩阵对哈密顿量求导的公式：两个能级之间的贡献是占据数之差除以能级之差。能级重合（简并）时取占据函数的导数，所以简并不会让导数变成无穷或 NaN。 |
| 切向（tangent） | 参数沿某个方向变化时，各个量随之变化的速率。例如 r0 变化时 SK 表每个值的变化率（M4c 用 hotcent 的差分求它），与 pydftb 的梯度相乘就得到损失对 r0 的导数。 |
| 带隙中点的费米能级 | 电子数为整数时，DFTB+ 先把费米能级放在最高占据和最低未占据能级的正中间，只要那里的电子数与目标差不超过 1e-7 就采用。有展宽、带隙小时电子数因此可以差一点，F 就不是严格的“电子数固定”的自由能（M4b 发现）。`Smearing(fermi_level="exact")` 总是二分到准确的电子数。 |
| 冗余积分 | 异核的两个 SK 文件 A-B 和 B-A 都存着 ss、pp、dd、ff 这几类积分（同一个物理量存两份），矩阵的上、下三角各用一份。改参数时两份要一起改，否则 S 不再对称。 |
| Richardson 外推 | 用两个步长的差分组合出更准的导数：(4D(h/2) − D(h))/3 消去了步长平方的误差。M4b 用它作为检验自动求导的参照。 |
| 贝叶斯优化（BO） | PTBP 目前用的参数搜索方法。不需要导数，但每试一组参数都要重算全部结构。 |
| 包络定理 | 损失 μ*(r0) = min<sub>σ</sub> μ(r0, σ) 是内层最优化的结果。在最优的 σ 处 μ 对 σ 的导数为零，所以 σ 怎么跟着 r0 移动不影响一阶导数：dμ*/dr0 = ∂μ/∂r0（M4c）。σ 落在搜索边界上时同样成立。 |
| 折点（kink） | 绝对值 \|r\| 在 r = 0 处不光滑。PTBP 的损失是很多绝对值之和，σ 的最优点常常正好落在某一项的折点上，这时 σ 跟着 r0 沿“这一项等于零”移动，导数要加修正项（M4c 的折点公式）。 |
| 微扰约束（perturbative confinement） | hotcent 2.0 起的默认做法：约束势只加在自由原子的势上解一次，不重新自洽。PTBP 给每个价层都设了波函数约束，密度就只由 r0_w 决定，r0_d 完全不影响 SKF（M4c 发现）。PTBP 用 `--confinement perturbative` 时是这种做法（复现 M3、M4 的结果）。 |
| 自洽约束（self-consistent confinement） | hotcent 1.x 的默认做法，也是 PTBP 自 M4e 起的默认：每个约束势都在一次完整的原子自洽计算里施加，r0_w 决定轨道的形状，r0_d 决定计算二中心积分时用的密度。PTBP 原来的三个参数（r0_w、r0_d、σ_rep）在这种做法下才都起作用。 |
| 投影 BFGS | 带边界的拟牛顿法：用梯度的变化估计曲率，走一步；碰到边界的分量不往外走。配合 Armijo 回溯（步子太大、损失没有足够下降就减半）。PTBP 的 `--optimizer gradient`。 |
| 损失的断崖 | 损失随参数突然跳变的地方，例如某组结构的 EOS 拟合跑出采样的体积范围、体积比从 +0.13 跳到 −1.06。跨过断崖的差分没有意义；梯度只描述断崖一侧的局部变化（M4c 报告）。 |
| 失败值 | PTBP 的一步失败时（DFTB+ 或 pydftb 报错、hotcent 没有生成 SKF、EOS 拟合出错等）损失记为 97–99 的随机整数。energygeometry 模式的真实损失只有 1–4，失败值远大于它；dataset、reaction 模式的真实损失可能更大，失败值反而像“最好的点”（M4c 报告第七节）。 |
| 初始随机点 | skopt 的 `gp_minimize` 先在参数范围内随机取 `n_initial_points`（默认 10）个点，之后才由高斯过程挑点。PTBP 给了种子点、默认又只调用 11 次，所以默认的 BO 是种子加 10 个随机点（M4c）。 |
| meta 设备 | torch 的一种“空”设备：张量只有形状，没有数据。把默认设备设成 meta 再计算，凡是没写明设备就新建的张量都落到 meta 上，一与真实数据相遇就报错。M4d 用它在没有 GPU 的机器上查出“张量建在了错误的设备上”这类只有在 GPU 上才会暴露的错误。 |
| 确定性算法 | GPU 上有些运算（原子加法、部分矩阵乘法）每次累加的顺序不同，结果的最后几位会变。torch 的确定性模式改用顺序固定的实现，同一台机器上重算逐位相同。pydftb 在 CUDA 上计算期间自动打开，算完恢复用户原来的设置（M4d）。 |
| ROCm | AMD GPU 的计算平台。ROCm 版的 torch 里 AMD GPU 也叫 `cuda`；本征分解等由 hipSOLVER 或 MAGMA 完成，批量计算的速度与 NVIDIA 不同（M4d）。 |
| MPS | Apple M 系列芯片的 GPU 接口。没有 float64，所以 pydftb 在 MPS 上只能用 float32，float64 的部分（S 的 Cholesky 分解、求和）放在 CPU 上（M4d）。 |
| 能力探测 | 第一次用 MPS、XPU 时，用 2×2 的小矩阵试一下 float64、复数、Cholesky、本征分解能不能运行，按结果决定哪些步骤留在 CPU，而不依赖可能过时的支持列表（M4d）。 |
| GPU 自检脚本 | `pydftb gpu-check`：在用户的 GPU 上重算 DFTB+ 参考算例、与 CPU 对照、检查确定性和自动求导，并计时；任何一项正确性检查失败都以非零状态退出（M4d）。 |
| fork 与 CUDA | fork 复制出的子进程不能再使用父进程已经初始化的 CUDA。所以 PTBP 用 GPU 时 DFTB 阶段在主进程里逐个结构计算，探测 GPU 放在单独启动的子进程里（M4d）。 |
| Davidson 方法 | 求大矩阵最低几个本征值的迭代法：在一个逐步扩大的子空间里对角化，每步用残差除以 (θ − 对角元) 作为新方向（对角元作预条件）。Casida 矩阵是对角阵加一个低秩的耦合，Davidson 往往十来步就收敛，比 ARPACK 的 Lanczos 快得多（M6d）。 |
| ARPACK、Stratmann | DFTB+ 解 Casida 方程的两种迭代求解器。ARPACK 是通用的隐式重启 Lanczos 库；Stratmann 是专为 TD-DFT 设计的子空间方法，同时处理 A+B 与 A−B。两者的收敛精度都是单精度量级（M6d）。 |
| Z 向量方法 | 求激发能对原子坐标的导数时，基态轨道随坐标的变化（轨道弛豫）本要对每个坐标解一次响应方程；Z 向量方法把它们合成一个线性方程 (A+B)Z = R，只解一次，代价与原子数无关。A+B 是基态的轨道 Hessian（M6e）。 |
| 弛豫密度 | 激发态与基态的密度差：未弛豫的差密度 T（由 X±Y 组成）加上轨道弛豫 ½(Z + Zᵀ)。它的 Mulliken 布居就是激发态电荷的改变，DFTB+ 写在 XCH.DAT，偶极写在 XREST.DAT（M6e）。 |
| 预条件共轭梯度（PCG） | 解对称正定线性方程的迭代法，每步只需要矩阵与向量的乘积；用矩阵的对角元作预条件。pydftb 的 Z 向量在跃迁数超过 500 时用它，收敛到机器精度（M6e）。 |
| 正则轨道乘子 | 有能量窗口时，只有窗口内的跃迁进入响应，激发能就不再对占据—占据、空—空的轨道转动驻定。补上这两块的乘子 z<sub>pq</sub> = −(G<sub>pq</sub> − G<sub>qp</sub>)/(ε<sub>p</sub> − ε<sub>q</sub>)，力才是能量的精确导数；DFTB+ 没有这一项（M6e）。 |
| XL-BOMD | 扩展拉格朗日的 Born–Oppenheimer 分子动力学：把辅助电荷 n 当作一个动力学变量，用时间可逆的 Verlet 公式与原子一起积分，每步只用它做 SCC 的初值，所以每步只要很少几轮 SCC（`XlbomdFast` 只做 1 轮）。耗散项 α Σ c<sub>k</sub> n(t − kδt) 压住数值噪声（M6e）。 |
| 影子能量 | XL-BOMD 守恒的不是真实的能量，而是一个“影子”：E<sub>band</sub>[D(n)] + ½(2q<sub>out</sub> − n)·γ·n，即把 SCC 能量在 n 处线性化。它在 n 自洽时等于普通能量；力是它在 n 固定时的导数，不需要 SCC 收敛（M6e）。 |
| 环形缓冲 | 只存最近 K + 1 个向量的数组，新值覆盖最旧的值，下标对 K + 1 取模。XL-BOMD 用它存辅助电荷的历史（M6e）。 |
| `ForceEvaluation` | DFTB+ 计算能量加权密度的三种方式：Traditional 用本征值 Σ f ε c cᵀ，DynamicsT0 用 ½DHD（占据数为 0 或 2 时才对；自旋通道的占据数是 0 或 1，应为 DHD），Dynamics 用 ½(DHS⁻¹ + S⁻¹HD)。H 就是被对角化的矩阵时三者相同；XL-BOMD 要求后两种（M6e）。 |
