关键信息

pydftb 现在支持 DFTB+ 的三项修正：H5 氢键修正（HCorrection = H5）、DFTB3 的卤素修正（HalogenXCorr）、平板的偶极修正（DipoleCorrection，25.1 之后才有）。与 DFTB+ 对照沿用 M6f 的严格标准：SCC 轮数逐个相同，每一轮的 SCC 误差也相同。只在 NumPy 引擎中；不用这些选项时逐位不变。

  • 与 DFTB+ 对照：13 个新的单点参考算例和 1 条 MD 全部通过：
    • SCC 轮数逐个相同（最长 18 轮）；能量差 ≤ 8.5e-11 Ha，卤素修正能量差 ≤ 4.8e-11 Ha（detailed.out 只有 10 位小数）；
    • 25.1 拒绝周期体系的卤素修正，也没有偶极修正：这三个算例对照自编的开发版 DFTB+（041e723）。开发版在 13 个已有算例上与 25.1 的冻结参考一致：能量逐位相同，力差 ≤ 3.4e-14。
  • DFTB+ 的三个错误（第五节）：pydftb 给出能量的导数，测试专用的开关能复现 DFTB+ 的结果，证明差别只在这些项上：
    • 卤素修正在开关区间内的力和应力符号错，力差 4.5e-3 Ha/Bohr；pydftb 的力与 DFTB+ 能量的差分一致到 8.1e-11；
    • 激发态的力漏了 H5（激发能里有），差 4.1e-3；pydftb 与 E0 + ω 的差分一致到 4.1e-11；
    • 偶极修正没有应力项，DFTB+ 的应力恰好差 (E/V)·diag(1, 1, −1)，即 1.2e-6；pydftb 与 DFTB+ 能量的应变差分一致到 3.7e-10。
  • 接口：DFTB(h5=True | {…}, halogen_correction=True, dipole_correction=True | {"layer_position": z0})；结果加 e_halogen、e_dipole_corr。PyDFTB 的层位置用 Å。
  • 13 + 1新的 DFTB+ 参考算例与 MD，全部通过
  • 0SCC 轮数与 DFTB+ 之差
  • 4.5e-3卤素开关区间内 DFTB+ 的力误差（Ha/Bohr）；pydftb 8e-11
  • 0旧计算路径改变的位

二、怎么用

from pydftb import DFTB

calc = DFTB(sk, h5=True)                       # 论文的参数：RScaling 0.714，WScaling 0.25，O 0.06、N 0.18、S 0.21
calc = DFTB(sk, h5={"r_scaling": 0.8, "w_scaling": 0.3,
                    "scaling": {"O": 0.1, "S": 0.3, "C": 0.1}})   # 按元素；≤ 0 表示不修正

calc = DFTB(sk, third_order="full", hubbard_derivs=ud, h_damping=4.0,
            halogen_correction=True)           # DFTB3 + 卤素修正
r = calc.calculate(labels, positions)
r.e_halogen                                    # 已计入 energy 与 free_energy

calc = DFTB(sk, kpts=(k, w), dipole_correction=True)         # 平板；偶极层在 −h/2
calc = DFTB(sk, kpts=(k, w), dipole_correction={"layer_position": 9.45})      # Bohr
r = calc.calculate(labels, positions, cell, pbc)
r.e_dipole_corr                                # 2πD²/V，已含在 e_scc 中；r.stress 含 DFTB+ 缺的项

atoms.calc = PyDFTB(skdir, kpts=(2, 2, 1), dipole_correction={"layer_position": 5.0})   # Å
  • H5：需要 SCC；不能与 h_damping 同用（DFTB+ 的 HCorrection 只有一个值）；没有 H 原子时报错。pydftb 按元素识别 H 与受体，DFTB+ 按物种名：只有带后缀的类型标签（如 O2）结果不同。γ、势、力、应力、Casida 的 γ、激发态的力、XL-BOMD 的力都含 H5；三阶不含（同 DFTB+）。
  • 卤素修正：需要 third_order（完整的或只 onsite 的）；体系中没有 O/N 或没有 Cl/Br/I 时报错；周期体系给警告（同开发版，25.1 拒绝）。力和应力是能量的导数；r < 0.7R 时不计算 f(r)，不会出 NaN。
  • 偶极修正：周期体系，平板法向沿 z（a3 ∥ z，a1、a2 没有 z 分量：比 DFTB+ 严格）；总电荷为 0，每轮 |ΣΔq| ≤ 1e-7；不能与固定费米能级、点电荷、外场、XL-BOMD 同用。只要没有原子跨过偶极层，层放在哪里、坐标给在哪个周期像上，结果都相同。
  • 三项都只在 NumPy 引擎中。

三、与 DFTB+ 的对照

参数为测试用的 ptbp_hcocu；N、S、Cl、Br 是 O 的类型副本（DFTB+ 只按物种名识别受体和卤素，走的是与真实元素完全相同的代码，“只用于测试”）。周期体系 EwaldTolerance = 1e-12。“SCC 误差”是逐轮误差的最大相对差（只比较 DFTB+ 打印值大于 1e-7 的轮）。带 * 的力和应力对 DFTB+ 能量的 4 点差分比较（forces_fd、激发态的 E0 + ω、stress_fd），括号里是 DFTB+ 自己的解析值与差分之差；“compat”是测试专用开关复现的 DFTB+ 的力与 DFTB+ 之差。

四、自洽检查

  • H5：
    • h5_scale 的 S′ 正是 γ(1 + g)，dS′ 与差分一致到 1e-10；
    • 水二聚体的力、水盒子的力与维里是能量的导数（2e-9、5e-8；维里用 1e-5 的两点应变差分，避开 SK 表的格点）；
    • 缩放全部 ≤ 0 时与不开 H5 逐位相同；类型标签 O2 与普通标签结果相同（1e-11，按元素识别）；
    • XL-BOMD：XL 的力是影子能量的梯度，H5 时也一致到 2e-10（DFTB+ 的 XL 梯度漏了 H5，不做 DFTB+ 参考）。
  • 卤素修正：
    • O–Cl、N–Br、O–I 三种原子对在开关区间两侧的对能与公式一致（相对 1e-13），每个原子一半；梯度与差分一致（1e-11），在 0.7R、0.8R 处能量与梯度连续；
    • compat 只改变开关区间内的梯度；截断 = 出现的最大 d + 4.2245 Å；r < d 时能量有限；
    • 甲醇–水（开关区间内）的力、水盒子的力与应力是能量的导数。
  • 偶极修正：
    • E = 2πD²/V（相对 1e-12），与探针 P11 的 5.896e-3 一致；
    • 力（步长 5e-5 Bohr：原子 0 离 SK 格点只有 2e-4 Bohr）与全部 6 个应力分量（含面外剪切，测试中关掉晶格检查）是能量的导数；
    • 分子给在低一个周期处时折叠到同一平板；层在 z0、z0 + h、−h/2、h/2 结果相同；整体平移 0.4 Bohr（没有原子跨层）能量不变；PyDFTB 的单位。
  • 拒绝：各种不支持的组合、错误的晶胞、未知的键、torch 后端、pydftb.autodiff.evaluate。

五、DFTB+ 的行为

1. H5

  • 激发态的力漏了 H5：linrespgrad 直接调用 expGammaPrime，既没有阻尼也没有 H5，而激发能用的 γ 矩阵含 H5。水二聚体 S1 的力与 E0 + ω 的差分：不带 H5 时 2.7e-8，带 H5 时 4.1e-3。pydftb 扩充测试专用的 compat "damping"（γ′ 去掉阻尼与 H5）后与 DFTB+ 的力一致到 2.7e-8。
  • XL-BOMD 的梯度（addGradientsDcXlbomd）也漏了 H5（源码）；pydftb 的 XL 力含 H5。
  • DFTB+ 按物种名识别 H5 的受体，半径按名字的前两个字符查：物种名 O2 的 O–H 对不修正，给了 H5Scaling { O2 = 0.06 } 也只警告半径“not available”；pydftb 按元素。
  • HCorrection 只有一个值，H5 与阻尼写不到一起；源码中 “H5 correction is not compatible with X-H damping” 的检查从输入到不了。

2. 卤素修正

  • 开关区间内的符号错误：梯度中 dσ 的两项是 +σ′[f(r) − f(0.7R)]，正确的是 −σ′[…]。r = 2.45 Å 时 DFTB+ 的力与其能量差分差 4.54e-3；把这两项反号的公式能把 DFTB+ 的卤素力复现到 7.9e-17。应力同样错：探针中原子对落在开关区间内的水盒子，应力差 2.1e-5。参考算例因此存 DFTB+ 能量的差分 forces_fd。
  • r < d 时 (r − d)4.518 是 NaN（源码），σ = 0 也乘不掉；pydftb 在 r < 0.7R 时不计算 f(r)。
  • 25.1 只在非周期体系中读 HalogenXCorr，周期体系报“未处理的节点”；开发版改成警告。
  • 没有三阶，或没有 O/N 与 Cl/Br/I 物种时，这个节点“未处理”，DFTB+ 报错退出；“only fitted for 3rd order models” 的检查同样到不了。

3. 偶极修正（开发版）

  • 没有应力项：DFTB+ 的应力与其能量的应变差分之差为 +1.213e-6（xx、yy）、−1.214e-6（zz）、4e-13（xy），正好是 (E/V)·diag(1, 1, −1)；pydftb 的维里 W = E(2nnT − I) 补上了这一项。
  • 晶格检查只看 a3：a1 带 z 分量的晶胞也照算，结果没有意义；pydftb 两者都查。含 z 的剪切应变会使晶胞通不过 DFTB+ 的检查，所以 stress_fd 只能做 xx、yy、zz、xy。
  • 能量记在 ESCC 里，不单独打印；外部点电荷不算进 D（pydftb 拒绝同用）。

4. SK 表格点附近的力

  • DFTB+ 用差分求 H0、S 的导数，原子对的距离靠近 SK 表的格点时与解析导数差到 1e-6：最初的水层几何上不带偶极修正也差 6.1e-7（折叠的 5.4e-6），与偶极修正无关。参考算例换了随机扰动的种子（第八节）。同样的原因，自查的差分要用小步长或两点应变差分。

八、与设计的偏差

  • 偶极修正的维里：设计中是 W = (4πD/V)·sym(ez ⊗ ΣAΔqArf,A) − E·I。其中 xz、yz 两项随原子取哪个面内周期像而变，能量却不变，所以它不是能量的导数。实现改为以平板法向定义高度：n = a1 × a2/|a1 × a2|，u = r·n，h = V/|a1 × a2|。均匀应变 ε 下 u 与 h 都乘 (1 + nTεn)，于是 D 也乘这个因子，V 乘 (1 + tr ε)，得到 W = ∂E/∂ε = E(2nnT − I)。n = ez 时 xx、yy 为 −E，zz 为 +E，剪切为 0；6 个分量都用差分验证过。
  • 水层的几何：最初的几何上 DFTB+ 的力差 6.1e-7（折叠的 5.4e-6），原因是 SK 格点附近的差分导数（第五节第 4 条）。改用随机扰动的种子 11 与 16 后力差为 8.4e-9、6.1e-9。
  • stress_fd：偶极修正的算例只取 xx、yy、zz、xy 四个分量（DFTB+ 拒绝面外剪切的晶胞），其余取 DFTB+ 的解析应力。
  • 卤素能量的容差：设计中 e_halogen 的容差是 1e-12，实际为 1e-10，因为 detailed.out 的 “Halogen correction energy” 只有 10 位小数。
  • SCC 容差：water_box_h5 4e-10、meoh_water_halogen 1e-9、meoh_water_halogen_nbr_h5 2e-10、water_slab_dipole 1e-9，使收敛判断离阈值足够远（第六节）；两个差分算例 1e-12。
  • 开发版的检验：设计中要求 6–8 个已有算例，实际比较了 13 个（含 SOC、DFTB+U、Casida、GB 溶剂），能量全部逐位相同，力差 ≤ 3.4e-14，应力差 ≤ 1.8e-16。
