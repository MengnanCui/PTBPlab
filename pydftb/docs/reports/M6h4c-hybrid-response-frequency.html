关键信息

杂化泛函下的极化率与响应核现在也能在有限频率下计算，三条路径都可以：分子与 Γ 点、k 点（共线自旋）、两分量（非共线自旋，分子）。DFTB+ 25.1 拒绝这种组合，所以没有 DFTB+ 参考，验证靠 TD-LC Casida 对全部激发的求和、去掉交换后的 M6g 与 M6g-3b、超胞与共线的极限。有限频率时一阶密度多出反对称部分，只有交换看得见它；占据–空轨道对空间的未知量加倍，方程仍对称，第一激发以上不定。求解仍用批量 MINRES，激发附近小体系改用稠密解。只有 NumPy 引擎；静态结果逐位不变（含 M6h-4 的 37 个算例）。

  • 实数路径（分子与 Γ 点）：
    • 与 TD-LC Casida 对全部激发的求和一致：H2O 在 0.1、0.25、0.5 Ha（第一激发 0.2264）≤ 9.0e-15，CH3 自旋在 0.05、0.2（第一激发 0.0995）≤ 1.5e-14（相对）。
    • C6H6 离 0.150397 Ha 的激发 1e-5 Ha：稠密解 9.3e-12（|α| 2210）。
    • 去掉交换后等于 M6g 的有限频率响应：CuCO 300 K 的金属 8.5e-13，H2CO +U 1.1e-13，干冰 Γ 点 2.0e-13；RPA 1.2e-14。
  • k 点与两分量：
    • k 点的核等于超胞 Γ 点的核：CO 盒子 1.1e-12，三重态 O2 1.7e-13；30000 K 的金刚石去掉交换后等于 M6g，8.1e-13。
    • 两分量去掉交换后等于 M6g-3b，1.5e-14；磁矩沿 z 时等于共线的结果：α 1.4e-10，q 5.7e-11，mz 6.9e-11。
    • 反厄米矩阵的 Pauli 交换要算完整的四个块。基态的捷径（右上块取左下块的伴随）对它给出符号相反的右上块。
  • 求解器：
    • 第一激发以下，MINRES 的轮数是静态的 1.3–2 倍，每轮两次批量的交换构建。
    • 激发附近与稠密的激发谱里 MINRES 停滞。不超过 3000 个未知量时转稠密解，更大时警告并给出达到的残差。
    • 两分量的整体转动在小 ω 是近零模：接受略高于容差的平台残差，MINRES 失败时才用稠密解。
  • η：pydftb 解 η → 0 的极限，去掉交换后与 DFTB+ 默认 η = 1e-8 的 M6g 一致。显式给出别的 η 时拒绝。
  • ≤ 1.5e-14与 TD-LC 对全部激发的求和（相对）
  • 9.3e-12离激发 1e-5 Ha 的稠密解（相对）
  • 1.1e-12k 点的核与超胞 Γ 点之差
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
response_hybrid.py
  • HybridResponse 的有限频率部分（三条路径共用）：
    • _omega_weights：每个块的 D（去掉同一简并组的对，带内的也去掉）、Ω、G；
    • _operator_omega：堆叠未知量 [zs…, y…] 上的算符，Ks 用静态的 kernel，Kx 用 _exchange_a；
    • _t_d、_tt_d：带权重 D 的 T 与 T†，不移动费米能级；
    • _solve_stacked：求解策略（第五节）；_pair_unknowns 数实未知量；
    • _dense_solve、_coordinates、_from_coordinates：物理子空间的基（(eij ± eji)/√2，复数块加 i 倍），按批量右端建矩阵，LU；
    • solve_omega：布居、在位布居与本征值导数（简并组取子块的本征值）都来自 Ps；费米能级的导数为零。
  • _minres 加可选的 op、maxit、strict、curvature、plateau。静态的调用不变，算术逐位相同。
  • KPointHybridResponse：复数的 _t_d、_tt_d；交换移到 _exchange，Pa 也用它（Pa(−k) = conj Pa(k)）。
  • PauliHybridResponse：复数的 _t_d、_tt_d；_exchange_a 用反厄米的 Pauli 交换；_zero_modes 报告有没有整体转动。有限频率不投影。
  • polarisability、response_kernel：逐个频率求解（_solve_all，ω = 0 走静态的 solve），结果按频率叠起来，与 M6g 同形。
hybrid.pyresponse_fock(dps, antihermitian=False)：HybridTerms 的 Pauli 分支在 antihermitian 时把右上块取反；k 点的类接受这个参数（卷积对任意矩阵成立）；NeighbourMinimumImageTerms 仍报错。
calculator.py去掉 “Finite frequency hybrid” 的拒绝；有限频率配显式的非默认 η 时拒绝（“eta other than DFTB+'s default 1e-8 is not supported”）。
测试
  • 新文件 tests/test_hybrid_response_frequency.py：17 项（第三、四、五节）。
  • test_hybrid.py 与 test_hybrid_response.py：有限频率的拒绝改成 η 的拒绝，坐标导数的拒绝不变。

没有 DFTB+ 参考算例（DFTB+ 拒绝），所以不加 refgen 的算例。用到的基态都是已与 DFTB+ 对上的参考算例。DFTB+ 格式的输出（detailed.out 的块、dE_band.out、dV_band.out）不用改：结果类与 M6g 相同，三条路径的多频率结果都试写过。

二、怎么用

r = DFTB(sk_lc, hybrid="lc", analysis={"polarisability": {"frequencies": [0.1, 0.2]}}).calculate(labels, pos)
r.analysis.polarisability.tensor          # (3, 3, 3)：ω = 0（静态）、0.1、0.2
r = DFTB(sk_lc, hybrid="lc", kpts=supercell_folding((2, 2, 2)),
         analysis={"response_kernel": {"static": False, "frequency_range": (0.05, 0.3, 0.05)}}).calculate(labels, pos, cell, pbc)
  • 范围：M6h-4 与 M6h-4b 的全部组合（屏蔽、LC/CAM/全局、自旋、金属、DFTB3、+U、onsite、外场、点电荷、k 点、两分量），频率的给法同 M6g。点电荷导数只有静态的（DFTB+ 也是）。
  • 物理：
    • 对 e−iωt 的扰动，一阶密度 P1 = Ps + Pa，含时密度 Ps cos ωt − iPa sin ωt。
    • 布居只来自 Ps（反对称矩阵的 Mulliken 布居为零），交换两部分都看。
    • 没有带内项，不移动费米能级（同 DFTB+ 与 M6g）。
  • η：DFTB+ 的有限频率权重带 +iη（默认 1e-8），pydftb 的杂化有限频率是 η → 0 的极限。离裸跃迁能 1e-8 以外，两者差 O(η2)。要展宽（吸收谱）的话，pydftb 不做，显式的非默认 perturbation={"eta": …} 拒绝。
  • 警告：
    • “did not converge in 1000 MINRES iterations”：频率在激发附近或在稠密的激发谱里，体系又大于 pydftb.response_hybrid.DENSE_LIMIT（3000 个未知量）。
    • 警告给出达到的残差与稠密解需要的上限。调大 DENSE_LIMIT 就用稠密解：内存是未知量个数的平方乘以 8 字节，再加 LU 的一份拷贝。
  • 耗时见第五节。

五、求解器与耗时

  • 策略：
    • 小体系（≤ 3000 个实未知量）、没有零模：MINRES 在未知量个数的轮数内不收敛，就建物理子空间上的稠密矩阵，LU 求解，误差为条件数乘以舍入。
    • 有两分量的整体转动或体系大：MINRES 最多 1000 轮；相对残差 ≤ 1e-11、100 轮内没有减半时接受（OMEGA_PLATEAU、PLATEAU_STEPS）。仍不收敛时，小体系用稠密解，大体系警告，结果用最后一步。
  • 两分量的近零模：
    • 没有 SOC 时整体转动在有限频率下不再是零模，但本征值 ∝ ω2。H3 120° 在 ω = 1e-5 有 3 个 2.1e-9，下一个是 2.3e-3。
    • 右端与它们正交到舍入（≤ 4e-15），舍入把它们带进 Lanczos 过程，MINRES 有时停在略高于容差的平台上。H3 的 scc_tol 1e-12 基态停在 2–3e-13；1e-6 到 1e-14 的其余基态 6–8 轮收敛。
    • 稠密 LU 则把舍入放大 1/ω2 倍（1e-5 时差 2.6e-4），所以只有 MINRES 失败时才用它。这时频率不小，稠密解准确（HCO 在 0.5 Ha：MINRES 1000 轮后转稠密解，不再警告）。
  • 平台判据：右端在零空间上有 1e-12 不相容部分的合成算符里，MINRES 的残差递推先停在 1e-12，再慢慢漂到 2.5e-13，而真实残差是 1.5e-12，迭代解在其余分量上的误差从 1.3e-15 涨到 5e-12。平台判据在漂移之前停下（单元测试，坑 169）。

八、与设计的偏差

  • 求解策略：设计让两分量（有整体转动）不用稠密解、只警告。实现后的计时改变了这一点：
    • HCO(H2O)10 在 0.1 Ha 第 100 轮已到 1.9e-12，之后停在平台上，跑满 1000 轮（22 s）并发出多余的警告；
    • 小的 HCO 在 0.5 Ha 停在 1.4e-4，只能警告，而稠密解在这个频率是准确的。
    现在有转动或体系大时接受平台残差（≤ 1e-11、100 轮不减半），之后小体系仍用稠密解（第五节）。前者降到 180 轮、4.2 s，不警告；后者 1000 轮后转稠密解。设计文档已改。
  • 平台的原因：起初以为是基态的自洽残差沿转动方向的分量。探针表明右端与转动正交到舍入，平台只在 scc_tol 1e-12 的那个基态出现，于是改成舍入的说法（坑 168）。代码的注释也改了，门槛是在改好之后重新跑的：第一次运行开始 2.5 分钟就停掉了。
  • 警告的原文：加了“或在激发之间”的说法，并给出稠密解需要的 DENSE_LIMIT。
  • 测试：设计的验证清单全部做了，另加平台判据的单元测试（合成算符）与两分量求解器的测试，共 17 项。“强制一个不可达的容差来触发平台”的做法不可靠：残差递推在有的环境里继续下降，所以平台判据改用合成算符测试，三个环境的结果相同。

九、下一步

  • M6h-4d 坐标导数（分子）：交换在固定密度下对坐标的导数进入一阶哈密顿量，用 Born 电荷对解析力的外场差分验证。M6h-4b 时的原型已一致到 3.4e-12–3.9e-11。
  • 不在计划内：有限 η 的展宽（吸收谱）。需要的话可以单列：复对称方程，用 COCG 或 QMR 一类的求解器。
  • 向 DFTB+ 报告 B1、B2、B3、B6、B13、B18–B26：需要你同意再提交 issue。
