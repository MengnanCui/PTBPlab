关键信息

杂化泛函下的坐标导数（DFTB+ 的 CoordDerivatives）现在可以计算：布居对原子位置的导数、Born 电荷、本征值导数，金属另有费米能级的导数。实数路径（闭壳层、共线自旋、金属、+U、onsite、DFTB3、外场与点电荷，三种屏蔽，LC、CAM、全局杂化）与两分量（非共线自旋）都做，只限分子。DFTB+ 拒绝杂化的坐标导数，所以没有 DFTB+ 参考。验证靠 Maxwell 关系：Born 电荷等于解析杂化力对外场的导数，而这些力已与 DFTB+ 对上。M6h 至此全部完成。只有 NumPy 引擎；旧计算逐位不变。

  • Born 电荷对 dF/dE（原子不动，没有 SK 表的折点）：
    • 实数路径的各种组合 ≤ 1.3e-10：H2O LC 3.4e-12，CAM 3.9e-11，全局杂化 1.7e-11，CH3 自旋 4.5e-11，CuCO 300 K（|Z*| 2.6）7.1e-11，+U 3.5e-11，onsite 5.2e-12，DFTB3 1.5e-11，外场加点电荷 2.5e-11，NeighbourBased 2.5e-11，Thresholded（阈值 1e-14）1.3e-12。
    • 两分量：HCO 2.2e-11，HCO 300 K 1.8e-11，外场加点电荷 1.1e-11，DFTB3 + D3 1.3e-11，CH3 1.5e-11。
  • 其余检验：
    • 去掉交换后等于 M6g-2、M6g-3a、M6g-3b（同一基态）：布居 ≤ 1.6e-14，本征值导数 ≤ 3.7e-15，费米能级 1.7e-16。
    • 几何差分（避开 SK 表的折点）：电荷 ≤ 6.5e-10，本征值 ≤ 3.7e-10，金属的费米能级 3.2e-11；CutoffReduction 10 的苯也对（3.5e-10），那里力不是能量的导数，Born 对 dF/dE 用不上。
    • 两分量磁矩沿 z 时等于共线的结果：电荷 4.0e-13，mz 3.3e-12，Born 1.4e-12。
  • 原型的掩码错误：M6h-4b 的原型把 S′ 限制在 “Scam ≠ 0” 的元素上。HCO 的三个原子都在 z = 0 平面上，pz 与其他原子轨道的重叠严格为零，导数却不为零，原型因此差 3.0e-3。实现改用原子对的近邻掩码，Born 对 dF/dE 2.5e-11。

开发细节一、做了什么
位置内容
response_hybrid.py
  • coordinate_derivatives（新）：实数路径与两分量共用。
    • 按原子分批组装 H0′、S′、势在固定电荷下的导数；
    • 显式哈密顿量 He（两分量用旋量的四个分量，块势含虚部的项）；
    • 正交归一的 PN，以及 ρS′ 的 Mulliken 与块布居的 SCC 势；
    • 对空间方程的右端带 −SC(ε̄∘N)C†S，投影后用 MINRES 求解；
    • 布居、本征值导数（简并组取子块的本征值）、金属的费米能级导数、Born 电荷，结果类同 M6g-2。
  • 实数路径与两分量的 kernel 各拆成 _scc_populations（可以给 S′）与 _scc_h，交换另加。运算与顺序不变，静态结果逐位相同。
hybrid.py模块函数 four_terms_lin；HybridTerms.gamma_derivative（轨道层面的 γ′）与 exchange_derivative（S′ 乘原子对近邻掩码，两分量的四个块各 −1/4）。
response.pycoordinate_derivatives 有杂化时转到 response_hybrid（在周期体系的检查之后、两分量的分支之前）。
calculator.py去掉 DFTB+ 的 “Coordinate derivative perturbations do not yet work with hybrid functionals”。
测试新文件 tests/test_hybrid_coord_derivatives.py：26 项；test_hybrid.py 去掉这项拒绝；test_hybrid_response.py 的拒绝改成周期体系。

没有 DFTB+ 参考算例（DFTB+ 拒绝），不加 refgen 的算例。用到的基态都是已与 DFTB+ 对上的参考算例。

二、怎么用

r = DFTB(sk_lc, hybrid="lc", analysis={"coord_derivatives": True}).calculate(labels, pos)
cd = r.analysis.coord_derivatives
cd.atom[K, i, 0, B]       # dN_B / dx_K,i；cd.born[K, i, j] = dμ_j / dx_K,i（物理符号）
cd.eigenvalue_derivatives # (n_K, 3, n_块, n_能级)；金属：cd.fermi_derivatives
DFTB(sk_lc, hybrid="lc", analysis={"coord_derivatives": {"atoms": [0, 2]}})   # 只移动部分原子
  • 范围：分子，M6h-1、M6h-1b 的全部基态组合。周期体系拒绝，同 M6g-2。输出同 M6g-2：detailed.out 的坐标导数块与 dBand_dx.out。
  • Thresholded：导数用筛选的极限（同 M6h-4 的响应）。对阈值 1e-6 的 SCC 做差分会混进筛选噪声：H2O 的 Born 对 dF/dE 差 2.9e-6，阈值 1e-14 时 1.3e-12。
  • CutoffReduction：坐标导数是截断模型自身的导数（S′ 限在 CAM 截断以内的原子对上）。DFTB+ 与 pydftb 的力在这里用不截断的 S′，不是能量的导数，所以两者在截断边界附近不一致，属预期。
  • 耗时（一个线程，只算分析）：
    • (H2O)10（30 个原子，60 个轨道）0.58 s；(H2O)20（60 个原子，120 个轨道）6.2 s，内存 0.29 GB，18 轮。静态极化率分别是 0.01 s 与 0.07 s：坐标导数有 3N原子 个右端，每列还要算一次交换的显式导数。
    • 两分量：HCO(H2O)5（78 个旋量能级）2.8 s；HCO(H2O)10（138 个）18 s，内存 0.47 GB，31 轮。

三、Born 电荷与 Maxwell 关系

Z*K,ij = ∂μj/∂xK,i = ∂FK,i/∂Ej。右边用解析杂化力（M6h-1、M6h-1b 已与 DFTB+ 对上）对外场做四点差分（h = 1e-4 a.u.，加在算例自己的外场上）；原子不动，所以没有 SK 表的折点。基态 scc_tol 1e-13，测试的界 1e-9（绝对）。

  • 原型的掩码：原型把 S′ 限制在 “Scam ≠ 0” 的元素上。苯的几何稍微不平（|z| 到 0.037 Å），没有严格的零，碰巧没有问题（P98b）；HCO 在 z = 0 平面上，pz 的重叠严格为零，原型差 3.0e-3。实现用原子对的近邻掩码（坑 172）。

五、DFTB+ 的情况

DFTB+pydftb 的做法
CoordDerivatives 配 Hybrid：“Coordinate derivative perturbations do not yet work with hybrid functionals”（25.1 与开发版）给出导数，用 Born 对 dF/dE、M6g 的极限、几何差分与共线的极限验证
坐标导数另外拒绝自旋、+U、onsite、SOC、非团簇杂化下照样支持自旋、+U、onsite、两分量（同 M6g-2、M6g-3a、M6g-3b）；周期体系同样拒绝
有 CutoffReduction 或 Threshold 时力不是能量的导数坐标导数是截断模型的导数；Threshold 用筛选的极限

本块没有新的 DFTB+ 问题。

七、与设计的偏差

  • 分批：设计按 RHS_ELEMENTS 分批，与静态求解相同。实测时这里同时存在的数组约为静态求解的两倍（He、PN、N、Kc 加上 MINRES 的向量），所以每批的原子数减半，并在 MINRES 之前释放中间量。HCO(H2O)10 从 23 s、0.75 GB 降到 18 s、0.47 GB，(H2O)20 从 8.2 s、0.45 GB 降到 6.2 s、0.29 GB。
  • 测试的 DFTB3 算例：最小环境与 torch 环境没有 dftd3，所以 Born 的 DFTB3 项改用不带 D3 的 ch3oh_lc_dftb3_pol（结果与带 D3 的相同，1.5e-11）。
  • 分批的比较：起初断言每批一个原子与整批逐位相同。conda 里确实逐位相同，但这依赖 BLAS 对不同列数的实现，所以改成 1e-13。
  • 其余按设计。
