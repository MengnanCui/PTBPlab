关键信息

pydftb 可以在收敛的电荷上求任意 k 点的本征态，给出能带、DOS 和 PDOS。6 个新对照算例全部通过：周期体系的本征值与 DFTB+ 相差 ≤ 1.7e-11 Ha，单原子晶胞和分子 ≤ 3e-14 Ha。

  • 区域投影权重与 DFTB+ 相差 5e-7，正好是区域文件 6 位小数的舍入；在同一输入下，DOS 曲线与 dp_dos 相差 1.3e-11（相对于曲线最大值）。
  • 为了达到上面的精度，统一了两个数值约定：玻尔兹曼常数改用 DFTB+ 25.1 的值；第二阶 γ 的短程部分改在 DFTB+ 的截断处（S < 1e-10）截断。统一后，周期体系的本征值差从 ~1e-9 降到 ~1e-11 Ha，有展宽的算例能量差下降 1–3 个数量级。
  • 发现 DFTB+ 的一个小问题：绝缘体的 k 点权重若不能精确表示（如 1/13），middleGap 累加的权重会比电子数少一个舍入单位，于是跳过能隙，费米能级落到导带底附近。占据数不受影响；pydftb 改为取能隙中点。
  • 接口：SCC.states()、PyDFTB.states()、PyDFTB.band_structure(path=...)；kpts 可以是 ASE 的 BandPath。在进程内算一条能带路径只要 12–46 ms。

二、验证结果

与 DFTB+ 的逐项对照

每个算例照常比较能量、力和电荷，另外比较 SCC 网格上和能带路径上的本征值与占据数、路径上的费米能级、区域权重（按简并组求和），以及冻结的 dp_dos 曲线。周期算例让 DFTB+ 用 EwaldTolerance = 1e-12（它的默认值 1e-9 本身会使水盒子的本征值偏 ~1e-7 Ha）。

验收标准：本征值、占据数、费米能级 ≤ 1e-8；区域权重 ≤ 1e-6；dp_dos ≤ 1e-9。实际结果比标准小 3 个数量级以上。区域权重的 5.0e-7 全部来自 DFTB+ 文件的 6 位小数。

原有 56 个算例全部照常通过。两个数值约定统一后（见三），有展宽的算例和周期算例的差异变小，没有任何算例变差到超出标准；详细数字见 3.1、3.2。

DOS 曲线与 dp_dos

  • 同一输入：把 DFTB+ 写出的 band.out 或区域文件解析后交给 broaden()，与 dp_dos 读同一文件的输出比较，差 ≤ 1.3e-11（dp_dos 只打印 11 位有效数字）。覆盖 Gaussian（默认与 -b）、Fermi、Methfessel-Paxton 2 阶、占据数加权（-w）、自定义网格（-g）和自旋（三列输出）。这几条曲线和它们的输入冻结在 cuo_chain_spin_bands、cu4co_pdos 的参考 JSON 中，离线测试会检查。
  • 端到端：pydftb 用自己的全精度本征值算 Cu fcc 的 DOS，与 dp_dos 读 DFTB+ 文件的结果比较：d 轨道 PDOS 差 1.6e-6（区域文件 6 位小数），总 DOS 差 7.2e-5（band.out 只有 4 位小数）。

测试

conda 环境 167 个测试全部通过（M2d 结束时 147 个）；最小环境（numpy、scipy、ase）151 个通过、16 个跳过（需要 D3/D4 库的算例）。PTBP 的测试除已知的 7 个界面冒烟测试外全部通过。PTBP 损失函数的两个引擎相对差为 8.0e-10（M1 时 1.2e-8），见 3.2 末尾。

三、发现的问题与学到的东西

3.1 玻尔兹曼常数

pydftb 原来用 3.166811429e-6 Ha/K，DFTB+ 25.1 的源码（common/constants.F90）是 3.16681534524639e-6，相对差 1.2e-6。用二进制核实：同一温度分别以 K 和以 Hartree（乘新常数）输入，两次结果逐位相同；乘旧常数则能量差 3e-9 Ha、电荷差 4.5e-9 e。pydftb 和 PTBP 的 utils/engines.py 都改为新值（原计划在 M2f 做，因为它直接影响本阶段的费米能级对照，提前到这里）。

算例（展宽）能量差：旧 → 新 (Ha)电荷差：旧 → 新 (e)
cu4co_300K（Fermi 300 K）1.6e-11 → 1.8e-112.5e-9 → 2.9e-13
cu_fcc_k6（Fermi 1000 K）6.1e-10 → 9.0e-133e-15 → 7e-15
cu8_distorted_k355（Fermi 1000 K）3.4e-9 → 1.8e-122.8e-9 → 3.0e-9
cu8_distorted_k355_gauss_1000K5.6e-10 → 3.9e-112.9e-9 → 2.9e-9
cu_fcc_k6_mp1_3000K2.7e-10 → 2.4e-113.5e-14 → 3.6e-14
cuo_chain_k422（Fermi 500 K）3.8e-9 → 7.0e-94.5e-8 → 4.0e-8

CuO 链在 DFTB+ 的默认 Ewald 精度下由 Ewald 误差主导，原来两个误差部分抵消；Ewald 精度提高到 1e-12 时，新常数把两边电荷差从 5.3e-9 降到 8.2e-10，再统一短程截断后降到 ~5e-11。PTBP 默认不展宽（T = 0 时 kT 取下限 1e-8 Ha，与常数无关），所以默认设置下的 PTBP 结果不受影响。

3.2 短程 γ 的截断

γ 的短程部分 S 随距离指数衰减。DFTB+ 对每一对 U 值求出 S 降到 1e-10 的距离（expGammaCutoff：先倍增再二分，二分精度也是 1e-10），超过这个距离就不算。pydftb 的第二阶项原来一直加到 S < 1e-14。逐一排查的过程（CuO 链，Ewald 精度 1e-12）：

  1. 能带路径上的本征值差 4.9e-10–8.4e-9 Ha，几乎是一个整体平移。
  2. 两边都把 SCC 收敛到 1e-13，差别不变（9.0e-10），排除 SCC 收敛精度。
  3. 用 DFTB+ 自己的输入电荷（WriteChargesAsText）在 pydftb 中建 H，本征值仍差 1.1e-9，说明是哈密顿量本身不同。
  4. 让 DFTB+ 读回收敛电荷并写出实空间 H（ReadInitialCharges + WriteRealHS），用 on-site 对角元减去 on-site 能得到每个原子的 SCC 势：与 pydftb 相差 −0.9e-9（Cu）和 −1.15e-9（O）；水盒子中为 −0.2e-9 到 −0.8e-9。Ewald 精度提高到 1e-16 时不变，排除 Ewald。
  5. 把 pydftb 的短程截断换成 DFTB+ 的规则后，势差降到 ≤ 9e-14。

决定：第二阶项也采用 DFTB+ 的截断（第三阶项在 M2b 已经这样做），两者共用 coulomb.short_cutoff。被截掉的每对贡献 < 1e-10 Ha，对物理结果没有意义，但统一后能逐位对照；截断距离也更短，计算略快。效果：周期算例在 Ewald 精度 1e-12 下能量差从 1.6e-9 降到 6e-11 Ha，本征值差从 ~1e-9 降到 ~1e-11 Ha；DFTB+ 默认 Ewald 精度下的算例仍由 Ewald 误差主导（水盒子 1.3e-7 Ha，与以前相同）；分子不受影响（所有原子对都在截断距离内）。

PTBP 损失函数（tools/engine_parity.py，dataset 模式，已发表的 Cu 参数，66 个结构）：DFTB+ 901629.83202，pydftb 901629.83274，相对差 8.0e-10（M1 时为 1.2e-8）。PTBP 默认不展宽，这里的改善来自短程截断的统一。单次耗时 DFTB+ 188 s、pydftb 125 s。

3.3 DFTB+ 的 middleGap 在舍入时跳过能隙

DFTB+ 的问题：对整数电子数，DFTB+ 先把费米能级试放在能隙中点（dftb/etemp.F90 的 middleGap）：把能级按能量排序，逐个累加 k 点权重，直到不小于填充数 N。k 点权重是 1/13 这样不能精确表示的数时，416 个权重累加得到 31.999999999999904 而不是 32，于是多加了一个导带能级，“中点”落在导带内部；接着的电子数检查不通过，转入二分法。二分法中，能隙内的电子数（Kahan 求和）比 32 少一个舍入单位，于是费米能级一路上移，停在导带底下方约 28 kT 处。

水盒子的 13 点能带路径：DFTB+ 的费米能级是 0.098460 Ha（导带底 0.098460 Ha），能隙中点是 0.065541 Ha。两者填充的态完全相同（占据数差 2.5e-12），能量也不受影响；受影响的只有报告出来的费米能级，例如以它为零点画图时零点会贴着导带底。

pydftb 的做法：累加时允许 1e-9 的舍入（CUM_WEIGHT_TOL），对这类情况给出真正的能隙中点；其他情况结果不变（原有 56 个算例的数值不因此改变）。对照时，绝缘体的路径费米能级改为与“DFTB+ 本征值给出的能隙中点”比较（水盒子 1.3e-12 Ha）。tests/test_smearing.py 有一个专门的测试：旧代码在那里重现 DFTB+ 的行为（导带底下方 3e-7 Ha），新代码给出中点。

3.4 DFTB+ 能带运行的“SCC 未收敛”

DFTB+ 看到 Klines 时把 MaxSCCIterations 的默认值设为 1。只算一轮时，路径 k 点上的输出电荷与读入电荷不同，DFTB+ 判定“SCC 未收敛”并报错退出（CuO 链：SCC 误差 0.066，返回码 1），所以多原子晶胞要写 ConvergentSCCOnly = No。单原子晶胞是例外：原子布居恒等于电子数，SCC 误差恒为 0。设计文档里原来写的是“一律需要”，探测实验后更正。

3.5 简并态的投影权重

简并能级的本征向量可以在简并子空间里任意旋转，单个态的区域权重因此不唯一。若区域在对称操作下不变（如 Cu fcc 的 d 壳层），交叉项为零，单个态的权重也唯一；一般情况下只有简并组的总和唯一。对照时把本征值相差小于 1e-7 Ha 的态归为一组，比较每组的平均权重。

四、与计划的偏差

  • 玻尔兹曼常数的统一从 M2f 提前到本阶段（影响本阶段的费米能级对照）。
  • 短程 γ 截断的统一不在计划内，是排查本征值残差时发现的。
  • 设计文档中“能带运行一律需要 ConvergentSCCOnly = No”不准确，见 3.4。
  • 路径费米能级的验收对绝缘体改为与能隙中点比较，见 3.3。
  • dp_dos 曲线只冻结了两个算例（5 条曲线），因为曲线较大；其余算例用本征值和区域权重对照即可推出曲线一致。
  • 含 f 轨道的能带路径按计划放在 M2g。

六、用法

from ase.build import bulk
from pydftb.ase_calc import PyDFTB

cu = bulk("Cu", "fcc", a=3.61)
cu.calc = PyDFTB("path/to/skf", kpts=(6, 6, 6), temperature=1000.0)
cu.get_potential_energy()                                  # SCC on the grid

bs = cu.calc.band_structure(path="GXWLGK", npoints=100)    # ASE BandStructure, eV
bs.plot(emin=-12, emax=6)

st = cu.calc.states(kpts=(24, 24, 24), projections=True)  # pydftb.bands.States
e, dos = st.dos()                                          # eV, states/eV (dp_dos rules)
e, d_pdos = st.pdos(atoms=[0], shell=2)                    # Cu d shell

PySCF 风格：mf = pydftb.SCC(system, params, kpts=(6, 6, 6)); mf.kernel(); st = mf.states(kpts=path_points)。底层：pydftb.bands.eigenstates(dftb, labels, pos, cell, pbc, result.q_in, kpts=...)，单位为 Bohr 和 Hartree。

参考 JSON 中新增的字段（reference 下）

  • eigenvalues、filling、fermi_levels：SCC 运行的 results.tag，形状 (自旋, k 点, 能级)；
  • band：能带运行的同三项；输入中的 band_kpoints 是 klines() 生成的路径点，klines 是 DFTB+ 输入原样；
  • regions：{文件名: 权重}，文件名规则同 DFTB+（标签.out、标签.壳层.out、标签.壳层.m.out）；
  • levels 和 dp_dos：dp_dos 的输入（解析后的 band.out 或区域文件）、参数、网格起点、点数和各列数值；
  • 文档顶层的 band_hsd 是能带运行的 DFTB+ 输入。
