关键信息

M6h 的第一块：分子的长程校正 LC-DFTB 与 CAM 杂化泛函（含 β = 0 的全局杂化），即 DFTB+ 的 Hybrid = LC {…} | CAM {…}，三种 Screening 都有。能量、哈密顿量、SCC（混合整个 ΔP）、力、共线自旋、重启与电荷文件、结构优化与 MD 都与 DFTB+ 25.1 一致。代码在新模块 hybrid.py，只有 NumPy 引擎；不开杂化时结果逐位不变。

  • 与 DFTB+ 对照：30 个参考算例与 3 条动力学参考全部通过。
    • 总能量差 ≤ 5.0e-11 Ha，力 ≤ 1.6e-12 Ha/Bohr，电荷 ≤ 3.7e-13 e，EFock ≤ 4.7e-11（detailed.out 印 10 位小数）。
    • 30 个算例的 SCC 轮数全部相同，每轮的 SCC 误差在 DFTB+ 印出的 8 位之内（相对 ≤ 2e-5）：混合的向量、第一轮与最少轮数的规则都与 DFTB+ 相同。
    • MD（水、CH3 自旋）每一步的 SCC 轮数都相同（678/678、1149/1149），ΔP 跨几何步沿用；带密度矩阵的 charges.bin/dat 读写与 DFTB+ 逐字节相同。
  • DFTB+ 的行为（第五节）：手册与代码不符（默认 MatrixBased、没有 Global）；SK 文件之间不查 ω 一致；ThirdOrderFull 能用；截断或阈值筛选时力不是能量的导数；静默关掉应力、忽略 TruncateSKRange；拒绝 Thresholded 的重启。
  • 不适合逐轮对照的体系：OH 自由基少数自旋的 π 对半满，交换让对称性按舍入的方向破缺，两个程序到达等价而取向不同的解（能量相同到 1e-11）；Thresholded 的 SCC 在误差降到阈值附近后按舍入走不同的路。参考算例因此换成 HCO、CuH，Thresholded 用 SCC 容差 1e-6。
  • 不支持：周期体系（M6h-3）、Casida/TD-LC（M6h-2）、响应（M6h-4）、非共线自旋、torch 与自动求导；DFTB+ 拒绝的组合照样拒绝。
  • 30 + 3新的 DFTB+ 参考算例与动力学参考，全部通过
  • 0SCC 轮数之差（30 个算例；两条 MD 的每一步）
  • ≤ 5e-11与 DFTB+ 25.1 的总能量之差（Ha）
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
hybrid.py（新）
  • Hybrid（导出为 pydftb.Hybrid）：类型 lc/cam、screening、threshold、cutoff_reduction，校验与 Hybrid.make（字符串、字典或对象）。
  • γ：gamma_hf、gamma_lr、gamma_cam 与三个导数，逐行移植 rshgamma.F90（在位、同 U、异 U 的 Y 子式，阈值 1e-5 Bohr 与 3.125e-6，100 ε 的系数规则），对原子对向量化；U 几乎相同（τ 相差 5 % 以内）时用 Hermite–Genocchi 积分（_yukawa_near 与 coulomb._short_near）。
  • HybridTerms（只依赖几何，进 _Setup.hybrid）：原子对 γ 与按轨道展开的 Γ、稠密 S、P0、CAM 近邻；打包与解包（每个自旋的下三角）；fock（MatrixBased 四个矩阵乘，NeighbourBased 用截断的 S，Thresholded 移植 DFTB+ 的增量构建，只让能过阈值的原子进乘积）；energy；力的两部分 pair_coefficient（dS 的系数）与 gamma_gradient（γ′）。
skf.pySKFile.range_sep：读 RangeSep 段并按 DFTB+ 的规则归类（CAM 0 1 → LC，β = 0 → 全局，α = β = 0 → 没有），DFTB+ 的三种错误。SKSet.has_range_sep、SKSet.range_sep()：每个同核文件与每对元素至少一个方向要有这一段，所有值必须相同。
calculator.py
  • 选项 hybrid；_check_hybrid（DFTB+ 的拒绝用它的原话，未做的注明里程碑）；带 RangeSep 的文件没开 hybrid 时报错，hybrid=False 忽略这一段。
  • _scc_hybrid：混合打包的 ΔP，每轮 H += Hx[ΔPin]（每个自旋），误差 max|ΔPout − ΔPin|，混合后输入布居 = _populations(ΔPin + P0)；DFTB+ 的第一轮（只有自旋时不混合）、最少轮数（自旋或 +U 时 2，给出 q_init 时 1）、最后一轮不混合。
  • DFTBResult.e_fock，terms 的 “Fock”；q_in/q_out = [布居 | 打包的 ΔP]；力：dS 系数加到成对项，γ′ 项按原子加。
  • charge_data、populations_from_file 带密度矩阵；_hybrid_terms 供 _setup 与 bands.eigenstates 共用。
dftbplus_io.pyChargeData.rho：charges.bin/dat 的 ΔPin（每个自旋整个 N × N，按列，每个值一条记录），读写都与 DFTB+ 逐字节相同；k 点的密度矩阵（周期的杂化）拒绝。
bands.pyeigenstates 接受杂化的 q_in，重建含 Hx[ΔPin] 的哈密顿量（SCC.states()、PyDFTB.states()）。
ase_calc.py、api.py、autodiff/api.pyPyDFTB(hybrid=…)（cutoff_reduction 用 Å，字典与 Hybrid 对象都换算）；SCC 重启传整个向量；自动求导拒绝。
validation/
  • make_hybrid_sets.py（新）：由 ptbp_hcocu 生成三套带 RangeSep 的参数，逐字节可重现，写进 PROVENANCE。
  • cases.py：Case.hybrid，容差组 TOL_HYB，30 个算例；dftbplus.py：Hybrid 块、“Energy Fock”；refgen.py：杂化的选项、Fock 项的比较、PyDFTB 的选项；dynamics.py：两边都带杂化，3 条参考。
测试新文件 tests/test_hybrid.py，69 项（参数化后）；test_charges_file.py 的引擎带上杂化选项（DFTB+ 的 3 个杂化电荷文件逐字节往返）。

二、怎么用

from pydftb import DFTB, ParamSet, dftbplus_io

sk = ParamSet("ob2-1-1/shift", max_l={"C": 1, "H": 0, "O": 1}).skset(labels)   # 带 RangeSep 的文件
calc = DFTB(sk, hybrid="lc")                    # MatrixBased（DFTB+ 的默认）
r = calc.calculate(labels, pos, forces=True)
r.e_fock                                        # DFTB+ "Energy Fock"，已计入 energy
DFTB(sk, hybrid="cam")                          # CAM、全局（β = 0）或 LC 的文件
DFTB(sk, hybrid={"type": "lc", "screening": "neighbour", "cutoff_reduction": 4.0})  # Bohr
DFTB(sk, hybrid={"type": "lc", "screening": "threshold", "threshold": 1e-6})
dftbplus_io.write_charges("charges.bin", calc.charge_data(labels, r))   # 带 ΔP，DFTB+ 能读
atoms.calc = PyDFTB(skdir, hybrid="lc", reuse_charges=True)  # Å；几何步之间沿用 ΔP
  • ω、α、β 只取自 SK 文件（与 DFTB+ 相同）；选项只选类型与 Screening。"lc" 要求 LC 的文件，"cam" 三种都接受。
  • r.q_in 是 [布居 | 打包的 ΔPin]，可直接作 q_init；只给布居时 ΔPin = 0（相当于 DFTB+ 读入不带密度矩阵的文件）。
  • 计算量（水团簇，单线程，含力，SCC 容差 1e-8；探针 P44，每轮毫秒数）：
    体系轨道数不开杂化MatrixBasedNeighbourBasedThresholded
    (H2O)84844211
    (H2O)2716211131081
    (H2O)64384487670569
    MatrixBased 每轮多四个 N × N 矩阵乘，几百个轨道时约 1.6 倍；轮数多 1–3。Thresholded 是 DFTB+ 的增量算法，在 pydftb 里是原子对的 Python 循环，慢得多：只为复现 DFTB+ 的数字，要速度就用 matrix。
  • 收敛：本套参数上 LC 的 SCC 一般比不开杂化多 1–3 轮；含 Cu 的分子（d 壳层）慢得多（38–90 轮），+U 较大时（0.15 Ha）两个程序都发散。

四、自洽检查

  • γ 对积分：τ = 3.2 U 的指数密度在倒空间的积分（库仑核与长程核 (1 − e−ωr)/r）与 γHF、γLR 一致到 1.4e-13（同 U、几乎相同的 U（相差 1e-4 与 1e-6）、异 U 三支，R = 0.7、2.5、6 Bohr）：确认 DFTB+ 的长程部分是 Yukawa 型（不是 erf）。在位 γHF = U；ω = 0 时 γLR = 0；R = 100 Bohr 时两者等于 1/R。
  • γ 的导数对中心差分 ≤ 1e-9（各支都在内）。U 几乎相同时 DFTB+ 的异 U 闭式严重抵消，pydftb 改用积分形式（第五节）。
  • 交换矩阵：Hx 线性、对称、自伴（⟨H[D1], D2⟩ = ⟨D1, H[D2]⟩ 到 1e-12），E = ½⟨H[D], D⟩ 的差分等于 Hx（1e-7，差分误差）；四个矩阵乘与 DFTB+ 按轨道对的求和一致到 1e-12。
  • 力对能量的差分（精确 SK 导数，步长 1e-6 Bohr）：LC、CAM、全局、自旋、+U、CuCO 300 K、onsite、外场加点电荷 8 个算例 ≤ 2e-7（差分噪声）。NeighbourBased 截断 10 Bohr 时，力（精确表达式，与 DFTB+ 相同）与能量的差分差 > 1e-6：截断的能量没有一致的导数。
  • Screening 的极限：NeighbourBased 不截断时能量与力等于 MatrixBased（1e-11、1e-10）；Thresholded 阈值 0 等于 MatrixBased（1e-10）；阈值 1e-6 时能量偏离 < 1e-5。
  • 闭壳层按自旋算与不按自旋算：能量、EFock 1e-10，电荷 1e-9。
  • 重启与文件：从 q_in 重启 ≤ 2 轮、能量相同；只给布居时多几轮、能量相同；charges.bin/dat 往返到 1e-14；不开杂化的计算读带密度矩阵的文件时忽略它。
  • 本征态：eigenstates(q_in) 重现 SCC 最后一轮的本征值（逐位；Thresholded 1.3e-6，一次完整的构建对累加的构建）。
  • 旧路径：不开杂化时代码不经过新模块；golden 的所有计算逐位相同（第六节）。

五、DFTB+ 的行为

  • 手册与代码：Screening 默认 MatrixBased（手册写 Thresholded）；没有 Hybrid = Global，全局杂化写成 CAM 加 β = 0 的文件。
  • SK 文件：按物种顺序读每个 A ≤ B 的文件，缺 RangeSep 就报错（另一个方向的文件不查）；类型取第一个物种的文件，ω、α、β 取最后读到的文件，彼此不查一致（ω 不同时静默地用最后一个）。pydftb 要求所有值一致，每对元素任一方向有这一段即可。
  • 组合：只拒绝 ThirdOrder，ThirdOrderFull 能算且结果与 pydftb 一致；静默关掉应力；杂化时静默忽略 TruncateSKRange（pydftb 拒绝）；拒绝 Thresholded 的重启（pydftb 允许，第一次构建用整个 ΔP）。
  • 截断与阈值时的力：分子的梯度总用完整的近邻表与 ΔPout，所以 CutoffReduction > 0 或 Thresholded 时力不是能量的导数（pydftb 照做，测试记录了这一点）。
  • 电荷文件：格式 8 在布居（与块）之后存每个自旋的 ΔPin，整个 N × N 按列，每个值一条记录（文本时每个值一行）；DFTB+ 的矩阵只有下三角，上三角是零。
  • Thresholded 的末尾：SCC 误差降到 ~1e-6 以后，筛选的取舍随舍入翻转，两个程序前 21 轮相同到 1e-8，之后分开（到 1e-10 用 74 对 52 轮，能量仍相同到 2e-11）。
  • 对称性破缺：OH 自由基少数自旋的 π 对只有一个电子；交换（或 +U）让电子占据一个取向的 π 轨道，取向由舍入决定。DFTB+ 落在 py 为主的解，pydftb 落在 px、py 各半的解：能量相同到 1.4e-11，轨道布居差 0.42 e，轮数 17 对 32。这不是任何一方的错误，但这样的体系不能逐轮对照。
  • 奇数电子的 CuCO 加 +U：两个程序前 38 轮相同到 1e-6，之后误差升到 102 的量级；DFTB+ 碰巧在 387 轮收敛，pydftb 500 轮不收敛。换成闭壳层的 CuH（U − J = 0.05 Ha）后 45/45 轮相同。
  • U 几乎相同时的 γ：τA、τB 相差略大于 3.125e-6（MinHubDiff）时，异 U 闭式的分母 (τA² − τB²)³ 让结果失去全部精度：|UA − UB| = 1e-6 时 γLR 错 2.2，1e-5 时 2.6e-3，1e-4 时 2.4e-7（与 M2b 发现的 SCC γ 的问题相同，同一元素的两套参数就会碰到）。pydftb 在 τ 相差 5 % 以内用 Hermite–Genocchi 积分：γHF = 1/r − S（SCC 的短程部分，M2b），γLR = γHF 减去核 e−ωr/r 的积分，其被积函数是 (e−ωr − e−√y r)/(r(y − ω²)) 的三阶导数。这一段与 DFTB+ 不同（DFTB+ 错）；本报告的算例都不在这一段。

七、与设计的偏差

  • 算例（共 30 个与 3 条动力学参考，设计约 20 个与 2 条）：
    • OH 自由基的两个算例（NeighbourBased 加自旋、+U 加自旋）换成 HCO；CuCO 的 +U 换成 CuH（U − J 0.05 Ha）；理由见第五节。
    • c6h6_lc_threshold 的 SCC 容差 1e-6（设计设想允许差 1 轮；实测末尾的差别远不止 1 轮）。
    • 新增 3 个重启算例与第二条 MD（自旋）。
  • 电荷文件：设计拒绝带密度矩阵的 DFTB+ 电荷文件；实现了（格式简单，DFTB+ 的读写都能逐字节对照）。本征态（eigenstates）也加上了交换项（设计没提，原来会丢掉 Hx）。
  • 混合向量：q_in/q_out 为 [布居 | 打包的 ΔP]，不只是 ΔP：几何步之间 DFTB+ 沿用的是布居本身，不按新的重叠重算。
  • 选项类：设计的 HybridSpec 叫 Hybrid，从 pydftb 导出。
  • U 几乎相同时的 γ：设计打算照抄 DFTB+；为与 M2b 的 SCC γ 一致，改用数值稳定的积分形式（第五节）。
  • Thresholded 的速度：照 DFTB+ 的算法写成原子对的循环；块的 max|S| 每个几何只算一次，只让能过阈值的原子进乘积（比最初逐对稠密的写法快 6 倍（162 个轨道）到 24 倍（384 个），能量与轮数逐位相同）；仍比 MatrixBased 慢 7 倍左右，只为复现 DFTB+。
