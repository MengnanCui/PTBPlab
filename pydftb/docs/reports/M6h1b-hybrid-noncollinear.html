关键信息

M6h-1 的 LC/CAM 杂化泛函加上非共线自旋（两分量），DFTB+ 支持的范围（MatrixBased、分子、不加自旋轨道耦合）全部做了：ΔP 是 2N × 2N 的复 Hermite 自旋矩阵，SCC 混合它下三角的实部与虚部，能量、力、展宽、+U 与 onsite、外场、点电荷、溶剂、DFTB3、色散、混合器、重启、本征态、结构优化与 MD 都能用。只有 NumPy 引擎；不开杂化或不用两分量时结果逐位不变。

  • 与 DFTB+ 对照：10 个参考算例与 1 条 MD 参考全部通过。
    • 总能量差 ≤ 8.0e-11 Ha，力 ≤ 2.9e-12 Ha/Bohr，电荷 ≤ 1.7e-11 e，磁矩 ≤ 3.5e-11（O2 90° 除外，见下）。
    • 9 个算例的 SCC 轮数相同，每轮误差在 DFTB+ 印出的 8 位之内；MD 40 步每一步的轮数都相同（1150/1150）。
  • DFTB+ 25.1 的三处问题（第五节；每一处都把 pydftb 照 DFTB+ 改一行，就精确复现了 DFTB+ 的数）：
    • +U 与 onsite：混合之后 DFTB+ 的块布居一直是第一轮输出的。HCO 的能量高 2.46e-3 Ha（+U）与 1.33e-3 Ha（onsite），pydftb 等于共线的结果（DFTB+ 自己的共线计算也是这个值）。
    • 混合之后的输入布居只用左下自旋块：自旋还在转动的 SCC（O2 两个自旋从 90° 出发）走另一条路，DFTB+ 20 轮、pydftb 16 轮，能量与力相同。
    • 力：γ 部分只用了 Pauli 分量的实部。H3 三角形停在 120° 的非共线态，DFTB+ 的力偏 1.1e-5 Ha/Bohr，pydftb 的力等于能量的差分（1.4e-9）。
  • 电荷文件：DFTB+ 不为非共线杂化写电荷文件，能读入不带密度矩阵的文件；pydftb 相同（charge_data 拒绝）。
  • 不支持（与 DFTB+ 相同）：NeighbourBased 与 Thresholded 加非共线、自旋轨道耦合、周期体系。
  • 10 + 1新的 DFTB+ 参考算例与 MD 参考，全部通过
  • ≤ 8e-11与 DFTB+ 25.1 的总能量之差（Ha）
  • 3DFTB+ 的问题，每一处都复现到它的数字
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
hybrid.py
  • HybridTerms(…, pauli=True)：密度是一个 2N × 2N 的复矩阵。reference（½ q0 在两个自旋对角块）、pack/unpack（下三角的 [Re | Im]）、新方法 error（复数元素之差的模；共线时 max|Δx|，值不变）。
  • fock：M6h-1 的四项算子作用在 uu、dd、du 三个块上（c = −1/4），ud = du†；energy：½ Re Σ H∘ΔP*（由静态方法改为方法）。
  • pair_coefficient 与 gamma_gradient 的两分量版本（2N × 2N 上取实部，再按 S × 1、Γ 铺满四块归约）；验证用的 _dftbp_pauli_gamma（DFTB+ 的 γ 部分）。
calculator.py
  • _check_hybrid：非共线只许 MatrixBased（DFTB+ 的原话），删去“非共线以后再做”的拒绝；_hybrid_terms 传 pauli。
  • _scc_hybrid：两分量的求解器与哈密顿量（_spinor_hamiltonian、块势时 _block_hamiltonian）加 Hx；复数 ΔPout；误差用 hy.error；第一轮不混合、至少两轮；混合之后由 ΔPin + P0 得到 [q, m] 与块布居。
  • _energies_pauli：EFock 与 [布居 | ΔP] 的 q_in/q_out；_split_hybrid_vector 的两分量版本；charge_data 拒绝、populations_from_file 拒绝带密度矩阵的文件。
bands.pyeigenstates 的两分量分支加 Hx[ΔPin]（共线时 ΔP 的展开改为共轭转置，实数时不变）。
validation/
  • cases.py：10 个算例；Case.forces_fd（参考的力取 DFTB+ 能量的四点差分，另比较 pydftb 的 DFTB+ 兼容模式与 DFTB+ 自己的力）；读电荷算例的 run1_skf_set。
  • refgen.py：上两项的生成与比较；dftbplus.py：run_restart 的 run 1 可去掉 Hybrid 块、换参数集；dynamics.py：支持非共线（pydftb 的选项与 DFTB+ 的输入），一条 MD 参考。
测试tests/test_hybrid.py 新增 10 项（共 79 项）。

二、怎么用

calc = DFTB(sk, hybrid="lc", spin="noncolinear", spin_constants=W,
            initial_spins=[[0, 0, 0], [0.48, 0.6, 0.64], [0, 0, 0]])
r = calc.calculate(labels, pos, forces=True)
r.e_fock, r.magmoms                      # E_Fock（已计入 energy），(n_atom, 3) 的磁矩
calc.calculate(labels, new_pos, q_init=r.q_in)   # 沿用 [q, m] 与复数 ΔP_in
atoms.calc = PyDFTB(skdir, hybrid="lc", spin="noncolinear", reuse_charges=True)
  • 只能用 MatrixBased；不能加 spin_orbit；只用于分子。q_in 是 [布居 | 2N × 2N 下三角的实部 | 虚部]，长度比共线时大约多一倍。
  • 没有自旋轨道耦合时任何共同方向都是解：自旋从一个方向出发就停在那个方向（与共线的计算相同），从不同方向出发时停在哪个方向取决于 SCC 的路径。
  • 电荷文件：charge_data 拒绝（DFTB+ 不写）；可以从不加杂化的非共线计算写的文件开始（ΔPin = 0）。

三、与 DFTB+ 的对照

参数 ptbp_hcocu_lc、ptbp_hcocu_cam（M6h-1），DFTB+ 25.1，两边 SCC 容差 1e-10（H3 1e-12），pydftb 用 DFTB+ 的 SK 差分步长。容差同 M6h-1：能量、力、电荷、磁矩 1e-8，SCC 轮数 0，每轮误差 1e-4（相对）。自旋常数是 M6h-1 的 HCO 一组（WHCO），初始自旋除注明外放在一个原子上、方向 (0.48, 0.6, 0.64)（不沿任何轴，ΔP 是复数）。

四、自洽检查

  • 交换矩阵：两分量的 Hx 等于显式的 2N × 2N 公式（S × 1、Γ 铺满四块、c = −1/4）到 1e-12，是 Hermite 的，E = ½ Re⟨H[D], D⟩ 的差分等于 Hx；块对角的实数 ΔP 给出共线两个通道的 Hx。
  • dS 系数对 S 的差分（ΔP 的左下块不对称、对角块有虚部）相对 1e-6 以内；力对能量的差分：HCO（复数 ΔP）与 H3 120°（Pauli 分量有虚部）在 M6h-1 的 8 个算例之外加入，≤ 5e-7（差分噪声）。
  • 与共线等价：自旋沿 z 或斜着时，能量、EFock、力、电荷都等于共线的计算（1e-9、1e-8），磁矩是共线的磁矩乘以起始方向；+U 与 onsite 等于共线的 +U（M6h-1 的 hco_lc_plusu_spin）与 onsite（hco_lc_onsite_spin）。
  • 重启与文件：从 q_in 重启 ≤ 2 轮；只给布居时多几轮、能量相同；charge_data 拒绝；不加杂化的非共线文件能读入，带密度矩阵的拒绝。
  • 本征态：eigenstates(q_in) 重现 SCC 最后一轮的本征值（1e-12）。

五、DFTB+ 的问题

三处都用同一个办法确认：把 pydftb 的那一处照 DFTB+ 的代码改掉（探针 P49、P51b），就复现了 DFTB+ 的数；pydftb 保留一致的做法。

七、与设计的偏差

  • 设计文档在原型完成之后写成，实现照它做；参考算例比设计第一版的 7 个多了 3 个（外场与点电荷、DFTB3 与 D3、共线的 onsite 加自旋），因为探针 P52 发现 onsite 与 +U 一样受 DFTB+ 冻结块的影响，需要一个 DFTB+ 的共线对照值。
  • 新增 Case.forces_fd：做法与 M6f-3 卤素修正的 forces_fd 相同（参考存 DFTB+ 能量的差分，兼容模式对照 DFTB+ 的力），卤素算例不变。
