关键信息

pydftb 有了空间分治的求解器 Subsystems（新模块 subsystems.py）。体系被切成子体系：一块核心区加上它周围的缓冲区，单位是成键的片段。每个子体系在全局 H(k)、S(k) 的主子矩阵上单独做本征分解，再按分区矩阵把各自的密度矩阵拼回 M7c 的图样（Yang 与 Lee 的分治密度矩阵，Nakai 组的 DC-DFTB）。所有子体系的态带着核心权重共用一个化学势，按 DFTB+ 的规则求。子体系分给本机的工作进程（processes=n）或多台机器上的 MPI 进程（processes="mpi"，可选的 mpi4py），结果与进程数无关，逐位相同。DFTB+ 没有这种求解器，对照用 pydftb 的本征分解。别的求解器不变，旧路径逐位不变。

  • 精确极限：缓冲区覆盖全部原子时（buffer=float("inf")）等于本征分解。14 种哈密顿量（分子、Γ 点、k 点、两种共线自旋、300 K、固定费米能级、每个 k 单独填充、DFTB3、溶剂、外场、点电荷、位点电势）的能量差 ≤ 4.3e-14 Ha，电荷 ≤ 7.5e-14 e，力 ≤ 1.5e-14 Ha/Bohr，应力 ≤ 1.8e-17，费米能级 ≤ 1.1e-14 Ha，SCC 轮数相同。在这个极限下，refgen --check --solver subsystems 通过全部 144 个适用的 DFTB+ 参考。
  • 精度由缓冲区决定（真实的水：DFTB+ 测试用的 mio-1-1，216 个分子，先弛豫）：6 Å 时电荷差 1.9e-5 e、力差 3.2e-5 Ha/Bohr；8 Å 时 1.3e-7 与 5.5e-8，相当于 M7c 截断 1e-6 的稀疏路径。216 个水分子的 NVE（6 Å，每步重新分区，4 个进程）与本征分解的轨迹每步相差 ≤ 7.6e-6 Ha，Verlet 自身的起伏是 5.8e-3 Ha，SCC 轮数相同。
  • 速度（本机 4 核，M7c 的水盒子，SCC 加力）：1000 个水分子、缓冲 6 Å、4 个工作进程共 115 s，本征分解 404 s，稀疏路径 219 s；其中分治本身 63 s。缓冲 8 Å 时 287 s，比稀疏路径慢 1.3 倍。1728 个水分子、6 Å 共 216 s：稀疏路径 411 s，本征分解估计约 1800 s。分治的求解每轮每个水分子 3.9 ms，随 N 线性。
  • 多机：mpiexec -n 3 python -m pydftb.subsystems script.py 与主进程串行的能量、电荷、力与应力逐位相同；本机 1、2、4 个工作进程也一样。
  • 不适用的：
    • 金属：Cu 在 1000–3000 K 时缓冲到 5 Å，每个原子仍差 4e-4–7e-4 Ha。
    • 缓冲小于 6 Å 且 T = 0 时，SCC 可能不收敛，要加电子温度。
    • 更大的体系卡在 Ewald 的建立阶段（与稀疏路径共用），由紧接的一块 M7d2 处理。
  • 144 / 144适用的 DFTB+ 参考在精确极限下通过
  • ≤ 4.3e-14精确极限对本征分解的能量差（Ha）
  • 115 s1000 个水分子 SCC 加力（4 个进程；本征分解 404 s）
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
subsystems.py（新）
  • 分区：bonded_fragments（ASE 的共价半径，d < 1.2 (ra + rb)，含周期像，connected_components），grid_cores（沿晶格矢量分格子，片段按第一个原子归入），subsystem_atoms（含周期像的邻居表），partition。片段大于 max_unit（64 个原子）时按原子。
  • 图样上的子体系：_index 用一个存着位置编号的 CSR 矩阵取出子体系块的 (行, 列, 图样位置)，以及分区系数 p > 0 的那部分；eig_subsystems（hegvd，核心权重），density_subsystems（占据的列，一次 GEMM，按 p 加到图样上）。
  • 化学势：chemical_potential 是 DFTB+ 的 Efilling 推广到带权重的能级：带隙中点规则（几个子体系里同一能级的拷贝算一个能级），否则二分；DFTB+ 的 1e-15 截断，按权重的熵，电子数的重新归一。
  • 执行：_Serial（本进程，BLAS 单线程），_Workers（fork 的工作进程，管道），_MPI 与 serve()（mpi4py），python -m pydftb.subsystems script.py。
  • Subsystems(buffer=6.0, core=6.0, units="auto", processes=None, max_unit=64)：set_geometry、prepare、density；诊断量 n_subsystems、sizes、last_count_error、timings。
calculator.pysolver="subsystems" 建默认的对象；_setup 在 M7c 的图样之后调用 set_geometry；_check_subsystems（M7c 的拒绝，抽成 _pattern_refusals，加上非 Fermi 的展宽）；_solve_subsystems：无自旋、各通道的 μ、relax_total_spin 的共用 μ、固定费米能级、每个 k 单独填充；_check_filling 放开 Subsystems。布居、能量、力与应力是 M7c 的稀疏分支，不改。
solvers.pySOLVERS["subsystems"] = Subsystems。
validationrefgen --check --solver subsystems：精确极限（Subsystems(buffer=inf)），不适用的算例按 subsystems_skip 打印原因跳过。
pyproject.toml可选依赖 mpi = ["mpi4py"]。
测试新文件 tests/test_subsystems.py：25 项（见第六节）。

二、怎么用

from pydftb.subsystems import Subsystems
DFTB(sk, solver=Subsystems())                           # 核心 6 Å、缓冲 6 Å，本进程
DFTB(sk, solver=Subsystems(buffer=8.0, processes=4))    # 4 个本机工作进程
DFTB(sk, solver=Subsystems(processes="mpi"))            # mpiexec -n 17 python -m pydftb.subsystems run.py
DFTB(sk, solver="subsystems", temperature=300.0)        # 默认参数，300 K
PyDFTB(skdir, solver=Subsystems(processes=4))           # ASE：每一步重新分区
  • 缓冲区：默认 6 Å，真实的水电荷约 2e-5 e、力约 3e-5 Ha/Bohr，MD 的能量守恒与本征分解相同；8 Å 与 M7c 截断 1e-6 的稀疏路径同等精度（第四节）。小于 6 Å 时给一个电子温度（300 K 就够）。
  • 进程：processes=None（默认）在本进程里逐个对角化，BLAS 单线程；processes=n 起 n 个工作进程，本机核数个最快（第五节）。线程没有用：SciPy 的广义本征求解不释放 GIL。
  • 多机：pip install pydftb[mpi]（mpi4py）。0 号进程运行脚本，其余进程服务：mpiexec -n N python -m pydftb.subsystems run.py，脚本不用改；或者在脚本开头写 if pydftb.subsystems.serve(): sys.exit()。
  • 能用的：M7c 稀疏路径能用的全部（分子、Γ 点、k 点；无自旋与共线自旋；DFTB3、H 阻尼、H5、色散、外场、点电荷、位点电势、溶剂、卤素与偶极修正、自定义 Hubbard 与参考占据、混合器、电荷文件、类型切换；力、应力、优化、MD），加上 T = 0 与 T > 0 的 Fermi 填充、relax_total_spin、固定费米能级、每个 k 单独填充。
  • 报错的：M7c 拒绝的那些（两分量、+U 与 onsite、杂化、Casida、分析输出、XL-BOMD 的力、torch），以及 MP 与 Gaussian 展宽。
  • 结果：没有本征值与占据数；fermi 是化学势，有限缓冲时一般在带边（二分让跨过电子数的那一级取分数占据）。solver.n_subsystems、solver.sizes（每个子体系的轨道数）、solver.last_count_error、solver.timings。

四、有限缓冲区的精度

探针 P112–P115（设计文档第二节）的原型与这里的实现用同样的分区（水分子就是成键的片段），所以设计里的误差表照样成立。实现之后的核对：

  • M7c 的计时盒子（P119，ptbp_hcocu 的参数，没有弛豫，核心 6 Å，第五节的运行）：
    • 1000 个水分子对本征分解：6 Å 时每个原子的能量差 6.6e-10 Ha、电荷 2.0e-6 e、力 4.0e-7 Ha/Bohr；8 Å 时 4.1e-12、4.9e-7、4.4e-7。同一盒子上稀疏路径 1e-6 是 3.4e-10、2.4e-6、1.4e-6。
    • 最大值由个别原子决定：力差的中位数 6 Å 时 3e-9、8 Å 时 6e-10，99% 分位 8e-8 与 2e-8；8 Å 的最大力差落在另一个原子上，没有比 6 Å 小。
    • 1728 个水分子 6 Å 对 M7c 截断 1e-7 的稀疏结果（它对本征分解约差 1e-8）：6.1e-10、1.8e-6、2.7e-7。
    • SCC 轮数全部与本征分解相同（16 轮）。
  • 测试（test_finite_buffers，64 个水分子，核心 4 Å）：4 Å 时电荷与力 < 2e-4，6 Å 时 < 1e-6，SCC 轮数与本征分解相同，电子数的误差 < 1e-9。
  • 真实的水（P115d，mio-1-1，216 个分子，先弛豫）：缓冲 4、5、6、8 Å 时电荷差 5.2e-3、1.0e-4、1.9e-5、1.3e-7 e，力差 8.4e-3、2.0e-4、3.2e-5、5.5e-8 Ha/Bohr；M7c 截断 1e-6 的稀疏路径 1.1e-7 与 8.2e-8。
  • MD：
    • 64 个水分子（P115c，原型，100 步）：6 Å 时总能量漂移 2.7e-4 Ha/ps（分区固定）与 2.8e-4（每步重分），本征分解 2.8e-4；4 Å 时 1.0e-2 与 2.3e-2。
    • 216 个水分子（P120，这里的实现）：缓冲 6 Å、核心 4 Å，每步重新分区（121–122 个子体系，平均 323 个轨道），4 个进程，0.5 fs，60 步，与 P115e 的本征分解同一起点与初速度。每一步的总能量与本征分解的轨迹相差 ≤ 7.6e-6 Ha（终点 5.6e-6），Verlet 自身的起伏是 5.8e-3 Ha。漂移 9.7e-3 Ha/ps，本征分解 9.9e-3：60 步太短，漂移由起伏决定。SCC 平均 10.0 轮、最多 13 轮，与本征分解相同。
    • 每步 11 s，本征分解 4.9 s：这个大小（1296 个轨道）上本征分解更快，分治要到上千个水分子才划算（第五节）。

  • 对本征分解与稀疏路径（6 Å、4 个进程）：1000 个水分子的求解 63 s，本征分解 336 s、稀疏路径 156 s（快 5.3 与 2.5 倍）；总计 115 s 对 404 s 与 219 s（3.5 与 1.9 倍）。1728 个水分子总计 216 s，稀疏路径 411 s（1.9 倍），本征分解按一次对角化估计约 1800 s（约 8 倍）。
  • 进程的加速：4 个进程时子体系的本征分解 181 → 51 s（6 Å，3.5 倍）、800 → 213 s（8 Å，3.8 倍），子体系越大越接近 4 倍。总计的加速小一些（6 Å 时 2.2 倍）：邻居对、γ 与力（约 50 s）不在分治里。线程不加速（P116b：SciPy 的广义本征求解不释放 GIL）。
  • 8 Å：子体系平均 1086 个轨道，本征分解是 6 Å 的 4.2 倍（m³ 是 5.1 倍）。4 个进程共 287 s，比稀疏路径 1e-6 慢 1.3 倍；在这个盒子上它的误差比稀疏 1e-6 小（第四节），在真实的水上两者相当（P115d）。
  • 逐位相同：1000 个水分子 6 Å 与 8 Å 时，本进程与 4 个工作进程的能量、电荷与力逐位相同。
  • 内存：主进程的峰值出现在建立 γ 的阶段，与本征分解、稀疏路径相近（1728 个水分子 9.7 GiB，稀疏路径 9.3 GiB）。本进程运行时，主进程还要存所有子体系的 C（8 Å 时 125 × 1086² × 8 B ≈ 1.2 GB，峰值 6.7 GiB）；用工作进程时这些分在各进程里，表中的峰值不含工作进程。
  • 与原型（P116，同样的盒子与参数）：1000 个水分子 4 个进程 115 s 对 119 s，1728 个 216 s 对 232 s。分区改用 ASE 的共价半径找成键片段，与原型按 O–H 距离找的分子相同；缓冲区的边界条件稍有不同，子体系的平均轨道数差 1–3 个，能量差 5e-9 Ha。

  • 分区：跨晶胞边界的分子保持完整，核心与缓冲区按整个分子进出；缓冲区经过周期像（最小像）；金属是一个大片段，"auto" 改按原子，"fragments" 保留整个。

  • ASE 计算器的两步（每一步重新分区）对本征分解；拒绝的原文；torch 拒绝。

七、与设计的偏差

  • MPI 的通信：设计写数值数组用 Bcast 与 Reduce（缓冲区接口）。实现用 mpi4py 的小写方法（bcast、scatter、gather，经 pickle），0 号进程按进程的固定次序相加：与本机工作进程是同一套消息，求和次序也一样，逐位相同的论证不用另做。传输量与本机相同（每轮每个进程一份 H 的图样数值），几千个水分子以内不是瓶颈；需要时再换缓冲区接口。
  • 本机工作进程的下标：设计写工作进程自己建立子矩阵的下标。本机的工作进程在 fork 时从主进程继承建好的下标；MPI 的进程照设计自己建。
  • 费米能级的选项：设计没有提 smearing 的 fermi_level。实现照用："dftb+"（默认，带隙中点规则）与 "exact"（总是二分到电子数）。
  • T = 0 的填充：设计写 “跨过电子数的那一级取余数”。实现用 DFTB+ 自己的二分（kT = 1e-8，pydftb 的约定），效果相同：那一级的拷贝能量相同、占据相同，其余的态是 0 或 1。
  • 216 个水分子的 MD：设计时串行原型太慢没有跑完，这里用实现与 4 个进程补做（第四节）。
  • 其余按设计：范围、分区、分区矩阵、两次交换、本机与 MPI 两种传输、拒绝的项目、可选的 mpi4py。
