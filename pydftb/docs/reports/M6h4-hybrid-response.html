关键信息

pydftb 的响应分析（M6g 的静态极化率、响应核与点电荷导数）现在也能用于杂化泛函：分子与周期体系的 Γ 点，LC、CAM 与全局杂化，三种屏蔽，以及共线自旋、金属、DFTB3、+U、onsite、外场与点电荷。一阶密度矩阵的交换进入一阶哈密顿量，响应写成占据–空轨道对空间里的对称方程，用批量的 MINRES 同时解所有方向或所有原子，每轮做一次批量的交换构建。只有 NumPy 引擎；不加杂化的计算逐位不变。

  • 与 DFTB+ 对照：37 个参考算例全部通过（25.1 的 34 个，开发版的 3 个）。
    • 比较 DFTB+ 的全部响应输出：极化率、dq/dE、dε/dE、核 dq/dV、在位布居、dε/dV、NF、dEF/dE、点电荷导数，以及 detailed.out 的表。分子 ≤ 1.4e-10，Γ 点 ≤ 5.8e-9（最大的是不稳定的金属 Cu4 的在位布居，DFTB+ 自己迭代了 55 轮；其余 ≤ 2.0e-9）。
    • 基态的能量差 ≤ 9.3e-11 Ha，SCC 轮数全部相同。
  • 独立检查（不靠 DFTB+）：
    • 与 pydftb 自己的有限场、格点势与点电荷位置的差分相比：极化率 ≤ 1.5e-9（相对），核 ≤ 1.1e-11。
    • 与 TD-LC Casida 对全部单重态求和得到的静态极化率相比：一致到 ≤ 6.0e-13（H2O 1.2e-14）。
    • 去掉交换后等于 M6g 的直接解（≤ 1.6e-13），RPA 等于 M6g 的裸 χ0（≤ 1.3e-14）。
  • 不稳定的基态：响应方程对称，但交换是负的，可能让它不定。Γ 点的 Cu4（1000 K）与自旋的 CuCO（300 K）的 SCC 解是鞍点，方程分别有 5 个与 3 个负本征值。原型的共轭梯度在这里失败，改用 MINRES，并警告“基态是鞍点”；两者都与 DFTB+ 一致。
  • DFTB+ 的问题（第五节）：
    • B24、B25：k 点杂化的响应核、非共线杂化的极化率段错误。pydftb 拒绝到 M6h-4b。
    • B26：杂化时响应 SCC 从不更新块布居，+U 与 onsite 的块势不响应（开发版也是），α 差 2.8–13 %。
    • B27（25.1）：响应 SCC 把点电荷的静电势加进每一个一阶势，有没有杂化都一样，α 与核差约 4 %；开发版已修。
    • pydftb 默认给正确的物理（与 DFTB+ 自己的有限场一致到 ≤ 1.1e-9），两个只供验证的开关复现 DFTB+。
  • 不支持（M6h-4b）：k 点、非共线、有限频率、坐标导数（DFTB+ 拒绝或崩溃）。SOC 配杂化连基态都不支持（DFTB+ 拒绝，pydftb 照做）。
  • 37新的 DFTB+ 参考算例，全部通过
  • ≤ 1.4e-10分子的响应与 DFTB+ 之差（Γ 点 ≤ 5.8e-9）
  • 2–53MINRES 的轮数（每轮一次批量的交换构建）
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
response_hybrid.py（新）
  • HybridResponse：
    • 基态：M6g 的 GroundState；每个块 D = √(−f w W)。
    • 费米组：一个通道，或 RelaxTotalSpin 时两个通道一组，u ∝ √(w δ)。
    • t_apply（P1 = −C (D ∘ z) CT）与 t_adjoint（D ∘ (CT H C)，窗口的对角元投影到与 u 正交）。
    • 批量的核：γ 与三阶的 Hessian、自旋 W、块势（对偶块布居经 M6g-3a 的块核，以 ½(SV + VS) 进入）、交换。
    • _minres：Paige 与 Saunders 的 MINRES（Lanczos 过程加 Givens 旋转，与 SciPy 的 minres 相同），每轮乘一次 A，相对残差 1e-13，最多 1000 轮，Lanczos 向量的 Rayleigh 商为负时记下并警告。
    • solve：右端按 r·n2 ≤ 2·106 分块；输出布居、在位布居、本征值导数（简并组取块的本征值）与费米能级导数。
  • polarisability、response_kernel（含 RPA）、external_charge_derivatives：返回 M6g 的结果类；有限频率时报 DFTB+ 的原话。
hybrid.pyHybridTerms.response_fock：无状态的精确交换，可带批量维；Thresholded 用 CAM 截断以内的 S（它的增量的极限），不碰筛选的状态；两分量时报错（M6h-4b）。
response.py
  • 三个入口在有杂化时转到 response_hybrid。
  • point_charge_shift，以及非杂化路径上 B27 的开关：打开时把点电荷的势加到极化率与核（非 RPA）的扰动上；默认关闭，逐位不变。
calculator.py
  • _check_hybrid：去掉 M6h-4 的拒绝；有限频率按 DFTB+ 的原话拒绝；非共线配响应拒绝到 M6h-4b。
  • _check_periodic_hybrid：k 点配响应拒绝到 M6h-4b。
  • 只供验证的类属性 _response_blocks_compat（B26）与 _response_pc_compat（B27）。
validation/
  • cases.py：37 个算例，由已有的杂化基态加上响应分析；TOL_HRESP、TOL_HRESP_COMPAT。
  • refgen.py：M6g-3b 的 skew_compat 推广成 RESPONSE_COMPAT（blocks_compat、pc_compat）。先比 pydftb 自己的结果与 DFTB+ 的有限场（pol_fd）、DFTB+ 的解析值（pol_dftbp、kernel_dftbp，即 DFTB+ 的误差），再打开开关比全部输出。
测试
  • 新文件 tests/test_hybrid_response.py：33 项（第四节）。
  • tests/test_hybrid.py：M6h-4 的拒绝换成有限频率与两分量的拒绝。

二、怎么用

calc = DFTB(sk_lc, hybrid="lc", analysis={"polarisability": True})
r = calc.calculate(labels, pos)
r.analysis.polarisability.tensor[0]                 # d mu_j / d E_i，与 M6g 相同的结果类
DFTB(sk_lc, hybrid="cam", plus_u=..., point_charges=pc,
     analysis={"response_kernel": True, "external_charge_derivatives": True})
  • 范围：分子与 Γ 点；静态（frequencies 只能是 0）；所有屏蔽、自旋、金属、DFTB3、+U、onsite、外场、点电荷与格点势；RPA 的核。
  • 与 DFTB+ 不同之处：
    • +U 与 onsite 的块势参与响应（DFTB+ 不，B26）。
    • 点电荷的静电势不进响应（DFTB+ 25.1 进，B27）。
    • Thresholded 给精确的响应：DFTB+ 的 α 带着它的筛选误差，H2O 偏 3.9e-6。
  • 鞍点上的基态：热的金属或开壳层的 d 体系，交换可能让 SCC 的解成为鞍点。这时 pydftb 警告，给出的仍是这个驻点的响应（与 DFTB+ 相同）。
  • 耗时：每轮每个右端一次交换构建。240 个轨道的 (H2O)40（LC，一个线程，19 轮）极化率 0.5 s，核（120 个原子）23 s、内存 0.4 GB。

三、与 DFTB+ 的对照

基态是已有的杂化算例（ptbp_hcocu_lc、_cam、_global），加上 Analysis 块；DFTB+ 的响应收敛到 PerturbSccTol = 1e-11。容差 TOL_HRESP：极化率与 dq/dE 1e-8，核 1e-9，基态同 M6h（能量 1e-8，SCC 轮数相同）。下表的“响应”是各项输出中最大的差；“DFTB+ 的误差”是 pydftb 默认的结果与 DFTB+ 解析值的相对差，“有限场”是它与 DFTB+ 自己的有限场（四点公式，h = 5e-4 a.u.）的相对差。

四、自洽检查

tests/test_hybrid_response.py 的 33 项（不需要 DFTB+）：

  • 方程：
    • H2O、CH3 自旋、H2CO +U、CuCO 金属、CO2 晶体 onsite 的稠密 I + TTKT 对称到 1e-13（相对），并且正定。
    • MINRES 与稠密直接解相同：H2O 4.2e-16、CuCO 5.7e-14、不定的自旋 CuCO 1.3e-13（相对），后者给出警告。
    • 分块的右端（每块一个）与一起解的结果相同到 1e-12。
  • M6g 的极限：
    • RPA 等于 M6g 的裸 χ0（≤ 1.3e-14，含金属与 Γ 点 onsite）。
    • 去掉交换后等于 M6g 的直接解，≤ 1.6e-13。覆盖自旋 W、+U、DFTB3 的 Hessian、金属的费米移动、Γ 点 onsite、金属 +U。
  • 差分（scc_tol 1e-13，四点公式）：
    • 极化率对有限场：H2O、CH3 自旋、CuCO 金属、H2CO +U、HCO onsite 自旋、CH3OH 外场加点电荷，相对差 ≤ 1.5e-9（金属），其余 ≤ 2.5e-10。
    • 核对 Gross 格点势：CO2 晶体 onsite 4.8e-12，H2CO +U 1.1e-11。
    • 点电荷导数对移动点电荷：H2O。
  • TD-LC 的求和：αij = 2 Σn μn,i μn,j / ωn 对全部单重态（精确解），H2O 与 CH3OH 与 CPKS 的 α 相同到 1e-10 的界（实测 1.2e-14 与 5.9e-14；C6H6 的 225 个态 6.0e-13）。
  • 屏蔽与开关：
    • Thresholded 的响应算符等于 MatrixBased 的四项公式（1e-14），两次计算逐位相同，筛选的状态不变。
    • B26 的开关等于去掉块通道的响应，并且与默认的不同。
    • B27 的开关：dq/dE 正好多出 ΣA vpc,A dq/dVA（1e-10，有与没有杂化）。
  • 拒绝：k 点、有限频率、坐标导数、非共线，各按其原话。

五、DFTB+ 的问题

DFTB+证据pydftb 的做法
B24（新，25.1）：k 点杂化的 ResponseKernel 段错误（复数路径 dRhoCmplx 本来就没有交换项）P90：金刚石 2×2×2 LC，返回码 −11，停在 “Derivative with respect to potential at atom 1”拒绝到 M6h-4b
B25（新，25.1）：非共线杂化的 Polarisability 段错误（dRhoPauli 也没有交换项）P90：HCO LC，返回码 −11，停在 “Polarisabilty for field along x”拒绝到 M6h-4b
B26（新，25.1 与开发版）：杂化时响应 SCC 的 dqBlockIn 从不更新（只有非杂化的分支更新），+U 与 onsite 的块势不响应8 个算例：DFTB+ 的 α 或核差 1.7–13 %；去掉块响应后一致到 ≤ 2e-10；pydftb 带块响应的 α 与 DFTB+ 自己的有限场一致到 ≤ 1.1e-9给正确的物理；_response_blocks_compat 复现
B27（新，25.1）：响应 SCC 从第二轮起用 getShiftPerAtom，其中含点电荷的静电势（extCharges%addShiftPerAtom），收敛后等于把它加到每一个扰动上；与杂化无关，开发版用 isOnlyInternalShifts 修正CH3OH 外场加点电荷：α 差 4.3 %，核差 3.9 %（不加杂化也一样）；开关下 ≤ 2e-12；开发版不开开关就对上给正确的物理；_response_pc_compat 复现 25.1
Thresholded 的响应接着基态的筛选历史（不是错误）α 偏 3.9e-6，轮数 22/17/25 对 12给精确的响应
鞍点上的基态（不是错误）Γ 点 Cu4 1000 K、自旋 CuCO 300 K：响应方程不定；DFTB+ 的混合仍收敛（55 轮）MINRES，警告
TD-LC 的核用未屏蔽的长程 γ（M6h-2，不是错误）C6H6 NeighbourBased 缩减 10 时，Casida 的求和与 CPKS 差 4.3e-3，MatrixBased 6.0e-13照 DFTB+；CPKS 用基态的算符

七、与设计的偏差

  • 求解器：原型与设计初稿用共轭梯度，假定方程正定。实现时两个金属算例在第 31 轮遇到负曲率，稠密的算符确有负本征值（SCC 的解是鞍点），所以改用 MINRES，加了警告与对应的测试；设计文档已改。
  • MINRES 的写法：第一版按共轭残差的写法（递推 r、p、Ap）。第一次门槛运行时，最小环境里 Γ 点 Cu4 的核停在相对残差 1.5e-12，到 1000 轮报错；conda 环境（numpy 与 BLAS 都不同）收敛。共轭残差的递推要除以 rTAr，方程不定时这个数可以接近零；Paige 与 Saunders 的 Lanczos 写法没有这个除法，SciPy 的 minres 也用它。改写后两个环境都在 53 轮收敛，各算例的轮数相同，与 DFTB+ 的差不变；门槛重跑。
  • 算例数：设计约 25 个，实际 37 个。多出的是 P93 的组合（+U 加自旋、onsite、金属 +U、Γ 点的金属与自旋、CAM 三重态、阳离子），以及两个不加杂化的 B27 算例。
  • Thresholded 的文本容差：α 的差 3.9e-6 让打印的数差最后一位，文本容差从 1e-4 放到 2e-4（JSON 里的容差是冻结的，这个算例重新生成）。
  • 差分检查：设计写有限场与格点势的差分，实际也加了移动点电荷的差分（点电荷导数）。

八、下一步

  • M6h-4b：DFTB+ 拒绝或崩溃的四项，都用差分或 Casida 验证。
    • k 点：复数的 P1(k) 与全网格的交换。
    • 非共线：两分量的 P1；没有 SOC 时整体的自旋转动是零模，要从解里去掉。SOC 配杂化的基态 DFTB+ 就拒绝，要先做基态。
    • 有限频率：P1 的对称与反对称部分（X + Y 与 X − Y）都进交换，库仑项只看对称部分。草稿目录里的原型与 TD-LC 对全部单重态的求和一致到 2e-13（相对，H2O、CH3OH、C6H6，含第一激发以上的频率）；离激发能很近时 MINRES 收敛慢，求解器还要再定。
    • 坐标导数：交换在固定密度下的坐标导数。
  • 向 DFTB+ 报告 B1、B2、B3、B6、B13、B18–B26：需要你同意再提交 issue。B27 开发版已修，不必报告。
