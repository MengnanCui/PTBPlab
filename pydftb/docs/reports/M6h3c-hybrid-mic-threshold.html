关键信息

M6h-3b 的 k 点杂化补上 DFTB+ 25.1 余下的两项。一是库仑矩阵 MinimumImage：不截断的 γ，格点和只取 BvK 超胞的 Wigner–Seitz 胞，WignerSeitzReduction 可以缩小超胞。二是 NeighbourBased 的 Threshold：交换按 ΔPin 的增量累加，按阈值筛掉近邻对组合（DFTB+ 在 k 点默认 1e-6）。两种屏蔽下的 MinimumImage 在 DFTB+ 里是两种不同的近似，pydftb 都照它实现：MatrixBased 就是 M6h-3b 的交换，平移换成 WS 向量、核换成完整的 γ；NeighbourBased 重写成显式格胞的核的卷积，用 FFT 求。筛选移植了 DFTB+ 保留近邻对组合的规则与增量累加，结果与 DFTB+ 一样依赖 SCC 的历史；默认仍不筛选。只有 NumPy 引擎；分子、Γ 点与 M6h-3b 的 k 点计算逐位不变。

  • 与 DFTB+ 对照：18 个参考算例全部通过。
    • 能量差 ≤ 5.5e-11 Ha，电荷 ≤ 1.8e-10 e，18 个算例的 SCC 轮数全部相同，每轮误差 ≤ 1.3e-5（相对）；能带重启的本征值 ≤ 1.7e-13 Ha；DFTB+ 给力的 Threshold 算例在 SCC 容差 1e-10 时力差 1.5e-12 Ha/Bohr，停在 2–4e-7 的算例差到 1.7e-8（B5，见第三节）。
    • 覆盖：MatrixBased MinimumImage（金刚石原胞 3×1×2、2×2×2 缩小 1，CAM、全局杂化，CO2 晶体 2×1×1，三斜 CO 2×2×2，能带重启）；NeighbourBased MinimumImage（金刚石 2×2×2 与缩小 1，能带重启）；Threshold 1e-6 与 1e-4（截断与阻尼截断，CO2 晶体，居中的金刚石 2×2×2，筛选的 MinimumImage 固定 20 轮，能带重启，从 DFTB+ 的电荷文件重启）。
  • 超出 DFTB+ 的部分：MatrixBased MinimumImage 的力与自旋（DFTB+ 拒绝），力与能量的差分相差 ≤ 2.1e-9 Ha/Bohr（差分本身的噪声）；DFTB+ 在默认截断无定义的晶胞上连 MinimumImage 也停下（B3，那个截断用不到），pydftb 照算。
  • DFTB+ 25.1 的问题（第五节）：
    • B23（新）：WS 向量是折回晶胞后原子坐标系里的格矢，不按原子对取最近像，所以能量随原子怎样折回晶胞而跳变：金刚石 2×1×1 的一个原子越过晶胞面，MatrixBased 跳 1.82 Ha，NeighbourBased（缩小 1）跳 0.073 Ha，两个程序的跳变一致到 5e-11。MinimumImage 因此不适合结构优化与 MD。
    • B22（新）：NeighbourBased MinimumImage 的交换算符不自伴（相对 23 %），交换矩阵不是能量的导数，力要解响应方程；DFTB+ 也不给，pydftb 拒绝并说明原因。
    • B9、B10 证实：WS 边界上的并列向量都以权重 1 计入；两种 MinimumImage 在金刚石 2×2×2 差 1.1e-3 Ha。默认 Threshold 1e-6 时 MinimumImage 的 SCC 停在 1e-5 的误差上不收敛。
    • 筛选的 SCC 尾巴（不是错误）：增量全部被筛掉以后交换冻结，Broyden 随后有一步几乎为零，下一次更新放大舍入，两个程序的每轮误差从那里分开，能量不受影响；参考的容差停在那一步之前。这时 B5（DFTB+ 的 k 点梯度混用 ΔPin）让力差到 1.7e-8 Ha/Bohr。
  • 不支持：NeighbourBased MinimumImage 的力（B22）；其余同 M6h-3b（Thresholded 屏蔽、非共线自旋、TD-LC、应力、带平移的网格）。

  • ≤ 2.1e-9MatrixBased MinimumImage 的力与能量差分之差（Ha/Bohr，DFTB+ 不给）

开发细节一、做了什么
位置内容
hybrid.py
  • Hybrid：新字段 wigner_seitz_reduction（非负整数，只配 coulomb="minimum_image"）与 neighbour_threshold（None 不筛选，只配 NeighbourBased）；MinimumImage 不收 coulomb_cutoff、gsum_cutoff（DFTB+ 在 MinimumImage 块里不读它们）；make 接受两个新键。
  • wigner_seitz_vectors(nfold, cell, reduction)：generateWignerSeitzGrid 的移植。N′ = max(N − r, 1)；n ∈ [−2N′, 2N′]³ 中度量长度在 n − i∘N′（i ∈ [−2, 2]³）里最小（容差 1e-8 Bohr²）的都保留，包括边界上的并列向量（B9）；按长度稳定排序。
  • KPointHybridTerms：
    • MinimumImage：平移取 WS 向量，核取不截断的 γ；不求默认截断（DFTB+ 求了不用，B3 时停下）。
    • Threshold：fock 走 _screened_fock。ΔΔP = ΔPin − ΔPprev 的超胞数组，pmax = max|ΔΔP|（所有自旋）；screening_groups(pmax) 给出 DFTB+ 保留的近邻对组合，按 est 分组（同组的 p 保留同一个 q 集合），每组用掩码后的 SP、SQ 求四项；H = Hprev + c·H4[ΔΔP]；pmax < 1e-16 时返回 0（B7）；reset 清空历史（每个新几何）。
    • fock_at 改为对 (SP, SQ) 的组求和；不筛选时只有一组，算术与 M6h-3b 相同（逐位）；筛选时是从 ΔP 一次的筛选构建（同 DFTB+ 的能带运行）。
  • NeighbourMinimumImageTerms(KPointHybridTerms)：在折回原子的坐标系里，把 S（CAM 截断以内，加在位单位阵）、WS 胞上的 ΔP 与各显式格胞的 γ 放到 L 网格上（Ld = 2(2hmax + gmax) + 1，卷积不混叠），四项 (S⋆P⋆S)∘γ、((S⋆P)∘γ)⋆S、S⋆((P⋆S)∘γ)、S⋆(P∘γ)⋆S 用 FFT 求，再折回超胞、换回 pydftb 的规范；fock_at 用显式格胞的相位与折回原子的规范 D(k)；筛选同上；力拒绝（B22）。
calculator.py去掉 M6h-3b 对 k 点 MinimumImage 的拒绝；_kpoint_hybrid_terms 按屏蔽选类；k 点的 NeighbourBased MinimumImage 要力时报 DFTB+ 的原话并说明原因；分子配 neighbour_threshold 时报错（DFTB+ 在分子上停下）。
bands.py只改文档字符串：eigenstates 每次新建 terms，任意 k 上的 Hx 由 fock_at 给出；有阈值时是一次筛选构建，不是 SCC 累加出来的交换。
validation/
  • dftbplus.py：hybrid_block 写 WignerSeitzReduction（非零时）与 neighbour_threshold（没有时仍是 1e-100）。
  • cases.py：18 个算例；属性 Case.pydftb_forces（k 点的 NeighbourBased MinimumImage 为假）与 Case.screened_history（k 点的 neighbour_threshold）。
  • refgen.py：pydftb 的运行按 pydftb_forces 要力；screened_history 的算例在 SCC 网格上比较 SCC 自己的能级（第三节 §）。
测试
  • 新文件 tests/test_hybrid_mic.py：27 项（第四节）。
  • tests/test_hybrid_kpoints.py：去掉 k 点 MinimumImage 拒绝的一项参数。

二、怎么用

from pydftb.kpoints import supercell_folding
k = supercell_folding((2, 2, 2))
DFTB(sk_lc, kpts=k, hybrid={"type": "lc", "coulomb": "minimum_image"})        # MatrixBased，有力
DFTB(sk_lc, kpts=k, hybrid={"type": "lc", "coulomb": "minimum_image",
                            "screening": "neighbour", "wigner_seitz_reduction": 1})   # 没有力
DFTB(sk_lc, kpts=k, hybrid={"type": "lc", "screening": "neighbour",
                            "neighbour_threshold": 1e-6})                     # DFTB+ 默认的筛选
  • MinimumImage：只在 k 点（Γ 点按 DFTB+ 的原话拒绝）。wigner_seitz_reduction = r 时取超胞 max(N − r, 1) 的 WS 胞。能量依赖原子怎样折回晶胞（B23）：原子越过晶胞面时能量跳变，结构优化与 MD 中不可用；照 DFTB+ 实现只为对照。MatrixBased 与 NeighbourBased 是不同的近似（B10）。
  • 力与自旋：MatrixBased MinimumImage 给精确的导数，共线自旋也支持（DFTB+ 都拒绝）。NeighbourBased MinimumImage 要力时报错：它的交换矩阵不是能量的导数（B22），能量与 SCC、能带、电荷文件照常可用。
  • neighbour_threshold：None（默认）建完整的算子，与 M6h-3b 相同；给一个数即 DFTB+ 的增量筛选，结果依赖 SCC 的历史（每个新几何从完整构建开始）。偏差的量级：金刚石 3×1×2 时 1e-6 偏 4.8e-6 Ha、1e-4 偏 1.7e-5 Ha，轮数多；MinimumImage 配 1e-6 时 SCC 停在 1e-5 的误差上。Γ 点接受但不起作用（同 DFTB+，B16）；分子报错。力是未筛选的公式在筛选后的密度上（同 DFTB+），不是筛选后能量的导数。
  • 电荷文件与能带：与 M6h-3b 相同（记录与库仑核无关）。能带在任意 k 上建 Hx；有筛选时是从文件的 ΔP 一次的筛选构建，与 DFTB+ 的能带运行相同，不是 SCC 累加出来的交换。

三、与 DFTB+ 的对照

参数与容差同 M6h-3b：ptbp_hcocu_lc、_cam、_global，DFTB+ 的 EwaldTolerance 1e-12，k 点写成不平移的 SupercellFolding；没有 neighbour_threshold 的 NeighbourBased 写 Threshold = 1e-100，有的写它的值。SCC 容差 1e-10，几个算例另设（见表）。

四、自洽检查

tests/test_hybrid_mic.py 的 27 项（不需要 DFTB+）：

  • WS 向量：FCC 2×2×2、3×1×2、3×3×3 各 19、11、43 个，覆盖超胞的每个类、关于 0 对称、按长度排序；缩小到 N′ = 1 时只剩 0；立方晶胞保留全部 27 个并列向量。
  • 筛选的组：screening_groups 覆盖的近邻对组合恰好是 estp·estq ≥ τ 的那些，每个组合只出现一次（5 个 τ，逐个对照暴力枚举）。
  • 算符：
    • 在 SCC 的网格上 fock_at 等于 fock（1e-12）：MatrixBased、NeighbourBased（缩小 0 与 1）、两种筛选；
    • 自伴性：截断的两种屏蔽与 MatrixBased MinimumImage 的 ⟨H[P], Q⟩ = ⟨H[Q], P⟩ 到 1e-12 相对，NeighbourBased MinimumImage 不是（B22）。
  • 力对能量的差分（MatrixBased MinimumImage，h = 5e-5 Bohr，SCC 容差 1e-12）：金刚石 3×1×2、2×2×2 缩小 1、O2 盒子的自旋（原子离开晶胞面，B23），三个环境里最大 2.1e-9；这是差分本身的噪声（能量的 SCC 误差除以 h，h 减半时并不按 h² 变小，四点公式也不更好），测试的界是 5e-9。
  • 一致性：闭壳层的自旋计算等于不加自旋（两种 MinimumImage）；Threshold 1e-100 等于不筛选（截断与 NeighbourBased MinimumImage，1e-12）。
  • 筛选的历史：阈值趋于 0 时增量累加等于完整算子；ΔP 不变时返回 0（B7）；reset 后重复同一密度给出同一结果；阈值很大时什么都不留；中等阈值时先后两个密度的结果与单独一个不同（依赖历史）。新几何从完整构建开始（DFTB+ 的 updateCoords）：接着上一步 q_in 的计算等于从它开始的新计算器，并且与从头算的结果不同。
  • 输入与拒绝：两个新字段的检查与 DFTB+ 输入块（WignerSeitzReduction、Threshold）；MinimumImage 不收截断；a2 沿 z 的晶胞（DFTB+ 停下，B3）用 MinimumImage 能算，等于转动后 DFTB+ 能算的同一体系（1e-9）；NeighbourBased MinimumImage 的力、Γ 点的 MinimumImage、分子的 neighbour_threshold 报错。

五、DFTB+ 的问题

DFTB+ 25.1证据pydftb 的做法
B23（新）：MinimumImage 的 WS 向量是折回晶胞后原子坐标系里的格矢（generateWignerSeitzGrid 只看格子，不看原子对），能量随原子怎样折回晶胞而变；原子越过晶胞面时跳变P89：金刚石 2×1×1，原子 0 在 a1 面两侧 ∓1e-6 Bohr：MatrixBased 跳 −1.818692 Ha（两个程序差 5.3e-11），NeighbourBased（缩小 1）+0.07272 Ha（1.8e-11），Truncated 只差斜率（−4.0e-7）。O2 盒子 2×1×1（自旋）跳 0.0356 Ha照 DFTB+（与折回的约定一起），文档写明；差分测试让原子离开晶胞面
B22（新）：NeighbourBased MinimumImage 只把每条路径 M → A → B → N 中 A–B 的密度限在 WS 胞里，与它配对的 M–N 偏移不限，交换算符不自伴P84d：随机厄米 P、Q 的 ⟨H[P], Q⟩ 与 ⟨H[Q], P⟩ 差 23 %（其余算符 ≤ 6.5e-16）；SCC 慢（金刚石 2×2×2 到 1e-10 要 55–59 轮），尾巴对舍入敏感照 DFTB+ 算能量；力拒绝并说明原因（精确的力要解响应方程）
B9（证实）：WS 边界上的并列向量都以权重 1 计入P83：FCC 2×2×2 19 个向量、8 个类照 DFTB+（这是它的 MinimumImage 的定义）
B10（证实）：MatrixBased 与 NeighbourBased 的 MinimumImage 是不同的近似P84c：金刚石 2×2×2 差 1.1e-3 Ha，缩小 1 时 8.8e-5；第四项 S(ΔP∘γ)S 相同到 3e-15，前三项不同两种都照 DFTB+，文档写明
B3 的延伸：MinimumImage 不用截断，DFTB+ 仍求默认截断，在 a2 沿 z 的晶胞上停下P88不求截断，照算（等于转动后 DFTB+ 能算的同一体系）
Threshold（不是错误）：按增量筛选，结果依赖历史；默认 1e-6 时 MinimumImage 的 SCC 不收敛，截断核的 SCC 在容差附近爬行P86、P86b；交换冻结后 Broyden 几乎为零的一步放大舍入，两个程序的 SCC 尾巴从那里分开（第三节 †），参考的容差停在那一步之前默认不筛选；给阈值时照 DFTB+
B7：ΔPin 不变时返回 H = 0 而不是 Hprev源码；SCC 中没有触发照 DFTB+（只在筛选的增量构建里）
B16：Γ 点的 NeighbourBased 不用 Threshold源码同 DFTB+

七、与设计的偏差

  • MinimumImage 不收截断，也不在 B3 上停下：设计只记了 DFTB+ 的做法（不读 CoulombCutoff、GSummationCutoff，默认截断照样求、B3 时停下）。实现时 pydftb 拒绝这两个参数（DFTB+ 遇到不读的键也停下），并且不求默认截断：MinimumImage 用不到它，停下只是 DFTB+ 的问题。新加一项测试对照转动后 DFTB+ 能算的同一体系。
  • bands.py 只改文档字符串：设计写“能带用新建的 terms”。原来的代码已经每次新建；筛选时的一次构建在 fock_at 里。
  • refgen.py 改了两处（设计写 refgen 不变）：pydftb 拒绝 NeighbourBased MinimumImage 的力，参考运行按 Case.pydftb_forces 不要力；有阈值时 SCC 的交换不能从 qin 重建（设计没有想到），能带算例在网格上比较 SCC 自己的能级（第三节 §）。
  • 两种 MinimumImage 的第四项相同只在探针 P84c 里查过，没有写成测试（类不单独给出各项）。
  • 算例数：设计约 16 个，实际 18 个（多了 Threshold 的电荷文件重启与居中的 2×2×2；设计里 MatrixBased MinimumImage 的电荷文件重启没有做，记录与库仑核无关，M6h-3b 已对照）。
  • Threshold 算例的 SCC 容差：设计写“容差按 P86 选，避开爬行的尾巴”。实际查清了尾巴的原因（第三节 †：冻结后 Broyden 几乎为零的一步放大舍入），四个算例的容差停在那一步之前（3e-7 到 5e-7）；这时 B5 让力差到 1.7e-8（‡），这些算例的力容差放到 5e-8。
  • 撤掉的动力学参考：实现时加过一条 Threshold 1e-6 的结构优化，想对照每个几何清空历史（updateCoords）。DFTB+ 的 SCC 在第 3、4 个几何上爬了 246 与 350 轮，两边的优化路径不同（6 步与 5 步）；筛选后的能量依赖路径，最终能量差 4.5e-9 Ha（几何差 6.1e-8 Å）。撤掉这条参考，改由电荷文件重启的算例（第一次构建是完整的，与新几何相同）与一项自洽检查覆盖。
