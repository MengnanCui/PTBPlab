关键信息

力进入拟合的框架与角度描述符都做完了，导数精确，单元测试全部通过。但在现有的 6 个理想相上，角度描述符没有解决 diamond：它把训练误差从 1.4 降到 0.5 meV/atom，留出 diamond 时误差却从 76 升到 224 meV/atom，留出 β-Sn 时从 19 升到 61。这是数据不够、模型过拟合，不是描述符错了：训练集里 q 只有 0、0.62、0.99 三个值，q 的基函数只“记住”了石墨与二聚体。角度项要等带力与畸变结构的数据才有意义。Cu 训练集（176 个结构，估计 1403 核时，约 140 元）的 VASP 输入与 Slurm 脚本已经生成在本地，没有上传、没有提交，等用户决定。

  • 角度描述符：q 的取值与设计一致（fcc、bcc 0，diamond 0.555，石墨 0.624，二聚体 0.990）；dq/dR 对差分 < 1e-8。带角度的模型的力、应力、∂F/∂θ 通过与 CN 模型相同的差分测试。
  • 力进入拟合：差分的力 Jacobian 与解析 ∂F/∂θ 的坐标导数一致（相对 1e-5，差分误差的量级）。用远离平衡的水分子（|F| > 0.5 eV/Å）的能量与力拟合，从零出发恢复已知的 4 个系数到 1e-4，力 RMSE < 1e-5 eV/Å。
  • 现有数据上的角度模型（48 个系数，meV/atom）：
    • 拟合全部 66 个结构：固定 15.6，自适应 1.4，加角度 0.5；
    • 留出 diamond：固定 75，自适应 76，加角度 224；
    • 留出 β-Sn：固定 62，自适应 19，加角度 61。
  • 训练集：cu_dft_m8b/，8 组 176 个结构（团簇含 MD 里重构掉的 Cu13 快照）。PBE、450 eV、300 K 的 Fermi 展宽、带力与应力。dg83 队列；先算三个校准作业再定总数。
  • 76 → 224留出 diamond 的误差（meV/atom），自适应 → 加角度：过拟合
  • 1.4 → 0.566 个结构的拟合误差（meV/atom）
  • 176训练集结构，约 1403 核时、140 元，未提交
  • 1e-4用力拟合恢复已知系数的误差

一、怎么用

from pydftb.adaptive import AdaptiveParams, RBF
from pydftb.adaptive_fit import Sample, fit_adaptive

m = AdaptiveParams("Cu", RBF((2.0, 6.0, 10.0), width=2.5),
                   angular=RBF((0.3, 0.6), width=0.15, constant=False),   # q 的基，不含常数
                   onsite=..., hopping=..., repulsive=..., pair_repulsive=...)
samples = [Sample(atoms, energy_per_atom, forces=forces_eV_per_A) for ...]
fit = fit_adaptive([m], samples, sk, options, force_weight=0.01, force_step=1e-4)
fit.rmse, fit.force_rmse; r.adaptive.cn, r.adaptive.q

实验：python -m pydftb.bench.adaptive_cu --kinds angular --cv-phases diamond,beta-Sn。训练集：python -m pydftb.bench.cu_dft_dataset。

二、角度描述符与导数

  • 取值（PTBP 的平衡体积）：fcc、bcc 0（反演对称，精确为 0），diamond 0.555（5/9），AA 石墨 0.624，二聚体 0.990（不是 1，是分母里的 ε = 0.01）。
  • dq/dR：扭曲的三原子 Cu 晶胞上对中心差分（步长 1e-6 Bohr）< 1e-8。
  • 力、应力、∂F/∂θ：Cu 周期金属的测试（3×3×3 k 点、1000 K）参数化为 cn 与 cn+angular，带角度时同样通过 M8a 的阈值。
  • 不用角度时：Φ 与 M8a 逐位相同。

三、力进入拟合

  • 对称性检验（test_force_jacobian_is_the_gradient_of_dF_dtheta）：水分子、4 个系数，θ 差分的 ∂F力/∂θ 与 −∇R(∂F/∂θ) 的坐标差分一致到相对 1e-5。
  • 恢复已知模型（test_fit_with_forces_recovers_a_model）：用一个已知的模型给几个扭曲水分子生成能量与力（最大力 > 0.5 eV/Å），从零系数出发、只用 40 次评估，恢复系数到 1e-4，能量 RMSE < 1e-6、力 RMSE < 1e-5 eV/Å。
  • 代价：每次评估多 2 nθ 次带力的计算。这次没有在真实数据上用：现有 66 个结构都是理想晶格，力按对称为 0。

四、现有数据上的角度模型

与 M8a 相同的数据与设置（66 个结构，ptbp_hcocu 的 Cu–Cu 表，300 K，l2 = 1e-4，每次拟合最多 150 次评估），在自适应模型上加 q 的 RBF（中心 0.3、0.6，宽 0.15，7 个通道各 2 个系数），共 48 个系数。10 个进程，拟合全部 1510 s；本机与其他会话共用 CPU，时间只作参考。

meV/atom固定（12）自适应（34）加角度（48）
拟合全部 66 个结构15.61.40.5
留出 diamond：训练 / 预测— / 75— / 760.4 / 224
留出 β-Sn：训练 / 预测— / 62— / 190.5 / 61
  • 为什么更差：留出 diamond 后，训练集里有 q ≠ 0 的只有石墨（0.62）与二聚体（0.99）。q 的基在 0.6 附近的系数完全由石墨决定，diamond 的 q = 0.555 正好落在这个基函数上，于是把“CN 3 的平面配位”的修正搬到了 CN 4 的四面体上。留出 β-Sn 时（q = 0，CN 6）同样：14 个多出来的系数让 5 个相拟合到 0.4 meV/atom，相之间的插值变差。
  • 结论：q 是对的描述符（导数精确、取值能区分结构），但 6 个点不能约束 7 × 2 个角度系数。需要同一个 CN 下 q 连续变化的数据：扰动的 diamond、sc、团簇、表面。训练集正是这样设计的。
  • 二聚体曲线（加角度的模型）：E(r) − E(3 Å) 在 1.2 Å 为 614 eV，1.9 Å 为 0.5 eV。短程墙照常起作用，没有 M8a 之前的电子能阱。

七、与设计的偏差

  • 目标没有达到：要求是“加入角度描述符解决 diamond 的问题”。描述符做完了，但在现有数据上让 diamond 变差（第四节）。不调参数去追这一折：q 的基、宽度在 6 个点上随便调都是过拟合。
  • 力的 Jacobian：按设计用差分，没有做解析的 implicit 导数。
  • 其余按设计。

八、下一步

  • 用户决定：是否在电光云上算训练集（全套约 140 元，或先算约 33 元的子集）。
  • 数据回来后：带力的拟合（CN 与 CN+角度两种）、按结构组的交叉验证、Cu13 与表面的 MD。
  • 描述符：按元素的 CN、q 与 CN 的交叉项；之后换神经网络的 Φ。
  • M8c 主动学习：几个拟合之间的差别作为不确定度，从 MD 中挑结构补充 DFT。
