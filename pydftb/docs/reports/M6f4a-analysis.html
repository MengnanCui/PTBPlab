关键信息

pydftb 现在能给出 DFTB+ Analysis 一节中不需要局域化或激发态的输出：按原子分解的能量（每一项都按 DFTB+ 的方式拆到原子上）、净布居与杂化比、CM5 电荷（含周期体系）、静电势（散点或网格，分子与周期体系），以及 DFTB+ 格式的 eigenvec.out/.bin、band.out、ESP.dat 与 detailed.out 的分析块。只在 NumPy 引擎中；不开分析时逐位不变。

  • 与 DFTB+ 对照：19 个新的参考算例全部通过（1 个用开发版），SCC 轮数逐个相同：
    • 按原子的能量四个块（电子、排斥、总能量、色散）差 ≤ 5.0e-9 Ha，即 detailed.out 8 位小数的舍入；涵盖 H0、Ewald 的 SCC、完整与只 onsite 的三阶、共线与非共线自旋、dual SOC、+U、onsite 修正、外场、点电荷、gross/net 位势、GB 溶剂、卤素修正、H5、偶极修正，以及 UFF、Slater–Kirkwood、SimpleDftD3、D3、D4 五种色散；
    • 净布居 ≤ 4.9e-9（8 位小数），CM5 电荷 ≤ 7.5e-11，静电势 ≤ 1.6e-11 a.u.（分子 6.4e-16），本征向量的 Mulliken 权重每个能级 ≤ 5.0e-7（eigenvec.out 只有 6 位小数），band.out 逐行相同；
    • pydftb 写的 band.out、eigenvec.out（实数、复数、两分量三种格式）、ESP.dat 与 detailed.out 的分析块，除数值外与 DFTB+ 的文件逐字节相同（本征向量的相位本来就任意）。
  • DFTB+ 的行为（第五节）：默认的 EwaldTolerance = 1e-9 让水盒子按原子的能量差 5.2e-8，收紧到 1e-12 后与 pydftb 一致到舍入；s-dftd3 库的 D3 能量被平均分给每个原子（E/N）；ESP 网格的 Directions 不是单位阵时文件头写错；点落在原子的周期像上时自身项的处理与中心晶胞不一致；D3H5 的 H–H 排斥把同一原子 ±L 两个像各算一次（源码）。
  • 接口：DFTB(analysis=True | dict | Analysis(...))，结果在 r.analysis；文件由 pydftb.dftbplus_io 的 write_band_out、write_eigenvectors、write_esp、detailed_tables 写出；ASE 计算器提供 atoms.get_potential_energies()。
  • 19新的 DFTB+ 参考算例，全部通过
  • 5.0e-9按原子能量与 DFTB+ 之差（Ha），即 8 位小数的舍入
  • E/NDFTB+ 对 D3 色散的按原子分配；pydftb 默认按原子对
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
analysis.py（新）

二、怎么用

from pydftb import DFTB, Analysis
from pydftb import dftbplus_io as io

calc = DFTB(sk, analysis=True)          # 按原子的能量、净布居、CM5
r = calc.calculate(labels, positions)
a = r.analysis
a.atom_energies["total"]                # (n_atom,)，Σ = r.energy（DFTB+ 的 "Total energy"）
a.atom_energies["electronic"], a.atom_energies["h0"], a.atom_energies["scc"]   # 以及各分项
a.net_populations, a.hybridisation, a.cm5_charges

calc = DFTB(sk, analysis={"esp": {"points": pts},               # Bohr，(M, 3)
                          "eigenvectors": True})
r = calc.calculate(labels, positions)
r.analysis.esp.internal                 # Hartree/e，物理电势；有外场或点电荷时还有 .external
io.write_esp("ESP.dat", r.analysis.esp)                       # V，DFTB+ 的格式
io.write_eigenvectors("eigenvec.out", r)                      # 或 "eigenvec.bin"
io.write_band_out("band.out", r)
print(io.detailed_tables(r))

calc = DFTB(sk, kpts=(k, w), analysis={"esp": {"grid": {
    "spacing": (1.0, 1.0, 1.0), "origin": (0, 0, 0), "points": (20, 20, 20)}}})
calc = DFTB(sk, kpts=(k, w), analysis={"esp": {"fractional": True, "grid": {
    "spacing": (0.05, 0.05, 0.05), "origin": (0, 0, 0), "points": (20, 20, 20)}}})

atoms.calc = PyDFTB(skdir, analysis={"atom_energies": True, "esp": {"points": pts_ang}})
atoms.get_potential_energies()          # eV，Σ = atoms.get_potential_energy()
  • 按原子的能量：各项的拆法照 DFTB+（设计文档第一节的表）；分项与 pydftb 自己的结果字段对应（h0 ↔ e_band、scc ↔ e_scc（含点电荷与偶极修正）、third_order ↔ e_3rd，等等）。DFTB+ 把只 onsite 的三阶记在 ESCC 里，pydftb 记在 e_3rd；电子与总能量两者相同。s-dftd3 库的 D3 按原子对分配（两体每对一半、三体每个原子 ⅓，同 D4）；DFTB+ 的 E/N 只在测试中复现。
  • 静电势：输出电荷的单极子；默认软化 1e-6 Bohr；需要 SCC；GB 溶剂时拒绝（同 DFTB+）。网格第三个下标变化最快；directions 的行是三个方向（自动归一化），文件头写正确的原点与步长矢量。
  • 本征向量：最后一次对角化的（由最后一轮输入电荷构成的 H），与 DFTB+ 相同；内存 N² × 块数，只在要写文件时开。
  • 只在 NumPy 引擎中；XL-BOMD 的影子能量不能按原子分解，报错。

三、与 DFTB+ 的对照

参数为测试用的 ptbp_hcocu；周期体系 EwaldTolerance = 1e-12。“分析”一栏是各量与 DFTB+ 之差的最大值：按原子能量（四个块）与净布居比 detailed.out 的 8 位小数，CM5 比 results.tag，静电势比 autotest.tag（a.u.），本征向量比 eigenvec.out 的 Mulliken 权重（简并能级求和后除以能级数），band.out 比 4 位小数的 eV。所有算例 pydftb 写的 detailed.out 分析块（和有的 ESP.dat、band.out）除数值外与 DFTB+ 的逐字节相同。带 * 的应力对 DFTB+ 能量的应变差分（偶极修正，DFTB+ 没有它的应力项）。

四、自洽检查

  • 求和：15 种组合（DFTB3、共线自旋、dual 与 onsite SOC、+U 加 onsite、k 点的自旋 +U、外场与位势、点电荷、GB、卤素、偶极修正、周期 UFF 与 SK、D3H5、只 onsite 的三阶）中，每个分项按原子求和等于对应的结果字段（≤ 1e-11），总能量之和等于 energy。
  • 不变性：甲醇整体旋转、平移后按原子的能量、CM5、净布居不变（1e-9）；CM5 的修正项对原子求和为零（DAB = −DBA），周期体系含像也是。
  • 静电势：分子与直接求和一致（1e-15）；周期体系的晶胞与加倍的超胞（不同的 Ewald α）给出相同的电势（1e-9）；网格与逐点相同，第三个下标最快；分数坐标网格与等价的笛卡尔网格相同；旋转网格的原点与步长矢量；点落在原子与它的像上结果相同，靠近原子时等于自身的 q/r 加上去掉自身项后的值；外部一栏与点电荷的直接求和一致；偶极修正使内部一栏变化 −Vdc。
  • 本征向量：每个态的权重之和为 1；按占据数加权的权重等于最后的 Mulliken 轨道布居（1e-10），证明它们来自产生最终密度的那次对角化。
  • 文件：band.out、eigenvec.out/.bin、ESP.dat 写出后能读回（二进制逐字节等于本征向量）；ESP.dat 追加时不重复文件头并带 “Geo n”。
  • 拒绝：ESP 非 SCC、ESP 加 GB、错误的 ESP 设定（同时给散点与网格、网格步长为零、分数坐标网格给方向、分子用分数坐标）、未知的键、torch 后端、XL-BOMD 的按原子能量；不开分析时 r.analysis 为 None。
  • ASE：get_potential_energies() 之和等于 get_potential_energy()；ESP 的点由 Å 换成 Bohr；未要求按原子能量时 PropertyNotImplementedError。

五、DFTB+ 的行为

  • Ewald 的精度：默认 EwaldTolerance = 1e-9 时水盒子的 EH0 差 7.9e-8、ESCC 差 5.3e-8、总能量差 1.3e-7（旧算例 water_box_gamma 的容差 1e-6 掩盖了这一点），按原子的电子能量差 5.2e-8；1e-12 与 1e-15 时与 pydftb 的 10 位小数相同，按原子能量差 4.9e-9。周期分析算例都收紧到 1e-12。
  • D3 的按原子分配：extlibs/sdftd3.F90 的 getEnergies 直接 energies = energy / nAtom，D3H5 的 H–H 排斥也在内；pydftb 默认按原子对（库的 get_pairwise_dispersion），compat 复现 E/N（差 1.8e-10）。DFTB+ 自己的 D4 与 SimpleDftD3 是按原子对的，与库的行和一致到 4.9e-9。
  • ESP 网格的文件头（parser.F90 的 readGrid）：点是 A·(…+ o)，写出的原点却是未旋转的 o；步长矢量写成 axes_ * spread(spacing, 2, 3)，按行乘步长。探针：方向 (y, −x, z)、步长 1、2、1.5 Å、原点 (1, 0.5, 0.2) Å 的网格，DFTB+ 写的原点仍是 (1, 0.5, 0.2)（实际 (−0.5, 1, 0.2)），第一个步长矢量写成 (0, 2, 0)（应为 (0, 1, 0)），电势值本身与 pydftb 一致到 9e-9 V。Directions 为单位阵时正确（参考算例如此）；分数坐标网格 Grid [F] 的值一致到 4e-10 V。pydftb 写正确的值（自洽测试覆盖了旋转网格）。
  • 点落在原子的周期像上：实空间跳过该项，但 −2α/√π 只在点与中心晶胞的原子重合时才减，两种情况结果不同；pydftb 两种都去掉自身项。
  • D3H5 的 H–H 排斥（addHHRepulsion，源码）：半近邻表中同一原子 ±L 两个像都在，能量各加一次（应力乘了 ½，能量没有），晶胞短于 10 Bohr 时能量偏大。pydftb 的 hh_repulsion 每对一半，正确。参考算例都是分子，不受影响。
  • 其他：按原子的能量只写进 detailed.out（8 位小数），单项不按原子打印，没有 tag；静电势两栏在文件中都是物理电势（内部的势取负再乘 27.2113845），autotest.tag 同号；只要分配了净布居（例如 net 位势）DFTB+ 就打印净布居块；GB 溶剂时拒绝静电势（只有 SASA 可以）。

八、与设计的偏差

  • 算例：设计列了 13 个（加上色散的 4 个是 17 个），实际 19 个：多了 h2o_site_atom（gross/net 位势与净布居块）；+U 与 onsite 分成 cu4co_plusu_atom、ch3oh_ons_atom 两个；water_slab_dipole_analysis 沿用 stress_fd（DFTB+ 没有偶极修正的应力项）。分析算例也逐轮比较 SCC 误差。
  • 容差：本征向量权重按“简并组求和后除以能级数”比较，容差 6e-7（每个能级的舍入 ≤ 5e-7），而不是设计中的组求和 1e-6；band.out 的 eV 容差 1.01e-4（最后一位的舍入边界）。
  • 接口：detailed_tables(res) 不需要 labels（DFTB+ 的块没有物种名）；周期体系的 CM5 是新函数 solvation.cm5_charges，GB 用的 cm5_correction 原样不动；色散的按原子能量通过 evaluate(..., atoms=) 与 DispersionTerms.atoms，不另写一套参数计算。
  • golden：命名元组原来按下标记录，DispersionTerms 多一个字段会显示为“[3] 只在工作树”；改为按字段名记录（两边用同一个记录脚本），允许列表只需 atoms。
