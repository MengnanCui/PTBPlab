关键信息

M6h-1 的 LC/CAM 杂化泛函推广到周期体系的 Γ 点，即 DFTB+ 25.1 只用 Γ 点的杂化计算。交换仍是分子的四项公式，只是 S 换成镜像折叠的 S(Γ)，γ 换成对晶格平移求和的截断 γ（Truncated 或 TruncatedAndDamped），P0 除以 Sμμ(Γ)。MatrixBased 与 NeighbourBased 都可用；能量、力、自旋、展宽与 M6h-1 的组合都有，可以从电荷文件重启，可以做结构优化与 MD。只有 NumPy 引擎；分子的结果逐位不变。k 点是 M6h-3b。

  • 与 DFTB+ 对照：23 个参考算例与 2 条动力学参考全部通过。
    • 能量差 ≤ 1.0e-10 Ha，力 ≤ 8.8e-12 Ha/Bohr，电荷 ≤ 2.6e-10 e，SCC 轮数相同（只有一个算例在 1e-12 的容差处因舍入差一轮）。
    • 覆盖：CO2 晶体、金刚石、Cu4（1000 K）、盒子里的 O2（自旋）、三斜与单斜的小晶胞；两种截断、两种屏蔽（含 CutoffReduction）、LC、CAM 与全局杂化；+U、onsite、完整 DFTB3 加 D3、外场加点电荷、MP 展宽、Anderson 混合器、自定义 Hubbard U、二进制与文本电荷文件的重启。
    • 动力学：CO2 晶体 20 步 MD（ΔPin 跨步沿用；用 DFTB+ 单位的 Verlet 能量差 7.8e-11 Ha）与金刚石的结构优化（能量差 1.0e-11 Ha）。
  • DFTB+ 25.1 的问题（第五节，pydftb 给出一致的结果，验证用的开关复现 DFTB+）：
    • B1：阻尼截断时，力里 HF 部分的导数用了 LR 的多项式。CAM 与全局杂化的力偏 7.0e-7 与 5.6e-6 Ha/Bohr。
    • B6：低对称晶胞里，输入布居丢了一半原子内的非对角项。三斜 CO 晶胞的电荷偏 1.3e-5 e，力偏 7.1e-6 Ha/Bohr。
    • B13：Γ 点写成显式 k 点时不能重启；B18：分子读 Γ 点的电荷文件时 ΔPin 错一位。
  • 不支持（与 DFTB+ 相同）：Thresholded、非共线自旋、TD-LC、Γ 点的 Full 与 MinimumImage、应力（DFTB+ 静默不算，pydftb 在要求时报错）。
  • 23 + 2新的 DFTB+ 参考算例与动力学参考，全部通过
  • ≤ 1.0e-10与 DFTB+ 25.1 的能量之差（Ha）
  • ≤ 8.8e-12与 DFTB+ 的力之差（Ha/Bohr）
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
hybrid.py
  • Hybrid 加 coulomb（"truncated"、"damped"，以及 Γ 点拒绝的 "full"、"minimum_image"）、coulomb_cutoff、gsum_cutoff（Bohr，默认 None 即 DFTB+ 的默认值）；make 认这三个键。
  • 截断的 γ：
    • ddgamma_hf：HF 的二阶导数（DFTB+ 的闭式；U 几乎相等时用一阶导数的中心差分）；
    • poly5zero、coulomb_gamma(…, kind, derivative)：两种截断的值与导数。阻尼区的 LR 二阶导数照 DFTB+ 取解析一阶导数的中心差分（δ = 1e-8）。dftbp_hf 是 B1 的开关。
  • 晶格：plane_spacings、default_coulomb_cutoff（最小晶面间距的一半）、lattice_translations（DFTB+ 的平行六面体）。
  • HybridTerms(…, cell=…, pairs=…)：
    • _periodic_setup：按 Hubbard U 分组对原子对与平移求 gt（大晶胞按平移分块，每块至多 220 个原子对 × 平移，内存有界；小晶胞只有一块）；NeighbourBased 的缩减 S(Γ) 用与 S(Γ) 相同的 fold（缩减为 0 时逐位相同）；P0 除以 Sμμ(Γ)。
    • pair_coefficient、gamma_gradient：NeighbourBased 用缩减的 S，系数只给 CAM 截断以内的原子对；_gamma_force 对平移求和，原子与自身镜像之间没有力。
    • 分子的路径不变（逐位）。
  • 验证用：类属性 _dftbp_hf_damped_derivative（B1）；函数 dftbp_dense_mulliken（B6）。
calculator.py
  • _check_periodic_hybrid：只许 Γ 点（其余 k 点是 M6h-3b）；Thresholded、非共线、激发态按 DFTB+ 的原话拒绝。
  • _hybrid_terms 传晶胞与成对的块；_run：杂化时默认不算应力，明确要求时报错。
  • _hybrid_input_populations：验证用的类属性 _dftbp_gamma_q_in 打开时，Γ 点的 qin 照 DFTB+ 算（B6）。
  • charge_data(…, periodic=…)：Γ 点的折叠矩阵记录；populations_from_file 读两种布局。
dftbplus_io.pyChargeData.folding；读写 k 点信息记录（12 个数，在 ΔPin 之前），读入时 Γ 点以外的折叠矩阵拒绝（M6h-3b）。
bands.pyeigenstates 在 Γ 点加周期的 Hx[ΔPin]，其他 k 点拒绝。
ase_calc.py三个长度以 Å 为单位；要应力时报 ASE 的 PropertyNotImplementedError；write_charges 写周期的布局。
validation/
  • cases.py：23 个算例与六个结构（干冰晶胞、金刚石、Cu4、O2 盒子、三斜 CO、单斜 H2O）；Case.gamma_q_in_compat（B6）；B1 算例的容差 TOL_B1。
  • dftbplus.py：hybrid_block 在设置不是默认值时写 CoulombMatrix（分子的块不变）；kpts="gamma_folding" 写单位矩阵的 SupercellFolding。
  • refgen.py、dynamics.py：周期杂化用 "gamma_folding"（避开 B13）；兼容开关；ASE 的长度单位。
  • dynamics.py：两条参考（CO2 晶体 MD、金刚石结构优化）。
测试

  • tests/test_hybrid.py：原来“周期体系是 M6h-3”的拒绝换成“k 点是 M6h-3b”。

二、怎么用

calc = DFTB(sk_lc, hybrid="lc")                     # 有晶胞、不给 k 点：Γ 点，DFTB+ 的默认截断
calc = DFTB(sk_cam, hybrid={"type": "cam", "coulomb": "damped",
                            "coulomb_cutoff": 8.0, "gsum_cutoff": 16.0})   # Bohr
r = calc.calculate(labels, pos, cell, forces=True)  # 没有应力
r.e_fock, r.q_in                                    # q_in = [布居 | ΔP 的下三角]
write_charges("charges.bin", calc.charge_data(labels, r, periodic=True))
atoms.calc = PyDFTB(skdir, hybrid={"type": "lc", "coulomb_cutoff": 4.2})   # Å
  • 截断（只用于周期体系；分子给了这三项就报错，DFTB+ 遇到分子的 CoulombMatrix 也停下）："truncated"（默认）在 Rc 处截断；"damped" 在 (Rc − 1 Bohr, Rc) 上用五次多项式光滑地降到 0。默认 Rc 是最小晶面间距的一半，Rg = 2Rc，与 DFTB+ 相同。Rc ≤ 1 Bohr 时报错（DFTB+ 的原话）。
  • 屏蔽："matrix" 与 "neighbour"；NeighbourBased 加 CutoffReduction 时，力用缩减的重叠，是能量的导数（与分子不同，与 DFTB+ 相同）。
  • 组合：共线自旋、展宽、+U、onsite、完整 DFTB3、D3/D4、外场、点电荷、各混合器、自定义 Hubbard U 与占据、states()（Γ 点）、结构优化与 MD（reuse_charges 沿用 ΔP）。
  • 电荷文件：DFTB+ 的格式 8，ΔPin 之前多一条折叠矩阵记录。pydftb 两种布局都能读：分子与 Γ 点的 ΔP 是同样的稠密矩阵。DFTB+ 只读自己那种（B18）。
  • 拒绝：Thresholded、非共线自旋、Casida、Γ 点的 Full 与 MinimumImage（DFTB+ 的原话）；k 点（M6h-3b）；应力；torch 与自动求导（同 M6h-1）。

四、自洽检查

tests/test_hybrid_periodic.py 的 46 项（不需要 DFTB+）：

  • 截断的 γ：
    • 五次多项式在两端的值、一阶与二阶导数；
    • ddgamma_hf 的四个分支（相等、DFTB+ 视为相等、几乎相等、不等）对一阶导数的差分（1e-9）；
    • LC、CAM、全局杂化：截断在 Rc 以内等于 γ，阻尼区以内逐位等于 γ，在阻尼起点处二阶连续；导数对差分（1e-9）；B1 的开关只改阻尼区里 α ≠ 0 的导数。
  • 晶格：晶面间距对倒格矢、默认截断；平移集包含 Rg 以内的所有格矢；分块求和（干冰晶胞分成 22 块）与一块的 gt、能量、力相同（1e-14、1e-12）。
  • 大盒子里的分子：没有镜像在截断与 SK 范围以内时，gt、S(Γ)、P0 与任意密度的 Hx 都等于分子的（1e-14）。
  • 缩减的重叠与 P0：CutoffReduction 去掉分子间的块；不缩减时与 S(Γ) 逐位相同，NeighbourBased 的能量与力等于 MatrixBased（1e-12）；三斜晶胞里 Sμμ(Γ) ≠ 1，tr(P0S(Γ)) 等于电子数。
  • 力对能量的差分（四点差分，h = 5e-5 Bohr，SCC 容差 1e-12，解析 SK 导数）：九个算例差 ≤ 1.9e-9（测试的界 5e-8），包括阻尼截断的 CAM 与全局杂化、缩减的近邻表、金属、自旋、+U 与三斜晶胞（pydftb 自己的布居）。
  • B1、B6 的开关：B1 只改力（7e-7 量级），LC 不受影响；dftbp_dense_mulliken 正好少了原子块里对角线以上的项；B6 的开关在立方晶胞里不改变结果（1e-12），在三斜晶胞里 pydftb 自己的电荷与 DFTB+ 的参考差 1.3e-5 e。
  • 结果与文件：EFock 在能量各项之和里；states() 在 Γ 点复现 SCC 的能级（1e-12），其他 k 点拒绝；电荷文件（二进制与文本）往返逐位不变，从文件重启 ≤ 2 轮；分子从 Γ 点的文件出发、Γ 点从分子的文件出发都能运行；非单位的折叠矩阵与缺少密度矩阵的写法报错；ASE 计算器的单位、应力的拒绝与电荷文件。
  • 拒绝：k 点、Thresholded、非共线、Casida、Full 与 MinimumImage、Rc ≤ 1 Bohr，分子的 CoulombMatrix 设置；Hybrid 的新选项的检查。

五、DFTB+ 的问题

DFTB+ 25.1证据pydftb 的做法
B1：TruncatedAndDamped 时，HF 部分在阻尼区的导数用了 LR 的多项式系数（hybridxc.F90 第 4370–4373 行；值在第 3801–3804 行用 HF 的系数）干冰晶胞，Rc = 8 Bohr：CAM 的力偏 7.0e-7，全局杂化 5.6e-6 Ha/Bohr；对 DFTB+ 自己能量的差分也偏这么多精确的导数；验证用的 HybridTerms._dftbp_hf_damped_derivative 与 DFTB+ 的力差 6.1e-12
B6：Γ 点的 qin 由只存下三角的 ΔPin 经 denseMullikenReal 算出，同一原子的块只按列求和（populations.F90 第 540–552 行）。低对称晶胞里 S(Γ) 有原子内的非对角元时，丢了一半这些项，SCC 的不动点不再是自洽解三斜 CO 晶胞：电荷偏 1.3e-5 e，力偏 7.1e-6 Ha/Bohr，能量 3e-11（二阶）；单斜 H2O 晶胞 4.6e-6 与 3.0e-7。立方、正交晶胞因对称不受影响真正的 Mulliken 布居；验证用的 DFTB._dftbp_gamma_q_in 与 DFTB+ 的电荷差 1.4e-11、力差 1.1e-12
B13：Γ 点写成显式 k 点再加 ReadInitialCharges，被当成只许一轮的能带计算而停下（parser.F90 第 3102–3103 行不查是否只有 Γ 点）P67验证工具对周期杂化写单位矩阵的 SupercellFolding，结果与显式 Γ 点逐位相同
B18：分子读 Γ 点写的电荷文件时不跳过折叠矩阵记录（sccinit.F90 第 552–573 行只在本次是周期杂化时读它），ΔPin(1,1) 取成记录的第一个数 1.0，其后每个数错后一位、最后一个丢掉；不报错P70：pydftb 从照此错位的矩阵出发，前两轮的 SCC 误差与 DFTB+ 印出的每一位相同；DFTB+ 75 轮，从正确的矩阵出发 24 轮，最后的能量相同。反过来，Γ 点读分子的文件时 DFTB+ 停下（折叠矩阵读不到，印成 0）两种文件都按格式读；分子与 Γ 点的 ΔP 是同样的稠密矩阵，互相可读
默认的 EwaldTolerance 1e-9（不是错误）干冰晶胞的能量差 8.6e-8（与杂化无关，M6f 记录过）参考用 1e-12

七、与设计的偏差

  • B6 的对照：设计写的是“参考存 DFTB+ 能量的差分，兼容模式对照”。但 B6 改的是 SCC 的不动点，DFTB+ 的能量不是 pydftb 那个泛函的值，差分也就不是好的参考。现在两个低对称算例在对照时直接打开兼容开关（Case.gamma_q_in_compat）；pydftb 自己的结果在测试里与 DFTB+ 比较，力用能量差分检查。
  • 实现的名字：两种截断合成一个 coulomb_gamma(…, kind, derivative)（设计写的是 gamma_truncated、dgamma_truncated）；HybridTerms 接收 cell 与 pairs，不是一个 periodic 开关。缩减的 S(Γ) 用与 S(Γ) 相同的 fold，不缩减时逐位相同。
  • B1 算例的容差：力对 DFTB+ 能量差分的容差 5e-8（差分本身只准到 1e-8 左右，第三节）；SCC 容差 1e-12 时 CAM 的算例差一轮，轮数容差 1。
  • MD 的能量容差：干冰的 MD 动能升得很高，ASE 单位常数的影响到 5.7e-8 Ha，容差放到 1e-7；DFTB+ 单位的比较仍是 2e-9。
  • 多出的部分：
    • 探针 P70 与 B18（实现 populations_from_file 时补做）：pydftb 接受另一种布局的文件，并在文档里写明 DFTB+ 的行为；
    • 探针 P71：设计写“分子不读这三项（与 DFTB+ 相同）”，实测 DFTB+ 遇到分子的 CoulombMatrix 会停下，pydftb 改为同样报错；
    • 文本电荷文件的周期重启算例（O2 自旋），设计只写了一个重启算例；
    • states() 的 Γ 点（设计没提）；
    • 格点和按平移分块：一次建整个距离数组时，500 个原子的晶胞要几 GB，现在内存有界，小晶胞仍是一块、结果逐位不变。
