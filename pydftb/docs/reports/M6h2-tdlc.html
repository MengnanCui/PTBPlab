关键信息

M6d/M6e 的 Casida 激发与激发态力加上 M6h-1 的长程校正（LC）交换，即 DFTB+ 25.1 的 TD-LC-DFTB。DFTB+ 支持的范围全部做了：LC 型的 SK 文件、分子、整数占据；单重态、三重态、两者、自旋极化；激发能、振子强度、跃迁偶极、Δ⟨S²⟩、跃迁电荷、激发态的电荷与偶极、激发态力。基态可以用三种屏蔽中的任何一种，也可以加外场与点电荷；激发态的结构优化与 MD 都能用。求解器有两个：稠密的对称化精确解，以及 Stratmann 子空间迭代。只有 NumPy 引擎；不开杂化时结果逐位不变。

  • 与 DFTB+ 对照：23 个参考算例与 2 条动力学参考全部通过。
    • 小分子：DFTB+ 的 Stratmann 子空间能装下全部跃迁，结果精确。基态用 MatrixBased 时，激发能之差 ≤ 1.5e-11 Ha，振子强度 ≤ 7.2e-14；激发态力用 DFTB+ 的 SK 差分步长比较，差 ≤ 1.4e-12 Ha/Bohr，覆盖单重态 S1–S3、三重态、自旋极化。Thresholded 的算例差 1.0e-10 与 6.4e-11：基态的屏蔽决定随舍入翻转。
    • 苯与萘：差别来自 DFTB+ Stratmann 的收敛阈值（残差平方 1.2e-8）。萘的 8 个激发能差 ≤ 1.0e-8 Ha（S1 3.1e-9），S1 的力差 6.5e-7 Ha/Bohr；pydftb 的力与它自己 E0 + Ω 的差分一致到 1.1e-9，DFTB+ 只到 6.6e-7。
    • 动力学：H2CO 的 S1 结构优化（分子变成锥形）与 S2 的 20 步 MD 都与 DFTB+ 一致，能量差 ≤ 1.1e-8 Ha，位置差 ≤ 7.0e-7 Å；MD 每一步的 SCC 轮数都相同。
  • DFTB+ 25.1 的情况（第五节）：
    • 外场加点电荷时，TD-LC 激发态力偏 3.0e-3 Ha/Bohr，漏的是 M6e 已发现的那几项。pydftb 给出精确的导数；兼容模式复现 DFTB+ 的力，差 9.2e-13。
    • 自旋极化且自旋常数是壳层矩阵时，DFTB+ 的力偏 2.6e-4，pydftb 照 M6e 拒绝。
    • 屏蔽：TD 部分用不屏蔽的交换，力不是 E0 + Ω 的导数。根源在基态：Thresholded 的基态力本身就偏 1.4e-3。pydftb 照 DFTB+ 的写法给出相同的力。
  • 不支持（与 DFTB+ 相同）：
    • CAM 与全局杂化的 TD、能量或振子窗口、onsite 修正、分数占据、周期体系。
    • pydftb 的 ARPACK 求解器只解 Hermite 形式，TD-LC 时拒绝。
  • 23 + 2新的 DFTB+ 参考算例与动力学参考，全部通过
  • ≤ 1.5e-11与 DFTB+ 25.1 的激发能之差（Ha，小分子，MatrixBased）
  • ≤ 1.4e-12与 DFTB+ 的激发态力之差（Ha/Bohr，小分子，MatrixBased）
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
hybrid.py
  • 四项算子改为模块函数 four_terms(s, g, d)；HybridTerms._four_terms 调用它，运算相同，基态结果逐位不变。
  • bilinear_ds、bilinear_dg：B(M1, M2) = ⟨M1, Kx[M2]⟩ 对 S 与 Γ 的导数，M 可以不对称。
  • HybridTerms.exchange_force(terms, pairs)：对一组 (c, M1, M2) 求和，返回成对元素上的 dS 系数和 γ 部分的梯度。γ 部分与基态共用 _gamma_force（从 gamma_gradient 中分出）。
casida.py
  • GroundState.lr_gamma：原子级的 γlr，不开杂化时为 None。
  • _Exchange：
    • 稠密的 (ij|ab) 与 (ib|ja) 用任意轨道对的 Mulliken 跃迁电荷各做一次 GEMM；
    • 对角 −[(ii|aa) + (ia|ia)]；
    • 对向量的乘积用 AO 的 four_terms（−2 CoTKx[Ys/a]Cv）。
  • _symmetric_rpa：(A−B)½(A+B)(A−B)½ 的本征问题，返回 Ω²、X+Y、X−Y；A−B 不正定时报基态不稳定。
  • HybridResponse：
    • A±B 的稠密矩阵与不建矩阵的乘积；
    • solve："exact"、"davidson"（Stratmann）、"auto"（≤ 500 个跃迁用前者）；"arpack" 拒绝；
    • stratmann：多跟踪几个态，免得边缘的简并组被切开；子空间满了就从 X+Y、X−Y 重新开始；新方向用完且子空间已是全空间时返回精确解。
  • _check_tdlc：窗口、onsite、分数占据，报错用 DFTB+ 的原话。
  • excitations：lr_gamma 不为 None 时走 TD-LC。_properties 接收现成的 X±Y；原来的路径不变，算 X±Y 的表达式只是挪到调用处。
  • 另加 Response.kernel_product：库仑与自旋耦合核对向量的乘积（不含前因子与 onsite 项），供 A+B 用。
casida_grad.py
  • _APlusB：Z 向量方程的 A+B 加交换项，稠密矩阵、乘积与对角都加。
  • relax：
    • 轨道梯度 Goo、Gvo、Gov、Gvv 的交换部分进入右端项与 W；
    • 基态对 T 与 Zs 的交换响应 −2Kx[M]；
    • Relaxed.xmy_ao = C(Ỹ − ỸT)CT。
  • exchange_terms：显式导数的三项：
    • −½ B(P, ΔP)：闭壳层；自旋极化时每个通道 −B(Pσ, ΔPσ)；
    • −B(Rs, Rs)；
    • −B(La, La)。
calculator.py
  • _check_hybrid：删去“TD-LC 是 M6h-2”的拒绝；改为 DFTB+ 的条件（CAM 与全局文件、窗口、onsite，DFTB+ 的原话）与 ARPACK 的拒绝。
  • _casida_ground_state 传 γlr；_excited_gradient 加交换的显式项。
validation/
  • cases.py：
    • 23 个算例；
    • 每种元素一个 W 的 W_HOAO（WHCO 壳层矩阵的 HOAO 值）；
    • 容差 TOL_TDLC 与 TOL_TDLC_STRATMANN；
    • 手工搭的萘（第七节）。
  • refgen.py：
    • TD-LC 的 forces_fd 由激发态的比较处理；
    • 简并组的 KS 能量只在整组不受旋转影响时比较（O2 的主导跃迁本身随旋转而变）。
  • dftbplus.py：spin_constants_block 拒绝壳层矩阵（第五节的工具问题）。
  • dynamics.py：两条参考（S1 结构优化、S2 MD）。
测试

二、怎么用

calc = DFTB(sk_lc, hybrid="lc",
            casida=Casida(n_excitations=6, symmetry="singlet", state_of_interest=2))
r = calc.calculate(labels, pos, forces=True)
r.excitations.energies, r.excitation_energy   # 激发能（Ha）
r.forces                                       # -d(E0 + Omega)/dR
r.excited_charges, r.excited_dipole            # 激发态的 Mulliken 电荷与偶极
atoms.calc = PyDFTB(skdir, hybrid="lc", casida={"n_excitations": 4, "state_of_interest": 1})
  • 选项：M6d/M6e 的 Casida 全部可用：对称性、态、最亮态、激发态力与电荷、跃迁电荷、求解器。条件与 DFTB+ 相同：
    • SK 文件必须是 LC 型（hybrid="cam" 配 LC 文件也可以）；
    • 不能用窗口，不能用 onsite 修正；
    • 占据必须是整数，否则在计算激发时报错。
  • 求解器：
    • "exact"：稠密的 A±B，对称化后对角化。
    • "davidson"：Stratmann 子空间迭代，A±B 不建成矩阵，残差收敛到 1e-10，比 DFTB+ 的阈值严得多。
    • "auto"：≤ 500 个跃迁用前者，更多时用后者。
  • 屏蔽：基态的屏蔽照常可选，TD 部分与 DFTB+ 一样不屏蔽。屏蔽下的激发态力照 DFTB+ 给出，与基态的屏蔽力一样不是能量的导数。
  • 自旋常数：三重态与激发态力都要求每种元素一个 W（M6d、M6e 的规则）。

三、与 DFTB+ 的对照

参数 ptbp_hcocu_lc（M6h-1），DFTB+ 25.1 用 Stratmann 求解器（TD-LC 只能用它），pydftb 用 "auto"。两边 SCC 容差 1e-10，pydftb 用 DFTB+ 的 SK 差分步长。

  • 容差（TOL_TDLC）：
    • 基态同 M6h-1；
    • 激发能 1e-8 Ha，振子强度与跃迁偶极 1e-7；
    • EXC.DAT 与 SPX.DAT 的表 0 处不同；
    • 激发态的能量 1e-9 Ha，电荷与偶极 1e-7；
    • 力与 DFTB+ 的力比较到 1e-10 Ha/Bohr。
  • 苯与萘照 Stratmann 的精度放宽（TOL_TDLC_STRATMANN），第七节说明。

四、自洽检查

tests/test_casida_lc.py 的 21 项：

  • 交换矩阵：
    • 稠密的 (ij|ab)、(ib|ja) 等于逐个算的 qijγqab、qibγqja（1e-13）；
    • A±B 是对称的，不建矩阵的乘积等于矩阵（1e-13）；
    • 两个自旋通道之间没有交换。单重态、三重态与自旋极化都测。
  • 对称解：(A+B)(X+Y) = Ω(X−Y)、(A−B)(X−Y) = Ω(X+Y)、(X+Y)·(X−Y) = 1，Ω² 等于 (A−B)(A+B) 的本征值（1e-12）。
  • Stratmann 与精确解：苯、自旋极化的 H2CO+ 与萘（576 个跃迁）的 Ω² 相同（1e-12），简并组的振子强度之和相同（1e-9）。
  • 没有交换的极限：γlr = 0 时，TD-LC 的解就是 M6d 的 Hermite Casida（单重态、三重态、自旋极化；Ω² 1e-14）。
  • 闭壳层按自旋极化算：H2CO 的 TD-LC 态就是限制性的单重态与三重态之并（1e-10）。
  • 力对 E0 + Ω 的差分：五种情形差 ≤ 3e-9 Ha/Bohr（解析 SK 导数），即单重态、三重态、自旋极化、C2H4 S1，以及外场加点电荷。
  • Z 向量：稠密解与共轭梯度（交换项的乘积与对角）给出相同的力与电荷（1e-12）。
  • 弛豫密度：电子数守恒，没有外场时力之和为零（1e-12）。
  • 双线性导数：∂B/∂S、∂B/∂Γ 对中心差分，S、Γ 保持对称，M1、M2 取对称、反对称、混合与一般的矩阵；B(M1, M2) = B(M2, M1)。
  • 拒绝：CAM 与全局文件、分数占据（3000 K）、ARPACK、壳层矩阵的 W；LC 文件配 hybrid="cam" 照常运行。

另有原型阶段的检查（设计文档第二节）：Ω² 与 DFTB+ 的差 ≤ 6.2e-14；激发态力用 DFTB+ 的步长时与 DFTB+ 差 ≤ 1.1e-12。

五、DFTB+ 的问题

DFTB+ 25.1证据pydftb 的做法
外场加点电荷时，激发态力漏了 dqex·∇Vext，shift 中也没有外场（M6e 已记录，TD-LC 相同）H2CO S2：DFTB+ 的力对其 E0 + Ω 的差分偏 3.0e-3 Ha/Bohr；pydftb 对 DFTB+ 能量的差分 9.5e-9精确的导数；兼容模式 external 去掉 DFTB+ 去掉的项，与 DFTB+ 的力差 9.2e-13（验证用）
自旋常数是壳层矩阵时，响应只用 HOAO 的 W，基态用整个矩阵，两者不一致（M6e 的机理）自旋极化的 H2CO+：DFTB+ 的力偏 2.6e-4（M6e 不加杂化时为 8.8e-6）照 M6e 拒绝，要求每种元素一个 W
屏蔽：TD 部分用不屏蔽的交换，基态用屏蔽的交换苯，NeighbourBased（CutoffReduction 10 Bohr）：两个程序的力都偏离各自 E0 + Ω 的差分 4.8e-5，彼此差 6.6e-8。Thresholded 的基态力本身就偏 1.4e-3，且差分随步长不收敛：E0 本身不光滑照 DFTB+ 给出（与基态的屏蔽力一样不是能量的导数），在文档中说明
Stratmann 的收敛阈值是残差平方 1.2e-8萘 S1：DFTB+ 的力对其差分偏 6.6e-7，pydftb 1.1e-9；8 个激发能差 ≤ 1.0e-8pydftb 收敛到 1e-10；苯与萘的参考容差放宽，小分子仍按 1e-10 比较
Stratmann 扩充子空间时，L 残差的预条件分母用的是上一个循环剩下的 dummyReal（linrespgrad.F90 第 1437 行）代码只影响收敛快慢，不影响结果；pydftb 按每个态的 Ω 做预条件
  • 验证工具的问题（不是 DFTB+ 的）：给限制性三重态写 HSD 的 spin_constants_block 遇到 W 矩阵只取第一个元素（ss），而两个程序都用 HOAO 的 pp 值，三重态差 3e-3。现在拒绝矩阵，算例改用 W_HOAO。M6d、M6e 的三重态算例本来就用标量 W，不受影响。
  • SK 网格：SK 表的网格是 0.02 Bohr，插值多项式在网格点处只有分段光滑。原子间距离离网格点太近时，DFTB+ 的差分步长（2−13 Bohr）或测试的差分会跨过网格点，力的比较出现 1e-5 量级的假差别。萘的第一个几何（种子 5）就是这样：一个 C–C 距离离网格点 7.5e-5 Bohr，DFTB+ 的力偏 3.1e-5，pydftb 对差分偏 4.1e-6。改用种子 37 后，所有原子对离网格点至少 3e-4 Bohr，差别降到上面的数。这是 SK 表本身的性质，不是哪个程序的错。

七、与设计的偏差

  • 参考算例：比设计的多了萘、苯的 NeighbourBased 激发态力与 H2CO 的 S1 力，共 23 个。
    • 萘有 576 个跃迁，超过 "auto" 的 500，所以 pydftb 走 Stratmann 迭代，Z 向量走共轭梯度。这两条路要有 DFTB+ 的对照。
    • 苯的 NeighbourBased 真的去掉了原子对（CutoffReduction 10 Bohr 时去掉间位、对位的 C–H 与 H–H）。H2CO 太小，什么都没去掉。
    • H2CO 的 S1 力是结构优化的基础。
  • 动力学：设计写的是“一条 MD 或一次结构优化”，实际两条都做了：S1 结构优化与 S2 的 20 步 MD。
  • Stratmann 的容差：苯与萘放宽到
    • 激发能 3e-8；
    • 振子强度 3e-6，跃迁偶极 3e-4：激发能的误差是本征向量误差的二阶，振子强度与跃迁偶极是一阶，残差 1e-4 时偶极就差 1e-4 量级；
    • 表中最多 10 处印出的值不同，力 3e-6，激发态电荷 1e-6、偶极 1e-5。
    这些都是 DFTB+ 收敛阈值的量级；pydftb 自己的 Stratmann 与精确解一致到 1e-12（第四节）。
  • 两个 SCC 容差：
    • 外场加点电荷的算例 SCC 容差 1e-12（参考是 DFTB+ 能量的差分），两个程序在舍入误差处差一轮（30 与 31），轮数容差为 1；
    • Thresholded 的算例每轮误差不比较（屏蔽的决定随舍入翻转，同 M6h-1 的 c6h6_lc_threshold），轮数与结果照常比较。
  • Stratmann 的重新开始：设计只说“子空间满了就从 X+Y、X−Y 重新开始”。H2CO 的调试表明，要先把新方向对旧子空间投影，再判断是否满，而且新方向用完且子空间已是全空间时要返回精确解，不能报错。
