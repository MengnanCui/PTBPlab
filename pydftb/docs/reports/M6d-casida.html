关键信息

pydftb 现在能算分子的激发态：在基态 SCC 收敛后解 Casida 方程，给出垂直激发能、振子强度、跃迁偶极、主要的单粒子跃迁及其权重，也就是吸收光谱。支持单重态、三重态、两者，共线自旋极化（带自旋污染 Δ⟨S²⟩），分数占据，onsite 修正，Γ 点周期体系，能量窗口与振子窗口，指定的态与“最亮态”，并可与外电场、点电荷、色散同用。18 个新的 DFTB+ 参考算例全部通过。新功能只在 NumPy 引擎中；旧的计算路径逐位不变。激发态的力按设计放到 M6e。

  • 与 DFTB+ 一致（18 个算例）：
    • 激发能差 ≤ 1.8e-11 Ha，振子强度差 ≤ 6.1e-10，跃迁偶极大小差 ≤ 9.2e-9 e·Bohr；这几个上限来自 DFTB+ 的 ARPACK 只收敛到单精度容差，大多数算例的振子强度差在 1e-14 量级；
    • EXC.DAT 和 SPX.DAT 中打印的每个值（激发能、振子强度、主要跃迁、权重、单粒子能量、对称性或 Δ⟨S²⟩）都一致；没有简并能级的分子，pydftb 写出的两个文件与 DFTB+ 的逐字节相同；
    • 基态部分：能量差 ≤ 4.6e-11 Ha，力差 ≤ 1.4e-8 Ha/Bohr（水 1.2e-6，是 DFTB+ 数值 SK 导数的已知误差），SCC 轮数全部相同；指定态的激发能（DFTB+ 的 “Excitation Energy”）差 ≤ 4.6e-11 Ha。
  • 三种求解器：稠密对角化（"exact"）、分块 Davidson（"davidson"）、SciPy 的 ARPACK（"arpack"）。默认 "auto"：跃迁数不超过 500 时用稠密对角化，更多时用 Davidson。18 个算例用三种求解器分别对照，都通过。
  • 速度（第六节）：C60（14,400 个跃迁，10 个单重态）的激发部分 pydftb 用 0.46 s，DFTB+ 的 Stratmann 求解器 1.46 s、ARPACK 9.1 s；两者的结果与 pydftb 分别一致到 3.6e-9 Ha（Stratmann 的收敛阈值）和 1.5e-15 Ha。
  • DFTB+ 25.1 的行为（第五节）：设置 StateOfInterest 后，“Total energy” 与 mermin_energy 仍是基态能量，激发能另行打印（与手册的说法不同）；含部分占据 d 能级的 Cu4CO（300 K）上两个求解器都失败，pydftb 三种求解器都正常；Stratmann 求解器使简并态的振子强度之和只准到约 5e-7；简并能级中单个态的输出取决于求解器给出的本征向量组合。
  • 18新的 DFTB+ 参考算例，三种求解器都通过
  • ≤ 1.8e-11与 DFTB+ 的激发能差（Ha）
  • 3.2×C60 上比 DFTB+ 最快的求解器快
  • 0旧计算路径改变的位

二、怎么用

import pydftb
from pydftb.casida import Casida

mf = pydftb.SCC(system, params,
                spin_constants={"H": -0.072, "C": -0.023, "O": -0.028},   # 三重态或自旋极化时需要
                casida=Casida(n_excitations=8, symmetry="singlet"))        # "triplet"、"both"
mf.kernel()
x = mf.result.excitations
x.energies, x.oscillator_strengths, x.transition_dipoles     # Ha；无量纲；e·Bohr
x.transitions, x.weights, x.ks_energies                      # 主要的单粒子跃迁 (i, a, 自旋)，从 0 起
x.spin_contamination                                         # 自旋极化时的 Δ⟨S²⟩
x.degenerate_groups()                                        # 简并态合并后的能量、振子强度、|μ|
print(x.table())                                             # EXC.DAT
print(x.single_particle.table())                             # SPX.DAT

Casida(10, energy_window=0.05, oscillator_window=0.01,   # Ha；无量纲
       state_of_interest=-1, excited_forces=False,       # 最亮的单重态；基态的力
       solver="auto")                                    # "exact"、"davidson"、"arpack"

# ASE
calc = PyDFTB(skdir, casida={"n_excitations": 8})
atoms.calc = calc; atoms.get_potential_energy(); calc.excitations
  • 单位：能量 Ha，偶极 e·Bohr；两个 table() 与 DFTB+ 一样用 eV。
  • symmetry="both"：结果是列表 [三重态, 单重态]（DFTB+ 的顺序）；EXC.DAT 写成 xs[0].table() + xs[1].table(header=False)。自旋极化时忽略 symmetry，两个自旋通道的跃迁一起耦合。
  • 指定态：state_of_interest > 0 时 excitation_energy 给出该态的激发能，< 0 时给出最亮的单重态；energy、free_energy 仍是基态的（与 DFTB+ 的输出相同，见第五节）。这时要求力会报错，提示 M6e；excited_forces=False 给出基态的力（DFTB+ 的 ExcitedStateForces = No）。
  • 求解器："auto" 一般就够用。"arpack" 慢，只用来独立核对。
  • 限制（与 DFTB+ 相同）：需要 SCC；不能与 DFTB3、壳层分辨 SCC、非共线自旋、SOC、DFTB+U、隐式溶剂同用；周期体系只能用 Γ 点。onsite 修正可以用（DFTB+ 只在 ARPACK 求解器中支持）；外电场、点电荷、色散可以用。torch 后端和自动求导报错。
  • 简并：简并的态之间可以任意组合，单个态的振子强度、跃迁偶极、主要跃迁和权重因此不唯一；有意义的是简并组的和，degenerate_groups() 给出。

四、自洽检查

  • 三种求解器：CH3OH（12 个态）、苯（8 个态，含简并）、自旋极化的 H2CO+ 上，Davidson、ARPACK 与稠密对角化的 Ω² 差 ≤ 1e-12，按简并组的振子强度差 ≤ 1e-9；苯最低的 20 个本征对中，Davidson 与稠密解的本征值差 ≤ 1e-13，每个简并组张成同一子空间（主角余弦与 1 差 ≤ 1e-8）。
  • Casida 矩阵：单重态、三重态、自旋极化、onsite、自旋极化 + onsite 五种情形下 Ω 严格对称，不组装矩阵的乘积与矩阵相同到 1e-12（相对）；本征向量满足 Σ (X+Y)² Ω/ω = 1 到 1e-12。
  • 不耦合的极限：γ 取零时激发能等于单粒子跃迁能（1e-14），闭壳层的振子强度是单粒子值的两倍，主要跃迁就是该跃迁、权重为 1。
  • 自旋极化路径用于闭壳层：H2CO 按自旋极化算（未成对电子为 0），12 个激发能就是同一分子单重态与三重态合在一起最低的 12 个（差 8e-16），Δ⟨S²⟩ 对三重态为 2、单重态为 0（1e-8）。
  • 转动与平移：分子整体转动并平移后，激发能、振子强度不变（1e-10），跃迁偶极随分子转动。
  • 表格：EXC.DAT、SPX.DAT 由参考数据的解析器读回后，与冻结的 DFTB+ 值完全相同（闭壳层、自旋极化、单重态 + 三重态、振子窗口四种）。
  • 大体系：C60（14,400 个跃迁）的 10 个单重态与 DFTB+ 的 ARPACK 一致到 1.5e-15 Ha（激发能）和 1.5e-15（振子强度），简并组的数目相同。

五、DFTB+ 的行为

1. 指定态时的“总能量”

手册说设置 StateOfInterest 后总能量包含激发能。实测 DFTB+ 25.1 中 detailed.out 的 “Total energy” 与 results.tag 的 mermin_energy 都还是基态能量：main.F90 先写出能量，之后才把激发能加到 Etotal 和 EMermin 上。激发能另行打印为 “Excitation Energy”，结构优化与 MD 用的是 Eforce related + 激发能。pydftb 的 energy 与 DFTB+ 的输出一致（基态），激发能在 excitation_energy 中。

2. Cu4CO（300 K）上两个求解器都失败

部分占据的 Cu d 能级之间有很多接近零的跃迁。ARPACK 报 “Maximum number of iterations reached”，Stratmann 报 “TDDFT diagonalisation failure. Increase SubSpaceFactor”（加大到 60 仍失败）。pydftb 的三种求解器都给出相同的 6 个态（最低的一个 0.0051 eV，在两个几乎简并的部分占据能级之间），稠密解 0.17 s、Davidson 0.03 s。

3. Stratmann 求解器与简并

  • Stratmann 的收敛阈值是残差 1.2e-8（0.1 × 单精度 ε）。苯的简并态上，它的振子强度之和与精确值差约 5e-7，ARPACK 则差 1e-14，所以苯的参考算例用 ARPACK。C60 上 Stratmann 的激发能与精确值差 3.6e-9 Ha，ARPACK 差 1.5e-15。
  • 简并能级中，单个态的振子强度、权重、主要跃迁，以及 SPX.DAT 中单个简并跃迁的振子强度，都取决于对角化程序给出的组合，DFTB+ 与 pydftb 的不同。只有简并组的和是确定的（手册附录也这样说明）。autotest.tag 已经把简并态合并，比较时用它。

4. 输入与输出的细节

  • onsite 修正只能配 ARPACK（Stratmann 报 “Onsite corrections not implemented for Stratmann diagonaliser”）。
  • Γ 点周期体系可以算激发能，但打开力就报 “Excited state stresses not implemented”。
  • 不计算力时写 ExcitedStateForces 是输入错误（节点不被读取）；计算力而 StateOfInterest = 0 时必须写 ExcitedStateForces = No。
  • Symmetry = both 时 autotest.tag 只保留后算的单重态，三重态只在 EXC.DAT 中；EXC.DAT 只有一个表头，先列三重态。
  • EXC.DAT 中自旋极化与闭壳层的列宽不同，Ω² < 0 的行又不同（闭壳层时振子强度后的空格从 5 个变为 2 个）；pydftb 的 table() 照搬这些格式。
  • 为 M6e 先做的检查：DFTB+ 的激发态力（单重态、三重态、自旋极化）与 E0 + ω 的有限差分一致到 3e-7 Ha/Bohr。

六、速度

两个程序都用单线程，不算力，SCC 容差 1e-10。DFTB+ 一栏是加不加 ExcitedState 两次运行的时间差（激发部分），总时间包含进程启动和读写文件。pydftb 在 conda 环境（MKL）中运行，“激发部分”是 timings["casida"]。

  • 为什么 Davidson 快：Ω 是对角阵 ωia² 加一个秩不超过原子数的耦合，以对角元为预条件的 Davidson 在 C60 上 10 次迭代（约 110 次矩阵—向量乘积）就收敛到残差 1e-12；ARPACK 的 Lanczos 在 C60 这种近简并的谱上要几千次乘积。每次乘积的代价是跃迁数 × 原子数。
  • 稠密对角化与 Davidson 的分界：用 C60 前若干个跃迁组成的矩阵测得，100 个跃迁时稠密解 0.001 s、Davidson 0.004 s；500 个时两者相当（0.014 s 对 0.011 s）；1000、2000、4000 个时稠密解 0.11、0.85、6.1 s，Davidson 0.02、0.04、0.10 s，两者的本征值差 ≤ 5e-17。"auto" 因此在 500 个跃迁处切换。
  • 内存：稠密 Ω 是跃迁数的平方（14,400 个跃迁约 1.7 GB），Davidson 与 ARPACK 只存跃迁电荷（跃迁数 × 原子数）和子空间向量。

八、与设计的偏差

  • 求解器：设计是默认稠密对角化，另备 SciPy 的迭代求解器（ARPACK）。实测 SciPy 的 ARPACK 在 C60 上要 10 s（加大 Krylov 子空间后 4.1 s），比 DFTB+ 的 Stratmann（1.46 s）慢，于是加了分块 Davidson 作为大体系的默认（0.46 s），ARPACK 保留作独立核对；"auto" 的分界从计划的 4000 个跃迁改为实测的 500 个。solver 的取值因此是 "auto"、"exact"、"davidson"、"arpack"。
  • 文本输出：做了 EXC.DAT 与 SPX.DAT 两张表（格式与 DFTB+ 相同）；TRA.DAT、TDP.DAT 没有写成文本，其中的数据都在结果里（xpy 与 pairs、transition_dipoles）。
  • 算例：18 个（计划约 15 个），多了 h2co_casida_state（指定第 4 个态，基态的力）和 h2co_cation_casida_onsite（自旋极化 + onsite 修正，设计时没有列出，DFTB+ 支持这种组合）。苯改用 DFTB+ 的 ARPACK（Stratmann 的简并组精度不够，第五节第 3 条），O2 与 CuCO+ 用 Stratmann。乙烯的结构换了随机扰动的种子（4 → 12）：原来的一个 C–H 距离离 SK 网格点只有 7e-5 Bohr，落在 DFTB+ 数值求导的步长内，基态的力差 7.4e-6（与 TOL_DFTBP_FD 记录的水分子问题相同，与激发态无关）。
  • 表格的比较：设计只说简并时比较和；实际把规则写细（第三节）：简并态组比较振子强度和 Δ⟨S²⟩ 之和与排序后的单粒子能量，主要跃迁与权重只在态不简并、且 X+Y 落在简并跃迁上的部分可以忽略时比较。
  • ASE：结果用 calc.excitations（设计写的是 calc.raw.excitations，两者都可用）。
  • 新增：Excitations.degenerate_groups()（DFTB+ autotest.tag 的合并规则）；refgen --casida-solver；检查输出中每个激发态算例多一行偏差。
