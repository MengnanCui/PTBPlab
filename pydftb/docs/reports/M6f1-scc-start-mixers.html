关键信息

pydftb 现在有 DFTB+ 的全部四种电荷混合器（Broyden 之外新增 Simple、Anderson、DIIS，以及 Broyden 的全部选项），能像 DFTB+ 的 InitialCharges、InitialSpins 那样指定 SCC 的起点，也能读写 DFTB+ 的电荷重启文件 charges.bin/charges.dat。与 DFTB+ 对照的标准比“收敛到同一个解”更严：每个算例的 SCC 轮数相同，每一轮的 SCC 误差也相同。只在 NumPy 引擎中；默认设置下逐位不变。

  • 与 DFTB+ 对照：25 个新的单点算例全部通过：
    • SCC 轮数逐个相同（最长 69 轮）；
    • 逐轮的 SCC 误差相对差 ≤ 3.1e-5，多数 ≤ 1e-6（DFTB+ 只打印 8 位）；
    • 能量差 ≤ 6.3e-11 Ha，电荷差 ≤ 7.5e-11 e，共线磁矩 ≤ 2.6e-10；
    • 水二聚体 Anderson 混合的 40 步 MD，每步的 SCC 轮数都与 DFTB+ 相同（共 529 轮）。
  • 电荷文件：
    • DFTB+ 写的 21 个文件（参考算例 9 个、探针 12 个；二进制与文本，无自旋、壳层、共线、非共线、+U 的块与虚部块、k 点）读入再写出，逐字节相同；
    • 文件中的布居与 pydftb 自己算的输入布居相差 ≤ 3.9e-11；
    • 两边互相读对方的文件重启，轮数和第一轮误差都相同。
  • 接口的一处改变：mixer="anderson" 现在是 DFTB+ 的 Anderson；它原来是 pydftb 的 Pulay 型混合器的别名，那个混合器仍是 mixer="pulay"。仓库里没有代码用过 "anderson"。mixing 的默认值改为 None（取各混合器在 DFTB+ 中的默认值，Broyden 仍是 0.2）。
  • DFTB+ 的行为（第五节）：SCC 位点很少时 DIIS 和 Broyden 的历史矩阵奇异，两个程序都只是在跟随舍入；周期体系必须把 EwaldTolerance 收紧到 1e-12，否则逐轮误差差 1e-5、轮数可差 1；InitialCharges 是按壳层逐层填（aufbau），Cu 多 0.2 个电子时起点是 4s2 4p6 3d3.2，壳层分辨的 Cu4CO 要 49 轮而不是 19 轮；非共线自旋读电荷时 DFTB+ 因“未读的 InitialSpins”停止。
  • 25 + 1新的 DFTB+ 参考算例（单点 + MD），全部通过
  • 0SCC 轮数与 DFTB+ 之差（每个算例、MD 的每一步）
  • 21DFTB+ 电荷文件逐字节往返
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
pydftb/mixer.py

二、怎么用

from pydftb import DFTB, dftbplus_io

DFTB(sk, mixer="anderson")                           # "broyden"（默认）| "simple" | "anderson" | "diis" | "pulay"
DFTB(sk, mixer={"kind": "diis", "generations": 4, "use_from_start": False})
DFTB(sk, mixer={"kind": "anderson", "generations": 6,
                "dynamic_mixing": [(1e-2, 0.3), (1e-4, 0.6)]}, mixing=0.05)
r = calc.calculate(labels, positions)
r.scc_errors                                          # 每一轮的 SCC 误差，同 DFTB+ 标准输出的一列

DFTB(sk, initial_charges=[0.4, -0.4, 0.1, -0.1])      # 或 {原子: 电荷}；电子按壳层逐层填
DFTB(sk, spin=True, unpaired_electrons=0, spin_constants=w,
     initial_spins=[1.0, 0.0, -1.0, 0.0])             # 共线：每个原子 N↑ − N↓（这里是反铁磁起点）

data = dftbplus_io.read_charges("charges.bin", norb_atom)    # DFTB+ 写的文件，格式 4–8
r = calc.calculate(labels, positions, q_init=data)            # 同 ReadInitialCharges 的检查
dftbplus_io.write_charges("charges.dat", calc.charge_data(labels, r))   # DFTB+ 能读

atoms.calc = PyDFTB(skdir, read_charges="charges.bin")        # 第一次计算从文件开始
atoms.calc.write_charges("charges.bin")                       # 写最后一次计算的输入布居
  • 混合器：选项名是 DFTB+ 关键字的 snake_case（inverse_jacobi_weight、minimal_weight、maximal_weight、weight_factor；generations、init_mixing、dynamic_mixing、diagonal_rescaling；use_from_start）；mixing 是 MixingParameter，DIIS 没有它（设了报错）。
  • 起点：两者可以同用，可以与壳层分辨、+U、onsite、非共线（只用电荷）同用；电荷之和不等于 charge 时给出 RuntimeWarning 并缩放，与 DFTB+ 相同。给了 q_init 时都不用。
  • 电荷文件：charge_data 用结果的 q_in，即构造最后一个哈密顿量的输入布居，也就是 DFTB+ 写的那组。populations_from_file(..., skip_charge_test=True) 对应 DFTB+ 的 SkipChargeTest。
  • 选哪个混合器：在这里测过的体系上，DFTB+ 默认的 Broyden 几乎总是最快的（第六节）；其余的混合器主要用于复现 DFTB+ 的计算，或在 Broyden 发散时（M6a 中非共线磁矩的软模）换一个试试。

三、与 DFTB+ 的对照

  • 重启的两步中，DFTB+ 也读了 pydftb 写的文件（探针，10 个组合），轮数与第一轮误差都与它读自己的文件时相同。

四、自洽检查

  • 混合器的公式：Anderson（6 组选项）和 DIIS（4 组）与逐行照抄的 Fortran（二维存储、1 起的索引、gesv 同样的方程）在线性映射上走 8–14 步，结果一致到 1e-12。
  • 同一个解：壳层分辨的 Cu4CO 上，Simple、Anderson、DIIS、Pulay 和非默认权重的 Broyden 都收敛到默认 Broyden 的解：能量 1e-10 Ha，电荷 1e-9，力 1e-8。mixing=None 与原来的 mixing=0.2 逐位相同。
  • 起点：
    • aufbau 的数值（Cu 的 10.8 与 11.2 个电子、C、O）、“Not enough orbitals” 报错、和不为零时的警告与缩放、共线自旋按壳层的分配，都与第一节的规则一致；
    • H2CO、O2、OH、Cu4CO + U、OH 非共线：换起点后轮数不同，能量一致到 1e-10、力到 1e-8。
  • 电荷文件：
    • 7 种布局（无自旋、壳层、共线、非共线、+U、dual SOC + U、周期自旋 + U）× 二进制与文本：pydftb 写出、读回，布居与原来一致到 1e-14，从文件重启 ≤ 2 轮即收敛；
    • DFTB+ 的四项检查（通道数、checksum、电子数、磁化）与 skip_charge_test；文件的原子多于体系、文件太短、未知格式号都报错；
    • 格式 4–7 的文件（手工按 DFTB+ 的读法构造）读出的布居相同；
    • gfortran 的 list-directed 格式：取自 DFTB+ 文件的 8 种数（0、F 格式的大小数、E 格式的正负数）逐字符相同；读文本时也接受逗号和 D 指数。
  • ASE：write_charges 写、read_charges 读（.bin 与 .dat），重启 ≤ 2 轮，能量一致到 1e-8；初始磁矩与 initial_spins 给出相同的 SCC 路径，全为零时与默认起点相同。
  • 拒绝：torch 后端构造时拒绝新的混合器、初始电荷、共线初始自旋，计算时拒绝电荷文件；pydftb.autodiff.evaluate 拒绝这些选项；torch 后端的 PyDFTB 照旧忽略共线的初始磁矩。

五、DFTB+ 的行为

1. 混合器的细节

  • Anderson 的历史是一个倒序的索引环：indx(1) 指向最新的一组，存入时整个环右移一位；前 Generations 次调用用 InitMixingParameter（计数从 −1 开始）；DynMixingParameters 从最后一行往前查第一个阈值大于 |F| 的行，第一次调用不受影响。
  • DIIS 的源码中有 AddIntrpGradient，但输入解析从不设置它，恒为关。
  • 混合的向量先由 (q, m) 换成 (上, 下) 再按等价类求和；每个几何步开始时混合器重置。读了电荷文件时，第一轮的输出照常混合（不读电荷、有自旋或块时第一轮的输出直接作为下一轮的输入）。

2. 逐轮比较什么时候不可靠

情形现象处理
H2O 只有 3 个 SCC 位点，DIIS（6 个向量）各 F 之和为零（电荷守恒），第 3 个向量起 DIIS 矩阵的条件数 6e16，两个程序的轮数不同参考算例不在位点少的体系上用 DIIS
OH 自由基 + U，Broyden前 7 轮一致到 1e-8，第 8 轮（误差约 1e-6）起突然相差 30%，但轮数仍相同不作参考算例
周期体系，DFTB+ 默认 EwaldTolerance 1e-9逐轮误差相差 1e-5；CuO 链自旋 Anderson 162 轮对 161 轮周期算例都用 1e-12（pydftb 的 Ewald 本来就收敛到机器精度）
CuO 链自旋 + U，读电荷重启67 轮，逐轮误差从第 17 轮起分开，相对差达 1.5e-2（轮数碰巧相同）；换一个挪动量轮数差 1；再换一个，DFTB+ 自己发散到 NaN、500 轮不收敛换成条件好的算例（O2 + U 的文本、CuO 链自旋）
水二聚体 MD，Anderson 默认值（每步约 60 轮）41 步中有 2 步的最后一轮误差离阈值不到 1.5%，轮数差 1改用 Generations 6、β = 0.3：最近的一步离阈值 14%，每步都相同

3. 起点

  • InitialCharges 按 SKF 的壳层顺序逐层填，每层最多 2(2l+1)：给 Cu 加 0.2 个电子的起点是 4s2 4p6 3d3.2，离真实的布居很远，壳层分辨的 Cu4CO 第一轮误差 7.2、49 轮收敛（默认起点 19 轮）。对过渡金属，用它“加快收敛”往往适得其反。
  • 和不等于 Charge 时 DFTB+ 警告 “Sum of initial charges does not match specified total charge … will be rescaled”，并整体缩放到电子数。
  • 共线 InitialSpins 可以给出别的自洽解：CuO 链在 UnpairedElectrons 0、AllAtomSpins {1 0 −1 0} 下收敛到反铁磁解（Cu 磁矩 ±0.14），两个程序相同。

4. 电荷文件

  • 写的是最后一轮的输入布居；一类轨道的总量放在第一个轨道上；多极记录 0 0 总在；+U 的块只存独立元素，读入时对角用布居重建。
  • 文本是 gfortran 的 list-directed 输出：实数 17 位有效数字，所以文本与二进制一样无损。
  • 非共线自旋配 ReadInitialCharges 时，DFTB+ 不读 InitialSpins，报“The following 1 node(s) have been ignored by the parser”后停止。
  • 从挪动 0.03 Å 后的几何的电荷重启，不一定更快：H2O 8 → 6 轮、OH 非共线 SOC + U 33 → 20 轮，但 O2 三重态 2 → 4 轮（对称的默认起点本来就几乎是解）。

八、与设计的偏差

  • 算例：
    • DIIS 晚启用的算例用壳层分辨的 O2（o2_triplet_shell_mixer_diis_late）：原子分辨的 O2 只有 2 × 2 个位点，DIIS 的矩阵会奇异；
    • 周期自旋 + U 的重启（cuo_chain_spin_plusu_k422_read_charges）因 SCC 近混沌而换成 o2_triplet_plusu_read_charges_text（共线的块，文本）和 cuo_chain_spin_k422_read_charges（周期自旋）；另加 oh_noncolinear_soc_plusu_read_charges（虚部块）；
    • MD 的基础算例用 Anderson 的 Generations 6、β = 0.3（water_dimer_hdamp_mixer_anderson），默认值下有两步的收敛判断离阈值太近（第五节第 2 条）。
  • 两步算例的比较：设计打算在 JSON 中同时存文件和解析后的数组，比较头的各项和数组。实际只存文件的字节，比较“文件中的布居 = pydftb 在同一几何上算出的输入布居”（容差 1e-8，实际 ≤ 3.9e-11）；头与格式的检查放在测试里（逐字节往返）。
  • 容差：逐轮误差用相对差 1e-4（只在 DFTB+ 打印值 > 1e-7 处比较），并比较共线的磁矩。
  • 新增：torch 后端的 PyDFTB 照旧忽略共线的初始磁矩（否则以前能跑的输入会报错）；refgen --check 多打印一行 SCC 的偏差；dynamics 对用了混合器的基础算例比较每步的 SCC 轮数。
