关键信息

pydftb 现在支持 DFTB+ 的 SelectedShells：一个原子的基组由几个 SK 文件中的壳层拼成，同一个 l 可以出现两次（sps* 一类的基组）。用法是 ParamSet(skdir, selected_shells={"O": ("sp", "s")})。读文件、排轨道、取 on-site 能/U/占据数、拼表、排斥势与质量的规则都照 DFTB+。只有 NumPy 引擎；不用这个选项时逐位不变。M6f（常用缺口与分析输出）的五块至此全部完成。

  • 与 DFTB+ 对照：8 个新的参考算例全部通过，SCC 轮数逐个相同：
    • 能量差 ≤ 5.0e-11 Ha，Mulliken 电荷 ≤ 2.2e-12，周期体系的应力 ≤ 1.5e-10；
    • 力：用 DFTB+ 的差分步长时差 ≤ 1.05e-12 Ha/Bohr（精确导数与 DFTB+ 的差分导数之差最大 2.7e-6，是 DFTB+ 的数值导数，与 h2o 算例相同）；
    • 算例覆盖：Cu 的 {"sd" "p"} 重排（分子、k 点 + 应力，与普通写法相同）、O 加一个 s* 壳层（不分壳层与分壳层、自定义占据 “s2”、eigenvec.out 的 “s2” 标签）、O 与 H 都分组（每对 2 × 2 个文件）、O2 三重态（3 × 3 自旋常数）、壳层分辨的 DFTB3（每个壳层一个 Hubbard 导数）。
  • DFTB+ 的行为（第五节）：SelectedShells 与 Type2FileNames 同用时 DFTB+ 25.1 段错误，不报错；同一物种两组之间的文件按异核格式读，带 on-site 行的文件会静默地读错（pydftb 检查并报错）；排斥势只取每对物种的第一个文件，不分壳层的 SCC 时所有壳层用第一个壳层的 U。
  • 不支持：torch 后端与自动求导、自旋轨道耦合、DFTB+U、onsite 修正、Casida、类型切换（M5a），报错并写明原因。
  • 8新的 DFTB+ 参考算例，全部通过
  • 1.05e-12用 DFTB+ 的差分步长时，力与 DFTB+ 的最大差（Ha/Bohr）
  • ≤ 1e-14Cu 写成 {"sd" "p"} 与普通写法的能量差（同一基组重排，Ha）
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
skf.py
  • parse_selected_shells：两种写法（壳层字符串，第 k ≥ 2 组的文件物种默认是“标签 + k”；或 (文件物种, 壳层)），DFTB+ 的检查（每组 1–4 个字母、组内不重复）；shell_names：DFTB+ 的壳层名（同 l 第二个起加序号，“s2”）；
  • SKSet(…, selected_shells=…)：groups、group_files[(a, b)][i][j]（同核格式只用于同一标签的同一组，即 DFTB+ 的 readAtomic）、按壳层的 on-site 能/U/占据数（各取自本组的同核文件）、第一组的质量、不分壳层时第一个壳层的 U；shells、norb、cutoff、truncated 处理多组；只有一组且壳层是 s…lmax 的标签当作普通标签（走原来的代码）；
  • 检查：同一对标签的所有文件（两个方向）网格相同（DFTB+ 的 checkSKCompElec）；同一标签两组之间的文件必须是异核格式（DFTB+ 不查，会静默读错）；不分壳层时 hubbard_from 必须是 "s"。
params.py、ase_calc.pyParamSet(selected_shells=…)（所需文件的存在检查包含各组的文件；与 max_l 不能同给一个标签），PyDFTB(selected_shells=…)。
hamiltonian.pyBasis.shell_local（壳层在原子内的序号）；onsite_energies 对选定的标签按壳层累加偏移；build_pairs 对有 group_files 的标签对用 _grouped_blocks：每个组对用该组对的 A-B、B-A 两个文件调用 sk_block，放进整块的对应位置（DFTB+ getFullTable 的规则），导数（复步或 DFTB+ 的差分）走同一个函数；单组的分支原样不动。
calculator.py按 l 取每个壳层数据的地方改为按 shell_local（默认标签两者相同，逐位不变）：_sites、_reference_shell_populations、_custom_shell_populations、_site_hubbard_derivs（原来的 .index(l) 在 l 重复时取第一个，是错的）；reference_occupations 用 DFTB+ 的壳层名；_check_selected_shells 拒绝 SOC、+U、onsite 修正、Casida、类型切换；numpy_only_options 加 selected_shells（torch 后端与 pydftb.autodiff 因而报错）。
validation/Case.selected_shells（文件由 typed 的类型副本提供）；dftbplus.sk_files_block 逐对列出 nA × nB 个文件，make_hsd 写 SelectedShells；refgen 的两条运行路径与中性布居（按壳层名套用自定义占据）；8 个算例与参考 JSON。
测试tests/test_selected_shells.py（12 项）；test_reference.py 的差分步长对照加上两个水分子算例。

二、怎么用

from pydftb import DFTB, ParamSet
p = ParamSet(skdir, selected_shells={"O": ("sp", "s")})                  # 第二组读 O2-O2.skf、O-O2.skf、O2-H.skf …
p = ParamSet(skdir, selected_shells={"O": (("O", "sp"), ("Ox", "s"))})   # 写明每组的文件物种
r = DFTB(p.skset(["O", "H"]), reference_occupations={0: {"s2": 0.0}}).calculate(labels, pos)
atoms.calc = PyDFTB(skdir, selected_shells={"Cu": ("sd", "p")})          # s、d、p 的顺序
  • 同一标签两组之间的文件（O-O2.skf）要用异核格式：从已有文件做副本时用 pydftb.skf.write_typed_copies（它去掉 on-site 行）。同一对标签的所有文件网格要相同。
  • spin_constants 是 n壳层 × n壳层 矩阵（或一个数），壳层分辨时 hubbard_derivs 与 hubbard 每个壳层一个值，顺序都是上面的壳层顺序。
  • 额外的壳层若与近邻重叠太大，重叠矩阵会不正定（第五节）。

四、自洽检查

  • 重排：Cu 写成 {"sd" "p"}（p 组取自 Cu 的副本）与普通写法是同一个基组换了顺序。pydftb 两种写法的能量差 1e-14 Ha，力差 4e-15，电荷差 2e-14，SCC 轮数相同；周期 fcc（3 × 3 × 3 k 点、斜晶胞）的应力差 ≤ 1e-12。
  • 单组即默认：selected_shells={"O": ("sp",), "H": ("s",)} 与普通的 SKSet 逐位相同（能量、力、电荷）。
  • 力与能量的差分：O {"sp" "s*"}（壳层分辨、s2 = 0、300 K）的 9 个力分量与自由能的中心差分一致到 2e-8 Ha/Bohr（步长 2e-6 Bohr，SCC 容差 1e-12）。步长要小：DFTB+ 式的 SK 插值在网格点处导数不连续，这个几何的 H–H 距离（3.059995 Bohr）比网格点 3.06 小 5e-6，步长 5e-4 的差分即使用 Richardson 外推也差 8e-6——普通写法也一样，是插值的性质，不是错误。
  • 按壳层的数据：O 三个壳层的 on-site 能、占据数取自各自组的同核文件，不分壳层时三个 U 都是 O 的 s 的 U，壳层分辨时 s* 是 H 的 U（测试逐项核对）。

五、DFTB+ 的行为

  • SelectedShells 与 Type2FileNames：Type2FileNames 每对物种只给一个文件，而 readSKFiles 按组数去取，DFTB+ 25.1 读完第一个文件后段错误（返回码 −11），没有错误信息。pydftb 的文件名由标签与组号生成，不存在这个问题。
  • 文件格式：同核格式只用于同一物种的对角组（readAtomic）；同一物种两组之间的文件按异核格式读，带 on-site 行就整体错一行，DFTB+ 不报错（与坑 88 相同的机制）。pydftb 检查第二行，带 on-site 行时报错。
  • 取值规则（探针确认）：排斥势只取每对物种的第一个文件；质量取第一组的同核文件；不分壳层的 SCC 时所有壳层用第一个壳层的 U；同一对物种的文件网格必须相同（否则 DFTB+ 报错，pydftb 同样报错）。
  • 重叠矩阵不正定：水盒子中给 O 加 s*（H 的 1s 放在 O 上）时，s* 与近邻 H 的 1s 重叠太大，S 的 Cholesky 分解失败（DFTB+ dpotrf info 104）。这是参数的问题：周期体系的验证改用 Cu 的重排。
  • 与本块无关的旧现象：9 个电子的水在 0 K 时最高能级半满，3 个 SCC 位点的 Broyden 历史矩阵奇异（坑 65，M6f-1 已记录），两个程序在第 6 轮（误差 5e-9）后走向不同。例如普通的水负离子 pydftb 42 轮、DFTB+ 7 轮，能量仍一致到 2e-11。h2o_selected_s2_noocc 因此用 300 K。

七、与设计的偏差

  • 算例：h2o_selected_s2_noocc 用 300 K（0 K 时 9 个电子的半满能级使 3 个位点的 Broyden 历史奇异，见第五节）；h2o_selected_s2 同时比较 eigenvec.out（“s2” 标签）。
  • 容差：水分子算例的力容差 5e-6（DFTB+ 的差分导数最大差 2.7e-6，h2o 算例用 2e-6），用 DFTB+ 的步长时 pydftb 复现到 1e-12（差分模拟测试）；带自定义占据的算例沿用 M6f-2 的 TOL_FILL。
  • 检查：比 DFTB+ 多查一项——同一标签两组之间的文件必须是异核格式；不分壳层时只接受 hubbard_from="s"（DFTB+ 的做法）。
  • 力的自查：设计中的差分步长按网格点上导数不连续改为 2e-6。
