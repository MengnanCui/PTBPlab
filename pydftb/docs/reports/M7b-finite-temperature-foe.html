关键信息

pydftb 现在可以不做本征分解，算出有限温度的 Fermi 密度 f((H − μ)/kT)、能量加权密度 W 与熵 TS：solver="foe"。方法是 Niklasson 的递归 Fermi 算符展开，每步一次矩阵乘法与一次 Cholesky 分解。M7a 的纯化只给 T = 0 的投影，体系要有带隙；新求解器处理金属，k 点与两个自旋通道可以共用费米能级，也可以用固定费米能级或每个 k 单独填充。DFTB+ 在 conda-forge 的构建里没有对应的求解器（它的有限温度 ELSI 求解器是 PEXSI），所以参照是 pydftb 自己的本征分解与 DFTB+ 本征分解的冻结参考。只有本征分解的旧计算逐位不变。

  • 对精确电子数的本征分解（fermi_level="exact"）：11 种哈密顿量下能量与自由能 ≤ 1.0e-12 Ha，电荷 ≤ 2.2e-12 e，力 ≤ 7.0e-13 Ha/Bohr，TS ≤ 8.5e-15 Ha，SCC 轮数全部相同；最大的一组来自固定费米能级的 38 轮 SCC，其余 ≤ 6.5e-14。这 11 种是：无自旋金属、共线自旋、两种共用费米能级的自旋、SOC、分子与 k 点的杂化、k 点（含应力）、+U、固定费米能级、每个 k 单独填充。
  • 对 DFTB+ 的参考：refgen --check --solver foe 跑全部 103 个适用的 Fermi 填充、T > 0 的参考，全部通过。其中 102 个的 SCC 轮数与 DFTB+ 相同。另 1 个是每个 k 单独填充的 CuO 链：DFTB+ 在某些 k 点用带隙中点，精确电子数走 17 轮而非 18 轮，能量差 2.3e-11 Ha，与精确电子数的本征分解差 1.8e-15 Ha。
  • 数值：
    • 递归写成 D = X − ½ 的形式（D ← 2D(1 + 4D²)−1），舍入不随步数增长。
    • 化学势用精确平移 P(μ + d) = P[P + e−βd(1 − P)]−1 在 ±5 kT 内求；SCC 与 MD 从上一个 μ 出发，通常每次一次递归。
    • 熵来自各步的对数行列式，到 1e-14 Ha。
    • 极低温自动加步：0.1 K 用 29–31 步，密度仍到 1e-13。
  • 速度：本机 4 核上一次递归是本征分解的 10–16 倍（288–3072 个轨道）。价值在 GPU 与之后的稀疏版本（M7c）。
  • 103 / 103适用的 DFTB+ Fermi 参考算例通过
  • ≤ 1e-12能量对精确电子数的本征分解（Ha）
  • 10–16×CPU 上一次递归相对本征分解的耗时
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
fermi_operator.py（新）
  • Recursion：从 X0 = ½ − T/4 出发，D 形式加倍 n 步，n ≥ 22，并保证 ‖T‖1 ≤ 2−8。它记下 D 与熵需要的 tr ln(1 + e−Y′)。
    • shifted(d)：精确平移，一次 Cholesky。
    • entropy：用 P 自己的 Y′ = Y + Y³/(12·4n) + Y⁵/(80·16n)。
  • chemical_potential：
    • 电子数已到 1e-14（相对），就直接接受；
    • 否则看 ±5 kT 窗口：目标在窗口内用 Newton 加二分；
    • 在带隙里（|N − 目标| ≤ 1e-11）接受；
    • 窗口外从窗口边按 Newton 走一步，或在 Gershgorin 界内二分，再递归一次。
  • FermiOperator（eigenpairs = False，finite_temperature = True）：
    • prepare(S)：用 M7a 的 Newton–Schulz 求 S−1/2，自旋通道重复的一半不重算。
    • density(...)：返回 (ρ, W, μ, TS)，可传固定 μ、每个 k 单独填充、共用 μ 的通道数。
    • solve：闭壳层接口。
    • μ 留作下一次调用的起点。
  • NumPy 或 torch；torch 的 Cholesky 在 linalg_device 上。
calculator.py
  • _check_fermi_operator：只用 Fermi 填充且 T > 0；要本征对的分析报错，与 NTPoly 共用 _check_density_analysis。_check_filling 对 FOE 放开固定费米能级与每个 k 单独填充。
  • _solve_fermi_operator：无自旋、两分量、两个自旋通道各自或共用 μ，固定 μ，每个 k 单独填充；TS 用求解器给的值。
  • _solver_object：solver="foe" 时每个计算器一个 FermiOperator，_scc、_scc_hybrid、_scc_hybrid_kpoints 都用它，下一个几何从上一个 μ 出发。
  • torch 的设备分支也用于 FOE。
ase_calc.pyASE 每一步新建一个 DFTB 对象，所以 solver="foe" 在构造时换成一个所有步共用的 FermiOperator。
solvers.pySOLVERS["foe"]；PEXSI 的拒绝改为指向 "foe"。
validation
  • refgen --check --solver foe：不适用的算例打印原因跳过（foe_skip）。
  • 没有本征值时不比较 SCC 的本征值。
  • SCC 轮数或每轮误差与 DFTB+ 不同时，用精确电子数的本征分解确认（_compare_fermi_rule）：它的轮数与 FOE 相同、能量差 ≤ 1e-10，就判定差别来自 DFTB+ 的带隙中点规则，轮数不再计较。能量、电荷与力照常比较。
测试新文件 tests/test_fermi_operator.py：35 项（见第六节）。

二、怎么用

DFTB(sk, solver="foe", temperature=1000.0)    # 金属、k 点、自旋都可以
from pydftb.fermi_operator import FermiOperator
DFTB(sk, solver=FermiOperator(steps=24), smearing=("fermi", 300.0), backend="torch")
PyDFTB(skdir, solver="foe", smearing=("fermi", 1000.0))   # ASE：μ 在 MD 的步之间延续
  • 结果：eigenvalues 与 occupations 为 None；fermi（自旋时 fermi_spin）是求出的化学势；TS 与 Mermin 自由能与本征分解相同。
  • 费米能级规则：新求解器求精确的电子数，即 pydftb 的 fermi_level="exact"。DFTB+ 与 pydftb 的默认在有带隙时取 HOMO–LUMO 的中点，这需要本征值，所以不仿照。有带隙时电荷差 < 1e-7 e；报出的费米能级可以是隙中任意一点，因为那里电子数平到舍入。
  • 能用的：
    • 只需要 ρ、W 与 TS 的功能：力、应力、优化、MD、XL-BOMD（T > 0 用 dynamics）。
    • SCC 的各项（DFTB3、+U、onsite、外场、点电荷、溶剂、色散、修正），杂化（分子、Γ 点、k 点），两分量。
    • 按原子的能量、净布居、CM5、键分析。
    • 能带与 DOS（后处理在 SCC 电荷上对角化）。
  • 报错的：MP 与 Gaussian 展宽；T = 0（提示用 "ntpoly"）；要本征对的分析（eigenvec.out、Pipek–Mezey、响应与坐标导数）；Casida。

  • 费米能级：有带隙的分子（OH、O2、CH3 杂化）上，两种做法的 μ 都是隙中的某一点，相差可到 0.1 Ha，密度与能量不受影响。
  • 力是 Mermin 自由能的导数：Cu4CO 300 K，scc_tol 1e-12，两个坐标的中心差分（步长 1e-4 Bohr）与解析力差 1.0e-8 Ha/Bohr（差分的截断误差）。
  • 动力学：
    • ASE 的 Velocity Verlet（Cu4CO，1000 K，6 步）与本征分解的轨迹相同；每次密度调用都只要一次递归，从上一个几何的 μ 出发。
    • XL-BOMD（水二聚体，快速模式，2000 K，15 步）：总能量差 2.6e-13 eV，位置差 5.8e-15 Å，每步的 SCC 轮数相同。
  • 能带：CuO 链 FOE 的 SCC 之后，能级与本征分解的 SCC 之后差 1.1e-15 Ha（后处理在 SCC 电荷上对角化）。
  • torch：
    • float64 与 NumPy 差 ≤ 3.4e-14（能量、电荷、力、TS），SCC 轮数相同。
    • float32 时 scc_tol 1e-5：能量 ≤ 7.6e-7 Ha，电荷 ≤ 4.4e-6 e，与 float32 的本征分解同一量级。

四、对 DFTB+ 的参考

517 个冻结参考里，103 个是 Fermi 填充、T > 0、不需要本征对的算例，全部用 solver="foe" 检查，用原来的容差。跳过的 414 个：347 个 T = 0，42 个要本征对的分析（响应、坐标导数、本征矢），13 个 DFTB+ 的 Solver 算例（M7a），10 个 MP 与 Gaussian 展宽，2 个 Casida。

  • 103 个全部通过；102 个的 SCC 轮数与 DFTB+ 相同。
  • cuo_chain_k422_indep_k（每个 k 单独填充）：精确电子数走 17 轮，DFTB+ 是 18 轮，能量差 2.3e-11 Ha，电荷 4.7e-11 e。DFTB+ 在某些 k 点的带隙里取中点，改变了 SCC 的路径。精确电子数的本征分解同样走 17 轮，与 FOE 差 1.8e-15 Ha，所以这是规则的差别。
  • 其余算例中，费米能级规则使 20 个（Cu4CO 壳层分辨、CuO 链自旋、Cu4CO +U 等）与 DFTB+ 差 1e-11–2e-8，都在容差之内，轮数相同（P105）。
  • 固定费米能级的 5 个算例与每个 k 单独填充的 3 个算例（原型不做）全部通过。
  • torch 后端：可用 torch 的 31 个算例全部通过；其余用了只有 NumPy 的物理（两分量、块势、外场等）。

五、数值、低温与速度

  • 递归本身（P105 记录的 4 个收敛 H，对本征分解与精确电子数）：密度 ≤ 4.9e-14，W ≤ 4.4e-15，μ ≤ 1.5e-15 Ha，TS ≤ 4.5e-16 Ha。固定 μ、每个 k 单独填充、两个通道共用 μ 也一样。从 μ 已知出发每次一次递归。
  • D 形式与 X 形式：X 形式的舍入随步数翻倍（约 2nε），在 48 个参考里多走了 SCC 轮数，5 个不收敛（P105 的第一版）；D 形式到 22–31 步都 ≤ 3.5e-13。
  • 熵：tr ln(1 + T/2) 的级数，T 不定，所以按上界 N‖T/2‖1j/j 停，不按迹停。实现时发现：按迹停时，若 μ0 正好在对称的能级中间（每个 k 单独填充的 Li），奇次项的迹为零，级数就提前停了，熵差 4.8e-6，TS 差 3e-8 Ha。改正后 ≤ 1e-14；测试里有对称谱的回归检查。
  • 低温：‖Y‖1 > 2n−8 时自动加步：
    • Cu4 LC：10 K 用 22 步，1 K 用 25 步，0.1 K 用 29 步；
    • Cu4CO：10 K 用 24 步，1 K 用 27 步，0.1 K 用 31 步；
    • 密度都 ≤ 3.5e-13，TS ≤ 2e-14 Ha。
    低温下熵本身的绝对误差约为 ‖Y‖Nε（它的各项互相抵消）；乘以 kT 之后仍在舍入。μ 搜索从头开始时，低温要 10–16 次递归（窗口只有 ±5 kT），SCC 中仍是一次。
  • 速度（P106，本机 4 核，1000 K，Γ 点，非 SCC 的 H0）：
    体系 / 轨道本征分解FOE（μ 已知）倍数FOE 从头（递归次数）S−1/2

    水 64 / 3840.022 s0.21 s9.60.47 s（2）0.025 s
    Cu 3×3×3 / 9720.11 s1.34 s12.73.06 s（2）0.23 s
    水 216 / 12960.26 s3.24 s12.63.08 s（1）0.51 s

七、与设计的偏差

  • NTPoly 的接口不改：设计让 NTPoly.density 也返回 TS = 0。实际上计算器按 finite_temperature 区分两种求解器，NTPoly 的路径一字未改。
  • 低温自动加步：设计在 βρ 太大时报错。现在自动加步，并留 28 的余量，使 tr ln(1 + T/2) 的级数短。测到 0.1 K。
  • 熵级数的停止条件：实现时发现的问题，见第五节。
  • μ 的延续：设计只说 “μ 留给下一次调用”。字符串 "foe" 原来每个几何新建一个求解器，μ 就丢了；现在每个计算器一个，ASE 的计算器另外共用一个。电子数已到 1e-14 时直接接受，省下窗口检查的两次 Cholesky。
  • refgen 的规则确认：设计说 “费米能级规则的差别都在容差之内”。能量确实如此，但每个 k 单独填充的 CuO 链的 SCC 少走一轮，所以 --solver foe 加了用精确电子数的本征分解确认的步骤（第四节）。
  • 响应：照设计拒绝。实际上响应模块在最终的 H 上自己对角化，原则上可以接在 FOE 的 SCC 之后。为与 M7a 一致仍然拒绝，因为那样的计算本来就要做一次本征分解。
  • 其余按设计。
