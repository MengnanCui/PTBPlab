关键信息

pydftb 现在能算三样东西：

  • DFTB+ Analysis 中的 CoordDerivatives：原子位置的一阶响应，给出电荷导数、Born 电荷、本征值与费米能级的导数；
  • Driver = SecondDerivatives：对力做中心差分得到 Hessian，同时给出偶极与极化率的导数；
  • DFTB+ 的 modes 程序：简正模的频率、红外与拉曼强度。

坐标响应建在 M6g-1 的响应代码上，加上 H0、S 和势对位置的导数。DFTB+ 拒绝或算错的五种情况（自旋、金属、简并、外场与点电荷、25.1 的 DFTB3），pydftb 都给出能量的正确导数。只有 NumPy 引擎；不开这些选项时逐位不变。这是 M6g 的第二块。

  • 与 DFTB+ 对照：20 个新的参考算例全部通过，SCC 轮数相同（DFTB3 对照开发版，轮数不同，见第三节）：
    • 与 25.1 的 CoordDerivatives：电荷导数差 ≤ 2.3e-12 e/Bohr，Born 电荷 ≤ 4.2e-12，detailed.out 两块打印的数字全部相同；DFTB3 与开发版同样一致；
    • DFTB+ 拒绝或算错的情况：解析 Born 电荷与 DFTB+ 自己的差分 Born 电荷一致到 4.8e-8（差分的截断误差）；
    • 数值 Hessian ≤ 1.4e-8 Ha/Bohr²（用 DFTB+ 的 SK 差分步长），偶极导数 ≤ 4.9e-8，极化率导数 ≤ 3.5e-7；
    • modes：频率 ≤ 6.5e-9 Ha（1.4e-3 cm−1），强度相对差 ≤ 6.9e-8。
  • DFTB+ 的行为（第五节）：
    • CoordDerivatives 的 Born 电荷是 −∂μ/∂x，与 born.out 反号；
    • 25.1 漏了 DFTB3 的项（差 1.4e-2），外场与点电荷对位置的导数两个版本都漏了（差 1.7e-2、0.12）；
    • 只支持无自旋、无简并的绝缘体分子；
    • SK 表插值的导数在格点处跳变，有限差分看得到；
    • （实现时发现）响应的占据窗口截掉离空或离满不到 1e-7 的能级，3000 K 的金属响应因此差约 2e-7。M6g-1 的极化率也受影响；新选项 filling_tol 给出精确导数。
  • 不支持：周期体系的坐标导数（Born 电荷要 Berry 相位，同 DFTB+）；+U、onsite 修正、非共线自旋与 SOC（M6g-3）；M6g-1 拒绝的其他组合；torch 与自动求导。数值 Hessian 只调用 calculate，能给力的组合都能用。
  • 20新的 DFTB+ 参考算例，全部通过
  • ≤ 4.2e-12Born 电荷与 DFTB+ 25.1 的最大差（e）
  • 5DFTB+ 拒绝或算错、pydftb 给出正确导数的情况

开发细节一、做了什么
位置内容
response.py
  • coordinate_derivatives：对每个位移的原子 K 和方向 c：
    • H0′、S′ 取自原子对的导数块（dh、ds，系数 δBK − δAK），只有 K 的行非零，CTH′C 按行算；
    • 基态势的项 Ω = ½S′(vμ + vν)，每个自旋通道一份；
    • 裸的一阶密度 X = W∘(M − ε̄N) − f̄N，W 由 M6g-1 的成对权重散布（窗口、θ 权重、带内项、简并组整组处理），加上密度不变时的 Mulliken 项 ρS′ 和金属的费米能级移动；
    • 电荷固定时势的导数：γ 的短程部分（含 H–X 阻尼与 H5）和 1/r、三阶的 ∂Γ/∂R、外场与点电荷的梯度；
    • SCC 响应 (I − AB)x = x0 + A·δV，与 M6g-1 相同的未知量；
    • 由此得到 Born 电荷、逐原子与逐轨道的电荷导数、本征值导数（简并组取组内块的本征值）、金属的 dEF/dx。
  • 辅助函数：coordinate_atoms（选项 {"atoms": [...]}）、static_weights、coulomb_jacobian、third_order_jacobian、external_jacobian；Response.potentials_with；结果类 CoordDerivativesResult。
  • perturbation 新增 filling_tol，GroundState 按它定窗口（第五节）。
vibrations.py（新）second_derivatives（DFTB+ 的位移顺序，每个位移从参考几何的电荷开始；周期体系不给偶极导数）与结果类 SecondDerivatives；normal_modes（质量加权、投影、规范、强度、合并，照 modes）与 NormalModes；masses_of（SKF 中的质量）。
analysis.py、calculator.py、constants.pyAnalysis(coord_derivatives=True | {"atoms": [...]}) 与 AnalysisResult.coord_derivatives，XL-BOMD 时报错；_check_response 同样检查坐标导数；新常数 HARTREE_CM（DFTB+ 的 Hartree__cm = 2 Rydberg/100）。
dftbplus_io.pycoord_derivative_tables(r, dftbplus_sign=True)（detailed.out 的两块）、write_band_derivatives(path, r, "coordinate")（dBand_dx.out）、write_hessian、write_born、write_born_derivatives（部分 Hessian 用 .a-b 文件名）、born_table、format_tag、write_vibrations_tag。
validation/
  • dftbplus.py：CoordDerivatives = Yes 的输入；hessian_driver（Driver = SecondDerivatives，部分 Hessian 的 Atoms、MovedAtoms）；parse_second_derivatives（hessian.out、born.out、bornderiv.out、results.tag 与 detailed.out）、run_modes 与 parse_vibrations_tag；tag dqdx、borncharges 与 dBand_dx.out；
  • cases.py：Case.fd_delta（按算例的 SK 差分步长）、Case.hessian（另跑一次 SecondDerivatives，可带 modes），20 个算例；
  • refgen.py：坐标导数的比较（dqdx、born、coord_text），_compare_hessian（born_fd、hessian、hess_born、hess_dpol、hess_text，modes 的频率、强度与振型）。
测试tests/test_vibrations.py（23 项）。

二、怎么用

from pydftb import DFTB
from pydftb.vibrations import second_derivatives, normal_modes, masses_of

r = DFTB(sk, analysis={"coord_derivatives": True}).calculate(labels, pos)
c = r.analysis.coord_derivatives
c.born                     # (n_K, 3, 3)：[K, i, j] = dmu_j/dx_Ki（物理符号，e）
c.atom                     # (n_K, 3, n_qm, n_atom)：dN_B/dx_Ki（电子布居，e/Bohr）
c.eigenvalue_derivatives   # (n_K, 3, n_block, n_level)：d eps/dx（Ha/Bohr）
c.fermi_derivatives        # 金属：(n_K, 3, n_channel)

calc = DFTB(sk, analysis={"polarisability": True})      # 带极化率时也给 d alpha/dx
sd = second_derivatives(calc, labels, pos)              # 6N + 1 次计算
nm = normal_modes(sd.hessian, masses_of(calc, labels), pos,
                  born=sd.dipole_derivatives, born_derivatives=sd.polarisability_derivatives,
                  remove_translation=True, remove_rotation=True)
nm.wavenumbers, nm.ir, nm.raman                         # cm^-1，虚频为负
  • {"coord_derivatives": {"atoms": [0, 3]}} 只位移这些原子（开发版 DFTB+ 的 WrtAtoms）。
  • {"perturbation": {"filling_tol": 1e-15}}：金属的精确导数（默认用 DFTB+ 的占据窗口，第五节）。
  • second_derivatives(..., atoms=..., moved_atoms=..., delta=1e-4)：部分 Hessian 的行是 atoms 的梯度分量、列是 moved_atoms 的位移坐标（同 DFTB+）。只调用 calculate，所以周期体系、自旋、DFTB3、外场等能给力的组合都能用。
  • normal_modes(..., triangle="modes") 照 modes 只读 Hessian 的一半；默认先对称化。
  • 写出 DFTB+ 格式：dftbplus_io.coord_derivative_tables(r)、write_band_derivatives(path, r, "coordinate")、write_hessian(path, sd)、write_born(path, sd)、write_vibrations_tag(path, nm)。
  • 计算量：坐标导数是一次单点的 1.1–1.3 倍（水、甲醇、Cu4CO），C60 是 3.1 倍；数值 Hessian 是 6N + 1 次单点（甲醇 0.67 s）。

三、与 DFTB+ 的对照

DFTB+ 25.1（DFTB3 对照开发版 041e723），测试参数 ptbp_hcocu。两边都用 SCC 容差 1e-12（差分把 SCC 误差放大约 5000 倍），pydftb 用 DFTB+ 的 SK 差分步长 fd_delta = 2−13 Bohr，所以 H0′、S′ 与力逐项相同。基态的能量、力、电荷与 SCC 轮数照旧比较，全部在容差内。

四、自洽检查

与差分比较时用精确的 SK 导数，几何避开 SK 格点：参考算例中的水，H–H 距离离格点只有 4.8e-6 Bohr，所以水与甲醇都先移动几个毫埃（第五节）。

  • Born 电荷对偶极的四阶差分（步长 1e-4 Bohr）：
    • 水（DFTB2、壳层分辨、非 SCC、外场中、点电荷旁）≤ 2.4e-11；
    • DFTB3 的甲醇 1.3e-10；水阳离子二重态 1.5e-11；
    • CO2（简并）1.1e-10；Cu4CO（3000 K，filling_tol = 1e-15）1.5e-9，用 DFTB+ 的窗口时 4.7e-7。
  • 电荷导数与求和规则（水负离子 300 K、水阳离子二重态）：
    • dN/dx 与布居的差分一致到 1e-7 以内（实际约 3e-11）；
    • 电子数守恒 ΣBdNB/dx = 0、平移不变 ΣKdNB/dxK = 0，都到 1e-11；
    • 声学求和规则 ΣKZK = Q·I（Q = ∓1），到 1e-10。
  • 本征值与费米能级：dε/dx 与本征值的差分一致到 1e-7 以内；金属的 dEF/dx 与费米能级的差分 < 1e-8。
  • 与旋转无关：CO2 的简并 π 能级在组内任意旋转，Born 电荷不变（< 1e-9）。
  • 选项：只位移原子 [4, 1] 时结果是完整结果的对应行（1e-12）；加色散，Born 电荷逐位相同。
  • 数值 Hessian：
    • 甲醇的 Hessian 对称（相对 1e-6）；部分 Hessian 等于完整 Hessian 的子块（1e-9）；计算次数正好 6N + 1；
    • 步长 1e-3、5e-4、2.5e-4 Bohr 时相邻两次的变化之比为 4.00（中心差分的 O(δ²)）；
    • 差分偶极导数等于解析 Born 电荷（1e-6 以内）；dα/dx 等于极化率的差分。
  • 简正模：投影后甲醇有 6 个、CO2 有 5 个零频，它们没有强度；默认的对称化与直接对角化对称化的质量加权 Hessian 一致；本征向量正交归一。

五、DFTB+ 的行为

  • Born 电荷的符号：CoordDerivatives 的 Born 电荷（tag borncharges 与 detailed.out）是 ΣBRB∂NB/∂x + δ·ΔN = −∂μ/∂x，而 DFTB+ 自己的偶极是 Σ(q0 − q)R，born.out 是 +∂μ/∂x：两个输出正好反号。pydftb 用物理符号，coord_derivative_tables 写 detailed.out 时默认照 DFTB+（dftbplus_sign=True）。
  • 25.1 漏了 DFTB3 的项：带完整三阶时 CoordDerivatives 照常运行，但三阶对位置的导数与它的线性项都没有，甲醇的 Born 电荷差 1.4e-2，不提示。开发版已修（与差分差 1.1e-8）。
  • 外场与点电荷：两个版本都漏了外势对原子位置的导数（在场中移动原子会改变它感到的势），水的 Born 电荷在 0.3 V/Å 的场中差 1.7e-2，点电荷旁差 0.12（开发版 0.077）；非 SCC 时连 ½dS·V 项也没有。
  • 拒绝的组合（25.1 的原话）：自旋（“Spin polarised calculations are not yet supported for coordinate derivative perturbations”）、金属（“… not currently supported for metallic systems”）、任何一对简并能级，包括两个空轨道（“… for high-symmetry/degenerate systems”）、周期体系（“Missing at moment”）。原因是一阶密度只用 Uji = fi(H′ − εiS′)ji/(εi − εj)，没有费米面项与费米能级的移动。还要求 Differentiation = FiniteDiff（Richardson 报错），差分步长 1e-3 时 Born 电荷差 5.5e-5。
  • 输入与输出：
    • 25.1 的 CoordDerivatives 只认逻辑值，WrtAtoms 只有开发版有；
    • tag dqdx 是逐轨道的 +dN（e/Bohr），detailed.out 的电荷导数块是 −dN/dx（e/Å），Born 电荷块每个原子三行、不写原子号；
    • 标准输出的 “dEi/d (eV / AA)” 实际单位是 Ha/Å；dBand_dx.out 用 eV/Bohr；
    • SecondDerivatives：只有 CoordDerivatives、没有 Polarisability 时也写 bornderiv.out，内容全是 0；部分 Hessian 写 hessian.out.2-3，同时留下一个空的 hessian.out；周期体系也写 born.out，只警告 “not well defined”。
  • modes：
    • 不投影时用 Hessian 的上三角，投影时用下三角，Hessian 不对称时两种情况读的是不同的一半；
    • 投影掉的平移与转动只要 λ 因舍入为正就算强度（λ 的符号是噪声），pydftb 不给它们强度；
    • 25.1 的 modes 不认 SlaterKosterFiles = Type2FileNames，质量要逐个写 X-X 文件或用 Masses；部分 Hessian 必须是方阵。
  • SK 插值的格点跳变：DFTB+ 在相邻 8 个格点上做多项式插值，越过格点时换一组点，数值连续、导数跳变。参考算例中水的 H–H 距离 3.0599952 Bohr 离格点 3.06 只有 4.8e-6，步长 1e-4 的差分跨过格点：DFTB+ 自己的 Hessian 在 H–H 块不对称 1.9e-4（用精确的 SK 导数时 6.5e-3），pydftb 也一样。参考算例因此用与 DFTB+ 相同的 SK 差分步长，自洽检查用移开格点的几何。
  • 占据窗口（实现时发现）：DFTB+ 的响应只让“部分占据”的能级改变占据。math/counting.F90 规定占据数大于 elecTolMax（1e-7）的能级可以占据，离满大于 epsilon(1.0)（单精度 ε，1.2e-7）的能级可以空出（emptyStates 接受容差参数却不用）。窗口外的能级在 3000 K 时 δ = βf(1 − f) 仍有约 1e-5，被截掉后 Cu4CO 的 Born 电荷差 4.7e-7（相对 2e-7），CuO 2.5e-7。
    • 设计以为这是差分的误差。查明的办法：换步长误差不变（2e-4、1e-4、5e-5 都是 4.72e-7）；非 SCC 时也有；本征值导数精确；30000 K 的水（能级稀疏）一致到 1e-11；把两个阈值都改为 0 后降到 1.5e-9。
    • M6g-1 的极化率与响应核照 DFTB+ 截断，所以与 DFTB+ 一致到 1e-11，但金属的结果同样偏离物理值约 1e-7。
    • pydftb 默认照 DFTB+（旧结果不变），新选项 analysis["perturbation"]["filling_tol"] 给一个正数时两边都用它，1e-15 包含所有部分占据的能级。

七、与设计的偏差

  • 算例（共 20 个）：
    • O2 三重态与 Cu4CO 的 Hessian 不单列，由 o2_triplet_dx、cu4co_dx_3000K 附带的 SecondDerivatives 比较；h2o_dx 也附带一次，检查解析 Born 电荷与 DFTB+ 的差分；
    • modes 不单列，附在 Hessian 算例上：h2o_hess_pol（不投影）、h2o_hess_projected、ch3oh_hess_dftb3、co2_hess_pol；
    • 新增 h2o_cation_dx：O2 的 Born 电荷按对称为 0，自旋的 Born 电荷要用有极性的开壳层体系检查；
    • Case.modes、Case.born_fd 合进 Case.hessian（{"modes": {"remove": …}}）与分析选项 "dftbplus_coord": False。
  • 容差：所有算例两边的 SCC 容差 1e-12（差分把 SCC 误差放大约 5000 倍，1e-10 时 Hessian 只准到 1e-6）；Hessian 1e-7（设计 1e-8，实际 ≤ 1.4e-8）、差分偶极导数 5e-8、dα/dx 1e-6（实际 3.5e-7）、modes 的强度相对 1e-5、振型 1e-4；DFTB3 对开发版的 SCC 轮数容差 10。
  • 金属：设计把 Cu4CO 的 4.8e-7 归于差分误差，实际是 DFTB+ 的占据窗口（第五节）；新增 filling_tol，金属算例用 1e-15 后与 DFTB+ 的差分一致到 4.8e-8，与其他算例相同。
  • 接口：质量用 vibrations.masses_of(calc, labels)，不在 DFTB 上加方法；投影掉的刚体运动不给强度（modes 给噪声）。
  • 自洽检查的几何：水与甲醇移开 SK 格点几个毫埃（参考的水与甲醇各有一个距离离格点 4.8e-6、1.6e-4 Bohr）。
