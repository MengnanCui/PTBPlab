关键信息

pydftb 经 ASE 做结构优化和分子动力学，结果与 DFTB+ 自带的驱动一致：11 个对照算例中，优化终点的能量差 ≤ 5e-11 Ha、结构差 ≤ 2.2e-6 Å、晶格常数差 ≤ 5.2e-8 Å；40 步 MD 的位置差 ≤ 4.4e-8 Å，每一步的 SCC 轮数与 DFTB+ 相同（最多差 1）。

  • 力和应力改用最后一轮的输出电荷，与 DFTB+ 的默认做法相同。SCC 容差 1e-5（PTBP 的设置）时，力与 DFTB+ 的差从最多 8.1e-7 降到 ≤ 3.2e-11 Ha/Bohr；收紧容差的算例结果不变。在 PTBP 的实际运行中（dataset 模式，66 个 Cu 结构），两个引擎的力差从最大 1.05e-5 降到 2.0e-8 eV/Å。
  • PyDFTB(reuse_charges=True)：每一步从上一步的电荷开始 SCC，与 DFTB+ 驱动相同；默认关闭。容差 1e-10 时 SCC 轮数少约 20%。
  • MD 的残差全部来自单位常数：ASE 用 CODATA 2014，DFTB+ 用自己的一组，相对差约 1e-7。用 DFTB+ 的常数跑同一个速度 Verlet，40 步内与 DFTB+ 相差 ≤ 1.5e-8 Å（DFTB+ 输出只有 8 位小数）、能量 ≤ 5e-10 Ha。
  • DFTB+ 驱动的几处行为：LBFGS 没有步长上限，在软势能面上会发散；Rational 稳定但很慢（甲醇 1918 步，LBFGS 45 步）；LatticeOpt 的 Isotropic 对非正交晶胞会剪切晶胞，而且只收敛压强。
  • PTBP 生成的 SKF 表带有约 1e-7 Ha 的数值噪声，DFTB+ 的插值导数在每个网格节点处跳变（最大 1e-3 Ha/Bohr）。原子对距离靠近节点时，DFTB+ 的差分力误差可达 1.3e-4 Ha/Bohr（4.5）。

二、力改用输出电荷

SCC 每一轮用输入电荷建哈密顿量，解出的电子分布给出输出电荷，收敛时两者几乎相同。DFTB+ 默认在每次对角化之后用输出电荷重算 SCC 势（RecomputeAfterDensity = Yes），所以力中的电荷项和势项都来自输出电荷。pydftb 原来用输入电荷。SCC 收敛到 1e-10 时两者差 < 1e-10，以前的对照看不出来；PTBP 用的是 1e-5。

两边都用 SCCTolerance = 1e-5，pydftb 用 DFTB+ 的差分步长 fd_delta = 1.22e-4（排除 DFTB+ 数值导数本身的误差）：

四、发现的问题与学到的东西

4.1 单位常数决定了 MD 的残差

ASE 的 Hartree、Bohr、时间单位来自 CODATA 2014；DFTB+ 用 Bohr 0.529177249 Å、Hartree 27.2113845 eV、au__fs 0.02418884326505、amu__au = 1/5.4857990945e-4。相对差约 1e-7。初速度相同时，第 0 帧的动能就差 5–8e-10 Ha；40 步后位置差 1e-8–4e-8 Å。用 DFTB+ 的常数后能量差降到 ≤ 5e-10 Ha、位置差 ≤ 1.5e-8 Å，说明积分器（更新顺序与 DFTB+ 完全相同）和力都没有问题。PyDFTB 的单位约定（坐标按 DFTB+ 的 Bohr 换算、能量和力按 ASE 的常数换算）与 ASE 的 DFTB+ 接口相同，不需要改。

4.2 DFTB+ 优化器的行为

DFTB+ 的问题：新的 GeometryOptimisation 驱动中，LBFGS 没有步长上限。从扰动过的水二聚体开始，第 12 步之后步长从 0.2 Bohr 涨到 0.8 Bohr，第 23 步的结构上 SCC 500 轮不收敛，程序报错退出。Rational（默认）不发散，但收敛很慢。

从同一个预优化起点、收敛到 1e-7 Ha/Bohr 所需的步数（ASE 的 fmax 取同样大小）：

体系ASE BFGSASE LBFGSASE FIREDFTB+ LBFGSDFTB+ RationalDFTB+ FIRE
H₂O883796365
甲醇4141106451918125
水二聚体3636944049398

所有优化器的终点能量相同（到 DFTB+ 输出的 10 位小数）。判据不完全相同（ASE 看每个原子力的模长，DFTB+ 看最大分量且要求能量不升高），步数只作参考。

4.3 晶格优化的两个坑

  • 软剪切方向。Li bcc 原胞做完全的晶格优化时，DFTB+ 的 LBFGS 沿一个非常软的剪切方向漂移，停在剪切过的晶胞上，能量比对称的极小点高 6.6e-9 Ha（应力已在判据以内）。在同一个结构上，两边的应力相差约 1e-14 Ha/Bohr³，所以这不是力的差别，而是优化器在平坦方向上停在了不同的地方。
  • DFTB+ 的问题：LatticeOpt 的 Isotropic = Yes 把应力换成压强，但晶格的梯度是 p·L−T，对非正交的晶胞（bcc 原胞）不平行于 L，LBFGS 的步长于是会剪切晶胞；收敛判据又只看压强，结果停在剪切过的晶胞上，能量高 2.7e-7 Ha。
    改用立方惯用胞（2 个原子，正交）做均匀缩放后，晶格常数差 5.2e-8 Å。

4.4 测试用 Cu 参数下的 Cu₄CO 会塌缩

原计划的 Cu₄CO 团簇优化：从算例结构出发，三种 DFTB+ 优化器都在 3000 步内收敛不了；pydftb 的 BFGS 也一样，能量一路下降、力达到 10–80 eV/Å。这组参数是 PTBP 为测试生成的，Cu–Cu 在短程不够排斥，团簇会塌缩，没有有意义的极小点。改用 Cu fcc 的晶格优化（金属、电子展宽）。单点算例不受影响（它们只在给定结构上比较）。

4.5 SKF 表格的噪声让插值在网格节点处有折点

DFTB+ 的 8 点插值每过一个网格节点就换一组插值点，所以插值函数的导数在节点处有跳变。表格光滑时跳变极小；PTBP 用 hotcent 生成的两组测试参数（ptbp_hcocu、orbit）的积分表带有约 1e-7 Ha 的数值噪声（8 阶差分的中位数约 1e-5，光滑表格应在 1e-12 以下），导数跳变的中位数为 5e-6 Ha/Bohr，最大达 1e-3 Ha/Bohr。

DFTB+ 用步长 1.22e-4 Bohr 的中心差分求 H0、S 的导数。某个原子对的距离落在节点两侧一个步长之内时，差分跨过跳变：在 0.1 fs 的水二聚体 MD 中，2% 的步上差分力与精确导数相差超过 1e-3 eV/Å，最大 6.6e-3 eV/Å（1.3e-4 Ha/Bohr）。第 100 步就是这样：一个 O–H 距离离 110 号节点 1.1e-5 Bohr，那里重叠积分 Sss 的导数跳 3.4e-4 Ha/Bohr，于是精确导数的轨迹从这一步起与 DFTB+ 分开。这些误差正负相抵，对能量守恒的净影响很小（见第五节）；单点对照中 TOL_DFTBP_FD 的来由也是它。

能量守恒

0.5 fs 的步长下，水二聚体 1 ps NVE 的总能量每步变化中位数 2.6e-5 Ha，最大 3.8e-4 Ha，三种算法（DFTB+、pydftb 差分、pydftb 精确导数）在相同的步上出现相同的跳动：这是速度 Verlet 对 O–H 伸缩振动（周期约 9 fs）的离散误差，不是力的误差。步长缩小到 0.1 fs（0.5 ps，5000 步）后，每步变化中位数降到 5.2e-7 Ha（三种算法相同），0.5 ps 内的起伏为 1.0–1.5e-4 Ha。DFTB+ 与 pydftb 差分始终在同一条轨迹上（总能量差在 282 fs 前 < 1e-6 Ha，495 fs 前 < 1e-5 Ha），线性拟合的漂移都是 −1.4e-4 Ha/ps。pydftb 精确导数的拟合漂移是 −6.5e-6 Ha/ps，但这不说明它更守恒：它的轨迹在第 100 步（10 fs）就与另两条分开（原因见 4.5），此后的起伏不同，前后两半的斜率分别是 −1.2e-4 和 +3.5e-5 Ha/ps。沿差分轨迹积分 (F差分 − F精确)·v，0.5 ps 只做了 5e-6 Ha 的功，所以差分力本身不造成可见的漂移。

六、与计划的偏差

  • 原计划“玻尔兹曼常数在本阶段统一”已在 M2e 完成。
  • 优化算例从预优化的起点开始，而不是直接从基础算例的结构开始（见 4.2、4.4）。
  • Cu₄CO 优化换成 Cu fcc 晶格优化（4.4）；Li bcc 晶格优化用立方惯用胞并做均匀缩放（4.3）。
  • 计划中“DFTB3 + D3 水二聚体”的优化没有做：它需要 D3 库，而力与 DFTB+ 一致已由单点算例和容差 1e-5 的 DFTB3 算例覆盖。
  • 新增了容差 1e-5 的单点算例，以及 DFTB+ 常数下的速度 Verlet，用来把 MD 残差归因到单位常数。

八、下一步

M2g：f 轨道（扩展 SKF 格式，hotcent 生成的 Gd 参数）。

PTBP 损失函数的惩罚项一直用默认的共价半径 0.5 Bohr（第二节末；索引页的已知问题）。修正会改变 PTBP 的优化结果，需要先确认再改。

另记一项可选的 PTBP 改进：生成 SKF 时提高 hotcent 的积分精度（或对表格做平滑），减小网格节点处的导数跳变（4.5）。它影响力的精度在 1e-4 Ha/Bohr 量级，远小于 DFTB 与 DFT 的力差，不急。
