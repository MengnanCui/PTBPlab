关键信息

pydftb 现在能处理分子所处的环境：均匀外电场、外部点电荷（静电嵌入，包括 ASE 的 QM/MM 接口）、原子格点势，以及隐式溶剂（广义 Born 的 Still、P16 核和 ALPB，溶剂可及表面积 SASA，氢键修正，CM5 电荷，溶剂常数表与参考态，xtb 格式的参数文件）。它们可以与自旋、非共线自旋、SOC、DFTB+U、onsite 修正、DFTB3、k 点、力、应力和能带一起用（溶剂只用于分子）。22 个新的 DFTB+ 参考算例全部通过，另有一个溶剂中的分子动力学对照。新功能只在 NumPy 引擎中；旧的计算路径逐位不变。

  • 与 DFTB+ 一致：
    • 能量差 ≤ 1.0e-10 Ha；Eext、Esolv、ESCC 等各项 ≤ 6.2e-11；
    • 力差 ≤ 1.7e-8 Ha/Bohr（水的 7 个算例为 1.2e-6，这是 DFTB+ 用数值差分求 SK 导数在这个结构上的已知误差，与新功能无关）；应力差 ≤ 5.8e-11 Ha/Bohr³；
    • 点电荷受的力 ≤ 5.0e-12 Ha/Bohr，偶极矩 ≤ 4.7e-9 e·Bohr（DFTB+ 只打印 8 位小数），Mulliken 电荷 ≤ 3.3e-10；
    • 22 个算例的 SCC 轮数全部相同；
    • 水在 GBSA 溶剂中的 40 步分子动力学：位置差 ≤ 3.9e-8 Å，能量差 ≤ 5.1e-9 Ha，每一步的 SCC 轮数相同。
  • 自洽检查：力、点电荷受的力、应力与能量的差分一致到 1e-8（点电荷受的力到 1e-11）；偶极矩等于能量对外场的导数；Born 半径、表面积、CM5 修正的导数与差分一致；外场为零、点电荷不带电、ε = 1 时与普通计算逐位相同；ASE 的 QM/MM（EIQMMM + TIP3P）中 QM 和 MM 原子的力都与差分一致。
  • DFTB+ 25.1 的问题（第五节）：
    • CM5 被算了两次：GB 模型里每对原子的 CM5 修正加了两遍（对称邻居表、循环里没有去重）。pydftb 默认按 CM5 原文，CM5(double_count=True) 可复现 DFTB+，参考算例这样对照。
    • CM5 加氢键修正时力错：DFTB+ 的力与它自己的能量差分相差 8.1e-3 Ha/Bohr，因为 CM5 的力项漏掉了氢键部分。pydftb 的力与能量一致。
    • 外场的应力：没有对称化；用的是未折回晶胞的坐标；晶格矩阵用反了，非立方晶胞的非对角元因此是错的（7.6 × 4 × 4 Å 的 CuO 链差 5.2e-6）。pydftb 的应力与应变差分一致。
    • 原计划说 DFTB+ 不允许外场与溶剂同用，实际允许，并把外场放大 3ε/(2ε+1) 倍；pydftb 照此实现。
  • 代价：外场和点电荷几乎不增加时间，QM/MM（约 3000 个 MM 电荷）比 DFTB+ 略快；GBSA 比 DFTB+ 慢 0.1 s（32 个水分子，来自 SASA），只用 GB 时与 DFTB+ 相当（第六节）。
  • 22 + 1新的 DFTB+ 参考算例（单点 + MD），全部通过
  • 22 / 22SCC 轮数与 DFTB+ 完全相同
  • ≤ 1.0e-10与 DFTB+ 的能量差（Ha）
  • 0旧计算路径改变的位

二、怎么用

import pydftb
from pydftb.solvation import GeneralizedBorn, SASA, CM5
from pydftb.constants import BOHR, VOLT_PER_ANGSTROM_AU

mf = pydftb.SCC(system, params,
                electric_field=(0.5 * VOLT_PER_ANGSTROM_AU, 0, 0),    # Ha/(e Bohr)
                point_charges=(R_bohr, Q, 0.5),                       # 位置、电荷、展宽
                site_potentials={"gross": {0: 0.01}, "net": {3: -0.02}})   # Hartree
mf.kernel()
mf.result.e_ext, mf.result.dipole, mf.forces()

gbsa = GeneralizedBorn.from_param_file("param_gbsa_water.txt")   # xtb 格式参数文件（DFTB+ 的 ParamFile）
alpb = GeneralizedBorn("water", free_energy_shift=0.0, born_scale=1.5, born_offset=0.0,
                       descreening="unity", kernel="p16", alpb=True,
                       cm5=CM5(),                                    # 用 CM5 电荷
                       sasa=SASA(probe_radius=1.4 / BOHR,            # Bohr
                                 surface_tension={"H": -0.33, "C": -0.75, "O": 0.92}))
pydftb.SCC(molecule, params, solvation=gbsa).kernel()

# ASE：外加条件用 V/Å、Å、eV；QM/MM 用 EIQMMM，它通过 calc.embed() 设置 MM 电荷
calc = PyDFTB(skdir, electric_field=(0.5, 0, 0), solvation=gbsa)
  • 单位：引擎（DFTB、SCC）全用原子单位；ASE 计算器中外加条件用 ASE 单位，溶剂参数与其他模型参数一样沿用 DFTB+ 的原子单位。
  • 能量的归属与 DFTB+ 相同：外场和格点势记在 e_ext（“Energy ext. field”），溶剂记在 e_solv（“Solvation energy”），点电荷的能量含在 e_scc 里。
  • CM5：默认按 CM5 原文；要与 DFTB+ 25.1 的数值一致时用 CM5(double_count=True)（第五节第 1 条）。
  • 限制：点电荷、格点势、溶剂需要 SCC（外场不需要）；溶剂只用于分子；有点电荷的周期体系不给应力（显式要求时报错）；含时外场、COSMO 不做；torch 后端和自动求导报错。

四、自洽检查

  • 力：外场、点电荷、格点势（分子、共线自旋、两分量 + SOC、+U 块路径）与各溶剂模型（Still、ALPB + P16、带电 ALPB、CM5、GBSA、GBSA + CM5、单独 SASA、两分量 + GB）的力与能量差分一致到 ≤ 1e-8（甲醇的差分底噪 4.4e-9）。
  • 点电荷受的力：分子与周期体系都与移动点电荷的能量差分一致到 1e-11 – 3e-10。
  • 应力：外场下的水盒子与 7.6 × 4 × 4 Å 的 CuO 链（k 点）都与应变差分一致到 2e-9，包括 DFTB+ 算错的非对角元。
  • 偶极矩：等于能量对外场的导数（Hellmann–Feynman），差分一致到 1e-8。
  • 几何部分的导数：Born 半径（1e-8）、溶剂可及表面积（1e-7）、CM5 修正（1e-9）对坐标的导数与差分一致。
  • 极限：外场为零、点电荷不带电、格点势为零、ε = 1 时，能量和力与普通计算逐位相同。
  • QM/MM：ASE 的 EIQMMM（QM 为 pydftb 的水分子，MM 为 TIP3P 水分子）中，QM 与 MM 原子的力都与总能量的差分一致到 1e-5 eV/Å（EIQMMM 自身的数值精度）。
  • 能带：eigenstates 用 SCC 的电荷重建 H（含外场、点电荷、净势），本征值与 SCC 的相同到 1e-9。

五、DFTB+ 的行为

1. GB 里的 CM5 修正被算了两次

DFTB+ 给溶剂模型用对称邻居表（每对原子出现两次），Born 半径的循环用 if (iAt2f > iAt1) cycle 去重，CM5 的 getCorrection 没有，于是每对原子的修正加了两遍。甲醇在简单 GB 中：按 CM5 原文 Esolv = −0.0036822 Ha，DFTB+ 给出 −0.0073133 Ha，pydftb 把修正加倍后与之一致到 2e-11。DFTB+ 单独输出 CM5 电荷时用的是半邻居表，没有这个问题。pydftb 默认按原文，CM5(double_count=True) 复现 DFTB+。

2. CM5 与氢键修正同用时 DFTB+ 的力错

CM5 修正改变的是 Born 项与氢键项共同使用的电荷，力中 CM5 的导数项应乘以完整的势 Bq + 2·SASA·h·q。DFTB+ 只用了 Bq（born.F90:addGradients 的 hemv(dEdcm5, bornMat, …)）。甲醇在 GBSA + CM5 中，DFTB+ 的力与它自己的能量差分相差 8.1e-3 Ha/Bohr（不加 CM5 时只差 3.6e-6，即差分本身的误差），与 pydftb 的力差 3.5e-2。pydftb 的力与能量差分一致到 1e-8。参考算例中 CM5 不与氢键同用。

3. 外场下的应力

  • 没有对称化：DFTB+ 的外场应力项是 Σ Δq Ei fj 乘晶格矩阵，张量不对称；对称应变只看得到它的对称部分（设计文档第二节的表）。
  • 用了未折回的坐标：势用折回晶胞后的坐标，应力却用原始坐标；有原子在晶胞外时对角元也错（水盒子中 7 个原子在晶胞外时 xx 差 0.12 Ha，单位为 −Vσ）。
  • 晶格矩阵用反了：getExtFieldStress 中 matmul(latDerivs, transpose(latVec)) 把分数坐标乘上了转置的晶格矩阵。立方晶胞中两者相同；7.6 × 4 × 4 Å 的 CuO 链上，对称化后 xy、xz 仍差 5.2e-6、4.7e-6 Ha/Bohr³，按这一公式用 pydftb 的电荷算出的差值与观察到的差值逐元素吻合。
  • pydftb 用折回坐标并对称化，与应变差分一致到 2e-9。参考算例用原子都在晶胞内的立方晶胞，与 DFTB+ 对称化后的应力比较。

4. 其他

  • 外场与溶剂：可以同用，外场乘 3ε/(2ε+1)（RescaleSolvatedFields，默认开启），打印的偶极矩也乘这个倍数；只有 SASA 时没有静电效应，DFTB+ 警告后关掉缩放。原计划说“不允许同用”是错的。
  • 非 SCC：外场和格点势可以用；点电荷报错；GB 能运行但 Born 项始终为零（电荷从不更新）。pydftb 对溶剂要求 SCC。
  • 格点势的输入：同一种（Gross 或 Net）写两个块时，DFTB+ 忽略第二个并报输入错误；应在一个块里列出多个原子。
  • Born 半径代码中的一个隐患（读代码发现）：getPsi 中“ij 重叠、ji 不重叠”的分支里，若一个原子完全落在另一个原子的范德华球内，第二部分会用到上一对原子留下的 r1。正常结构不会触发；pydftb 一律用 1/d。
  • 有点电荷时不给应力（不提示）；周期体系的 GB、SASA 报错。这些 pydftb 都照搬。

六、速度

pydftb 在 conda 环境（MKL）中运行。两个程序都用单线程，都算力，SCC 容差 1e-8，电子温度 300 K。DFTB+ 25.1 的时间包含进程启动和读写文件。

八、与设计的偏差

  • CM5 的处理：设计时留待核实；核实后 pydftb 默认按原文，另给复现 DFTB+ 的选项（第五节第 1 条）。
  • k 点外场算例：计划用原来的 CuO 链晶胞（7.6 × 4 × 4 Å），因 DFTB+ 的应力在非立方晶胞中有误，改为 7.6 Å 立方晶胞（cuo_chain_field_k411）；非立方晶胞由 pydftb 的应变差分测试覆盖。
  • 偶极矩：所有分子计算都给出（旧算例也多了这个字段，golden 中按新字段处理）。
  • 宽展宽的点电荷：周期体系实空间求和的截断取 Ewald 截断与 10σ 中的较大者，展宽项因此是完整的；DFTB+ 只用 Ewald 的格点集合，σ 很大时会截掉一部分。σ 小时两者相同。
  • Lebedev 网格：只接受 DFTB+ 列出的点数，其他点数报错（DFTB+ 改用相邻的网格并警告）。
  • 新增：设计中没有的 cross_pairs（两组点之间的邻居搜索），避免 MM 电荷很多时生成点电荷之间的配对。
