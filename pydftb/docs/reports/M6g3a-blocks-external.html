关键信息

M6g-3 拆成两块，这是前一块。M6g-1、M6g-2 的三种响应（极化率、响应核、坐标导数）现在都能带 DFTB+U（FLL、pSIC）和 onsite 修正，两者同时用也可以，而 DFTB+ 不允许同时用。新增原子布居对外部点电荷位置的导数，对应开发版 DFTB+ 的 ExternalChargeDerivatives，分子与周期体系都能算。只有 NumPy 引擎；不开这些选项时结果逐位不变。

  • 与 DFTB+ 对照：18 个新的参考算例全部通过。
    • 极化率与响应核，对照 25.1（8 个算例：Cu4CO 的 FLL 与 pSIC，GdO 的自旋加 f 壳层 +U，水与甲醇的 onsite，CuO 链的自旋加 +U 并用 k 点，以及两个响应核）：
      • 极化率差 ≤ 3.7e-11 a.u.，电荷导数差 ≤ 1.3e-9，响应核差 ≤ 2.8e-12；
      • 写出的 detailed.out 块与 DFTB+ 的数字在打印位数内相同。
    • 坐标导数，对照 DFTB+ 自己的差分（5 个算例；DFTB+ 遇到任何块势都拒绝坐标导数）：
      • 解析 Born 电荷与 DFTB+ 的差分 Born 电荷一致到 6.4e-8，这就是差分的截断误差；
      • 数值 Hessian 差 ≤ 9.1e-9 Ha/Bohr²。
    • 点电荷导数，对照开发版（5 个算例，含展宽、只对一个点电荷求导、自旋、onsite、周期体系的 Ewald 求和）：
      • dN/dR 差 ≤ 1.4e-11 e/Bohr；
      • detailed.out 的块逐字相同（周期体系先把开发版的值换号）。
  • DFTB+ 的行为（详见第五节）：
    • 开发版的点电荷导数，在分子上是电子布居的导数 dN，尽管块的标题写的是 charges。
    • 周期体系的点电荷导数符号是反的：Ewald 部分对原子求导，没有对点电荷求导。源码可以确认，DFTB+ 自己的差分也确认。
    • +U 与 onsite 修正同时用时，DFTB+ 拒绝一切响应；坐标导数遇到任何块势都拒绝。
    • DFTB+ 能算的块势响应与 pydftb 一致到 1e-11，没有发现错误。
  • 不支持：
    • 非共线自旋与 SOC（M6g-3b）；
    • M6g-1 拒绝的其他组合；
    • 周期体系的坐标导数；
    • torch 引擎与自动求导。
  • 18新的 DFTB+ 参考算例，全部通过
  • ≤ 3.7e-11带块势的极化率与 DFTB+ 25.1 的最大差（a.u.）
  • ≤ 1.4e-11点电荷导数与开发版的最大差（e/Bohr）
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
response.py
  • 块通道：新类 BlockChannels 与函数 block_channels。
    • 对象：块势会碰到的原子块矩阵元，取 i ≤ j。+U 碰到各组的 idx × idx 块，onsite 碰到整个原子块。
    • 每个通道 c 有一个势形状 Ec = (Eij + Eji)/(1 + δij)，进入哈密顿量的算符是 ½(SEc + EcS)。
    • 与它共轭的布居是 (2 − δij)Qij，Q 是对偶块布居。
    • 块核取 BlockTerms.potentials 对块布居的线性部分。势是布居的仿射函数，所以常数项（FLL 的常数、onsite 的参考布居）不进入。
  • χ0 与求解：
    • chi0(..., channels=) 在同一个能级对循环里累加块通道的行与列；逐轨道的部分逐位不变。
    • 金属的费米能级移动在行、列上各加块通道的分量。
    • Response 的未知量是三段：SCC 位点上的 dq、壳层上的 dm、每个自旋分量的块布居 dQ。
  • 本征值与费米能级的导数：加上块势的项 ½(S dV + dV S)。
  • 坐标导数，在 M6g-2 之上加三项：
    • 每个自旋通道基态块势的 ½(S′V + VS′)；
    • 块布居的变化 ½(dρS + Sdρ)AA + ½(ρS′ + S′ρ)AA，作为 x0 的块分量；
    • 费米能级移动中的块分量。
  • 点电荷导数：external_charge_derivatives、结果类 ExternalChargeDerivativesResult 和选项解析 external_charge_selection。
external.pyExternalTerms.pc_jacobian()：外势在各原子上的值对点电荷位置的导数 dVA/dRj。
  • 分子：Qjφ′(d)(rA − Rj)/d；展宽时 φ 取 erf 形式。
  • 周期体系另加倒空间项 −QjΣGg(G) sin(G·(rA − Rj))G。
analysis.py、calculator.py
  • 新选项 Analysis(external_charge_derivatives=True | {"charges": [...]}) 与结果 AnalysisResult.external_charge_derivatives；XL-BOMD 时报错。
  • _check_response：放开块势；两分量的拒绝信息改指 M6g-3b；点电荷导数要求有点电荷（点电荷本身已要求 SCC）。
dftbplus_io.pyexternal_charge_tables(r)：写出开发版 detailed.out 的块。
validation/
  • dftbplus.py：输入 ExternalChargeDerivatives = Yes 或 { WrtCharges = … }；解析 tag dqdxext 与 detailed.out 的块。
  • cases.py：18 个算例；水盒子的点电荷提成常量 PC_BOX；容差组 TOL_BRESP、TOL_BDX、TOL_BDX_METAL、TOL_EXTQ。
  • refgen.py：比较 dqdxext（周期体系换号）与 extq_text。
测试
  • 新文件 tests/test_response_blocks.py，16 项；
  • test_response.py、test_vibrations.py 中原来断言 +U 被拒绝的测试，改为断言两分量被拒绝。

二、怎么用

from pydftb import DFTB, dftbplus_io

# 块势下的三种响应：没有新选项
r = DFTB(sk, plus_u={"Cu": [("d", 0.15)]}, onsite_corrections=ons,
         smearing=("fermi", 3000.0),
         analysis={"polarisability": True, "response_kernel": True,
                   "coord_derivatives": True}).calculate(labels, pos)

# 对点电荷位置的导数
calc = DFTB(sk, point_charges={"positions": R, "charges": Q},       # Bohr
            analysis={"external_charge_derivatives": True})        # 或 {"charges": [0, 2]}
r = calc.calculate(labels, pos)
e = r.analysis.external_charge_derivatives
e.charges     # 求导的点电荷（0 起）
e.atom        # (n_j, 3, n_qm, n_atom)：dN_B/dR_j,c（电子布居，e/Bohr）
e.orbital     # (n_j, 3, n_qm, n_orb)
print(dftbplus_io.external_charge_tables(r))   # 开发版 detailed.out 的块（dN，e/Å）
  • 块势可以与共线自旋、金属、DFTB3、k 点同用；块势下的极化率同样支持有限频率，以及周期体系的电荷响应。
  • 点电荷导数可以与共线自旋、金属、DFTB3、+U、onsite 修正同用。
    • {"charges": [...]} 只对列出的点电荷求导，对应开发版的 WrtCharges（那里从 1 计数）。
    • e.atom[..., 1, :] 是自旋体系中磁化的导数。
  • 计算量：
    • onsite 修正让每个原子的整个块都成为通道：Cu 的 spd 基 45 个对称元，Cu4CO 共 200 个通道；
    • 块势下的极化率与坐标导数，耗时是一次单点的 1.1–1.3 倍（水的 onsite、Cu4CO 的 FLL），Cu4CO 加 onsite（200 个通道）时 2.1 倍；没有块势时是 1.0–1.1 倍；
    • 点电荷导数是每个点电荷 3 列外势，耗时是一次单点的 1.05 倍（水与 3 个点电荷）。

坐标导数：对照 DFTB+ 的差分

DFTB+ 的坐标导数遇到 +U 或 onsite 修正都拒绝，SecondDerivatives 却能运行。所以每个算例另跑一次 SecondDerivatives，用它的差分偶极导数检查 pydftb 的解析 Born 电荷，同时比较两边的数值 Hessian。设置与 M6g-2 相同：两边的 SCC 容差都是 1e-12，pydftb 用 DFTB+ 的 SK 差分步长。

四、自洽检查

与有限差分比较时用精确的 SK 导数，水的几何移开 SK 格点（同 M6g-2）。

  • 极化率对外场中偶极的四阶差分（这些组合 DFTB+ 部分不能算）：
    • 水的 onsite 2.3e-11，水阳离子二重态加 +U 4.3e-11（相对值）；
    • Cu4CO（3000 K）的 FLL 1.9e-10、pSIC 1.8e-9、FLL 加 onsite 1.2e-9（DFTB+ 拒绝），都是步长 2.5e-4 时的相对值；
    • Cu4CO 在步长 1e-3 时差 3e-7，步长每减半误差降为 1/16，所以这是差分的 h4 截断误差（金属簇的超极化率大）。
  • Born 电荷对偶极的四阶差分：
    • 水的 onsite 1.5e-11，水阳离子二重态加 +U 1.4e-11（步长 2e-4 Bohr）；
    • Cu4CO 的 FLL 1.0e-9、pSIC 2.7e-10、FLL 加 onsite 2.2e-9（步长 4e-4 Bohr，差分噪声随 1/h 增长）；
    • 电子数守恒、平移不变、声学求和规则 ΣKZK = Q·I 都到 3e-14。
  • 点电荷导数对移动点电荷后布居的四阶差分（步长 1e-3 Bohr）：
    • 水 3.3e-12，展宽点电荷加 onsite 4.7e-12，周期的水盒子 3.5e-11；
    • 电子数不变，到 2e-16；逐轨道的导数加起来等于逐原子的，到 1e-12；
    • 只对部分点电荷求导时，结果就是完整结果的对应行（1e-12）。
  • χ0 的对称性：静态的 χ0（逐轨道的行求和到壳层，含费米能级移动）在 [壳层 | 块通道] 上对称，相对偏差：
    • Cu4CO 的 FLL 加 onsite（200 个通道）3.3e-16；
    • 水阳离子二重态加 +U（6 个通道，两个自旋）7.8e-17。
  • 旧路径：
    • 有块通道时 χ0 的逐轨道部分与没有块通道时逐位相同；
    • 没有块势、不开点电荷导数时，golden 的所有计算逐位相同（第六节）。

五、DFTB+ 的行为

  • 开发版的 ExternalChargeDerivatives（derivs/perturb.F90: dxExtCharges）：
    • 输入：ExternalChargeDerivatives = Yes，或 { WrtCharges = … }（从 1 计数）。源码中还有带雅可比矩阵的“组合点电荷”，但只能从 API 调用，输入里用不到。
    • 输出：tag dqdxext（nAtom × 3 × n电荷，e/Bohr）与 detailed.out 的块 “Derivatives of atomic charges w.r.t. coordinates of external charges”（e/Å）。
      • 在分子上，两者都是电子布居的导数 dN，尽管标题写 charges：pdqdxExt = −Σ dqOut，写出时再取负号。
      • 标准输出逐个位移打印的值，符号与 tag 相反。
    • 周期体系的符号是反的：
      • calcInvRPrimeAsymmCluster 对点电荷的位置求导，得到 Q(rA − R)/d³ = ∂φ/∂R。
      • calcInvRPrimeAsymmPeriodic 的实空间与倒空间部分，都对 rA − R 求导，也就是对原子求导，差一个负号。
      • 水盒子的 tag 因此是 −dN。DFTB+ 自己移动点电荷的差分确认了这一点：|差分 + tag| = 4.9e-6，是差分的精度。
    • pydftb 在分子与周期体系上都给 dN；与开发版比较时，周期体系先换号。
  • +U 与 onsite 修正同时用：
    • 极化率、响应核、点电荷导数都报 “Onsite corrected and DFTB+U terms currently not compatible for perturbation”。
    • 基态与 SecondDerivatives 照常运行。
    • pydftb 允许同时用：块核就是两者之和，与外场中偶极的差分一致到 1.2e-9（相对值）。
  • 坐标导数遇到块势就拒绝：
    • 报错信息：“DFTB+U calculations are not yet supported for coordinate derivative perturbations” 与 “Onsite corrected …”。
    • dxAtom 中处理块布居的代码被注释掉了。
    • pydftb 补上基态块势的 S′ 项和块布居的非变分项，与 DFTB+ 的差分一致到 6.4e-8。
  • DFTB+ 能算的块势响应：
    • 响应循环像基态一样，用基态的混合器混合块布居（dqBlockIn/dqBlockOut）。
    • 只用块势对布居的线性部分。
    • 与 pydftb 一致到 1e-11（Cu4CO 的 FLL 3.7e-11），没有发现错误。

七、与设计的偏差

  • 算例（共 18 个）：
    • 坐标导数中，设计的 GdO（自旋加 +U）换成了水阳离子二重态加 O p 壳层的 +U。它也是有极性的开壳层体系，Born 电荷不为零；GdO 的 f 壳层块已由极化率算例覆盖。
    • 新增 cu4co_plusu_ons_dx_3000K（坐标导数中 +U 与 onsite 同时用；DFTB+ 的 SecondDerivatives 能运行，可以作参考）和 h2o_cation_pc_extq（自旋下的点电荷导数）。
    • onsite 加 DFTB3 的极化率用甲醇，设计写的是水。
  • 容差：
    • GdO 的 dEF/dE 用 5e-9，理由是下自旋通道 NF 很小（第三节）；
    • 两个 Cu4CO 坐标导数算例：SCC 轮数允许差 1 轮（与 M6b 的块势算例相同），差分偶极导数用 1e-7；
    • 点电荷导数 1e-9，detailed.out 的块 2e-8（8 位小数）。
  • 开发版 tag 的符号：设计初稿以为 tag 是电荷的导数（−dN）。实际上分子是 dN，周期体系的 −dN 是开发版的错误（第五节）。设计文档已改正。
  • 接口：
    • 删去“点电荷导数需要 SCC”的检查：点电荷本身已经要求 SCC，这个检查不会被触发。
    • 设计文档示例中 plus_u 的写法已改正（构造函数收 {标签: 组}）。
  • 自洽测试：极化率对外场差分的步长用 2.5e-4。用 1e-3 时，金属簇超极化率带来的截断误差有 3e-7。
