# M2d 完成报告：色散修正，仓库改为 MIT 许可

## 一句话结论

**色散：**

- pydftb 现在支持 DFTB+ 的五种色散修正：`LennardJones`（UFF）、`SlaterKirkwood`、`DftD3`、`SimpleDftD3`、`DftD4`。能量、力、应力都可用，也能与 DFTB3、自旋组合。
- 19 个新的 DFTB+ 参考算例全部通过，只看色散部分的差异：
  - 能量 ≤ 1.2e-10 Ha（这是 DFTB+ 输出的精度上限）；
  - 力 ≤ 9e-11 Ha/Bohr；
  - 应力 ≤ 3e-13 Ha/Bohr³。
- 对照中发现 DFTB+ 自己的 D4 实现有三处问题：
  - Cu 等 6 种元素多用了一个参考体系；
  - 周期体系的 EEQ 电荷有错；
  - 周期体系的三体项计数有错。
  pydftb 跟随 dftd4 参考库。

**许可：** 整个仓库改为 MIT 许可。

`validation/` 的改动：

- 生成 DFTB+ 的 `Dispersion` 输入块；
- 解析 “Dispersion energy”，单独比较色散能；
- 参考 JSON 记录完整的色散设置和库版本；没装库或版本不同时跳过，并写明原因；
- 新增 19 个算例。

用法：

```python
atoms.calc = PyDFTB("path/to/skf", dispersion={"model": "dftd3", "damping": "beckejohnson",
                                               "a1": 0.5719, "a2": 3.6017, "s6": 1.0, "s8": 0.5883})
```

键名与 DFTB+ 关键字一一对应（小写、下划线），单位与 DFTB+ 的默认单位相同（Bohr、Hartree）。各模型的参数和默认值见 `design/M2d-dispersion.md`。

几点说明：

- 能量差 1e-11 量级来自 DFTB+ 的 detailed.out 只有 10 位小数。

- SimpleDftD3 和 D4 在 DFTB+ 中是原生实现，与库差约 1e-10，来自参考数据的舍入。
- SCC 轮数全部与 DFTB+ 相同。
- 37 个旧算例结果不变。

### 2.2 自洽检验（`test_dispersion.py`）

- **力与应力：** 各模型的力与能量差分一致，应力与应变差分一致。
  - UFF、SK、H–H 排斥：力 < 1e-9，应力 < 1e-7。
  - D3/D4 在分子中：< 1e-11。
  - D3/D4 在周期体系中，库的硬截断会让能量在应变下跳变，只检验符号和量级（见第三节第 5 条）。
- **Ewald r⁻⁶：** 同一晶格换一组基矢（η 和 G 集合都变）时能量不变（差 < 1e-9）；超胞每个晶胞的能量与原胞相同；三斜晶胞也一致。
- **UFF 短程墙：** 在 r0 处与 LJ 的值和斜率都连续。
- **SK：** 邻居计数正确；极化率为 0 的原子不贡献任何能量。
- **D4（库）：**
  - 大盒子收敛到分子极限（差 < 1e-8）；
  - 超胞不变：水盒子 < 1e-9；不含电荷依赖时 < 1e-13（包括三体项）。
- **组合进总能量：** 加色散后总能量、力、应力的变化与色散模块本身的结果一致；ASE 接口同样。

## 三、发现的问题与学到的东西

详细的实验和源码分析见 `design/M2d-dispersion.md`。

### 1. DFTB+ 的 DftD4 是原生实现，与 dftd4 参考库有三处不同

动手前先对比了 DFTB+ 和库：

- **Cu、Zn、Ag、Cd、Au、Hg 多一个参考体系。**
  - 两份参考数据的 3366 项共同数据全部相同，只有这 6 种元素的参考体系数不同：DFTB+ 为 3，dftd4 3.6 为 2。
  - 第 3 个参考体系（Cu：CN = 2.9）在库里仍然存在，但没有启用。
  - Cu₄CO 的色散能因此差 2.1e-3 Ha（约为色散能本身）；Cu₃ 差 1e-7 Ha；双原子分子完全一致。
- **周期体系的 EEQ 电荷有错。** DFTB+ 的结果随 EEQ 的 Ewald 参数变化（0.3 与自动选取相比差 1.3e-4 Ha），把分子放进越来越大的盒子也不收敛到分子值（按 1/L 衰减）。正确的 Ewald 和不会依赖这个参数。
- **周期体系的三体项计数有错。** 同一晶体用原胞和超胞计算，DFTB+ 得出的每个晶胞的三体能不同（相差 10%），库的结果则相同。原因是 DFTB+ 只存半个近邻表，而对“同一原子的不同像”组成的三元组，折扣因子与实际枚举次数不符。

结论：

- pydftb 跟随参考库；
- 与 DFTB+ 对照的 D4 算例只用 H、C、O；
- 周期 D4 只对照二体项（`ChargeScale = 0`、`s9 = 0`）；
- 完整模型的周期行为由大盒子极限和超胞不变性检验。

### 2. dftd4 库的周期 EEQ 在扭曲或细长的晶胞中收敛不足

- 同一个水盒子换一组等价基矢，能量差 1.8e-7 Ha，梯度差 2.5e-6 Ha/Bohr，维里差 4e-6 Ha。
- CuO 链的 2×1×1 超胞（15.2 × 4 × 4 Å）每个晶胞差 1.2e-6 Ha。
- 关掉电荷依赖后这些差异都消失（< 1e-13），所以问题出在库的 EEQ Ewald 求和。量级远小于 DFTB+ 的 EEQ 错误。这是库的问题，记录在此，pydftb 不做改动。

### 3. DFTB+ Slater-Kirkwood：极化率和电子数都为 0 时得到 NaN

- DFTB+ 只检查原子对中的第一个原子是否被跳过，第二个原子的 √(α/N) 会算成 0/0。
- 要关掉一个原子，只需把它的极化率设为 0，电子数保持原值。
- pydftb 对两个原子都检查。

### 4. 其他 DFTB+ 细节（读源码发现，算例中没有触发）

- **HHRepulsion：** 对“氢原子与自己的周期像”，DFTB+ 按两次计能量、按一次计应力。只在晶胞小于 10 Bohr 时出现。
- **UFF 参数查找：** DFTB+ 按物种名的前两个字母查 UFF 表，所以 `Li1` 会查成 Li，`O2` 查不到。pydftb 用类型标签的元素去查；对照工具对类型标签写显式数值。
- **HybridDependentPol：** DFTB+ 只在读入时按输入结构数邻居，结构优化中邻居数变化时，参数仍是初始结构的。pydftb 每次按当前结构数，单点结果相同。

### 5. D3/D4 库的硬截断让周期体系的能量不完全光滑

- D3 的配位数计数函数在 40 Bohr 截断处仍有 5e-7/对。原子移动或晶胞应变时，有原子对跨过截断，能量会跳变：水盒子中力与差分差约 5e-7 Ha/Bohr，应力与应变差分差约 1e-5（相对 3e-4）。
- DFTB+ 用的是同一个库，结果相同。
- 分子没有这个问题。

### 6. 近邻表的边界情况

- 原子在晶胞外较远时（随机放置的水盒子中分数坐标跨度可超过 1），按“截断/晶面间距”取的周期像数可能少一层。
- 色散的截断长达 60–95 Bohr，比 SK 积分远得多，所以顺带修正：按原子分数坐标的实际跨度补足。
- 原子都在晶胞内时取法不变，原有算例结果不变。

## 四、与计划的偏差

- **D3 不支持“库内方法名”。** 与 DFTB+ 的输入保持一致，只接受数值。3ob/mio 常用的 D3、D4 参数写在设计文档中。
- **周期 D4 的对照改为 `ChargeScale = 0`、`s9 = 0`，** 原因是 DFTB+ 的两处错误（第三节第 1 条）。
- **算例数：** 计划约 16 个，实际 19 个。另加了：
  - 带 Cu 的 D3 周期算例；
  - 类型标签 + 修正零阻尼；
  - SK 逐原子参数（含被跳过的原子）。
- **SK 测试参数：** H 的共价半径取 0.5 Å（不是常见的 0.4 Å），让测试分子中的每个键都算邻居。
- **暂缓：** TS/MBD（libmbd）、D4 的自洽电荷变体（`ChargeModel = SelfConsistent`）、D3H5 中的 H5 氢键修正（属于哈密顿量）。
- **验收：** 能量差 < 1e-6 Ha、力差 < 1e-5 Ha/Bohr、应力差 < 1e-7 Ha/Bohr³ 全部满足；色散部分本身的差异小 4–8 个数量级。

## 五、性能

24 原子水盒子（周期），一次色散计算（含梯度和维里）的耗时：

| 模型 | 耗时 |
|---|---|
| UFF | 19 ms |
| SK | 7 ms |
| D3(BJ) | 15 ms |
| SimpleDftD3 | 6 ms |
| D4（无三体项） | 8 ms |
| D3 或 D4 + 三体项（库） | 约 2.5 s |

三体项远比 SCC 本身（约 0.1 s）慢，这也是 DFTB+ 默认关掉 D3 三体项、D4 要求显式给出 s9 的原因。
