关键信息

pydftb 现在能算 DFTB+ Analysis 中的耦合微扰 SCC 响应。电场极化率：静态与频率相关，还给出电荷、本征值和费米能级对电场的导数。响应核：各原子与各轨道的布居对一个原子上势的导数，SCC 屏蔽的或裸的（RPA）。公式与 DFTB+ 相同（对未微扰态求和，简并组与金属的费米能级移动照 DFTB+），但 pydftb 直接解线性方程，不迭代。只有 NumPy 引擎；不用这些选项时逐位不变。这是 M6g 的第一块。

  • 与 DFTB+ 25.1 对照：19 个新的参考算例全部通过（DFTB+ 的响应收敛到 1e-11），SCC 轮数逐个相同：
    • 极化率差 ≤ 3.6e-11 a.u.（CH3OH 的 DFTB3），金属 Cu4CO（α ≈ 170）≤ 5.4e-12；
    • 电场导数 dq/dE ≤ 3.3e-11（分子）、1.8e-10（周期 Γ 点）、1.2e-8（k 点的金属 CuO 链，数值约 25）；
    • 响应核 dq/dV ≤ 1.5e-13；
    • 写出的 detailed.out 响应块与 dE_band.out、dV_band.out 除数值外与 DFTB+ 逐字节相同；
    • 覆盖：静态与频率相关、非 SCC、壳层分辨、完整 DFTB3、外场中的基态、共线自旋、金属（费米能级移动、固定费米能级）、简并（含窗口内半满的简并对）、周期 Γ 点与 k 点、RPA。
  • DFTB+ 的行为（第五节）：
    • 默认的 PerturbSccTol（1e-5）下，水的极化率只准到 2.5e-7，张量也不对称；
    • dEF/dE 打印的是物理值除以满占据；
    • k 点的有限频率响应在约化的 k 点集里留下一个正比于 η 的人为项（实现时发现）；
    • 多个频率时 dV_band.out 被覆盖；Static = No 又没给频率时什么也不算。
  • 不支持：
    • 与 DFTB+ 相同：非 Fermi 展宽、溶剂、只 onsite 的三阶；
    • 留到 M6g-3：DFTB+U、onsite 修正、非共线自旋与 SOC；
    • 另外：偶极修正、每个 k 点单独填充、选定壳层、XL-BOMD、torch 后端与自动求导。
    色散不影响响应，所以允许（DFTB+ 拒绝）。
  • 19新的 DFTB+ 参考算例，全部通过
  • ≤ 3.6e-11极化率与 DFTB+ 的最大差（a.u.，19 个算例）
  • 2.5e-7DFTB+ 默认容差下水的极化率误差（pydftb 直接解，没有这项误差）
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
response.py（新）
  • GroundState：
    • 重新对角化最后的 H，得到每个 (自旋, k) 块的本征对；
    • 占据数用 DFTB+ 的 θ 函数；
    • DFTB+ 的 nF、nE 阈值（1e-7 与单精度 ε）、窗口 W、金属标记；
    • 链式简并组（1e-9 Ha）；
    • NF 与费米移动用的向量 d（Mulliken 与 on-site 两种）。
  • chi0：
    • 壳层势到轨道布居的 χ0 = ΣpRe[GpmXpconj(mμp)]（上/下自旋分块），以及 on-site 布居的同样矩阵；
    • 对 DFTB+ 的对集合按批累加，一次处理全部频率；
    • 窗口内的简并组用与旋转无关的整组权重；
    • 费米移动是秩 1 修正 ddT/D，每个通道各自守恒，relax_total_spin 时两个通道共用。
  • scc_kernel：Coulomb.gamma 加上完整三阶在基态（最后一轮输入电荷）处的 Hessian（third_order_hessian，与 DFTB+ 的 getdShiftdQ 相同）；自旋用 W。
  • Response：解 (I − AB)x = AVext，未知量是 SCC 位点上的 dq 与壳层上的 dm。
  • eigenvalue_derivatives：M = C†dH C 的对角元，简并组内取本征值并按升序排列。
  • fermi_derivative：dEF = ΣδiMii/Σδi。
  • polarisability、response_kernel，以及结果数据类 PolarisabilityResult、ResponseKernelResult。
analysis.pyAnalysis(polarisability=…, response_kernel=…, perturbation=…)（键与类型检查、频率表在构造时验证）；AnalysisResult.polarisability、.response_kernel；evaluate 调用 response，XL-BOMD 时报错。
calculator.py_check_response：第二节的拒绝；测试专用的 DFTB._response_eta_compat（第五节）。
dftbplus_io.pyresponse_tables(res, part=None, dftbplus_fermi=False)：detailed.out 的响应块，顺序同 DFTB+：先响应核，再写 DOS、电荷导数、费米能级导数、极化率；25.1 的频率行格式带 “:”。write_band_derivatives(path, res, kind)：dE_band.out、dV_band.out。
validation/
  • dftbplus.analysis_block 写 Polarisability、ResponseKernel 与 PerturbSccTol = 1e-11、MaxPerturbIter = 1000（只在 SCC 时写；PerturbEta 只在有有限频率时写，否则 DFTB+ 报“未读的节点”）；
  • parse_response 读 results.tag 的 8 个 tag、detailed.out 的两部分文本、dE_band.out 与 dV_band.out；
  • refgen._compare_response：比较的键是 pol、dqdE、dedE、dEf、dos、dqdV、dqnet、dedV、response_text；
  • 19 个算例。
另有两处小修：
  • _numbers_close 把数前的空格或负号算进数字（接近 0 的数两边符号可能不同）；
  • _compare_scc_start 能处理非 SCC 的结果。
测试tests/test_response.py（23 项）。

二、怎么用

r = DFTB(sk, analysis={"polarisability": {"frequencies": [0.05]},   # Hartree，静态默认也算
                       "response_kernel": True}).calculate(labels, pos)
p = r.analysis.polarisability
p.tensor[0]                 # 静态极化率 d mu_j / d E_i（a.u.）；周期体系为 None
p.charge_derivatives[-1]    # (3, n_qm, n_atom)：最后一个频率的 dN_A/dE_i
k = r.analysis.response_kernel
k.atom[0, :, 0, :]          # [A, B] = dN_B / dV_A（静态、SCC 屏蔽）
print(dftbplus_io.response_tables(r))      # DFTB+ detailed.out 的响应块
  • 频率用 Hartree；{"static": False, "frequency_range": (起, 止, 步长)} 照 DFTB+ 生成频率表。
  • {"response_kernel": {"rpa": True}} 给裸的 χ0；非 SCC 计算总是裸的。
  • {"perturbation": {"degeneracy_tol": 1e-9, "eta": 1e-8}} 即 DFTB+ 的 PerturbDegenTol、PerturbEta。没有迭代，也就没有 PerturbSccTol。
  • 周期体系只有电荷响应，没有极化率张量（同 DFTB+）。

四、自洽检查

  • 与差分比较：静态极化率等于外场下偶极的中心差分（步长 1e-4 a.u.，相对差 < 2e-5）。覆盖水、壳层分辨、DFTB3、O2 三重态、水负离子（300 K）、Cu4CO（3000 K）。金属的 dEF/dE 等于费米能级的差分（< 1e-6），说明 pydftb 给的是物理值。
  • 对称性与守恒：
    • 静态极化率与响应核对称；
    • 响应核每一列的和为 0：绝缘体、金属（费米能级移动）、自旋，RPA 与有限频率都成立；
    • 频率很小时，α(ω) − α(0) ∝ ω²。
  • 与旋转无关：O2（无自旋，300 K）的半满简并 π* 对在组内任意旋转，χ0 不变（< 1e-9）。
  • k 点：CuO 链用完整的 16 个 k 点与按时间反演约化的 8 个 k 点，pydftb 的有限频率结果相同（差 1e-12）；保留 η 项时差 2e-6。
  • 不影响结果的选项：开关色散，响应逐位相同。

五、DFTB+ 的行为

  • 默认容差的误差：DFTB+ 用基态的混合器迭代 SCC 响应，PerturbSccTol 默认 1e-5 且与 SccTolerance 无关。水的极化率因此差 2.5e-7，张量不对称 1.6e-7。设为 1e-11 后，水 7 轮收敛，张量的 12 位有效数字逐位对称。pydftb 直接解线性方程，没有这项误差。
  • k 点的 η 项（实现时发现）：
    • 频率相关的权重 (fi − fa)/(Δ ± ω + iη) 是复数。对复数本征向量，布居中留下一项 Im(G)·Im(mXmY*)，它在 k 与 −k 之间抵消；
    • DFTB+ 拿到按时间反演约化的 k 点集时，这一项不抵消；
    • CuO 链（1 eV，η = 1e-8）：DFTB+ 偏离完整网格的结果 +2.1e-6。pydftb 若保留这一项，偏离 −2.0e-6，方向相反，因为两边的 Bloch 相位约定互为共轭；
    • pydftb 去掉这一项，所以约化的 k 点集与完整网格给出相同的结果；测试专用的 DFTB._response_eta_compat 复现 DFTB+（参考算例这样比较）。
  • dEF/dE 除以了满占据：DFTB+ 用未乘满占据的 dρ 的电荷除以已含满占据的 NF，无自旋时打印的值只有物理值的一半；电荷与极化率不受影响。pydftb 给物理值，差分验证过。
  • 输出：
    • 多个频率时，dq/dE、∂ε/∂E、dEF/dE 只保留最后一个；
    • dV_band.out 中原子 1 的部分每个频率都被覆盖重写；
    • tag 名 staticChargeReponse 有拼写错误；
    • dE_band.out、dV_band.out 中本征值用 eV、微扰用原子单位（pydftb 相同）。
  • 输入：
    • Static = No 又没有频率时什么也不算，也不提示（pydftb 报错）；
    • FrequencyRange 的点数 int((止 − 起)/步长) + 1 可能因舍入丢掉端点（pydftb 照做，测试中写明）；
    • PerturbEta 只在有有限频率时读，PerturbSccTol、MaxPerturbIter 只在 SCC 时读，多写会被当作未读的节点而报错。
  • 拒绝的组合（25.1 的原话）：
    • 只 onsite 的三阶：“Only full 3rd order currently supported for perturbation”；
    • 色散：“Dispersion (particularly charge dependent) not currently implemented”；
    • 溶剂：“Solvation not currently implemented”；
    • Methfessel–Paxton 展宽：“Choice of filling function currently incompatible”。

七、与设计的偏差

  • 算例：
    • 新增 o2_pol_300K：设计以为 CuCO（300 K）的窗口里有简并对，实际只有一个半满的 σ 能级。不加自旋的 O2 的 π* 对才是窗口内的简并组；
    • 共 19 个。
  • k 点的 η 项：设计打算照 DFTB+ 的复数公式逐项实现。实现时发现那一项是约化 k 点集的人为项，于是改为默认去掉，另加测试专用开关复现 DFTB+。
  • dV_band.out 的单位：设计说 DFTB+ 乘错了 eV。实际上两个文件一致地用“本征值 eV、微扰原子单位”，pydftb 照写。真正的问题只是多频率时的覆盖。
  • 容差：
    • 水负离子的力 5e-6（DFTB+ 的差分导数）；
    • k 点 CuO 链的 dq/dE 5e-8（数值约 25，DFTB+ 金属响应迭代的残差）；
    • 其他照设计。
  • 写出：detailed.out 的块顺序照 DFTB+（响应核在前），频率行用 25.1 实际的格式（带 “:”，与 041e723 的源码不同）。
