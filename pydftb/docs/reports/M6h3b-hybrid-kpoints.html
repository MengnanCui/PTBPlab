关键信息

M6h-3a 的周期杂化从 Γ 点推广到 k 点，对应 DFTB+ 25.1 用不平移的 SupercellFolding 的杂化计算。每个 k 的交换 Hx(k) 是 SCC 网格上 ΔP(q)、S(q) 与 γ 的格点和的卷积，也就是 BvK 超胞在 Γ 点的交换算符；pydftb 在超胞的实空间里把它算成逐元素的乘积。MatrixBased 混合每个 k 的复数 ΔP(k)，NeighbourBased 混合超胞实空间的数组；截断、阻尼截断与 Full 三种库仑核，共线自旋，力，电荷文件与重启，任意 k 上的能带，结构优化与 MD。只有 NumPy 引擎；分子与 Γ 点的计算逐位不变。MinimumImage 是 M6h-3c。

  • 与 DFTB+ 对照：29 个参考算例与 2 条动力学参考全部通过。
    • 能量差 ≤ 7.5e-11 Ha，力 ≤ 8.2e-12 Ha/Bohr，电荷 ≤ 2.2e-10 e，29 个算例的 SCC 轮数全部相同，每轮误差一致到 DFTB+ 打印的精度。
    • 覆盖：金刚石原胞（2×2×2、3×3×3、1×2×3、3×1×2）、CO2 晶体 2×1×1、Cu 3×3×3（1000 K）、O2 盒子（自旋）、三斜 CO；LC、CAM、全局杂化；三种库仑核、两种屏蔽（含 CutoffReduction）；+U 与 onsite（照 DFTB+ 冻住块布居）、DFTB3 加 D3、外场加点电荷、MP 展宽、DIIS；从 DFTB+ 的电荷文件重启（MatrixBased 与 NeighbourBased，二进制与文本，自旋）；DFTB+ 的能带重启（本征值 ≤ 2.5e-14 Ha）。
    • 动力学：CO2 晶体 20 步 MD（ΔP(k) 跨步沿用；DFTB+ 单位的 Verlet 能量差 6.9e-11 Ha）与金刚石原胞的结构优化（能量差 3.8e-11 Ha）。
  • 超出 DFTB+ 的部分（你的决定）：DFTB+ 25.1 在 k 点拒绝的阻尼截断与 Full 的力、自旋的力，pydftb 都给出能量的精确导数，对差分 ≤ 2e-9 Ha/Bohr（h = 5e-5 Bohr）。
  • DFTB+ 25.1 的问题（第五节）：
    • B20：k 点时混合后的块布居从不更新，+U 与 onsite 修正一直用起始的块布居。CO2 晶体里差 2.2e-3 与 3.6e-2 Ha；pydftb 每轮从 ΔPin 求，对照时用开关复现 DFTB+。
    • B21（新）：几何步之间沿用的 ΔPin(k) 是上一步折回坐标的规范，原子沿折叠方向穿过晶胞面的那一步多 4–5 轮 SCC（结果不变）。
    • B19：Full 的有限格点和取决于原子怎样折回晶胞（pydftb 照 DFTB+）。B2、B3、B12 证实；NeighbourBased 的默认 Threshold 让能量偏到 1.6e-6 Ha（pydftb 不筛选）。
  • 不支持：MinimumImage（M6h-3c）；与 DFTB+ 相同地拒绝 Thresholded、非共线自旋、TD-LC、应力、带平移或非对角的折叠、非网格的 k 点。

开发细节一、做了什么
位置内容
hybrid.py
  • dftbp_coulomb_cutoff(cell, nk)：DFTB+ 的 getCoulombTruncationCutoff 照代码移植（B2 的按分量缩放；体对角线交点用 x、y 投影求，z 检查不过时报 DFTB+ 停下时的原话，B3）。Γ 点只用它做检查，取值仍是 default_coulomb_cutoff（逐位不变）。
  • dftbp_fold_shifts：DFTB+ foldCoordsToCell 减去的晶格矢量；bvk_cells：超胞的 N 个胞（DFTB+ 的顺序，n1 最快）。
  • KPointLayout：本次计算的 k 点集与超胞实空间之间的变换（X(n) = Σk wk Re[X(k)e−i2πk·n]，两次实矩阵积；反变换同样），混合向量的打包、解包与误差（复数模），DFTB+ 电荷文件记录的换算（D†ΔP(k)D 与胞号移 TB − TA，两种 k 点集之间 ±k 取共轭）。
  • KPointHybridTerms（接口同 HybridTerms）：
    • 格点和：用 DFTB+ 折回的坐标与 Γ 点相同的平行六面体，每项记到胞 ng + TA − TB；截断核只留 Rc 以内的项；得到超胞实空间的 g(n)AB。
    • Hx(k) = c[C(SΔPS) + C(SΔP)S(k) + S(k)C(ΔPS) + S(k)C(ΔP)S(k)]，C(X) 是超胞实空间的 X(n)∘g(n) 再变回 k；ΔP 全为零时 Hx = 0。fock_at 在任意 k 上用带相位 ei2πk·ng 的格点和（能带）。
    • P0(k) = diag(q0/Sμμ(k))；EFock 用 ΔPout（同 DFTB+）。
    • 力：S 的系数 X(k) 的超胞矩阵在胞 −T 的元素；γ 的系数 W(n) 乘各项的 γ′（每项同时出现在 (A, B, n) 与 (B, A, −n)）。NeighbourBased 用缩减的 S 与截断掩码。
kpoints.pysupercell_folding(n)：DFTB+ getSuperSampling 的约化集与顺序；folding_of(kpts, weights)：认出折叠（完整网格，或每对 ±k 中任一个），其余返回 None。
calculator.py
  • _check_periodic_hybrid 返回折叠：非网格的 k 点按 DFTB+ 的原话拒绝（提示 supercell_folding 与 ASE 的写法），k 点的 MinimumImage 拒绝到 M6h-3c；_setup 建 KPointHybridTerms。
  • _scc_hybrid_kpoints：k 点的 SCC（复数 ΔP(k)，Fock 按自旋拼接，对角化后用 ΔPout 求 EFock，混合后从 ΔPin(k) + P0(k) 求布居与块布居）；验证用的类属性 _dftbp_stale_blocks（B20）。Γ 点与分子的 _scc_hybrid 不变。
  • charge_data、populations_from_file 多 positions、cell（k 点记录的规范要用）；calculate 读 ChargeData 时自己传入；折叠不同时报 DFTB+ 的原话（没传晶胞时提示要传几何）；两种记录都能读给两种屏蔽。
dftbplus_io.pyChargeData.rho_kpoints（复数 ΔP(k)，DFTB+ 的 k 点）与 rho_bvk（实的超胞数组），都按 C 序读出的样子；二进制由长度认出布局，文本由 “(re,im)” 认出；ld_complex 照 gfortran 写复数（指数形式比实数多一位）；folding_diagonal 照 DFTB+ 检查折叠记录。DFTB+ 写的 6 个 k 点文件逐字节往返。
bands.pyeigenstates：SCC 在折叠网格上时，任意 k 加 fock_at 的 Hx(k)；Γ 点的 SCC 仍只在 Γ 点给本征态。
ase_calc.pykpts 接受 ASE 的 {"size" 或 "density", "gamma"}；states()、band_structure() 可用于 k 点杂化；write_charges 与 read_charges 传入原子坐标与晶胞（k 点记录的规范要用）。
validation/
  • cases.py：Case.folding（pydftb 用 supercell_folding）、stale_blocks_compat、fixed_scc、属性 dftbp_forces；29 个算例；居中的两个结构（动力学用，B21）。
  • dftbplus.py：kpts={"folding": n} 写 SupercellFolding；hybrid_block(spec, kpoints=True) 为 NeighbourBased 写 Threshold = 1e-100。
  • refgen.py、dynamics.py：折叠、固定轮数、DFTB+ 不给力时 PrintForces = No；电荷文件的检查传 run 1 的坐标；两条动力学参考。
测试

  • tests/test_hybrid_periodic.py 三处、tests/test_hybrid.py 一处：拒绝与报错的原话改为 k 点的新行为。

二、怎么用

from pydftb.bands import eigenstates
from pydftb.kpoints import supercell_folding
calc = DFTB(sk_lc, hybrid="lc", kpts=supercell_folding((2, 2, 2)))   # DFTB+ 的约化与顺序
r = calc.calculate(labels, pos, cell, forces=True)                   # 没有应力
r.e_fock, r.q_in                     # q_in = [布居 | 每个 k 的 ΔP(k)（[Re | Im]）或超胞数组]
write_charges("charges.bin", calc.charge_data(labels, r, periodic=True, positions=pos, cell=cell))
eigenstates(calc, labels, pos, cell, populations=r.q_in, kpts=path)  # 任意 k
atoms.calc = PyDFTB(skdir, hybrid="lc", kpts={"size": (2, 2, 2), "gamma": True})
  • k 点：必须是某个折叠 diag(n1, n2, n3) 的 Γ 心网格，完整的或每对 ±k 中任一个（权重相应）；supercell_folding(n) 给出 DFTB+ 的集合与顺序。带平移的 Monkhorst-Pack 网格（偶数时的普通网格）、显式的其他 k 点按 DFTB+ 的原话拒绝。
  • 库仑核："truncated"、"damped" 同 Γ 点；"full" 只在 k 点有，是 DFTB+ 平行六面体上不截断的和，随 gsum_cutoff 增大，SCC 不收敛，只供对照。默认 Rc 照 DFTB+ 的代码（B2），Rg = 2Rc；DFTB+ 求不出默认值的晶胞（B3）报错，给 coulomb_cutoff 即可。
  • 屏蔽：MatrixBased 与 NeighbourBased（缩减的 S）；NeighbourBased 建完整的算子，相当于 DFTB+ 的 Threshold → 0（DFTB+ 默认的 1e-6 会偏到 1.6e-6 Ha）。
  • 组合：共线自旋、展宽、+U、onsite、完整 DFTB3、D3/D4、外场、点电荷、各混合器、自定义 Hubbard U 与占据；阻尼截断、Full 与自旋的力（DFTB+ 不给）。
  • 电荷文件：DFTB+ 的格式 8，折叠记录 diag(N) 之后一条记录：MatrixBased 是 DFTB+ 各 k 点的复数 ΔP(k)，NeighbourBased 是超胞数组，都是 DFTB+ 折回原子的规范，所以 charge_data 与 populations_from_file 要坐标与晶胞。pydftb 两种记录都能读给两种屏蔽、任一种 k 点集；DFTB+ 只读自己那种。
  • 拒绝：MinimumImage（M6h-3c）；Thresholded、非共线、Casida（DFTB+ 的原话）；应力；torch 与自动求导。

四、自洽检查

tests/test_hybrid_kpoints.py 的 39 项（不需要 DFTB+）：

  • k 点集：supercell_folding 等于 Γ 心网格的时间反演约化（六种折叠）；folding_of 认出约化集、完整网格与任意代表，拒绝带平移的网格、单个非网格点、不完整的集合与错的权重。
  • DFTB+ 的默认截断与折回：Γ 点的值等于最小晶面间距的一半（1e-14）；FCC 1×2×3 为 2.88885111 Bohr（B2，超胞本应是 1.94586）；2×2×2 是 Γ 点的两倍；a2 沿 z 的晶胞在 Γ 点与 k 点都报 DFTB+ 的原话（B3），给 coulomb_cutoff 后能算；foldCoordsToCell 的 floor 与 eps 规则。
  • 变换与记录：k 点集与超胞实空间的变换互逆（1e-13，约化集与完整网格）；打包、解包、复数模的误差；DFTB+ 记录的规范换算往返（1e-13），两种记录读给两种屏蔽、两种 k 点集。
  • 超胞 Γ 点：
    • 固定的 ΔP 下，k 点的 Hx(k) 逐胞等于 M6h-3a 的超胞 Γ 点算符（截断、阻尼、NeighbourBased 加缩减；1e-12）；
    • 原子不与自身镜像重叠的盒子（Sμμ(k) 逐位为 1）里，整个 k 点计算等于超胞的 Γ 点计算：能量与 EFock 的 N 倍 1e-9，力与电荷 1e-8；
    • +U 时 pydftb 的 k 点结果等于超胞 Γ 点的结果（1e-9），照 DFTB+ 冻住块布居则不同（B20）。
  • 一致性：NeighbourBased 不缩减时等于 MatrixBased；完整网格等于约化集；闭壳层的自旋计算等于不加自旋（能量 1e-9，力 1e-8）。
  • 力对能量的差分（h = 5e-5 Bohr，SCC 容差 1e-12，解析 SK 导数）：截断、NeighbourBased 加缩减、阻尼截断、CAM、自旋（两种屏蔽）、自旋加阻尼截断，七项都 ≤ 2e-9；差分的截断误差按 h² 变小，不加杂化时也一样大。Full 的 SCC 不收敛，单独检查固定 ΔP 与 S 时 γ 部分的梯度（1e-8）。
  • 文件与能带：两种屏蔽的电荷文件（二进制与文本）往返逐位不变，重启一轮收敛；另一种屏蔽的计算从这个文件重启 ≤ 3 轮；折叠不同、Γ 点的计算读 k 点文件、缺坐标时报错；写入时缺折叠、非对角折叠、两条密度记录、长度不对的记录报错。能带：SCC 网格上的本征值等于 SCC 的能级（1e-12），fock_at 在网格上等于 fock（1e-13），任意 k 的路径能算，Γ 点的 SCC 仍拒绝其他 k 点。
  • ASE 与输入：kpts={"size": (2, 2, 2), "gamma": True} 的能量与 supercell_folding 相同（1e-12 相对），band_structure 可用；普通的偶数网格按 DFTB+ 拒绝；ASE 计算器写出的 k 点电荷文件由另一个计算器读入，一轮收敛、能量相同；DFTB+ 输入的 SupercellFolding 与 Threshold。
  • 拒绝：带平移的网格、非网格的 k 点、k 点的 MinimumImage、Thresholded、Rc ≤ 1 Bohr。

五、DFTB+ 的问题

DFTB+ 25.1证据pydftb 的做法
B20：k 点时混合后不更新块布居（main.F90 的 getNextInputDensityCplx 只更新 qin；Γ 点的 getNextInputDensityReal 用 denseBlockMulliken 更新 qBlockIn），DFTB+U 与 onsite 的势一直用起始的块布居（自旋时是第一轮的输出）P79：照此冻住块布居时与 DFTB+ 一致到 7.5e-11 Ha、轮数相同；正确的做法差 2.2e-3（+U）与 3.6e-2 Ha（onsite）。超胞 Γ 点的计算（DFTB+ 在那里更新块布居）支持正确的做法每轮从 ΔPin 求块布居；验证用的 _dftbp_stale_blocks 复现 DFTB+
B21：几何步之间沿用的 ΔPin(k) 是上一步折回坐标的规范；原子穿过晶胞面后折回的格矢变了，沿用的矩阵差一个相位 ei2πk·ΔTP82：未居中的干冰晶胞 MD（600 K，2×2×2），第 2、4、6、15 步有原子穿过晶胞面，DFTB+ 用 30、30、31、36 轮，pydftb 26、26、26、31 轮，其余每步相同；结果不变。2×1×1 时穿过的方向不折叠（相位为 1），没有差别ΔP(k) 用未折回坐标的规范，跨步连续；动力学的参考把晶胞居中
B19：Full 的格点和是折回坐标的有限平行六面体，结果随原子怎样折回晶胞而变P72f：用原坐标差 0.1–0.3 Ha；用折回坐标与 DFTB+ 差 2.5e-11（diamond2_lc_k222_full）照 DFTB+（格点和用折回的坐标）；文档写明 Full 不收敛、只供对照
B2：默认 Rc 的“BvK 向量”按笛卡尔分量乘折叠数，不是格矢乘折叠数P75；diamond2_lc_k123照代码（与 DFTB+ 相同），文档写明
B3：体对角线交点只用 x、y 投影求，a2 沿 z 等晶胞求不出，DFTB+ 带着没赋值的点继续，在阻尼区的检查处停下（Γ 点也一样）P75报 DFTB+ 的原话并说明原因，可给 coulomb_cutoff；Γ 点也加了这个检查（非退化晶胞的值逐位不变）
B12：负的非对角折叠能通过检查P78：能量 −3.15436 Ha（对角 −3.13078）只认对角折叠，文件里的非对角折叠也拒绝

B5：NeighbourBased 的 k 点力混用 ΔPin(R)P74：紧容差下看不出（9.7e-13）精确的导数（ΔPout）
NeighbourBased 的默认 Threshold 1e-6（不是错误）：按增量筛选，结果依赖历史P80：能量偏到 1.6e-6 Ha，轮数多；1e-8 时不收敛不筛选；参考用 1e-100；移植筛选放在 M6h-3c

七、与设计的偏差

  • 卷积的算法：设计（与原型）是对每个约化 k 按 q 求和、轨道级的 G(k − q) 按 q 分块展开。实现改成在超胞实空间做乘积：k 点集与超胞之间的变换是两次实矩阵积，不需要 k − q 的下标表与轨道级的 G(p)，内存只有 N·n² 个实数，且对任何合法的 k 点集（完整网格、任一代表的约化集）都成立。与原型在 15 个探针体系上一致：能量多数到 1e-15，46 轮的长 SCC 舍入到 2.9e-12，力 ≤ 1.4e-12，轮数相同。
  • 格点和的折回：设计写“每个原子对的平行六面体移 TA − TB”；实现等价地用 DFTB+ 折回的坐标与共同的平行六面体，只把每项记到胞 ng + TA − TB，可以按 Hubbard U 成组向量化。
  • 电荷文件的接口：k 点记录的规范要坐标，charge_data 与 populations_from_file 多了 positions、cell 两个参数（分子与 Γ 点不需要，旧的调用不变）；_split_hybrid_vector 没有改，k 点用新的 _split_kpoint_vector。
  • 多出的部分：
    • 探针 P82 与 B21：做动力学参考时发现，晶胞因此居中，多了两个居中结构的参考算例（共 29 个，设计写约 25 个）；
    • 写入时检查：实的 ΔP 配非 Γ 的折叠、k 点记录缺折叠都报错（M6h-3a 的一项测试相应改为写入时报错）；
    • ASE 也接受 {"density": …, "gamma": True}，band_structure() 可用于 k 点杂化。
  • 没有做的：Γ 点的 SCC 之后在其他 k 点求本征态仍然拒绝（DFTB+ 的 Γ 点文件是实数记录，它的能带运行读不了；pydftb 可以做，但没有参考）。
  • MD 的轮数：设计没有说；实测两步因 1e-10 量级误差的舍入多 1–2 轮，test_md_opt.py 对这条参考放宽到每步 2 轮、全程 3 轮（其他 MD 仍是 1 与 2）。
