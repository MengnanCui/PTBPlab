关键信息

pydftb 现在有 DFTB+U（FLL 和 pSIC 两种泛函）和 onsite 修正。两者都是作用在同一原子整个轨道块上的“块势”，共用一套机制：块布居、以 ½(SV + VS) 进入哈密顿量、混合向量中的块元素、力和应力中的块项。它们可以与无自旋、共线自旋、非共线自旋、dual 模型的自旋轨道耦合、DFTB3、k 点、力、应力和能带一起用。18 个新的 DFTB+ 参考算例全部通过，另有一个分子动力学对照。新功能只在 NumPy 引擎中；旧的计算路径逐位不变。

  • 与 DFTB+ 一致：
    • 能量差 ≤ 5.6e-11 Ha；EU、Eons 等各项 ≤ 4.6e-11（DFTB+ 只打印 10 位小数）；
    • 逐轨道的电子布居 ≤ 8.0e-11（results.tag 全精度），SCC 的本征值 ≤ 1.8e-11 Ha；
    • 力差 ≤ 2.2e-8 Ha/Bohr，这是 DFTB+ 自己用数值差分求导的误差（用 DFTB+ 的差分步长时两者差 2e-11）；应力差 ≤ 2.2e-10 Ha/Bohr³；
    • SCC 轮数 17 个算例完全相同，剩下一个是 62 对 63；
    • 水加 onsite 修正的 40 步分子动力学：位置差 ≤ 4.5e-8 Å，能量差 ≤ 9.2e-9 Ha（与 M2f 的 MD 对照相同的量级）。
  • 自洽检查：力、应力与能量的差分一致到 1e-8（分子、k 点、共线自旋、两分量 + dual SOC 的虚部块势），势与能量对块布居的导数一致。
  • DFTB+ 的行为（第五节）：
    • DFTB+ 25.1 的一个崩溃：只有 s 壳层的 +U 组让 DFTB+ 在初始化后段错误退出。pydftb 支持这种组，用差分检查验证。
    • onsite 势在第一轮缺席：DFTB+ 每个几何步的第一轮 SCC 不加 onsite 势，读电荷文件时才加。pydftb 把给定的电荷当作读入的电荷，分子动力学里每步少 2.3 轮，轨迹不变。
    • 费米能级取在带隙中点的规则：费米能级两侧各有一个近简并能级时，DFTB+ 的这条规则让电子数随结构变化 5e-8 左右，力与能量差分可差到 2.7e-7（Cu₄CO 的 Cu p、d 都加 FLL 时）。这是 M4b 记过的老问题，两个代码相同；用 fermi_level="exact" 后降到 1e-8。
    • 难收敛的组合：CuO 链加 dual SOC 和 +U，500 K 时两个代码都要约 140 轮，U − J 改为 0.1 Ha 时 DFTB+ 发散；1000 K 时 62/63 轮。
  • 代价：见第六节。
  • 18 + 1新的 DFTB+ 参考算例（单点 + MD），全部通过
  • 17 / 18SCC 轮数与 DFTB+ 完全相同（另一个差 1 轮）
  • ≤ 5.6e-11与 DFTB+ 的能量差（Ha）

二、怎么用

import pydftb
from pydftb.blockpot import ONSITE_PBE
mf = pydftb.SCC(system, params, temperature=300,
                plus_u={"Cu": [("d", 0.15)]},       # 每组壳层一个 U − J（Hartree）
                plus_u_functional="fll",            # 或 "psic"
                onsite_corrections=ONSITE_PBE)      # 每种元素的 f_uu、f_ud
mf.kernel()
mf.result.e_plus_u, mf.result.e_onsite             # DFTB+ 的 "Energy DFTB+U"、"Energy onsite"
  • 壳层：写成角动量字母，如 "d"，或 "pd"（p 与 d 作为一组，组内的 p–d 块也受修正）；也可以写从 0 开始的壳层序号。DFTB+ 的 Shells 从 1 开始数。
  • onsite 常数：结构中每种元素都要给出，H 写零矩阵。ONSITE_PBE 收录 H（s）、C、N、O（sp）、S、Ti、Au（spd），用于壳层不同的参数集时报错。
  • 组合：可与自旋（共线、非共线）、SOC（+U 只能配 dual 模型，与 DFTB+ 相同）、DFTB3、色散、k 点一起用；能带用 mf.states(kpts=路径)。
  • 重启与 MD：DFTBResult.q_in 是块路径的完整混合向量，可直接作为 q_init；PyDFTB(reuse_charges=True) 自动这样做。
  • 不支持：backend="torch"、pydftb.autodiff，遇到时报错。SP2 求解器可以用（无自旋、Γ 点）。

五、DFTB+ 的行为

1. 只有 s 壳层的 +U 组让 DFTB+ 崩溃

OrbitalPotential { Cu { Shells = {1} UJ = 0.1 } } 让 DFTB+ 25.1 在 “Starting initialization...” 之后段错误退出（返回码 −11），没有错误信息。源码 initprogram.F90 的注释说已考虑到纯 s 组（这时没有块元素），但实际仍然崩溃。这样的组物理上没有问题：+U 势只是 s 轨道上的一个移动。pydftb 支持它，力与能量差分一致到 4e-9。

2. onsite 势在第一轮缺席

  • DFTB+ 在每个几何步的第一轮 SCC 里不把 onsite 势加进 H（processPotentials 的条件 iSCCIter > 1 .or. tReadChrg），能量和力用的输出势里则总有它。只有读入电荷文件时（包括能带运行）第一轮就有。水的第 2 轮总能几乎不变、第 3 轮才明显下降，就是这个原因。
  • 这只影响 SCC 的路径。分子动力学中几何步之间沿用电荷，DFTB+ 每一步仍从不含 onsite 的 H 开始，平均每步 13.6 轮；pydftb 把给定的电荷当作读入的电荷，每步 11.3 轮，轨迹一致到 4.5e-8 Å。
  • 测试里让 pydftb 也照 DFTB+ 的规则在每步第一轮去掉 onsite 势，41 步的 SCC 轮数与 DFTB+ 逐步相同（共 557 轮）。这说明差别只来自这一条规则，几何步之间传递的块向量与 DFTB+ 一致。

3. 带隙中点费米能级与近简并能级对

  • 电子数为整数时，DFTB+ 只要带隙中点处的电子数与 N 相差不到 1e-7，就把费米能级放在中点（M4b 报告已记录：这时自由能不是电子数固定的 Mermin 自由能）。
  • Cu₄CO 在 300 K 时费米能级两侧各有一个能级，相距约 2e-4 Ha，占据约 1.05 和 0.95；更远的空能级还有约 5e-8 的占据，电子数随结构变化 5e-8 量级。不加 +U 时力与能量差分相差 1e-8；Cu 的 p、d 壳层都加 FLL（U − J = 0.15 Ha）后达 1.7–2.7e-7，改变 U − J 或温度又回到 1e-8。差别与差分步长（3e-6 到 1e-3）和 SCC 容差（1e-9 到 1e-14）都无关，所以不是数值噪声。
  • 两个代码的力相同（用 DFTB+ 的差分步长时差 2e-11），所以这是 DFTB+ 规则本身的结果。Smearing("fermi", 300, fermi_level="exact") 下降到 1e-8。差分检查的测试避开了这种情形。

4. 难收敛的组合

  • CuO 链加 dual SOC 和 Cu d 的 +U：500 K 时 DFTB+ 143 轮、pydftb 139 轮才收敛；U − J = 0.1 Ha 时 DFTB+ 500 轮不收敛；1000 K 时 63 和 62 轮。参考算例用 1000 K。
  • 同一条链在 2×1×1 的 k 网格、500 K 下加 +U，Broyden 要 211 轮，Pulay 混合 300 轮不收敛；1000 K 时 47 轮。CuO 链同时加 +U 和 onsite 时，1e-12 的容差下 500 轮不收敛。

5. 输出与输入

  • detailed.out 列出每个原子的 “Block populations” 及其本征分解，只有 4 位小数；results.tag 的 orbital_charges 是全精度的逐轨道电子布居，共线自旋时按 ↑、↓ 存放（不是 q、m）。
  • OrbitalPotential 和 OnSiteCorrection 只在 SCC 时读取，非 SCC 时是输入错误；U − J = 0 报 “too small”；同一壳层写两次时打印各壳层的出现次数后终止；+U 配 SOC 的 onsite 模型报 “Only dual spin orbit currently supported for orbital potentials”。pydftb 的报错与之对应。
  • DFTB+ 的等价类还会把壳层分辨 SCC 中 Hubbard U 相同的壳层合为一类。pydftb 不照搬（设计文档第二节），参考数据集里各壳层的 U 都不同，不受影响。

六、速度

pydftb 在 conda 环境（MKL）中运行。两个程序都用单线程，都算力，SCC 容差 1e-8。DFTB+ 25.1 的时间包含进程启动和读写文件。

八、与设计的偏差

  • 给定电荷时第一轮就加 onsite 势。设计时打算完全照 DFTB+ 的几何步规则；实现时改为把 q_init 当作读入的电荷（DFTB+ ReadInitialCharges），重启和分子动力学每步少走几轮，结果不变（第五节第 2 条），设计文档已同步修改。
  • SP2 求解器：设计时留待确认；无自旋、Γ 点的块势计算只需要密度矩阵，可以直接用，加了测试。
  • 算例：比计划多两个（共 18 个）：cuo_chain_soc_plusu_k422（k 点上虚部块势的力与应力）和 ch3oh_ons；cuo_chain_soc_plusu_k422 用 1000 K，因为 500 K 时 SCC 很长、两边差 4 轮（第五节第 4 条）。
  • 差分测试的条件：Cu₄CO 的力只查 Cu 原子并避开 p、d 同时加 FLL 的情形（第五节第 3 条）；CuO 链用 1000 K。
  • 代码整理：混合向量的块元素原先逐个用 Python 循环取，改为按原子成组的向量化写法。
