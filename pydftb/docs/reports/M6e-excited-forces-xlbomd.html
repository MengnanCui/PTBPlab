关键信息

pydftb 现在能算激发态的力：用 Z 向量方法求 E0 + ω 对原子位置的导数，同时得到激发态的 Mulliken 电荷与偶极，ASE 的优化器和 MD 可以直接在激发态中运行。另一项是 XL-BOMD：辅助电荷随原子一起积分，每步只做几轮 SCC（XlbomdFast 只做 1 轮），积分器、影子能量、力和 SCC 规则都与 DFTB+ 相同。两者都只在 NumPy 引擎中；旧的计算路径逐位不变。

  • 激发态的力：
    • pydftb 的力与它自己的 E0 + ω 的差分一致到 2e-11 – 5e-11 Ha/Bohr（单重态、三重态、自旋极化、最亮态、外场加点电荷、H–X 阻尼、能量窗口、自旋极化加窗口加外场、格点势，共 9 种）；
    • 与 DFTB+ 对照（11 个新算例）：用 DFTB+ 的差分步长时力一致到 1.8e-12 Ha/Bohr；激发态电荷与偶极一致到 XCH.DAT、XREST.DAT 打印的位数（5e-9 e、2e-9 e·Bohr），两个文件 pydftb 能逐字节写出；
    • 在 S1 中做结构优化、在 S2 中做 MD，与 DFTB+ 的驱动一致（终点能量差 4.4e-15 Ha，20 步 MD 的位置差 2.0e-8 Å）。
  • DFTB+ 的激发态力在五种组合下不是 E0 + ω 的导数（第五节；另外它的 ForceEvaluation = DynamicsT0 在自旋极化时给出错误的力）：外电场、点电荷、H–X 阻尼、能量窗口少了几项，按壳层的自旋常数用错了 W，与 DFTB+ 自己的能量差分相差 8.8e-6 – 5.4e-3 Ha/Bohr。pydftb 计入了这些项（最后一种报错）；在前四种组合下，参考数据存 DFTB+ 能量的差分，pydftb 与之一致到 6.7e-11，按 DFTB+ 的写法去掉这几项后又与 DFTB+ 的力一致到 1.1e-12，差别正好是这几项。
  • XL-BOMD：7 条 DFTB+ 轨迹（Xlbomd 的 K = 5、6、加 PreSteps，XlbomdFast 的 K = 5、7，DFTB3，500 K 下 k 点的 CuO 链），每一步的 SCC 轮数都与 DFTB+ 相同，位置、速度、影子能量一致到 DFTB+ 打印的位数（5e-9 Å、7e-9 Å/ps、5e-11 Ha）。影子能量的力与应力是它在 n 固定时的精确导数（差分 3e-11、1e-12）。
  • 顺带发现：DFTB+ 默认的差分步长是 2−13 = 1.2207e-4 Bohr，而验证工具从 M2f 起用的是 1.22e-4。两个差分点跨过 SK 网格点时，这点差别使力相差可达 2.4e-8 Ha/Bohr，在 XL 轨迹的第 30 步留下 1.6e-6 Å/ps 的速度差。已改为 2−13（只是验证工具的常数，引擎不变）。
  • 11 + 9新的 DFTB+ 参考算例（单点 + 优化/MD），全部通过
  • 1.8e-12用 DFTB+ 的差分步长时与 DFTB+ 激发态力之差（Ha/Bohr）
  • 0XL 轨迹每步 SCC 轮数与 DFTB+ 之差
  • 0旧计算路径改变的位

开发细节一、做了什么
位置内容
pydftb/casida_grad.py（新，470 行）
  • relax(gs, x, state)：由 X±Y 组成未弛豫的差密度 T；右端项 R（K 项与基态哈密顿量对 T 的响应）；在全部占据—空轨道对上解 (A+B)singlet Z = R：对不超过 500 个的轨道对组装矩阵直接解，更多时用对角预条件的共轭梯度（从真残差重启，收敛到 1e-14）；W 的三块（一般形式，含 V[γ q(T)] 与 V[γ q(Z)]）；弛豫密度 P = T + ½(Z + ZT)；AO 表象的 P、W、(X+Y)，以及 Δqex、ξ。
  • 有能量窗口时加上占据—占据、空—空块的正则轨道乘子 zpq = −(Gpq − Gqp)/(εp − εq)：只有窗口内的跃迁进入响应时，激发能对这两块的轨道转动不驻定，没有这一项导数差 2.7e-4。
  • pair_terms：原子对元素上的 dS 系数（P 的位移项、−W、Vex·D0、γξ·(X+Y)，自旋极化时的自旋项）；mulliken_tables：XCH.DAT、XREST.DAT（DFTB+ 的 Fortran 格式）。
  • window_only=True（只供 _excited_compat）按 DFTB+ 的写法只在窗口内解 Z、用简化的 W。
pydftb/xlbomd.py（新，185 行）ExtLagrangian（DFTB+ 的环形缓冲、K = 5、6、7 的系数（K = 7 的 α 取单精度值）、四个阶段与插值，运算顺序与 Fortran 相同）；XLBOMD（选项与检查，对应 Xlbomd/XlbomdFast）；Integrator（几何步之间的状态、每步的 SCC 设置：转入积分之前用计算器自己的设置，最少轮数只在第一步起作用）。
calculator.py
  • 去掉 M6d 的 NotImplementedError：有指定态且 excited_forces 为真时 forces = −∇(E0 + ω)；DFTBResult 末尾追加 excited_energy、excited_free_energy、excited_charges、excited_dipole 与 q_out（默认 None）；Casida(excited_charges=True) 不算力也给电荷。
  • _excited_gradient：P 代替 ρ、W 代替能量加权密度，位移用基态完整的势（含外场、点电荷、格点势），γ′ 项用有阻尼的 γ，外加势加 ext.gradient(Δqex)；点电荷受的力用 Δq + Δqex。原子对求和抽成 _add_pair_terms，运算顺序不变。
  • XL：SCCControl(min_iter, max_iter, tol) 与 calculate(…, scc_control=, xl=True)，最后一轮之后不混合；_energies_xl（影子能量）；_gradient(xl=True)：位移用 V[n]，SCC 项 2·∇(½ qout·γ·n) − ∇(½ n·γ·n)，三阶项用新的 ThirdOrder.gradient_xl；force_evaluation（_dynamics_wdm：DHD / fmax（fmax = 2，自旋通道为 1）或 ½(DHS−1 + S−1HD)，两分量计算用旋量的重叠矩阵）；_check_xl 与 _check_excited（DFTB+ 的限制，另拒绝按壳层不同的自旋常数）。
scc_control=None、xl=False、force_evaluation="traditional"、没有指定态时走原来的代码。
coulomb.py、thirdorder.pyCoulomb.gradient(dq, other=…)：½ dq·γ·other 的导数（短程、Ewald 实空间与倒空间、应力、分子），不给 other 时逐位与原来相同；ThirdOrder.gradient_xl(n, q)：线性化三阶项的导数。
casida.pyExcitations.xmy（X−Y = F√(Ω/ωia)）与 Casida.excited_charges；激发能等数值不变。
ase_calc.pyPyDFTB(xlbomd=…, force_evaluation=…)：每次计算是一个 MD 步，积分器给出这一步的 n 与 SCC 设置，算完把 qout 交回；force_evaluation 默认在 XL 时取 "dynamics_t0"（T = 0）或 "dynamics"；reset() 重新开始积分。激发态时 energy、free_energy 是 E0 + ω（calc.excited）。
autodiff/api.py遇到 dynamics 的 force_evaluation 报 NotImplementedError（Casida 在 M6d 已拒绝）；torch 后端在构造时拒绝。
validation/
  • dftbplus.py：WriteMulliken、ExcitedStateForces；解析 XCH.DAT、XREST.DAT 与 autotest.tag 的全精度 E0 + ω；md_driver(xlbomd=…) 写 Xlbomd/XlbomdFast 块。
  • refgen.py：激发态电荷、偶极；forces_fd 参考（对 DFTB+ 的 E0 + ω 做四点差分，全部 3N 个分量）及 _excited_compat 对照。
  • dynamics.py：DynCase.xlbomd、force_evaluation；激发态与 XL 的 9 个新算例；比较速度和每步的 SCC 轮数；差分步长改为 DFTB+ 的 2−13（第五节第 4 条）。golden.py 在两个提交中都用这个步长，保持可比。
测试11 个单点和 9 个动力学参考 JSON；tests/test_casida_forces.py（21 个）、tests/test_xlbomd.py（28 个）；tests/test_casida.py 中 M6d 的 NotImplementedError 断言改为新的行为。

二、怎么用

from pydftb import DFTB
from pydftb.casida import Casida

calc = DFTB(sk, casida=Casida(6, state_of_interest=2))   # excited_forces 默认为 True
r = calc.calculate(labels, positions)        # Bohr
r.forces                                     # −∇(E0 + ω2)，Ha/Bohr
r.excited_energy, r.excited_free_energy      # E0 + ω；r.energy 仍是基态（同 DFTB+ 的输出）
r.excited_charges, r.excited_dipole          # 激发态的 Mulliken 布居（电子数）与偶极（e·Bohr）
Casida(6, state_of_interest=4, excited_charges=True, excited_forces=False)  # 只要电荷，力是基态的

from pydftb.casida_grad import mulliken_tables
xch, xrest = mulliken_tables(net_charges, dipole, sym, state)   # XCH.DAT、XREST.DAT 的文本

# ASE：能量是 E0 + ω，与力一致，优化器和 MD 直接在激发态中运行
atoms.calc = PyDFTB(skdir, casida={"n_excitations": 6, "state_of_interest": 1})
BFGS(atoms).run(fmax=0.01)

# XL-BOMD：每次计算是一个 MD 步
from pydftb.xlbomd import XLBOMD
atoms.calc = PyDFTB(skdir, xlbomd=XLBOMD(integration_steps=5, scc_tol=1e-6))
VelocityVerlet(atoms, 0.5 * units.fs).run(1000)
PyDFTB(skdir, xlbomd=XLBOMD(fast=True, scale=0.5))          # XlbomdFast：每步 1 轮 SCC
PyDFTB(skdir, xlbomd={"integration_steps": 7, "pre_steps": 3})   # 也可以写成 dict

# 引擎层：一步 XL（n 是辅助电荷）
r = calc.calculate(labels, pos, q_init=n, scc_control=SCCControl(1, 1, 1e-5), xl=True)
r.free_energy, r.forces, r.q_out             # 影子能量、它在 n 固定时的力、交给积分器的输出
  • 激发态的力：分子，整数占据，一个态（state_of_interest > 0，或 −1 取最亮的单重态）；单重态、三重态、共线自旋极化；可以与外电场、点电荷、格点势、色散、H–X 阻尼、能量窗口同用。报错的情况：周期体系、分数占据、振子窗口、onsite 修正（与 DFTB+ 相同），自旋极化时按壳层取不同值的自旋常数（DFTB+ 在这种情况下给出错误的力），与 XL-BOMD 同用，torch 后端与自动求导。
  • XL-BOMD：XLBOMD 的参数与 DFTB+ 一一对应（integration_steps、pre_steps、min_scc、max_scc、scc_tol；fast=True 时 transient_steps、scale）。转入积分之前的步（pre_steps、K + 1 步填充历史、XlbomdFast 的过渡）用计算器自己的 scc_tol、max_scc。限制与 DFTB+ 相同：要 SCC 和 Fermi 展宽，不能有自旋、+U、onsite、外场、点电荷、溶剂、激发态的力，DFTB3 要用完整三阶（third_order="full"）。
  • 用法上的注意：积分器假定每次计算就是下一个 MD 步，用在优化器或别的驱动上没有意义；换一条轨迹前调用 calc.reset()。XlbomdFast 的 scale 要按体系试：水二聚体 0.5 稳定、1.0 发散，金属性的 CuO 链 0.5 也发散（两个程序相同）。

四、自洽检查

  • 激发态的力是 E0 + ω 的导数：H2CO 的 9 种情形（单重态、三重态、自旋极化的阳离子、最亮态、外场加点电荷、H–X 阻尼、能量窗口、自旋极化加窗口加外场、格点势）中，四点差分（步长 1e-4 Å，pydftb 的 SK 导数是精确的）与解析力之差为 2.0e-11 – 5.2e-11 Ha/Bohr。
  • 其他导数：激发态偶极等于 −∂(E0 + ω)/∂F（6.2e-11）；点电荷受的力等于 −∂(E0 + ω)/∂Rpc（4.9e-11）。
  • Z 向量的两种解法：稠密解与预条件共轭梯度给出的力差 1.4e-17、电荷差 8.9e-16（闭壳层；自旋极化加窗口加外场）。
  • 不变性：弛豫密度不改变电子数（3.6e-15）；没有外场时力之和为零（1.4e-17）；分子整体转动、平移后力、电荷、偶极随之转动（1.3e-15）。
  • XL 的影子能量：从离自洽 1e-2 – 5e-2 的 n 出发做一步 XlbomdFast，力与影子能量在 n 固定时的差分一致：水二聚体 DFTB2 3.2e-11、DFTB3 2.3e-11，CuO 链（k 点，500 K）2.7e-10 Ha/Bohr，应力 9.6e-13（σ 的大小 6.6e-4）。
  • 自洽的极限：n 自洽时影子能量与普通能量逐位相同，XL 的力与普通的力差 ≤ 4e-14；三种 force_evaluation 给出的力差 ≤ 3.3e-16（CuO 链的应力 8.7e-19），自旋极化的 O2 与两分量的 OH（SOC）同样 ≤ 1.7e-16。
  • 积分器：环形缓冲与写开的递推公式（保存全部历史）一致到 1e-13（K = 5、6、7，含过渡与 Scale）；各种设置下 BO 步的数目与 DFTB+ 的参考相同（K + 1 + PreSteps，XlbomdFast 再加过渡步）。
  • ASE：PyDFTB 在 S1 中用 BFGS 优化收敛；XL 的 MD 中 ASE 的势能就是影子能量，过渡之后每步 1 轮 SCC，reset() 后重新从收敛的 BO 步开始。

五、DFTB+ 的行为

1. 激发态的力在五种组合下不正确

对 DFTB+ 自己的 E0 + ω 做差分（autotest.tag 的全精度值，步长 1e-4 Bohr），单重态、三重态、自旋极化、色散只差 2.5e-7 – 5e-7 Ha/Bohr（它的数值 SK 导数的误差），以下五种组合差得多（timedep/linrespgrad.F90）：

组合与差分之差（Ha/Bohr）原因
外电场1.1e-3dS·P 项的位移只有 SCC 势和点电荷势，没有外场的势；也没有 Δqex·∇Vext 一项
点电荷5.4e-3位移里有点电荷的势，但没有 Δqex·∇Vpc
能量窗口3.9e-3Z 只在窗口内的跃迁上求解，W 用简化公式，占据—空块只取窗口内的对；也没有正则轨道乘子
H–X 阻尼1.3e-4γ′ 用没有阻尼的 expGammaPrime，而响应用的 γ 有阻尼
按壳层的自旋常数8.8e-6Z 向量的 A+B 只用 HOAO 的 W，基态的轨道 Hessian 用整个 W 矩阵

pydftb 计入前四种的全部项（最后一种报错），与自己的能量差分一致到 5e-11。测试专用的 DFTB._excited_compat（"external"、"damping"、"window"）按 DFTB+ 的写法去掉这些项，再用 DFTB+ 的差分步长，就与 DFTB+ 的力一致到 1.1e-12：差别正好来自这几处。能量窗口下 XCH.DAT 的电荷来自窗口内的 Z，与完整弛豫的电荷相差 4.7e-2 e，参考算例的电荷也按 DFTB+ 的写法比较。

2. 激发态的能量与输出

  • DFTB+ 的驱动用 EMermin + ω：md.out 的势能、优化器打印的能量都是它；detailed.out 的 “Total energy” 与 results.tag 的 mermin_energy 仍是基态的（M6d 已记录）。autotest.tag 的 mermin_energy 是全精度的 EMermin + ω；detailed.out 只打印 10 位小数，用它做差分有约 1e-6 Ha/Bohr 的噪声，用 autotest.tag 时误差降到 5e-11。
  • 激发态中 DFTB+ 打印的点电荷受力仍是基态的。
  • XCH.DAT 是每个原子的净电荷 −Δq − Δqex（%5d %16.8f），XREST.DAT 是偶极（Debye）及其大小，每个态追加一块；由 WriteMulliken = Yes 打开。

3. XL-BOMD 的规则

  • 前 PreSteps 步、之后 K + 1 步填充环形缓冲、XlbomdFast 再加 TransientSteps 步，这些步用哈密顿量部分的 SCC 设置（收敛的 BO 步）；之后才用 XL 的设置。
  • 收敛判据是 iSccIter ≥ minSccIter .or. iGeoStep > 0：最少轮数只在第 0 个几何步起作用，而那一步本来就是 BO 步，所以 MinSccIterations 实际上不起作用。
  • SCC 到最大轮数时不再混合，n 就是构造 H 的电荷；对角化之后不再用 qout 更新势，力用 V[n]。
  • K = 7 的 α = 1.6e-3 在源码中没写 _dp，是单精度常数（与双精度值差 4e-11），pydftb 照用。
  • ForceEvaluation = Traditional 配 XL 报 “Force evaluation method incompatible with XLBOMD”；DynamicsT0 在 T > 0 时报错；旧的 ThirdOrder 报 “XLBOMD not working with third order yet”，ThirdOrderFull 可以。
  • XlbomdFast：水二聚体 Scale = 1 发散（总能量漂移 −50 Ha），0.5、0.25 稳定；CuO 链（500 K）0.5 也发散。
  • 自旋极化时 DynamicsT0 的力是错的（main.F90:getEDensityMtxFromRealEigvecs）：½DHD 只在占据数为 0 或 2 时等于能量加权密度，而每个自旋通道的占据数是 0 或 1，这时它只有一半。三重态 O2 的力因此差 0.19 Ha/Bohr（方向都反了），Dynamics 与 Traditional 一致到 6e-17。XL-BOMD 本来不允许自旋，所以只影响在普通计算中指定 DynamicsT0 的情形。pydftb 用 DHD / fmax（fmax = 2 或 1），并补上两分量计算中 Dynamics 需要的旋量重叠矩阵。

4. 差分步长的默认值是 2−13

Differentiation = FiniteDiff 的 Delta 默认为 ε1/4 = 2−13 = 1.220703125e-4 Bohr（dftb_pin.hsd 中可见），不是此前验证工具里写的 1.22e-4。两个差分点在同一段插值多项式上时，这点差别只让力差约 3e-12；两点跨过 SK 网格点（0.02 Bohr 一个）时，两段 8 点多项式之差被 1/(2h) 放大。水二聚体 XL 轨迹第 30 步的 O–H 距离离网格点只有 2e-5 Bohr，那一步的力差 6.2e-9（附近可达 2.4e-8）Ha/Bohr，之后的速度差 1.6e-6 Å/ps。validation/dynamics.py 改用 2−13 后，所有轨迹与 DFTB+ 一致到打印的位数；以前的 13 个优化/MD 算例同样通过。refgen 的测试本来就用 ε1/4。

八、与设计的偏差

  • 代码的位置：设计打算把 A+B 的乘积放进 casida.py（Response.apb_product），并把 excitations() 拆出求解部分。实际 Z 向量需要的 (A+B) 乘积与矩阵都在 casida_grad.py 的 _APlusB 中，直接用 Excitations 的 X±Y；casida.py 只加了 xmy 与 excited_charges，数值不变。Coulomb.gradient_bilinear 写成了 gradient(…, other=)，三阶项的 gradient_directional 写成 gradient_xl。
  • 能量窗口：设计只说在全部 ov 对上解 Z；实测还缺占据—占据、空—空块的正则轨道乘子（只在窗口内响应时激发能对这两块不驻定），加上后导数从差 2.7e-4 变为精确。
  • 拒绝的情况：设计写的是“基态的 U、W 与响应核不一致时报错”；线性响应本来要求原子分辨 SCC（U 一致），所以只剩自旋极化时按壳层不同的自旋常数这一种。
  • 算例：激发态的 MD 用 S2（h2co_s2_md），S1 用于结构优化（h2co_s1_opt，另加单点 h2co_exc_forces_s1）；多了 h2co_exc_charges（不算力只要电荷）和 water_dimer_xl_minscc_md（验证 MinSccIterations 不起作用）。
  • 比较：动力学的对照多了速度（DFTB+ 的 xyz 文件）和每步的 SCC 轮数；为此发现并改正了验证工具的差分步长（第五节第 4 条）。
  • 测试：设计中“积分器时间可逆”改为环形缓冲与写开的递推公式对照（耗散项使积分器本来就不可逆），另加影子能量的应力、自洽极限和 ASE 的测试。
  • 新增：PyDFTB 的 force_evaluation 在 XL 时按温度自动选取；XLBOMD.make 接受 dict；autodiff 拒绝 dynamics 的力。
