关键信息

pydftb 现在可以让一个元素的原子在它的几套参数（类型标签，如 Cu 与 Cu2）之间按配位数平滑切换：每个原子带一组权重，H0、S 与排斥能按权重混合，能量、力、应力一致，周期体系与 MD 都能用。这是引擎机制；PTBP 的拟合一侧（M5b）与电池算例以后再做。只在 NumPy 引擎中；不用切换时逐位不变。

  • 离散极限对 DFTB+ 25.1：权重恰为 0/1 的两个几何（Cu(111) 平板的表层与内层、13 原子立方八面体的外层与中心）用对应的固定类型标签跑 DFTB+：能量差 ≤ 2.2e-11 Ha，SCC 轮数相同；力差 1.5e-7 来自 DFTB+ 用差分求 H0/S 的导数（用它的步长时 2.9e-11）。同一几何上 pydftb 用切换与用显式标签逐位相同（能量、力、应力、布居、本征值、SCC 轮数）。
  • 切换区内的自洽（DFTB+ 做不了）：力对能量的 4 点差分 ≤ 5.0e-10 Ha/Bohr（8 种物理组合：SCC、非 SCC、DFTB3 + 共线自旋、非共线 + 自旋轨道、DFTB+U、固定费米能级、外场、轨道分辨 SCC；三种类型），周期体系的力 4.4e-10、维里 4.6e-9 Ha（|W| 达 9.3 Ha）；权重项占力的大部分（Cu6 中 0.106/0.154 Ha/Bohr），所以检验是实在的。原子的 CN 穿过窗口时能量与力连续（窗口边上的能量跳变 ≤ 2.5e-14 Ha，对应移动 2e-7 Bohr 的 F·ds）。
  • MD：原子不断进出切换窗口（1 ps 内 78–220 次）的 NVE（ASE 速度 Verlet）中，守恒量 F + Ekin 的误差按 dt² 收敛，漂移 ≤ 6e-3 eV/ps（不切换 2.9e-3），和不切换时同一量级（第四节）。
  • 探针中的发现：异标签文件若带 on-site 行，DFTB+ 不报错而能量错 3.1e-2 Ha（pydftb 拒绝）；hotcent 2.1 不能处理同一元素的两种约束（生成脚本绕过）；按任务书命名的 types.py 会遮住标准库（改名 typeswitch.py）。
  • 2离散极限的 DFTB+ 参考算例，全部通过
  • 0切换与显式标签之差（逐位）
  • 5e-10切换区内力与能量差分之差（Ha/Bohr）
  • 0旧计算路径改变的位

二、怎么用

from pydftb import DFTB, ParamSet
from pydftb.typeswitch import TypeSwitch

sw = TypeSwitch("Cu", types=("Cu2", "Cu"),     # 按 CN 从小到大：低配位 Cu2，块体 Cu
                centre=10.5, width=1.0)        # 窗口 [10, 11]；三种类型时 centre、width 各给两个
                                               # cutoff=(r_on, r_off) Bohr，或 {"O": (r_on, r_off)}
sk = ParamSet(skdir).skset(["Cu", "Cu2"])      # 所有类型都要在 SK 集中（含 Cu-Cu2、Cu2-Cu）
calc = DFTB(sk, kpts=k, type_switching=[sw])
r = calc.calculate(["Cu"] * n, pos, cell, pbc)  # 被切换元素的原子只给元素名
r.type_weights["Cu2"]                          # 每个原子的 Cu2 权重
sw.coordination_numbers(["Cu"] * n, pos, cell, pbc)   # 选窗口前先看 CN

atoms.calc = PyDFTB(skdir, kpts=(4, 4, 1), type_switching=[sw])   # 截断用 Bohr
  • 类型文件：同一元素的各类型必须有相同的 on-site 能、U、占据数、基组与质量（PTBP 的类型满足）；异标签文件（Cu-Cu2.skf）用异核格式，不能带 on-site 行（hotcent 写出的同符号文件带这一行，要去掉；validation/make_cu_types_set.py 给出完整的做法）。
  • 按标签的选项（hubbard_derivs、spin_constants、spin_orbit、plus_u、onsite_corrections、hubbard）按参考类型查：元素名在类型中时就是它（上例中 "Cu"），否则是第一种类型；给了多种类型时值必须相同。
  • 可以组合：SCC 与非 SCC、k 点、应力、DFTB3、阻尼、H5、共线与非共线自旋、自旋轨道、DFTB+U、onsite 修正、外场、点电荷、位点势、溶剂、色散、卤素与偶极修正、固定费米能级、独立 k 点填充、fd_delta、各求解器、能带、电荷文件。拒绝：torch 后端、pydftb.autodiff、Casida（含激发态的力）、XL-BOMD。
  • 窗口怎么选：权重只在 CN 落在窗口内、并且有近邻处在计数窗口 (ron, roff) 内时才随几何变化。默认计数窗口（1.1–1.3 倍共价半径之和）把 fcc 金属的第一壳层计 1、第二壳层计 0，CN 为整数，切换只发生在配位真正改变的地方；要让热振动下的键长也参与，就把计数窗口放在键长上。窗口越窄、类型差别越大，切换区的力变化越快，MD 的步长要相应减小（第四节）。

三、离散极限：与 DFTB+ 的对照

参数为新做的 cu_types（Cu：PTBP 发表的约束 r0w 2.749、r0d 12.036；Cu2：r0w 3.0；排斥能为 physrep，σrep 0.42 与 0.45）。DFTB+ 跑切换给出的固定类型标签（Type2FileNames）；“切换”一列是 pydftb 用切换与用显式标签之差，对 eigh、batched 与带 DFTB+ 差分步长的 batched 三种设置都检查（golden 也跑这三种）。括号里是用 DFTB+ 的差分步长（2−13 Bohr）时的值。

四、切换区内：自洽检查与 MD

力与应力是能量的导数

Cu6（八面体扰动 0.12 Å），计数窗口 4.6–5.4 Bohr、切换窗口 [2.2, 4.2]：6 个原子的权重都在 0 与 1 之间。力对 4 点差分（h = 1e-4 Bohr，SCC 容差 1e-12），18 个坐标全查：

  • 三种类型（Cu2 → Cu → Cu3，Cu3 是 Cu2 的副本，两个相邻窗口都有原子）：力一致到 1e-8 以内（测试）。
  • 周期体系：扰动并剪切的 4 原子 fcc 晶胞，计数窗口 4.4–5.3 Bohr 穿过第一壳层，k 2×2×2：12 个力分量 4.4e-10；6 个维里分量对 4 点应变差分（h = 1e-5）4.6e-9，而 |W| 达 9.3 Ha，其中权重项 9.9 Ha。陡的切换使两点应变差分的 h² 误差达 1e-6（h 减半误差降为 1/4），所以用 4 点。
  • 一个原子的 fcc 晶胞（CN 全部来自它自己的周期像）：力为 0，维里对差分 7e-10。

能量连续

Cu4 四面体加一个盖在面上的原子，沿面法线拉出 1.7 Bohr：它的 CN 从 3 降到 0，穿过窗口 [0.5, 2.5]（三个键依次穿过计数窗口 5.0–6.0 Bohr）。路径上 18 个点（避开 SK 格点 ±1e-3 Bohr）的斜率与 4 点差分之差 ≤ 3.7e-10；在窗口两个边上相距 2e-7 Bohr 的两点，能量之差与 F·ds 之差 ≤ 2.5e-14 Ha，力之差 ≤ 6.8e-9；路径两端（权重 0/1）与固定标签逐位相同。

MD

五、行为说明

  • DFTB+ 不会发现异标签文件中多出的 on-site 行：把 Cu-Cu.skf（带 on-site 行）复制成 Cu-Cu2.skf、Cu2-Cu.skf，DFTB+ 照算，Cu13 的能量 −28.2991 而正确值为 −28.2682（差 3.1e-2 Ha）：第二行被当作质量与多项式行，表整体错位。hotcent 2.1 对同一符号的两个原子正好写出这样的文件。pydftb 同样按标签决定格式，所以对切换的类型对做检查，遇到就拒绝并说明怎么改。
  • hotcent 2.1 与同一元素的两种约束：符号相同时只算一个方向、只取第一个原子的波函数范围（范围小的原子在前时积分被截断）、按符号命名文件。make_cu_types_set.py 的 CrossTable 两个方向都算并取两个原子的范围（与 hotcent 处理两种元素相同），文件按异核格式写出、按标签命名；所得 Cu-Cu2 与 Cu2-Cu 的 ssσ 逐位相同。
  • PTBP 发表的 σrep 与现在的表：用 PTBP 发表的 Cu σrep 0.299 时，Cu6 的 MD 塌缩（最短原子距 2.24 → 1.1 Å，势能一路下降）：二聚体在 1.4 Å 以上没有极小，压缩到 a = 2.8 Å 的 fcc 比平衡态还低。0.299 与现在生成的表不配套：PTBP 自己在发表的 r0 上按现在的做法（自洽约束，仓库自带的数据）搜索得到 σrep = 0.403（engine_parity 的日志），与这里用的 0.42 相近（二聚体极小 2.2 Å，实验 2.22 Å）。所以这与切换无关，只说明测试参数要配套。
  • 标签：被切换元素的原子在 calculate 中只给元素名，给类型标签时报错；类型中没有元素名时（如 Cu_a、Cu_b），引擎用第一种类型作参考，结果与同样内容的 Cu/Cu2 逐位相同（测试）。没有被切换元素的原子时走原来的路径，type_weights 全为 0。
  • 性能（36 原子的 Cu(111) 平板，k 2×2×1，力与应力，SCC 都是 17 轮）：不切换 2.14 s；权重全为 0/1 时 2.04 s，与显式标签的 2.11 s 相同（差别在噪声内）；36 个原子都在窗口内时 2.64 s，其中建块 0.19 → 0.62 s（每个原子对要算 4 个类型对），力 0.06 → 0.18 s（权重项）。只有窗口内原子所在的原子对多算、多存块。
  • 模块名：pydftb/types.py 在 pydftb/ 目录中运行 Python 时遮住标准库的 types（Python 3.13 下 import enum 失败），所以叫 typeswitch.py。

七、与设计的偏差

  • 模块名：任务书写的是 pydftb/types.py，实际为 pydftb/typeswitch.py（设计 P8：前者遮住标准库）。
  • 测试参数的排斥能：设计时 Cu 用 PTBP 的 σrep 0.299、Cu2 用 0.42；MD 测试中团簇塌缩（第五节），改为 0.42 与 0.45，两个参考算例按最终的参数集重新生成。Cu 的 r0w、r0d 仍是 PTBP 发表的值。
  • 应力的差分：设计中是 1e-5 应变的两点差分；切换陡时两点差分的 h² 误差达 1e-6（h 减半误差降为 1/4），改为 4 点差分。
  • 连续性的检查：最初想用力的数值积分（梯形、Simpson）对能量差，但 SK 表的插值在格点处导数不连续，积分误差到 1e-5，分不出真正的跳变；改为路径上逐点的差分、窗口边上的两侧比较与两端的逐位比较。
  • 补充：设计中没有的 onsite_line_files 检查（来自探针 P7′）、TypeSwitch.reference（按标签的选项按它查，元素名是类型之一时就用元素名）、按元素选择近邻的计数窗口字典。
