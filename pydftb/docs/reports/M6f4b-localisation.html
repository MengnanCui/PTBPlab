DFTB+ Analysis 的输出补齐了：Pipek–Mezey 局域轨道（DFTB+ 的稠密算法，逐步照它的扫描顺序与收敛判据）、键布居、键能与 Mayer 键级（DFTB+ 25.1 之后的新功能），以及 Casida 跃迁电荷，并能写出 DFTB+ 格式的 localOrbs.out/.bin、bond_*.dat 与 ATQ.DAT。只在 NumPy 引擎中；不开这些选项时逐位不变。

  • 与 DFTB+ 对照：10 个新的参考算例全部通过（4 个用开发版），SCC 轮数逐个相同：
    • 局域化：pm_localisation 与每个自旋通道的终值差 ≤ 1.8e-10，每个局域轨道的 Mulliken 布居（按最佳配对）差 ≤ 1.9e-8，localOrbs.out 除数值与符号外逐字节相同；
    • 键布居、键能、Mayer 键级差 ≤ 5.7e-14（分子）与 4.0e-11（k 点），bond_*.dat 逐字节相同；
    • 跃迁电荷 q² 差 ≤ 8.1e-15，ATQ.DAT 差 ≤ 4.9e-10（9 位小数），版式相同。
  • DFTB+ 的行为（第五节）：k 点的 Pipek–Mezey 用不取共轭的乘积，结果依赖本征向量的任意相位，在 CuO 链上 8 个 k 点全部超过最大扫描次数，pydftb 只局域化实数轨道；稠密算法用 acos 求旋转角，局域轨道只能确定到约 4e-9；有简并时（O2）收敛只能碰巧满足；StateOfInterest = Brightest 时 DFTB+ 写出 NaN 的跃迁电荷，pydftb 用找到的最亮态；周期体系拒绝 Mayer 键级（同 DFTB+）。
  • 接口：Analysis(localise=…, bond_populations=…, bond_energies=…, bond_orders=…)，结果在 r.analysis.localisation、r.analysis.bond_populations 等；Casida(transition_charges=True) 给 r.excitations.transition_charges；文件由 write_eigenvectors(…, localised=True)、write_bond_files、write_transition_charges 写出。

开发细节一、做了什么
位置内容
analysis.py
  • Analysis 加 localise（True 或 {"max_iterations", "tolerance"}，默认同 DFTB+ 的 100 与 1e-4，检查键名与取值）、bond_populations、bond_energies、bond_orders；新数据类 Localisation（每个自旋通道的轨道、Mulliken 权重、布居、局域化的个数、泛函的初值与终值、扫描次数、是否收敛；value 为 DFTB+ 的 pm_localisation）；AnalysisResult 加四个字段；
  • pipek_mezey：逐行照 DFTB+ 的 PipekMezeyOld_real（每个 s 开头对 t > s 一次算好 Sct，Scs 每对重算，acos 求角，带符号的 αmax，第 3 次扫描起检查）；pm_populations；
  • _localise：每个通道局域化最低的 nint(Nσ/(3 − nspin)) 个本征向量（Nσ 由占据数求和），分数占据与超过最大扫描次数时警告（同 DFTB+）；k 点与两分量拒绝；
  • bond_analysis：自旋求和的输出密度（两分量用电荷分量），Σk wk Re[ρ(k)μν S(k)νμ]（或 H0）按原子求和；Mayer 用 PS∘(PS)T，周期体系拒绝；
  • _eigenvectors 只返回本征向量与权重（是否保存由 evaluate 决定），局域化单独要求时不保存正则本征向量。
casida.pyCasida(transition_charges=False)（三重态、both 与无指定态时报错，同 DFTB+）；Excitations.transition_charges：κ·qT(X+Y)n，κ = √2 或 1，用已有的 Mulliken 跃迁电荷与 X+Y；最亮态用找到的态号。
dftbplus_io.pywrite_eigenvectors(…, localised=True)（localOrbs.out/.bin）；write_bond_matrix、write_bond_files、read_bond_matrix（两行注释、ES16.8 与一个空格，行末无空格）；write_transition_charges、read_transition_charges（ATQ.DAT）。
validation/
  • cases.py：10 个算例；TOL_LOC、TOL_BONDS、TOL_TRANSQ；
  • dftbplus.py：analysis_block(spec, periodic) 写 Localise { PipekMezey }（分子加 Dense = Yes）与键分析的关键字，casida_block 写 WriteTransitionCharges；parse_analysis 读标准输出每个通道的初值与终值、pm_localisation、localOrbs.bin（全精度）与 localOrbs.out 文本、三个键矩阵与它们的文件；parse_casida 读 transq_sqr 与 ATQ.DAT；
  • refgen.py：_compare_localisation（用 pydftb 的重叠矩阵算 DFTB+ 局域轨道的布居，按最佳配对比较；localOrbs.out 比较版式，忽略数值与符号）、键矩阵与文件、_compare_transition_charges（q² 与对齐符号后的 ATQ.DAT）；分析的键名加入 ANALYSIS_KEYS，偏差加入 ANALYSIS_DEV。
测试10 个参考 JSON；tests/test_localisation.py（13 项）。

二、怎么用

from pydftb import DFTB, Analysis, dftbplus_io as io
from pydftb.casida import Casida

calc = DFTB(sk, analysis={"localise": True,              # 或 {"max_iterations": 1000, "tolerance": 1e-8}
                          "bond_populations": True, "bond_energies": True, "bond_orders": True})
r = calc.calculate(labels, positions)
loc = r.analysis.localisation
loc.orbitals[0][:, :loc.n_localised[0]]   # 局域轨道（列），其余列是正则的虚轨道
loc.populations[0]                        # (n, n_atom)：每个局域轨道在各原子上的 Mulliken 布居
loc.value, loc.initial, loc.final, loc.sweeps
r.analysis.bond_populations               # (n_atom, n_atom)，行和 = Mulliken 布居
r.analysis.bond_energies                  # Hartree，总和 = r.e_band
r.analysis.bond_orders                    # Mayer 键级（分子）
io.write_eigenvectors("localOrbs.out", r, localised=True)
io.write_bond_files(r, ".")               # bond_pop.dat、bond_energy.dat、bond_order.dat

calc = DFTB(sk, casida=Casida(6, state_of_interest=2, transition_charges=True))
r = calc.calculate(labels, positions)
r.excitations.transition_charges          # (n_atom,)，整体符号任意（同 DFTB+）
io.write_transition_charges("ATQ.DAT", r)
  • 局域化：只有 DFTB+ 的稠密算法（分子也用它；DFTB+ 分子默认的稀疏算法不做）。默认 max_iterations = 100、tolerance = 1e-4（同 DFTB+）；要可比较的结果时收紧（参考算例用 10000 与 1e-10）。k 点（复数本征向量）与两分量计算报错。
  • 键分析：三个开关各自独立；用最后的输出密度（自旋求和）；周期体系的键含所有周期像；Mayer 键级只用于分子（同 DFTB+）。
  • 跃迁电荷：要求指定态与单重态或自旋极化（同 DFTB+）；不乘 √(fi − fa)，分数占据时 ΣqARA 不等于跃迁偶极。

三、与 DFTB+ 的对照

参数为测试用的 ptbp_hcocu；周期体系 EwaldTolerance = 1e-12；局域化 Tolerance 1e-10、MaxIterations 10000。“分析”一栏：局域化比较 pm_localisation、每个通道的终值（E20.12）与初值（E15.8，相对差）、每个局域轨道的 Mulliken 布居（DFTB+ 的 localOrbs.bin 用 pydftb 的重叠矩阵换算，按最佳配对）；键矩阵比较 results.tag 的全精度值与 bond_*.dat 的文本；跃迁电荷比较 autotest.tag 的 q² 与 ATQ.DAT（对齐整体符号）。

四、自洽检查

  • 局域化（甲醇、甲醛阳离子、水盒子）：局域轨道 S-正交（CTSC = I，1e-12），张成的空间不变（ΣiciciT 不变，1e-12），虚轨道原样不动，每个轨道的布居之和为 1，泛函不减，局域化的个数等于 nint(Nσ/(3 − nspin))；翻转输入轨道的符号，输出只差符号（1e-7，acos 的精度）。
  • 键分析：矩阵对称；行和等于 Mulliken 布居（1e-10），键能之和等于 e_band（1e-11）；闭壳层整数占据时 Mayer 行和等于 2 × 布居（1e-10），甲醇的 C–O 键级 0.946；两分量计算也满足求和规则；k 点 0 与 ½ 的晶胞等于加倍晶胞的 Γ 点（每对原子与两个副本之和，1e-9），总和等于电子数。
  • 跃迁电荷：Σq = 0（1e-12）；整数占据时 ΣqARA 等于该态的跃迁偶极（1e-12）；最亮态用找到的态号，电荷有限（DFTB+ 写 NaN）；不要求时为 None。
  • 文件：localOrbs.out/.bin、bond_*.dat、ATQ.DAT 写出后能读回；二进制逐字节等于轨道；没有对应结果时写出函数报错。
  • 拒绝：k 点与两分量的局域化、未知的局域化选项、MaxIterations < 1、Tolerance ≤ 0、周期体系的 Mayer 键级、三重态或无指定态的跃迁电荷；分数占据时警告。

五、DFTB+ 的行为

  • k 点的 Pipek–Mezey（PipekMezeyOld_kpoint）：Qst、Qss 用不取共轭的 cμs(Sct)μ，不是 Mulliken 布居，随每个本征向量的任意相位改变。原型（照它的公式）在 CuO 链 4 × 2 × 2 上用 pydftb 的本征向量、原样与两组随机相位，2000 次扫描都不收敛，各 k 点之和为 78.48、70.01、67.99，有的 k 点终值低于初值；DFTB+ 25.1 本身 Tolerance 1e-4 时 7 个 k 点超出、终值 78.33，1e-10 与 2000 次时 8 个全部超出、终值 80.33。pydftb 不实现它，k 点报错并说明原因。
  • acos 的分辨率：接近收敛时 −A/√(A² + B²) 舍入成 1，旋转角只能分辨到约 4e-9 rad。从 DFTB+ 写出的本征向量出发，pydftb 的实现复现 localOrbs.bin 到系数差 3.6e-9（甲醇）与 5.3e-9（水盒子），泛函差 ≤ 6e-14。
  • 简并与收敛判据：DFTB+ 的 αmax 存的是带符号的角（if (alphamax < abs(alpha)) alphamax = alpha），判据是相邻两次扫描 |αmax| 之差。O2 的 π 轨道简并，泛函沿简并方向是平的，DFTB+ 用 4 + 114 次扫描碰巧满足，pydftb 从自己的本征向量出发自旋向下的通道 10000 次仍未满足（泛函早已一致到 6e-14）；参考算例改用没有简并的甲醛阳离子。
  • 稀疏算法（分子默认）：收敛阈值在这条路径上从未赋值；甲醇上它给出与稠密算法相同的泛函（4.60995609907495）。pydftb 不做。
  • 输入规则：分子只写 Tolerance 会因未处理的节点退出（不写 Dense = Yes 时 Tolerance 不读）；周期体系写 Dense 会退出（总是稠密）。
  • 键分析（开发版）：用自旋求和的密度；周期体系的对角含全部自身像（fcc Cu 的 B = 11）；键能之和等于 EH0；Mayer 键级只用总密度（开壳层少了自旋密度项），周期体系退出；三个文件只在写 tag 时才写。默认 EwaldTolerance = 1e-9 时 CuO 链的键布居差 4.2e-8，收紧到 1e-12 后 4.0e-11（同 M6f-4a）。
  • 跃迁电荷：StateOfInterest = Brightest 能通过检查，但写跃迁电荷时拿 −1 当下标，ATQ.DAT 与 tag 全是 NaN；三重态退出；不乘 √(fi − fa)（3000 K 时 ΣqARA 与跃迁偶极差 0.54），与 Casida 矩阵和跃迁偶极的约定不同。

六、SCC 收敛的余量

DFTB+ 倒数第二轮误差与阈值之比、阈值与最后一轮误差之比（局域化与键分析算例逐轮比较 SCC 误差；Casida 算例的 SCC 与已有的同名基态算例相同）。甲醛阳离子最后一轮离阈值只有 1.3 倍，但 pydftb 与 DFTB+ 逐轮误差的相对差 1.4e-7，不会跨阈值（与已有的 h2co_cation_casida 相同）。

八、与设计的偏差

  • 算例：设计中自旋极化的局域化用 O2 三重态，实测其 π 简并使收敛只能碰巧满足，改用甲醛阳离子；键分析多了一个 cu_fcc_k6_bonds（只有自身的像），共 10 个。
  • 容差：局域化的初值（E15.8）按相对差 1e-7 比较（8 位有效数字的舍入可达 5e-8）；局域轨道的布居 1e-7（acos 的精度）。
  • 接口：Casida 不从 pydftb 顶层导出（与以前相同，用 pydftb.casida.Casida）；Localisation 另给每个局域轨道的布居 populations。
  • 开发方式：P1 合并后的门槛运行期间，M6f-4b 在临时 worktree（$S/m6f4b_wt，从合并提交检出）中开发与对照，门槛结束后再搬回主工作区，避免改动正在被门槛读取的文件。
