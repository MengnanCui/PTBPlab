关键信息

pydftb 是从零写成的 Python SCC-DFTB 程序，每一项功能都与 DFTB+ 逐项对照，参考结果冻结在仓库里，测试不需要 DFTB+。它已接入 PTBP，可以替代 DFTB+ 做参数优化。

  • 已完成：原型、M0 底座、M1 接入 PTBP，M2 的全部七项（应力、DFTB3、共线自旋、色散、能带与 DOS/PDOS、结构优化与 MD 的验证、f 轨道），以及 M3 的四项：PTBP 的 BO 步默认用满可用核心，Cu 数据集 4 核上一个 BO 步从 147 s 降到 27 s，运行目录与原来逐字节相同；进程数和线程数由成本模型决定，启动时给出预计耗时（与实测差 2–4%），ptbp plan 不运行优化就能看到方案和建议；DFTB+ 配置顾问（pydftb advisor）按 18 条规则检查 DFTB+ 的输入和输出，PTBP 用 DFTB+ 时自动检查。M4 已完成：M4a 的 PyTorch 后端（backend="torch"）已完成，74 个单点和 11 个优化/MD 的 DFTB+ 参考在 torch 上全部通过，与 NumPy 的差 ≤ 1.4e-13；M4b 的自动求导（pydftb.autodiff）已完成：能量、电荷、本征值、力、应力对 SK 表、U、排斥势系数等参数和坐标的导数，与引擎的有限差分对照 346 项全部通过（中位相对差 2e-9）；M4c 已完成：PTBP 能算损失对 r0_w、r0_d 的梯度，新增可选的 --optimizer gradient 和 bo_grad，默认的 BO 逐字节不变。与 BO 的对比（Cu，4 核）：energygeometry 模式梯度法 635 s 把损失从 1.899 降到 0.760，3 次 BO 中最好的是 0.855；dataset 模式两者打平（209.9 对 208.5）；M4d 已完成：pydftb 可以在 NVIDIA/AMD（cuda）、Apple（mps）、Intel（xpu）的 GPU 上算，按设备能力把部分步骤留在 CPU，CUDA 上用确定性算法；新增 GPU 自检脚本 pydftb gpu-check；PTBP 新增 --pydftb_backend、--device、--dtype。本机没有 GPU，GPU 的正确性和速度要等用户运行自检脚本后才有实测数字。
  • M4e 已完成：PTBP 的参数化回到原计划，每个元素三个有效参数（r0_w、r0_d、σ_rep）。hotcent 的原子计算默认用自洽约束（hotcent 1.x 的做法），r0_d 重新进入 SKF；发表的 Cu 参数下 energygeometry 损失从 1.899 降到 0.920（论文 0.288）。--confinement perturbative 复现之前的结果。
  • M6a 已完成：pydftb 能做两分量计算，即非共线自旋与自旋轨道耦合（DFTB+ 的 onsite 和 dual 两种模型），可与 DFTB3、壳层分辨 SCC、k 点、力、应力、能带与 DOS 一起用（只有 NumPy 引擎）。16 个新的 DFTB+ 参考算例全部通过，SCC 轮数逐个相同，能量差 ≤ 4.9e-11 Ha。
  • M6b 已完成：DFTB+U（FLL、pSIC）与 onsite 修正，两者都是作用在同一原子轨道块上的“块势”，可与无自旋、共线和非共线自旋、dual 模型的 SOC、DFTB3、k 点、力、应力、能带一起用（只有 NumPy 引擎）。18 个新的 DFTB+ 参考算例全部通过，能量差 ≤ 5.6e-11 Ha，17 个的 SCC 轮数完全相同、另一个差 1 轮；水加 onsite 修正的 MD 与 DFTB+ 一致到 4.5e-8 Å。
  • M6c 已完成：外电场（周期体系为 DFTB+ 的锯齿势）、外部点电荷（静电嵌入，可加高斯展宽，周期体系用 Ewald，给出点电荷受的力，ASE 的 QM/MM 可直接用）、原子格点势，以及分子的隐式溶剂（广义 Born 与 ALPB、SASA、氢键修正、CM5）；可与自旋、SOC、+U、onsite、DFTB3、k 点、力、应力、MD 一起用（只有 NumPy 引擎）。22 个新的 DFTB+ 参考算例全部通过，SCC 轮数全部相同，能量差 ≤ 1.0e-10 Ha；水在 GBSA 溶剂中的 MD 与 DFTB+ 一致到 3.9e-8 Å。
  • M6d 已完成：激发态（Casida 线性响应，TD-DFTB）：激发能、振子强度、跃迁偶极、主要跃迁与权重，单重态、三重态、共线自旋极化（Δ⟨S²⟩），分数占据、onsite 修正、Γ 点周期体系、能量窗口与振子窗口、指定态与最亮态，可与外电场、点电荷、色散同用（只有 NumPy 引擎）。18 个新的 DFTB+ 参考算例全部通过，激发能差 ≤ 1.8e-11 Ha，EXC.DAT、SPX.DAT 中打印的值全部一致；大体系用分块 Davidson，C60 比 DFTB+ 最快的求解器快 3 倍。
  • M6e 已完成：激发态的力（Z 向量方法求 E0 + ω 的完整导数，单重态、三重态、共线自旋极化，可与外场、点电荷、色散、H–X 阻尼、能量窗口同用），激发态的 Mulliken 电荷与偶极，ASE 中的激发态结构优化与 MD；以及 XL-BOMD（DFTB+ 的 Xlbomd/XlbomdFast，影子能量与它的力，ForceEvaluation）（只有 NumPy 引擎）。11 个单点与 9 个动力学的 DFTB+ 参考算例全部通过：用 DFTB+ 的差分步长时激发态力差 ≤ 1.8e-12 Ha/Bohr；7 条 XL 轨迹每步的 SCC 轮数与 DFTB+ 相同，位置、速度、能量一致到 DFTB+ 打印的位数。
  • M6f-1 已完成：SCC 的起点与混合器。DFTB+ 的 Simple、Anderson、DIIS 混合器与 Broyden 的全部选项，InitialCharges、共线 InitialSpins，读写 DFTB+ 的电荷重启文件 charges.bin/.dat（文本逐字节相同），每轮的 SCC 误差 scc_errors（只有 NumPy 引擎）。25 个新的 DFTB+ 参考算例和 1 条 MD 全部通过：SCC 轮数逐个相同、MD 每一步都相同，逐轮误差相对差 ≤ 3.1e-5；DFTB+ 写的 21 个电荷文件逐字节往返。注意 mixer="anderson" 现在是 DFTB+ 的 Anderson，原来的 Pulay 型是 "pulay"。
  • M6f-2 已完成：占据与参数覆盖。固定费米能级（电子数不守恒，力与应力是力相关能量 F − Σ NsEf,s 的梯度）、每个 k 点单独填充、自定义 Hubbard U、自定义参考占据（“虚拟掺杂”）、截断 SK 表（只有 NumPy 引擎）。20 个新的 DFTB+ 参考算例全部通过，SCC 轮数逐个相同，能量差 ≤ 1.0e-10 Ha；带电周期晶胞的应力 pydftb 与 DFTB+ 能量的应变差分一致到 8e-13，DFTB+ 自己的应力差 3.9e-7。
  • M6f-3 已完成：修正项。H5 氢键修正（γ 的短程部分乘 1 + g(r)）、DFTB3 的卤素修正（HalogenXCorr）、平板的偶极修正（DipoleCorrection，25.1 之后才有）（只有 NumPy 引擎）。13 个新的 DFTB+ 参考算例和 1 条 MD 全部通过，SCC 轮数逐个相同，能量差 ≤ 8.5e-11 Ha；25.1 没有的两项对照自编的开发版 DFTB+（041e723）。DFTB+ 在卤素开关区间内的力、激发态带 H5 的力、偶极修正的应力都不是能量的导数，pydftb 的是。
  • M6f-4a 已完成：分析输出的前一半。按原子分解的能量（每一项都按 DFTB+ 的方式拆到原子上）、净布居与杂化比、CM5 电荷（含周期体系）、静电势（散点与网格），以及 DFTB+ 格式的 eigenvec.out/.bin、band.out、ESP.dat 与 detailed.out 的分析块（只有 NumPy 引擎）。19 个新的 DFTB+ 参考算例全部通过，按原子的能量差 ≤ 5.0e-9 Ha（detailed.out 8 位小数的舍入），写出的文件除数值外与 DFTB+ 逐字节相同。DFTB+ 把 D3 色散平均分给每个原子，pydftb 按原子对。
  • M6f-4b 已完成：分析输出的后一半。Pipek–Mezey 局域轨道（DFTB+ 的稠密算法，逐步照它的扫描顺序与收敛判据）、键布居/键能/Mayer 键级（DFTB+ 25.1 之后的新功能）、Casida 跃迁电荷，以及 DFTB+ 格式的 localOrbs.out/.bin、bond_*.dat、ATQ.DAT（只有 NumPy 引擎）。10 个新的 DFTB+ 参考算例全部通过（4 个用开发版），局域轨道的 Mulliken 布居差 ≤ 1.9e-8，键矩阵 ≤ 4e-11，bond_*.dat 逐字节相同。DFTB+ 的 k 点局域化依赖本征向量的任意相位且不收敛，pydftb 只局域化实数轨道。
  • P1 已完成：拆成两个可安装的包。pydftb 只依赖 numpy、scipy、ase、threadpoolctl，可以单独安装（pip install ./pydftb，开发时 pip install -e ./pydftb -e .），有自己的命令 pydftb（advisor、refgen、dynamics、golden、gpu-check、gradcheck）；ptbp 依赖它，tools/engine_parity.py 成为 ptbp parity。旧的 python -m … 写法照常可用。
  • M5a 已完成：同一元素多套参数的平滑切换（引擎机制）。DFTB(type_switching=TypeSwitch("Cu", types=("Cu2", "Cu"), centre=…, width=…))：被切换元素的每个原子按配位数在它的类型之间取权重，H0、S 与排斥能按权重混合，力与应力含权重的导数，周期体系与 MD 都能用（只有 NumPy 引擎）；DFTB+ 每个原子只能固定一种类型。权重恰为 0/1 时与 DFTB+ 用固定类型标签的计算对照（2 个参考算例，能量差 ≤ 2.2e-11 Ha），切换区内力与能量差分一致到 5e-10，MD 中守恒量的漂移与不切换时同一量级。PTBP 一侧的按类型拟合（M5b）已完成：多元素数据集默认每个元素一套参数，--shared-parameters 复现以前的共用一组；M5b-2 的后续修正也已完成：失败点按本次运行至今最差成功损失的 2 倍计，部分结构没有结果也算失败，BO 的默认次数按维数放大。
  • M6f-5 已完成，M6f 至此全部完成：SelectedShells，一个原子的基组由几个 SK 文件中的壳层拼成，同一个 l 可以出现两次（ParamSet(skdir, selected_shells={"O": ("sp", "s")})；只有 NumPy 引擎）。读文件、轨道顺序、按壳层的 on-site 能/U/占据数、拼表、排斥势与质量都照 DFTB+。8 个新的 DFTB+ 参考算例全部通过，能量差 ≤ 5.0e-11 Ha，用 DFTB+ 的差分步长时力差 ≤ 1.05e-12。SelectedShells 与 Type2FileNames 同用时 DFTB+ 25.1 段错误。
  • M6g-1 已完成：电场极化率（静态与频率相关）与响应核（DFTB+ Analysis 中的耦合微扰 SCC；DFTB(analysis={"polarisability": …, "response_kernel": True})；只有 NumPy 引擎）。公式与 DFTB+ 相同（对未微扰态求和，简并组与金属的费米能级移动照 DFTB+），但直接解线性方程而不迭代；含共线自旋、金属、简并、DFTB3、Γ 点与 k 点。19 个新的 DFTB+ 参考算例全部通过，极化率差 ≤ 3.6e-11 a.u.，响应核 ≤ 1.5e-13，写出的 detailed.out 块与 dE_band.out、dV_band.out 除数值外与 DFTB+ 逐字节相同。发现 DFTB+ 默认的响应容差让水的极化率差 2.5e-7、dEF/dE 打印的是物理值除以满占据、k 点的有限频率响应在约化 k 点集里留下 ∝η 的人为项。
  • M6g-2 已完成：坐标导数与 Born 电荷（DFTB+ 的 CoordDerivatives；DFTB(analysis={"coord_derivatives": True})）、数值 Hessian（Driver = SecondDerivatives，同时给偶极与极化率的导数）与简正模（modes 的频率、红外与拉曼强度；pydftb.vibrations）。只有 NumPy 引擎。坐标响应用有限温度下的完整一阶密度，DFTB+ 拒绝的自旋、金属、简并与它算错的外场、点电荷都给出正确导数。20 个新的 DFTB+ 参考算例全部通过，电荷导数差 ≤ 2.3e-12 e/Bohr，Born 电荷 ≤ 4.2e-12，数值 Hessian ≤ 1.4e-8 Ha/Bohr²，modes 的频率 ≤ 6.5e-9 Ha。发现 DFTB+ 的 Born 电荷与 born.out 反号、25.1 漏了 DFTB3 项、两个版本都漏了外场与点电荷对位置的导数，以及响应的占据窗口使金属的响应差约 2e-7（新选项 filling_tol）。
  • M6g-3a 已完成：DFTB+U（FLL、pSIC）与 onsite 修正下的极化率、响应核与坐标导数（两者同用也可以，DFTB+ 拒绝），以及原子布居对外部点电荷位置的导数（开发版 DFTB+ 的 ExternalChargeDerivatives；DFTB(analysis={"external_charge_derivatives": True})，分子与周期体系）。只有 NumPy 引擎。18 个新的 DFTB+ 参考算例全部通过：带块势的极化率与 25.1 差 ≤ 3.7e-11 a.u.，坐标导数对照 DFTB+ 的差分 Born 电荷到 6.4e-8（DFTB+ 拒绝块势下的坐标导数），点电荷导数与开发版差 ≤ 1.4e-11 e/Bohr。发现开发版的点电荷导数在周期体系中符号相反。
  • M6g-3b 已完成，M6g 至此全部完成：两分量计算（非共线自旋，onsite 与 dual 两种 SOC，可带 +U 与 onsite 修正）下的极化率、响应核、坐标导数（分子）与点电荷导数（新模块 response_pauli.py；只有 NumPy 引擎）。每个 k 点一个 2N × 2N 的旋量块，χ0 的四个 Pauli 分量互相耦合；没有 SOC 时整体转动是严格零模式，用加边方程求不含转动的解（与 DFTB+ 的纵向结果一致），有 SOC 时 SVD 截掉偶然的零模式并警告。21 个新的 DFTB+ 参考算例全部通过：极化率与 25.1 差 ≤ 1e-11 a.u.（GdO 的软模式 1.1e-9），坐标导数对照 DFTB+ 的差分 Born 电荷到 4.9e-8（DFTB+ 拒绝两分量的坐标导数），点电荷导数与开发版差 4.1e-14 e/Bohr。发现 DFTB+ 25.1 在 dual SOC 与 +U 或 onsite 同用时丢掉块布居虚部的响应：分子的极化率差 2.2e-5–1.3e-4，周期 CuO 链的响应核差 75 %；pydftb 的物理值对照 DFTB+ 自己的有限外场到 3.8e-12，测试专用开关复现 DFTB+ 到 1e-13。
  • 下一步：M6h 长程校正 LC/CAM（含 TD-LC）；再做 M7、M8。PTBP 的参数化仍是每个元素 r0_w、r0_d、σ_rep 三个参数（M5b 起多元素数据集按元素分开）。GPU 自检请在有 GPU 的机器上运行 pydftb gpu-check --dtype both --json gpu_check.json 并把 JSON 发回来。
  • 验收标准：与 DFTB+ 的能量差 < 1e-6 Ha、力差 < 1e-5 Ha/Bohr、应力差 < 1e-7 Ha/Bohr³。实际差异通常小 3–5 个数量级，剩下的差异都已归因。

如何接手

环境

  • 最小环境：numpy、scipy、ase（与 CI 相同）。全部离线测试都能跑；需要 D3/D4 库或 DFTB+ 的用例会跳过并写明原因。
  • 完整环境：再从 conda-forge 装 dftbplus=25.1（nompi）、dftd3-python=1.0.0、dftd4-python=3.6.0、hotcent。这两个库的版本与 DFTB+ 链接的库相同，参考结果才能逐位复现。开发机上它们在 /opt/mm/dftb，DFTB+ 路径可用环境变量 DFTBPLUS 指定。重新生成 M2e 中冻结的 DOS 曲线还需要 DFTB+ 仓库里的 dptools 源码（tools/dptools/src，环境变量 DPTOOLS）。
  • 安装（P1）：pydftb 与 PTBP 是两个包，开发时在仓库根目录 pip install -e ./pydftb -e .（pydftb 可以单独装：pip install ./pydftb），装好后有 pydftb 和 ptbp 两个命令。不安装也照旧可用：在仓库根目录用 PYTHONPATH=.，把下面的 pydftb 换成 python -m pydftb。

已知问题

  • PTBP 的 --optimization_option bandstructure 模式有多处错误，目前跑不通（与 pydftb 无关，另有任务）。
  • 已修正（M3 之前）：PTBP 损失函数的惩罚项过去总用 0.5 Bohr 的共价半径（cli/run.py 算出了元素的半径，但没有传给 Loss(...)），Cu 的惩罚因子因此是 1.2e4 而不是 6.0。现在用被参数化元素的半径；参数表中已发表的 75 个元素的损失值都能用这个公式复现（相对差 ≤ 5e-5）。已发表的 Cu 参数下，dataset 模式的损失从 901629.83 变为 446.20，energygeometry 模式从 3837.92 变为 1.8993，两个引擎的相对差仍在 1e-8 以内。旧运行的损失值是另一个尺度：旧的 skopt 检查点在恢复时会被拒绝，可用 tools/rescale_checkpoint.py 精确换算。
  • energygeometry 模式在已发表的 Cu 参数下的损失为 0.920（M4e 之前为 1.90），论文中为 0.288：μV 已回到论文的量级（0.0129 对 0.0182），μE 仍大 3.8 倍（0.293 对 0.0775）。M4e 查明前一半来自 hotcent 约束方式的默认值；剩下的最可能来自 hotcent 在 2021-10 修正的二中心积分 GGA 错误（PTBP 最初用的版本带着它），这部分不应恢复（M4e 报告第四节）。
  • 已修正（M5b）：多元素模式（--multi_element）以前跑不通（命令行的元素符号与要求的原子序数不符、参数表没有 r_wave 键、只优化 σrep 的分支调用错误）；现在的含义是只拟合列出的元素，其余用 PTBP 发表的参数。data.get_full_dftb 以前按 Hill 顺序重建结构，非 Hill 顺序的多元素结构（如 [Na, N, N, N]）写出的元素与坐标错位（能量与按下标的力不受影响），也已修正。
  • 已修正（M5b-2）：PTBP 失败点的损失以前是 97–99 的随机整数，reaction/dataset 模式中低于真实损失（150–5000），BO 会把失败点当作好点；部分结构没有 DFTB 结果时，损失只在其余结构上算（偏低），旧路径在 dataset/reaction 中还会让运行停止。现在失败点的损失是本次运行至今最差成功损失的 2 倍（第一个成功点之前 energygeometry 1000、dataset/reaction 每个结构 1000），部分失败算失败；只有出现失败的运行结果会变。仍然存在：旧路径 energygeometry 不支持一个 EOS 组里有多个元素，Loss.get_elements_from_dataset 遇到元素数不同的结构出错，bandstructure 模式的失败值 20 未改（M5b-2 报告第八节）。
  • k 点密度较低（--kpts 2.0）、T = 0 时，Cu 数据集的第 44 个结构（6×6×6 网格）在两个引擎中都 1000 轮 SCC 不收敛（各约 40 s），结果照常返回：pydftb 给出警告，DFTB+ 只在输出文件里注明。默认的 5.0 和 3.0 下都收敛（见 M3a 报告）。
  • σ_rep 搜索每个 BO 步评估 74 次，其中 L-BFGS-B 的 41 次回到网格搜索已经找到的 σ（损失在 1e-8 量级上有噪声，差分梯度没有意义）；部分 σ 上状态方程拟合失败，损失出现尖峰（例如 σ = 0.38 时 101.8）。改搜索方法会改变结果，见 M3b 报告。
  • PTBP 的历史 DFTB+ 输入（--smearing none，默认）：ParserVersion = 1 让 DFTB+ 用 0.01 Bohr 的差分步长求 H、S 的导数（水、甲醇的力差 4–7e-3 eV/Å），写在 Filling 外的展宽被忽略、实际 T = 0。已发表的参数就是这样拟合的，为了可比没有改；配置顾问把它们标为“预期”（M3d 报告第三节）。
  • pydftb 的库仑准备把截断内的所有原子对和壳层对展开成数组：64 个 Cu 原子的周期晶胞要 2.2 GB 内存（DFTB+ 0.3 GB），耗时也是 DFTB+ 的 2.5 倍。推荐器会按内存减少进程；改为分块处理是后续的优化项（M3c 报告）。
  • 大的金属晶胞只用 Γ 点、T = 0（PTBP 历史输入的默认）时 SCC 很难收敛：64 个 Cu 原子的晶胞 DFTB+ 跑了 3 分半钟仍未收敛，1000 K 的展宽下 23 轮。PTBP 的数据集是小晶胞加 k 点，没有这个问题；用大晶胞时应开 --smearing。
  • torch 后端（M4a）：float32 不要用于 T ≈ 0 的金属的力（Cu 数据集个别结构差 3e-2 eV/Å，加 1000 K 展宽后 ≤ 8e-5）；从多线程跑过 torch 的进程 fork 子进程时，子进程要先设 torch 的线程数（PyDFTB(threads=n) 会做），否则会卡死。
  • 自动求导（M4b）：引擎的 F 有两处不是“电子数固定”的 Mermin 自由能——MP 展宽配 DFTB+ 的 TS（hf 模式拒绝给 dF，用 ts_convention="variational" 或 implicit 模式），以及电子数为整数时 DFTB+ 的带隙中点费米能级（电子数可漂移 1e-7；fermi_level="exact" 去掉）。异核 SK 文件 A-B、B-A 都存的 l₁ = l₂ 积分和相等的 U，只有一起变的方向有导数。T ≈ 0 的金属里力对参数的导数可以很大（只用 Γ 点的 2 原子 Cu 晶胞达 7e3），以力为损失求梯度时宜加展宽；PTBP 的 SCC 容差 1e-5 也限制非变分量导数的精度（M4b 报告第六节）。
  • T ≈ 0、只用 Γ 点的单原子 Cu 晶胞，费米能级搜索可能失败（“Fermi level search did not converge”，与 DFTB+ 同一算法、同一容差）；PTBP 的 k 点规则下这些结构用 k 网格，实际运行不受影响（M4a 报告第六节）。
  • PTBP 损失的梯度（M4c）：M4c 时 r0_d 不改变 SKF（hotcent 2 的微扰约束默认值，M4e 已改回自洽约束，r0_d 重新起作用）。energygeometry 损失在发表的 Cu 参数附近不连续：组 4 的 Birch–Murnaghan 拟合有两个最小二乘解（r0_w 改变 0.005 Bohr 体积比就在 +0.12 和 −0.14 之间跳），组 3 的拟合 B < 0，r0_w = 2.751 时拟合失败、2.789 时体积比 −1.06；梯度只描述当前拟合分支，grad.out 对这样的拟合给出提示。hotcent 的数值噪声使梯度有 1–3% 的不确定度（M4c 报告第七节）。
  • PTBP 默认的 BO（--n_calls 11）实际是种子点加 10 个随机点：skopt 的 gp_minimize 默认先取 10 个随机点，高斯过程不参与选点。要让 BO 起作用，调用次数要明显多于 11（M4c 报告第七节）。
  • GPU（M4d）：本机没有 GPU，GPU 上的正确性和速度都没有实测；MPS、XPU 只保证能运行（自检脚本是唯一的检验）。PTBP 用 GPU 时 DFTB 阶段在主进程里逐个结构计算，只有 GPU 比 CPU 上的多个进程更快才划算；梯度优化器只用 NumPy 后端（M4d 报告）。
  • 非共线自旋（M6a）：磁矩的方向是 SCC 的软方向。没有自旋轨道耦合时整体转动不改变能量，耦合很弱时也几乎不变，DFTB+ 和 pydftb 默认的 Broyden 混合因此可能发散：周期体系里不沿坐标轴的磁矩（CuO 链，各种温度都发散），或 ξ 很小的分子（OH，ξO = 0.0004 Ha）。这些情形用 mixer="pulay" 收敛了；默认仍与 DFTB+ 相同（M6a 报告第五节）。两分量计算只有 NumPy 引擎。
  • DFTB+U 与 onsite 修正（M6b）：DFTB+ 在每个几何步的第一轮 SCC 不加 onsite 势，pydftb 给定电荷（重启、reuse_charges）时第一轮就加，所以 MD 中每步的 SCC 轮数比 DFTB+ 少，轨迹不变。电子数为整数、费米能级两侧有近简并能级时，DFTB+ 的带隙中点费米能级让力与能量差分相差可达 2.7e-7（Cu₄CO 的 Cu p、d 都加 FLL；两个代码相同，fermi_level="exact" 去掉）。CuO 链加 dual SOC 和 +U 的 SCC 很难收敛（M6b 报告第五节）。块势只有 NumPy 引擎。
  • 外场、点电荷与溶剂（M6c）：周期体系的外场是锯齿势，原子跨过晶胞边界时能量跳变（两个代码都警告）；有点电荷的周期体系不给应力（与 DFTB+ 相同）；隐式溶剂只用于分子，不支持 COSMO 和含时外场。pydftb 的 CM5 默认按原文，要与 DFTB+ 25.1 的数值一致需 CM5(double_count=True)；DFTB+ 在 CM5 加氢键修正时的力与能量不符（8.1e-3 Ha/Bohr），外场应力在非立方晶胞中的非对角元有误，pydftb 不复现这两处（M6c 报告第五节）。只有 NumPy 引擎。
  • 激发态（M6d）：简并能级中的态可以任意组合，单个态的振子强度、跃迁偶极、主要跃迁和权重不唯一，只有简并组的和确定（Excitations.degenerate_groups()）；energy 在指定态时仍是基态能量（与 DFTB+ 的输出相同），激发能在 excitation_energy。只有 NumPy 引擎。
  • 激发态的力与 XL-BOMD（M6e）：激发态的力只用于分子、整数占据、一个态，不能与振子窗口、onsite 修正同用（与 DFTB+ 相同），自旋极化时按壳层不同的自旋常数报错；DFTB+ 的激发态力在外场、点电荷、H–X 阻尼、能量窗口下不是能量的导数，pydftb 的是，所以这些组合下两者的力不同（测试用 _excited_compat 复现 DFTB+）。XL-BOMD 的限制与 DFTB+ 相同（SCC、Fermi 展宽，没有自旋、+U、onsite、外场、点电荷、溶剂、激发态的力）；XlbomdFast 的 scale 要按体系试（CuO 链 0.5 也发散）。只有 NumPy 引擎。
  • SCC 的起点与混合器（M6f-1）：逐轮与 DFTB+ 相同依赖于条件好的 SCC：SCC 位点很少时（如 H2O 用 DIIS）混合器的历史矩阵奇异，两个程序的轮数可能不同；周期体系要用 EwaldTolerance = 1e-12 的 DFTB+ 来比较。InitialCharges 按壳层逐层填（与 DFTB+ 相同），过渡金属上常常比默认起点更慢。电荷文件不支持 DFTB+ 为长程校正写的密度矩阵和原子多极。只有 NumPy 引擎。
  • 占据与参数覆盖（M6f-2）：固定费米能级的 SCC 在两个程序中都很脆弱：分子里钉在 Ef 上的半满能级（OH 自由基）不收敛，致密的周期体系可能“跑掉”到所有能带全满（CuO 链）；T = 0 时整数占据来回跳，要加展宽。分数电子数（自定义占据）的分子在 T ≈ 0 时 SCC 误差停在 1e-10–1e-9 的舍入水平，也要加展宽。带电周期晶胞的应力 pydftb 是对的，DFTB+ 的差 1e-8–4e-6（对角、各向同性）。按 k 点填充不支持共线自旋（DFTB+ 25.1 崩溃）。只有 NumPy 引擎。
  • 修正项（M6f-3）：pydftb 按元素识别 H5 的受体与卤素，DFTB+ 按物种名，所以类型标签（如 O2）上两者不同。卤素修正在开关区间内、激发态的力带 H5、偶极修正的应力上，DFTB+ 的结果不是能量的导数，pydftb 的是，两者在这些地方不同（测试用 _halogen_compat、_excited_compat 复现 DFTB+）。偶极修正要求平板法向沿 z、体系中性，不能与固定费米能级、点电荷、外场、XL-BOMD 同用。只有 NumPy 引擎。
  • 分析输出（M6f-4a）：按原子的能量只能与 DFTB+ 比到 8 位小数（detailed.out 的位数）；周期体系要用 EwaldTolerance = 1e-12 的 DFTB+ 来比较。s-dftd3 库的 D3 色散 pydftb 按原子对分配，DFTB+ 平均分给每个原子（测试用 _atom_energy_compat 复现）。DFTB+ 把只 onsite 的三阶记在 ESCC 里，pydftb 记在 e_3rd（电子与总能量相同）。静电势需要 SCC、不能与 GB 溶剂同用；XL-BOMD 的影子能量不能按原子分解。本征向量占 N² × 块数的内存，只在要写文件时开。只有 NumPy 引擎。
  • 局域化、键分析与跃迁电荷（M6f-4b）：Pipek–Mezey 只局域化实数轨道（分子与 Γ 点）——DFTB+ 的 k 点算法用不取共轭的乘积，结果依赖本征向量的任意相位，也不收敛；DFTB+ 的稠密算法用 acos 求旋转角，局域轨道只能确定到约 4e-9，有简并的体系（如 O2）收敛判据只能碰巧满足（泛函与布居仍确定）。Mayer 键级只用于分子、只用总密度（同 DFTB+）。跃迁电荷与 X+Y 一样整体符号任意。
  • 类型切换（M5a）：同一元素的各类型必须有相同的 on-site 能、U、占据数、基组与质量（PTBP 生成的类型满足）；不能与 Casida、XL-BOMD 和分析输出同用（按原子的排斥能等需要混合后的原子对，以后再放开）；窗口越窄、类型差别越大，切换区内的力变化越快，MD 的步长要相应减小（M5a 报告第五节）。只有 NumPy 引擎。
  • 选定壳层（M6f-5）：同一标签两组之间的文件必须是异核格式（没有 on-site 行），同一对标签的所有文件网格相同；不能与自旋轨道耦合、DFTB+U、onsite 修正、Casida、类型切换同用；额外的壳层与近邻重叠太大时重叠矩阵不正定（参数的问题）。只有 NumPy 引擎。
  • 极化率与响应核（M6g-1）：只有 NumPy 引擎；不能与非 Fermi 展宽、溶剂、只 onsite 的三阶（与 DFTB+ 相同）、偶极修正、每个 k 点单独填充、选定壳层同用；周期体系只有电荷响应，没有极化率张量；χ0 是显式矩阵，大体系的内存随壳层数与能级对数增长。
  • 坐标导数与 Hessian（M6g-2）：坐标导数只有 NumPy 引擎、只用于分子（周期体系的 Born 电荷要 Berry 相位，同 DFTB+），不能与 M6g-1 拒绝的组合同用；默认的占据窗口照 DFTB+，金属的响应因此差约 1e-7，filling_tol = 1e-15 给出精确导数；数值 Hessian 会看到 SK 插值在格点处的导数跳变（两个原子的距离正好在格点附近时）。
  • 块势下的响应与点电荷导数（M6g-3a）：只有 NumPy 引擎；onsite 修正让每个原子的整个块成为 χ0 的通道（Cu 的 spd 基 45 个，Cu4CO 共 200 个），大体系时 χ0 的块部分随之变大。点电荷导数与开发版对照，开发版在周期体系中的符号相反（pydftb 不照抄）。
  • 两分量下的响应（M6g-3b）：只有 NumPy 引擎；χ0 是共线时的 4 倍（四个分量），dual SOC 加块势时另有虚部通道；坐标导数只用于分子；弱 SOC 的磁性体系磁化响应大而条件数差（GdO 的软模式），SCC 容差松时 SVD 可能把软模式截掉（有警告）；dual SOC + 块势没有 DFTB+ 的正确解析参考，分子对照 DFTB+ 自己的有限外场，周期体系靠位点势的差分。
  • 两个原子相距不到 0.01 Bohr 时 DFTB+ 报错退出（proximity），pydftb 不报错：完全重合的原子被当作互不作用。已列为待办（dftbplus_map.md 第 36 条）。
  • 用 PTBP 参数表中 Ga 的 r0、p，hotcent 2.1 算不出受限原子（“Eigensolver out of iterations”，4d 壳层几乎不束缚）。
  • physrep.evaluate_pbc 的超胞层数由最短的晶格矢量长度决定，晶胞很斜时会漏掉近邻（γ = 13° 的测试晶胞：22 对中只算 20 对）；Cu 数据集没有遗漏。为了结果不变，没有修。
