# Example 1 — SKF generation from published parameters

Generates Slater-Koster files for H + O using the PTBP published
hyperparameters. **No DFTB+ needed** — only hotcent + physrep + pylibxc.

```
./run.sh
```

Expected:

```
H-H.skf  H-O.skf  O-H.skf  O-O.skf
```

Each .skf has both the band-structure block (H/S integral tables generated
by hotcent) and a Spline block (repulsive potential generated by physrep).
File sizes ~14-17 KB.

This is the fastest end-to-end check that the install is working — see
also `tests/test_skf_generator.py` for the same recipe in pytest form.
